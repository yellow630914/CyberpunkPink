# CyberpunkPink — 緋灣夜行（暫名）

> 狀態：**設計階段，尚未動工**。目前只有文件，沒有程式。所有數值都是初稿。

一款成人向（18+）的賽博龐克跑團風格 RPG 網頁遊戲。架構沿用 [ElondiaRPG](https://github.com/yellow630914/ElondiaRPG)：玩家用 UI 操作，**遊戲引擎**負責所有擲骰與數值，每次行動結束後輸出一份**結構化報告**，再交給 **AI 敘事器**寫成小說式的經過（AI 可以關閉）。

和 ElondiaRPG 不同的地方，是系統不照搬，而是依世界觀重新推導：

- **世界觀**：另一條世界線的 2081 年，緋灣自由市。這條世界線上，腦機介面是從快感迴路突破的——**快感即協定**。所以義體、網路、媒體、戰爭機器全部長在情慾產業上：防火長城叫「粉牆」，入侵對抗電子叫「蕾絲（LACE）」，戰爭機甲是靠全身神經同步駕駛的「女武神機甲」。本質沒變，只是染了色。
- **三條主玩法**：戰鬥（掩體、護甲、義體）、竄網（快駭與深潛）、媒體／中間人（素材、直播、盤口、名冊）。
- **一案一團**：一件案子就是一場跑團——接案、踩點、行動、收尾。
- **成人內容是世界的規則，不是外掛**：神經過載（感載）是和生命值並列的第二條傷害軌，慾望指標就是神經介面的硬體參數。

## 內容聲明

本作是成人向虛構作品。所有登場角色皆為成年人（18 歲以上），這是引擎與內容檢查的硬性規則，不是可關閉的選項。較重口的題材（非自願、契約支配、NTR 等）都可以在「設定 → 內容篩選」關閉，見 [`docs/LEWD_SYSTEM.md`](docs/LEWD_SYSTEM.md) 第 9 節。
