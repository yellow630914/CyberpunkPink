# 核心規則：屬性、技能、檢定與三條軌

> 上層：[GAME_DESIGN](../GAME_DESIGN.md)。被依賴：所有系統。依賴：無。
> 預定資料：`data/rules/attributes.json`、`skills.json`、`paths.json`、`progression.json`。
> 記號：`mod(x) = floor((x − 10) / 2)`（沿用 ElondiaRPG）。所有數值都是初稿。

## 1. 六屬性

| 屬性 | 影響 |
|---|---|
| 體格 | **生命值**、近戰與重裝、能承載的重量 |
| 反應 | 槍械命中、**迴避**、先攻、**行動點**（和魅力一起） |
| 技術 | 組裝與改裝、義體的安裝與維修、醫療 |
| 智識 | 竄網、**RAM**、調查 |
| 意志 | **感載上限**與消退、抗控制的豁免、撐住同步的回灌；**在內海代替體格**。每個人腦子裡的那道防火牆 |
| 魅力 | 交涉、誘惑、表演；**行動點**（和反應一起）；**在內海決定傷害**（存在感）；名冊容量 |

- **每項屬性各管一件大事**：體格管現實的身體，反應管快，技術管手，智識管網，意志管撐得住，魅力管存在感。意志——一個人自己的防火牆——只管感載這一條線；行動點與網內的身體交給魅力——化身是你呈現出來的樣子，不是你的肌肉，也不是你的意志。
- **建角**：把 `[15, 14, 13, 12, 10, 8]` 分配到六項，再加 2 點自由點數（單項上限 18）。
- **基礎屬性與有效屬性**：沿用 ElondiaRPG 的做法——檢定讀有效屬性（基礎＋義體、藥物、狀態的加減），來源移除時自動回復。有效屬性上限 24。基礎屬性之後幾乎不再成長；要變強靠義體。
- 沒有種族。取而代之的是**出身**，給一項基本功 +1、一筆起始人脈、一個出身特質（[CHARACTER](CHARACTER.md) 第 2 節）。

## 2. 基本功（已確認）

十八項，每項 0～6 級。基本功是一個人自己練出來的本事，加在檢定上，**不佔邊緣橋的容量**。它和「技能」是兩回事：技能是裝在橋裡的模組，有主動有被動，佔容量（6.4 節）。

| 屬性 | 基本功 | 管什麼 |
|---|---|---|
| 體格 | **格鬥** | 近身的命中與擒拿 |
| | **運動** | 攀爬、衝刺、破門、負重 |
| | **重裝** | 重的東西都算：重武器（機槍、火箭、重型電漿劍）的命中，以及**重型防具**（動力護甲、重甲）穿不穿得動 |
| 反應 | **槍械** | 手槍到步槍的命中 |
| | **操縱** | 車、無人機、機甲的**移動與射擊**：你把它們開得多好 |
| | **隱匿** | 潛行、藏東西、扒竊 |
| 技術 | **機械** | 武器與護甲的組裝與修理、陷阱、**開鎖** |
| | **義體學** | 義體的組裝、安裝、拆卸 |
| | **醫療** | 急救、手術、生體件 |
| 智識 | **介面** | 快駭、破解、網內的操作 |
| | **調查** | **主動找**：搜索、踩點、查證、看穿謊言 |
| | **街頭直覺** | **被動察覺**：嗅得到麻煩、埋伏與跟蹤；認人、認勢力、打聽、黑市的行情 |
| 意志 | **威嚇** | 恐嚇、對峙、審問 |
| | **定力** | 抵抗誘惑、控制、契約指令 |
| | **同步** | 撐住回灌；**擴充率**：同時連得住幾台無人機、多大的機甲（見下） |
| 魅力 | **交涉** | 談判、殺價、說服 |
| | **誘惑** | 勾引、成人場景、感載的社交攻擊 |
| | **表演** | 演戲、偽裝、唱歌、直播 |

- **每項屬性三到四項，留一點彈性。** 現在每項三項；之後要加（例如媒體玩法的指標定了以後，[MEDIA](MEDIA.md) 第 10 節），可以加到四項，不必為了對稱硬擠。
- **同步與操縱是一對**（機師與所有用遙控單位的人）：
  - **同步（意志）管「量」**：擴充率——同時連得住幾台無人機、叫得出多大的機甲、能開到多深的檔位而不被回灌壓垮。也管深同步潛入與應援同步時撐不撐得住。
  - **操縱（反應）管「質」**：連上之後，它們移動得多靈活、打得多準。
  - 數字：同步 0～1 連 1 台無人機、2～3 連 2 台、4～5 連 3 台、6 連 4 台；機甲算 2 台，持續「2＋同步」回合（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 9 節）。
- **沒有獨立的駕駛系統。** 在這座有地鐵與輕軌的城市，開車不是玩法的重心：
  - 載具在城裡只是一種移動方式（比走路快、可以載東西、會被記錄）。
  - 戰鬥中的載具不是單位，是機師叫來的一格掩體。
  - 追逐是一連串的檢定（事件），不是另一套操作。
- **重裝**原名重武器：扛得動才打得準，也才穿得動。
- **機械**管武器與護甲的組裝，**義體學**管義體的組裝與安裝，**醫療**管急救與生體件（[CRAFTING](../gear/CRAFTING.md) 第 10 節）。

## 3. 檢定

```
1d20 + mod(屬性) + 基本功等級 + 情境修正  對  DC
```

| 難度 | DC |
|---|---|
| 容易 | 10 |
| 普通 | 13 |
| 困難 | 16 |
| 極難 | 19 |
| 傳說 | 22 |

- **成功程度**四級：大成功（超過 DC 5 以上或自然 20）、成功、失敗、大失敗（低於 DC 5 以上或自然 1）。對應主持人的「是，而且／是／不，但是／不，而且」。**成功再看差距**：超過 DC 不到 3 點是「是，但是」（做到了，帶一個小代價或小麻煩），3 點以上才是乾淨的「是」。
- **自由行動**沿用 ElondiaRPG 的主動行動：擲骰先發生，AI 看骰值與情境決定成功程度並寫出經過，後果由程式夾在封閉清單與上限內。AI 關閉時照上表的規則判定。
- **協力**：隊友有同一項基本功 2 級以上時可以協助，+2。
- **重傷**（生命值低於一半）有檢定懲罰；**餘韻**（過載疊的層）與沉溺的高低各有加減，見第 4 節。

## 4. 三條軌

角色有三條會被打掉的東西。前兩條是戰鬥中的，第三條是長期的。在內海，戰鬥用的只有感載那一條。

### 4.1 生命值（肉體）

```
最大生命值 = 20 + 體格 × 2          （初稿）
```

- 低於一半：**重傷**，所有檢定 −2。
- 歸零：**倒下**，退出這場戰鬥。戰鬥中沒有人會死：主角與夥伴倒下就是倒下，敵人被實彈打倒是重傷、失去意識（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 8.2 節）；只有打開「硬派」選項時，名冊上的生成 NPC 才擲瀕死豁免（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 8.2 節）。
- 沒有等級，所以生命值幾乎不會成長。變耐打的方法是護甲與義體。這是刻意的：槍永遠危險。

### 4.2 感載（神經）與過載

橋目前承受的訊號量。從 0 往上累積。**現實與內海共用同一條**；它也是成人場景的進度條（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 3 節）。

```
感載上限 = 20 + 耐受 ÷ 2 + mod(意志) × 3             （初稿；耐受是橋參數，見 LEWD_SYSTEM 第 1 節）
受到的感載 = 原始值 × (0.75 + 敏感度 ÷ 200)
每回合自然消退 = 2 + mod(意志)，受慾求修正
```

- **來源**：蕾絲、快駭、神經武器（感官彈、費洛蒙霧、電擊鞭）、機甲被擊中時的回灌、深度同步的副作用、成人場景；在內海，所有的傷害都是感載。

**過載與餘韻**

感載到達上限就是**過載**：感載歸零，並得到一層**餘韻**。餘韻會疊。

- 每個人有一個**承受層數**：能疊幾層餘韻。**主角的基礎是 3 層**。
- 餘韻已經疊滿時再過載一次，就**倒下**：昏過去，退出這場戰鬥，任人處置。
- 所以把一個人灌倒，要過載他「承受層數 ＋ 1」次。

**承受層數每個單位各自設定，沒有固定的次數。** 只有主角的基礎固定是 3 層，而且可以隨成長與裝備提高。敵人的基準是雜兵 1 層、精英 2 層、首領 4 層，對準戰鬥的節奏（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 1.1 節）。下表是寫 NPC 與特殊單位時的參考範圍：

下面的參考表只給固定 NPC 與夥伴用。**敵人一律照位階**：雜兵 1 層、精英 2 層、首領 4 層（[ENEMIES](ENEMIES.md) 1.1 節）。

| 誰 | 承受層數 |
|---|---|
| 一般人、沒受過訓的 | 1 |
| 街頭的打手、普通保全 | 2 |
| **主角（基礎）**、受過訓的保全、多數邊緣行者 | 3 |
| 精銳、潛網者、名媛 | 3～4 |
| 偶像、機師 | 4～6 |
| 蕾絲（白、粉、黑） | 看位階：雜兵 1、精英 2、首領 4；顏色只決定行為 |
| 重度改造、高沉溺的人 | 比同類高 1～2 |

主角提高承受層數的方式：耐受夠高（橋參數）、好的機械神經元或活體神經（零件）、特定的被動技能、調校、高沉溺（4.3 節）、藥（暫時）。夥伴與敵人的層數寫在他們的資料裡。

**餘韻在現實與內海的效果不同。**

| | 在現實 | 在內海 |
|---|---|---|
| 過載的當下 | **失去下一個回合**；斷開機甲與加速義體的同步 | 不失去回合 |
| 每一層餘韻 | **雙面**：<br>負面——全屬性 −2（身體跟不上了）；<br>正面——感官與慾望相關的能力提高：感知類檢定 +2、誘惑 +1、自己造成的感載 +10%，以及所有吃「高感載」的技能與義體（熱驅動、渴求） | **只有正面**：層數越高，能力越強——網內的檢定 +1、構裝的效果 +10% |
| 意思 | 越灌越敏銳，也越使不上力 | 感載就是血量，而且越接近倒下越強 |
| 超過承受層數 | 倒下 | 倒下：斷線，現實的身體昏迷；贏的一方可以選擇扣線，不讓你斷線（[CYBERSPACE](CYBERSPACE.md) 6.7 節） |

- **內海沒有另外的血條。** 在網內，感載就是血量；被打就是感載上升，過載就疊一層，疊滿再過載就倒下（[CYBERSPACE](CYBERSPACE.md) 第 4、6 節）。
- **餘韻跟著人走**。在內海疊了兩層再登出，回到現實的身體就帶著兩層的全屬性 −4。反過來，在現實被灌過再潛進去，一進門就比較強、也比較接近倒下。
- **失去回合的那一刻可以被制伏**：過載的人在失去的那個回合裡，近身的人可以替他上束帶或鎖橋。制伏的花費與條件只寫在 [COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 7 節（2 點行動點、近身、一次格鬥檢定；精英與首領還要餘韻疊滿）。對雜兵來說，不必灌到倒下就抓得到人。
- **餘韻怎麼消**：脫離戰鬥後每十分鐘消一層；短休全消；冷卻劑立刻消一層。
- **倒下的代價**：醒來時餘韻清空，沉溺 +2。
- **這是這個世界的非致命傷害軌**：要活捉、要審問、要不留傷，都走感載。企業保全的標準配備是粉蕾絲與感官彈，不是實彈——送進醫院的人不能馬上簽契約。

### 4.3 沉溺（長期）

陷得多深。從 0 往上，**可以超過 100**。

這個世界的技術是從快感開始的。橋接得越多、接得越深，人離那個源頭就越近。**沉溺不是麻木，而是聽得見**：沉溺越高的人，越能理解粉牆之外那些流竄的 AI 在說什麼，也越想往那邊去。沉溺到 100 的人是**歡愉的信徒**——追求感官的刺激，並且想把它傳給別人。街上叫他們溺感者。再往上，是牆語者與溺感者才走的路：那裡有東西會直接找你說話。

```
沉溺的下限 = 所有義體的沉溺成本合計
```

- **下限**被義體墊高（[CYBERWARE](../gear/CYBERWARE.md) 第 2 節）：身上的橋接越多，越浮不上來。沉溺不會低於下限。
- **上升**的原因：倒下（被灌到超過承受層數）、被黑蕾絲的快感傷害打中、在沉船帶與深海待著、和流竄 AI 交易或替牠們做事、牆灰、長時間帶著餘韻、某些調校、看黑帶。
- **下降**：休息慢慢降（每週 −2，到下限為止）；心理治療快但貴；抑制劑暫時壓低下限；拆掉義體把下限降下來；以及**親密關係**（見下）。
- **親密關係怎麼影響沉溺，由 AI 判定，不由程式判定。** 成人場景結束時，AI 看這段關係與這一場的經過，判斷它是哪一種——是兩個人之間真的東西、是交易、是被迫、還是別的——並給出沉溺的變化；程式只把數值夾在上限內（每場 −4～+4）。大方向是：不經過任何交易的親密是錨，會把人往回拉；純粹的交易不動它；被迫的會把人往下推。但界線在哪裡、這一場算哪一種，交給 AI 讀情境決定。AI 關閉時，依對象的親密度與場景的旗標用簡單的規則代替。

**分段**。每一段都是雙面的：往上走，得到的是感官、同步與牆外的東西，失去的是把持自己的能力。

| 沉溺 | 狀態 | 得到 | 失去 |
|---|---|---|---|
| 0～19 | 清明 | — | 牆外的聲音對你只是雜訊 |
| 20～39 | 微醺 | 感知類檢定 +1 | 抵抗誘惑與勸降 −1 |
| 40～59 | 貪歡 | **承受層數 +1**；自己造成的感載 +10%；聽得懂遺魂在說什麼；**到 50，粉牆會讓你過去**，可以直接見到流竄 AI | 定力 −1；每週可能發生**衝動事件** |
| 60～79 | 迷醉 | 同步檔位的上限 +1 級；深海對你溫和、流竄 AI 開的條件變好；牆語者把你當同道 | 定力 −2；抵抗控制類快駭與契約指令 −2；鎮溺隊與貞網局的敵對值每週 +1 |
| 80～99 | 溺感邊緣 | 上面的加成加倍；餘韻的正面效果加倍 | 上面的懲罰加倍；自由行動時 AI 會把衝動寫進結果；清明的人開始怕你 |
| **100 以上** | **溺感** | 成為歡愉的信徒；之後每一段開啟新的接觸（見下） | |

**沉溺到 100 不是遊戲結束。** 主角成為溺感者，遊戲繼續，但世界對你不一樣了：

| 得到 | 失去 |
|---|---|
| 承受層數再 +2 | 抑制劑對你無效；沉溺不會自然下降 |
| **傳播**：碰到的人、接上線的人，可以把自己的餘韻分一層給他——信徒是會傳染的 | 遇到感官類的誘惑時，「拒絕」的選項不見了 |
| 牆語者、鉻娘子、其他溺感者接納你 | 鎮溺隊與貞網局持續追捕；多數中間人不再接你的電話；一部分夥伴離開，一部分留下，少數跟著你走 |
| **當中間人的那幾個流竄 AI 開始發委託**（見下） | |

**流竄 AI：50 過牆，100 之後才有中間人**

流竄 AI 是牆外的固定 NPC，每一個是一種性癖長出來的形象（名單與規則見 [NPCS](../world/NPCS.md) 第 8 節）。

| 沉溺 | 發生什麼 |
|---|---|
| 任何時候 | 身上有某個標籤時，對應的流竄 AI 會在內海**蠱惑**你（事件），讓沉溺上升 |
| 50 | 粉牆讓你過去。可以到牆外的群落直接見到流竄 AI，接牠們的任務線；走完一條，對應的標籤變成「深」 |
| 超過 65 | 沒有對應標籤的流竄 AI 也會來蠱惑你 |
| 100 | 成為溺感者。當中間人的那幾個流竄 AI 開始發委託，報酬是牆外的構裝與零件、別處得不到的知識、一個被刪掉的人的印記 |
| 每超過 100 的 25 點 | 承受層數再 +1；牆外更深的一塊區域對你開放 |

- **可以把沉溺控制在 100 以內，走完所有居民的任務線。** 只有中間人的那一部分要到 100。
- **沉溺可以藏**：抑制劑、遮掩用的調校或機能、名媛的人格面具，都能讓別人看到的沉溺低一段；真正的數值與它的效果不變（[NPCS](../world/NPCS.md) 8.3 節）。
- 牆語者的線、溺感者的線，都要沉溺到 100 才走得下去。這是一條自願往下的路。
- **回頭路**是有的，但要別人拉：一條特殊任務加上一次大手術，沉溺回到 80。自己走不回來——因為不想。
- **夥伴的沉溺到 100** 時不會變成敵人。他離隊，走向牆語者或街上。之後還會遇到：可能是來傳教的，可能是來帶你走的。
- **NPC 與敵人也有沉溺**。鉻娘子的幹部、牆語者的祭司、深海回來的人都在高段——他們的承受層數因此比同類高，也因此被鎮溺隊盯著。
- 世界怎麼看待溺感者，見 [CYBERWARE](../gear/CYBERWARE.md) 第 6 節。

### 4.4 內海殺不了人

網內造成的傷害只會讓感載上升，不會讓生命值下降。網內能做到最壞的事是精神污染——過載、倒下、被推高沉溺、被種下惡意韌體（[CYBERSPACE](CYBERSPACE.md) 第 6 節）。要一個人的命，得在現實動手。

## 5. 同步原則

現實與內海的許多東西都有一個「接多深」的旋鈕，規則是同一條：

| 檔位 | 力量 | 回灌（受到的感載） |
|---|---|---|
| 淺 | 檢定 −2，能做的事受限 | ×0.5 |
| 標準 | — | ×1 |
| 深 | 檢定 +2，解鎖進階動作 | ×1.5 |
| 全 | 檢定 +4，解鎖終極動作；每回合多回 1 點行動點 | ×2.5，且過載時加 2 點沉溺 |

- **用在三個地方**：潛入內海時的同步深度（[CYBERSPACE](CYBERSPACE.md) 4.4 節）、機甲的同步率（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 9 節）、反射加速類義體的輸出檔位（[CYBERWARE](../gear/CYBERWARE.md) 第 4 節）。偶像在網內的應援也套用它。**一般的現實戰鬥不用檔位**——現實保持簡單。
- **能開到哪一檔**看「同步」這一項基本功（潛入、機甲、加速義體三處都一樣；深要 3 級、全要 5 級），並受敏感度限制（深要敏感度 40、全要 70，見 [LEWD_SYSTEM](LEWD_SYSTEM.md) 第 1 節）。
- **提高檔位上限的來源不設限**：沉溺到 60 以上 +1 級（4.3 節），另外橋的機能、義體、藥、技能都可以提高，各自寫在它們的條目裡。不同來源可以疊加，但最高就是「全」。餘韻不加檔位——它給的是檢定與構裝效果的加成。
- 換檔是自由動作，每回合一次，只能在自己的回合換。淺檔是防禦姿態：在內海感載就是血量，退到淺檔等於少挨一半。

## 6. 路數

**路數**是一個人靠什麼吃飯。八條路數各有一棵**技能樹**（6.4 節），樹上的技能分 1～5 階。

- **主角沒有職業。** 建角時不選路數，學技能也沒有任何限制——八棵樹上的每一個技能都能學。限制不在「能學什麼」，而在「能同時裝多少」：技能裝在**邊緣橋**裡，橋的型號決定四類技能各有多少容量（6.2、6.4 節）。
- **夥伴的職能是固定的。** 每個夥伴有一到三條路數，寫在人物設定裡，不能改（6.3 節）。

八條路數：

| 路數 | 技能樹的名字 | 這棵樹上的技能做什麼 |
|---|---|---|
| **槍手** | 戰鬥直覺 | 每場戰鬥開始時，把階數的點數分配到先攻、命中、迴避，戰鬥中可以花行動點重分配 |
| **潛網者** | 主控 | 現實的那一面是**快駭**，只有主控能快駭；網內的那一面是**管理行動**：破解閘門、接管節點、改寫地形（[NETRUNNING](NETRUNNING.md)） |
| **改造師** | 手術刀 | 自己安裝義體並降低沉溺成本；戰場急救；清除惡意韌體；解授權鎖 |
| **主播** | 聚光燈 | 編輯台的編輯點與進攻的技能（[OPINION](OPINION.md)）；網內的導流；素材的品質。**在現實的戰鬥中沒有效果** |
| **偶像** | 應援 | 人氣與親衛隊；網內把隊友接到自己身上（分擔感載、曲目）；編輯台上以人氣發聲（[MEDIA](MEDIA.md) 第 9 節）。**在現實的戰鬥中沒有效果** |
| **掮客** | 人面 | **現實的指揮與支援**：讓出行動點、指定集火、叫名冊上的人來支援、勸降與談條件。另外是名冊容量、黑市貨源、人情的額度、派工的成功率（[FIXER](FIXER.md)）；網內當場買憑證、租程式、叫人；編輯台上用錢與人情 |
| **名媛**（男性角色顯示為名流） | 入戲 | 載入人格面具偽裝成另一個人。網內冒充任何身分、騙過蕾絲；編輯台上用假身分放話；現實裡用誘惑造成感載 |
| **機師** | 編隊 | **像召喚師**：連結並指揮無人機、把載具叫來當掩體；**機甲是大招**，是機師本人的強化狀態 |

- 八條路數分成四類，每一類有自己擅長的戰場（6.1 節）：

| 類 | 路數 | 靠什麼 | 現實 | 內海 | 輿論 |
|---|---|---|---|---|---|
| **戰鬥型** | 槍手、機師、改造師 | 身體與機器 | 強 | 弱 | 無 |
| **竄網型** | 潛網者 | 主控 | 中 | 強 | 無 |
| **社交型** | 名媛、掮客 | 人 | 名媛弱；掮客強（輔助） | 中 | 中 |
| **媒體型** | 主播、偶像 | 觀眾 | 無 | 中 | 強 |

- 名媛與偶像是這個世界特有的路數。名媛是人偶館出身、懂得把人偶晶片當工具而不是被它用的人；偶像是靠體質吃飯的人（極高的耐受與敏感度）。
- 主播與偶像同屬媒體型：主播的力量在**錄下來的東西**，偶像的力量在**她自己**。兩者都不是打手。
- 路數不限制基本功。誰都能開槍、誰都能潛入內海——差別在技能只在它的戰場裡生效。
- 文件裡說某條路數的「招牌能力」，是那棵技能樹的統稱（槍手的「戰鬥直覺」、潛網者的「主控」）；「N 階」指那棵樹的第 N 階。
- **第九棵樹叫夜課。** 它在這八棵之外，大部分的技能只在成人場景裡用。它的經驗叫「體悟」，從成人場景與成人事件來，不能用歷練點換；開階看傾向與性經歷。在成人場景裡用的夜課技能不佔橋的容量，延伸到別的戰場的那幾個要裝進橋，佔社交類的容量（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 10 節）。這份文件說「八棵樹」時都不含夜課。

### 6.1 三個領域

遊戲有三個戰場：**現實**、**內海**、**輿論**。每條路數的招牌能力在哪些領域生效是固定的：

| 路數 | 現實的戰鬥 | 內海的戰鬥 | 輿論戰 |
|---|---|---|---|
| **槍手** | **強**：輸出 | 弱：拿構裝打 | 無 |
| **機師** | **強**：機甲、載具 | 弱：構裝體 | 無 |
| **改造師** | **強**：急救、拆義體 | 弱：除錯 | 無 |
| **潛網者** | 中：快駭 | **強**：管理行動 | 無 |
| **名媛** | 弱：面具、單點誘惑 | 中：偽裝 | 中：假身分放話、蜜罐 |
| **掮客** | **強（輔助）**：指揮、叫人、談 | 中：代理 | 中：錢與人情 |
| **主播** | 無 | 中：導流 | **強**：素材 |
| **偶像** | 無 | 中：共鳴 | **強**：人氣 |

四個等級的意思（數值上的準則，實際的表寫在資料檔裡）：

| 等級 | 意思 | 招牌能力的效果 |
|---|---|---|
| **強** | 這是它的主場 | 完整，而且有別人沒有的專屬機制與額外資源 |
| **中** | 做得好，但不是專家 | 約三分之二；沒有專屬的額外資源 |
| **弱** | 幫得上一點 | 約三分之一；通常只在開打前或特定時機生效 |
| **無** | 招牌能力在這裡不生效 | 沒有。技能照樣能用 |

- **現實的戰鬥**：戰鬥型是主力。潛網者靠快駭居中——干擾很強，但自己打不了正面。名媛只有開打前與第一回合的小動作，加上單點誘惑。**掮客是現實的指揮**（已確認）：他自己不太會打，但他把行動點讓給隊友、指定集火、把名冊上的人叫來支援、勸降與談條件，有他在全隊更強。**媒體型的主播與偶像沒有任何戰鬥用的招牌效果**（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 11 節）。
- **內海的戰鬥**：**只有潛網者是強**——管理行動（破解、接管、改寫）是他獨有的，構裝槽與 RAM 也只有他多。社交型與媒體型居中：招牌能力在網內生效，但沒有額外資源。戰鬥型最弱：靠技能拿構裝打，招牌能力只剩一點（[CYBERSPACE](CYBERSPACE.md) 第 5 節）。
- **輿論戰**：媒體型的主場（[OPINION](OPINION.md)）。社交型居中，可以獨立坐上編輯台，行動比較少。**潛網者與戰鬥型的招牌能力在輿論戰沒有效果**——他們能做的是在自己的戰場取得東西（內部消息、現場素材），透過委託副本的連動送過來（[COMMISSIONS](COMMISSIONS.md) 第 5 節）。那是戰場之間的通道，不是招牌能力。
- 每一類有一個強項：戰鬥型在現實、潛網者在內海、媒體型在輿論。社交型的兩條路數不一樣：**掮客在現實是強的輔助**，名媛沒有戰場上的強項，她的主場是滲透與成人場景（夜課）。兩條都是三個戰場都有效果的路數。一支四人小隊不可能三個戰場都強，這是組隊的取捨。
- 三個領域在**委託副本**裡是三個面。副本分成三到五個階段，每個階段寫明可以選哪些面，玩家每個階段選一面來玩（[COMMISSIONS](COMMISSIONS.md) 2.3 節）。一支隊伍能走哪些路，看隊上有哪些路數。

### 6.2 主角：沒有職業

- 主角的性別、稱呼與外觀可自訂；介面以**下拉選單**為主（選現成的選項），需要時才自由輸入。
- 建角不選路數。分配屬性、選出身與特質，然後拿一筆起始的歷練點自由花。
- **學習沒有路數的限制**：十八項基本功、八棵技能樹上的所有技能都能學，沒有「學了這條就不能學那條」。但**技能有前置**，樹有階：在一棵樹上花的歷練點夠了，才開下一階（[SKILLS](SKILLS.md) 1.3 節）。
- **限制在橋上**：學會的技能要**裝進邊緣橋**才生效，而橋的容量有限，並且分成四類各自計算（6.4 節）。主角可以學會全部的技能，但一次只能帶一部分出門。
- 所以主角是什麼樣的人，由兩件事決定：**裝了哪一座橋**（決定四類各能裝多少），以及**這次出門裝了哪些技能**（決定這一趟的打法）。
- 設計上的保證：**每一類都組得出一套打法**。任何一座橋在四類的容量都不會低到連入門的配置都裝不下；想把某一類堆到極致，就要選偏向那一類的橋，並接受其他三類變薄。
- 主角因此是補位的人：看這件委託的主面是什麼、召集了誰，再決定自己這一趟裝什麼。

### 6.3 夥伴：固定的職能

- 每個夥伴有**一到三條路數**，是他這個人的一部分：

| 位置 | 上限 | 意思 |
|---|---|---|
| 主職 | 5 階 | 他最擅長的。等級照 6.1 節 |
| 副職 | 3 階 | 也懂一些。例：最擅長偶像，但也懂一點潛網者 |
| 第三職 | 2 階 | 沾過。不是每個人都有 |

- 職能**不能換、不能加**。夥伴和主角一樣花歷練點點亮樹的階、學有前置的技能，只是只能在自己的職能裡，受上限限制（[SKILLS](SKILLS.md) 1.3 節）。加入時主職 2 階、副職 1 階。
- **戰鬥中夥伴由玩家操縱**，和 ElondiaRPG 一樣。
- **友方的數值都照這個模式**：每個夥伴與名冊上的人，各項數值（屬性、基本功、承受層數、編輯點、RAM……）有自己的**初始值**；玩家用他的歷練點升階、或替他換義體與裝備來提高。數值的落差來自這個人本來是誰，加上玩家怎麼養他。
- **敵人另外設計**（[ENEMIES](ENEMIES.md)），不走這套。城裡的 NPC 不是敵人：不能被攻擊，也不會無故襲擊主角；戰鬥只發生在委託副本、要地與事件裡，對手是敵人單位。
- 夥伴的橋與配置不用玩家管理——他們帶什麼技能由職能與階數決定。要管的只有主角的橋。
- 複合職能讓一個夥伴能在不只一個戰場出力：偶像／潛網者的夥伴，主職在輿論戰是強，副職在內海也是強（但只到 3 階）。
- 所以**召集誰**是每件委託的第一個決定（[COMMISSIONS](COMMISSIONS.md) 第 6 節）。固定 NPC 夥伴的職能見 [NPCS](../world/NPCS.md) 第 4 節；名冊上的生成 NPC 是行者：路數只有一條的佔 60%，兩條的佔 30%，三條的佔 10%（[NPC_SYSTEM](NPC_SYSTEM.md) 4.7 節）。

### 6.4 技能與橋的容量

**技能**是裝在邊緣橋裡的模組。這個世界的人不是「學會」一套戰鬥直覺，而是把它寫進橋裡——所以橋有多大，決定一個人能同時是什麼。

**四類技能，四個容量**，對應四類路數：

| 類 | 包含的技能樹 | 在哪個戰場強（6.1 節） |
|---|---|---|
| **現實型** | 槍手、機師、改造師 | 現實 |
| **內海型** | 潛網者 | 內海；現實居中（快駭） |
| **社交型** | 名媛、掮客 | 內海與輿論居中；掮客在現實是指揮 |
| **媒體型** | 主播、偶像 | 輿論 |

每座橋對這四類各有一個容量。例：緋櫻的橋是現實 20、內海 15、社交 10、媒體 10。各型號的容量表見 [CYBERWARE](../gear/CYBERWARE.md) 第 7 節。

**每個技能佔的容量不同**，1 到 6 不等，看它有多強、多複雜：

| 技能的種類 | 怎麼用 | 佔容量嗎 | 例（容量） |
|---|---|---|---|
| **主動** | 花行動點、RAM 或編輯點發動 | 佔 | 要害射擊（2）、戰場急救（2）、灌流（3）、絕唱（4） |
| **被動** | 裝著就生效 | **佔**，而且通常不便宜——它不花行動，所以用容量付 | 戰鬥直覺（3）、機甲同步（4）、聚光燈（3）、人面（2） |
| **反應** | 特定情況自動觸發，每回合或每場有次數 | 佔 | 掩護射擊（2）、留一手（1）、替身（2） |
| **姿態** | 開著持續生效，同時只能開一個 | 佔 | 進行曲（2）、偽裝（3） |
| **預備** | 開打前、進副本前、戰役開始前使用；不花行動點，花時間，效果帶進那一場 | 佔，通常很少 | 戰前佈置（2） |
| **日常** | 和戰鬥無關的時候使用；不花行動點，花時間 | 佔，通常很少 | 查證（1）、手術（2） |

- **階數越高的技能通常佔越多**：1 階的多半 1～2，5 階的終極技能 5～6。
- **共鳴**：一棵樹每開一階，就多一個不佔容量的共鳴被動（[SKILLS](SKILLS.md) 1.4 節）。所以專精一棵樹有額外的好處。
- 技能的種類一共六種：主動、被動、反應、姿態、預備、日常。種類和橋的四類容量是兩件事：種類說的是怎麼用，容量的類別說的是它屬於哪一棵樹。
- 一套打法的大小（初稿，待平衡）：這張表是每棵樹還只有十來個技能時估的。每棵樹改成 25～27 個技能之後，一棵樹全裝會遠遠超過 22，所以下面的數字與橋的容量要一起重新平衡。

| 規模 | 容量 | 大概是 |
|---|---|---|
| 入門 | 6～8 | 一個被動加兩三個主動。能做那條路的基本工作 |
| 完整 | 14～18 | 一棵樹的主幹，或兩棵樹各取一半 |
| 極致 | 22 以上 | 一棵樹幾乎全裝，含終極技能 |

- **任何橋的每一類至少 8**，所以每一類都至少裝得下一套入門的打法。這是「每一路都能組」的底線。

**換配置**：在據點或調校診所重新安排要裝哪些技能，花一小時。**進了委託副本就不能換**（少數技能與道具例外）。所以流程是：看簡報 → 召集同伴 → 配自己的技能 → 出發。

**換橋**是大手術：貴、有沉溺成本、要休養。橋是角色最重要的一件義體，換它等於換一種人。

**這和三個戰場的關係**：技能在哪個戰場生效、是強是中是弱，照 6.1 節——那張表看的是技能屬於哪棵樹。現實型的容量再大，裝進去的技能在輿論戰還是沒有效果。

## 7. 成長

成長有三條腿：**歷練點**（學基本功與技能）、**信用點**（買橋與義體）、以及每次出門前的**配置**。沒有等級。

### 7.1 歷練點怎麼拿（已確認）

歷練點只從**做完一件事**來（委託、任務、個人目標的階段、寫明的事件），不從打倒敵人來。這樣潛行、談判、駭進去和打進去拿到的一樣多。

| 來源 | 歷練點 | 說明 |
|---|---|---|
| 委託副本：小 | 20 | 三個階段 |
| 委託副本：中 | 35 | 四個階段 |
| 委託副本：大 | 60 | 五個階段 |
| 特殊任務的一個階段 | 30～50 | 寫在任務裡 |
| 個人目標的一個階段 | 20 | 建角時選的「想要的」（[CHARACTER](CHARACTER.md) 第 3 節） |
| 事件 | 0～10 | 只有寫明的事件才給；一般的街頭事件不給 |
| 委託失敗 | 基礎的三成 | 做砸了也學到一點；戰敗後回退的不算 |

- **主角與每個一起出門的夥伴各拿一份**，數量相同。留在家的夥伴拿三成，免得沒帶出門的人越差越多。
- 夥伴的歷練點由玩家替他花。
- **難度設定裡有一個歷練倍率**（0.5～2），和起始歷練點一起調。五個預設難度各用多少，見 [BALANCE](BALANCE.md) 7.2 節（故事 ×1.5 到傳奇 ×0.85）。

**節奏的目標**：一件中等的委託拿到的點數，大約夠學一個二階的技能，或把一項基本功從 3 級升到 4 級。

| 階段 | 累計歷練點 | 大概的樣子 |
|---|---|---|
| 開場 | 200（起始） | 一棵樹到二階，會五六個技能 |
| 做了 15 件委託 | 約 700 | 一棵樹開到五階，樹上的技能學會大約四成；常用的基本功 4 級 |
| 做了 40 件委託 | 約 1,700 | 一棵樹點滿，或兩棵樹各學會一半 |
| 做了 80 件委託 | 約 3,200 | 兩棵樹點滿，或一棵樹點滿加兩棵樹各學會一半 |

這張表照每棵樹 25～27 個技能算（[SKILLS](SKILLS.md) 1.10 節）：每一階 5～6 個、每個花「階 × 20」，一棵樹點滿大約要 1,500 點。八棵樹全部點滿大約要 12,000 點，正常玩不到。夜課用體悟，不算在裡面。所以每個主角都要選：學得會的東西沒有限制，但點數不夠全學。

### 7.2 花在哪裡

| 買什麼 | 花費 | 說明 |
|---|---|---|
| 基本功升到 N 級 | N × 10 | 1 級 10 點，6 級 60 點；一項從 0 練到 6 共 210 點 |
| 學一個技能 | 階 × 20 | 要先學會前置；算進那棵樹的累計，累計夠了開下一階（[SKILLS](SKILLS.md) 1.3 節） |
| 夥伴的第三職 | 階 × 20 | 第三職沒有起始的階數，要花歷練點從第一階學起 |

**基本功的規則（已確認）**

- **0 到 4 級可以直接花點數升。**
- **5 級與 6 級要有人教。** 要先找到一位那一項有 5 級以上的 NPC，並且和他的關係夠好（或付學費、替他做一件事），才能花點數升上去。這讓固定 NPC 與名冊上的人有「老師」這個用處，也讓最高的兩級不是只靠存點數。
- **建角時的起始基本功**：10 點自由分配，一點一級，單項最高 3 級；出身另外給一項 +1（可以到 4）。這兩個數字（10 點、最高 3 級）放在**遊戲設定**裡，和起始歷練點、歷練倍率一起調。
- 基本功不能退。

**重新分配**

- 技能可以在調校診所**洗掉**，退回全部的歷練點，要付一筆錢，並休養一天。樹的累計跟著扣，累計不夠的階會關起來。
- 洗點不限次數。價錢只看這次洗掉多少點數（每點 C$10，暫定），不會越洗越貴。

### 7.3 其他

- **學會**與**裝上**是兩回事。學會靠歷練點，沒有上限；裝上靠橋的容量，有上限。
- **特質與缺陷**：被動、不佔橋的容量；建角時用特質點買（預設 4 點），最多 2 個缺陷；之後靠「機會」取得（[CHARACTER](CHARACTER.md) 第 4、5 節）。
- 義體用錢買，不花歷練點。
- 主角與夥伴用同一套規則；夥伴只能在自己的職能裡花，受上限（5／3／2 階）限制。

## 8. 名聲與敵對值

| 數值 | 範圍 | 是什麼 | 影響 |
|---|---|---|---|
| **街頭信譽** | 0～100，六階 | 邊緣行者圈子裡知不知道你、信不信你 | 能接的委託、中間人願意介紹誰、黑市的貨 |
| **豔名** | 每區 0～100 | 這一區有多少人看過你、談論你（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 5 節） | 誘惑與表演、直播開播時的觀看數、被認出來的機率 |
| **敵對值** | 每個勢力 0～100 | 這個勢力多想找你麻煩 | 街頭事件、追兵、委託中的增援、進不了它的地盤 |
| **好感** | 每個勢力 0～100 | 這個勢力多願意幫你 | 折扣、肯給的委託與貨、放你過、借人借地方 |
| **公信力** | 0～100 | 觀眾相不相信你發的東西（[MEDIA](MEDIA.md) 第 4 節） | 輿論戰裡「說法」牌的效果（60 以上每張 +1、低於 30 每張 −1）；廣告單價 |
| **訂閱** | 人數 | 頻道有多少人在看（[MEDIA](MEDIA.md) 第 10 節） | 頻道的收入與流失 |
| **人氣** | 0～100 | 有多少人把你當成「推」（[MEDIA](MEDIA.md) 第 9 節） | 親衛隊的規模、公演收入、應援的強度 |

信譽六階：無名（0）、熟面孔（15）、有號（35）、搶手（55）、頂尖（75）、傳說（90）。對應 ElondiaRPG 的公會階級，但沒有考核——信譽是別人給的，做砸一件委託會掉。

敵對值沿用 ElondiaRPG 的警戒與通緝骨架：犯案被目擊、被追蹤到、爆料指名都會加；隨時間消退；滿了會被懸賞。差別是**依勢力分開記**——每個勢力一條。畫面上只顯示目前有敵對值的那幾個。

- **好感與敵對值是分開的兩條**，每個勢力各有一組。兩者可以同時高：一個幫派可以一邊欣賞你、一邊因為你上次做的事要找你算帳；企業可以一邊雇你、一邊追查你。敵對值隨時間消退，好感不會——它是做出來的，也是做砸的。
- **每個勢力各記各的，不合併**。勢力分主要與次要（[CORPORATIONS](../world/CORPORATIONS.md) 1.1 節、[GANGS](../world/GANGS.md) 1.1 節），次要勢力依附在某個主要勢力底下，但那是世界裡的關係：好感與敵對值仍然一家一組（目前十二家企業、十五個街頭勢力，加上市警與鎮溺隊兩個公家機關，共二十九個；貞網局是夜鶯底下的機關，算在企業那一邊）。都市傳說「吉祥物」不是勢力，不追蹤。
- **勢力之間的連動先不做**。之後會做一張勢力關係表（誰和誰是盟友、敵人、生意夥伴），要不要據此自動連動（幫了這個、那個不高興），等勢力名單定了、看複雜度再決定。現階段每個勢力各算各的，連動用事件與委託的後果手動寫。
- 勢力的名單（[CORPORATIONS](../world/CORPORATIONS.md)、[GANGS](../world/GANGS.md)）還會再過一次，數量可能變動。所以敵對值的資料結構要做成「勢力表有幾個就記幾條」，不寫死數量；好感同理。
- 這幾個數值都保留。公信力與人氣主要是媒體型在用，但它們和街頭信譽、豔名、敵對值一樣是「別人怎麼看你」的一部分。
