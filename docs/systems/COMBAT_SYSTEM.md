# 戰鬥系統

> 上層：[GAME_DESIGN](../GAME_DESIGN.md)。依賴：[CORE_RULES](CORE_RULES.md)（屬性、檢定、三條軌、同步原則）、[CYBERWARE](../gear/CYBERWARE.md)。被依賴：[NETRUNNING](NETRUNNING.md)（快駭在戰鬥中的行動）、[FIXER](FIXER.md)（案子的行動階段）。
> 來源：ElondiaRPG 的逐回合行動點戰鬥，加上槍戰需要的站位、護甲與彈藥。預定資料：`data/rules/combat.json`、`weapons.json`、`armor.json`、`enemies.json`、`statuses.json`。數值都是初稿。

目標是跑團的槍戰感：**開槍很快、很痛、很少打第二輪**。有掩體的人活，沒掩體的人死；想活捉就換一種打法。

## 1. 回合與行動點

沿用 ElondiaRPG：逐回合，輪到自己時連續行動直到行動點用完或結束回合，沒用完的累積到下回合。

```
先攻 = 1d20 + mod(反應) + 槍手的戰鬥直覺分配
行動點上限 = 4 + floor((mod(反應) + mod(魅力)) / 2)
每回合回復 = 3
```

| 行動 | 行動點 |
|---|---|
| 射擊（單發／點射） | 2 |
| 連射（全自動，見第 5 節） | 3 |
| 近戰攻擊 | 2 |
| 瞄準（下一次射擊 +2；可以指定部位） | 1 |
| 換位（和相鄰那一格的隊友交換，或移到相鄰的空格） | 1 |
| 換彈 | 1 |
| 換武器（主武器、副武器、近戰之間） | 1 |
| 使用道具／急救 | 1～2。**只能用快取格裡的道具**（[EQUIPMENT](../gear/EQUIPMENT.md) 4.1 節） |
| 快駭 | 0～1，另花 RAM（[NETRUNNING](NETRUNNING.md) 第 2 節） |
| 壓制、掩護、待命（反應射擊） | 2 |
| 撤退 | 2，全隊檢定 |

## 2. 站位

不用格子地圖。雙方各有一排**四格的縱深**，面對面排開：

```
        我方                              敵方
  後 ◀──────────── 前      前 ────────────▶ 後
 ┌────┬────┬────┬────┐    ┌────┬────┬────┬────┐
 │ 4  │ 3  │ 2  │ 1  │    │ 1  │ 2  │ 3  │ 4  │
 └────┴────┴────┴────┘    └────┴────┴────┴────┘
  掩體  半掩  半掩  暴露      暴露  掩體  半掩  掩體      ← 每一格的遮蔽，依場景而定
```

**一格一個人。** 每一方最多四個單位在場——正好是委託副本一個面的人數上限（[COMMISSIONS](COMMISSIONS.md) 6.1 節）。大型的單位（機甲、重型無人機）佔兩格。敵人超過四個時，多的在後方等著，有空格才補上來。

### 2.1 遮蔽

每一格有三種遮蔽之一。它是那一格的屬性，站上去的人就得到它：

| 遮蔽 | 迴避 | 備註 |
|---|---|---|
| **掩體** | +4 | 有耐久，會被重武器與霰彈打穿，打穿後降成半掩體 |
| **半掩體** | +2 | 打穿後降成暴露 |
| **暴露** | 0 | |

- 八格的遮蔽由**場景**決定（辦公室的掩體多、停車場少、走廊幾乎沒有），也由**怎麼開打**決定：埋伏的一方多一格掩體，被埋伏的一方全部降一級。這讓「在哪裡開打」是踩點值得打聽的事。
- 掩體可以被製造：潛網者放下防爆門、掮客事先藏好的東西、技能丟出的煙霧（暫時的半掩體）。

### 2.2 距離

兩個單位之間的距離，是兩邊的格數加起來減一：

```
距離 = 我在第幾格 ＋ 對方在第幾格 − 1          （1 到 7）
```

- 雙方的**第 1 格貼在一起**：距離 1，就是**近身**。只有這裡能打近戰。
- 我在第 2 格打對方第 3 格：距離 4。
- 每種武器有自己好用的距離（第 5 節）。太近或太遠都扣命中。這取代了「整場戰鬥共用一個射程」——站在哪一格，決定你的槍好不好用。

| 位置 | 適合誰 |
|---|---|
| 第 1 格 | 近戰、霰彈槍、重甲。貼著敵人，也被敵人貼著 |
| 第 2 格 | 手槍、衝鋒槍、伶人（誘惑要夠近） |
| 第 3 格 | 步槍、潛網者、改造師（搆得到前面的隊友） |
| 第 4 格 | 狙擊槍、無人機的操作者、要被保護的人（主播、偶像） |

### 2.3 近身

雙方第 1 格的人算是**貼在一起**：

- 可以互相近戰。
- 長槍（步槍、狙擊槍）在第 1 格命中 −4。
- 別人朝第 1 格的敵人開槍 −2（怕打到自己人），除非用的是近戰或霰彈以外的精準武器並先瞄準。
- 想離開第 1 格往後換，要先通過運動檢定，否則對面那個人免費打你一下。

### 2.4 換位與陣型

- **換位**：花 1 點行動點，和相鄰那一格的隊友交換，或移到相鄰的空格。
- **補位**：前面的人倒下，後面的人自動往前遞補。所以前排倒了，後排就得面對敵人。
- **推與拉**：有些武器與技能會改變別人的位置——霰彈把人往後推一格、抓捕索把後排的人拉到第 1 格、震撼彈讓兩個人互換。把對方的狙擊手拉到前面，或把自己人推出火線，是戰術的主要來源。
- **打後排**：近戰打不到第 2 格以後的人。要動到後排，靠射程夠的槍、推拉、快駭，或**側襲**——花 2 點行動點並通過隱匿或運動檢定，這一擊無視對方的遮蔽，而且可以打任何一格。
- **開場的排列**：戰鬥開始前，玩家排好四格誰站哪裡；被埋伏時排列是亂的。
- 控制節點被潛網者拿下時，可以改變戰場：關燈（全場迴避 +2，有夜視的不受影響）、放下防爆門（替一格造出掩體，或切斷增援）、接管砲塔（多一個佔格的友軍）。

## 3. 命中

```
攻擊 = 1d20 + mod(反應) + 槍械 + 武器修正 + 距離修正     （近戰用體格＋格鬥；重武器用體格＋重武器）
迴避 = 10 + mod(反應) + 那一格的遮蔽 + 義體
```

- 命中：攻擊 ≥ 迴避。超過 5 以上是**要害**，傷害骰加一顆。自然 20 另擲一次重創（第 6 節）。
- **距離修正**：在武器的適用距離內不扣；每超出 1 格距離 −2（第 5 節）。

## 4. 護甲

護甲與武器都由底材與零件組裝而成（[CRAFTING](../gear/CRAFTING.md) 第 3 節）：護甲值來自板材與纖維，風格來自外皮；槍的傷害與射程來自槍管，射速與彈匣來自機構，智慧功能來自晶片與軟體。下面寫的是組好之後怎麼算。

護甲是服裝與義體給的**護甲值**，每次受到傷害時直接減掉。

```
實際傷害 = max(0, 傷害 − 護甲值 + 穿甲)
```

- **耗損**：每次有傷害穿透，那件護甲的護甲值 −1，戰鬥後要修。皮下裝甲不耗損。
- 護甲越重，隱匿與迴避的懲罰越大，風格也越差（穿全套重甲進夜店是不行的）。**護甲、隱匿、風格三選二**。
- 護甲值量級：街頭服裝 2～4、防彈衣 6～8、軍規 10～12、機甲 15 以上。

## 5. 武器與傷害

| 類型 | 傷害 | 適用距離 | 特性 |
|---|---|---|---|
| 近戰（刀、內藏刃、爪） | 2d6 + mod(體格) | 1 | 只能打近身；穿甲看武器；無聲 |
| 霰彈槍 | 4d6（距離 1～2）／2d6（3 以上） | 1～3 | 打穿遮蔽；把目標往後推一格 |
| 手槍 | 2d6 | 1～4 | 近身不扣；可以藏 |
| 衝鋒槍 | 2d6 | 2～5 | 連射 |
| 步槍 | 4d6 | 3～7 | 連射；穿甲 2；近身 −4 |
| 狙擊槍 | 5d6 | 5～7 | 需要瞄準；穿甲 4；近身 −4 |
| 重武器 | 6d6 以上 | 3～7 | 打穿遮蔽；打相鄰的兩格 |
| 神經武器（感官彈槍） | 2d6～4d6 **感載** | 2～5 | 無視護甲；對沒有橋的目標（機器、車族的純人）無效 |
| 神經武器（電擊鞭、費洛蒙霧） | 2d6～3d6 **感載** | 1～2 | 同上；電擊鞭可以把人拉近一格 |
| 快駭 | 依程式 | 任何距離 | 看得到就打得到；不看遮蔽 |

適用距離是底材與槍管零件的屬性（[CRAFTING](../gear/CRAFTING.md) 3.2 節）：換一根長槍管，步槍的適用距離往後移。

- **連射**：花 3 點行動點與 10 發子彈，命中後超過迴避每 1 點多 2 點傷害（上限武器骰的最大值）。也可以改成**壓制**：不擲傷害，目標區域的敵人要通過定力檢定，否則不能離開掩體。
- **彈藥**要算。彈種（穿甲、空尖、感官、電磁）是換彈時的選擇。

**傷害類型**精簡成七種（ElondiaRPG 是十三種）：

| 類型 | 被什麼擋 | 備註 |
|---|---|---|
| 動能 | 護甲 | 子彈、鈍器 |
| 利刃 | 護甲（軟甲減半） | |
| 熱能 | 護甲減半 | 燃燒彈、雷射；附帶燃燒 |
| 電磁 | 不看護甲 | 對人傷害低，但讓義體失效數回合 |
| 化學 | 密封裝備 | 持續傷害 |
| 神經 | 不看護甲；敏感度與耐受 | 打的是感載 |
| 蝕 | 定力 | 只在網內；在造成感載之外額外推高沉溺。黑蕾絲與少數東西才有（[CYBERSPACE](CYBERSPACE.md) 第 6 節） |

## 6. 重創

自然 20、或單次傷害超過最大生命值的四分之一時，擲一次重創：指定部位（瞄準時由攻擊者選）出事。

- 肢體：那一邊的義肢失效或斷肢，相關檢定 −4，直到手術。
- 頭：暈眩一回合；義眼或甲板損壞。
- 軀幹：流血（每回合 −2 生命值，直到急救）。
- 橋：感載立刻 +10；這場戰鬥的承受層數 −1。

重創是買義體的主要理由之一：斷了的手臂，換一條鉻的比接回去便宜。

## 7. 兩種打法

因為有兩條傷害軌，每場戰鬥開始前有一個隱含的選擇：

| | 實彈 | 神經 |
|---|---|---|
| 打的是 | 生命值 | 感載 |
| 被什麼擋 | 護甲、掩體 | 耐受、心防、冷卻迴路；護甲沒用 |
| 打倒要多久 | 看生命值與護甲 | 要過載對方「承受層數 ＋ 1」次；雜兵一兩次，精銳四五次 |
| 過程中 | 對方低於一半生命值時重傷，檢定 −2 | 對方每過載一次失去一回合，並疊一層餘韻：全屬性 −2，但感官與慾望相關的能力變強（[CORE_RULES](CORE_RULES.md) 4.2 節） |
| 結果 | 死人、熱度高、有聲音 | 活口、熱度低、安靜；可以審問、綁架、勒索 |
| 弱點 | 重甲目標很難打 | 沒有橋的東西打不動；承受層數高的敵人（偶像、機師、高沉溺的人）很難灌倒，而且越灌他的神經攻擊越痛 |

- **制伏**：敵人過載、失去回合的那一刻，花 1 點行動點可以上束帶或鎖橋，他就退出戰鬥。不必灌到倒下。這是對付高層數敵人的正解：灌一次，趁他動不了的時候綁起來。
- **餘韻是雙面的，對敵我都是**。被灌了兩層的槍手打不準了，但被灌了兩層的伶人更危險。玩家自己也一樣：帶著餘韻時，神經類的技能與吃高感載的義體（熱驅動）反而更強。
- 案子常常對打法有要求：「不准死人」「要活的」「做得像意外」。

## 8. 戰敗

全隊倒下或過載時，不是直接讀檔，而是依**誰贏了**進入戰敗事件（沿用 ElondiaRPG 的戰敗事件架構）：

| 對手 | 下場 |
|---|---|
| 天使急救會員資格有效 | 被搶救出來，醒在診所。帳單是一大筆債。案子失敗。 |
| 企業保全 | 被捕。審訊（事件鏈），結局是被植入竊聽花後釋放、被要求簽契約抵罪、或同伴來劫囚。 |
| 市警 | 罰金與拘留；熱度高時轉交企業。 |
| 幫派 | 贖金，或被留下來「還債」（依幫派不同：打黑拳、跑腿、被送去歡場） |
| 拆體客 | 最壞的一種：醒來時少了一兩件義體。 |
| 粉蕾絲（在網內過載） | 身體留在原地，等保全來收。等於被企業保全打敗，除非隊友把你拔線帶走。 |

- 戰敗事件的內容受內容篩選控制（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 9 節）。
- 真正的死亡只發生在瀕死豁免失敗三次且沒有急救。存檔規則可以把它改成一律進戰敗事件。

## 9. 女武神機甲

後期內容。規則骨架先定下來。

- 機甲是一個**有自己生命值、護甲與武器的殼**，機師坐在裡面，用「操甲」技能取代槍械與格鬥。
- **同步率**套用同步原則（[CORE_RULES](CORE_RULES.md) 第 5 節），並加一條：機甲受到的傷害，依檔位有 10%／20%／35%／50% 以感載回灌到機師身上。全同步的機甲快得像活的，但機師是在用自己的神經挨打。
- 機師過載 → 機甲停機一回合。打機甲的正解常常不是打穿裝甲，而是**打到機師受不了**：神經武器對機甲本體無效，但電磁武器會讓回灌比例暫時上升；潛網者可以駭進同步鏈路直接灌感載。
- 徒步小隊對上機甲是一場解謎戰：找掩體、斷它的同步、駭它、或者逃。
- 玩家取得機甲的途徑是機師路數的任務線；維修與彈藥極貴，是「帳單是敵人」的頂點。
- 敵方的企業機師多半是契約人，橋權在公司手上——這是可以用竄網或劇情解決的事。

## 10. 畫面

戰鬥不用格子地圖。探索用格子（走到敵人那一格就開打），戰鬥畫面是另一個畫面——沿用 ElondiaRPG「冒險頁的中欄換成戰鬥畫面」的做法，內容重新設計：

- **雙方各一排四格**，面對面。每格一張卡片，格子底下標著那一格的遮蔽。換位就是把卡片移到隔壁格。一眼看得出誰在前面、誰躲得好、誰貼在一起。
- **選了行動者之後，畫面列出他到每個敵人的距離**，並把他的武器打得到的格子亮起來。
- **每張卡片上有兩條量條**：紅的生命值、粉的感載，底下是餘韻的層數（幾個點）。這兩條並排，是這款遊戲戰鬥的招牌畫面——玩家隨時在看「打哪一條比較快」。
- **先攻條**在最上面，敵我混排。潛入中的隊友、網內的蕾絲也在同一條上，用不同的底色。
- **場景條**在中間：環境（暗、煙、警報中）。控制節點被拿下時，這裡多出可以按的東西（關燈、放防爆門）。
- **行動列**只列現在做得到的事，灰掉的寫明原因（「沒有視線」「RAM 不足」）。招牌能力一顆按鈕展開。
- **雙層戰鬥**時，畫面上方多一個切換：現實／內海。兩邊是同一個版面（網內只有感載一條、遮蔽換成防火牆節點），共用先攻條。不是兩個小遊戲，是同一場戰鬥的兩個房間。
- **手機版**：兩排改成上下堆疊，敵方在上、我方在下。
- 戰鬥結束產生一份 `combat` 報告，AI 寫成一段；AI 關閉時顯示戰報。這一點和 ElondiaRPG 完全相同。

實際的版面樣稿之後畫（[ART_STYLE](../art/ART_STYLE.md) 第 6 節）。

## 11. 每條路數在現實的戰鬥裡做什麼

四類路數在現實戰鬥的分量不同（三個領域的總表見 [CORE_RULES](CORE_RULES.md) 6.1 節）：戰鬥型強，潛網者中，社交型弱，媒體型無。

| 路數 | 分量 | 定位 | 招牌能力在戰鬥中 |
|---|---|---|---|
| **槍手** | 強 | 輸出 | 戰鬥直覺：把階數的點數分配到先攻、命中、迴避，戰鬥中可以花行動點重分配。高階：一回合兩次要害判定、壓制不花彈 |
| **機師** | 強 | 重火力、載具 | 同步：駕駛機甲與載具；徒步時可以遙控一台無人機當第五個單位。高階：遠端呼叫機甲的支援火力 |
| **改造師** | 強 | 治療、拆解 | 手術刀：1 點行動點急救（回生命值、止血、救起倒下的人）；對有義體的敵人近身「拆」——讓一件義體失效，高階直接卸下來；戰鬥中替隊友的義體超頻一回合 |
| **潛網者** | 中 | 干擾、開路 | 介面：快駭（[NETRUNNING](NETRUNNING.md) 第 2 節）——致盲、鎖槍、卡關節、接管場景裡的裝置。**在現實裡他是干擾者，不是輸出**：神經類快駭造成的感載不多，要靠隊友收尾；RAM 的量只有網內的一半。目標義體越多，他越有用 |
| **伶人** | 弱 | 開場、單點控制 | 入戲：戴著面具時第一回合敵人不把她當目標；用誘惑對**一個**目標造成感載（不看護甲，但量不大，每回合一次）。她能讓一個人失去戰力，打不了一群 |
| **掮客** | 弱 | 戰前佈置 | 人面：**戰鬥開始前**用掉佈置次數（階數的一半，至少 1）——買通一名敵人（他第一回合不動）、預先藏好的裝備（開場多一個掩體或一件道具）、叫人（名冊上的一個人在第 N 回合到場）。開打之後他沒有招牌能力可用 |
| **主播** | 無 | — | 聚光燈在現實的戰鬥裡不給任何加成。可以用技能開槍、躲、跑，也可以錄影——錄到的東西是編輯台的牌 |
| **偶像** | 無 | — | 應援在現實的戰鬥裡不給任何加成。她的同步是接在網路上的，不是戰場上；親衛隊也不進戰鬥的公式 |

- **媒體型影響現場的唯一途徑是間接的**：在委託副本裡把輿論指標推高，觸發連動——保全被禁止用致命手段、出現內應、門口擠滿圍觀的人（[COMMISSIONS](COMMISSIONS.md) 第 5 節）。偶像動員親衛隊也走這條路：那是輿論面改變了現實面的條件，不是誰在戰鬥中做了什麼。
- **潛網者居中**：他讓敵人變弱、讓場景變有利，但生命值與火力都不如戰鬥型。
- **社交型的效果都發生在開打前或第一回合**。他們的價值是讓這場架變小，甚至不用打；真打起來要靠別人。
- 隊伍帶著主播或偶像打架，等於帶著一個要保護的人。這是刻意的：她們強的地方不在這裡。
