# 委託副本

> 上層：[GAME_DESIGN](../GAME_DESIGN.md)。依賴：[FIXER](FIXER.md)（接案、踩點、收尾）、[COMBAT_SYSTEM](COMBAT_SYSTEM.md)（現實面）、[CYBERSPACE](CYBERSPACE.md) 與 [NETRUNNING](NETRUNNING.md)（內海面）、[OPINION](OPINION.md)（輿論面）、[CORE_RULES](CORE_RULES.md) 第 6 節（三個領域）。被依賴：[FIXER](FIXER.md) 第 2、3 節。
> 來源：新做。ElondiaRPG 只有特殊任務與事件兩種內容形式；這是第三種。可以借的：一般委託的生成、地下城生成器、特殊地圖。預定資料：`data/rules/commissions.json`、`data/world/commission_maps.json`。數值都是初稿。

## 1. 三種內容形式

| | 特殊任務 | 事件 | **委託副本** |
|---|---|---|---|
| 是什麼 | 人工編寫的任務鏈，用劇情旗標串起來 | 走在路上、待在某處時發生的一件事 | 一件委託的行動階段：一組**獨立的地圖**，分成三到五個階段 |
| 發生在哪 | 城市的地圖網上（街區、要地、內海的固定區） | 當下所在的格子 | **地圖網之外**。從入口進去，做完出來 |
| 數量 | 有限，每一條都是寫出來的 | 幾百件，重複觸發 | 無限：模板 × 生成 × 類型 |
| 會不會重複 | 不會 | 會 | 會，但每次的地圖、敵人、條件不同 |
| 規則 | **傳統的旗標系統**：完成了哪些任務點、立了哪些旗標。沒有主面、沒有階段、沒有路線的限制，怎麼寫就怎麼走 | 條件與效果 | **主面與階段**（第 2～4 節） |
| 給玩家的 | 故事 | 生活感 | **玩法**：這是遊戲的主食 |
| ElondiaRPG 的 | 有 | 有 | 沒有（最接近的是一般委託＋隨機地下城） |

分工很清楚：城市是固定的、有記憶的；委託副本是可以一直玩下去的。特殊任務、委託副本、事件、線索可以歸進同一個**系列**（[SERIES](SERIES.md)）：系列只管分組與分類，讓它們接起來的仍是各自的旗標與計數器。中間人給的一般委託（[FIXER](FIXER.md) 第 3 節）全部是委託副本。

## 2. 一個副本長什麼樣

```
            ┌─────────── 委託副本 ───────────┐
 城市  ──▶ 入口                              出口 ──▶ 城市
（接案、踩點）│  現實面 ── 內海面 ── 輿論面   │       （收尾）
            │   地圖      地圖      棋盤    │
            │   每個階段選一面來玩           │
            │      ╲       │       ╱       │
            │         達成條件              │
            └───────────────────────────────┘
```

每個副本有：

| 部分 | 說明 |
|---|---|
| **類型** | 暗殺、竊密、抹黑、滅火……（第 7 節） |
| **主面** | 每個委託有**一個**主面，由類型決定。目標只能在主面完成；其餘的面是輔助（第 4 節） |
| **三個面** | 現實面、內海面、輿論面。每個副本有其中一到三個 |
| **達成條件** | 做完最後一個階段（第 3、4 節） |
| **連動點** | 前面的階段與輔助面的成果怎麼幫到後面：讓後面的階段變短、變容易、或開出新路（第 5 節） |
| **階段** | 副本分成三到五個階段，每個階段是主面上的一段玩法（2.3 節）。沒有另外的時鐘，壓力來自每個面的壓力條 |
| **封閉** | **進行中不能做副本以外的事**，像 MMO 的副本：城市的地圖、街頭事件、商店、休息、其他委託都暫停；出來只有達成、撤退、全員倒下三種方式；**撤退會把所有進度回退到副本開始前**，委託還在手上（[SERIES](SERIES.md) 第 6 節） |
| **附帶條件** | 不准死人、不准留痕跡、不准曝光……來自簡報 |

### 2.1 三個面

| 面 | 是什麼 | 地圖 | 用哪套規則 | 壓力條 |
|---|---|---|---|---|
| **現實面** | 目標所在的實體場所：辦公樓、倉庫、俱樂部、機房、宅邸、片場 | 1～3 張固定的模板地圖（9×9 ～ 13×9），依類型抽，換上不同的房客、保全與擺設 | 探索、滲透、[戰鬥](COMBAT_SYSTEM.md) | 警戒 |
| **內海面** | 目標的子網，或和這件事有關的網內場所 | 隨機生成（2～4 層）；可能另有一塊**隔離區** | [竄網](NETRUNNING.md)、[網內戰鬥](CYBERSPACE.md) | 追蹤度 |
| **輿論面** | 這件事在九個格子上的樣子 | 不是地圖，是一張棋盤（[OPINION](OPINION.md) 第 3 節） | 輿論戰（SLG） | 沒有；輿論戰本身有回合數的限制 |

- **獨立於地圖網**：副本裡的現實面不在城市的街區圖上，內海面不在企業環礁的固定子網裡。它們是「這件委託的那棟樓」「這件委託的那個子網」，做完就消失。
- 入口在城市裡：接案後，地圖上某個街區出現委託地點的標記，走過去、進去，就進了副本。所以**區還是有意義的**——副本繼承入口所在那一區的治安、增援、物價與勢力。
- **要地不是副本**。緋櫻塔、九號塔這些地方在地圖網上、是固定的、給特殊任務用（[DISTRICTS](../world/DISTRICTS.md) 1.3 節）。副本的現實面是「緋櫻某間分公司的辦公樓」這種不具名的地方。

### 2.2 隔離區

有些子網的核心沒有接上內海——**氣隙隔離**。從網內怎麼打都進不去；唯一的入口是那棟樓裡的資料埠。

這是三個面第一種也是最重要的咬合：**要先在現實面入侵機房，才能潛入被隔離的內海**。隔離區裡通常放著決定性的那一步。

### 2.3 階段、面與分支（已確認）

**一個副本是三到五個階段。** 階段是時間的單位，沒有另外的時鐘與期限。

| 規模 | 階段數 | 歷練點（[CORE_RULES](CORE_RULES.md) 7.1 節） |
|---|---|---|
| 小 | 3 | 20 |
| 中 | 4 | 35 |
| 大 | 5 | 60 |

**每個階段各自寫明可以選哪些面。**

- 每個階段有一份「可選的面」：現實、內海、輿論當中的一到三個。玩家每個階段選其中**一個**來玩。
- **主面只決定最後一個階段是哪一種。** 主面是現實的委託，最後一個階段一定在現實；前面的階段可以是任何面，看這個副本怎麼寫。
- 所以同一個副本可以是「第一階段打輿論戰、第二階段潛進內海、第三階段到現場動手」。也可能第一階段只准選現實，或三個面都能選；每個副本不一樣。
- **輔助面只能部署在這個階段可選、但玩家沒選的面上。** 這個階段只有一個面可選時，就沒有輔助面。

| 這個階段可選的面 | 玩家 | 輔助面 |
|---|---|---|
| 只有現實 | 玩現實 | 不能部署 |
| 現實、內海 | 選一個玩 | 另一個可以派人去 |
| 現實、內海、輿論 | 選一個玩 | 另外兩個都可以派人去 |

**每個階段的流程：**

```
① 看這個階段可選哪些面，選一個自己玩，決定要不要派人去其餘可選的面
② 結算輔助面      派去的人擲一次，可能拿到一個連動（6.4 節）
③ 選分支          在自己選的那一面，有兩到三條路可以走
④ 玩這一段        那一面的玩法
⑤ 拿到里程碑      壓力條結算，進下一個階段
```

**每一面在一個階段裡玩什麼：**

| 面 | 一般的階段 | 當最後一個階段時（決定性的一步） |
|---|---|---|
| 現實 | 一段探索加一場遭遇 | 一場戰鬥，或一次動手的檢定 |
| 內海 | 子網的一層：探索加一場遭遇 | 核心層的戰鬥或下載 |
| 輿論 | 一場短的輿論戰（四回合的小議題） | 一場完整的輿論戰（六回合） |

- **輿論戰開戰前，先結算前面的結果**：前面各個階段選了什麼面、走了哪條分支、輔助面拿到哪些連動，換成牌庫裡的牌、開場的格子、開場的聲量與風向（[OPINION](OPINION.md) 4.5 節）。
- 前面的階段打的輿論戰，結果也是連動：贏了，後面現實或內海的階段多一條分支、少一些敵人。

**分支**是選好面之後、那一段怎麼走的選擇：

| 分支的種類 | 例 | 條件 |
|---|---|---|
| 強攻 | 從正門打進去 | 沒有條件。壓力條漲得最快 |
| 潛行 | 走通風管、偽裝成員工 | 隱匿或表演夠高；直播中不能選 |
| 交涉 | 買通守衛、說服內應 | 交涉或誘惑；或花錢、人情 |
| 連動開出來的路 | 潛網者已經開了門；輿論讓保全不敢開槍 | 前面的階段或輔助面拿到對應的連動 |
| 踩點開出來的路 | 事先知道的後門、班表的空檔 | 踩點時發現 |

- 每個階段、每個可選的面，至少有「強攻」這一條，所以永遠走得下去。
- 選過的面與分支會記下來，影響後面的階段與結算（走過潛行的階段不留目擊者；強攻過的階段讓下一段的敵人有準備）。

**壓力條**每個面一條，整個副本累計：

| 面 | 壓力條 | 滿了會怎樣 |
|---|---|---|
| 現實 | 警戒（0～100） | 到 60 增援加入下一場遭遇；到 100 目標轉移或逃走，最後一個階段變難一級（不是直接失敗） |
| 內海 | 追蹤度（[CYBERSPACE](CYBERSPACE.md) 6.8 節） | 30、60、90 各有東西來；90 被定位 |
| 輿論 | 沒有。輿論戰本身有回合數的限制 | — |

**每個副本要寫的欄位：**

| 欄位 | 內容 |
|---|---|
| 等級 | I～V，和敵人、裝備的等級同一把尺（[ENEMIES](ENEMIES.md) 1.1 節）。副本裡的敵人在這個等級 ±1 |
| 主面 | 最後一個階段的類型 |
| 每個階段 | 可選的面；每個面的分支；每個面的遭遇（位階的組合：四個雜兵、兩個雜兵加一個精英、一個首領加兩個雜兵等）；做完給哪些連動 |
| 戰敗事件 | 用目標勢力預設的，或自訂的；另有一個旗標寫明戰敗算不算委託失敗（第 8 節） |
| 直播目標 | 一到三個，開了副本直播才用得到（[MEDIA](MEDIA.md) 1.2 節） |
| 附帶條件 | 不准死人、不准留痕跡、不准曝光 |
| 輿論戰的開場表 | 有輿論階段時才有：前面的每種結果各換成什麼牌或開場狀態 |

## 3. 里程碑與連動

- **每個階段做完給一個里程碑**。最後一個階段的里程碑就是**決定性的一步**：殺掉那個人、拿到那個東西、贏下那場輿論戰。拿到它，委託達成。
- 原本「每個面一條 0～100 的指標」拿掉了：進度就是做到第幾個階段。
- 每個階段的每個面，做完之後可以給**連動**：對後面的階段有幫助的結果。玩家自己玩的那一面一定給；輔助面要擲過才給（6.4 節）。
- 介面上：上緣是一排階段，寫著每個階段可選的面；已經拿到的連動列在下面，寫著它在哪個階段會生效。踩點可以提前揭開後面的階段有哪些面、哪些分支。

以一件主面是現實的三階段竊取為例：

| 階段 | 可選的面 | 選現實 | 選內海 | 選輿論 |
|---|---|---|---|---|
| 1 | 現實、內海、輿論 | 摸進大樓，拿到門禁卡 | 進訪客層，偷到員工憑證 | 打一場小輿論戰，讓這家公司忙著滅火 |
| 2 | 現實、內海 | 到達目標樓層 | 接管這棟樓的控制節點 | — |
| 3（主面） | 只有現實 | **進保險庫，拿到實體的晶片** | — | — |

## 4. 主面與輔助面

**每個委託有一個主面，由它的類型決定。主面是最後一個階段的類型：決定性的一步一定在主面完成。** 前面的階段可以選別的面來玩，或派人去當輔助（2.3 節）。

| 主面 | 這類委託的目標 | 為什麼只能在這裡 |
|---|---|---|
| **現實** | 殺一個人、毀掉一樣實體的東西、帶走一個人或一件物品、護送、討債 | 內海殺不了人、碰不到實體（[CYBERSPACE](CYBERSPACE.md) 第 6 節的「精神污染」）；輿論只能毀掉名聲 |
| **內海** | 偷資料、刪資料、改資料、打撈、對一個人的心智動手（讓他忘記、讓他崩潰、在他的橋裡種東西） | 資料在網裡；精神污染只有網內做得到 |
| **輿論** | 抹黑、爆料、滅火、造勢、洗白 | 「大家怎麼想」只能在編輯台上改變 |

**達成條件只有一條：做完最後一個階段。**

連動能做的三種事（玩家自己玩的階段與輔助面都會給連動）：

| 連動的種類 | 意思 | 例 |
|---|---|---|
| **代勞** | 讓後面某個階段變短：那個階段的遭遇少一半，或不必探索直接到遭遇 | 內海的階段接管了門禁 → 後面現實的階段不必探索，直接到遭遇 |
| **減壓** | 後面的階段變容易：敵人變少、變弱、變慢，壓力條漲得慢 | 前面的輿論階段大勝 → 後面現實階段的保全被禁止用致命手段 |
| **開路** | 替後面的階段開出原本沒有的分支，或原本進不去的地方 | 現實的階段插上機房的資料埠 → 內海的隔離區打開 |

- **最後一個階段只有主面可選**，所以沒有輔助面。那一步——扣扳機、按下載、讓風向定案——一定由玩家在主面做。
- **可以一路走到通**：只帶隊伍，不從名冊找人去輔助面。這永遠可行，只是硬，但錢與人情都省下來了。
- **可以分多路進攻**：每個階段分一部分人去其餘可選的面，替後面的階段拿連動。人手分散，但後面的階段更容易。
- **有些委託前面有必經的階段**：資料存在隔離區的竊密案，主面是內海，但不先在現實的階段入侵機房，內海的最後一步就做不了。這種階段只開一個面，簡報或踩點時會標明。
- 簡報會說主面是什麼（「這是一件要動手的委託」）。後面的階段有哪些面、哪些分支，要踩點才知道。

**特殊任務沒有這些限制。** 它們用傳統的劇情旗標：到某地、和某人談、打贏某場、做某個選擇。要在現實還是在網內、要不要打輿論戰，由那條任務線自己寫，不套主面與階段。

## 5. 連動

連動是前面的階段幫到後面的階段的方式（代勞、減壓、開路，見第 4 節）。玩家自己玩的那一面做完一定給連動；輔助面要擲過才給（6.4 節）。每個副本生成時帶二到四個連動，踩點可以提前知道。下表列出常見的連動。

| 在哪一面 | 做了什麼 | 幫到後面哪一面的階段 | 效果 |
|---|---|---|---|
| 現實 | 插上機房的資料埠 | 內海 | **開啟隔離區**；或直接從核心附近進入，略過外面幾層 |
| 現實 | 活捉一名主管 | 內海 | 取得管理憑證：內海階段的閘門不用破解 |
| 現實 | 拿到實體文件，或拍到現場 | 輿論 | 牌庫多一張和議題有關的料；或開場聲量 +3 |
| 現實 | 切斷大樓的電力或網路 | 內海 | 蕾絲降一級；追蹤度的上升減半 |
| 內海 | 接管控制節點 | 現實 | 開門、關攝影機、停砲塔、放下防爆門（[NETRUNNING](NETRUNNING.md) 第 4 節） |
| 內海 | **取得內部消息**（郵件、帳目、通訊紀錄） | 輿論 | 牌庫多一張「內幕」牌（聲量 +4，對手不能下架） |
| 內海 | 竄改班表或調度系統 | 現實 | 下一個現實階段的巡邏減半；增援延後 |
| 內海 | 駭進平台 | 輿論 | 開場就佔著主流的一格 |
| 輿論 | 這一場小勝 | 現實 | 現場有圍觀的人與記者，保全綁手綁腳（多一種掩護，也多一種麻煩） |
| 輿論 | 這一場大勝 | 現實 | 保全被上層禁止使用致命手段；出現願意開門的內應 |
| 輿論 | 這一場大勝 | 內海 | 目標子網的追蹤度起始值降低 |
| 輿論 | 走了「假消息調虎離山」的分支 | 現實 | 下一個現實階段的警戒不上升，或增援去了錯的地方 |

- 連動有好處，也有麻煩：對手在輿論戰輸了，可能改用實體的手段，派人去找主播的身體（[OPINION](OPINION.md) 第 6 節）。前面的輿論階段打輸了，後面階段的警戒會提高。
- 最漂亮的打法是把三個面串成一條鏈：第一階段在內海取得內部消息，第二階段拿這張牌打贏輿論戰，第三階段現實的門有內應替你開。

## 6. 怎麼玩

### 6.1 召集與分工

**行動開始前召集同伴。** 走到委託地點、進入副本之前，從名冊（[FIXER](FIXER.md) 第 6 節）選這次要帶的人。

- **隊伍**：最多 4 人，含主角；另外最多 2 位不打仗的同行（[NPC_SYSTEM](NPC_SYSTEM.md) 10.0 節）。隊伍整趟都跟著玩家選的那一面走。
- **輔助面另外找人**：不從隊伍裡分，直接從名冊上找（6.5 節）。所以派人去輔助面不會讓玩家那一面少人。
- 帶越多人，報酬分得越薄，名冊上的人也不是每次都有空。
- **配自己的技能**：主角進副本前在據點決定這一趟裝哪些技能（[CORE_RULES](CORE_RULES.md) 6.4 節）。進去之後不能換。
- **看職能召集**：主角沒有職業，什麼都能碰一點；夥伴的職能是固定的，每人一到三條路數（[CORE_RULES](CORE_RULES.md) 6.2、6.3 節）。這件委託的主面是什麼、打算開幾條輔助的路，決定該找誰。

| 去哪 | 人在哪 | 誰在這裡強 |
|---|---|---|
| 現實面 | 現場 | 戰鬥型與掮客（強）；潛網者（中）；藝人負責開打前的事（弱） |
| 內海面 | 身體在安全屋或現場的接入點，意識在網內 | 潛網者（強）；社交型與媒體型（中）；戰鬥型（弱） |
| 輿論面 | 編輯台（據點、轉播站、或任何有訊號的地方） | 媒體型（強）；社交型（中） |

- **玩家每個階段只玩自己選的那一面**（已確認）：隊伍由玩家操作。**其餘可選的面由數值結算**：從名冊找人去（6.5 節），每個階段擲一次（6.4 節）。
- **沒有人去的面，什麼都不會發生**。主角一定在玩家選的那一面。

### 6.2 階段

副本的時間單位是階段，流程見 2.3 節。這裡補充幾條：

- 每個階段先結算輔助面，再進玩家選的那一面，所以輔助面拿到的連動這個階段就生效。
- 玩家在現實的階段裡照常可以用快駭（站在現實丟程式）；它不算去了內海。
- 階段之間不能回城、不能補給、不能換技能配置（副本是封閉的）。
- **每個階段在城市那邊算 2 小時**，所以一個副本大約是一個晚上。出來之後，城裡的時間照這個數字往前走。
- **每兩個階段之間可以喘一口氣一次，沒有代價**（已確認）：彈匣補滿，感載與餘韻帶著走。消耗品用掉多少就少多少。

### 6.3 一個人怎麼玩三個面

- **玩家每個階段選一面來玩**，最後一個階段一定是主面。
- **輔助面是一個決策，不是一場操作**：這個階段還有哪些面可選、派誰去、派幾個人，結果每個階段結算一次（6.4 節）。
- 只想打的玩家：專接主面是現實的委託，輔助面不派人也行。想要全貌的玩家：多接主面不同的委託，並用好的輔助配置把主面變輕鬆。

### 6.4 輔助面的結算（已確認）

每個階段開始時，每個有人去的輔助面（這個階段可選、但玩家沒選的面）擲一次：

```
1d20 + 那一面最高的相關基本功 + 分量修正 + （人數 − 1）   對   10 + 副本的等級 × 2
分量修正：那個人的路數在那個戰場是強 +4、中 +2、弱 +0
```

| 結果 | 發生什麼 |
|---|---|
| 超過 5 以上 | 拿到這一面的下一個連動，並且這一面的壓力不漲 |
| 成功 | 拿到下一個連動 |
| 失敗 | 沒拿到；這一面的壓力 +10（輿論面沒有壓力條，不加） |
| 自然 1 | 出事：有人過載或受傷，這一面的人要撤一個階段 |

- 拿到的是那一面在這個階段寫好的連動，當場生效：可能是多一條分支、少一些敵人、或讓後面的階段變短。
- 沒有人去的面不擲，也不會出事。

### 6.5 輔助面從名冊找人（已確認）

進副本之前，替每個可能用到的輔助面安排人手。每一面派 1～2 個人，都從名冊上**不在隊伍裡**的人找。要讓對方肯去，有四種辦法：

| 辦法 | 怎麼做 | 代價 |
|---|---|---|
| 付錢 | 付他的出場費（[NPC_SYSTEM](NPC_SYSTEM.md) 10.5 節）。固定夥伴照分紅拿一份 | 錢 |
| 用人情 | 用掉一個他欠你的人情 | 一個小人情 |
| 欠人情 | 他答應，但你欠他一個人情 | 你欠他一個小人情（[FIXER](FIXER.md) 第 8 節） |
| 靠交情 | 擲交涉（魅力），對 20 − 他對你的親密度 ÷ 5。忠誠 70 以上的人不用擲 | 失敗的話，這一次他不肯，這個辦法不能再用 |

- **名冊上沒有合適的人時**，可以向中間人臨時借一個：照那件委託的等級生成一位行者，只能付錢，價錢是出場費的 1.5 倍，而且沒有分量修正。
- 派去的人一路待在那一面，到副本結束。某個階段那一面不能選的時候，他們那個階段不擲。
- 派去的人擲出自然 1 出事時，事件照常發生在他們身上（受傷、被捕），出了副本之後會變成一件要處理的事。
- **掮客的人面**讓這件事比較容易：每一階讓付錢的價錢便宜一成，靠交情的難度 −1。

## 7. 委託的類型

每種類型有一個**主面**（★），最後一個階段一定在這一面。其餘三種記號說的是前面的階段多常開出那一面：◐ 常見、○ 偶爾有、— 不會有。

| 類型 | 現實 | 內海 | 輿論 | 決定性的一步 | 前面的階段在別的面通常拿到什麼 |
|---|---|---|---|---|---|
| **暗殺** | ★ | ◐ | ○ | 殺掉目標 | 內海：定位他、關掉他的保全系統。輿論：把他引到公開場合 |
| **破壞** | ★ | ◐ | ○ | 毀掉那樣東西 | 內海：關閉安全系統、解鎖 |
| **奪取（實體）** | ★ | ◐ | — | 把東西拿到手 | 內海：門禁、位置、密碼 |
| **挖角／綁架** | ★ | ◐ | ○ | 把人帶出來 | 內海：處理他的橋權，不然帶出來也會被遠端鎖死 |
| **護送** | ★ | ○ | ○ | 人安全抵達 | 內海：路線上的監視器。輿論：全城在看，對方不敢動手 |
| **救援** | ★ | ◐ | ○ | 把人帶出來 | 內海：找出他被關在哪、關掉門禁 |
| **討債／回收** | ★ | ○ | — | 拿到錢或義體 | 內海：查出他把錢藏在哪 |
| **蜜罐** | ★ | — | ◐ | 取得把柄 | 輿論：事先把目標捧高，他才會上鉤 |
| **接待** | ★ | ○ | ○ | 受雇陪一個人一段時間，讓他滿意 | 內海：讀他的橋或紀錄，知道他喜歡什麼。輿論：事先替你造勢，他會更想見你 |
| **獵溺** | ★ | ◐ | ○ | 搶在鎮溺隊之前制伏那個溺感者並帶走（委託人多半要活的） | 內海：找出他在哪、把他從線上引開。輿論：讓鎮溺隊晚到 |
| **竊密（資料）** | ◐ | ★ | — | 下載檔案 | 現實：偷憑證、插資料埠直通核心；**有隔離區時，現實的階段是必經的** |
| **抹除** | ○ | ★ | ○ | 刪掉資料與備份 | 現實：毀掉離線的備份 |
| **竄改** | ○ | ★ | ◐ | 改掉紀錄 | 輿論：讓改過的版本被當成真的 |
| **心智**（讓人忘記、崩潰、聽話） | ◐ | ★ | ○ | 對目標的橋造成指定的精神污染 | 現實：讓他待在接得上線的地方 |
| **網內打撈** | — | ★ | — | 把東西從沉船帶帶出來 | 沒有別的面 |
| **抹黑** | ○ | ◐ | ★ | 贏下最後一場輿論戰 | 內海：內部消息換成一張「內幕」牌。現實：蜜罐、拍到現場 |
| **爆料** | ◐ | ◐ | ★ | 贏下最後一場輿論戰 | 現實與內海提供證據；沒有證據的爆料，牌庫裡只有基本牌 |
| **滅火** | ◐ | ◐ | ★ | 贏下最後一場輿論戰（守住自己的格子） | 現實與內海：找出並毀掉對方的料，對手的牌庫少幾張 |
| **造勢／洗白** | — | ○ | ★ | 贏下最後一場輿論戰 | 內海：駭進平台，開場先佔一格 |

- 同一個東西可以是不同的委託：一份機密，要**實體的晶片**是奪取（主面現實），要**裡面的資料**是竊密（主面內海）。委託人要的是哪一個，簡報會說。
- 中間人的門路決定他給哪些類型（[DISTRICTS](../world/DISTRICTS.md) 第 12 節）：舊港的帳房多半給現實的；地下層的探員給內海的；玻璃岸的製作人給輿論的。
- **委託人不一定是人**：沉溺到 100 的主角會接到流竄 AI 發布的委託（[NPCS](../world/NPCS.md) 第 8 節）。四十二個流竄 AI 裡只有五個是中間人（夜后、陛下、@all_eyes、還沒好、Ａ子）。牠們是牆外的中間人：規則相同，門路照牠是哪一種性癖，報酬不是錢。
- **同一件事可以從兩邊接**：一個中間人發抹黑案，另一個同時發滅火案，對手是另一隊邊緣行者。

### 7.1 每種類型的階段怎麼排（已確認）

下表是每種類型在**小型（三個階段）**時的樣子。方括號裡是那個階段可以選的面，最後一個階段只有主面。

| 類型 | 第一階段 | 第二階段 | 最後階段 |
|---|---|---|---|
| 暗殺 | 找到他〔現實、內海、輿論〕 | 靠近他〔現實、內海〕 | 動手〔現實〕 |
| 破壞 | 摸清楚〔現實、內海〕 | 進去〔現實、內海〕 | 毀掉它〔現實〕 |
| 奪取（實體） | 摸清楚〔現實、內海〕 | 進去〔現實、內海〕 | 拿到手並帶出來〔現實〕 |
| 挖角／綁架 | 接觸他〔現實、輿論〕 | 處理他的橋權〔內海、現實〕 | 把人帶出來〔現實〕 |
| 護送 | 出發前的安排〔現實、內海、輿論〕 | 路上〔現實〕 | 抵達〔現實〕 |
| 救援 | 找到人〔現實、內海〕 | 進去〔現實、內海〕 | 把人帶出來〔現實〕 |
| 討債／回收 | 找到人或錢〔現實、內海〕 | 上門〔現實〕 | 收走〔現實〕 |
| 蜜罐 | 接近他〔現實、輿論〕 | 獨處〔現實〕 | 取得把柄〔現實〕：一場有目的的成人場景，或一場套話的對峙 |
| 接待 | 打聽他的喜好〔現實、內海〕 | 赴約，打扮與暖場〔現實、輿論〕 | 取悅〔現實〕：一場目的是「取悅」的成人場景，結算看契合 |
| 獵溺 | 找出他在哪〔現實、內海〕 | 搶在鎮溺隊之前〔現實、輿論〕 | 制伏並帶走〔現實〕 |
| 竊密（資料） | 拿到入口〔現實、內海〕 | 往下一層〔內海；有隔離區時只有現實〕 | 下載〔內海〕 |
| 抹除 | 找出備份在哪〔內海、現實〕 | 毀掉離線的備份〔現實、內海〕 | 刪掉核心的資料〔內海〕 |
| 竄改 | 拿到權限〔內海、現實〕 | 鋪路，讓改過的版本有人信〔輿論、內海〕 | 改掉紀錄〔內海〕 |
| 心智 | 讓他上線〔現實、輿論〕 | 進他的橋〔內海〕 | 動手〔內海〕 |
| 網內打撈 | 下潛〔內海〕 | 找到它〔內海〕 | 帶出來〔內海〕 |
| 抹黑 | 找料〔現實、內海〕 | 備料，或先放風聲〔現實、內海、輿論〕 | 輿論戰〔輿論〕 |
| 爆料 | 找證據〔現實、內海〕 | 查證，或先放風聲〔現實、內海、輿論〕 | 輿論戰〔輿論〕 |
| 滅火 | 找出對方手上的料〔現實、內海〕 | 毀掉它、買下它，或先帶風向〔現實、內海、輿論〕 | 輿論戰〔輿論〕 |
| 造勢／洗白 | 備料〔現實、輿論〕 | 鋪路〔內海、輿論〕 | 輿論戰〔輿論〕 |

護送與救援已經分成兩種（已確認）。

- **中型多一個中段的階段，大型多兩個。** 多出來的階段插在第二階段的前後，內容是那一型的變化：多一道門、多一層子網、中途出了狀況。
- **每個副本至少有一個階段可以選兩個以上的面**，網內打撈除外。這樣玩家至少有一次機會選擇，也至少有一次機會派人去輔助面。
- **生成時的詞條可以把某個階段鎖成只有一個面**（例如「今晚子網在維護」讓內海選不了）。
- 非最後階段選到輿論時，打的是四回合的短輿論戰。
- 表裡寫的是這一型最常見的排法。人工寫的委託可以不照它，只要最後一個階段在主面。

### 7.2 這些是模板（已確認）

第 7 節的類型表與 7.1 節的階段排法是**模板**，放在資料檔（`data/rules/commission_types.json`），一種類型一筆。

- **生成**一般委託時，程式拿模板，再套上委託人、目標勢力、現實面的地圖、內海的參數、議題與詞條（第 9 節），做出一件具體的副本。
- **人工寫的委託**（特殊任務裡的、主線的）不必照模板，直接寫一件具體的副本（[DATA](DATA.md) 第 9 節的格式）。
- **之後的內容編輯器**兩種都能改：改模板，之後生成的委託都跟著變；改一件具體的副本，只影響那一件。內容編輯器還沒寫（[ROADMAP](../plan/ROADMAP.md)）。

## 8. 路線與後果

達成之後，依**每個階段走了哪一面、哪條分支**結算。同一份報酬，不同的餘波：

| 怎麼做的 | 留下什麼 | 額外得到 |
|---|---|---|
| 每個階段都強攻 | 痕跡最重（硬闖的現場、被追蹤的入侵、公開的敵人） | 沒有 |
| 有階段走了現實 | 目擊者、監視畫面。目標勢力的敵對值上升 | 實體的戰利品 |
| 有階段走了內海 | 追蹤紀錄。夜鶯與貞網局的敵對值上升 | 資料：可以賣、可以當素材、可以當下一件委託的憑證 |
| 有階段走了輿論 | 一個公開的敵人 | 觀眾、公信力、人氣 |
| 走了潛行或交涉的分支 | 那個階段不留目擊者 | 評價加分 |
| 沒有派人去輔助面 | 沒有額外的痕跡 | 最少的人分最多的錢 |

- **戰敗事件**（已確認）：每個副本都要設定一個。它用目標勢力預設的，或自訂的。**戰敗不等於委託失敗**；委託失敗由一個旗標控制，有些委託要刻意戰敗才走得到某條分支。大部分的委託是戰敗 → 戰敗事件 → 委託失敗 → 回退到進副本之前，紀錄、性經歷與記憶保留（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 8.4 節）。
- **評價**看附帶條件、壓力條的高低、拿到幾個連動。評價影響街頭信譽與報酬的加成；歷練點照規模固定給（2.3 節），不看評價。
- **沒有「部分完成」**（已確認）：副本沒有做完最後一個階段，就是沒有達成。撤退與委託失敗都回退到進副本之前，副本裡拿到的東西不留（[SERIES](SERIES.md) 第 6 節）。

## 9. 生成

一個副本＝**類型 × 委託人與目標勢力 × 現實面模板 × 內海面生成參數 × 輿論面的議題 × 連動點 × 詞條**。

| 部分 | 來源 |
|---|---|
| 現實面模板 | 手工畫的固定地圖，約 24 張起：小辦公室、辦公樓層、倉庫、機房、俱樂部、人偶館、診所、宅邸、片場、碼頭貨櫃區、公寓、停車場……每張標了可以放目標、資料埠、入口的位置 |
| 現實面的內容 | 依目標勢力放保全（[CORPORATIONS](../world/CORPORATIONS.md) 第 7 節的敵人類型）、依等級與位階定數量（[ENEMIES](ENEMIES.md)） |
| 內海面 | ElondiaRPG 的地下城生成器（[CYBERSPACE](CYBERSPACE.md) 第 8 節）；蕾絲的風格依企業 |
| 輿論面 | 議題模板 × 對手的公關強度（[OPINION](OPINION.md) 第 5 節） |
| 詞條 | 一兩個讓這次不一樣的條件：「今晚有派對」「正在換班」「目標不在預定的位置」「另一隊人也在裡面」 |

- **現實面用固定模板，不用隨機生成**——現實的地圖應該看起來是人蓋的。重玩的變化來自內容與詞條，不是牆的位置。
- 生成的結果存在存檔裡，重新整理不會變。

## 10. 四個例子

**暗殺（主面：現實，三個階段）**
委託人要星旗的一名軍需官死。內海殺不了人，最後一步只能在現實做。
- 第一階段可選現實與內海。玩家選內海：潛進他宅邸的子網，關掉警報，把他的位置報出來。這個階段的連動是「下一個現實階段不必探索」。
- 第二階段可選現實與輿論。玩家選現實，從踩點發現的後門摸到他那一層樓。另外派偶像去輿論面，擲成功了，拿到「護衛被叫去應付記者」，最後一場遭遇少兩個人。
- 第三階段只有現實：打穿剩下的護衛，扣扳機。
- 想一路走到通的玩家，三個階段都選現實的強攻分支，一樣走得完，只是每一場都比較硬。

**竊取機密（主面：內海，四個階段，中間有必經的現實階段）**
委託人要蜜腺的一份配方。他要的是資料，所以主面是內海。
- 踩點發現配方存在隔離區，從網內進不去。
- 第一階段可選現實與內海：摸進實驗室拿門禁卡，或進訪客層偷員工憑證。
- 第二階段可選現實與內海：到達機房那一層，或接管這棟樓的控制節點。
- 第三階段只有現實，是必經的：進機房，插上資料埠（開路：隔離區打開）。
- 第四階段只有內海：一個人在機房裡接線潛入，在核心層下載。

**抹黑（主面：輿論，三個階段）**
委託人要讓星旗的一位領事下台。名聲只能在編輯台上毀掉。
- 第一階段可選現實、內海、輿論。玩家選內海：進領事館的子網，拿到一批內部郵件。連動是牌庫多一張對手不能下架的「內幕」牌。同一個階段派藝人去現實認識領事的秘書，擲成功了，對手在最後一場的第一回合少 2 點公關點。
- 第二階段可選現實與輿論。玩家選輿論，打一場四回合的小輿論戰，贏了，最後一場開場就佔著一格。
- 第三階段只有輿論：打完整的六回合，讓風向定案。
- 一路走到通的玩家三個階段都坐在編輯台上，只用手上的基本牌和星旗的公關拉鋸。這樣做得到，但牌比較差。

**救援（主面：現實，三個階段）**
一名契約人從伊甸園逃出來，要送到蜜糖會。
- 第一階段可選現實與輿論。玩家選輿論：偶像在編輯台上表態、動員親衛隊，這一場大勝。連動是後面的現實階段裡，伊甸園的回收員被禁止動手，只能跟著。
- 第二階段可選現實與內海：帶著人穿過四十二番街，或先進內海把路線上的監視器關掉。
- 第三階段只有現實：甩掉最後一批追兵，讓人走進糖罐的門。
