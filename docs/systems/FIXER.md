# 中間人與委託

> 上層：[GAME_DESIGN](../GAME_DESIGN.md)。依賴：[CORE_RULES](CORE_RULES.md)（街頭信譽、敵對值）、[COMBAT_SYSTEM](COMBAT_SYSTEM.md)、[NETRUNNING](NETRUNNING.md)、[MEDIA](MEDIA.md)。被依賴：無（這是把所有系統串起來的那一份）。
> 來源：ElondiaRPG 的公會委託與階級、特殊任務與劇情旗標、夥伴與雇傭、交易與談判、情報、派奴隸去工作（→ 派工）、房屋（→ 據點）。預定資料：`data/rules/gigs.json`、`fixers.json`、`favors.json`、`bases.json`。數值會在平衡時再調。

這份文件有兩半：第 1～4 節是**委託**——所有玩家都會經歷的主迴圈；第 5～9 節是所有人都有的名冊、派工、人情與據點，掮客在這幾樣上有加成。

## 1. 中間人是什麼

緋夜城沒有冒險者公會。想找人做事的人不認識做事的人，做事的人不想讓雇主知道自己是誰，中間站著的就是中間人。他們賣的是信任：保證雇主付錢、保證做事的人不亂說。

每個中間人有自己的**地盤**（區）、**門路**（擅長的委託類型）、**後台**（哪個勢力罩他）與**脾氣**。他們是固定 NPC，各有一條關係線。信譽越高，肯見你的中間人越多。

除了城裡的中間人，牆外還有另一種：流竄 AI，只有沉溺到 100 的人接得到牠們的委託，而且四十二個裡只有五個是中間人（[NPCS](../world/NPCS.md) 第 8 節）。

城裡每個區各有一位，名單與場所見 [DISTRICTS](../world/DISTRICTS.md) 第 12 節。

## 2. 一案一團

一件委託有固定的四拍，每一拍是一到數份報告。這是把跑團的一場團變成遊戲流程。

### ① 接案

- 中間人給一份**簡報**：目標、地點、報酬、主面、**條件**（不准動實彈／不准留痕跡／要活的／不准曝光），以及他**願意說**的情報。
- 簡報可能不完整，也可能有假。調查或街頭直覺可以當場看出破綻。
- **談判**（沿用 ElondiaRPG 的談判）：報酬、預付款、裝備補助、分紅、**怎麼付**。戰利品一律歸玩家分配，不在談判裡。
- **怎麼付**：報酬用哪一種錢付，三選一。介面上每個選項直接寫出到手的數字與代價（[UI](../art/UI.md) 3.5 節）。

| 付法 | 到手 | 代價 |
|---|---|---|
| 現金晶片（預設） | 全額 | 查不到；要付帳戶的帳單得先洗錢（[TRADE](TRADE.md) 第 7 節） |
| 匯進帳戶 | 報酬 × 85%（雇主替你洗） | 留下紀錄：這是一筆髒交易，委託目標所屬勢力的敵對值 +2（[LIFE](../world/LIFE.md) 1.1 節） |
| 三成換人情 | 報酬 × 70% ＋ 一個小人情（大型委託換中人情） | 人情記在中間人名下；不經中間人的委託記在雇主名下。換成人情的部分中間人不抽成 |

- 也可以不經中間人直接找雇主，或自己找上門的委託（街頭事件、關係線、看了某段素材之後）。

### ② 踩點

行動前的準備。踩點花時間換情報；委託沒有期限，但時間照樣在過，帳單照樣要付，踩點的次數有上限，失敗還會驚動目標。

每件委託有一張隱藏的**未知清單**：保全人數、蕾絲的顏色、有沒有機甲、入口、目標的作息、雇主沒說的事。每一次踩點行動揭開一到兩項。踩點的成果有兩種：**提前看到後面的階段有哪些面、哪些分支**，以及替某個階段開出一條**踩點開出來的路**（[COMMISSIONS](COMMISSIONS.md) 2.3 節）。

| 手段 | 揭開／得到 | 主要技能 |
|---|---|---|
| 實地勘查 | 地圖、入口、掩體 | 隱匿、調查 |
| 打聽 | 傳聞、作息、內部矛盾 | 街頭直覺、交涉 |
| 淺層駭入 | 子網的層數與蕾絲、班表；可以預埋後門 | 介面 |
| 收買或色誘內線 | 憑證、內應；行動時多一個入口 | 交涉、誘惑 |
| 以採訪為名 | 進入場所、接觸目標 | 表演 |
| 進人偶館當班 | 聽到目標在床上說的話 | 名媛的招牌能力 |
| 買情報 | 直接買一項未知 | 錢或人情 |

- 踩點行動可能失敗並**驚動目標**：警戒起始值上升。
- 沒揭開的未知，行動時會以最壞的時機出現。完全不踩點直接衝也行——那是另一種玩法。
- 沿用 ElondiaRPG 的情報系統與冒險備忘錄：委託的頁面列出已知與「？？？」。

#### 踩點的規則

**時間與次數**

- 一次踩點行動花一個時段（4 小時）。踩點在城裡做，不是副本的一部分，所以可以分好幾天做、中間回家睡覺。
- 一件委託最多踩點**階段數**那麼多次（小型 3 次、中型 4 次、大型 5 次）。踩得越多，目標越可能察覺：第 4 次起，每一次的難度 +1。

**每一次踩點**

```
選一種手段 → 擲那個手段的基本功（屬性）對 10 + 委託的等級 × 2 → 結果
```

| 結果 | 得到 |
|---|---|
| 超過 5 以上 | 揭開兩項未知，或揭開一項並開出一條「踩點開出來的路」 |
| 成功 | 揭開一項未知 |
| 失敗 | 什麼都沒有 |
| 自然 1 | 驚動目標：現實的警戒起始值 +15，或內海的追蹤度起始值 +15（看是用哪一種手段） |

- 名冊上的人可以替你踩點（算派工，第 7 節），結果照他的能力擲，你不必花時間。
- 「買情報」不擲骰：直接花錢或人情揭開指定的一項，價錢是委託等級 × 300。

**未知清單**

每件委託有四到八項未知，從下面這幾類裡生成。生成時就決定好，踩點只是把它翻開：

| 類 | 例 | 揭開之後 |
|---|---|---|
| 階段 | 第二階段可以選哪些面 | 簡報上那個階段的面不再是「？」 |
| 路 | 一條潛行或交涉的分支，或一扇後門 | 那個階段多一條「踩點開出來的路」 |
| 守備 | 某個階段的遭遇有幾個人、什麼位階 | 那一場戰鬥你看得到敵方的配置 |
| 蕾絲 | 子網的層數、蕾絲的顏色 | 內海的那幾個階段看得到 |
| 目標 | 目標的作息、在哪裡 | 最後一個階段多一條路，或敵人少一個 |
| 雇主 | 雇主沒說的事（真正的目的、他會不會背刺） | 收尾時的背刺檢查你事先知道 |
| 詞條 | 這次的詞條（今晚有派對、另一隊人也在裡面） | 不會在最壞的時機才發現 |

**沒有揭開的未知**

- 階段的面沒揭開：進到那個階段時才看得到可以選哪些面。
- 路沒揭開：那條路不存在。
- 守備沒揭開：那一場的敵方配置在開打時才看得到，敵人多一次先攻的機會。
- 詞條沒揭開：照「最壞的時機」出現，也就是那個詞條在對你最不利的階段生效。

**手段與它能揭開什麼**

| 手段 | 擲 | 能揭開的類 |
|---|---|---|
| 實地勘查 | 隱匿或調查 | 路、守備、階段 |
| 打聽 | 街頭直覺或交涉 | 目標、雇主、詞條 |
| 淺層駭入 | 介面 | 蕾絲、階段、守備 |
| 收買或色誘內線 | 交涉或誘惑 | 路、守備；成功時另外多一個入口 |
| 以採訪為名 | 表演 | 目標、詞條 |
| 進人偶館當班 | 誘惑 | 目標、雇主；可能接成一場成人場景 |
| 買情報 | 不擲 | 任何一類，指定一項 |

### ③ 行動

走到地圖上的委託地點，進入**委託副本**（[COMMISSIONS](COMMISSIONS.md)）。副本是一組獨立於城市地圖網的地圖，帶著這件委託的目標。

- **行動開始前召集同伴**：從名冊選人，隊伍最多 4 人含主角，另外最多 2 位不打仗的同行；輔助面另外從名冊找人（[NPC_SYSTEM](NPC_SYSTEM.md) 10.0 節）。主角沒有職業；夥伴的職能固定，看這件委託需要什麼來找人。
- **副本分成三到五個階段**（小 3、中 4、大 5）。副本裡沒有另外的時鐘，也沒有期限。
- **每個階段寫明可選的面**：現實面（那棟樓）、內海面（它的子網）、輿論面（這件事在九個格子上的樣子）當中的一到三個。玩家每個階段選其中一面來玩。
- **每件委託有一個主面**，由類型決定：要殺人就得在現實動手，要抹黑就得打輿論戰，要偷資料就得進內海。主面只決定最後一個階段，決定性的一步一定在主面完成。
- **輔助面**：這個階段可選、但玩家沒選的面，可以派人去。派去的人每個階段擲一次，成功了拿到一個連動。
- **連動**是前面的階段幫到後面的階段的方式：讓後面的階段變短、變容易，或開出新的分支。
- 選好面之後再選**分支**：強攻、潛行、交涉、連動開出來的路、踩點開出來的路。每個面至少有強攻這一條。
- 每兩個階段之間可以喘一口氣一次，沒有代價：彈匣補滿，感載與餘韻帶著走。

| 面 | 靠什麼 | 壓力條 | 誰最強 |
|---|---|---|---|
| 現實面 | 滲透、偽裝、交涉、戰鬥（[COMBAT_SYSTEM](COMBAT_SYSTEM.md)） | **警戒**（0～100：被看見、倒下的人被發現、警報響都會加。到 60 增援加入下一場遭遇；到 100 目標轉移或逃走，最後一個階段變難一級） | 戰鬥型與掮客 |
| 內海面 | 竄網、網內戰鬥（[CYBERSPACE](CYBERSPACE.md)） | 追蹤度 | 潛網者 |
| 輿論面 | 編輯台（[OPINION](OPINION.md)） | 沒有；輿論戰本身有回合數的限制 | 媒體型 |

- **撤退**永遠是選項。撤退會把所有進度回退到進副本之前，委託還在手上，可以重新準備再進去。副本沒有「部分完成」。
- **特殊任務不走副本，也沒有主面的限制**：它們發生在地圖網上的固定地點（街區、要地、內海的固定區），直接用傳統的劇情旗標推進（第 3 節）。

### ④ 收尾

- **結算**：報酬（依附帶條件與評價，照談好的付法入帳）、歷練點（照規模固定給）、街頭信譽（照委託的級與主角的級比，同級 +2、高一級以上 +4、評價 S 再 +1、低級不變、做砸 −3，[CORE_RULES](CORE_RULES.md) 8.1 節）、各勢力的敵對值、戰利品、素材。每個階段走了哪一面、哪條分支，留下的後果不同（[COMMISSIONS](COMMISSIONS.md) 第 8 節）。
- **背刺檢查**：雇主或中間人依其性格、後台與你知道了多少，有機率翻臉——少付、滅口、把你賣給對方。踩點時查過雇主的話會事先知道。玩家也可以背刺：私吞貨、把貨賣給對家、把過程拍下來（[MEDIA](MEDIA.md)）。
- **餘波**：委託的結果寫進劇情旗標與區域狀態，影響之後出現的委託。
- 一份 `gig` 報告交給 AI 寫成這場團的尾聲。

## 3. 委託的種類

| 類 | 內容 | 這個世界特有的版本 |
|---|---|---|
| 竊取 | 偷資料、偷原型、偷義體 | 偷一段感官帶母帶 |
| 抹除 | 殺人、毀證、刪資料 | 把一個人從所有人的記憶庫裡刪掉 |
| 挖角 | 把一個企業員工帶出來 | 他是契約人：要連橋權一起處理，不然帶出來也會被遠端鎖死 |
| 護送與保鏢 | | 護送一個剛逃出人偶館的人到蜜糖會 |
| 救援 | | 把被粉蕾絲扣線的潛網者拔出來 |
| 蜜罐 | 用色誘取得把柄或情報 | 名媛與主播的主場 |
| 討債與回收 | 收錢，或收義體 | 你也可能是被回收的那個 |
| 滅火 | 幫客戶處理醜聞 | 在帶子發出去之前找到它 |
| 獵溺 | 處理一個溺感者，搶在鎮溺隊之前 | 委託人常常是他的家人，要活的 |

- 一般委託由引擎依區、中間人的門路與信譽**生成**，每一件是一個委託副本。完整的類型表（十九種，含三個面的比重與決定性的一步）在 [COMMISSIONS](COMMISSIONS.md) 第 7 節；下面這張表是世界觀上的說法。
- **特殊任務**是人工編寫的任務鏈，沿用 ElondiaRPG 的劇情旗標系統。每個中間人、每個路數、每個主要勢力各有一條。

## 4. 每週帳單

每七天結算一次（週一是收租日，`downtime` 報告）。**這個壓力是可以調的**：存檔規則有一個**帳單倍率**（預設 ×1，範圍 ×0～2，×0 就是不結算），另外有四個快捷的檔位：關閉（不結算）、寬鬆（金額減半、付不出來只到鎖義體為止）、標準、嚴苛（金額 ×1.5、寬限期更短），細節在 [DOWNTIME](DOWNTIME.md) 5.3 節。帳單倍率是獨立的設定，不看難度（[BALANCE](BALANCE.md) 7.4 節）。


| 項目 | 說明 |
|---|---|
| 房租 | 依據點等級 |
| 義體訂閱 | 每週付售價的 3%；沒付就鎖（[CYBERWARE](../gear/CYBERWARE.md) 第 5 節） |
| 生體件的營養劑 | 每件每週約 40；斷了會萎縮（[CRAFTING](../gear/CRAFTING.md) 第 8 節） |
| 抑制劑與藥 | 停藥的後果見 [CYBERWARE](../gear/CYBERWARE.md) 第 2 節 |
| 債的利息 | 胭脂堂與伊甸園的利率不同、催討方式也不同 |
| 天使急救會費 | 可以不保 |
| 小隊的薪水與分紅 | |
| 收入 | 頻道的廣告、派工的抽成、店面 |

付不出來時依序發生：鎖義體 → 討債人上門（街頭事件）→ 債權被賣給伊甸園 → 被要求簽契約（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 7 節）。**這條下坡路是遊戲的預設失敗狀態**，取代「主角死亡」成為最常見的壞結局入口——而且它是可以玩下去的。

## 5. 掮客在這裡做什麼

沒有「當中間人」的經營玩法。掮客的主場在現實的戰鬥，當指揮與支援（[CORE_RULES](CORE_RULES.md) 6.1 節、[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 11 節）。

留下來的三樣東西是**所有人都有的**輕量系統，掮客只是在這三樣上有加成：

| 系統 | 所有人 | 掮客的加成 |
|---|---|---|
| 名冊（第 6 節） | 有 | 容量比較大 |
| 派工（第 7 節） | 有 | 成功率比較高 |
| 人情（第 8 節） | 有 | 額度比較多，討人情比較順 |

## 6. 名冊

取代 ElondiaRPG 的夥伴名單與酒館雇傭。名冊是你認識、而且願意接你電話的人。

- 容量：`3 + mod(魅力) + 人面階數 × 2`。不學人面的人也有名冊，只是小。
- 每個人有：路數與階數、技能、出場費、**可靠度**（會不會做完、會不會亂說）、**忠誠**（對你個人）、目前的狀況（有空、受傷、躲風頭、欠你一次）。細節見 [NPC_SYSTEM](NPC_SYSTEM.md) 第 10 節。
- 來源：一起出過任務的人、中間人介紹、救過的人、買下契約的人、用人情換來的引薦。
- 名冊上的人可以：**召集進委託**（隊伍最多 4 人含主角；輔助面另外找人，[COMMISSIONS](COMMISSIONS.md) 第 6 節）、去委託副本的**輔助面**、**派工**（第 7 節）。
- 名冊上的人會出事。他們有自己的生活：被抓、欠債、溺感邊緣、被對家挖走。這些是事件與關係線的來源。

## 7. 派工（簡化版）

把名冊上沒帶出門的人派去做一件小事，自己不去。它不是一個玩法，是每週結帳時的一個選項；契約人的系統也會用到它（持約人派契約人去工作，[LEWD_SYSTEM](LEWD_SYSTEM.md) 7.5 節）。

- 每週可以派的人數＝名冊上有空的人，每人一件。
- 派去做什麼從一張短清單裡選：小委託、打工、盯梢、收帳、在場所工作。
- **每週結帳時擲一次**，和委託副本的輔助面同一套算法（[COMMISSIONS](COMMISSIONS.md) 6.4 節）：

```
1d20 + 那個人最高的相關基本功 + 分量修正 + 掮客的人面階數   對   10 + 那件事的等級 × 2
```

| 結果 | 發生什麼 |
|---|---|
| 超過 5 以上 | 全額的錢，另帶回一樣東西（一則線索、一個人情、一件零件） |
| 成功 | 全額的錢 |
| 失敗 | 一半的錢 |
| 自然 1 | 出事：他受傷、被捕或惹了麻煩，變成一件要處理的事件 |

- 錢照那件事的等級；派工的人拿他的出場費，剩下的是你的。
- 可靠度低的人，自然 1 的範圍擴大到 1～2。

## 8. 人情

第二種貨幣。不能存銀行，但買得到錢買不到的東西。

- **欠你的**與**你欠的**分開記，對象是具體的人或勢力，有大小（小、中、大）。
- 來源：幫忙不收錢、救人、放人一馬、壓下一段素材、替人擔保。
- 用途：要一項情報、借一個人、借一件裝備、請市警晚到十分鐘、讓某個中間人肯見你、讓企業的人「沒看見」。
- 你欠的人情會被**討**：對方在不方便的時候打來，要你做一件事。拒絕可以，信譽大跌。
- 談判時人情可以當籌碼（沿用 ElondiaRPG 的談判，多一種標的）。報酬也可以三成換成一個人情（第 2 節①）。
- **人情只記在主角名下**：委託裡拿到的人情，對方欠的是帶隊的人，夥伴不分。用人情請名冊上的人去輔助面，用掉的也是主角的人情（[COMMISSIONS](COMMISSIONS.md) 6.5 節）。
- 勢力的人情要找那個勢力裡寫明的人兌。

## 9. 據點

**家園系統要做**：主角有自己的公寓，可以升級、擺設、帶人回來。骨架參考 ElondiaRPG 的房屋系統。掃描的結果（[CODESCAN](../plan/CODESCAN.md) 2.6 節）：那邊有買斷的房子、擺在格子上的家具、影響長休的舒適度；儲物、家僕、擴建三份計畫完全沒有開始，訪客連計畫都沒有。這邊照搬資料模型，程式重寫，把那三份計畫當規格。細節寫在 [DOWNTIME](DOWNTIME.md)。

| 等級 | 例 | 功能 |
|---|---|---|
| 0 | 愛情旅館、膠囊 | 只能睡 |
| 1 | 蜂巢的單位 | 儲物、休息回復、養傷 |
| 2 | 改裝過的安全屋 | 工作台（改裝）、接入點（從家裡潛入）、多人住 |
| 3 | **店面**：酒吧、診所、小型人偶館、轉播站、同人工坊（[DOWNTIME](DOWNTIME.md) 7.11 節） | 每週收入；名冊上的人有地方待 |

- 店面的種類決定經營的方向：酒吧偏情報與人情，診所偏義體與改造師的任務線，人偶館偏錢與蜜罐（也帶來伊甸園的注意），轉播站偏媒體線。
- 據點會被找到。敵對值高時，街頭事件變成**上門事件**。
- 家具沿用 ElondiaRPG；種植不做。
- 懷孕系統不做；和它綁在一起的家庭內容（育兒、子嗣）也不做。公寓本身、同居的人、來訪的事件不受影響。
