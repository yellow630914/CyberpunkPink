# 技能：八棵技能樹

> 上層：[CORE_RULES](CORE_RULES.md) 第 6 節。依賴：[CORE_RULES](CORE_RULES.md) 6.1～6.4 節與第 7 節（路數、三個戰場、容量、歷練點）、[COMBAT_SYSTEM](COMBAT_SYSTEM.md)、[CYBERSPACE](CYBERSPACE.md)、[NETRUNNING](NETRUNNING.md)、[OPINION](OPINION.md)、[MEDIA](MEDIA.md)、[CYBERWARE](../gear/CYBERWARE.md) 7.1 節（橋的型號）。被依賴：[FIXER](FIXER.md)（名冊上的人帶什麼）、[NPCS](../world/NPCS.md) 第 4 節（夥伴）、敵人與 NPC 的生成。
> 來源：ElondiaRPG 的 `abilities.json`（主動技能的欄位：消耗、目標、判定、效果、次數）與 `perks.json`（被動加值的寫法），加上「技能攜帶上限」改成按容量計算（[CODESCAN](../plan/CODESCAN.md)）。預定資料：`data/rules/skills.json`（技能）、`data/rules/paths.json`（八棵樹與招牌）。

技能是裝在邊緣橋裡的模組。基本功是人自己練的，技能是寫進橋裡的；兩者分開（[CORE_RULES](CORE_RULES.md) 第 2 節）。這份列出八棵樹上的每一個技能，以及它在三個戰場各做什麼。

## 1. 規則

### 1.1 欄位

每個技能有這些欄位。下面各樹的表照這個順序排。

| 欄位 | 意思 |
|---|---|
| 樹 | 八條路數之一。決定它在三個戰場的強弱（[CORE_RULES](CORE_RULES.md) 6.1 節） |
| 類別 | 現實、內海、社交、媒體。決定吃橋的哪一類容量。**類別由樹決定**：槍手、機師、改造師→現實；潛網者→內海；名媛、掮客→社交；主播、偶像→媒體 |
| 階 | 1～5。決定歷練點花費、夥伴幾階才會用 |
| 種類 | 主動、被動、反應、姿態、預備、日常（1.2、1.11 節） |
| 容量 | 1～6。裝上時佔的容量 |
| 歷練 | 主角學會它的花費＝階 × 20（[CORE_RULES](CORE_RULES.md) 第 7 節） |
| 前置 | 它接在哪個技能後面（1.3 節） |
| 消耗 | 「2 行」＝2 行動點；「1 編」＝1 編輯點；RAM 照寫；「每場 1」＝每場戰鬥或每場戰役一次 |
| 現實／內海／輿論 | 它在那個戰場的效果。「—」＝在那裡不生效 |

**招牌技能**：每棵樹的第一個技能，名字就是那棵樹的招牌能力（戰鬥直覺、同步、手術刀……）。表裡用粗體標出。

### 1.2 六種種類

| 種類 | 怎麼用 | 規則 |
|---|---|---|
| 主動 | 花行動點、RAM 或編輯點發動 | 寫了次數的照次數 |
| 被動 | 裝著就生效 | 不花行動，所以容量偏貴 |
| 反應 | 條件成立時自動觸發 | 要花行動點的，從上回合留下來的行動點扣；沒有留就不觸發。每個反應各算次數 |
| 姿態 | 開著持續生效 | **同時只能開一個**（含偶像的曲目）。開、關、換都花 1 行動點；編輯台上換姿態不花編輯點，每回合一次 |
| 預備 | 開打前、進副本前、戰役開始前使用 | 不花行動點，花時間（寫在消耗欄）；效果帶進那一場 |
| 日常 | 和戰鬥無關的時候使用 | 不花行動點，花時間 |

### 1.3 前置、樹的階與歷練點

**技能分階，不是角色分階。** 每棵樹有 1～5 階；主角與夥伴都用歷練點「點亮」一棵樹的階，再學那一階裡的技能。

- **前置要擋**：主角與 NPC（夥伴、名冊上的人）學技能都要先學會前置。前置欄寫的就是學習條件。
- **樹的階靠在那棵樹花的點數解鎖**：在一棵樹上累計花了足夠的歷練點，就開下一階。門檻：

| 開到 | 在這棵樹累計花費 | 說明 |
|---|---|---|
| 1 階 | 0 | 每棵樹的 1 階一開始就開著 |
| 2 階 | 40 | 大約是學兩個 1 階技能 |
| 3 階 | 120 | |
| 4 階 | 240 | |
| 5 階 | 400 | 終極技能在這一階 |

- **學一個技能**花「階 × 20」歷練點，算進那棵樹的累計。起始的 200 點大約能把一棵樹開到 3 階；數字留到平衡階段再微調。
- **夥伴也一樣花歷練點點亮樹**，只是只能在自己的職能裡，並受上限限制（主職 5 階、副職 3 階、第三職 2 階，[CORE_RULES](CORE_RULES.md) 6.3 節）。夥伴加入時：主職 2 階、副職 1 階。
- **起始歷練點 200**，可以在建角時調整（和難度一起設定）。

### 1.4 樹的共鳴

**共鳴照樹的階給**：每開一階，那棵樹就多一個**共鳴被動**，**不佔容量**，開了就生效。每棵樹有五個共鳴，內容依樹而定，例如槍手 2 階的共鳴是「掩體間換位不花行動點一次」、潛網者 3 階的共鳴是「RAM 上限 +2」。

- **夜課的共鳴照分支給**：夜課的五個分支各自照軸開階，所以每個分支各有 5 個共鳴，一共 25 個，只在成人場景裡有效（[NIGHT_LESSONS](../content/NIGHT_LESSONS.md) 每個分支的開頭）。
- 共鳴的內容寫在 [SKILL_TREES](../content/SKILL_TREES.md) 每棵樹的開頭。

### 1.5 編輯點的加值

編輯點的加值寫在**被動技能**裡（提高上限）。這是 1.8 節「不改每回合回復的編輯點」的明寫例外：每棵樹最多一個被動提高上限，最多 +1。另有一些技能**臨時加值**（這一回合多幾點），或**加快回復**（每回合多回幾點）。不再有「招牌技能自動加幾點」或「同時裝好幾個招牌怎麼疊」的規則。

### 1.6 三個戰場的強弱怎麼落到技能上

照 [CORE_RULES](CORE_RULES.md) 6.1 節的矩陣。表裡每一格已經換算好，下面是換算的準則：

| 等級 | 技能在這個戰場 | 例 |
|---|---|---|
| **強** | 全額；這棵樹的**專屬機制**只在這裡（戰鬥直覺的重分配、機甲、管理行動、編輯台的全套行動）；有額外資源（構裝槽、RAM、編輯點） | 潛網者在內海：RAM 上限 +3、每回合多回 1 點、構裝槽 +2、管理行動 |
| **中** | 約三分之二；沒有額外資源 | 潛網者在現實：迴圈每回合 1d6＋1，網內 2d6 |
| **弱** | 約三分之一；多半只在開打前、第一回合或特定時機 | 槍手在內海：戰鬥直覺的點數只有三分之一，不能重分配 |
| **無** | 不生效。裝著也一樣 | 主播在現實的戰鬥 |

| 樹 | 類別 | 現實 | 內海 | 輿論 |
|---|---|---|---|---|
| 槍手、機師、改造師 | 現實 | **強** | 弱 | 無 |
| 潛網者 | 內海 | 中 | **強** | 無 |
| 名媛 | 社交 | 弱 | 中 | 中 |
| 掮客 | 社交 | **強（輔助）** | 中 | 中 |
| 主播、偶像 | 媒體 | 無 | 中 | **強** |

硬規則照 [DOMAINS](../DOMAINS.md) 第 3 節：媒體型的技能不進現實戰鬥的公式；戰鬥型與潛網者的技能不進輿論戰的公式；名媛在現實只在開打前與第一回合生效，例外是單點誘惑；掮客在現實是強（輔助），整場都能指揮、叫人、談。表裡「日常」的效果（素材品質、收入、名冊）和戰鬥無關，不受這幾條限制。

### 1.7 橋的機能與技能

[CYBERWARE](../gear/CYBERWARE.md) 7.1 節的機能怎麼套到技能上：

| 橋 | 和技能有關的機能 |
|---|---|
| 緋櫻 奉公 | 現實型的**被動**技能容量 −1（最低 1）。招牌技能也算 |
| 夜鶯 深水 | 內海型的主動技能 RAM −1（最低 1）。快駭的 RAM 不在此列，除非它是技能 |
| 伊甸園 伶 | 入戲的面具與「換臉」不花行動點 |
| 萬華鏡 聚光 | 坐上編輯台時編輯點 +1 |
| 蜜腺 原型 | 四類之間可以挪用 3 點容量：例如把 3 點社交當成現實用 |
| 織女 標準 | 換配置半小時 |

### 1.8 技能能做什麼：效果的清單

三個戰場的規則定了之後，技能的效果限制在下面這張清單裡。生成技能時只能從裡面挑，程式也只需要處理這些。

| 戰場 | 技能可以做的事 |
|---|---|
| **現實與內海共用** | 命中或迴避的加減；傷害骰的加減；無視一部分護甲或防護；多一次攻擊；換位或補位不花行動點；把一個人推或拉一格；退還或減免行動點；給一個狀態（壓制、暈眩、流血、標記、干擾、失去回合）；解除一個狀態；替一格補遮蔽或拆遮蔽、改遮蔽倍率；灌感載或排感載；消一層餘韻或加一層；改變先攻；觸發一次反擊 |
| **只在現實** | 彈匣（補一格、不耗彈）；生命值的回復；重創的機率或抵抗；要害的門檻；制伏的檢定；勸降（重傷的雜兵投降退場）；隊友過載時不失去回合；隊友倒下前停在 1 點生命；叫出、指揮、強化無人機與機甲；叫名冊上的人支援（射擊、補遮蔽、拆遮蔽三選一） |
| **只在內海** | RAM 的增減與回復；同步檔位的上限、換檔的次數；閃斷的抵抗或反轉；管理行動的次數與檢定；釘住的檢定；不會被扣線；追蹤度的增減（可以從負數起算）；守衛程式與構裝體 |
| **輿論** | 聲量的增減；風向的增減；多佔一格；無視相鄰佔一格；替格子設防；讓對手少公關點；抽牌或換牌；編輯點（只有被動提高上限，或臨時多一點） |
| **預備** | 開打之前的準備：戰前佈置、踩點、埋伏、預先上的增益。效果帶進接下來的那一場 |
| **日常** | 和戰鬥無關的事：素材的品質、收入、名冊與人情、製作、手術、換配置的時間、戰敗事件多一個被贖回的選項（保釋）。不進任何戰鬥的公式 |
| **成人場景** | 只有夜課（第九棵樹）的技能用得到，清單寫在 [LEWD_SYSTEM](LEWD_SYSTEM.md) 第 10 節 |

- **技能不直接改三樣東西**：每回合回復的行動點、每回合回復的編輯點、敵人的承受層數。這三樣是戰場的節奏。能動它們的只有招牌技能與少數五階的終極技能，而且要寫明。
- **每棵樹只有一個終極**可以動上面那三樣。
- **RAM 是同一個池**：潛網者的 RAM 加成（上限 +3、回復 +1）在現實的快駭也算。
- 每個技能至少在一個戰場有效果。在它那棵樹「無」的戰場，那一欄一定是「—」。

### 1.9 強度預算（斜率先這樣）

用和特質同一把尺：**一格**＝命中 +1，或迴避 +1，或一類檢定 +2，或傷害多半顆骰，或感載上限 +4（[CHARACTER](CHARACTER.md) 5.2 節）。

| 階 | 被動（一直生效） | 主動（花行動點） | 每場一次的主動 | 佔的容量 |
|---|---|---|---|---|
| 1 | 1 格 | 比同樣行動點的普通行動多 1 格 | 多 3 格 | 被動 2；其餘 1 |
| 2 | 1.5 格 | 多 2 格 | 多 4 格 | 被動 3；其餘 1 |
| 3 | 2 格 | 多 3 格 | 多 6 格 | 被動 4；其餘 2 |
| 4 | 2.5 格 | 多 4 格 | 多 8 格 | 被動 5；其餘 2 |
| 5 | 3 格 | 多 5 格 | 多 10 格；可以動 1.8 節禁止的那三樣之一 | 被動 6；其餘 3 |

- **狀態與其他效果怎麼算**：照 [CORE_RULES](CORE_RULES.md) 7.4 節的兩張表。壓制、標記、干擾各 2 格；暈眩、流血各 3 格；讓對方失去一回合 6 格（所以只有三階以上的每場一次技能做得到）；餘韻 ±1 層 2 格；退還 1 點行動點 2 格；推拉一格、免費移動、灌排 4 點感載、追蹤度 ±5 各 1 格。
- **範圍怎麼算**：打一格上的所有人 ×1.5；打整排 ×2.5。
- **反應**照主動算，但因為要留行動點才觸發，多給 1 格。
- **姿態**照被動算，因為同時只能開一個、開關要 1 點行動點，多給 0.5 格。
- **招牌技能**是每棵樹的第一個技能，一階，不照這張表：它給的是那棵樹的專屬機制（戰鬥直覺的分配、管理行動、編隊、編輯台的技能組）。
- **三個戰場的折算**照 1.6 節：強是全額，中是三分之二，弱是三分之一。
- **共鳴**每個 1 格，不佔容量。

### 1.10 每棵樹的組成

| 項目 | 數量 |
|---|---|
| 招牌技能 | 1（一階） |
| 每一階的技能 | 5～6 個，分**兩層** |
| 每棵樹合計 | 25～27 個技能，加 5 個共鳴 |
| 八棵樹合計 | 約 210 個技能，40 個共鳴 |

**每一階分兩層：**

| 層 | 幾個 | 怎麼學 |
|---|---|---|
| 前層 | 3 個 | 這一階開了就能學。三個各是一條線的起點（進攻、防守或支援、改變規則） |
| 後層 | 2～3 個 | 要先學會這一階前層的某一個（寫在前置欄）。它是那個前層技能的進階或變化 |

- 下一階的前層技能，前置可以接上一階的前層或後層。所以一條線可以「只拿前層一路往上」，也可以「每一階都把後層補齊」。
- 樹的階還是照累計花費開（1.3 節）；因為每階的技能變多，門檻不變的話會比較快開到下一階，這一點留給技能樹的平衡（[BALANCE](BALANCE.md) 第 6 節）。
- 每一階的種類大致是：主動 3、被動 1、反應或姿態 1、預備或日常 0～1。
- 五階的三個前層技能是那棵樹的三種終極：一個偏進攻、一個偏防守或支援、一個改變規則。

### 1.11 預備與日常

六種種類裡，預備與日常專管戰鬥以外的時間：

| 種類 | 怎麼用 |
|---|---|
| 主動、被動、反應、姿態 | 照 1.2 節 |
| **預備** | 專門處理戰鬥之前的準備。在開打前、進副本前、戰役開始前使用，效果帶進那一場 |
| **日常** | 和戰鬥無關的技能：打工、製作、手術、剪片、交涉、過日子。和戰鬥無關的技能都放這一類 |

### 1.12 第九棵樹：夜課

另外有一棵獨立的技能樹，叫做夜課，大部分的技能只在成人場景使用。它的規則和這八棵不一樣：經驗從成人事件來，不花歷練點；開階看的是傾向與性經歷，不看累計花費。寫在 [LEWD_SYSTEM](LEWD_SYSTEM.md) 第 10 節。

## 11. 夥伴：職能對應技能樹

### 11.1 規則

- 一條路數就是一棵樹。夥伴有一到三條（[CORE_RULES](CORE_RULES.md) 6.3 節）：

| 位置 | 上限 | 會用到 | 意思 |
|---|---|---|---|
| 主職 | 5 階 | 那棵樹的全部技能，含終極 | 招牌在那個戰場的分量照 6.1 節，全額 |
| 副職 | 3 階 | 1～3 階 | 主幹與專精，沒有 4、5 階的高階與終極 |
| 第三職 | 2 階 | 1～2 階 | 招牌與入門的幾招 |

- **不佔容量**：夥伴沒有橋的管理，學會的技能都能用。限制只有：姿態同時一個、反應與主動照寫的次數、資源（行動點、RAM、編輯點）照算。
- **樹的階**照 1.3 節；共鳴照 1.4 節，夥伴也有。
- **升階**：和主角同一套：花歷練點點亮樹的階、學有前置的技能（1.3 節）。
- **戰鬥中由玩家操縱**，和 ElondiaRPG 一樣。委託副本裡玩家每個階段只玩自己選的那一面，其餘可選的面由數值結算（[COMMISSIONS](COMMISSIONS.md) 6.3 節）。
- **名冊上的生成 NPC**：路數一條 60%、兩條 30%、三條 10%；主職最高 5 階，階數依所在的區、街頭信譽與出場費（[NPC_SYSTEM](NPC_SYSTEM.md) 4.7 節）。

職能照 [NPCS](../world/NPCS.md) 第 4 節。加入時的階數是這份定的。

| 夥伴 | 主職（5） | 副職（3） | 第三職（2） | 加入時 | 副職或第三職封頂時拿到的 |
|---|---|---|---|---|---|
| 小麥 | 掮客 | 名媛 | — | 1／1（開場） | 名媛 3：媚態、說服蕾絲、換臉 |

## 13. 資料的樣子

`data/rules/paths.json` 一棵樹一筆；`data/rules/skills.json` 一個技能一筆。效果分三個戰場寫，`null` 就是在那裡不生效。欄位沿用 ElondiaRPG `abilities.json` 的 `target`、`resolve`、`damage`、`apply`、`uses`。

```json
{
  "paths": [
    { "id": "gunner", "name": "槍手", "tree": "戰鬥直覺", "category": "meat",
      "signature": "gun_instinct",
      "domains": { "meat": "strong", "net": "weak", "opinion": "none" } }
  ],
  "skills": [
    {
      "id": "vital_shot", "name": "要害射擊", "path": "gunner", "category": "meat",
      "tier": 1, "kind": "active", "cap": 1, "xp": 20, "after": "gun_instinct",
      "use": { "ap": 2 },
      "meat":    { "target": "enemy", "resolve": "attack", "weapon": true,
                   "crit_margin": 3, "on_crit": { "damage": [{ "dice": "1d6" }] } },
      "net":     { "target": "enemy", "resolve": "attack", "construct": true, "crit_margin": 4 },
      "opinion": null
    },
    {
      "id": "flood", "name": "灌流", "path": "streamer", "category": "media",
      "tier": 2, "kind": "active", "cap": 1, "xp": 40, "after": "expose",
      "use": { "ap": 2, "ram": 2 },
      "meat":    null,
      "net":     { "target": "enemy_or_node", "resolve": "check", "check": "performance",
                   "choose": [
                     { "load": { "dice": "2d6", "plus": "traffic" } },
                     { "apply": [{ "status": "node_jammed", "turns": 1 }] } ] },
      "opinion": null
    },
    {
      "id": "cheer", "name": "應援", "path": "idol", "category": "media",
      "tier": 1, "kind": "passive", "cap": 3, "xp": 20, "after": null,
      "meat":    null,
      "net":     { "link": { "count": "tree_tier+1", "share": 0.5, "trace_per_turn": 1 } },
      "opinion": { "ep_max": 1 }
    }
  ]
}
```

- `category` 決定吃哪一類容量；`domains` 只寫在樹上，技能的三個欄位要照它換算好（1.6 節），載入時檢查：媒體類技能的 `meat` 必須是 `null`，現實類與內海類技能的 `opinion` 必須是 `null`。
- `tree_tier`、`traffic` 這種字串是公式，由引擎代入（1.4 節、第 8 節）。
- 共鳴與橋的機能不寫在技能上，由引擎在裝配時算。
