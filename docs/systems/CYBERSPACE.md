# 網路空間：內海

> 上層：[GAME_DESIGN](../GAME_DESIGN.md)。依賴：[CORE_RULES](CORE_RULES.md)（屬性、技能、感載、同步原則、路數）、[NETRUNNING](NETRUNNING.md)（快駭、蕾絲、追蹤度）、[COMBAT_SYSTEM](COMBAT_SYSTEM.md)（回合與站位）。被依賴：[NETRUNNING](NETRUNNING.md)（子網在內海的位置）、[DISTRICTS](../world/DISTRICTS.md)（接入點）、[FIXER](FIXER.md)（網內的委託）。
> 來源：ElondiaRPG 的隨機地下城（分層、層主、寶箱、陷阱）搬到這裡。預定資料：`data/world/cyberspace.json`、`data/rules/constructs.json`。結構圖：[`art/preview/cyberspace.png`](../art/preview/cyberspace.png)。數值都是初稿。

緋夜城有兩座：一座在地上，一座在線上。線上的那座叫**內海**——粉牆以內的網路空間。它不是駭客專用的後台，而是一個**所有人都會去的地方**：買東西、看演唱會、打遊戲、談生意、偷東西、打架。牆的另一邊是**深海**。

分工：這份寫「網路空間是什麼地方、誰能進去、進去之後怎麼玩」；[NETRUNNING](NETRUNNING.md) 寫「怎麼駭」（快駭、程式、蕾絲、追蹤度）。

## 1. 兩座城市

| | 現實（緋夜城） | 網路（內海） |
|---|---|---|
| 地圖 | 幾乎都是**固定**的（[DISTRICTS](../world/DISTRICTS.md) 1.3 節） | 公共區固定；**其餘大量隨機生成** |
| 身體 | 就是你 | **化身**。身體留在現實 |
| 被打倒 | 生命值歸零：倒下 | 餘韻疊滿再過載：倒下、斷線，現實的身體昏迷 |
| 最壞的結果 | **死亡** | **精神污染**。網內殺不了人 |
| 共通 | **感載是同一條**。在網內被灌到過載，現實的身體也過載 | |
| 裝備 | 槍、護甲、義體 | **構裝**（第 4 節） |
| 時間 | 一比一。網內過一小時，現實也過一小時 | |
| 探索的樂趣 | 認識一座城市：每條街都有人認得你 | 下潛：每次進去都不一樣，越深越怪 |

這個分工是刻意的：**現實給熟悉感，網路給未知**。固定地圖讓城市有記憶，隨機地圖讓重玩有變化，兩者各放在適合的地方。

## 2. 怎麼進去

### 2.1 兩種連線

| | 投影 | 潛入 |
|---|---|---|
| 是什麼 | 橋把網路的畫面疊在視野上。人還在走路 | 意識整個進去。身體躺著不動 |
| 能做什麼 | 耳語、看牆報、逛大街的櫥窗、付錢、快駭 | 在內海裡走動、進任何區、戰鬥 |
| 需要 | 橋 | 橋，加上一個**接入點** |
| 風險 | 幾乎沒有 | 身體沒人顧；感載是真的 |

### 2.2 接入點

| 接入點 | 在哪 | 進去之後在哪 | 特性 |
|---|---|---|---|
| 自己的床 | 據點 | 港灣（自己的房間） | 免費；安全程度等於據點的安全程度 |
| 據點的接入艙 | 二級以上的據點 | 港灣 | 身體有鎖、有維生；可以多人一起潛 |
| **潛艙店** | 街上。每個區都有，四十二番街與櫻町最多 | 大街 | 付費的隔間，像網咖；便宜的不鎖門；有紀錄 |
| 設施的資料埠 | 委託的目標建築裡 | **那個設施的子網核心** | 繞過所有外圍防禦——這是實地滲透的理由 |
| 地下層的舊網節點 | 地下層中層與深層 | 沉船帶；深層的那一個通往「門」 | 不留追蹤度；也沒有任何保護 |

### 2.3 誰能進

**有橋的人都能潛入。** 不需要是潛網者。

| | 能去哪 | 能做什麼 |
|---|---|---|
| **訪客**（沒有甲板） | 港灣、大街、樂園島 | 逛、買、玩。沒有構裝，不能戰鬥，遇到事只能登出 |
| **租用甲板**（潛艙店附的） | 以上，加上暗礁的外圍 | 2 個構裝槽；有紀錄；在裡面倒下要賠押金 |
| **自己的甲板** | 任何地方 | 依甲板等級（第 4 節） |
| **被帶潛** | 帶你的人能去的地方 | 借用對方的構裝槽。用在護送委託人、帶沒有甲板的隊友 |

沒有橋的人（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 1 節）進不來。他們只能用板子看到內海的文字介面——那是另一種完全不同的、安全的、盲的體驗。

### 2.4 身體

潛入的時候，身體是最大的弱點。

- 身體在現實受到傷害，化身立刻知道（並受一次干擾）。
- **追蹤度**到「定位」（[NETRUNNING](NETRUNNING.md) 第 5 節），對方就知道身體在哪——現實的人會去找它。
- 隊伍的標準做法：一部分人潛入，一部分人守著。或者全員一起潛，把身體留在夠安全的地方——「夠不夠安全」是踩點的一項。

## 3. 內海的地理

越往裡越深，越深越沒有規矩。

| 區 | 是什麼 | 誰在這裡 | 危險 | 地圖 |
|---|---|---|---|---|
| **港灣** | 登入點。每個人有一間自己的**房間** | 你，和你邀請的人 | 無 | 固定 |
| **大街** | 內海的市中心：商店、銀行、市政、牆報廣場、萬華鏡的頻道大廳 | 所有人 | 無。貞網局巡邏，禁止戰鬥 | 固定（3 塊） |
| **樂園島** | 娛樂區：遊戲館、演唱會場、擂台、主題館、賭場 | 玩家、觀眾、偶像、賭徒 | 低；館內的危險是「遊戲的一部分」，但感載是真的 | 場館固定（3 塊）；**館內關卡隨機** |
| **企業環礁** | 一圈島，主要的企業各一座。外圍是客服與商店，裡面是子網 | 員工、客戶、蕾絲、入侵者 | 中～高 | 各家前台固定；主線的子網固定；**一般委託的子網生成** |
| **暗礁** | 沒有登記的節點：黑市、同人伺服器、駭客的窩、無照擂台 | 潛網者、同人眾、牆語者、資料掮客、貞網局的臥底 | 中 | 據點固定（2 塊）；其餘**會搬家** |
| **沉船帶** | 大潮崩時被隔在牆內的舊網殘骸。沒人維護，沒人管 | 拾荒的人、殘留的程式、野生的蕾絲 | 高 | **隨機** |
| **深海** | 牆外 | 流竄 AI | 不是高低的問題 | **隨機**，規則不同（[NETRUNNING](NETRUNNING.md) 第 7 節） |

### 3.1 港灣

每個有橋的人在內海都有一間房間。它是網內的據點：

- 可以佈置（外觀是風格的一部分）、存放構裝與資料、邀請別人進來談事情。
- **房間有鎖**，鎖的強度看甲板。被闖入是一種事件：有人翻過你的東西。
- 中間人常在自己的房間見人——比現實安全，因為誰都帶不了槍進來。

### 3.2 大街

現實的商店多半在這裡有分店，另外賣只存在於網內的東西：

| 店 | 賣什麼 |
|---|---|
| 構裝店 | 合法的構裝：護盾、工具、遊戲用的武器構裝 |
| SKIN 店 | 化身的外觀。緋櫻映畫的聯名款最貴 |
| 夜鶯服務中心 | 甲板的登記、更新、維修 |
| 牆報廣場 | 全城各區的牆報匯集在這裡（[LIFE](../world/LIFE.md) 第 7 節）。一般委託的來源 |
| 頻道大廳 | 萬華鏡的入口。主播與偶像的頻道在這裡有「門面」 |
| 銀行 | 帳戶。洗錢不在這裡，在暗礁 |

大街是安全區：動手會被貞網局當場踢出並記錄。所以它也是談判的好地方。

### 3.3 樂園島

內海最熱鬧的地方，也是**隨機地圖最大的來源**。每座館是一個入口，進去之後是館方生成的空間。

| 館 | 玩法 | 生成 |
|---|---|---|
| **迷宮館** | 組隊闖關的遊戲：打程式生成的敵人、解機關、打館主。破關有獎金與稀有構裝 | 每次進去都不同。分層，越深獎越好——就是 ElondiaRPG 的地下城 |
| **競技場** | 化身對化身。有排名、有賭盤 | 固定的幾張場地 |
| **感官擂台・線上** | 比誰先過載（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 6 節）的網路版，觀眾更多 | 固定 |
| **演唱會場** | 虛擬偶像與真人偶像的公演。萬人同步 | 固定；演出內容隨偶像 |
| **主題館** | 溫泉、海灘、古城、太空站……想得到的場景。也有成人向的館 | 固定的幾種，細節隨機 |
| **賭場** | 伊甸園與胭脂堂各開一間 | 固定 |

- 迷宮館是**合法的地下城**：打輸只是斷線、睡一覺。它是練手、賺錢、找隊友的地方，也是偶像與主播的舞台（闖關可以直播）。
- 館方是企業（多半是萬華鏡與伊甸園）。有些館的深層接著不該接的東西——沉船帶的一角、企業的實驗、被關在裡面出不來的人。
- 遊戲裡的「死亡」不痛。但館內的感載是真的，有些館靠這個賺錢。

### 3.4 企業環礁

主要的八家企業各一座島，次要的四家掛在上家的島上（天使急救在蜜腺、織女在崑崙、貞網局在夜鶯；甜心食品自己有一座小的）。島的結構相同：

```
前台（公開：客服、商店、展示廳）→ 員工區（要憑證）→ 管理區 → 核心
```

- 這就是 [NETRUNNING](NETRUNNING.md) 第 4 節的**子網**。從內海正面進去，要一層一層打穿；從設施內的資料埠進去，直接到核心附近。
- 企業在現實的**每一棟設施**各有一個子網，掛在島上。控制節點連著現實的那棟樓。
- 主線與特殊任務的子網是手工設計的；一般委託的子網依企業與設施類型生成。

### 3.5 暗礁

沒有地址的地方。要有人帶、或自己找到入口。

- **蚌殼市**：網內的黑市。違禁構裝、偷來的資料、憑證、假身分、洗錢。
- **同人伺服器**：同人眾的地盤（[GANGS](../world/GANGS.md) 第 4 節）。同人夜市的線上版，每天都開。
- **窩**：潛網者團體的據點。牆語者在這裡有前哨。
- 暗礁的節點會被貞網局掃蕩，所以**會搬家**：固定的只有兩個老據點，其餘每隔幾天換位置，要重新打聽。

### 3.6 沉船帶

大潮崩那三天，有一部分舊網沒有被隔到牆外，而是沉在牆內的底部。破碎的伺服器、斷掉的連結、沒人關的程式。

- **全部隨機生成**。每一艘「船」是一座地下城：分層、有守在裡面的東西、有寶。
- **能撈到的**：大潮崩之前的程式（有些比現在的好，有些有問題）、失落的資料（值錢）、死在那三天的人留下的**印記**——一小段人格的殘片，會說話，不知道自己已經死了。
- **在裡面的**：殘留的失控程式（街上叫**遺魂**）、沒有主人的野生蕾絲、「快感漩渦」的碎片（碰到就開始灌，要立刻脫離）、別的拾荒者。
- 不屬於任何企業，所以**沒有追蹤度**。壓力來自別的東西：越深，登出的訊號越弱。
- 離牆越近的船越完整、越危險。最深的那幾艘貼著牆。

### 3.7 深海

見 [NETRUNNING](NETRUNNING.md) 第 7 節。地圖上，它是沉船帶的延續：沒有底的隨機生成，規則不同（沒有追蹤度，只有沉溺）。

## 4. 化身

潛入之後，你是一個化身。

### 4.1 數值

**內海沒有另外的血條：感載就是血量。**

- 在網內，所有的傷害都讓**感載**上升。感載滿了就過載，疊一層**餘韻**；餘韻疊到承受層數之後再過載一次，就**倒下**（[CORE_RULES](CORE_RULES.md) 4.2 節）。主角的承受層數基礎是 3，每個 NPC 與敵人不一樣。
- **餘韻在網內只有好處**：層數越高，能力越強——檢定 +1、構裝的效果 +10%。被打得越慘，打回去越痛，直到倒下。
- **餘韻跟著人回現實**。在網內疊的層，登出後變成現實的全屬性 −2（每層）。打完一場網內的硬仗，身體要休息才動得了。
- **倒下**：斷線，現實的身體昏迷一段時間（一小時內不能再潛入），沉溺 +2。你倒下之後，贏的一方可以選擇不讓你斷線，等現實的人去找你的身體；這叫**扣線**（6.7 節）。
- **生命值**在網內不會掉。**內海殺不了人**（見第 6 節的「精神污染」）。
- **屬性**照用，有兩項替換：**體格在網內由意志代替**（近戰與重構裝的檢定、撐不撐得住），**傷害的屬性加值一律用魅力**：每一次攻擊的傷害加上魅力的調整值，拿槍型的構裝和近戰型的都加；超頻只加一次。化身是你呈現出來的樣子：它站不站得穩看意志，它打出去有多重看存在感。於是一個瘦弱但魅力高的人，在內海可以是巨人——這也是媒體型與社交型在網內站得住的原因。
- **基本功**照用。槍械就是槍械，格鬥就是格鬥——只是拿的是構裝。這是關鍵：**在現實會做的事，在網內也會**，不必重新學一套。裝在橋裡的技能則看它屬於哪一類（第 5 節）。
- **行動點**照舊。**RAM** 是網內的能量，有甲板的人都有；構裝的特殊動作與快駭都花它。

### 4.2 構裝

網內的裝備。存在甲板裡，槽數看甲板等級。

| 類 | 是什麼 | 對應現實的 |
|---|---|---|
| 武器構裝 | 網內的槍與刀。造成感載 | 武器 |
| 防護構裝 | 護盾、誘餌。減少受到的感載 | 護甲 |
| 工具構裝 | 隱形、探針、後門、追蹤干擾 | 工具 |
| 駭入程式 | 管理行動用的程式：破解閘門、接管節點、改寫地形。**要「主控」招牌能力才能用**。快駭的程式不在這一類，有甲板的人都能用（[NETRUNNING](NETRUNNING.md) 第 2 節） | — |
| 專屬構裝 | 各路數的招牌能力在網內的形式（第 5 節） | — |
| 構裝體 | 大型的戰鬥化身。機師專用 | 機甲 |

- **構裝維持「程式」，不做零件組裝**（已確認）：和現實的裝備做出區別。取得方式是買、寫、撈（沉船帶）、偷。
- 構裝有等級（I～V）與牌子（[LIFE](../world/LIFE.md) 第 4、5 節）。它們是程式，不走設計圖與零件的組裝：夜鶯的穩但會回報、聖堂的強但沒有保護、同人的有怪癖、沉船帶撈上來的不照規則。
- **目錄**在 [ITEMS](../gear/ITEMS.md) 第 11 節（2026-11-20）：等級怎麼加、價格與合法性、六類各自的表，以及 SKIN。武器構裝沿用現實武器的原型，防護構裝沿用護甲的量級，構裝體沿用機甲；每個構裝的進階效果（深檔）從 III 級起有，終極效果（全檔）只有 IV 級。
- 沒有甲板＝沒有構裝槽＝不能戰鬥。**甲板因此是所有人都值得買的裝備**，不只是潛網者的。入門甲板 2,500，4 槽。

### 4.3 SKIN：化身的穿著（已確認）

> 用詞：化身與虛擬主播穿的那一層一律寫 **SKIN**。義體零件的那一層叫**外皮**（[ITEMS](../gear/ITEMS.md) 2.8 節）；生物的皮膚照常寫皮膚。

- **SKIN 不佔構裝槽。** 它是另外的欄位，不擠掉武器與防護。
- **一套 SKIN 算一件**：沒有現實那樣的十格穿著，也沒有外層內層。可以存好幾套，在任何接入點切換；戰鬥中不能換。
- SKIN 只給兩樣東西：**風格**與**曝露度**（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 2 節）。扮相的傾向、場所的要求、直播的熱度在內海照樣看這兩項。SKIN 不給護甲、不給數值——防護是防護構裝的事。
- SKIN 和化身的身體是兩回事：身體（性別、體型、是不是人形）自由設定（[CHARACTER](CHARACTER.md) 1.1 節），SKIN 是穿在上面的。
- 現實穿什麼、帶什麼，進內海都不算；反過來也是。
- SKIN 的來源：買（樂園島與大街的店）、同人社團做的、活動送的、自己畫的。牌子與風格照現實的那張表。目錄在 [ITEMS](../gear/ITEMS.md) 11.8 節。

### 4.4 同步深度

潛入時每個人都選一個同步檔位（[CORE_RULES](CORE_RULES.md) 第 5 節）。深檔讓化身更強，回灌更重。這個旋鈕不是潛網者專屬的。

## 5. 每條路數的兩面

**八條路數在網路空間都有自己的位置，但分量不同。內海是潛網者的地方。**

| 分量 | 路數 | 意思 |
|---|---|---|
| **強** | 潛網者 | 招牌能力完整生效，且有別人沒有的機制（管理行動）；構裝槽 +2、RAM 上限與回復都多 |
| 中 | 藝人、掮客、主播、偶像 | 招牌能力的網路面生效，約是「強」的三分之二；沒有額外的構裝槽與 RAM |
| 弱 | 槍手、機師、改造師 | 技能照用（拿構裝打），招牌能力的網路面只有約三分之一 |

- 藝人與媒體型在現實打不了正面，內海是他們**能打**的地方，但他們最強的地方是輿論戰。掮客在現實是強的輔助（指揮、叫人、談），他在內海同樣居中。
- 戰鬥型在網內像是離了水：槍法還在，直覺不在。
- 三個領域的總表見 [CORE_RULES](CORE_RULES.md) 6.1 節。

招牌能力在兩邊各有一種表現，階數共用：

| 路數 | 現實 | 網路 | 在網內的角色 |
|---|---|---|---|
| **槍手**・戰鬥直覺【弱】 | 分配先攻、命中、迴避 | **戰鬥構裝精通**：同樣的分配；武器構裝的傷害骰加大；可以同時持有兩把武器構裝 | 幫手。靠槍法而不是直覺 |
| **潛網者**・主控【強】 | 快駭 | **管理行動**：破解閘門、接管控制節點、改寫地形（造牆、斷路、開後門）、降低追蹤度。每回合額外的次數＝階數 | 開路的人。沒有他，隊伍只能走正門 |
| **改造師**・手術刀【弱】 | 手術、急救、解鎖 | **除錯**：替隊友排掉感載、消一層餘韻、清除惡意韌體、**解剖**被打倒的蕾絲取得構裝與憑證 | 醫護與拆解。戰利品的來源 |
| **主播**・聚光燈【中】 | 沒有戰鬥效果；編輯台 | **導流**：把觀眾的流量當成武器。**灌流**——把流量灌向一個節點或一個化身，造成感載或讓它癱瘓一回合（觀眾越多越痛）；**曝光**——照亮隱形的敵人與隱藏的節點；**洗版**——用雜訊蓋住隊伍的痕跡，追蹤度下降；**圍觀**——把這場戰鬥變成全城在看的事，企業的蕾絲被上層降級 | 控場與干擾。內海是他能正面打的地方，但打不過潛網者 |
| **掮客**・人面【中】 | 強（輔助）：指揮、叫人、談 | **代理**：當場買到憑證與後門、租用守衛程式當傭兵、把名冊上的人遠端叫進來 | 補給與增援。用錢和人情解決問題 |
| **藝人**・入戲【中】 | 弱：面具、單點誘惑 | **偽裝**：化身冒充成別的身分——員工、管理員、甚至某個蕾絲。高階的蕾絲有人格，所以**可以被說服、被誘惑、被騙** | 滲透。不打穿閘門，而是讓閘門替你開。內海是她真正的舞台：這裡每個人都只是一張 SKIN |
| **偶像**・應援【中】 | 沒有戰鬥效果；人氣與親衛隊 | **共鳴**：把隊友的化身接到自己身上——分擔感載、唱曲目給增益（[MEDIA](MEDIA.md) 9.1 節）。網內沒有距離，全隊都接得到。可以**安撫**蕾絲與遺魂，讓它們暫時不攻擊；**召集**——親衛隊的人湧進來，成為一群擋路、佔位、灌流的化身 | 增益、保險與群眾。能和「不是人的東西」溝通的人 |
| **機師**・編隊【弱】 | 機甲、載具 | **構裝體**：駕駛大型的戰鬥化身，有自己的感載上限與承受層數（傷害先打在構裝體上）、自己的武器 | 重火力。網內的坦克，也是現實與網路之間的橋 |

設計上的保證：

- **每條路數在網內都有「只有它做得到」的事**。
- 現實與內海是互補的：在現實最強的戰鬥型，在網內最弱；在現實居中的潛網者，在網內最強；在現實沒有戰鬥能力的媒體型，在網內居中。
- **沒有潛網者的隊伍進得了內海**，也打得了架，只是吃力，而且破不了閘門——要靠偽裝（藝人）、買憑證（掮客）、或實地去插資料埠。
- **網內不靠槍手**。一隊戰鬥型下去，是最不划算的組合。
- 成長是一份：升了招牌能力，兩邊一起變強。玩家不必在「現實的自己」與「網路的自己」之間分配點數。
- 但**裝備是兩份**：現實要槍與護甲，網內要甲板與構裝。錢怎麼分，是每個角色的取捨。

> 原則是**不另外做一套**：回合、行動點、站位、距離、命中、遮蔽都照現實戰鬥（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 1～3 節），只在下面列出的地方不一樣。數字都對著現實戰鬥已確認的基準。

### 6.1 和現實戰鬥的對照

| 現實 | 內海 | 差別 |

| 生命值與感載兩條 | **只有感載一條** | 沒有實彈與神經兩種打法的選擇；所有攻擊都往同一條灌 |
| 行動點：上限 4＋(反應＋魅力調整值)÷2，每回合回 3 | 相同 | — |
| 站位：雙方各四格，第 1 格是近身 | 相同 | — |
| 距離每格 −2、迴避 10＋反應＋遮蔽 | 相同 | — |
| 遮蔽（掩體 30、半掩體 15、暴露），會被打壞、會跟著補位 | **防火牆節點**，數字相同 | 潛網者可以當場造出來或拆掉（6.6 節） |
| 護甲：直接減傷害 | **防護構裝**：直接減感載，數字相同（1～2／3～4／5～6／8 以上） | — |
| 彈匣 1～4 格、換彈 1 點 | **RAM**：每次攻擊花 RAM，每回合自己回（6.3 節） | 沒有彈匣，全部的構裝共用一池 |
| 武器 | **武器構裝**：沿用現實武器的原型（距離、傷害骰、遮蔽倍率），名字與外觀另取 | 不用重新學一套 |
| 物理、熱能、電磁、神經、快感 | **只有神經與快感**（6.5 節） | 干擾是一種效果，不是傷害類型 |
| 過載：失去一回合，餘韻是雙面的 | 過載：**不失去回合**，餘韻只有好處，但會**閃斷**（6.2 節） | 越打越兇 |
| 重創 | **破損**：一個構裝槽失效（6.5 節） | — |
| 制伏：目標失去回合時，近身綁起來 | **釘住**：目標餘韻疊滿時，近身釘在線上（6.7 節） | 敵人也會對你做 |
| 沒有 | **同步檔位**：每回合可以換一次（6.4 節） | 內海獨有的攻守旋鈕 |
| 沒有 | **追蹤度**：戰鬥拖越久，來的東西越多（6.8 節） | 內海獨有的時間壓力 |

### 6.2 感載、餘韻與閃斷

- **敵人的感載基準和現實一樣**：雜兵上限 20～24、1 層；精英 28～32、2 層；首領 38～44、4 層。用一把 3 顆骰的武器構裝，打倒雜兵約 4 下、精英約 9 下、首領約 20 下——和現實的節奏相同（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 1.1 節）。
- **蕾絲的耐打程度看等級與位階，不看顏色**。顏色只決定它做什麼：白的拉警報、粉的要釘住你、黑的打快感。
- **餘韻每層**：網內的檢定 +1、構裝造成的感載 +10%。敵我都算。
- **閃斷**：過載的那一刻 RAM 歸零。不失去回合，但那一回合只能做不花 RAM 的事（換位、瞄準、換檔、回填）。這是網內的「破綻」：把人打到過載，他下一回合的火力就斷一拍。這是預設；**技能可以把它反過來**，讓過載變成好事（例如過載時 RAM 不歸零、反而回滿），留給技能樹設計。
- **主角在網內比在現實耐打很多**。主角感載上限約 38、3 層，要過載 4 次才倒，合計約 150 點；現實的生命值只有約 44。所以**網內敵人的攻擊骰比現實同等級、同位階的敵人多 1 顆**（雜兵 4 顆、精英 5 顆、首領 6 顆）。扣掉 3 點防護之後，雜兵打倒主角約要 14 下；開深檔（感載 ×1.5）約 9 下。現實是約 5 下（待平衡）。這是先抓的合理範圍，等敵人設計出來再調平衡。網內的危險不在當場倒下，在於餘韻會跟回現實、以及被釘住。

### 6.3 RAM

```
RAM 上限 = 4 + mod(智識)（最少 4）
每回合回復 = 2
潛網者（主控）：上限 +3、回復 +1
甲板、構裝與技能可以再加
```

| 行動 | 行動點 | RAM | 說明 |
|---|---|---|---|
| 攻擊 | 2 | 1（重型構裝 2） | 現實的「射擊」與「近戰」 |
| 超頻 | 3 | 手上全部，至少 2 | 現實的「連射」：每多花 1 點 RAM，傷害骰多 1 顆；自帶壓制（定力對 10＋RAM×2） |
| 瞄準 | 1 | 0 | +3 |
| 換位 | 1 | 0 | |
| 回填 | 1 | — | RAM +2（潛網者 +3）。現實的「換彈」 |
| 換構裝 | 1 | 0 | 換手上拿的那一個武器構裝 |
| 腳本 | 1 | 0 | 一次性的程式，現實的「道具」 |
| 工具構裝 | 1～2 | 1～3 | 隱形、探針、誘餌等，各自寫明 |
| 待命 | 1 | 0 | 觸發時的攻擊照算 RAM |
| 釘住 | 2 | 1 | 6.7 節 |
| 拔線 | 1 | 0 | 自己登出，安全；被釘住時不能用 |
| 換檔 | 0 | 0 | 每回合一次（6.4 節） |

- 第一回合 RAM 從上限開始。
- **普通人上限 4～5、每回合回 2；普通的潛網者上限 7～8、每回合回 3。** 差距是「多一次管理行動或多一顆超頻的骰」，不是別人打一下、他打三下。要拉出巨大的差距，得靠頂尖的甲板加上技能樹。
- 快駭在網內照用，花 RAM（[NETRUNNING](NETRUNNING.md) 第 2 節）。

### 6.4 同步檔位

| 檔位 | 自己的檢定 | 受到的感載 | 能做的事 | 條件 |
|---|---|---|---|---|
| 淺 | −2 | ×0.5 | 不能超頻、不能用專屬構裝 | — |
| 標準 | — | ×1 | 全部的一般行動 | — |
| 深 | +2 | ×1.5 | 構裝的**進階效果**（每個構裝各寫一條） | 同步 3 級 |
| 全 | +4 | ×2.5；過載時沉溺 +2 | 構裝的**終極效果**；**每回合多回 1 點行動點**；管理行動次數 +1 | 同步 5 級 |

- 換檔不花行動點，每回合一次，**只能在自己的回合換**；被打的當下不能換。換了之後維持到下次換。
- 受到的感載算法：`（原始值 − 防護構裝）× 檔位 × 敏感度修正`。
- **這是內海每回合的那個決定**：這回合要開深檔把對面那隻灌倒，還是退淺檔撐過牠的回合。因為換檔是在自己的回合，開了深檔就得用深檔挨打到下一輪。
- 敵人也有檔位。蕾絲固定一個檔位（雜兵標準、精英深、首領會換）；對方的潛網者會像玩家一樣換。

### 6.5 傷害類型、干擾與破損

內海的傷害只有兩種，都屬於全書的五種傷害類型（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 5 節）：

| 類型 | 效果 | 來源 |
|---|---|---|
| **神經** | 加感載。網內的基本傷害 | 所有的武器構裝 |
| **快感** | 加感載，並且每次命中沉溺 +1；因為它而過載時，沉溺再 +2 | 黑蕾絲、遺魂；誘惑與部分技能 |

- **干擾**是一種效果，不是傷害類型。帶干擾的攻擊不加感載；命中時目標的一個構裝**停用一回合**（攻擊的人選類別：武器、防護、工具）。它打在防火牆節點上時，遮蔽倍率 ×2。來源是干擾類的武器構裝、快駭與部分管理行動。

- **破損**（現實的重創）：自然 20，或瞄準之後打出要害。目標的一個構裝槽失效。
  - 輕：到這場戰鬥結束。
  - 重（對方本來就有破損時再中一次）：到登出之後修好為止，改造師的「除錯」可以當場修。
  - 雜兵不算破損，直接多 1 顆傷害骰（和現實一樣）。

### 6.6 管理行動（潛網者）

只有「主控」招牌能力能做。**不花行動點，花 RAM**；每回合的次數＝主控的階數。檢定是 `1d20 + mod(智識) + 介面` 對節點的防火牆。

| 管理行動 | RAM | 效果 |
|---|---|---|
| 造牆 | 2 | 我方一格的遮蔽升一級（暴露→半掩體→掩體），耐久補滿 |
| 拆牆 | 2 | 敵方一格的遮蔽降一級。不必過耐久 |
| 斷路 | 2 | 敵方一格這一回合不能換位、不能補位 |
| 接管 | 3 | 拿下一個控制節點：現實那一區的門、攝影機、砲塔聽你的（[NETRUNNING](NETRUNNING.md) 第 4 節）；戰鬥中的守衛程式可以被接管一回合 |
| 破解 | 2 | 開閘門。戰鬥中做，等於開出一條離開這場戰鬥的路（脫離不必檢定） |
| 擦痕跡 | 1 | 追蹤度 −5 |
| 標記 | 1 | 一個敵人被全隊攻擊時 +2，持續到他下次過載 |

- 每做一次，追蹤度 +1；檢定失敗 +5。
- 沒有潛網者的隊伍：遮蔽只能靠打的，閘門只能靠憑證、偽裝或實地的資料埠。

### 6.7 釘住、倒下與戰敗

- **釘住**是網內的制伏：把一個化身釘在線上，他退出戰鬥、不能登出。條件：
  - 目標的餘韻已經**疊滿**（再過載一次就會倒下）；
  - 動手的人在**近身**；
  - 通過 `1d20 + mod(智識) + 介面` 或 `1d20 + mod(意志) + 格鬥` 對（10＋目標的等級×2，精英再 +2、首領再 +4），花 2 點行動點與 1 點 RAM。
- **扣線**是另一件事：對方已經倒下之後，贏的一方選擇不讓他斷線，把他的意識留在線上。釘住發生在戰鬥中，對象是餘韻疊滿但還沒倒下的人；扣線發生在對方倒下之後，不需要檢定（見本節最後的表）。
- **粉蕾絲會對你做同樣的事。** 餘韻疊滿的隊友站在第 1 格，是最危險的位置。被釘住的人算倒下，而且戰鬥贏了之後要有人花行動把釘子拆掉。
- **倒下**（餘韻疊滿再過載）：斷線，身體昏迷，沉溺 +2。
- **拔線**是個人的脫離：花 1 點行動點登出，那個人退出這場戰鬥，沒有代價。全隊都拔線等於撤退（委託副本裡是回退到進副本之前，[COMMISSIONS](COMMISSIONS.md)）。
- **戰敗**：全隊倒下或被釘住。進戰敗事件，依贏的是誰（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 8 節）：白蕾絲——被踢出去，現實的保全知道位置；粉蕾絲——全隊被扣線，接活捉類的事件；黑蕾絲——沉溺大幅上升、帶著惡意韌體醒來。
- 打完之後餘韻跟回現實（每層全屬性 −2）。一場硬仗之後馬上接現實的戰鬥，是很糟的安排。委託副本的階段之間，感載與餘韻都帶著走，所以排階段時要把這件事算進去。

### 6.8 追蹤度與增援

追蹤度是每個子網一條的壓力條（[NETRUNNING](NETRUNNING.md) 第 5 節）。在戰鬥裡它是計時器：

- 戰鬥每過一回合 +3；管理行動 +1；檢定失敗 +5。
- 到 30：一隻白蕾絲加入（牠不打人，每回合再 +5）。
- 到 60：對方的潛網者或一隻精英蕾絲加入。
- 到 90：**定位**。三回合後全隊被強制斷線，現實的增援已經在去接入點的路上；這場算戰敗，但走的是「被定位」的事件。
- 公開的地方（港灣、大街、樂園島）沒有追蹤度。大街禁止戰鬥（3.2 節），港灣沒有危險，所以這一條實際上用在樂園島的場館裡：那裡的戰鬥就是單純的戰鬥。

所以網內的戰鬥不能慢慢磨：餘韻讓雙方越打越兇，追蹤度讓敵人越打越多。

### 6.9 叫出來的東西

照現實的召喚規則（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 9 節），換名詞：

| 現實 | 內海 | 誰用 |
|---|---|---|
| 無人機：和人重疊、不佔格、每格一台、數量看同步、指揮 1 點 | **守衛程式**：規則相同 | 機師（自己的）、掮客（租的）、潛網者（接管來的） |
| 機甲：機師本人的強化狀態，3 點啟動、每場一次、持續 2＋同步回合 | **構裝體**：規則相同；有自己的感載上限與層數，傷害先打在它上面 | 機師 |
| 沒有 | **群眾**：偶像的「召集」與主播的觀眾。不是單位，是一格上的效果（擋路、灌流） | 偶像、主播 |

### 6.10 委託副本裡的網內戰鬥

玩家每個階段只玩自己選的那一面（已確認）。玩家選現實的階段，派去內海當輔助的那一組不開戰鬥畫面：他們每個階段擲一次，成功就拿到內海面在這個階段寫好的連動（例如拿下一個控制節點），失敗時那一面的壓力上升，擲出自然 1 時有人過載或受傷。玩家選內海的階段反過來，派去現實的那一組同樣每個階段擲一次。現實與內海沒有同場的先攻序列。細節放在 [COMMISSIONS](COMMISSIONS.md) 6.4 節。

**敵人**：蕾絲（白、粉、黑）、守衛程式、企業的潛網者與保全化身、遺魂、別的入侵者、迷宮館的遊戲敵人。流竄 AI 是牆外的固定 NPC，不是敵人，不在這張清單上。敵人用 ElondiaRPG 的敵人資料格式。

倒下之後有兩種下場，由贏的一方決定：

| | 放他斷線 | 扣線 |
|---|---|---|
| 結果 | 對方回到現實，昏迷一陣子。人沒事，而且知道是誰幹的 | 對方的意識留在網內出不去。現實的隊友可以去找他的身體 |
| 適合 | 趕人、爭取時間 | 活捉、滅口（要有人在現實動手）、斷後 |

企業的粉蕾絲選的是第二種。這就是為什麼在網內打輸可以比在現實打輸更糟。

### 精神污染

**這個世界的設定：內海只能造成精神污染，不能殺人。**

大潮崩那三天，數百萬人死在線上。之後每一座橋都被強制加裝**熔斷器**：訊號強到會致命之前，橋會自己斷開。這是公約少數真的被執行的條文——沒有熔斷器的橋掃不過任何一道閘門。

所以在網內能對一個人做的事，到精神污染為止。它有三種形式，由輕到重：

| 形式 | 是什麼 | 多久 | 來源 |
|---|---|---|---|
| **過載與倒下** | 感載灌滿，疊餘韻；疊滿再過載就倒下；餘韻疊滿時可以被釘住，倒下之後可以被扣線 | 幾分鐘到幾小時 | 網內所有的攻擊 |
| **快感** | 沉溺被直接推高。把持不住的東西多一樣，牆外的聲音近一點 | 長期，要治療 | 黑蕾絲、遺魂、快感漩渦的碎片、深海 |
| **植入** | 惡意韌體留在橋裡，之後自己發作（[CYBERWARE](../gear/CYBERWARE.md) 第 5 節） | 直到清除 | 粉蕾絲與黑蕾絲的附帶效果、妖精的吻 |

- 被快感傷害推到沉溺滿 100，是溺感（[CORE_RULES](CORE_RULES.md) 4.3 節）——人還活著，只是成了歡愉的信徒。這是內海能做到的最壞的事；對牆語者來說，這是它能做到的最好的事。
- **要殺人，得在現實動手。** 在網內把人打到過載、釘住、定位出他的身體，然後現實的人走過去——這是兩個戰場配合的殺法，但最後那一下一定在現實。
- 這條設定直接決定了委託的主類型：以殺人、破壞實體、帶走人或物為目標的委託，主面一定是現實（[COMMISSIONS](COMMISSIONS.md) 第 4 節）。
- 熔斷器可以被拔掉。那是違禁的改造，也是幾條任務線的題材；但它不改變規則——拔掉的人只是讓自己能被殺，不是讓自己能在網內殺人。


## 7. 雙層的委託

一件委託可以發生在：

| 類型 | 例 | 隊伍 |
|---|---|---|
| **只在現實** | 護送、討債、街頭的衝突 | 全員在現實；潛網者用快駭 |
| **只在網路** | 迷宮館的比賽、暗礁的交易、從內海正面入侵企業環礁、沉船帶的打撈 | 全員潛入；身體放在安全的地方 |
| **雙層** | 滲透一棟樓：這個階段可以選現實或內海。玩家選一面來玩，另一面派人去當輔助 | 分兩組。輔助的那一組每個階段擲一次，拿到的連動（例如控制節點）幫到玩家那一面；兩邊沒有同場的先攻序列 |
| **接力** | 前一個階段在現實拿到資料埠，下一個階段全員從那裡潛進核心 | 先一起，再一起 |

雙層是這款遊戲最有特色的場面，但不是每件委託都要是。前兩種讓「全隊一起行動」保持是常態。

## 8. 地圖的規模

網內地圖用同一套格子引擎。

| | 塊數 | 生成 |
|---|---|---|
| 港灣（房間） | 1（小，7×5，可佈置） | 固定 |
| 大街 | 3 | 固定 |
| 樂園島的場館區 | 3 | 固定 |
| 暗礁的老據點 | 2 | 固定 |
| 企業環礁的前台 | 7（理事會六家加貞網局，各一小塊） | 固定 |
| 主線與特殊任務的子網 | 約 15 座，每座 3～4 層 | 固定 |
| 一般委託的子網 | 無限 | **生成**：依企業（蕾絲的風格）與設施類型（結構） |
| 迷宮館的關卡 | 無限 | **生成**：幾種主題，分層 |
| 沉船帶 | 無限 | **生成**：每艘船一座 |
| 深海 | 無限 | **生成**：另一套規則 |

- 隨機生成沿用 ElondiaRPG 的地下城生成器：`carve_steps` 挖出結構，依層放敵人、陷阱（→ 警報與迴圈碎片）、寶箱（→ 檔案庫）、層主（→ 閘門守衛）。
- 每種生成地圖有**主題**（企業的冷白、樂園的糖果色、沉船帶的鏽與雪花、深海的粉）與**詞條**（這一座特別的地方：「有一個還在運作的印記」「蕾絲全是粉的」「登出點只有一個」）。詞條讓隨機地圖每次有個說法，也給 AI 敘事材料。

下面六節是隨機地圖的生成規則（初稿，數字待平衡）。8.1 節是所有隨機地圖共用的部分，8.2～8.6 節寫各區的差別。用到的敵人寫在 [ENEMY_ROSTER](../content/ENEMY_ROSTER.md)。

### 8.1 共通的生成規則（初稿）

**一張隨機地圖由什麼決定**

```
隨機地圖 ＝ 區 × 等級 × 主題 × 層數 × 詞條 × 固定目標（有委託或任務時才有）
```

- 區有五種：迷宮館、一般子網、暗礁的通路、沉船帶、深海。暗礁的通路沒有地圖，只有幾次檢定（8.4 節）。
- 生成的結果存在存檔裡，同一座子網、同一艘船離開再回來還是同一張圖（[COMMISSIONS](COMMISSIONS.md) 第 9 節）。迷宮館每次報名、深海每次潛入都重新生成。
- 一層是一張格子圖。迷宮館每層 9×7，其餘 11×9，和 [SITES](../world/SITES.md) 第 11 節的地下城式區域一樣大。

**生成的順序**

1. **定參數**：區、等級、主題、層數；擲那一區的詞條表一次，等級 III 以上再擲一次本節的共通詞條表。
2. **挖結構**：`carve_steps` 從入口往外挖，步數決定節點的多寡（見下面的密度表）。挖出來的空間分成節點與鏈路，一部分鏈路標成單向或會斷。
3. **放入口與出口**：入口在這一層的一邊；往下的閘門（最後一層是出口）放在離入口最遠的節點，距離照鏈路算。
4. **放固定目標**：有委託或任務時，先放目標節點（本節最後一段）。
5. **放遭遇**：照密度表，離入口越遠的遭遇越重；閘門前那一場是層主。
6. **放寶**：檔案庫、寶箱或殘骸放在死路的盡頭與遭遇的後面，不放在入口旁邊。
7. **放陷阱與地形**：警報節點與迴圈碎片放在鏈路上；各區的地形照各區的規則。
8. **放安全點**：後門、休息點、錨點或浮點，數量照密度表。
9. **套詞條**：詞條可以改上面任何一步的結果。
10. **檢查**：入口到出口一定有一條不經過陷阱的路，可以要繞遠；固定目標一定走得到。

**節點**

| 節點 | 是什麼 | 出現在 |
|---|---|---|
| 入口 | 這一層的進入點。第一層的入口連著企業的前台、館的報名處、船的破口或牆的接縫 | 全部 |
| 鏈路 | 節點之間的路。有的是單向，有的走過一次就斷 | 全部 |
| 遭遇 | 一場戰鬥。可以潛行繞過、談判或用偽裝混過去的，照各區寫明 | 全部 |
| 巡邏 | 會移動的遭遇。隊伍每走三個節點，它往相鄰的節點走一步；撞上了就打 | 子網、深海；沉船帶偶爾 |
| 閘門 | 通往下一層。有層主守著；有憑證、後門鑰匙或破解時可以不打層主，但拿不到它的掉落 | 子網、迷宮館、沉船帶 |
| 檔案庫（寶） | 要拿的東西。子網的叫檔案庫，館裡叫寶箱，船上叫殘骸，深海叫沉積 | 全部 |
| 控制節點 | 連著現實的裝置（[NETRUNNING](NETRUNNING.md) 第 4 節） | 子網；少數沉船 |
| 人 | 連在這座子網上的員工，或困在船上、海裡的人。可以快駭、可以談 | 子網、沉船帶、深海 |
| 警報節點 | 陷阱。子網裡踩到時追蹤度 +10；館裡叫出兩個小兵；船上叫醒附近的一個遺魂 | 子網、迷宮館、沉船帶 |
| 迴圈碎片 | 陷阱。走進去的人要過介面或意志的檢定（DC 照等級），失敗的話感載 +8，被送回這一層的入口 | 全部 |
| 機關 | 迷宮館的謎題（8.2 節） | 迷宮館 |
| 印記 | 會說話的人格殘片，是一件事件 | 沉船帶、深海 |
| 安全點 | 短休的地方。子網的是後門，館的是休息點，船上的是錨點，深海的是浮點；各自的規則照各區 | 全部 |
| 目標 | 委託或任務寫死的節點（本節最後一段） | 全部 |

「DC 照等級」指的是：I 級 10、II 級 12、III 級 14、IV 級 16、V 級 18。下面各節的檢定沒有另外寫 DC 時都照這個。

**每一層的密度**

| 區 | `carve_steps` | 節點 | 遭遇 | 巡邏 | 寶 | 陷阱 | 安全點 |
|---|---|---|---|---|---|---|---|
| 迷宮館 | 18～24 | 6～8 | 2（第三層 1 加館主） | 0 | 寶箱 1～2 | 機關 1、陷阱 0～1 | 層與層之間的休息點 |
| 一般子網 | 30～40 | 8～12 | 2～3 | 1 | 檔案庫 1～2 | 1～2 | 只有預埋的後門 |
| 沉船帶 | 30～40 | 8～12 | 2～4 | 0～1 | 殘骸 2～3 | 1～2 | 錨點 1 |
| 深海 | 24～34 | 7～10 | 2～3 | 1（跟著海流走） | 沉積 1～2 | 群落的地形 | 浮點：群落的第二層 1 |

- **遭遇**照 [ENEMIES](ENEMIES.md) 第 13 節的點數組：一般遭遇 3＋等級；閘門前的層主 5＋等級；每座地圖最後一場的首領戰 7＋等級。敵人的等級在地圖的等級 ±1 之內。
- 人數少於四人時，預算照 ENEMIES 第 13 節扣。
- **巡邏**可以躲：全隊過一次潛行檢定，或有人開著隱形類的構裝，就讓它擦身而過。

**壓力條**

ElondiaRPG 的地下城用光線當壓力。內海每一區換一樣東西：

| 區 | 壓力條 | 怎麼漲 | 漲到底會怎樣 | 規則在 |
|---|---|---|---|---|
| 迷宮館 | 時間與評價 | 探索與戰鬥的回合 | 評價下降，獎金變少；不會被趕出去 | 8.2 節 |
| 一般子網 | 追蹤度 | 管理行動、戰鬥的回合、白蕾絲、警報節點、下載 | 定位：強制斷線，現實的增援出發 | [NETRUNNING](NETRUNNING.md) 第 5 節；本章 6.8 節與 8.3 節 |
| 暗礁的通路 | 沒有條，每一段一次檢定 | — | 過礁事件 | 8.4 節 |
| 沉船帶 | 登出訊號 | 往下走、戰鬥的回合、漩渦的碎片 | 拔線越來越難，到 0 只能走錨點 | 8.5 節 |
| 深海 | 沉溺 | 每一層、快感傷害、群落的地形 | 拔線越來越難；到 100 是溺感 | 8.6 節 |

- 探索中每走一個節點算一個探索回合。壓力條在探索回合裡會不會動，照各區寫明。

**帶出去才算數**

- 從寶拿到的東西，正常登出時全部帶走。正常登出是拔線成功、走到安全點登出、或打完最後一層從出口離開。
- 倒下、被強制斷線時，這一趟拿到的東西每一件擲一次 d6，1～3 那一件丟掉。迷宮館的籌碼照算到倒下的那一刻。
- 被扣線的人，東西還在他身上；誰把他的身體收走，誰就拿走。

**共通詞條**（d12，III 級以上的地圖多擲一次）

| d12 | 詞條 | 效果 |
|---|---|---|
| 1 | 另一隊人也在裡面 | 多一隊別的入侵者：一場可以談的遭遇。他們先拿走一個寶 |
| 2 | 有一個還在運作的印記 | 多一個印記節點；子網裡出現時，那是一個員工留在系統裡的人格備份 |
| 3 | 寂靜 | 沒有巡邏；第一場遭遇開場時敵人還沒察覺，我方先手 |
| 4 | 熱點 | 一場遭遇的敵人等級 +1，那一場後面的寶多擲一次 |
| 5 | 維修通道 | 第一層與第二層之間多一條不經過閘門的路，要一次介面檢定才找得到 |
| 6 | 訊號不穩 | 所有的介面檢定 −1；拔線照常 |
| 7 | 多一層 | 層數 +1；最後一層的寶多擲一次 |
| 8 | 有人留了記號 | 一條從入口到閘門的路上，陷阱全部被標出來 |
| 9 | 單向的路 | 一半的鏈路是單向，回頭要繞路 |
| 10 | 剛被翻過 | 寶少一個，陷阱少一個，遭遇少一場 |
| 11 | 有東西在看 | 每場戰鬥有一個不出手的觀察者；離開時擲一次事件，看是誰看見了你 |
| 12 | 雙份 | 擲兩次所在區的詞條表，兩個都用（衝突時重擲第二個） |

**把固定目標放進生成的地圖**

委託與任務常常要在一張生成的地圖裡放一個寫死的東西：一份檔案、一個控制節點、一個要救的人、一段印記。規則如下。

- 委託副本的內海面，每一個階段對應子網的一層（[COMMISSIONS](COMMISSIONS.md) 2.3 節）。階段寫的 `layer`（訪客、員工、管理、核心）決定生成哪一層。玩家在某個階段選了現實面時，那一層不生成，改由輔助面擲骰代替（[COMMISSIONS](COMMISSIONS.md) 6.4 節）；擲失敗時，追蹤度 +10 帶進下一個內海階段。
- 目標節點放在離入口最遠的那一半節點裡，不放在陷阱的後面。它可以和這一層的閘門是同一個節點：決定性的下載常常就在閘門守衛的身後。
- 隔離區（[COMMISSIONS](COMMISSIONS.md) 2.2 節）生成成另外一層，鎖到現實面的連動打開為止。
- 特殊任務的區域（[QUESTS](../content/QUESTS.md) 裡標了 `zone` 的那些）可以給一個固定的種子：每個玩家拿到同一張圖，劇情寫的節點擺在寫好的位置，其餘照生成。

| 目標 | 放在 | 完成的方式 |
|---|---|---|
| 下載 | 檔案庫 | 待在節點上 2～4 個回合（委託寫明），期間不能離開；子網裡每回合追蹤度 +2 |
| 接管 | 控制節點 | 一次管理行動「接管」，或用後門鑰匙 |

### 8.2 迷宮館（初稿）

迷宮館是樂園島上合法的地下城（3.3 節）。一趟很短：三層，打完館主就結束，一個晚上可以跑兩三趟。打輸只是斷線、扣押金，所以這裡是練手、試新構裝、找隊友與直播的地方。館方是萬華鏡與伊甸園，聯名的關卡由緋櫻映畫與星旗出錢。

**報名**

| 公開組 | II | C$150 | 比賽版，或自己的 I～II 級構裝 | C$900 | II 級 |
| 無差別組 | III～IV | C$500 | 自己的構裝，不限等級 | III 級 C$3,000；IV 級 C$8,000 | 和組別同級 |

- 一隊最多四人，可以一個人報名。每趟重新生成；同一個主題一天之內擲到兩次就重擲。

**三層**

| 3 | 館主廳 | 1 場遭遇、館主戰、獎品室 | 結算評價與獎金 |

- **寶箱**每個有一成的機會是寶箱怪。
- **機關**是這一館的謎題：壓力板、鏡子、開關的順序、會動的地板。解一個機關要一次檢定，用介面、街頭直覺或體格都可以（DC 照等級）。失敗的話，解的人感載 +8，或者叫出兩個關卡小兵打一場；之後可以再試。解開的機關打開一條近路或一個寶箱。
- **延長賽**是第 4 層以下。進得去的方法有兩種：擲到「延長賽」的詞條，或前兩層的「加碼」都接受了。延長賽每一層的等級 +1、獎金再加一倍，館方的熔斷保護關掉（倒下照算沉溺）。每一層有一成的機會接到不該接的地方（3.3 節）：那一層換成沉船帶的一角，照 8.5 節生成，登出訊號從 60 起算。EVENTS_CITY 的 `nt_isle_trapped` 發生在這裡。

**館內的規則**

- 沒有追蹤度。館方的熔斷設定讓倒下不加沉溺（6.7 節的「沉溺 +2」不算），也不會有人被扣線。感載與餘韻是真的，打完照樣帶回現實。
- **時間與評價**：每一層有一個標準回合數，探索與戰鬥的回合一起算：前庭 12、迴廊 15、館主廳 10。破關時照三件事評 S～C：總回合數、倒下的人數、直播的觀看數。評價乘在獎金上：S ×1.5、A ×1.2、B ×1、C ×0.7。
- **直播**：館方提供機位，主播的導流器與直播目標照用（[DATA](DATA.md) 第 10 節）。直播的觀看數算進評價。

### 8.3 一般子網（初稿）

每一家企業在企業環礁有一座島（3.4 節）。島的前台是固定的地圖，前台後面是企業每一棟設施各一座子網。一般委託的子網，和玩家自己從前台闖進去的子網，照這一節生成。主線與特殊任務的子網是手工的，不照這一節。

**兩種進去的方式**

| | 委託 | 自己去挖 |
|---|---|---|
| 從哪進 | 委託指定的設施。可以從前台一層一層打穿，也可以從現實的資料埠直接進到核心附近（[COMMISSIONS](COMMISSIONS.md) 第 5 節） | 從那家企業的前台。前台的設施名錄每週更新，挑一間，或擲設施類型 |

| 目標 | 固定目標（8.1 節） | 沒有；每一層的檔案庫多一個 |
| 離開時 | 照委託 | 照當時的追蹤度加那家企業的敵對值（[NETRUNNING](NETRUNNING.md) 第 5 節）。被定位的話，那家企業可能發懸賞（事件） |

- 自己去挖是沒有委託人的竊盜：拿到的東西全部歸自己，但沒有中間人替你洗乾淨。偷來的帳戶餘額與設計圖要去暗礁的蚌殼市脫手或洗過（3.5 節）。

- 首領只在企業等級範圍的最高兩級出現（[ENEMIES](ENEMIES.md) 1.6 節）。子網的等級不到那兩級時，核心由閘門守衛或一隻精英加兩個雜兵守。

**追蹤度在生成的子網裡**

- 一座子網一條追蹤度，往下一層不歸零。
- 探索中追蹤度不會自己漲。漲的是：踩到警報節點 +10；下載每回合 +2；管理行動 +1，失敗 +5；戰鬥每回合 +3；白蕾絲在場每回合 +5；快駭照程式（NETRUNNING 第 5 節、6.8 節，數字以 6.8 節為準）。
- 到 30：剩下的每一層巡邏 +1，閘門 DC +2。到 60：現實的保全進入警戒，委託的警戒照 COMMISSIONS 的規則上升。到 90：定位。
- 同一座子網七天之內再進去，追蹤度從上次離開時的一半起算。被定位過的子網，七天之內每一層的遭遇多一個雜兵。
- 後門讓下次直接從那一層進來（NETRUNNING 第 4 節），追蹤度從 0 起算。被定位之後，那座子網的後門有一半的機會被清掉。

### 8.4 暗礁的通路（初稿）

沉船帶只能從暗礁進去。暗礁的節點會搬家（3.5 節），通往沉船帶的那幾條路也跟著換位置，街上叫它們**水道**。水道本身是安全的：沒有守衛，沒有追蹤度，不放遭遇。危險在於每一次經過都要過幾道檢定，失敗時會碰上別的東西。

**找水道**

- 要一張有效的**水道圖**。來源：在蚌殼市買（近岸 C$200、中段 C$400、貼牆 C$600）；向牆語者的前哨要（牆語者的好感，或沉溺 40 以上）；請拾荒客的嚮導帶路（名冊）；自己找（介面或街頭直覺 DC 14，花一個小時；失敗可以再找一次，第二次失敗時擲一次過礁事件）。
- 水道圖三天後失效，因為節點搬家了。

**過礁**

| 去哪 | 段數 | 每段的 DC | 船的等級 | 登出訊號的起點 |
|---|---|---|---|---|
| 近岸 | 1 | 12 | II～III | 100 |
| 中段 | 2 | 14 | III～IV | 80 |
| 貼牆 | 3 | 16 | IV～V | 60 |

- 每一段由隊伍挑一個人擲：介面（找路）、潛行（躲開掃蕩）或意志（不理水道裡的聲音），三選一。另一個人可以協助，+2。
- 成功就過去；失敗的那一段擲一次過礁事件，處理完照樣過去。
- **帶貨回來**：沉船帶撈到的大件東西（印記、V 級構裝、漩渦的碎片）帶不過橋的熔斷器，直接拔線的人帶不出去。要帶它們，得走回程，從暗礁的老據點登出。回程照去程的段數再擲一次，DC −2；身上有大件的東西時 DC +2。小件的東西（資料、構裝、設計圖、舊帳戶）直接登出也帶得走。

### 8.6 深海與群落（初稿）

深海是牆外（[NETRUNNING](NETRUNNING.md) 第 7 節）。沉船帶最深的船貼著牆，船心的接縫是一道門，門後是牆本身。沉溺到 50 的人，牆讓他過去。沉溺不到 50 的人，牆會勸他回頭；這一段是事件，沒有戰鬥，醒來時人在船心的錨點上，不太記得自己為什麼想過去（[NETRUNNING](NETRUNNING.md) 7.1 節）。

**一趟潛水**

1. 穿過牆，落進一個隨機的**群落**（擲 d8）。
2. 每個群落走兩層。第一層是群落的外圍；第二層是群落的中心，最後一場是首領戰，首領戰的後面是**海流**與**浮點**。
3. 走完兩層，選一個：從浮點**上浮**（登出，不必檢定，東西全部帶走），或跟著海流**往下**，擲 d8 換到另一個群落，擲到去過的就重擲。
4. 八個群落都走過之後，海流只通往「更深的地方」，那裡是當中間人的流竄 AI 待的地方，沉溺 100 以上的人才進得去（[NPCS](../world/NPCS.md) 8.3 節）。其餘的人只能上浮。

- 走到第幾個群落叫**深度**。深度 1～2 的敵人是 IV 級，深度 3 起是 V 級；深度每 +1，每個沉積多擲一次。
- 首領戰擲 d6：1～3 鯨落，4～6 漩渦之心。

**生成的群落與居民的群落**

[NPCS](../world/NPCS.md) 8.3 節有四個居民的群落（關係、感官、身體、扮相），那是手工的地圖，流竄 AI 住在那裡。這一節生成的群落是它們周圍的野地；NPCS 那一節說的「群落之間的路」就是這裡。每個生成的群落偏向一軸。在那個群落的海流旁邊，有一條固定的路通往同一軸的居民群落，沉溺 50 以上的人隨時可以走過去；走過去不算進生成的層數，回來時接著原本的那一層。

**深海的規則**

- **沒有追蹤度，壓力條是沉溺。** 穿過牆時沉溺 +1。每進一層沉溺 +2，深度 3 起每層 +3。快感傷害照 6.5 節加沉溺，群落的地形另外加。
- **拔線**要過意志檢定，DC＝10＋沉溺÷10（無條件捨去）。失敗的話沉溺 +1，這一層不能再拔線，只能走到浮點。失敗的意思是那個人自己不想走；文字照這個方向寫，不寫成被困住。
- **浮點**：每個群落的第二層有一個，在首領戰的後面；第一層有一成的機會也有一個。站上去免檢定登出，東西全部帶走。
- **倒下**：斷線，沉溺 +2，再走 `polluted`（沉溺 +3～6，帶回一段不是自己的習慣；那段習慣照所在的群落，見下表）。
- **沉溺 60 以上**的人，深海對他溫和（[CORE_RULES](CORE_RULES.md) 4.3 節）：深海的生物第一回合不攻擊他，除非他先動手；他撈沉積時多擲一次。
- **沉溺到 100**：在深海裡到 100 的人當場成為溺感者（CORE_RULES 4.3 節）。遊戲繼續，這一趟照常走完。在深海裡，沉溺的數字一直顯示在畫面的正中間。
- 流竄 AI 偶爾路過生成的群落（事件）。牠們不是敵人，不加入戰鬥（NETRUNNING 7.1 節）。
- 敵人用 ENEMY_ROSTER 的「深海的生物」。

## 9. 網內的人

- 固定 NPC 在兩邊都有（[NPCS](../world/NPCS.md)）：中間人在港灣見人；蕾諾拉只在網內；澪只在樂園島；貞網局的霜兩邊都追。
- **常駐者**：幾乎不登出的人。身體在潛艙店的長租隔間、療養院、或某個沒人知道的地方。他們是內海的在地人——店員、嚮導、賭徒、傳教的。有些人的身體已經不在了，自己不知道。
- **AI**：店員、客服、遊戲裡的角色。法律上是程式。有幾個不太確定。
- 化身可以和本人長得完全不同。**網內認識的人，在現實見面時可能認不出來**——這是關係線與偽裝的材料。豔名與街頭信譽在網內用的是化身的名字，可以和現實分開經營，也可以被人連起來。

## 10. 成人向

- 樂園島有成人向的主題館；暗礁有不合法的。
- 網內的親密是化身之間的，但**感載是真的**，橋參數照樣成長（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 1、3 節）。
- 化身可以不是自己的樣子，所以網內的關係多一層「對方到底是誰」。
- 粉蕾絲、遺魂、流竄 AI 的手段，以及在網內被釘住或扣線的戰敗事件，都受內容篩選控制（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 9 節）。
- 所有化身背後的人都是成年人；化身的外觀同樣不得呈現為未成年。
