# 事件：一個統一的事件導演

> 上層：[GAME_DESIGN](../GAME_DESIGN.md)（第 6 節的三種內容形式之一）。依賴：[CORE_RULES](CORE_RULES.md)（檢定、三條軌）、[DISTRICTS](../world/DISTRICTS.md)（各區、橋接區、日與夜）、[LIFE](../world/LIFE.md)（星期、城市的大事、行規）、[NPC_SYSTEM](NPC_SYSTEM.md)（登場角色、NPC 自己的日子）、[LEWD_SYSTEM](LEWD_SYSTEM.md)（第 7 節契約、第 9 節內容篩選）、[COMMISSIONS](COMMISSIONS.md)、[CYBERSPACE](CYBERSPACE.md)、[FIXER](FIXER.md)。被依賴：[DOWNTIME](DOWNTIME.md)（家園）、[STORY_QUESTS](../world/STORY_QUESTS.md)（事件可以開出特殊任務）、[SITES](../world/SITES.md)（要地的事件表）。
> 來源：ElondiaRPG 的 EVENTS（事件視窗）、TRAVEL_EVENTS（旅途、城鎮事件與事件導演）、ADULT_EVENTS（地下城與寄生物的事件），以及主人事件（`slavery`）。那邊有五套結構相同的事件導演（`townEvents`、`dungeonEvents`、`leadEvents`、`parasiteEvents`、`pregnancyEvents`），掃描建議合併（[scan/03](../plan/scan/03-map-npc.md) 第 6 節 E7、[scan/05](../plan/scan/05-adult-home.md) 7.2 節）。這裡從一開始就只做一個。預定資料：`data/rules/events.json`（導演的設定）、`data/events/<範圍>.json`（模板，依範圍分檔）。數值都是初稿。
> **所有登場角色都是成年人。** 成人事件這份只寫機制與性質，不寫描寫。

## 1. 事件是什麼

事件是「走在路上、待在某處時發生的一件事」（[GAME_DESIGN](../GAME_DESIGN.md) 第 6 節）。它和另外兩種內容形式的分工：

| | 事件 | 特殊任務 | 委託副本 |
|---|---|---|---|
| 長度 | 一件事，一到兩個決定 | 一條寫好的任務鏈 | 一件委託的行動階段 |
| 會不會重複 | 會 | 不會 | 會 |
| 誰決定什麼時候發生 | **事件導演**（本文件） | 劇情旗標 | 玩家接案 |

事件可以**開出**另外兩種：效果 `start_quest` 開一條特殊任務，`start_commission` 生成一件委託（2.4 節）。

**只有一個導演。** 每一種「範圍」（街頭、要地、家園……）不是一套程式，而是一組參數：在哪些觸發點擲、機率、冷卻、篩選。新增一種範圍只要在 `events.json` 加一筆，不寫新的程式。

## 2. 事件的格式

### 2.1 欄位

| 欄位 | 說明 |
|---|---|
| `id` | 唯一。前綴照範圍（`st_` 街頭、`si_` 要地、`nt_` 內海、`cm_` 委託、`ct_` 契約、`hm_` 家園、`ad_` 成人、`wa_` 流竄 AI、`ms_` 吉祥物） |
| `scope` | 範圍（第 4 節） |
| `triggers` | 在哪些觸發點可以抽到（3.1 節） |
| `where` | 區、街區、設施類型、橋接區、要地與樓層、內海的區與子網的層、副本的類型與面 |
| `when` | 時段（白天 6～18、夜晚 18～24、深夜 0～6）、星期。沒有月份：城市的大事由事件與任務觸發（[LIFE](../world/LIFE.md) 8.2 節） |
| `requires` | 條件（2.2 節），全部成立才進候選 |
| `weight`、`weight_mods` | 基本權重；條件式的倍率（例：這一區豔名每 20 點 ×1.2） |
| `category` | 類型：人情、麻煩、機會、傳聞、買賣、慾望（3.5 節） |
| `cast` | 登場角色 0～2 位：指定的固定 NPC、主角認識的人、或依當下的區新生成的人（[NPC_SYSTEM](NPC_SYSTEM.md) 第 4 節） |
| `blocking` | 要回應才能繼續（預設是）；不擋的叫**通知** |
| `options` | 回應，最多 4 個（2.3 節） |
| `tags` | 內容標籤（第 6 節） |
| `repeat_days` | 同一件事幾天內不再出現（不寫照範圍的預設） |
| `deadline` | 只有契約指令與鉤子：多久之內要處理 |

### 2.2 條件

`requires` 能看的東西（全部是引擎的狀態，AI 不參與）：

| 類 | 條件 |
|---|---|
| 角色 | 屬性、基本功等級、沉溺的範圍、餘韻層數、感載、生命值低於一半、橋參數、傾向等級、身上的義體與惡意韌體、調校、有沒有橋 |
| 外表 | 曝露度、風格、獸化、光紋露不露出來 |
| 名聲 | 街頭信譽的階、這一區的豔名、某勢力的敵對值與好感、公信力、人氣 |
| 人 | 某個 NPC 的親密度、在不在名冊、忠誠、隊上有誰（路數）、主角是契約人或持約人、主僕關係、持約人的滿意 |
| 地方 | 這一區的狀態（封鎖、祭典）、據點的等級、鄰里（蜂巢） |
| 時間 | 時段、星期、正在發生的城市大事、離上次長休多久、帳單有沒有欠 |
| 劇情 | 旗標（包括 AI 的 `ai:` 旗標）、某條特殊任務的階段、某件委託正在進行 |

### 2.3 選項與檢定

每個選項：

| 欄位 | 說明 |
|---|---|
| `text` | 選項的一句話 |
| `need` | 要有才看得到：一件物品、一項基本功 2 級以上、隊上有某條路數、有現金 |
| `check` | `基本功（屬性）` 與難度：容易 10、普通 13、困難 16、極難 19、傳說 22（[CORE_RULES](CORE_RULES.md) 第 3 節）。範圍可以把整張表往上推（要地的深層、內海的深處 +2） |
| `outcomes` | 依成功程度四級（大成功、成功、失敗、大失敗）各一組效果；沒有檢定的只寫一組 |
| `adult_scene` | `always`／`success`／`fail`：這個結果把「可能進入成人場景」交給 `scene_gate`（4.7 節） |

- **誰擲**：發生在主角身上的事由主角擲；街頭、要地、委託裡「隊伍遇到的事」由隊上那一項最好的人擲，另一位有同一項 2 級以上時協力 +2。
- **自由回應**：每個擋住行動的事件都多一個「我要做別的」——走主動行動，交給 judge 判定（3.7 節）。

### 2.4 效果（封閉清單）

事件只能產生下表的效果。**上限只管 AI 自己生成的事件**（已確認）：Agent 模式提出的事件、AI 判定「我要做別的」的結果，超過的由程式夾住。內建的事件，以及之後用世界編輯器做的事件，不受這張表的上限限制，寫多少就是多少。

| 效果 | 上限（每件） | 說明 |
|---|---|---|
| `cred`、`cash` | ±（主角信譽那一階的委託報酬下限 × 0.5） | 帳戶或現金晶片（[LIFE](../world/LIFE.md) 1.3 節） |
| `item`、`part` | 等級不超過主角所在那一區的等級 | |
| `hp`、`load`、`afterglow` | 不會讓人倒下或瀕死，除非事件標了 `combat` | |
| `sink` | ±3；流竄 AI 的接觸 ±5 | 成人場景的沉溺只由 `scene_settle` 改 |
| `bridge` | 一項 +1 | 橋參數慢慢長（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 1 節） |
| `tendency` | 一個標籤一點 | |
| `hostility`、`favor`（勢力） | ±10、±5 | 每個勢力各記各的 |
| `affinity`、`loyalty`（個人） | ±8、±10 | [NPC_SYSTEM](NPC_SYSTEM.md) 第 7 節、10.4 節 |
| `owed`（人情） | 一個小或中人情 | [FIXER](FIXER.md) 第 8 節 |
| `fame`（豔名） | 這一區 ±5 | |
| `rep`（街頭信譽） | ±3 | |
| `footage` | 一段素材 | [MEDIA](MEDIA.md) 第 2 節 |
| `condition` | 一個暫時的狀態 | 例：被下藥、受驚、宿醉 |
| `malware` | 一個惡意韌體的潛伏期 | [CYBERWARE](../gear/CYBERWARE.md) 第 5 節 |
| `lock` | 鎖一件義體若干小時 | |
| `time` | 推進若干小時 | |
| `move` | 帶到一個固定的地點或場景地圖 | 現實不用隨機地圖 |
| `fight` | 開一場戰鬥，敵人照當下的區與勢力 | |
| `start_commission` | 生成一件委託，`commission_gen` 寫內容 | |
| `start_quest` | 開一條特殊任務 | |
| `roster_add` | 一位登場角色進名冊候選 | [NPC_SYSTEM](NPC_SYSTEM.md) 10.7 節 |
| `order` | 一條契約指令進佇列 | 4.5 節 |
| `district_state` | 一區的狀態幾小時到幾天 | 封街、臨檢加強 |
| `alert`、`trace` | 只在委託副本裡：警戒、追蹤度 ±20 | 4.4 節 |
| `link` | 只在委託副本裡：給一個連動（後面的階段多一條分支、少一些敵人） | [COMMISSIONS](COMMISSIONS.md) 第 3 節 |
| `city_event` | 開始一件城市的大事（先預告三天） | [LIFE](../world/LIFE.md) 8.2 節 |
| `insight` | 體悟，一件最多 5 點 | 夜課的經驗（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 10 節） |
| `neighborhood` | 鄰里 ±3 | 蜂巢的鄰里（[DISTRICTS](../world/DISTRICTS.md) 第 3 節） |

| `grace` | 寬限：一項欠款延後，最多 7 天 | 欠繳的週數在寬限期間不往上加 |

## 3. 導演

### 3.1 觸發點

引擎在這些時候問導演「有沒有事」。觸發點寫在引擎的回合管線裡（`afterStep`、`afterAction`），不放在介面那一層——ElondiaRPG 把它寫在 store 是掃描點名的問題（[scan/03](../plan/scan/03-map-npc.md) 第 6 節 E6）。

| 觸發點 | 什麼時候 |
|---|---|
| `enter_block` | 走進一塊街區 |
| `walk` | 在街區裡每走 10 格 |
| `enter_bridge` | 走進一塊橋接區 |
| `enter_facility` | 走上一個設施格（店、診所、夜店、潛艙店……） |
| `transit_stop` | 公共交通每過一站 |
| `enter_floor` | 進要地的一層，或內海的一個區、子網的一層 |
| `open` | 開鎖、開檔案庫、搜索 |
| `stage` | 委託副本的每個階段開始；壓力條跨過 60 |
| `rest` | 短休、長休醒來 |
| `work` | 打工每做完一班 |
| `sleep_out` | 露宿醒來（算街頭範圍，機率 25%） |
| `home` | 回到據點；在據點待滿 3 小時 |
| `daily` | 每天 08:00 一次（契約的排程、流竄 AI、NPC 自己的日子長出來的事） |
| `weekly` | 每週一的帳單結算之後 |
| `downed` | 在現實或內海倒下（不是戰鬥裡的戰敗事件，是之後醒來前後的事） |
| `malware` | 惡意韌體到了發作的階段 |
| `hook` | AI 留下的鉤子到期（3.7 節） |

### 3.2 一次觸發的流程

```
觸發點 ──▶ 找出這個觸發點相關的範圍
          └▶ 每個範圍：範圍冷卻過了嗎？ → 擲範圍的機率（3.3 節）
               └▶ 中了：篩選模板（where、when、requires、內容篩選、不重複天數）
                    └▶ 依權重抽一件：weight × weight_mods × 類型平衡 × 最近出現的懲罰
                         └▶ 放進候選
          ──▶ 所有候選照優先序排，依每回合的上限放行（3.4 節）
          ──▶ 放行的：檢定事件馬上擲骰、出報告；選擇事件進事件視窗
```

- 所有亂數用「存檔種子＋時間＋觸發點」，回退之後重來會得到同樣的結果。
- 篩選後一件都沒有：這次當作沒發生，不吃冷卻。

### 3.3 機率、冷卻與不重複

| 範圍 | 觸發點 | 基本機率 | 範圍冷卻 | 單件不重複 | 每天上限 |
|---|---|---|---|---|---|
| 街頭 | `enter_block`、`walk`、`enter_bridge`、`enter_facility`、`transit_stop` | 12%、6%、25%、8%、6% | 2 小時 | 3 天 | 5 件 |
| 要地 | `enter_floor`、`open`、`rest` | 25%、10%、20% | 1 小時 | 同一處 7 天 | — |
| 子網與內海 | `enter_floor`、`open`、登入與登出 | 20%、10%、10% | 1 小時 | 3 天 | — |
| 委託副本內 | `stage` | 每個階段 30%；壓力條 15% | 每個階段最多一件 | 同一件委託不重複 | — |
| 契約指令 | `daily`、走到持約人那裡 | 4.5 節 | — | 2 天 | 佇列最多 3 條 |
| 家園 | `home`、`rest`、`weekly` | 10%、20%、依帳單 | 6 小時 | 7 天 | 2 件 |
| 成人事件 | 見 4.7 節 | 依觸發點 | 4 小時 | 5 天 | — |
| 流竄 AI 的接觸 | 在內海時的 `enter_floor` 與登入、`rest`、`daily` | 4.8 節 | 24 小時 | — | 1 件 |
| 打工 | `work`：每做完一班 | 15% | 每班最多一件 | 3 天 | — |
| 吉祥物的目擊 | `walk`、`transit_stop`、`stage` | 4.9 節 | 72 小時 | — | 1 件 |

- **存檔規則**可以調每個範圍的倍率（0～3），以及成人事件的比重（1～8 倍，沿用 ElondiaRPG 的 `adultDungeonMult`：成人向模板的權重乘上它，觸發機率依可抽模板的平均倍率拉高，最高 100%）。
- **敵對值、豔名、曝露度**是共通的修正：敵對值 40 以上的勢力，它的「找麻煩」類模板權重 ×2；這一區的豔名每 20 點，「被認出來」類 ×1.2；曝露度超過這一區的容忍（[DISTRICTS](../world/DISTRICTS.md) 1.1 節）時，街頭的觸發機率 ×1.5。

### 3.4 排序與每回合的上限

**一回合**是一個會推進時間的玩家動作：走一步、走進設施、做一個行動、休息一次。

**每回合最多放行：一件擋住行動的事件，加上兩則通知。** 擋住行動的事件怎麼取一件（已確認）：

| 序 | 範圍 | 輸掉的怎麼辦 |
|---|---|---|
| — | 戰鬥、特殊任務的任務點、戰敗事件 | 不屬於導演，永遠先處理；這一回合導演的擋住型事件全部延後 |
| 1 | 委託副本內 | 只在副本裡跑；在副本裡時，其他的擋住型事件都不擲 |
| 2 | 契約指令的強制執行（抗拒失敗後到期的、走到持約人那裡觸發的） | 延後到下一回合 |
| 3 | 家園的上門（敵對值、討債） | 延後，最多 6 小時 |
| 其餘 | 要地、子網與內海、吉祥物、流竄 AI、成人事件、街頭 | **不排順序**：同一回合有好幾個範圍都擲中時，隨機抽一個放行，其他的作廢（流竄 AI 的延後到下次長休） |

- **通知**（不擋行動）：契約指令送達、流竄 AI 的低語、名冊的人耳語來借錢、上門的預告。每回合最多兩則，多的排到下一回合。在委託副本裡只收契約指令的送達，期限暫停到出副本為止。
- 城裡一天的擋住型事件總共最多 8 件（存檔規則可調），不含委託副本內與契約。
- 延後的事件存在 `pending`，到期還沒放行就作廢；作廢的不吃冷卻。

### 3.5 類型平衡

沿用 ElondiaRPG 城鎮事件的做法：記住最近 6 件的類型，候選事件的類型每出現過一次，權重 ×0.35。類型：

| 類型 | 例 |
|---|---|
| 人情 | 鄰居、走失的人、有人求助 |
| 麻煩 | 盤查、找碴、被跟蹤、討債 |
| 機會 | 撿到東西、便宜貨、臨時的工作 |
| 傳聞 | 牆報、耳語、異象、目擊 |
| 買賣 | 攤販、黑市、有人兜售 |
| 慾望 | 成人向的事件；另外受 3.3 節的比重控制 |

### 3.6 事件視窗與佇列

沿用 ElondiaRPG 的事件視窗：帶遮罩的對話框，一次一件，標題寫還有幾件。

- 擋住行動的事件不處理就不能移動、休息（引擎回錯誤）。可以關掉視窗先看看周圍。
- **契約指令另有一個面板**（4.5 節），不佔事件視窗：列出佇列裡的指令、期限、做到哪一步。
- 導演的狀態存在存檔的 `events`：每個範圍上次的時間、每件事上次的日子、最近的類型、延後的事件、契約的佇列、吉祥物的目擊數、鉤子。

### 3.7 AI 在哪裡

**Agent 模式關著時，AI 不挑事件、不編事件**；開著時可以提議事件，但仍由導演驗證與排程（見表的最後一列）。挑哪一件、什麼時候、結果的數值，全是導演與模板。AI 只透過 [AI_TASKS](../plan/AI_TASKS.md) 的任務碰這裡：

| 地方 | 任務與工具 | 退路 |
|---|---|---|
| 事件的經過 | `narrate` 照報告寫 | 只顯示模板的文字 |
| 自由回應 | `judge` 依骰值給成功程度；效果只能是 2.4 節的清單 | 照選項的規則結算 |
| 成人場景的進入點 | 結果帶 `adult_scene` 時送 `scene_gate` | 不進 |
| `start_commission` | `commission_gen` 寫委託的內容 | 模板生成 |
| 新登場的人 | `meet_npc`；名字由程式產生 | 模板 |
| **鉤子** | judge 用 `add_hook` 留下「誰、在哪、何時、一句話」（一區同時最多一則、有期限）。導演把它變成一件街頭範圍的事件，在那裡、那時候放行。它和街頭的事件一樣不排優先序，但**不吃冷卻、不擲機率** | 沒有鉤子 |
| **AI 生成的事件** | **只在 Agent 模式開著時**（[AI_TASKS](../plan/AI_TASKS.md) 1.2 節），**以單發為主**；對系列只是調味或指引，不寫系列的旗標（[SERIES](SERIES.md) 第 7 節）。AI 用 `propose_event` 交出一件符合第 2 節格式的事件。導演驗證格式、效果清單與內容篩選後排進佇列。AI 提出的事件算街頭範圍，不擲機率、不吃範圍的冷卻；它照樣受每回合一件、城裡每天 8 件的上限限制，另外每天有自己的件數上限。Agent 模式關著時沒有這條路，事件只來自資料 | 沒有 |

> **第 4 節各範圍裡的事件例子是內容層（L4）的素材**（[DESIGN_ORDER](../plan/DESIGN_ORDER.md)）；範圍的規則照常有效。

## 4. 範圍

### 4.1 街頭

走在街上、穿過橋接區、搭車時遇到的事。每一區有**白天**與**夜晚**兩張表，橋接區有自己的一張，車廂與月台共用一張（[DISTRICTS](../world/DISTRICTS.md) 1.2 節、1.2.1 節）。星期與城市的大事改權重（[LIFE](../world/LIFE.md) 第 8 節）：週一收租日討債的事多，週五番街熱鬧，週六高架橋下的夜市。

- **敵對值**：某勢力的敵對值 60 以上時，牠的人在牠的地盤上可能直接找你——這是街頭範圍的「對峙」事件（開打前比氣勢，[ROADMAP](../plan/ROADMAP.md) 第 2 節；輸了的退讓或帶著懲罰開打）。
- **NPC 自己的日子**長出來的事（被捕、欠債、溺感邊緣，[NPC_SYSTEM](NPC_SYSTEM.md) 第 9 節）多半在這裡發生：那個人走過來找你，或你聽說了。
- 冠冕區的街頭幾乎沒事（機率 ×0.3）；蜂巢最多（×1.3）。

| 事件 | 在哪、條件 | 選項與檢定 | 結果 |
|---|---|---|---|
| 收租無人機追錯人 | 蜂巢，週一白天 | 修好它（機械 13）；擋在鄰居前面（威嚇 13）；不管 | 修好：鄰里 +、鄰居的親密度 +3；擋：無人機記下你，下週帳單 +C$20；不管：鄰里 − |
| 掉了通行憑證的主管 | 四十二番街上城，週五夜 | 還給他（交涉 13）；收下（隱匿 13）；拿去賣 | 還：緋櫻好感 +2、一個小人情；收：一張一次性的冠冕區憑證；賣：現金晶片 C$300、緋櫻敵對值 +3（如果被查到） |
| 警備局臨檢 | 櫻町大街，白天，隨機掃橋 | 配合；混過去（表演 16）；跑（運動 13） | 配合：照藏匿與掃描結算（[EQUIPMENT](../gear/EQUIPMENT.md) 第 6 節）；混過：沒事；跑：緋櫻敵對值 +4，可能追逐 |

| 孤星連盤查野良 | 蜂巢東側，白天 | 替野良說話（交涉 16）；幫孤星連（威嚇 13）；走開 | 孤星連與野良的好感一升一降（各 ±3） |

### 4.5 契約指令

主角是**契約人**時，持約人不同行，指令以**有期限的佇列**送達（[LEWD_SYSTEM](LEWD_SYSTEM.md) 7.2、7.4 節）。這是 ElondiaRPG 主人事件的改寫：那邊是「主人在身邊、當場回應」，這邊是「遠端送來、自己走去做」（[scan/05](../plan/scan/05-adult-home.md) 2.4 節）。

**一條指令**：

| 欄位 | 說明 |
|---|---|
| `kind` | 差事、改造、侍奉、工作、回報、出借（規矩不進佇列，是持續的狀態） |
| `from` | 持約人（固定 NPC、生成 NPC、或勢力本身——伊甸園、企業） |
| `place` | 要去的地方：一個設施或持約人的所在 |
| `deadline` | 期限：差事 24～72 小時、改造 48 小時、侍奉 4～12 小時、工作是指定的時段、回報是每週固定的一天 |
| `state` | 送達、照做中、抗拒成功、強制（抗拒失敗）、完成、逾期 |

**送達**：每天 08:00（`daily`）持約人擲一次要不要下指令：

```
機率 = 持約人的基本頻率 × 滿意的倍率
基本頻率：伊甸園 40%、幫派 30%、企業 25%、個人 15～45%（依性格）
滿意 0～29 ×1.5；30～69 ×1；70～100 ×0.6
```

指令以耳語送到（通知，不擋行動），出現在契約面板。佇列滿 3 條時持約人等你。

**照做或抗拒**：收到時選。抗拒是定力檢定：

```
DC = 12 ＋ 4（管理級）＋ ⌊馴化 ÷ 10⌋ ＋ 沉溺的懲罰（迷醉 +2、溺感邊緣 +4）− 主僕關係（夥伴、戀人 −4）
```

結果照 [LEWD_SYSTEM](LEWD_SYSTEM.md) 7.4 節：照做，滿意上升、馴化慢慢上升；抗拒成功，這一條不用做、滿意 −5；抗拒失敗，變成**強制**，有期限。

**執行**：走到 `place` 時觸發這條指令的事件（契約範圍，優先序 2）。事件的內容依持約人是誰、他的性格與傾向、主僕關係抽。

**逾期**：強制的指令過了期限，橋自己動手，依持約人抽一種：鎖一件義體 24 小時、感載一次加到上限的一半、把位置報出去（持約人那一方的敵對值 +10）。滿意 −10。

- 在委託副本裡期限暫停。
- **主角是持約人時**方向反過來：契約人會「主動找你」（`daily`、`home`），沿用 ElondiaRPG「奴隸主動找你」的事件；調教介面的「事件」頁從同一個範圍挑事件（[LEWD_SYSTEM](LEWD_SYSTEM.md) 7.5 節），手動觸發不擲機率，但同一個人一天一次。
- **陛下的誓約**（[LEWD_SYSTEM](LEWD_SYSTEM.md) 7.7 節）：誓約裡陛下有一份，每週 10% 以你的名義下一道指令給你的契約人，或替持約人下一道給你。

| 事件 | 指令 | 選項與檢定 | 結果 |
|---|---|---|---|
| 「把這個送到」 | 差事：一個封住的盒子，送到舊港某處，48 小時 | 照送；打開看（機械 16，不留痕跡）；送之前先拍下來 | 照送：滿意 +5；打開成功：知道裡面是什麼（一則情報）；失敗：滿意 −10 |
| 「去靜室裝這個」 | 改造：裝一個指定的調校（常見是指向持約人的「忠犬」） | 照裝；在診所動手腳（義體學 19，裝了但不生效）；拖延 | 照裝：調校上身，鑰匙在持約人手上；動手腳失敗：滿意 −15、規矩 +1 條 |
| 「過來」 | 侍奉：走到持約人那裡 | 照去；找理由晚到（表演 13） | 到了之後抽一件侍奉事件：依持約人的性格與主僕關係；要不要進成人場景由 `scene_gate` 判定 |
| 「今晚去上班」 | 工作：到指定的場所做幾小時（人偶館、夜店、片場） | 照做；清醒模式（藝人的技能，收入少、能偷聽） | 收入歸持約人，你拿一成；清醒模式多一則情報 |
| 「借你一天」 | 出借：另一個人一天之內有持約人的權限 | 照做；抗拒（照上面的 DC） | 那個人照自己的性格下一兩條指令；主僕關係是戀人時不會發生 |

- **篩選**：關掉「契約支配」時只剩差事、工作、回報與規矩；關掉「主角非自願」時，強制的指令只會是差事與工作，侍奉不會在抗拒失敗後發生（[LEWD_SYSTEM](LEWD_SYSTEM.md) 7.8 節）。

### 4.6 家園

據點（[FIXER](FIXER.md) 第 9 節）裡的事：**住戶**與**訪客**。規格細節見 [DOWNTIME](DOWNTIME.md) 7.10 節。

- **住戶**：同居的人（親密度 80 以上的夥伴或戀人，[NPC_SYSTEM](NPC_SYSTEM.md) 10.3 節；據點 1 級以上、有空床）、住在據點的名冊成員（據點 2 級以上）、主角持約而安排住在這裡的契約人。
- **訪客**：鄰居（蜂巢的鄰里，[DISTRICTS](../world/DISTRICTS.md) 第 3 節）、名冊上出了事的人（受傷、逃出來、借錢）、討債的人（帳單的下坡路，[FIXER](FIXER.md) 第 4 節）、找上門的勢力（敵對值 60 以上、據點被找到時街頭事件變成上門事件）、偶爾是中間人。

| 事件 | 條件 | 選項與檢定 | 結果 |
|---|---|---|---|
| 鄰居送來一碗麵 | 蜂巢，回家時，鄰里不差 | 請他進來聊（交涉 10）；收下道謝 | 聊：鄰居的親密度 +3、一則傳聞 |
| 討債的人上門 | 帳單欠了一週以上 | 付一部分；談延期（交涉 16）；嚇走（威嚇 16）；躲（隱匿 13） | 談成：寬限 3 天；嚇走：債權人那一方的敵對值 +5，下次來的人更兇；躲：他守在門口 6 小時 |
| 有人來搜 | 某勢力敵對值 60 以上，據點被找到 | 藏東西（隱匿，依藏匿量）；開門應付（表演 16）；從後面走；開打 | 失敗：違禁品被沒收；開打：戰鬥在據點裡；之後要考慮搬家 |
| 半夜的談話 | 同居的人，長休醒來前 | 陪他聊（交涉 10）；繼續睡 | 親密度 +3；可能推進他的關係線；可能進成人場景（`scene_gate`，兩情相悅） |
| 帶傷來躲的人 | 名冊上的人受傷或被捕逃出來 | 收留並治療（醫療 13）；給錢讓他走；拒絕 | 收留：忠誠 +10，追他的勢力敵對值 +3；拒絕：忠誠 −15 |

### 4.7 成人事件

成人事件是**一組有自己觸發點的範圍**，也是其他範圍裡帶 `adult` 標籤的模板的總稱：兩者用同一個比重（3.3 節）與同一套篩選（第 6 節）。

**觸發點**：

| 觸發 | 什麼時候 |
|---|---|
| 被認出來 | 走在街上，這一區的豔名 40 以上 |
| 場所 | 在人偶館、夜店、片場、感官擂台工作或消費時（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 6 節） |
| 倒在路上 | 在街上倒下（`downed`），醒來之前誰先找到你 |
| 惡意韌體 | 發作的階段到了（[CYBERWARE](../gear/CYBERWARE.md) 第 5 節） |
| 藥 | 用了催情劑或被下藥之後 |

**機制**：

- 選項通常三個：**脫身**（檢定）、**另一種應付**（別的檢定、付代價、叫人）、**接受**。只有結果帶 `adult_scene` 的才可能進場景，而且**進不進由 `scene_gate` 判定**（[LEWD_SYSTEM](LEWD_SYSTEM.md) 3.1 節）；玩家永遠可以略過成一段敘事加自動結算。
- 事件的效果只到「進場景之前」：豔名、錢、狀態、感載、餘韻。場景裡的沉溺、橋參數、傾向、性經歷由 `scene_settle` 結算。
- 標籤：非自願的標 `pc_unwilling`；NTR、人偶晶片失憶、黑帶各有自己的標籤；每個流竄 AI 的題材一個標籤；對象的性別一個標籤。
- 主角的傾向會改權重：傾向相合的模板 ×(1 ＋ 等級 × 0.2)。

| 事件 | 觸發、條件 | 性質與機制 |
|---|---|---|
| 被認出來的人 | 街上；豔名 40 以上、曝露度 2 以上 | 一個看過你的帶子的人搭話。表演 13 成功：豔名 +2、可能一筆打賞；接受邀約：交給 `scene_gate`（自願） |
| 飲料裡加了東西 | 夜店、酒吧，夜 | 定力 16 或醫療 13 察覺。沒察覺：狀態「蜜」（[LIFE](../world/LIFE.md) 第 6 節的催情劑）；之後隊友、店家或陌生人誰先到，各一個分支；標 `pc_unwilling` 的分支在篩選關掉時改成「被店家的保全帶到後門醒來，錢包少了」 |
| 倒在路邊 | `downed`，街上 | 依區抽誰先找到你：舊港是拆體客（走戰敗，不是成人事件）；四十二番街是蜜糖會、好心人、或伊甸園的回收員；成人的分支只在篩選允許時 |
| 發情蠕蟲發作 | 惡意韌體到了發作階段 | 感載不消退、之後每小時自己漲。選項：冷卻劑、找改造師（義體學對階段 DC）、忍（定力）、找一個人——最後一個交給 `scene_gate` |
| 擂台的邀約 | 四十二番街的井，豔名或耐受夠高 | 一場感官擂台（感載對感載，[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 6 節）；可以下注；輸的一方的後續交給 `scene_gate` |

### 4.8 流竄 AI 的接觸

流竄 AI 是牆外的居民（[NPCS](../world/NPCS.md) 第 8 節）。這個範圍管牠們找上主角的幾種方式：

| 方式 | 條件 | 觸發 | 形式 |
|---|---|---|---|
| **蠱惑** | 主角有某個標籤（狀態是「有」）；或沉溺超過 65，這時沒有標籤的也會來。對應的流竄 AI 沒被篩選關掉 | 在內海的時候：登入、進子網的一層、在沉船帶；另外是長休醒來的夢 | 擋住行動的事件。牠透過碎片、夢或插進來的訊號找上主角，還見不到本人 |
| **過牆之後** | 沉溺 50 以上，已經過過牆 | 在群落裡走動 | 居民的事件：對話、相處、任務線的階段 |
| **中間人的委託** | 沉溺 100 以上 | `daily` | 通知。點開是一件委託 |
| **間接** | 任何時候 | 牆語者傳話、長得像牠的粉蕾絲 | 街頭或內海的一般事件 |

- **蠱惑誰來**：有對應標籤的那幾個裡，依那一軸的等級排序；一次只來一個。
- **沉溺超過 65 之後，沒有標籤的蠱惑也會來**（已確認）：任何一個沒被篩選關掉的流竄 AI 都可能找上主角。順著牠，主角**得到那個標籤**（從「沒有」變成「有」），沉溺 +1～+2。
- **每個標籤預計有兩種蠱惑事件**。內容是 L4 的事，先記在這裡，不展開。
- **妖精的吻**的事件也在這個範圍：它是留在橋裡的一小片流竄 AI，照潛伏、發作、擴散三個階段各有事件，做法和 ElondiaRPG 的寄生物一樣（[CYBERWARE](../gear/CYBERWARE.md) 第 5 節）。
- 蠱惑的每個選項都寫明沉溺的變化：順著牠 +2～+3（沒有標籤的那種是 +1～+2，並得到標籤）、拒絕（定力檢定）成功不變而失敗 +1、問牠是誰 +1 並揭開一點牠的事。順著牠累計三次，會給一則指向粉牆的線索。
- 一天最多一件（不含通知）。主角藏著沉溺不影響蠱惑：牠們看的是真正的數值。

| 事件 | 條件 | 選項與檢定 | 結果 |
|---|---|---|---|
| 媽咪在夢裡替你蓋被子 | 有「溺愛」的標籤 | 讓牠蓋；醒過來（定力 13）；問牠是誰 | 讓牠蓋：沉溺 +2，下次長休的回復加倍；醒過來成功：沒事 |
| 耳後的一口氣 | 有「聲音」的標籤；在內海 | 聽完；捂住耳朵（定力 16） | 聽完：身邊某個人的一個秘密碎片（同讀橋，[NPC_SYSTEM](NPC_SYSTEM.md) 6.4 節）、沉溺 +2 |
| @all_eyes 給你看一段畫面 | 有「窺視」的標籤；在內海 | 看；不看 | 看：一段素材（別人藏起來的畫面）、沉溺 +2 |
| 牆語者傳的話 | 沉溺 40 以上；在地下層 | 聽；拒絕；跟去聖堂 | 聽：一則指向粉牆的線索、沉溺 +1；跟去：`move` 到聖堂前，牆語者好感 +3 |
| 陛下替你下了一道指令 | 沉溺 100 以上；主角是持約人 | 照轉；攔下（定力 19） | 照轉：契約人收到一條指令；攔下失敗：照轉，陛下的好感 −3 |

### 4.9 吉祥物的目擊

吉祥物不是勢力，沒有好感、敵對值、地盤，不能交涉（[GANGS](../world/GANGS.md) 第 3 節）。它只以**目擊**出現。

- **條件**：夜或深夜；獨自（隊上沒有人在身邊）或人很少的地方；城市的大事「假面夜」發生時機率 ×3。委託副本裡也可能出現（現場多出來的一顆氣球）。
- **基本機率**：符合條件的 `walk` 2%、`transit_stop`（末班車）5%、副本的 `stage` 1%。
- **目擊數**：程式記一個隱藏的數字，每次目擊 +1。到 3、6、10 各立一個旗標，給吉祥物的長任務線用（[STORY_QUESTS](../world/STORY_QUESTS.md)）。玩家看不到這個數字。
- 選項多半只有三種：**不回頭**、**拍下來**、**跟上去**。「看到氣球就不要回頭」是街上的說法——回頭的選項有代價。
- 真的打起來是罕見的分支：不會被誘惑，過載了也不停。

| 事件 | 在哪 | 選項與檢定 | 結果 |
|---|---|---|---|
| 末班車上的玩偶裝 | 車廂，深夜，車廂裡只剩你和牠 | 坐著不動（定力 13）；下一站下車；看牠 | 定力失敗：感載 +10、受驚；看牠：牠歪頭，目擊 +1，下車時口袋裡多一顆氣球 |
| 監視器的一格畫面 | 任何有監視器的地方；調查或快駭時 | 存下來；追查來源（介面 16） | 一段素材；追查成功：一個地點的旗標 |
| 現場多出來的氣球 | 委託副本，現實面 | 帶走；不碰 | 帶走：目擊 +1；之後這件委託的收尾多一行「現場有人看見玩偶裝」 |
| 街角揮手 | 蜂巢或櫻町的巷子，深夜 | 不回頭；揮手回去；跟上去（隱匿 16） | 揮手：目擊 +1、沉溺 +1；跟上去：失敗時倒下並醒在另一區，少了一樣東西 |
| 回來的鄰居 | 名單上一個失蹤過的人；目擊 6 以上 | 叫他的名字；跟著他；報給蜜糖會 | 叫名字：他歪頭；報給蜜糖會：蜜糖會好感 +3，懸賞的線索 |

## 5. 連鎖與收尾

- **事件只能連一層**：一件事件的結果可以直接帶出另一件（`chain`），被帶出的那件不能再帶。更長的鏈用特殊任務寫，或用旗標把幾件事件、線索、委託接起來，再歸進同一個**系列**方便整理（[SERIES](SERIES.md)；系列只管分組，不管邏輯）。
- 事件的結果寫成一份 `event` 報告（[GAME_DESIGN](../GAME_DESIGN.md) 第 9 節），共同記憶照 [NPC_SYSTEM](NPC_SYSTEM.md) 8.1 節記。
- 輿論戰的「城市事件」（[OPINION](OPINION.md) 5.3 節）是棋盤的天氣，不經過這個導演。

## 6. 內容篩選

所有範圍共用一套（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 9 節）：

| 標籤 | 關掉時 |
|---|---|
| `pc_unwilling` | 這類模板與分支不抽；有替代分支的走替代 |
| `contract_dom` | 契約指令只剩差事、工作、回報、規矩（4.5 節） |
| `ntr`、`puppet_amnesia`、`blacktape` | 對應的模板不抽 |
| `male_partner`、`female_partner` | 那個性別不當成人事件的對象 |
| `ai:<自稱>`、`tendency:<標籤>` | 那一個流竄 AI 不接觸、不發委託；那個題材不進事件 |

- 篩選關掉的只有內容；機制（感載、橋參數、敵對值）照算，因為它們同時是戰鬥與竄網的規則。
- **沒有成人內容的總開關**，所以沒有 `adult` 這個篩選標籤。`adult_scene` 只是交給成人場景模型的記號。用到某個細項題材的模板，必須能在那個細項關掉時整件不出現，或有一個不含那個題材的分支。內容編輯器會檢查。

## 7. 已確認的事項

2026-11-18 逐條過完：

1. 只有一個事件導演，十種範圍是它的十組參數（後來加了「打工」；露宿的事件算街頭）。
2. 每回合最多一件擋住行動的事件，加上兩則通知；城裡一天最多 8 件擋住型的事件，可以調。
3. 優先序只排前三個：委託副本內、契約的強制執行、上門。其餘的範圍不排順序，同時擲中就隨機抽一個。
4. 各範圍的機率照 3.3 節；每個範圍的倍率和成人事件的比重可以調。
5. 格式：條件、最多四個選項、每個選項一次檢定、四級結果，另有一個「我要做別的」交給 AI 判定。
6. 效果是封閉清單。上限只管 AI 自己生成的事件；內建的與世界編輯器做的不受限。事件給的東西不超過主角所在那一區的等級。
7. 事件只能連一層。
8. 類型平衡：六類，最近出現過的類型權重降低。
9. 契約指令：佇列最多 3 條、可以抗拒、逾期時橋自己動手；在委託副本裡期限暫停。
10. 吉祥物：用隱藏的目擊次數推進牠的長任務線，門檻是 3、6、10 次。
11. 流竄 AI 的蠱惑：一天最多一件；有標籤的順著牠沉溺 +2～+3；沉溺超過 65 之後沒有標籤的也會來，順著牠得到標籤、沉溺 +1～+2；每個標籤預計兩種蠱惑事件。
12. Agent 模式下 AI 提出的事件算街頭範圍，不擲機率、不吃範圍的冷卻，但照樣受每回合與每天的上限限制。
