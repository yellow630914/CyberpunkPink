> 來源：ElondiaRPG 的特質與缺陷（`perks`：情境修正、取得的機會、受訓、老師）；附件的入門規則裡的「生命軌跡」。預定資料：`data/rules/origins.json`、`lifepath.json`、`perks.json`。**狀態：建角的步驟、外觀、出身、起始的橋與義體、特質點與第 5 節的數字都已確認。** 還標著暫定的只有義體點數的價目（2.1 節）與起始的錢和裝備（5.4 節），它們等裝備與經濟的框架定了再對一次。 特質的實際清單屬於內容層（L4），等底層定了再生成（[DESIGN_ORDER](../plan/DESIGN_ORDER.md)）。

## 1. 建角的步驟

建角介面以**下拉選單**為主：每一步都有現成的選項可以選，也可以按「隨機」；需要時才自由輸入。

| 步 | 做什麼 | 得到什麼 |
|---|---|---|
| 1 | **基本資料**：名字、性別、稱呼、年齡（成年）、外觀、背景 | 敘事用的資料。外觀用下拉選（體型、髮、眼、膚、特徵），另有一格可以**手動輸入文字**補充外觀；背景也有一格自由輸入，寫進給 AI 的角色資料裡 |
| 2 | **出身**（第 2 節） | 一項基本功 +1、一個出身特質、起始的身分與住處、一個勢力的好感 |
| 3 | **屬性**：把 15、14、13、12、10、8 分到六項，再加 2 點自由點數（單項上限 18） | 六屬性（[CORE_RULES](CORE_RULES.md) 第 1 節） |
| 4 | **基本功**：一筆起始點數自由分配 | 十八項基本功的起始等級 |
| 5 | **生命軌跡**（第 3 節）：幾張表，可以擲、可以選、可以跳過 | 認識的人、仇人、一件還沒了結的事 |
| 6 | **橋與義體**：用一筆**起始的義體點數**自由選一座橋與其他義體（2.1 節）；橋參數的初值 | 四類技能的容量；起始的改造 |
| 7 | **特質與缺陷**（第 4 節、5.3 節）：用起始的特質點買；最多 2 個缺陷，各退 1～3 點；可以自訂 | 被動的修正 |
| 8 | **技能**：起始歷練點 200（可調），在技能樹上花 | 起手的配置（[SKILLS](SKILLS.md) 1.3 節） |
| 9 | **起始的錢與裝備**；難度與存檔規則 | — |

- 每一步都可以回頭改。最後有一頁總覽。
- **快速開始**：選一個預設角色（每個出身兩個），直接進遊戲。
- 內容篩選在建角前先設定（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 9 節）；關掉的題材不會出現在傾向與生命軌跡的選項裡。

### 1.1 外觀：現實與內海（已確認）

沿用 ElondiaRPG 的做法：外觀由**體型**、**各部位的詞條**與一段**自由描述**組成，NPC 與主角用同一套詞條。這裡每個角色有**兩份**外觀：

| | 現實的身體 | 內海的化身 |
|---|---|---|
| 組成 | 體型（陽剛、陰柔、中性）＋各部位的詞條（髮、眼、膚、胸、腰、腿、特徵……）＋自由描述 | 同一套欄位，另存一份 |
| 性別的外觀 | 建角時選；**之後可以靠義體或生技改變** | **可以自由變化** |
| 怎麼改 | 去診所：機械的做法是換外皮與義體，快、有沉溺成本；生技的做法是蜜腺的轉換療程，慢（要長合）、幾乎不加沉溺（[CRAFTING](../gear/CRAFTING.md) 第 8 節）。要錢、要時間 | 在潛艙店、據點或任何接入點改，不花錢、不花時間；也可以存好幾套切換 |
| 限制 | 改的是身體，照義體與生體件的規則；獸化改造也走這條 | 沒有身體的限制：性別、體型、獸耳、不是人形都可以。**外觀不改數值**，數值照 [CYBERSPACE](CYBERSPACE.md) 4.1 節 |
| 別人怎麼認你 | 照常 | 網內認識的人只認得化身；現實與網內是兩個身分，被認出來才合併（[NPC_SYSTEM](NPC_SYSTEM.md)） |

- 建角時先做現實的外觀，化身預設照著現實複製一份，之後隨時可以改。
- **性別**是五個選項之一（已確認）：男、女、偽娘（含男娘）、TS、扶他。它決定戰敗事件、成人事件與 NTR 分到哪些版本（[ENEMIES](ENEMIES.md) 第 6 節）。體型與部位只決定敘事怎麼寫這個身體。現實的身體改了，敘事跟著改；內海的敘事讀化身那一份。
- 蜜腺的文化分支（流動）與流竄 AI「都可以」對應的就是現實這一邊的改變；內海的自由變化是所有人都有的。
- 成人場景發生在哪一邊，就用哪一邊的外觀。

## 2. 出身

這個世界沒有種族；出身取代它。出身是「你在這座城市的哪裡長大成人」。

| 出身 | 一句話 | 基本功 +1 | 起始身分 | 起始住處（開場的地點） | 好感 25 的勢力 | 開場就在名冊上 |
|---|---|---|---|---|---|---|
| **蜂巢** | 巨型公寓裡長大的孩子，現在是大人了 | 街頭直覺 | 市民 | 蜂巢四號塔的單位 | 孤星連或野良（選一） | 小麥、雷 |
| **企業** | 社宅出身，離開了公司，或被公司離開 | 交涉 | 市民（曾是社員） | 蜂巢四號塔的單位 | 原本那家企業（十二家選一） | 潘妮、雷 |
| **車族** | 荒地上的車隊，進城討生活 | 操縱 | 無籍 | 一台能住的車，停在舊港的車廠 | 野薔薇 | 真白、雷 |
| **歡場** | 四十二番街的店裡長大、工作過 | 誘惑 | 市民 | 番街的隔間 | 蜜糖會 | 琥珀、雷 |
| **舊港** | 碼頭與黑市的人 | 隱匿 | 無籍 | 舊港的倉庫隔間 | 胭脂堂 | 奈奈、雷 |
| **櫻町** | 同人圈、女僕咖啡、劇場後台的人 | 表演 | 市民 | 櫻町的合租屋 | 特攻姬或女僕公會（選一） | 燈、雷 |
| **地下層** | 沒有登記的人，從下面上來的 | 機械 | 無籍 | 月台市的鋪位 | 野良或牆語者（選一） | 零、雷 |

- 每個出身帶一個**出身特質**（第 4 節的格式），以及建角時多幾個相關的生命軌跡選項。
- **每個出身從自己的住處開場**，名冊上已經有一位和這個出身有關的固定夥伴，另外加上雷（[NPCS](../world/NPCS.md) 第 4 節）。所以開場的內容要照出身各寫一份，這是 L4 的事。
- **企業出身是十二家選一**（已確認），選的那一家決定好感給誰、買得到哪一家的橋。**企業出身不帶債**（已確認）。
- **歡場與櫻町出身另外有固定的傾向與豔名**（已確認）：

| 出身 | 傾向 | 豔名 |
|---|---|---|
| 歡場 | 扮相那一軸從 1 級開始，風格標籤「歡場」是「有」 | 四十二番街的豔名 +10 |
| 櫻町 | 扮相那一軸從 1 級開始，風格標籤「櫻町系」是「有」 | 櫻町的豔名 +5 |

- 出身影響開場在哪裡、名冊上先有誰、第一個中間人是誰、一些 NPC 怎麼看你。它不限制之後的發展。
- 玻璃岸與鏽帶沒有出身：前者不會淪落到當邊緣行者（落魄的有錢人用「企業」出身），後者算在車族。

### 2.1 起始的橋與義體（已確認）

**自由選，但有點數限制。** 建角時有一筆**起始的義體點數**（暫定 10 點），用來買橋與其他義體：

| 東西 | 點數（暫定） |
|---|---|
| 入門的橋（I 級） | 2～3 |
| 好一點的橋（II 級） | 5～6 |
| 一件輕度義體（義眼、義耳、獸耳、聲帶……） | 1～2 |
| 一件侵入式義體（義臂、義腿、皮下裝甲……） | 3～4 |
| 沒花完的點數 | 換成起始的錢 |

- 所以可以選「好橋、身體沒改」或「普通的橋、多幾件義體」。
- 每一件照常算沉溺的下限（[CYBERWARE](../gear/CYBERWARE.md)）：開場改得越多，沉溺的起點越高。
- 出身不限制選擇，只影響有些型號買不買得到（企業出身才選得到那家企業的橋）。
- 實際的型號與點數等裝備的框架定了再寫（[DESIGN_ORDER](../plan/DESIGN_ORDER.md)）。

## 3. 生命軌跡

借自桌上角色扮演的做法：建角時用幾張表交代這個人的過去。**每一張都可以擲、可以選、可以跳過。** 結果不是文字設定而已——它們會變成遊戲裡的東西。

| 表 | 選項的樣子 | 變成什麼 |
|---|---|---|
| **家人** | 還在、失散、過世、是某個勢力的人 | 一位生成的 NPC（或沒有）；可能是一條生活系列的開頭 |
| **那件事**（變故） | 欠了一筆債、被公司開除、替人頂罪、橋出過事、有人失蹤 | 一個起始的狀態：債、敵對值、一個缺陷、或沉溺的下限 +5；附一則線索 |
| **朋友** | 一起長大的、救過你的、一起做過一票的 | 一位**名冊上的人**（[FIXER](FIXER.md) 第 6 節），親密度起始較高 |
| **仇人** | 被你害過的、害過你的、搶同一個位置的 | 一位帶著**敵對值**的 NPC，或某個勢力的敵對值 +15 |
| **舊情** | 分了、被拆散、對方不見了、還有聯絡 | 一位 NPC 與一段關係記憶；可能是一條系列的開頭 |
| **想要的** | 錢、名、一個人、真相、離開這座城、被記住 | 一個**個人目標**：達成階段時多一份歷練點 |
| **性經歷** | 沒有、很少、普通、豐富；是和誰、在什麼情況下（選項受內容篩選控制） | 性經歷記錄的起始值（[LEWD_SYSTEM](LEWD_SYSTEM.md)）；橋參數的初值微調；可能連到「舊情」那位 NPC |
| **潛在性癖** | 從傾向標籤裡選或擲一到兩個（[LEWD_SYSTEM](LEWD_SYSTEM.md) 1.1 節） | 選的標籤直接是「有」；標成「潛在」的還沒被本人察覺，第一次碰到時才揭開，那一軸多長一點（標籤只有沒有、有、深三種狀態，等級在四條軸上） |

- 擲出來的人照 [NPC_SYSTEM](NPC_SYSTEM.md) 的規則生成（名字由程式產生），所屬的勢力與出身有關。
- 「朋友」與「仇人」各最多一位，避免開場就有一長串名字。
- 遊戲沒有成人內容的總開關，只有細項的篩選。**性經歷**與**潛在性癖**兩張表的每個選項照內容篩選過濾；一張表的選項全部被濾掉時，那張表不出現。所有相關的人物都是成年人。
- 生命軌跡給的線索與系列都是**模板**生成的（[SERIES](SERIES.md) 第 3 節的生活系列），不是人工寫的主線。
- AI 開著時，可以請 AI 把這幾張表的結果寫成一段背景（只寫文字，不改結果）。

## 4. 特質與缺陷

沿用 ElondiaRPG 的做法，改掉和等級、職業、種族有關的部分。

### 4.1 特質是什麼

- **被動**，一直生效。**不佔橋的容量**：特質是人的一部分，不是裝進橋裡的模組。這是它和技能最大的差別。
- 效果只有幾種：
  - 某一類檢定的加值（照基本功或情境分：交涉、誘惑、威嚇、隱匿、調查……）；
  - 對某一類對象的加值（對某個勢力的人、對某種出身的人）；
  - 某一條軌的修正（感載上限、沉溺的下限或上升速度、回復）；
  - 某個場合的修正（踩點、打工、交易、成人場景）；
  - 戰鬥的修正（命中、迴避、先攻……）。這一類的數字寫在 5.2 節。
- 強度有預算：一個特質大約等於「一類檢定 +2」。

### 4.2 分類

| 分類 | 例子（只是樣子，清單之後生成） |
|---|---|
| 街頭 | 人面廣、嗅得到麻煩、黑市熟客 |
| 社交 | 能言善道、看起來可靠、撒謊不眨眼 |
| 身體 | 耐打、手穩、酒量好 |
| 橋與神經 | 天生耐受高、同步體質、對蕾絲遲鈍 |
| 技藝 | 巧手、機械直覺、刀法 |
| 網路 | 舊網的孩子、記得住密碼、不留痕跡 |
| 媒體 | 上鏡、筆快、聲音好聽 |
| 慾望 | 和傾向、橋參數有關的體質（[LEWD_SYSTEM](LEWD_SYSTEM.md)）；受內容篩選控制 |
| 出身 | 每個出身一個，只能在建角時拿到 |

### 4.3 缺陷

- 缺陷是**只有壞處**的特質，強度大約抵銷一個一般特質。
- 建角時最多選 2 個。每個缺陷照它有多礙事退 1～3 點特質點，退回來的點數可以拿去買特質（5.3 節）。
- 之後只會從事件與特殊任務**染上**（例如重創之後的舊傷、藥的後遺症），自由行動的大失敗不會給永久的缺陷。
- 可以**克服**：在對應的設施受訓，或某些任務的結果。
- 例子的樣子：怕痛、口無遮攔、舊傷、貪杯、認床、對某種蕾絲特別沒抵抗力、欠著人情。

### 4.4 之後怎麼取得

特質不直接塞給角色，而是給一次**機會**：從幾個裡選一個學，或放棄。

| 來源 | 機會 |
|---|---|
| **街頭信譽升一階** | 三選一。取代 ElondiaRPG 的「升級時三選一」 |
| 事件與特殊任務 | 照寫；可以指定特質，也可以給選項 |
| 受訓 | 在對應的設施花錢與時間、過一次檢定（診所、道場、潛艙店、人偶館、轉播站……） |
| 老師 | 固定 NPC 會教他的特質：親密度夠，學費打折 |
| 書與帶子 | 讀完或看完給一次機會 |
| 向 AI 爭取（Agent 或 AI 判定開著時） | 寫一段說法；AI 依角色的經歷判斷合不合理，設計一個特質，程式夾在強度預算內 |

- 特質的總數上限是 8 個，不含出身特質與缺陷；滿了要先放掉一個（5.3 節）。
- **夥伴與 NPC 用同一套**：生成時用 2～6 點的特質點抽特質與缺陷（5.3 節）；夥伴也能經由事件與受訓得到。

## 5. 建角的數字與特質的細則（已確認）

已確認的：出身七個；生命軌跡加上性經歷與潛在性癖兩張表；起始的橋與義體自由選、有點數限制；起始歷練點 200；起始基本功 10 點、單項最高 3 級（[CORE_RULES](CORE_RULES.md) 第 7 節）。下面各小節是這些數字與特質的細則，同樣已確認；還是暫定的數字會在該處註明。

### 5.1 屬性

- 建角時把 15、14、13、12、10、8 分到六項，再加 2 點自由點數，單項最高 18。調整值是（屬性 − 10）÷ 2，無條件捨去。
- **屬性不能用歷練點升。** 之後要提高只有三條路：義體（裝著才算）、藥（暫時）、少數特殊任務的獎勵（永久，一項最多 +2）。
- 理由：屬性牽動的東西太多（行動點上限、感載上限、RAM 上限），讓它能用點數堆，戰鬥的基準就守不住。成長放在基本功與技能上。

### 5.2 特質的強度

一個特質的預算是「一類檢定 +2」。換成別的效果時，照下面的對照，一個特質只能拿其中一格：

| 效果 | 一個特質的份量 |
|---|---|
| 一項基本功的檢定 | +2 |
| 對某一類對象（一個勢力、一種出身）的所有社交檢定 | +2 |
| 現實或內海的命中 | +1 |
| 迴避 | +1 |
| 先攻 | +3 |
| 感載上限 | +4 |
| 生命值上限 | +5 |
| RAM 上限 | +1 |
| 沉溺每次上升的量 | −1（最少 1） |
| 某個場合的收入（打工、交易、打賞） | +15% |
| 輿論戰 | 每場的第一回合多 1 點編輯點 |

- **特質不給行動點、不給每回合的編輯點或 RAM 回復。** 這三樣是每個戰場的節奏，只由屬性、招牌能力與裝備決定。
- 缺陷是同一張表的反面：一個缺陷是其中一格的負值。

### 5.3 特質點

特質與缺陷用**點數**買賣，免得有人拿幾乎沒有壞處的缺陷去換很強的特質。

| 項目 | 規則 |
|---|---|
| 每個特質的價錢 | 1～3 點，照強度：5.2 節的一格是 2 點；比一格弱的（條件很窄、很少用到）1 點；比一格強的（兩格的效果，或很常用到）3 點 |
| 每個缺陷退的點數 | 1～3 點，照它真的有多礙事。很少碰到的缺陷只退 1 點 |
| 建角時的特質點 | 4 點（遊戲設定可以調），另外送出身特質 1 個 |
| 建角時的缺陷 | 最多 2 個 |
| 特質總數的上限 | 8 個，不含出身特質與缺陷；開場就適用。滿了要先放掉一個 |
| 街頭信譽升一階 | 給一次三選一的機會，不花點數。信譽有六階，所以整場遊戲有五次 |
| 夥伴與生成的 NPC | 生成時用 2～6 點的特質點抽 |

**自訂特質**

玩家可以自己寫特質與缺陷：

- 寫一個名字和一段說明，再從 5.2 節的表裡選它的效果。價錢照選的效果算，和現成的特質同一套。
- AI 開著時，可以只寫說明，由 AI 依說明從 5.2 節的表裡挑效果、定價錢；程式檢查它沒有超出表的範圍。玩家看過價錢之後才決定要不要買。
- 自訂的缺陷退多少點由程式照效果算，不由玩家填。

### 5.4 起始的義體、錢與裝備

- **起始的義體點數 10 點**，價目照 2.1 節。沒花完的點數每點換 C$500。
- **起始的錢**：C$3,000，出身會加減（企業出身多、街頭出身少）。這個數字的意思是「兩週的生活開銷，加上一件入門的裝備」，等經濟的框架定了再對一次。
- **起始的裝備**依出身給一包：一把入門的武器、一件輕護甲、一個接入用的小東西。內容等裝備的框架定了再寫。

### 5.5 生命軌跡的結果

八張表的內容是 L4 的事，這裡只定**結果的格式**。每一條軌跡的結果只能是下面幾種，程式才處理得了：

| 結果 | 例 |
|---|---|
| 一個有關係的 NPC | 一個朋友、一個仇人、一個舊情人；生成後進名單 |
| 一個勢力的好感或敵對值 | 好感 +15，或敵對值 +15 |
| 一筆錢或一筆債 | 起始多 C$1,000，或欠某個中間人 C$2,000 |
| 一個旗標 | 掛在某個系列上，之後有事件會來找你 |
| 一個起始的狀態 | 一個缺陷，或沉溺的下限 +5（「那件事」那張表） |
| 一個個人目標 | 「想要的」那張表選的目標；達成階段時給歷練點（[CORE_RULES](CORE_RULES.md) 7.1 節） |
| 性經歷記錄與橋參數的初值（只有性經歷那張表） | 性經歷記錄的起始值；橋參數的初值微調 |
| 傾向與標籤（只有性經歷與潛在性癖兩張表） | 某一軸 +1 級；一個標籤變成「有」 |

- **潛在性癖**在建角時只記下來，不生效。它第一次在遊戲裡被揭開時，那個標籤從「沒有」變成「有」，對應的那一軸 +1 級。

### 5.6 放進遊戲設定的數字

這些數字開新遊戲時可以調，和難度放在同一頁：

| 設定 | 預設 |
|---|---|
| 起始歷練點 | 200 |
| 歷練倍率 | 1（0.5～2） |
| 起始基本功的點數 | 10 |
| 起始基本功的單項上限 | 3 |
| 起始特質點 | 4 |
| 起始義體點數 | 10 |
| 起始的錢 | C$3,000 |

### 5.7 快速開始

每個出身準備兩個預設角色，一個偏戰鬥、一個偏非戰鬥，共十四個。內容是 L4 的事。
