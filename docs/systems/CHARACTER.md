# 建角、出身、特質與缺陷

> 上層：[CORE_RULES](CORE_RULES.md)。依賴：[CORE_RULES](CORE_RULES.md)（屬性、基本功、三條軌、路數）、[LIFE](../world/LIFE.md)（身分、錢）、[CYBERWARE](../gear/CYBERWARE.md) 第 7 節（橋的型號）、[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 1 節（橋參數、傾向）、[FACTIONS](../world/FACTIONS.md)（好感）、[SERIES](SERIES.md)（線索與系列）。被依賴：[NPC_SYSTEM](NPC_SYSTEM.md)（NPC 用同一套特質）、[UI](../art/UI.md)（建角畫面）。
> 來源：ElondiaRPG 的特質與缺陷（`perks`：情境修正、取得的機會、受訓、老師）；附件的入門規則裡的「生命軌跡」。預定資料：`data/rules/origins.json`、`lifepath.json`、`perks.json`。**這是 L1 的草稿，還沒過。** 特質的實際清單屬於內容層（L4），等底層定了再生成（[DESIGN_ORDER](../plan/DESIGN_ORDER.md)）。

## 1. 建角的步驟

建角介面以**下拉選單**為主：每一步都有現成的選項可以選，也可以按「隨機」；需要時才自由輸入。

| 步 | 做什麼 | 得到什麼 |
|---|---|---|
| 1 | **基本資料**：名字、性別、稱呼、年齡（成年）、外觀 | 敘事用的資料。外觀分成幾個下拉（體型、髮、眼、膚、特徵），另有一格自由描述 |
| 2 | **出身**（第 2 節） | 一項基本功 +1、一個出身特質、起始的身分與住處、一個勢力的好感 |
| 3 | **屬性**：把 15、14、13、12、10、8 分到六項，再加 2 點自由點數（單項上限 18） | 六屬性（[CORE_RULES](CORE_RULES.md) 第 1 節） |
| 4 | **基本功**：一筆起始點數自由分配 | 十八項基本功的起始等級 |
| 5 | **生命軌跡**（第 3 節）：幾張表，可以擲、可以選、可以跳過 | 認識的人、仇人、一件還沒了結的事 |
| 6 | **橋與義體**：用一筆**起始的義體點數**自由選一座橋與其他義體（2.1 節）；橋參數的初值 | 四類技能的容量；起始的改造 |
| 7 | **特質與缺陷**（第 4 節）：2 個特質；最多 2 個缺陷，每個多換 1 個特質 | 被動的修正 |
| 8 | **技能**：起始歷練點 200（可調），在技能樹上花 | 起手的配置（[SKILLS](SKILLS.md) 1.3 節） |
| 9 | **起始的錢與裝備**；難度與存檔規則 | — |

- 每一步都可以回頭改。最後有一頁總覽。
- **快速開始**：選一個預設角色（每個出身兩個），直接進遊戲。
- 內容篩選在建角前先設定（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 9 節）；關掉的題材不會出現在傾向與生命軌跡的選項裡。

### 1.1 外觀：現實與內海（已確認）

沿用 ElondiaRPG 的做法：外觀由**體型**、**各部位的詞條**與一段**自由描述**組成，NPC 與主角用同一套詞條。這裡每個角色有**兩份**外觀：

| | 現實的身體 | 內海的化身 |
|---|---|---|
| 組成 | 體型（陽剛、陰柔、中性）＋各部位的詞條（髮、眼、膚、胸、腰、腿、特徵……）＋自由描述 | 同一套欄位，另存一份 |
| 性別的外觀 | 建角時選；**之後可以靠義體或生技改變** | **可以自由變化** |
| 怎麼改 | 去診所：機械的做法是換外皮與義體，快、有沉溺成本；生技的做法是蜜腺的轉換療程，慢（要長合）、幾乎不加沉溺（[CRAFTING](../gear/CRAFTING.md) 第 8 節）。要錢、要時間 | 在潛艙店、據點或任何接入點改，不花錢、不花時間；也可以存好幾套切換 |
| 限制 | 改的是身體，照義體與生體件的規則；獸化改造也走這條 | 沒有身體的限制：性別、體型、獸耳、不是人形都可以。**外觀不改數值**，數值照 [CYBERSPACE](CYBERSPACE.md) 4.1 節 |
| 別人怎麼認你 | 照常 | 網內認識的人只認得化身；現實與網內是兩個身分，被認出來才合併（[NPC_SYSTEM](NPC_SYSTEM.md)） |

- 建角時先做現實的外觀，化身預設照著現實複製一份，之後隨時可以改。
- 「性別」欄仍是玩家填的文字（下拉為主）；體型與部位決定敘事怎麼寫這個身體。現實的身體改了，敘事跟著改；內海的敘事讀化身那一份。
- 蜜腺的文化分支（流動）與流竄 AI「都可以」對應的就是現實這一邊的改變；內海的自由變化是所有人都有的。
- 成人場景發生在哪一邊，就用哪一邊的外觀。

## 2. 出身

這個世界沒有種族；出身取代它。出身是「你在這座城市的哪裡長大成人」。

| 出身 | 一句話 | 基本功 +1 | 起始身分 | 起始住處 | 好感 25 的勢力 |
|---|---|---|---|---|---|
| **蜂巢** | 巨型公寓裡長大的孩子，現在是大人了 | 街頭直覺 | 市民 | 蜂巢的單位 | 孤星連或野良（選一） |
| **企業** | 社宅出身，離開了公司，或被公司離開 | 交涉 | 市民（曾是社員） | 蜂巢的單位（欠著一筆「離職費」） | 原本那家企業（選一） |
| **車族** | 荒地上的車隊，進城討生活 | 操縱 | 無籍 | 一台能住的車 | 野薔薇 |
| **歡場** | 四十二番街的店裡長大、工作過 | 誘惑 | 市民 | 番街的隔間 | 蜜糖會 |
| **舊港** | 碼頭與黑市的人 | 隱匿 | 無籍 | 舊港的倉庫隔間 | 胭脂堂 |
| **櫻町** | 同人圈、女僕咖啡、劇場後台的人 | 表演 | 市民 | 櫻町的合租屋 | 特攻姬或女僕公會（選一） |
| **地下層** | 沒有登記的人，從下面上來的 | 機械 | 無籍 | 月台市的鋪位 | 野良或牆語者（選一） |

- 每個出身帶一個**出身特質**（第 4 節的格式），以及建角時多幾個相關的生命軌跡選項。
- 出身影響開場在哪裡、第一個中間人是誰、一些 NPC 怎麼看你。它不限制之後的發展。
- 原本的五個出身加了櫻町與地下層。玻璃岸與鏽帶沒有出身：前者不會淪落到當邊緣行者（落魄的有錢人用「企業」出身），後者算在車族。

### 2.1 起始的橋與義體（已確認）

**自由選，但有點數限制。** 建角時有一筆**起始的義體點數**（暫定 10 點），用來買橋與其他義體：

| 東西 | 點數（暫定） |
|---|---|
| 入門的橋（I 級） | 2～3 |
| 好一點的橋（II 級） | 5～6 |
| 一件輕度義體（義眼、義耳、獸耳、聲帶……） | 1～2 |
| 一件侵入式義體（義臂、義腿、皮下裝甲……） | 3～4 |
| 沒花完的點數 | 換成起始的錢 |

- 所以可以選「好橋、身體沒改」或「普通的橋、多幾件義體」。
- 每一件照常算沉溺的下限（[CYBERWARE](../gear/CYBERWARE.md)）：開場改得越多，沉溺的起點越高。
- 出身不限制選擇，只影響有些型號買不買得到（企業出身才選得到那家企業的橋）。
- 實際的型號與點數等裝備的框架定了再寫（[DESIGN_ORDER](../plan/DESIGN_ORDER.md)）。

## 3. 生命軌跡

借自桌上角色扮演的做法：建角時用幾張表交代這個人的過去。**每一張都可以擲、可以選、可以跳過。** 結果不是文字設定而已——它們會變成遊戲裡的東西。

| 表 | 選項的樣子 | 變成什麼 |
|---|---|---|
| **家人** | 還在、失散、過世、是某個勢力的人 | 一位生成的 NPC（或沒有）；可能是一條生活系列的開頭 |
| **那件事**（變故） | 欠了一筆債、被公司開除、替人頂罪、橋出過事、有人失蹤 | 一個起始的狀態：債、熱度、一個缺陷、或沉溺的下限 +5；附一則線索 |
| **朋友** | 一起長大的、救過你的、一起做過一票的 | 一位**名冊上的人**（[FIXER](FIXER.md) 第 6 節），親密度起始較高 |
| **仇人** | 被你害過的、害過你的、搶同一個位置的 | 一位帶著**熱度**的 NPC，或某個勢力的熱度 +15 |
| **舊情** | 分了、被拆散、對方不見了、還有聯絡 | 一位 NPC 與一段關係記憶；可能是一條系列的開頭 |
| **想要的** | 錢、名、一個人、真相、離開這座城、被記住 | 一個**個人目標**：達成階段時多一份歷練點 |
| **性經歷** | 沒有、很少、普通、豐富；是和誰、在什麼情況下（選項受內容篩選控制） | 性經歷記錄的起始值（[LEWD_SYSTEM](LEWD_SYSTEM.md)）；橋參數的初值微調；可能連到「舊情」那位 NPC |
| **潛在性癖** | 從傾向標籤裡選或擲一到兩個（[LEWD_SYSTEM](LEWD_SYSTEM.md) 1.1 節） | 選的標籤直接是「有」；標成「潛在」的還沒被本人察覺，第一次碰到時才揭開，那一軸多長一點（標籤只有沒有、有、深三種狀態，等級在四條軸上） |

- 擲出來的人照 [NPC_SYSTEM](NPC_SYSTEM.md) 的規則生成（名字由程式產生），所屬的勢力與出身有關。
- 「朋友」與「仇人」各最多一位，避免開場就有一長串名字。
- **性經歷**與**潛在性癖**兩張表只在成人內容開著時出現；每個選項照內容篩選過濾。所有相關的人物都是成年人。
- 生命軌跡給的線索與系列都是**模板**生成的（[SERIES](SERIES.md) 第 3 節的生活系列），不是人工寫的主線。
- AI 開著時，可以請 AI 把這幾張表的結果寫成一段背景（只寫文字，不改結果）。

## 4. 特質與缺陷

沿用 ElondiaRPG 的做法，改掉和等級、職業、種族有關的部分。

### 4.1 特質是什麼

- **被動**，一直生效。**不佔橋的容量**：特質是人的一部分，不是裝進橋裡的模組。這是它和技能最大的差別。
- 效果只有幾種：
  - 某一類檢定的加值（照基本功或情境分：交涉、誘惑、威嚇、隱匿、調查……）；
  - 對某一類對象的加值（對某個勢力的人、對某種出身的人）；
  - 某一條軌的修正（感載上限、沉溺的下限或上升速度、回復）；
  - 某個場合的修正（踩點、打工、交易、成人場景）；
  - 戰鬥的修正（命中、迴避、先攻……）——**這一類等核心戰鬥定了才寫數字**。
- 強度有預算：一個特質大約等於「一類檢定 +2」。

### 4.2 分類

| 分類 | 例子（只是樣子，清單之後生成） |
|---|---|
| 街頭 | 人面廣、嗅得到麻煩、黑市熟客 |
| 社交 | 能言善道、看起來可靠、撒謊不眨眼 |
| 身體 | 耐打、手穩、酒量好 |
| 橋與神經 | 天生耐受高、同步體質、對蕾絲遲鈍 |
| 技藝 | 巧手、機械直覺、刀法 |
| 網路 | 舊網的孩子、記得住密碼、不留痕跡 |
| 媒體 | 上鏡、筆快、聲音好聽 |
| 慾望 | 和傾向、橋參數有關的體質（[LEWD_SYSTEM](LEWD_SYSTEM.md)）；受內容篩選控制 |
| 出身 | 每個出身一個，只能在建角時拿到 |

### 4.3 缺陷

- 缺陷是**只有壞處**的特質，強度大約抵銷一個一般特質。
- 建角時最多選 2 個，每個多換 1 個特質的名額。
- 之後只會從事件與特殊任務**染上**（例如重創之後的舊傷、藥的後遺症），自由行動的大失敗不會給永久的缺陷。
- 可以**克服**：在對應的設施受訓，或某些任務的結果。
- 例子的樣子：怕痛、口無遮攔、舊傷、貪杯、認床、對某種蕾絲特別沒抵抗力、欠著人情。

### 4.4 之後怎麼取得

特質不直接塞給角色，而是給一次**機會**：從幾個裡選一個學，或放棄。

| 來源 | 機會 |
|---|---|
| **街頭信譽升一階** | 三選一。取代 ElondiaRPG 的「升級時三選一」 |
| 事件與特殊任務 | 照寫；可以指定特質，也可以給選項 |
| 受訓 | 在對應的設施花錢與時間、過一次檢定（診所、道場、潛艙店、人偶館、轉播站……） |
| 老師 | 固定 NPC 會教他的特質：親密度夠，學費打折 |
| 書與帶子 | 讀完或看完給一次機會 |
| 向 AI 爭取（Agent 或 AI 判定開著時） | 寫一段說法；AI 依角色的經歷判斷合不合理，設計一個特質，程式夾在強度預算內 |

- 特質的總數有上限（暫定 8 個，不含出身特質與缺陷），滿了要先放掉一個。
- **夥伴與 NPC 用同一套**：生成時抽一到三個特質、可能一個缺陷；夥伴也能經由事件與受訓得到。

## 5. 待確認

已確認（2026-11-16）：出身七個；生命軌跡加上性經歷與潛在性癖兩張表；起始的橋與義體自由選、有點數限制。

還沒定的：

1. 生命軌跡原本的六張表（家人、那件事、朋友、仇人、舊情、想要的）內容與結果。
2. 特質不佔橋的容量，建角 2 個，缺陷最多 2 個、每個換 1 個特質。
3. 街頭信譽升階時給一次特質的機會，取代升級。
4. 特質總數上限 8。
5. 起始的義體點數（暫定 10）與各項的價目。
6. 「潛在性癖」第一次揭開時多長多少。
7. 基本功的起始點數（名單已定，數字還沒有）。
8. 快速開始的預設角色：每個出身兩個。
