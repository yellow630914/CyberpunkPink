# 工藝：底材與零件

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[CYBERWARE](CYBERWARE.md)（部位、人性成本、授權鎖、橋的型號）、[CORE_RULES](CORE_RULES.md) 6.4 節（技能容量）、[LIFE](LIFE.md) 第 3～5 節（合法性、牌子）、[COMBAT_SYSTEM](COMBAT_SYSTEM.md)（武器與護甲的數值）、[CULTURE](CULTURE.md) 第 2 節（獸化改造）。被依賴：之後的 `ITEMS`（底材與零件的目錄）。
> 來源：ElondiaRPG 的裝備「底材 × 材料」與工藝、委託打造、自創配方（[plan/MIGRATION](plan/MIGRATION.md) H、I 組）。預定資料：`data/rules/bases.json`（底材）、`parts.json`（零件）、`brands.json`。數值都是初稿。

在一座企業把專利看得比人命重的城市，沒有人用廢鐵「搓」出一條義臂或一把槍。這裡的工藝不是製造，是**組裝**：**義體、武器、護甲**都由一個**底材**與幾個**零件**構成，零件是買來的、拆來的、訂做的、偷來的——或者養出來的。玩家做的事是挑零件、配零件、把它們裝進底材。

## 1. 三層：底材、零件、成品

```
底材（殼與規格：這是什麼東西、有哪幾個槽、能裝到幾級的零件）
  ＋ 零件 × 數個（每個槽一個）
  ＝ 成品（一件能用的義體、武器或護甲；數值是底材與零件合起來的）
```

沿用 ElondiaRPG「底材 × 材料」的組合式設計，換了軸：材料只有一個，零件有好幾個槽。目錄不用寫幾千件成品——寫幾十個底材與幾百個零件，組合自己會長出來。

**一套系統管三種裝備。** 同一顆晶片可以裝進橋、裝進義眼、裝進一把智慧手槍；同一層外皮可以包在義臂上，也可以是一件外套的面料。零件是全遊戲共通的貨。

## 2. 零件

每個零件有四個身分：**類型、材質、牌子、等級**，再加一到三條**屬性**（第 5 節）與一個狀態（全新、二手、同人）。

### 2.1 類型

十二種。八種通用，四種專用。

| 零件 | 管什麼 | 主要影響 | 用在 |
|---|---|---|---|
| **晶片** | 運算 | 容量、功能的階數；武器上是智慧功能 | 義體、智慧武器、智慧護甲 |
| **機械神經元** | 和神經的接合 | 同步上限、感載的修正、**人性成本**；武器上是神經連結 | 義體、連橋武器 |
| **軟體**（韌體） | 行為 | 功能怎麼分配；授權鎖與後門；槍靈的人格 | 義體、智慧武器 |
| **板材** | 結構 | 護甲值、耐久、重量 | 義體、武器的框體、護甲的插板 |
| **致動器**（人工肌肉） | 出力 | 力量、速度；武器上是後座力補償 | 義體、動力護甲、重武器 |
| **感測器** | 感知 | 感知的範圍與精度；武器上是瞄具 | 義體、武器、護甲 |
| **電源** | 能量 | 續航、超頻的時間、每場的次數 | 義體、能量武器、動力護甲 |
| **外皮**（外裝、面料） | 外觀 | 風格、社交與媒體的加成、防不防掃描 | 義體、服裝、武器的塗裝 |
| **槍管** | 彈道 | 傷害骰、射程、穿甲、準度 | 槍械 |
| **機構** | 擊發與供彈 | 射速（能不能連射）、彈匣量、可靠度 | 槍械 |
| **刃** | 切割與貫穿 | 近戰的傷害與穿甲 | 近戰武器、內藏武器 |
| **纖維** | 織物 | 軟甲的護甲值、重量、活動度 | 服裝與護甲 |

### 2.2 材質：機械與生體

每個零件是**機械**的，或是**生體**的。這是零件的一個屬性，不是另一套系統——同一個槽，可以裝機械件，也可以裝生體件。生體的規則在第 8 節。

| 類型 | 機械件 | 對應的生體件 |
|---|---|---|
| 晶片 | 晶片 | 神經節（培養的神經團） |
| 機械神經元 | 機械神經元 | 活體神經 |
| 軟體 | 韌體 | 基因譜（寫在細胞裡的行為：貓的、狐的、兔的……） |
| 板材 | 合金、陶瓷 | 骨、甲殼 |
| 致動器 | 人工肌肉 | 培養肌 |
| 感測器 | 感測陣列 | 感官（真的耳蝸、真的鬍鬚、真的鼻子） |
| 電源 | 電池 | 代謝腺（吃糖就有電） |
| 外皮 | 合成皮、塗層、布料 | 活皮、毛皮 |
| 槍管、機構 | 金屬 | 沒有生體版 |
| 刃 | 鋼、單分子刃 | 爪、牙、骨刺 |
| 纖維 | 防彈纖維 | 蛛絲織物（活的，會自己補） |

### 2.3 等級與狀態

見第 4 節。

## 3. 底材

底材是一件裝備的殼與規格。每個底材寫明它**一定要哪些零件**、**可以加哪些零件**。底材自己也有牌子、等級與材質。

### 3.1 義體

| 底材 | 部位 | 必要的零件 | 選配 |
|---|---|---|---|
| **邊緣橋** | 橋 | 晶片 ＋ 機械神經元 ＋ 軟體 | 外皮（後頸蓋） |
| 甲板 | 腦 | 晶片 ×2 ＋ 軟體 ＋ 電源 | — |
| 反射加速器 | 腦 | 晶片 ＋ 機械神經元 ×2 ＋ 電源 | — |
| 記憶庫 | 腦 | 晶片 ＋ 軟體 | — |
| 人格面具槽 | 腦 | 晶片 ＋ 機械神經元 ＋ 軟體 | — |
| 義眼 | 眼 | 感測器 ＋ 晶片 ＋ 軟體 | 外皮（虹膜） |
| 義耳、**獸耳** | 耳 | 感測器 ＋ 機械神經元 ＋ 外皮 | 致動器（會動）；軟體（決定是哪一系） |
| 聲帶 | 喉 | 致動器 ＋ 軟體 | — |
| 皮下裝甲 | 軀幹 | 板材 ×2 ＋ 機械神經元 | — |
| 藥泵 | 軀幹 | 致動器 ＋ 軟體 | 電源 |
| 合成臟器 | 軀幹 | 致動器 ＋ 電源 ＋ 機械神經元 | — |
| 觸覺皮膚 | 皮膚 | 外皮 ＋ 機械神經元 ＋ 感測器 | — |
| 光學迷彩 | 皮膚 | 外皮 ＋ 晶片 ＋ 電源 | — |
| 義臂 | 臂 | 板材 ＋ 致動器 ＋ 機械神經元 | 外皮；內藏槽（刃、工具、駭入接頭） |
| 義腿 | 腿 | 板材 ＋ 致動器 ＋ 機械神經元 | 外皮；電源（跳躍增壓） |
| **尾** | 軀幹／腿 | 致動器 ＋ 機械神經元 ＋ 外皮 | 感測器；軟體（哪一系） |
| **爪** | 臂（內藏） | 刃 ＋ 致動器 | — |
| 私密部位 | 私密 | 機械神經元 ＋ 感測器 ＋ 外皮 | 致動器；藏匿艙 |

- 橋一定是**晶片＋機械神經元＋軟體**：它是純粹的介面，沒有結構也沒有出力。
- 表裡的「機械神經元」「軟體」是槽的名字；槽裡可以裝生體的對應件（活體神經、基因譜）。

### 3.2 武器

| 底材 | 必要的零件 | 選配 | 備註 |
|---|---|---|---|
| 手槍 | 槍管 ＋ 機構 ＋ 板材（握把框） | 感測器（瞄具）；外皮（塗裝）；智慧套件 | 智慧套件＝晶片＋軟體 |
| 衝鋒槍 | 槍管 ＋ 機構 ＋ 板材 | 同上；致動器（後座力補償） | |
| 霰彈槍 | 槍管 ＋ 機構 ＋ 板材 | 同上 | |
| 步槍 | 槍管 ＋ 機構 ＋ 板材 | 感測器；致動器；智慧套件；神經連結 | 神經連結＝機械神經元 |
| 狙擊槍 | 槍管 ＋ 機構 ＋ 板材 ＋ **感測器** | 致動器；智慧套件；神經連結 | 瞄具是必要的 |
| 重武器 | 槍管 ＋ 機構 ＋ 板材 ×2 ＋ 致動器 | 電源；感測器 | 沒有致動器扛不動 |
| 能量武器 | 槍管 ＋ **電源** ＋ 晶片 ＋ 板材 | 感測器 | 沒有機構：沒有子彈 |
| 感官彈槍 | 槍管 ＋ 機構 ＋ **晶片** | 感測器 | 神經武器。晶片決定打出去的是什麼感覺 |
| 電擊器、電擊鞭 | **電源** ＋ 晶片 ＋ 板材 | 致動器 | 神經武器 |
| 刀、劍 | 刃 ＋ 板材（柄） | 外皮；電源（單分子刃要通電） | |
| 鈍器 | 板材 ×2 | 致動器；電源 | |
| 無人機 | 晶片 ＋ 軟體 ＋ 致動器 ＋ 電源 ＋ 感測器 | 槍管＋機構（武裝）；板材 | 機師與潛網者的 |

- **智慧套件**（晶片＋軟體）讓一把槍變成智慧武器：命中 +、自動管彈、可以被駭。崑崙的軟體帶槍靈——**槍靈是裝在槍裡的一個軟體零件**，可以拆下來換到另一把槍上，它會記得。
- **神經連結**（機械神經元）讓武器接上橋：先攻 +、瞄準不花行動點；代價是武器被擊中或被駭時，回灌打在你的感載上。
- 沒有電子零件的槍（星旗的作風）不能被駭，也沒有任何智慧功能。這從「牌子的脾氣」變成了零件層級的選擇：**你自己決定要不要在槍裡放一顆晶片**。

### 3.3 護甲與服裝

| 底材 | 必要的零件 | 選配 | 備註 |
|---|---|---|---|
| 一般服裝（上身、下身、外套） | 纖維 ＋ 外皮（面料） | 板材（暗袋裡的插板） | 外皮決定風格與曝露度 |
| 防彈衣 | 纖維 ＋ 板材 | 外皮；感測器 | |
| 戰術護甲 | 纖維 ＋ 板材 ×2 | 外皮；感測器；晶片 | |
| 重甲 | 板材 ×3 ＋ 纖維 | 致動器 ＋ 電源（動力化）；晶片；感測器 | 沒有動力的重甲很重 |
| 裝甲制服（女僕服、執事服、高訂） | 纖維 ＋ 外皮 ＋ 板材 | 內藏槽（刃、槍套） | 護甲藏在看不出來的地方；纖維與外皮都要 III 級以上才壓得住 |
| 頭部（帽、盔、面具） | 板材 或 纖維 | 感測器；外皮；晶片 | |
| 密封服 | 纖維 ＋ 外皮 ＋ 電源 | 板材 | 擋化學 |

- 內衣、鞋、飾品是現成的單件，不組裝。
- **護甲、隱匿、風格三選二**（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 4 節）現在是零件的取捨：板材給護甲、加重量、壞風格；好的外皮給風格、不擋子彈；高級的纖維兩邊都顧一點，貴。
- 外皮是服裝上最重要的零件：**同一件外套的剪裁，換一塊面料，從街頭變成高訂**。風格標籤、曝露度、社交與媒體的親和都從它來。

### 3.4 底材的規則

- 選配的槽空著也能用。裝了，多一份屬性，也多一份重量、人性成本（義體）或被駭的面。
- **底材的等級是零件等級的上限**（第 4 節）。
- 底材決定外形與基礎數值、槽的數量、對零件牌子的挑剔程度（第 6 節）。
- 底材是買來的殼。企業的底材要從正規管道買、從成品拆出來、或有設計圖請人做（第 10 節）。

## 4. 等級

**同一個牌子的東西有強弱之分。** 底材與零件都分五級。這取代了先前的「品級」——現在全部的裝備只有一套等級。

| 等級 | 街上的叫法 | 合法性（[LIFE](LIFE.md) 第 3 節） | 零件價格的量級 |
|---|---|---|---|
| **I** | 入門 | 自由 | 100～300 |
| **II** | 標準 | 自由或登記 | 300～900 |
| **III** | 專業（制式） | 許可 | 1,000～3,000 |
| **IV** | 軍規 | 違禁 | 4,000～12,000 |
| **V** | 原型 | 不在市面上 | 不賣 |

- 緋櫻的義臂有 I 到 V 五個等級，名字不同（緋櫻習慣用花名：一分咲、三分咲、五分咲、滿開、散華），外形一脈相承，數值與槽數逐級上去。星旗的步槍同理（M1 到 M5）。
- **底材的等級是零件等級的上限**：III 級的底材最多裝 III 級的零件。
- **超規**：改造師可以硬把高一級的零件塞進去（義體學或機械的檢定）。成功了，成品超出規格；失敗了，零件燒掉，或成品帶一個瑕疵。原廠絕不做這件事，同人社團天天在做。
- **成品的等級**＝底材的等級，但實際的強弱看裡面的零件。「先買好的殼，零件慢慢換」是一條成長的路。
- **合法性看最高的那個零件**：一把 II 級的手槍裝了一根 IV 級的槍管，被掃到時算違禁。
- 等級之外還有**狀態**：

| 狀態 | 意思 |
|---|---|
| 全新 | 照規格 |
| 二手 | 便宜四到七成。可能有**瑕疵**；義體件可能有**殘響**（[CYBERWARE](CYBERWARE.md) 第 5 節）；不在任何登記上 |
| 同人 | 社團自製或魔改。帶一個**怪癖**（好壞都有）；沒有保固 |
| 活的 | 生體件專用（第 8 節）：會長、會病、不能二手 |

## 5. 零件的屬性

每個零件帶**一到三條屬性**，成品的特色從這裡來。

### 5.1 數值

直接加在成品上的數字：護甲、傷害、射程、出力、感知、RAM、續航、同步上限、重量、人性成本的增減。

### 5.2 親和

對四類技能（[CORE_RULES](CORE_RULES.md) 6.4 節）的加成：**現實、內海、社交、媒體**。

| 裝在哪 | 親和的效果 |
|---|---|
| **橋**的零件 | 那一類的**技能容量** +N |
| 其他義體、武器、護甲的零件 | 那一類技能的**效果**略增；相關基本功的檢定 +（外皮的社交親和加在交涉與誘惑上，瞄具的現實親和加在槍械上） |

| 零件 | 屬性 |
|---|---|
| 外皮「瓷肌」（緋櫻，機械，III） | 風格 +2；**社交 +1、媒體 +1**。它就是好看 |
| 外皮「消光」（星旗，機械，II） | 防掃描；現實 +1；風格 −1 |
| 外皮「雪貂」（蜜腺，生體，III） | 真的毛皮。風格 +2；社交 +2、媒體 +1；掃描不到；要梳 |
| 機械神經元「絹」（伊甸園，III） | 社交 +2；感載的受傷倍率 +10% |
| 晶片「算盤」（崑崙，II） | 內海 +1；資料回傳 |
| 軟體「播報員」（萬華鏡，III） | 媒體 +2；內建錄影 |
| 槍管「長舌」（星旗，II） | 射程 +1 段；準度 −1 |
| 塗裝「櫻吹雪」（緋櫻，外皮，II） | 風格 +1；媒體 +1：這把槍很上鏡 |
| 板材「白鐵」（星旗，I） | 護甲 +1。沒有別的 |

**好看的外皮提高社交與媒體**，是這套系統最直觀的例子：同一條義臂、同一件外套、同一把槍，換一層皮，從打手的變成偶像的。

### 5.3 全能型

有些零件四類都加——「現實、內海、社交、媒體各 +1」。它們存在，但有代價：貴（同等級的三到五倍）；數值類的屬性平庸；多半是蜜腺的或高級訂製的同人件。「兼顧」是一種買得到的選擇，不是預設；專精的零件永遠在它那一類比全能的強。

### 5.4 特性

不是數字的屬性：靜音、防水、自我修復、防掃描、內建錄影、回報後門、授權鎖、殘響、怪癖。雙面效應（[CYBERWARE](CYBERWARE.md) 第 3 節）在零件層級體現：**每個有分量的好處，同一個零件上通常掛著一個代價**。

## 6. 牌子與相容

零件與底材都有牌子，脾氣照 [LIFE](LIFE.md) 5.1、5.2 節。

| 情況 | 結果 |
|---|---|
| **原廠全套**（底材與所有零件同一個牌子） | 套裝加成（緋櫻：同步回灌 −10%、要害 +；星旗：不卡彈、耐久 +；織女：維修費減半；崑崙：槍靈的全部功能）；但授權鎖與後門也是全套的 |
| **混搭** | 沒有套裝加成。每多一個牌子，組裝的難度 +1 |
| **挑剔的底材** | 有些底材只認自家的軟體或晶片（緋櫻、伊甸園、崑崙的智慧槍）。要裝別家的，得先破解 |
| **排異** | 組裝檢定失敗，或硬裝不相容的零件：成品帶一個瑕疵；義體的人性成本上升 |
| **機械與生體混裝** | 見第 8.4 節 |

- 織女的東西最不挑，什麼都能配——混搭的基底。
- **拔掉後門的標準做法**：留著夜鶯的晶片，把軟體換成同人的。

## 7. 邊緣橋

橋是最重要的一次組裝，因為它決定四類技能的容量。

| 零件 | 在橋上決定什麼 |
|---|---|
| **晶片** | **總容量**。等級越高越多（初稿：I 40、II 46、III 52、IV 58、V 64，各牌 ±4） |
| **軟體** | **怎麼分**。每套軟體是一個配分：均衡、偏現實、偏內海、偏社交、偏媒體，以及各種折衷 |
| **機械神經元** | 同步檔位的上限、感載的修正、人性成本、橋參數的修正 |
| 外皮（選配） | 親和：多半是社交與媒體 |

- [CYBERWARE](CYBERWARE.md) 第 7 節那十個型號是**原廠的組合**。換零件就是改型號。
- **每一類最低 8** 的底線寫在軟體的規格裡：沒有任何軟體能把一類分到 8 以下。
- 橋的組裝是最難的（難度比其他裝備高一級），失敗的代價也最重。
- 橋可以用生體件——那就是蜜腺的原型橋（第 8.5 節）。

## 8. 生體

貓耳有兩種。一種是裝上去的，一種是**長出來的**。

生體科技不是另一套系統，而是**零件的另一種材質**：每種通用零件都有生體的對應物（2.2 節），裝進同樣的槽。一對天然的貓耳，和一對機械的貓耳，是**同一個底材規格**（感測器＋神經元＋外皮），裝的是不同材質的零件：

| 槽 | 機械的貓耳 | 天然的貓耳 |
|---|---|---|
| 感測器 | 指向收音陣列 | 培養的貓系耳蝸 |
| 神經元 | 機械神經元 | 活體神經 |
| 外皮 | 合成絨毛 | 真的毛皮 |
| 致動器（選配） | 微型馬達 | 耳肌 |
| 軟體（選配） | 情緒連動韌體 | 貓系基因譜 |

差別全在材質的規則。

### 8.1 生體件和機械件哪裡不同

| | 機械 | 生體 |
|---|---|---|
| 怎麼來 | 買、拆、訂做 | **培養**：下單、等它長。或者從活的東西身上移植 |
| 安裝 | 手術，裝上就能用 | 手術之後要**長合**：幾天到幾週。這段時間功能不全 |
| 人性成本 | 有 | **極低或沒有**。身體認得它是自己的 |
| 被駭 | 會（有電子零件的） | **不會**。沒有東西可以駭 |
| 被掃描 | 掃得出來 | **掃不出來**。法律上不算義體，合法性一律自由 |
| 壞了 | 要修、要換零件 | **自己會好**（慢）；但會生病、會感染、會排斥 |
| 維持 | 保養、訂閱 | **要養**：每週的營養劑與免疫調節（蜜腺賣的），加進每週帳單。斷了會萎縮 |
| 升級 | 換更高級的零件 | **會成長**（8.3 節） |
| 拆下來 | 可以，零件還在 | **拆了就死**，除非立刻移植。不能二手、不能囤 |
| 峰值 | 高 | 同等級的數值約低一級。出力、容量、護甲都比不上金屬 |
| 感覺 | 準 | **細**。感知類更靈；觸感是真的 |
| 親和 | 看零件 | 天生偏**社交與媒體**：真的體溫、真的毛、真的反應 |
| 感載 | 看神經元 | 活的神經更敏感：受到的感載略增 |

一句話：**機械是買的，生體是養的。** 機械強、快、可換、有人性成本、會被駭；生體弱一點、慢、不可逆、幾乎不傷人性、沒人駭得進去。

### 8.2 等級與來源

- 生體件同樣分 I～V 級，指的是培養的世代與純度。
- **蜜腺生技**幾乎獨佔。正規的生體件從蜜腺療養院與玻璃岸的診所下單，等一到四週。
- **車庫生技**：同人眾裡做生體的社團。便宜、快、什麼都敢做；狀態是同人，怪癖可能是**變異**（多長了一點什麼）。
- **移植**：從活體取下的生體件可以直接移植。這是拆體客另一門更黑的生意，也是生體件唯一的「二手」來源——時效以小時計。
- 生體件的價格約是同級機械件的兩倍，加上每週的維持費。所以生體派在世界裡是有錢人的選擇（[CULTURE](CULTURE.md) 第 2 節）。

### 8.3 成長

機械的東西出廠是幾級就是幾級。生體的東西**會長**。

- 每個生體件有**成熟度**。裝著、用著、養著，它慢慢累積；滿了升一級，直到底材的等級上限。
- 怎麼累積：用它（獸耳用來聽、培養肌用來出力）、每週的營養劑、好的生活（睡得好、吃真的食物）。
- 怎麼倒退：斷營養劑、重傷、感染、長期高感載、戰鬥藥。
- 升級時有機率長出一條新的屬性——可能是你要的，可能不是。高級的營養劑能引導方向。
- 所以生體派的成長是**時間**，機械派的成長是**錢**。兩條路都通到 IV 級；V 級的生體件只有蜜腺的實驗室裡有。

### 8.4 混裝

同一個底材裡，機械件與生體件可以混裝，但它們不太願意待在一起。

| 組合 | 結果 |
|---|---|
| **全機械** | 第 6 節的規則 |
| **全生體** | 「活的」加成：人性成本歸零、自癒加快、掃描不到、親和（社交、媒體）各 +1；感載的受傷倍率 +10% |
| **混裝** | 每一個「機械接生體」的接面，組裝難度 +1，並且需要一個過渡件（通常是機械神經元當轉接）。成品不算全生體：掃得出來、有人性成本（但比全機械低） |
| 生體的底材裝機械件 | 可以，但那個機械件掃得出來，而且會讓這件生體的成熟度長得慢 |

最常見的混裝：**機械的骨架與致動器，生體的皮與神經**——外表與觸感是真的，力氣是機器的。高級人偶與偶像的標準做法。

### 8.5 獸化改造

把上面的規則套在 [CULTURE](CULTURE.md) 第 2 節的兩派上：

| | 機械派 | 生體派 |
|---|---|---|
| 底材 | 機械的耳、尾、爪 | 生體的耳、尾、爪 |
| 「哪一系」由什麼決定 | 底材的外形＋情緒連動韌體 | **基因譜**（軟體槽的生體件）：貓、狐、兔、犬…… |
| 系的特色 | 感測器的型號：貓系偏高頻與夜視、狐系偏範圍、兔系偏遠距、犬系偏追蹤（配嗅覺） | 同上，由譜帶出來；而且會隨成熟度長得更像 |
| 情緒外洩（耳朵與尾巴藏不住心情） | 有。可以裝抑制器鎖住 | 有，而且**鎖不住**——它是真的反射。要靠定力 |
| 誰在用 | 街頭、潛網者、野良 | 有錢人、偶像、高級人偶 |

- **基因譜**是獸化的核心零件：它是「軟體」的生體版，決定這對耳朵是哪一系、有哪些本能（聽到高頻會轉向、緊張時尾巴會炸毛）。換譜等於換一種動物，但要等它重新長。
- **全身獸化**（耳、尾、爪、毛皮都是同一系的生體件）有系的套裝加成：貓系的落地與夜行、狐系的察覺、兔系的跳躍、犬系的追蹤。這是野良裡最資深的那些人的樣子——以及他們付不起營養劑時的處境。
- 天然的獸耳在掃描器前是**人的一部分**。冠冕區的門禁攔不住它，但雇主的眼睛看得見。

### 8.6 生體的武器與護甲

- **爪、牙、骨刺**是刃的生體件，裝在義臂的內藏槽或「爪」的底材裡。掃描不到——進得了任何不准帶武器的地方。
- **蛛絲織物**是纖維的生體件：輕、會自己補破洞、要保濕。蜜腺的高級防護服用它。
- **活皮革**是外皮的生體件，用在服裝上：風格極高，會老。
- 槍管與機構沒有生體版。這個世界沒有「長出來的槍」——至少牆內沒有。

### 8.7 生體的橋

邊緣橋也可以用生體件：活體神經當神經元、神經節當晶片。

- 活體神經的橋人性成本最低、同步最順。
- **神經節的容量比同級的晶片少**（約低兩級）。純生體的橋裝不了多少技能。
- 所以實務上的做法是**機械的晶片＋活體的神經**——這就是蜜腺原型橋（[CYBERWARE](CYBERWARE.md) 第 7 節）四類各 15、人性成本最低、要長期用藥的由來。
- 純生體的橋有一個別人沒有的特性：**沒有熔斷器可以裝**（[CYBERSPACE](CYBERSPACE.md) 第 6 節）。它不是違禁品，因為法律沒想過這種東西。這是一條任務線的種子。

## 9. 零件從哪來

| 來源 | 拿得到什麼 | 備註 |
|---|---|---|
| **正規商店**（刀巷、電器街、槍店、裁縫） | I～II 級，全新；III 級要許可 | 會登記 |
| **原廠直營** | 自家的 I～III 級與底材 | 只賣給有身分的人；保固 |
| **同人夜市、緋夜祭** | 同人件；改過的零件；拆下來的二手件 | 怪癖；冷門的屬性組合在這裡 |
| **黑市**（舊港夜市碼頭、蚌殼市） | III～IV 級；來路不明的 | 貴；可能有後門、有追蹤器 |
| **蜜腺的診所** | 生體件，下單培養 | 要等；每週維持費 |
| **車庫生技** | 同人的生體件 | 可能變異 |
| **拆解** | 從自己的舊裝備、戰利品、撿到的東西拆出來 | 第 10 節 |
| **骨場** | 隨機的二手零件 | 每天不同；要挖 |
| **拆體客** | 二手的義體零件；移植用的生體件 | 有殘響；你知道它們怎麼來的 |
| **委託的戰利品與報酬** | III～V 級 | 軍規以上主要從這裡來 |
| **訂做** | 指定屬性的零件 | 找同人社團或固定 NPC；要等、要交情 |
| **特殊任務** | V 級原型 | 每一個都有名字 |

玩家**不能從原料做出零件**。訂做是請別人做——這個世界裡做零件需要一座工廠、一間培養室，或一個瘋子。

## 10. 組裝、安裝與拆解

### 10.1 組裝

- **在哪裡**：有工作台的據點（二級以上）、診所、槍店、同人社團的攤位。
- **誰來做**：

| 誰 | 品質 | 代價 |
|---|---|---|
| 自己或夥伴 | 技術的檢定——義體用義體學，武器與護甲用機械，生體件用醫療 | 免費；失敗有後果 |
| 診所、槍店、裁縫 | 穩定的成功 | 工錢；會登記；不做超規、不碰授權鎖 |
| 同人社團 | 成功率高，願意超規與魔改 | 便宜；成品可能多一個怪癖 |
| 原廠 | 完美 | 貴；只裝原廠全套 |

- **難度**＝底材的等級 ＋ 牌子數量的修正 ＋ 機械與生體接面的修正 ＋ 超規的修正。
- **結果**：

| 成功程度 | 成品 |
|---|---|
| 大成功 | **精工**：一項屬性多一點，或人性成本少一點 |
| 成功 | 照規格 |
| 失敗 | 能用，帶一個瑕疵 |
| 大失敗 | 燒掉一個零件（隨機，或超規的那一個） |

- 組裝前可以**預覽**：介面顯示成品的全部數值、四類親和、重量、合法性、難度；義體另外顯示人性成本。這個畫面是工藝的核心——玩家在這裡來回換零件，看數字怎麼動。

### 10.2 安裝

- **武器與護甲**組好就能用。
- **義體**裝到身上是手術，照 [CYBERWARE](CYBERWARE.md) 第 2 節：人性成本、休養、併發症的機率。可以先組好放著，可以組好拿去賣。
- **生體的義體**手術之後還要長合。

### 10.3 換零件

裝備可以**只換其中一個零件**，不用整件重來。這是日常的升級方式：這個月換一根好一點的槍管，下個月換一層皮。武器與護甲在工作台上換；身上的義體是小手術；橋的零件每一次都是大手術；生體件換了就是重新養。

先前說的「改裝件」就是選配槽裡的零件。

### 10.4 拆解

- 每個零件有機率完好拆下；失敗的零件降一級或報廢。
- **有授權鎖的東西要先解鎖**，不然一拆就鎖死或回報。
- **戰利品**：敵人的武器與護甲可以整件撿走，也可以拆成零件帶走（輕）。敵人身上的義體要改造師拆。這是 III 級以上零件的重要來源——也是拆體客在做的事。行規與人性對此有話說（[LIFE](LIFE.md) 第 9 節）：拆死人的是一回事，拆活人的是另一回事。
- 拆下來的零件是二手的。生體件拆下來要立刻移植，否則報廢。

## 11. 設計圖與訂做

- **設計圖**（沿用 ElondiaRPG 的圖紙）：一個底材的規格。有了它，可以請同人社團做出那個底材的殼——企業不賣給你的東西，這樣弄到手。設計圖是偷來的、買來的、或把一件成品完整拆解後畫出來的。
- **訂做零件**（沿用 ElondiaRPG 的自創配方）：向社團或固定 NPC 指定「我要一層社交 +2 的外皮，三級」。對方報價、開條件、要時間。AI 開著時可以用文字描述想要的零件，AI 設計屬性，程式把數值夾在那個等級允許的範圍內。產物一律是同人狀態。
- **玩家自己的社團**：據點是同人社團店面時（[FIXER](FIXER.md) 第 9 節），可以接別人的組裝與訂做委託，在同人夜市擺攤賣自己組的成品。

## 12. 例子

**一條給偶像用的義臂（混裝）**
底材：緋櫻「三分咲」義臂（II 級，機械）。

| 槽 | 裝什麼 | 屬性 |
|---|---|---|
| 板材 | 織女 輕合金 II | 重量 −1 |
| 致動器 | 緋櫻 細工 II | 精細動作 +1 |
| 神經元 | 蜜腺 活體神經 II（生體） | 人性成本 −2；感載受傷 +5% |
| 外皮 | 蜜腺 活皮 II（生體） | 風格 +2；社交 +2、媒體 +1；有體溫 |

機械的骨架，生體的皮與神經。握起來是真的手。兩個機械接生體的接面，難度 +2。

**同一個底材，給槍手用**
板材換星旗「白鐵」、致動器換星旗的高出力款、神經元換星旗的、不裝外皮。護甲 +2、近戰與後座力控制 +、風格 −1，看起來就是一條軍用義肢。

**一對天然的貓耳**
底材：蜜腺 生體獸耳（II 級）。貓系耳蝸（感測器）＋活體神經＋毛皮「三花」（外皮）＋耳肌（致動器）＋貓系基因譜（軟體）。全生體：人性成本零、掃描不到、社交與媒體各 +1、感知 +2（高頻）。下單後三週長好；每週要營養劑；高興的時候它會自己動，鎖不住。一年後成熟度滿了，升到 III 級，多了一條「夜裡聽得見心跳」。

**一把自己配的手槍**
底材：織女的通用手槍框（II 級）。星旗的槍管 II（不卡彈）＋崑崙的機構 II（彈匣大）＋崑崙的智慧套件（晶片＋槍靈軟體「小滿」）＋緋櫻的塗裝「櫻吹雪」。三個牌子，沒有套裝加成；槍靈能用但少了全套才有的進階功能。一把會說話、很上鏡、而且可以被駭的槍。

**一件女僕服**
底材：白手套訂製的裝甲制服（III 級）。蛛絲織物 III（生體纖維，自己補）＋高訂面料 III（外皮：風格 +3、社交 +2）＋陶瓷夾層 III（板材，護甲 6）＋內藏槽（一把刃）。護甲、隱匿、風格三樣都有——代價是三個零件都要 III 級，其中一個是活的。

**一座自己配的橋**
崑崙的晶片 III（總容量 50，內海 +1，資料回傳）＋織女的神經元 III＋同人軟體「三七開」（配分偏內海與媒體）。出來是現實 9、內海 19、社交 9、媒體 14。
