# 義體工藝：底材與零件

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[CYBERWARE](CYBERWARE.md)（部位、人性成本、授權鎖、橋的型號）、[CORE_RULES](CORE_RULES.md) 6.4 節（技能容量）、[LIFE](LIFE.md) 第 4、5 節（品級、牌子、合法性）。被依賴：之後的 `ITEMS`（義體與零件的目錄）。
> 來源：ElondiaRPG 的裝備「底材 × 材料」與工藝、委託打造、自創配方（[plan/MIGRATION](plan/MIGRATION.md) H、I 組）。預定資料：`data/rules/cyber_bases.json`（底材）、`cyber_parts.json`（零件）、`brands.json`。數值都是初稿。

在一座企業把專利看得比人命重的城市，沒有人用廢鐵「搓」出一條義臂。這裡的工藝不是製造，是**組裝**：義體由一個**底材**與幾個**零件**構成，零件是買來的、拆來的、訂做的、偷來的。玩家做的事是挑零件、配零件、把它們裝進底材——以及決定要不要把一顆軍規晶片塞進一個民用的殼裡。

## 1. 三層：底材、零件、成品

```
底材（殼與規格：這是一條什麼義臂、有哪幾個槽、能裝到幾級的零件）
  ＋ 零件 × 數個（每個槽一個：晶片、板材、機械神經元、軟體……）
  ＝ 成品（一件能裝到身上的義體；數值是底材與零件合起來的）
```

沿用 ElondiaRPG「底材 × 材料」的組合式設計，換了軸：材料只有一個，零件有好幾個槽。好處相同——目錄不用寫幾千件成品，寫幾十個底材與幾百個零件，組合自己會長出來。

## 2. 零件的類型

八種。每種管一件事。

| 零件 | 管什麼 | 主要影響 |
|---|---|---|
| **晶片** | 運算 | 容量、功能的階數、反應的上限 |
| **機械神經元** | 和神經的接合 | 同步檔位的上限、感載的修正、**人性成本** |
| **軟體**（韌體） | 行為 | 功能怎麼分配、有哪些模式；授權鎖與後門也在這裡 |
| **板材** | 結構 | 護甲、耐久、重量 |
| **致動器**（人工肌肉） | 出力 | 力量、速度、負重 |
| **感測器** | 感知 | 感知的範圍與種類、精度 |
| **電源** | 能量 | 續航、超頻能撐多久、每場能用幾次 |
| **外皮**（外裝） | 外觀 | 風格、社交與媒體的加成、防不防掃描、看不看得出是義體 |

- 每個零件有：**類型、牌子、等級（I～V）、一到三條屬性**（第 5 節）、狀態（全新、二手、同人）。
- 零件本身不能用，要裝進底材。零件是行囊裡的物品，可以買賣、可以當報酬、可以當戰利品。

## 3. 底材

底材是一件義體的殼與規格。每個底材寫明它**一定要哪些零件**、**可以加哪些零件**。

| 底材 | 部位 | 必要的零件 | 選配 |
|---|---|---|---|
| **邊緣橋** | 橋 | 晶片 ＋ 機械神經元 ＋ 軟體 | 外皮（後頸蓋） |
| 甲板 | 腦 | 晶片 ×2 ＋ 軟體 ＋ 電源 | — |
| 反射加速器 | 腦 | 晶片 ＋ 機械神經元 ×2 ＋ 電源 | — |
| 記憶庫 | 腦 | 晶片 ＋ 軟體 | — |
| 人格面具槽 | 腦 | 晶片 ＋ 機械神經元 ＋ 軟體 | — |
| 義眼 | 眼 | 感測器 ＋ 晶片 ＋ 軟體 | 外皮（虹膜） |
| 義耳、獸耳 | 耳 | 感測器 ＋ 機械神經元 ＋ 外皮 | 致動器（會動的耳朵） |
| 聲帶 | 喉 | 致動器 ＋ 軟體 | — |
| 皮下裝甲 | 軀幹 | 板材 ×2 ＋ 機械神經元 | — |
| 藥泵 | 軀幹 | 致動器 ＋ 軟體 | 電源 |
| 合成臟器 | 軀幹 | 致動器 ＋ 電源 ＋ 機械神經元 | — |
| 觸覺皮膚 | 皮膚 | 外皮 ＋ 機械神經元 ＋ 感測器 | — |
| 光學迷彩 | 皮膚 | 外皮 ＋ 晶片 ＋ 電源 | — |
| 義臂 | 臂 | 板材 ＋ 致動器 ＋ 機械神經元 | 外皮；內藏槽（武器、工具、駭入接頭） |
| 義腿 | 腿 | 板材 ＋ 致動器 ＋ 機械神經元 | 外皮；電源（跳躍增壓） |
| 尾 | 軀幹／腿 | 致動器 ＋ 機械神經元 ＋ 外皮 | 感測器 |
| 私密部位 | 私密 | 機械神經元 ＋ 感測器 ＋ 外皮 | 致動器；藏匿艙 |

- 橋一定是**晶片＋機械神經元＋軟體**：它是純粹的介面，沒有結構也沒有出力。
- 選配的槽空著也能用。裝了，多一份屬性，也多一份重量、人性成本與被駭的面。
- **底材自己也有牌子與等級**。它決定：外形與基礎數值、槽的數量、**能裝到幾級的零件**、對零件牌子的挑剔程度（第 6 節）。
- 底材是買來的殼。企業的底材要從正規管道買、或從成品拆出來、或有設計圖請人做殼（第 8 節）。

## 4. 等級

**同一個牌子的義體有強弱之分。** 底材與零件都分五級：

| 等級 | 街上的叫法 | 對應的品級與合法性（[LIFE](LIFE.md) 第 3、4 節） | 價格的量級（零件） |
|---|---|---|---|
| **I** | 入門 | 量產，自由 | 100～300 |
| **II** | 標準 | 量產，自由或登記 | 300～900 |
| **III** | 專業 | 制式，許可 | 1,000～3,000 |
| **IV** | 軍規 | 軍規，違禁 | 4,000～12,000 |
| **V** | 原型 | 原型，不在市面上 | 不賣 |

- 緋櫻的義臂有 I 到 V 五個等級，名字不同（緋櫻習慣用花名：一分咲、三分咲、五分咲、滿開、散華），外形一脈相承，數值與槽數逐級上去。
- **底材的等級是零件等級的上限**：III 級的底材最多裝 III 級的零件。
- **超規**：改造師可以硬把高一級的零件塞進去（義體學檢定）。成功了，成品超出規格；失敗了，零件燒掉，或成品帶一個瑕疵。原廠絕不做這件事，同人社團天天在做。
- **成品的等級**＝底材的等級。但實際的強弱看裡面的零件：一個裝滿 III 級零件的 III 級底材，和一個只裝 I 級零件的 III 級底材，差很多。這讓「先買好的殼，零件慢慢換」是一條成長的路。
- 等級之外還有**狀態**：

| 狀態 | 意思 |
|---|---|
| 全新 | 照規格 |
| 二手 | 便宜四到七成。可能有**瑕疵**；義體類的可能有**殘響**（[CYBERWARE](CYBERWARE.md) 第 5 節）；不在任何登記上 |
| 同人 | 社團自製或魔改。帶一個**怪癖**（好壞都有）；沒有保固 |

## 5. 零件的屬性

零件不只有等級。每個零件帶**一到三條屬性**，成品的特色從這裡來。屬性分三種：

### 5.1 數值

直接加在成品上的數字：護甲、出力、感知、RAM、續航、同步上限、人性成本的增減。

### 5.2 親和

對四類技能（[CORE_RULES](CORE_RULES.md) 6.4 節）的加成：**現實、內海、社交、媒體**。

| 裝在哪 | 親和的效果 |
|---|---|
| **橋**的零件 | 那一類的**技能容量** +N |
| 其他義體的零件 | 那一類技能的**效果**略增；相關基本功的檢定 +（外皮的社交親和加在交涉與誘惑上，感測器的現實親和加在槍械上） |

例：

| 零件 | 屬性 |
|---|---|
| 外皮「瓷肌」（緋櫻，III） | 風格 +2；**社交 +1、媒體 +1**。它就是好看 |
| 外皮「消光」（星旗，II） | 防掃描；現實 +1；風格 −1 |
| 機械神經元「絹」（伊甸園，III） | 社交 +2；感載的受傷倍率 +10% |
| 晶片「算盤」（崑崙，II） | 內海 +1；資料回傳 |
| 軟體「播報員」（萬華鏡，III） | 媒體 +2；內建錄影 |
| 板材「白鐵」（星旗，I） | 護甲 +1。沒有別的 |

**好看的外皮提高社交與媒體**，是這套系統最直觀的例子：同一條義臂，換一層皮，從打手的手臂變成偶像的手臂。

### 5.3 全能型

有些零件四類都加——「現實、內海、社交、媒體各 +1」。它們存在，但有代價：

- 貴（同等級的三到五倍）。
- 數值類的屬性平庸。全能的晶片容量不會是最高的。
- 多半是蜜腺的（原型路線）或高級訂製的同人件。

所以「兼顧」是一種買得到的選擇，不是預設。專精的零件永遠在它那一類比全能的強。

### 5.4 特性

不是數字的屬性：靜音、防水、自我修復、防掃描、內建錄影、回報後門、授權鎖、殘響、怪癖。雙面效應（[CYBERWARE](CYBERWARE.md) 第 3 節）在零件層級體現：**每個有分量的好處，同一個零件上通常掛著一個代價**。

## 6. 牌子與相容

零件與底材都有牌子，脾氣照 [LIFE](LIFE.md) 5.2 節。組裝時牌子之間的關係：

| 情況 | 結果 |
|---|---|
| **原廠全套**（底材與所有零件同一個牌子） | 套裝加成（各牌不同：緋櫻的同步回灌 −10%、星旗的耐久 +、織女的維修費減半）；但授權鎖與後門也是全套的 |
| **混搭** | 沒有套裝加成。每多一個牌子，組裝的難度 +1 |
| **挑剔的底材** | 有些底材只認自家的軟體或晶片（緋櫻、伊甸園）。要裝別家的，得先破解底材 |
| **排異** | 組裝檢定失敗，或硬裝不相容的零件：成品的人性成本上升，或帶一個瑕疵 |

- 織女的東西最不挑，什麼都能配——所以是混搭的基底。
- **拔掉後門的標準做法**：留著夜鶯的晶片，把軟體換成同人的。

## 7. 邊緣橋

橋是最重要的一次組裝，因為它決定四類技能的容量。

| 零件 | 在橋上決定什麼 |
|---|---|
| **晶片** | **總容量**。等級越高越多（初稿：I 40、II 46、III 52、IV 58、V 64，各牌 ±4） |
| **軟體** | **怎麼分**。每套軟體是一個配分：均衡、偏現實、偏內海、偏社交、偏媒體，以及各種折衷 |
| **機械神經元** | 同步檔位的上限、感載的修正、人性成本、橋參數的修正 |
| 外皮（選配） | 親和：多半是社交與媒體 |

- [CYBERWARE](CYBERWARE.md) 第 7 節那十個型號是**原廠的組合**：「緋櫻 奉公」＝緋櫻的晶片＋緋櫻的神經元＋「奉公」軟體，出來是現實 20、內海 15、社交 10、媒體 10。
- 換零件就是改型號：把「奉公」軟體換成同人寫的均衡配分，同一顆晶片變成 14／14／14／13，而且沒有忠犬調校槽了——代價是失去緋櫻的套裝加成，並且這座橋從此不在緋櫻的保固與登記裡。
- **每一類最低 8** 的底線寫在軟體的規格裡：沒有任何軟體能把一類分到 8 以下。
- 橋的組裝是最難的（難度比其他義體高一級），失敗的代價也最重。多數人一輩子只換一兩次。

## 8. 零件從哪來

| 來源 | 拿得到什麼 | 備註 |
|---|---|---|
| **正規商店**（刀巷、電器街、原廠店） | I～II 級，全新；III 級要許可 | 會登記 |
| **原廠直營** | 自家的 I～III 級與底材 | 只賣給有身分的人；保固 |
| **同人夜市、緋夜祭** | 同人件；改過的零件；拆下來的二手件 | 怪癖；冷門的屬性組合在這裡 |
| **黑市**（舊港夜市碼頭、蚌殼市） | III～IV 級；來路不明的 | 貴；可能有後門、有追蹤器 |
| **拆解** | 從自己的舊義體、戰利品、撿到的東西拆出來 | 第 9 節 |
| **骨場** | 隨機的二手零件 | 每天不同；要挖 |
| **拆體客** | 二手零件，便宜 | 有殘響；你知道它們怎麼來的 |
| **委託的戰利品與報酬** | III～V 級 | 軍規以上主要從這裡來 |
| **訂做** | 指定屬性的零件 | 找同人社團或固定 NPC；要等、要交情、要材料費 |
| **特殊任務** | V 級原型 | 每一個都有名字 |

玩家**不能從原料做出零件**。訂做是請別人做——這個世界裡做零件需要一座工廠或一個瘋子。

## 9. 組裝、安裝與拆解

### 9.1 組裝

把零件裝進底材，得到成品。

- **在哪裡**：有工作台的據點（二級以上）、診所、同人社團的攤位。
- **誰來做**：

| 誰 | 品質 | 代價 |
|---|---|---|
| 自己或夥伴 | 技術 ＋ 義體學的檢定，對組裝難度 | 免費；失敗有後果 |
| 診所 | 穩定的成功 | 工錢；會登記；不做超規、不碰授權鎖 |
| 同人社團 | 成功率高，願意超規與魔改 | 便宜；成品可能多一個怪癖 |
| 原廠 | 完美 | 貴；只裝原廠全套 |

- **難度**＝底材的等級 ＋ 牌子數量的修正 ＋ 超規的修正。改造師的「手術刀」樹上有降低難度、減少排異的技能。
- **結果**：

| 成功程度 | 成品 |
|---|---|
| 大成功 | **精工**：一項屬性多一點，或人性成本少一點 |
| 成功 | 照規格 |
| 失敗 | 能用，帶一個瑕疵 |
| 大失敗 | 燒掉一個零件（隨機，或超規的那一個） |

- 組裝前可以**預覽**：介面顯示成品的全部數值、四類親和、人性成本、合法性、難度。這個畫面是工藝的核心——玩家在這裡來回換零件，看數字怎麼動。

### 9.2 安裝

成品裝到身上是手術，照 [CYBERWARE](CYBERWARE.md) 第 2 節：人性成本、休養、併發症的機率。組裝與安裝是兩個步驟——可以先組好放著，可以組好拿去賣。

### 9.3 換零件

裝在身上的義體可以**只換其中一個零件**，不用整件重來。小手術，便宜、快。這是日常的升級方式：這個月換一顆好一點的晶片，下個月換一層皮。

橋的零件也能單獨換，但每一次都是大手術。

### 9.4 拆解

把成品拆回底材與零件。

- 每個零件有機率完好拆下（看義體學與零件的狀態）；失敗的零件降一級或報廢。
- **有授權鎖的東西要先解鎖**，不然一拆就鎖死或回報。
- **從敵人身上拆**：過載或倒下的敵人，身上的義體可以拆（改造師的技能，或戰後花時間）。這是 III 級以上零件的重要來源——也是拆體客在做的事。行規與人性對此有話說（[LIFE](LIFE.md) 第 9 節）：拆死人的是一回事，拆活人的是另一回事。
- 拆下來的零件是二手的。

## 10. 設計圖與訂做

- **設計圖**（沿用 ElondiaRPG 的圖紙）：一個底材的規格。有了它，可以請同人社團做出那個底材的殼——企業不賣給你的東西，這樣弄到手。設計圖是偷來的、買來的、或把一件成品完整拆解後畫出來的。
- **訂做零件**（沿用 ElondiaRPG 的自創配方）：向社團或固定 NPC 指定「我要一層社交 +2 的外皮，三級」。對方報價、開條件、要時間。AI 開著時可以用文字描述想要的零件，AI 設計屬性，程式把數值夾在那個等級允許的範圍內。產物一律是同人狀態。
- **玩家自己的社團**：據點是同人社團店面時（[FIXER](FIXER.md) 第 9 節），可以接別人的組裝與訂做委託，在同人夜市擺攤賣自己組的成品。

## 11. 例子

**一條給偶像用的義臂**
底材：緋櫻「三分咲」義臂（II 級）。必要的槽：板材、致動器、機械神經元；選配：外皮。

| 槽 | 裝什麼 | 屬性 |
|---|---|---|
| 板材 | 織女 輕合金 II | 重量 −1 |
| 致動器 | 緋櫻 細工 II | 精細動作 +1 |
| 機械神經元 | 伊甸園「絹」II | 社交 +1；感載受傷 +5% |
| 外皮 | 緋櫻「瓷肌」II | 風格 +2；社交 +1、媒體 +1 |

三個牌子，混搭，沒有套裝加成。成品：一條不能打的手臂，社交 +2、媒體 +1、風格 +2，上鏡與握手會都用得上。

**同一個底材，給槍手用**
板材換星旗「白鐵」、致動器換星旗的高出力款、神經元換星旗的、不裝外皮。成品：護甲 +2、近戰與後座力控制 +、風格 −1，看起來就是一條軍用義肢。

**一座自己配的橋**

## 12. 還沒決定的

| 問題 | 目前的想法 |
|---|---|
| **武器與護甲要不要也用零件** | 先不用。武器維持「型號 × 牌子 × 品級 ＋ 改裝件」（[LIFE](LIFE.md) 第 4、5 節），比較輕。之後如果想統一，零件的類型可以直接沿用 |
| **生體改造**（蜜腺的獸耳、毛皮） | 不走組裝。生體件是整件培養的，只有等級、沒有零件槽——這是它和機械派的差別，也是它不能退貨的原因 |
| **甲板的構裝**（網內的裝備） | 不走組裝。構裝是程式，另一套 |
| 零件的總數 | 起步目標：8 類 × 6 個牌子 × 3 個等級，約一百多個；再加有名字的特殊件 |
