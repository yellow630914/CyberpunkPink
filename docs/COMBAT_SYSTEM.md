# 戰鬥系統

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[CORE_RULES](CORE_RULES.md)（屬性、檢定、三條軌、同步原則）、[CYBERWARE](CYBERWARE.md)。被依賴：[NETRUNNING](NETRUNNING.md)（快駭在戰鬥中的行動）、[FIXER](FIXER.md)（案子的行動階段）。
> 來源：ElondiaRPG 的逐回合行動點戰鬥，加上槍戰需要的站位、護甲與彈藥。預定資料：`data/rules/combat.json`、`weapons.json`、`armor.json`、`enemies.json`、`statuses.json`。數值都是初稿。

目標是跑團的槍戰感：**開槍很快、很痛、很少打第二輪**。有掩體的人活，沒掩體的人死；想活捉就換一種打法。

## 1. 回合與行動點

沿用 ElondiaRPG：逐回合，輪到自己時連續行動直到行動點用完或結束回合，沒用完的累積到下回合。

```
先攻 = 1d20 + mod(反應) + 槍手的戰鬥直覺分配
行動點上限 = 4 + floor((mod(反應) + mod(膽識)) / 2)
每回合回復 = 3
```

| 行動 | 行動點 |
|---|---|
| 射擊（單發／點射） | 2 |
| 連射（全自動，見第 5 節） | 3 |
| 近戰攻擊 | 2 |
| 瞄準（下一次射擊 +2；可以指定部位） | 1 |
| 換站位 | 1 |
| 換彈 | 1 |
| 換武器（主武器、副武器、近戰之間） | 1 |
| 使用道具／急救 | 1～2。**只能用快取格裡的道具**（[EQUIPMENT](EQUIPMENT.md) 4.1 節） |
| 快駭 | 0～1，另花 RAM（[NETRUNNING](NETRUNNING.md) 第 2 節） |
| 壓制、掩護、待命（反應射擊） | 2 |
| 撤退 | 2，全隊檢定 |

## 2. 站位

不用格子地圖。每個單位在戰鬥中處於三種站位之一，敵我各自記：

| 站位 | 被射擊 | 射擊 | 近戰 |
|---|---|---|---|
| **掩體** | 迴避 +4；掩體有耐久，被重武器打穿 | 正常 | 不能，除非對方過來 |
| **暴露** | 正常 | 正常 | 可以被近身 |
| **近身**（和某個敵人纏在一起） | 被其他人射擊 −2（怕打到自己人） | 長槍 −4；手槍與霰彈正常 | 可以 |

- 戰鬥開始時的站位由遭遇方式決定：埋伏方全員掩體、被埋伏方全員暴露；正面遭遇各自擲運動或隱匿搶掩體。
- **側襲**：花 2 點行動點並通過隱匿或運動檢定，下一次攻擊無視對方的掩體。
- **場景的掩體數量有限**，是地圖格的屬性（辦公室多、停車場少、走廊沒有）。這讓「在哪裡開打」成為踩點階段值得打聽的事。
- 控制節點被潛網者拿下時，可以改變站位條件：關燈（全場迴避 +2，有夜視的不受影響）、放下防爆門（製造掩體或切斷增援）、接管砲塔。

## 3. 命中

```
攻擊 = 1d20 + mod(反應) + 槍械或重武器 + 武器修正 + 射程修正     （近戰用體格＋格鬥）
迴避 = 10 + mod(反應) + 站位 + 義體                              
```

- 命中：攻擊 ≥ 迴避。超過 5 以上是**要害**，傷害骰加一顆。自然 20 另擲一次重創（第 6 節）。
- 射程分近、中、遠三段，每種武器有最適射程，離一段 −2。戰鬥的射程段是場景格的屬性，不逐單位計算。

## 4. 護甲

護甲與武器都由底材與零件組裝而成（[CRAFTING](CRAFTING.md) 第 3 節）：護甲值來自板材與纖維，風格來自外皮；槍的傷害與射程來自槍管，射速與彈匣來自機構，智慧功能來自晶片與軟體。下面寫的是組好之後怎麼算。

護甲是服裝與義體給的**護甲值**，每次受到傷害時直接減掉。

```
實際傷害 = max(0, 傷害 − 護甲值 + 穿甲)
```

- **耗損**：每次有傷害穿透，那件護甲的護甲值 −1，戰鬥後要修。皮下裝甲不耗損。
- 護甲越重，隱匿與迴避的懲罰越大，風格也越差（穿全套重甲進夜店是不行的）。**護甲、隱匿、風格三選二**。
- 護甲值量級：街頭服裝 2～4、防彈衣 6～8、軍規 10～12、機甲 15 以上。

## 5. 武器與傷害

| 類型 | 傷害 | 特性 |
|---|---|---|
| 手槍 | 2d6 | 近身不扣；可以藏 |
| 衝鋒槍 | 2d6 | 連射 |
| 霰彈槍 | 4d6（近）／2d6（中） | 近身不扣；打掩體 |
| 步槍 | 4d6 | 連射；穿甲 2 |
| 狙擊槍 | 5d6 | 需要瞄準；穿甲 4 |
| 重武器 | 6d6 以上 | 打穿掩體；範圍 |
| 近戰（刀、內藏刃） | 2d6 + mod(體格) | 穿甲看武器；無聲 |
| 神經武器（感官彈、電擊鞭、費洛蒙霧） | 2d6～4d6 **感載** | 無視護甲；對沒有橋的目標（機器、車族的純人）無效 |

- **連射**：花 3 點行動點與 10 發子彈，命中後超過迴避每 1 點多 2 點傷害（上限武器骰的最大值）。也可以改成**壓制**：不擲傷害，目標區域的敵人要通過定力檢定，否則不能離開掩體。
- **彈藥**要算。彈種（穿甲、空尖、感官、電磁）是換彈時的選擇。

**傷害類型**精簡成七種（ElondiaRPG 是十三種）：

| 類型 | 被什麼擋 | 備註 |
|---|---|---|
| 動能 | 護甲 | 子彈、鈍器 |
| 利刃 | 護甲（軟甲減半） | |
| 熱能 | 護甲減半 | 燃燒彈、雷射；附帶燃燒 |
| 電磁 | 不看護甲 | 對人傷害低，但讓義體失效數回合 |
| 化學 | 密封裝備 | 持續傷害 |
| 神經 | 不看護甲；敏感度與耐受 | 打的是感載 |
| 資料 | 甲板的防火牆 | 只在網內；打的是完整度。網內的傷害不會讓生命值下降（[CYBERSPACE](CYBERSPACE.md) 第 6 節） |

## 6. 重創

自然 20、或單次傷害超過最大生命值的四分之一時，擲一次重創：指定部位（瞄準時由攻擊者選）出事。

- 肢體：那一邊的義肢失效或斷肢，相關檢定 −4，直到手術。
- 頭：暈眩一回合；義眼或甲板損壞。
- 軀幹：流血（每回合 −2 生命值，直到急救）。
- 橋：感載立刻 +10，下一次過載必定扣人性。

重創是買義體的主要理由之一：斷了的手臂，換一條鉻的比接回去便宜。

## 7. 兩種打法

因為有兩條傷害軌，每場戰鬥開始前有一個隱含的選擇：

| | 實彈 | 神經 |
|---|---|---|
| 打的是 | 生命值 | 感載 |
| 被什麼擋 | 護甲、掩體 | 耐受、膽識、冷卻迴路；護甲沒用 |
| 結果 | 死人、熱度高、有聲音 | 活口、熱度低、安靜；可以審問、綁架、勒索 |
| 弱點 | 重甲目標很難打 | 沒有橋的東西打不動；低人性的敵人感覺遲鈍；過載只停一回合，要有人補上束縛 |

- 敵人被過載後，花 1 點行動點可以**制伏**（上束帶或鎖橋），他就退出戰鬥。
- 案子常常對打法有要求：「不准死人」「要活的」「做得像意外」。

## 8. 戰敗

全隊倒下或過載時，不是直接讀檔，而是依**誰贏了**進入戰敗事件（沿用 ElondiaRPG 的戰敗事件架構）：

| 對手 | 下場 |
|---|---|
| 天使急救會員資格有效 | 被搶救出來，醒在診所。帳單是一大筆債。案子失敗。 |
| 企業保全 | 被捕。審訊（事件鏈），結局是被植入竊聽花後釋放、被要求簽契約抵罪、或同伴來劫囚。 |
| 市警 | 罰金與拘留；熱度高時轉交企業。 |
| 幫派 | 贖金，或被留下來「還債」（依幫派不同：打黑拳、跑腿、被送去歡場） |
| 拆體客 | 最壞的一種：醒來時少了一兩件義體。 |
| 粉蕾絲（在網內過載） | 身體留在原地，等保全來收。等於被企業保全打敗，除非隊友把你拔線帶走。 |

- 戰敗事件的內容受內容篩選控制（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 9 節）。
- 真正的死亡只發生在瀕死豁免失敗三次且沒有急救。存檔規則可以把它改成一律進戰敗事件。

## 9. 女武神機甲

後期內容。規則骨架先定下來。

- 機甲是一個**有自己生命值、護甲與武器的殼**，機師坐在裡面，用「操甲」技能取代槍械與格鬥。
- **同步率**套用同步原則（[CORE_RULES](CORE_RULES.md) 第 5 節），並加一條：機甲受到的傷害，依檔位有 10%／20%／35%／50% 以感載回灌到機師身上。全同步的機甲快得像活的，但機師是在用自己的神經挨打。
- 機師過載 → 機甲停機一回合。打機甲的正解常常不是打穿裝甲，而是**打到機師受不了**：神經武器對機甲本體無效，但電磁武器會讓回灌比例暫時上升；潛網者可以駭進同步鏈路直接灌感載。
- 徒步小隊對上機甲是一場解謎戰：找掩體、斷它的同步、駭它、或者逃。
- 玩家取得機甲的途徑是機師路數的任務線；維修與彈藥極貴，是「帳單是敵人」的頂點。
- 敵方的企業機師多半是契約人，橋權在公司手上——這是可以用竄網或劇情解決的事。

## 10. 畫面

戰鬥不用格子地圖。探索用格子（走到敵人那一格就開打），戰鬥畫面是另一個畫面——沿用 ElondiaRPG「冒險頁的中欄換成戰鬥畫面」的做法，內容重新設計：

```
┌──────────────── 先攻條：這一輪誰先誰後（敵我混排，現實與內海的單位都在上面）────────────────┐
│                                                                                          │
│   敵方      [ 掩體 ]            [ 暴露 ]             [ 近身 ]                              │
│            保全 ×2             保全隊長              ——                                   │
│            ▓▓▓░ 掩體耐久                                                                  │
│  ─────────────────────────── 場景：辦公樓層 · 射程 中 · 掩體 4 ───────────────────────────  │
│   我方      [ 掩體 ]            [ 暴露 ]             [ 近身 ]                              │
│            喬、零（潛入中）       小麥                 ——                                   │
│                                                                                          │
├──────────────────────────────────────────────────────────────────────────────────────────┤
│ 目前行動：喬                                                                              │
│ 生命 ████████░░  感載 ███░░░░░░░  行動點 ◆◆◆◇◇  彈 8/12                                   │
│ [射擊] [連射] [瞄準] [換站位] [換彈] [道具] [招牌能力] [待命] [結束回合]                     │
├──────────────────────────────────────────────────────────────────────────────────────────┤
│ 戰鬥紀錄（擲骰與結果，戰後交給 AI 寫成一段）                                                │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

- **站位是三欄**：掩體、暴露、近身。敵我各一排，單位是欄裡的卡片。換站位就是把卡片移到另一欄。一眼看得出誰露在外面、誰被貼住了。
- **每張卡片上有兩條量條**：紅的生命值、粉的感載。這兩條並排，是這款遊戲戰鬥的招牌畫面——玩家隨時在看「打哪一條比較快」。
- **先攻條**在最上面，敵我混排。潛入中的隊友、網內的蕾絲也在同一條上，用不同的底色。
- **場景條**在中間：這一場的射程段、剩下幾個掩體位、環境（暗、煙、警報中）。控制節點被拿下時，這裡多出可以按的東西（關燈、放防爆門）。
- **行動列**只列現在做得到的事，灰掉的寫明原因（「沒有視線」「RAM 不足」）。招牌能力一顆按鈕展開。
- **雙層戰鬥**時，畫面上方多一個切換：現實／內海。兩邊是同一個版面（網內把生命值換成完整度、掩體換成防火牆節點），共用先攻條。不是兩個小遊戲，是同一場戰鬥的兩個房間。
- **手機版**：三欄改成上下堆疊，一次看一方。
- 戰鬥結束產生一份 `combat` 報告，AI 寫成一段；AI 關閉時顯示戰報。這一點和 ElondiaRPG 完全相同。

實際的版面樣稿之後畫（[ART_STYLE](ART_STYLE.md) 第 6 節）。

## 11. 每條路數在現實的戰鬥裡做什麼

四類路數在現實戰鬥的分量不同（三個領域的總表見 [CORE_RULES](CORE_RULES.md) 6.1 節）：戰鬥型強，潛網者中，社交型弱，媒體型無。

| 路數 | 分量 | 定位 | 招牌能力在戰鬥中 |
|---|---|---|---|
| **槍手** | 強 | 輸出 | 戰鬥直覺：把階數的點數分配到先攻、命中、迴避，戰鬥中可以花行動點重分配。高階：一回合兩次要害判定、壓制不花彈 |
| **機師** | 強 | 重火力、載具 | 同步：駕駛機甲與載具；徒步時可以遙控一台無人機當第五個單位。高階：遠端呼叫機甲的支援火力 |
| **改造師** | 強 | 治療、拆解 | 手術刀：1 點行動點急救（回生命值、止血、救起倒下的人）；對有義體的敵人近身「拆」——讓一件義體失效，高階直接卸下來；戰鬥中替隊友的義體超頻一回合 |
| **潛網者** | 中 | 干擾、開路 | 介面：快駭（[NETRUNNING](NETRUNNING.md) 第 2 節）——致盲、鎖槍、卡關節、接管場景裡的裝置。**在現實裡他是干擾者，不是輸出**：神經類快駭造成的感載不多，要靠隊友收尾；RAM 的量只有網內的一半。目標義體越多，他越有用 |
| **伶人** | 弱 | 開場、單點控制 | 入戲：戴著面具時第一回合敵人不把她當目標；用誘惑對**一個**目標造成感載（不看護甲，但量不大，每回合一次）。她能讓一個人失去戰力，打不了一群 |
| **掮客** | 弱 | 戰前佈置 | 人面：**戰鬥開始前**用掉佈置次數（階數的一半，至少 1）——買通一名敵人（他第一回合不動）、預先藏好的裝備（開場多一個掩體或一件道具）、叫人（名冊上的一個人在第 N 回合到場）。開打之後他沒有招牌能力可用 |
| **主播** | 無 | — | 聚光燈在現實的戰鬥裡不給任何加成。可以用技能開槍、躲、跑，也可以錄影——錄到的東西是編輯台的牌 |
| **偶像** | 無 | — | 應援在現實的戰鬥裡不給任何加成。她的同步是接在網路上的，不是戰場上；親衛隊也不進戰鬥的公式 |

- **媒體型影響現場的唯一途徑是間接的**：在委託副本裡把輿論指標推高，觸發連動——保全被禁止用致命手段、出現內應、門口擠滿圍觀的人（[COMMISSIONS](COMMISSIONS.md) 第 5 節）。偶像動員親衛隊也走這條路：那是輿論面改變了現實面的條件，不是誰在戰鬥中做了什麼。
- **潛網者居中**：他讓敵人變弱、讓場景變有利，但生命值與火力都不如戰鬥型。
- **社交型的效果都發生在開打前或第一回合**。他們的價值是讓這場架變小，甚至不用打；真打起來要靠別人。
- 隊伍帶著主播或偶像打架，等於帶著一個要保護的人。這是刻意的：她們強的地方不在這裡。
