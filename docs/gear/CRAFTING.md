# 組裝：設計圖與零件

> 上層：[GAME_DESIGN](../GAME_DESIGN.md)。依賴：[CYBERWARE](CYBERWARE.md)（部位、沉溺成本、授權鎖、橋的型號）、[CORE_RULES](../systems/CORE_RULES.md) 6.4 節（技能容量）、[LIFE](../world/LIFE.md) 第 3～5 節（合法性、牌子）、[COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md)（武器與護甲的數值）、[CULTURE](../world/CULTURE.md) 第 2 節（獸化改造）。被依賴：[ITEMS](ITEMS.md)（設計圖與零件的目錄）。
> 來源：ElondiaRPG 的裝備「底材 × 材料」與工藝、委託打造、自創配方（[plan/MIGRATION](../plan/MIGRATION.md) H、I 組）。預定資料：`data/rules/blueprints.json`（設計圖）、`parts.json`（零件）、`brands.json`。數字待平衡。

在一座企業把專利看得比人命重的城市，沒有人用廢鐵「搓」出一條義臂或一把槍。這裡不製造東西，只**組裝**：**義體、武器、護甲**都由一個**設計圖**與幾個**零件**構成，零件是買來的、拆來的、訂做的、偷來的——或者養出來的。玩家做的事是挑零件、配零件、把它們裝進設計圖。

## 1. 三層：設計圖、零件、成品

```
設計圖（規格：這是什麼東西、有哪幾個槽、能裝到幾級的零件）
  ＋ 零件 × 數個（每個槽一個）
  ＝ 成品（一件能用的義體、武器或護甲；數值是設計圖與零件合起來的）
```

沿用 ElondiaRPG「底材 × 材料」的組合式設計，換了軸：材料只有一個，零件有好幾個槽。目錄不用寫幾千件成品——寫幾十個設計圖與幾百個零件，組合自己會長出來。

**一套系統管三種裝備。** 同一顆晶片可以裝進橋、裝進義眼、裝進一把智慧手槍；同一層外皮可以包在義臂上，也可以是一件外套的面料。零件是全遊戲共通的貨。

## 2. 零件

每個零件有四個身分：**類型、材質、牌子、等級**，再加一到三條**屬性**（第 5 節）與一個狀態（全新、二手、同人）。

### 2.1 類型

十二種。八種通用，四種專用。

| 零件 | 管什麼 | 主要影響 | 用在 |
|---|---|---|---|
| **晶片** | 運算 | 容量、功能的階數；武器上是智慧功能 | 義體、智慧武器、智慧護甲 |
| **機械神經元** | 和神經的接合 | 同步上限、感載的修正、**沉溺成本**；武器上是神經連結 | 義體、連橋武器 |
| **軟體**（韌體） | 行為 | 功能怎麼分配；授權鎖與後門；槍靈的人格 | 義體、智慧武器 |
| **板材** | 結構 | 護甲值、耐久、重量 | 義體、武器的框體、護甲的插板 |
| **致動器**（人工肌肉） | 出力 | 力量、速度；武器上是後座力補償 | 義體、動力護甲、重武器 |
| **感測器** | 感知 | 感知的範圍與精度；武器上是瞄具 | 義體、武器、護甲 |
| **電源** | 能量 | 續航、超頻的時間、每場的次數 | 義體、能量武器、動力護甲 |
| **外皮**（外裝、面料） | 外觀 | 風格、社交與媒體的加成、防不防掃描 | 義體、服裝、武器的塗裝 |
| **槍管** | 彈道 | 傷害骰、射程、穿甲、準度 | 槍械 |
| **機構** | 擊發與供彈 | 射速（能不能連射）、彈匣量、可靠度 | 槍械 |
| **刃** | 切割與貫穿 | 近戰的傷害與穿甲 | 近戰武器、內藏武器 |
| **纖維** | 織物 | 軟甲的護甲值、重量、活動度 | 服裝與護甲 |

### 2.2 材質：機械與生體

每個零件是**機械**的，或是**生體**的。這是零件的一個屬性，不是另一套系統——同一個槽，可以裝機械件，也可以裝生體件。生體的規則在第 8 節。

| 類型 | 機械件 | 對應的生體件 |
|---|---|---|
| 晶片 | 晶片 | 神經節（培養的神經團） |
| 機械神經元 | 機械神經元 | 活體神經 |
| 軟體 | 韌體 | 基因譜（寫在細胞裡的行為：貓的、狐的、兔的……） |
| 板材 | 合金、陶瓷 | 骨、甲殼 |
| 致動器 | 人工肌肉 | 培養肌 |
| 感測器 | 感測陣列 | 感官（真的耳蝸、真的鬍鬚、真的鼻子） |
| 電源 | 電池 | 代謝腺（吃糖就有電） |
| 外皮 | 合成皮、塗層、布料 | 活皮、毛皮 |
| 槍管、機構 | 金屬 | 沒有生體版 |
| 刃 | 鋼、單分子刃 | 爪、牙、骨刺 |
| 纖維 | 防彈纖維 | 蛛絲織物（活的，會自己補） |

### 2.3 等級與狀態

見第 4 節。

## 3. 設計圖

設計圖是一件裝備的規格：零件怎麼組合。它不是實物，是一份你「會做」的東西。每個設計圖寫明它**一定要哪些零件**、**可以加哪些零件**。設計圖自己也有牌子、等級與材質。

### 3.2 武器

| 設計圖 | 必要的零件 | 選配 | 備註 |
|---|---|---|---|
| 手槍 | 槍管 ＋ 機構 ＋ 板材（握把框） | 感測器（瞄具）；外皮（塗裝）；智慧套件 | 智慧套件＝晶片＋軟體 |
| 衝鋒槍 | 槍管 ＋ 機構 ＋ 板材 | 同上；致動器（後座力補償） | |
| 霰彈槍 | 槍管 ＋ 機構 ＋ 板材 | 同上 | |
| 步槍 | 槍管 ＋ 機構 ＋ 板材 | 感測器；致動器；智慧套件；神經連結 | 神經連結＝機械神經元 |
| 狙擊槍 | 槍管 ＋ 機構 ＋ 板材 ＋ **感測器** | 致動器；智慧套件；神經連結 | 瞄具是必要的 |
| 重武器 | 槍管 ＋ 機構 ＋ 板材 ×2 ＋ 致動器 | 電源；感測器 | 沒有致動器扛不動 |
| 能量武器 | 槍管 ＋ **電源** ＋ 晶片 ＋ 板材 | 感測器 | 沒有機構：沒有子彈 |
| 感官彈槍 | 槍管 ＋ 機構 ＋ **晶片** | 感測器 | 神經武器。晶片決定打出去的是什麼感覺 |
| 電擊器、電擊鞭 | **電源** ＋ 晶片 ＋ 板材 | 致動器 | 神經武器 |
| 刀、劍 | 刃 ＋ 板材（柄） | 外皮；電源（單分子刃要通電） | |
| 鈍器 | 板材 ×2 | 致動器；電源 | |
| 無人機 | 晶片 ＋ 軟體 ＋ 致動器 ＋ 電源 ＋ 感測器 | 槍管＋機構（武裝）；板材 | 機師與潛網者的 |

- **智慧套件**（晶片＋軟體）讓一把槍變成智慧武器：命中 +、自動管彈、可以被駭。崑崙的軟體帶槍靈——**槍靈是裝在槍裡的一個軟體零件**，可以拆下來換到另一把槍上，它會記得。
- **神經連結**（機械神經元）讓武器接上橋：先攻 +、瞄準的加值從 +3 變成 +4；代價是武器被擊中或被駭時，回灌打在你的感載上。
- 沒有電子零件的槍（星旗的作風）不能被駭，也沒有任何智慧功能。這從「牌子的脾氣」變成了零件層級的選擇：**你自己決定要不要在槍裡放一顆晶片**。

### 3.3 護甲與服裝

| 設計圖 | 必要的零件 | 選配 | 備註 |
|---|---|---|---|
| 一般服裝（上身、下身、外套） | 纖維 ＋ 外皮（面料） | 板材（暗袋裡的插板） | 外皮決定風格與曝露度 |
| 防彈衣 | 纖維 ＋ 板材 | 外皮；感測器 | |
| 戰術護甲 | 纖維 ＋ 板材 ×2 | 外皮；感測器；晶片 | |
| 重甲 | 板材 ×3 ＋ 纖維 | 致動器 ＋ 電源（動力化）；晶片；感測器 | 沒有動力的重甲很重 |
| 裝甲制服（女僕服、執事服、高訂） | 纖維 ＋ 外皮 ＋ 板材 | 內藏槽（刃、槍套） | 護甲藏在看不出來的地方；纖維與外皮都要 III 級以上才壓得住 |
| 頭部（帽、盔、面具） | 板材 或 纖維 | 感測器；外皮；晶片 | |
| 密封服 | 纖維 ＋ 外皮 ＋ 電源 | 板材 | 擋毒與環境（狀態） |

- 內衣、內褲、鞋、飾品是現成的單件，不組裝。欄位的完整清單、外層蓋住內層、藏匿與掃描見 [EQUIPMENT](EQUIPMENT.md)。
- **護甲、隱匿、風格三選二**（[COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 第 4 節）現在是零件的取捨：板材給護甲、加重量、壞風格；好的外皮給風格、不擋子彈；高級的纖維兩邊都顧一點，貴。
- 外皮是服裝上最重要的零件：**同一件外套的剪裁，換一塊面料，從街頭變成高訂**。風格標籤、曝露度、社交與媒體的親和都從它來。

### 3.4 設計圖的規則

- 選配的槽空著也能用。裝了，多一份屬性，也多一份重量、沉溺成本（義體）或被駭的面。
- **設計圖的等級是零件等級的上限**（第 4 節）。
- **設計圖指定每個槽收哪種材質**：只收機械、只收生體、或兩者都收。這是設計圖的一部分，不是玩家臨時決定的。

  | 槽的材質 | 意思 | 例 |
  |---|---|---|
  | 機械 | 只能裝機械件 | 星旗的軍規義臂：全部的槽都是機械 |
  | 生體 | 只能裝生體件 | 蜜腺的「天然獸耳」：全部的槽都是生體；它因此掃描不到、不被駭 |
  | 皆可 | 兩種都能裝 | 同人社團的通用獸耳：每個槽皆可，機械與生體可以混裝（8.4 節） |

  - 同一張設計圖可以每個槽不一樣：一條「活皮義臂」的板材與致動器限機械，外皮與神經元限生體。
  - 所以**「純生體」「純機械」「混裝」是三種設計圖，不是一種設計圖的三種裝法**。企業的設計圖多半限定材質（也限定牌子，第 6 節）；同人與黑市的設計圖多半皆可，但等級低。
  - 生體的特性（不被駭、掃不到、沉溺成本低）要**所有帶電子功能的槽都是生體**才成立；混裝的只拿到一部分（8.4 節）。
- 設計圖決定外形與基礎數值、槽的數量、對零件牌子的挑剔程度（第 6 節）。
- 設計圖不是實物。企業的設計圖要買授權、偷、或把一件成品完整拆解後畫出來（第 11 節）。

## 4. 等級

**同一個牌子的東西有強弱之分。** 設計圖與零件都分五級。全部的裝備只有這一套等級。

| 等級 | 街上的叫法 | 合法性（[LIFE](../world/LIFE.md) 第 3 節） | 零件價格的量級 |
|---|---|---|---|
| **I** | 入門 | 自由 | 100～300 |
| **II** | 標準 | 自由或登記 | 300～900 |
| **III** | 專業（制式） | 許可 | 1,000～3,000 |
| **IV** | 軍規 | 違禁 | 4,000～12,000 |
| **V** | 原型 | 不在市面上 | 不賣 |

- 緋櫻的義臂有 I 到 V 五個等級，名字不同（緋櫻習慣用花名：一分咲、三分咲、五分咲、滿開、散華），外形一脈相承，數值與槽數逐級上去。星旗的步槍同理（M1 到 M5）。
- **設計圖的等級是零件等級的上限**：III 級的設計圖最多裝 III 級的零件。
- **超規**：改造師可以硬把高一級的零件塞進去（義體學或機械的檢定）。成功了，成品超出規格；失敗了，零件燒掉，或成品帶一個瑕疵。原廠絕不做這件事，同人社團天天在做。
- **成品的等級**＝設計圖的等級，但實際的強弱看裡面的零件。「先弄到高級的設計圖，零件慢慢換」是一條成長的路。
- **合法性看最高的那個零件**：一把 II 級的手槍裝了一根 IV 級的槍管，被掃到時算違禁。
- 等級之外還有**狀態**：

| 狀態 | 意思 |
|---|---|
| 全新 | 照規格 |
| 二手 | 便宜四到七成。可能有**瑕疵**；義體件可能有**殘響**（[CYBERWARE](CYBERWARE.md) 第 5 節）；不在任何登記上 |
| 同人 | 社團自製或魔改。帶一個**怪癖**（好壞都有）；沒有保固 |
| 活的 | 生體件專用（第 8 節）：會長、會病、不能二手 |

## 5. 零件的屬性

每個零件帶**一到三條屬性**，成品的特色從這裡來。

### 5.1 數值

直接加在成品上的數字：護甲、傷害、射程、出力、感知、RAM、續航、同步上限、重量、沉溺成本的增減。

### 5.2 親和

對四類技能（[CORE_RULES](../systems/CORE_RULES.md) 6.4 節）的加成：**現實、內海、社交、媒體**。

| 裝在哪 | 親和的效果 |
|---|---|
| **橋**的零件 | 那一類的**技能容量** +N |
| 其他義體、武器、護甲的零件 | 那一類技能的**效果**略增；相關基本功的檢定 +（外皮的社交親和加在交涉與誘惑上，瞄具的現實親和加在槍械上） |

| 零件 | 屬性 |
|---|---|
| 外皮「瓷肌」（緋櫻，機械，III） | 風格 +2；**社交 +1、媒體 +1**。它就是好看 |
| 外皮「消光」（星旗，機械，II） | 防掃描；現實 +1；風格 −1 |
| 外皮「雪貂」（蜜腺，生體，III） | 真的毛皮。風格 +2；社交 +2、媒體 +1；掃描不到；要梳 |
| 機械神經元「絹」（伊甸園，III） | 社交 +2；感載的受傷倍率 +10% |
| 晶片「算盤」（崑崙，II） | 內海 +1；資料回傳 |
| 軟體「播報員」（萬華鏡，III） | 媒體 +2；內建錄影 |
| 槍管「長舌」（星旗，II） | 射程 +1 段；準度 −1 |
| 塗裝「櫻吹雪」（緋櫻，外皮，II） | 風格 +1；媒體 +1：這把槍很上鏡 |
| 板材「白鐵」（星旗，I） | 護甲 +1。沒有別的 |

**好看的外皮提高社交與媒體**，是這套系統最直觀的例子：同一條義臂、同一件外套、同一把槍，換一層皮，從打手的變成偶像的。

### 5.3 全能型

有些零件四類都加——「現實、內海、社交、媒體各 +1」。它們存在，但有代價：貴（同等級的三到五倍）；數值類的屬性平庸；多半是蜜腺的或高級訂製的同人件。「兼顧」是一種買得到的選擇，不是預設；專精的零件永遠在它那一類比全能的強。

### 5.4 特性

不是數字的屬性：靜音、防水、自我修復、防掃描、內建錄影、回報後門、授權鎖、殘響、怪癖。雙面效應（[CYBERWARE](CYBERWARE.md) 第 3 節）在零件層級體現：**每個有分量的好處，同一個零件上通常掛著一個代價**。

### 5.5 裝備的強度預算

戰鬥的基準定了之後（[COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 1.1 節），裝備能加多少要有上限，不然打倒一個雜兵會從四下變成一下。這一節用和技能、特質同一把尺：**一格**＝命中 +1，或迴避 +1，或一類檢定 +2，或傷害多半顆骰，或護甲 +1。

**設計圖決定「型」，零件決定「多好」。**

| 由設計圖決定，不隨等級改變 | 由零件決定 |
|---|---|
| 武器：基礎的傷害骰、適用距離、彈匣容量、遮蔽倍率、傷害類型 | 多出來的傷害、命中、穿甲、彈匣 +1、特性 |
| 護甲：基礎的護甲值、重量級、蓋住哪些欄位 | 多出來的護甲、減輕重量、風格與曝露度 |
| 義體：裝在哪個部位、做什麼、基礎的沉溺成本 | 效果的大小、親和、特性 |

**每個零件的份量看它的等級：**

| 零件等級 | 份量 | 可以帶的屬性條數 |
|---|---|---|
| I | 0.5 格 | 1 |
| II | 1 格 | 1～2 |
| III | 1.5 格 | 2 |
| IV | 2 格 | 2～3 |
| V | 3 格 | 3 |

- **I、II 級的板材與纖維，護甲最多 +1**；+2 從 III 級起。這讓護甲的量級留在 [COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 第 4 節的範圍裡。
- **槍管的等級骰**（[COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 第 5 節）：決定傷害的零件（槍管、刃；電擊器與能量武器是電源）是 III 級時，武器的傷害骰 +1 顆，IV 級 +2 顆，V 級 +3 顆。設計圖的基礎骰照舊不隨等級變，這幾顆也不算在零件的份量裡。
- **帶一個代價，可以多拿半格到一格**（雙面效應）。例如槍管「長舌」：射程 +1 段是 1 格，準度 −1 退 1 格，所以它雖然是 II 級，還可以再帶一條。
- 二手的瑕疵、同人的怪癖照同樣的方式算。

**每種零件能帶什麼**（生成零件時只能從這裡挑）：

| 零件 | 能帶的數值 |
|---|---|
| 槍管 | 傷害、適用距離、穿甲、遮蔽倍率 |
| 機構 | 彈匣容量、連射的壓制、換彈 |
| 刃 | 傷害、穿甲、傷害類型（通電是電磁、加熱是熱能） |
| 板材 | 護甲、重量 |
| 纖維 | 護甲（少量）、重量、隱匿 |
| 外皮 | 風格、曝露度、社交與媒體的親和、防掃描 |
| 感測器 | 命中、先攻、感知類檢定 |
| 致動器 | 體格類檢定、負重、後座力（連射的命中） |
| 電源 | 續航、出力（能量武器的傷害、動力甲的負重） |
| 晶片、軟體 | 內海的親和、RAM、智慧功能、可以被駭 |
| 機械神經元、活體神經 | 同步上限、感載上限、承受層數、四類親和 |

**等級之間的差距要大**：頂級裝備和入門裝備的差距要明顯，不是只多幾成。敵人也分等級 I～V（[ENEMIES](../systems/ENEMIES.md) 1.1 節），裝備的等級就是用來對上敵人的等級的。實際差多少照 [BALANCE](../systems/BALANCE.md) 第 2 節：戰鬥的數字每級約 ×1.22，錢每級約 ×3.2，零件的份量就是 BALANCE 2.1 節與 2.10 節的那一列；同級的裝備打同級的敵人，手感每一級都一樣，高一級的敵人掉兩倍的血（BALANCE 第 4 節的跨級表）。

另外有兩條：

- **裝備幾乎不給節奏類的資源**：行動點、每回合的 RAM 回復、每回合的編輯點，只有 IV 級以上的特定零件可以各 +1，全身合計最多 +1。反射加速器的行動點 +1 算在這個額度裡（[CYBERWARE](CYBERWARE.md) 第 4 節）。機甲是每場一次的大招，是明寫的例外（[COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 9.3 節）。
  - **反射加速器是明寫的例外**：它的行動點 +1 等級不限（II、III 級的也有），但一樣算在全身合計 +1 的額度裡。
  - **這個「全身合計最多 +1」管的是什麼**：所有穿戴、植入與吃下去的東西，也就是零件、義體（含反射加速器）、構裝、藥（含興奮劑）。這些加起來，每回合回復的行動點最多 +1；RAM 回復與編輯點也各自最多 +1。
  - **不算在這個額度裡的**：屬性算出來的行動點上限、招牌技能與五階技能的效果、全檔同步的 +1、機甲（每場一次的大招）、掮客讓出來的行動點（那是從他身上轉過來的，不是多出來的）。
- **敵人的裝備照牠的等級**：I 級的敵人用 I 級的東西，V 級的用 IV～V 級的。位階高的在同一級裡拿比較好的那一端。

**構裝**（內海的程式，不用零件組）直接分五級，一個構裝的份量等於「同等級的一整件武器或護甲」，武器構裝照構裝的等級給同樣的等級骰（BALANCE 2.3 節）。

**價格**：成品的價錢＝設計圖的價錢＋所有零件的價錢。零件的價格量級照第 4 節的表。

## 6. 牌子與相容

零件與設計圖都有牌子，脾氣照 [LIFE](../world/LIFE.md) 5.1、5.2 節。

| 情況 | 結果 |
|---|---|
| **原廠全套**（設計圖與所有零件同一個牌子） | 套裝加成（緋櫻：同步回灌 −10%、要害 +；星旗：不卡彈、耐久 +；織女：維修費減半；崑崙：槍靈的全部功能）；但授權鎖與後門也是全套的 |
| **混搭** | 沒有套裝加成。每多一個牌子，組裝的難度 +1 |
| **挑剔的設計圖** | 有些設計圖只認自家的軟體或晶片（緋櫻、伊甸園、崑崙的智慧槍）。要裝別家的，得先破解 |
| **排異** | 組裝檢定失敗，或硬裝不相容的零件：成品帶一個瑕疵；義體的沉溺成本上升 |
| **機械與生體混裝** | 見第 8.4 節 |

- 織女的東西最不挑，什麼都能配——混搭的基底。
- **拔掉後門的標準做法**：留著夜鶯的晶片，把軟體換成同人的。

## 7. 邊緣橋

橋是最重要的一次組裝，因為它決定四類技能的容量。

| 零件 | 在橋上決定什麼 |
|---|---|
| **晶片** | **總容量**。等級越高越多（I 40、II 46、III 52、IV 58、V 64，各牌 ±4） |
| **軟體** | **怎麼分**。每套軟體是一個配分：均衡、偏現實、偏內海、偏社交、偏媒體，以及各種折衷 |
| **機械神經元** | 同步檔位的上限、感載的修正、沉溺成本、橋參數的修正 |
| 外皮（選配） | 親和：多半是社交與媒體 |

- [CYBERWARE](CYBERWARE.md) 第 7 節那十個型號是**原廠的組合**。換零件就是改型號。
- **每一類最低 8** 的底線寫在軟體的規格裡：沒有任何軟體能把一類分到 8 以下。
- 橋的組裝是最難的（難度比其他裝備高一級），失敗的代價也最重。
- 橋可以用生體件——那就是蜜腺的原型橋（第 8.5 節）。

## 8. 生體

貓耳有兩種。一種是裝上去的，一種是**長出來的**。

生體科技不是另一套系統，而是**零件的另一種材質**，而且**寫在設計圖裡**——設計圖指定每個槽收機械、收生體、或皆可（3.4 節）。每種通用零件都有生體的對應物（2.2 節），裝進同樣的槽。一對天然的貓耳，和一對機械的貓耳，是**同一個設計圖規格**（感測器＋神經元＋外皮），裝的是不同材質的零件：

| 槽 | 機械的貓耳 | 天然的貓耳 |
|---|---|---|
| 感測器 | 指向收音陣列 | 培養的貓系耳蝸 |
| 神經元 | 機械神經元 | 活體神經 |
| 外皮 | 合成絨毛 | 真的毛皮 |
| 致動器（選配） | 微型馬達 | 耳肌 |
| 軟體（選配） | 情緒連動韌體 | 貓系基因譜 |

差別全在材質的規則。

### 8.1 生體件和機械件哪裡不同

| | 機械 | 生體 |
|---|---|---|
| 怎麼來 | 買、拆、訂做 | **培養**：下單、等它長。或者從活的東西身上移植 |
| 安裝 | 手術，裝上就能用 | 手術之後要**長合**：幾天到幾週。這段時間功能不全 |
| 沉溺成本 | 有 | **極低或沒有**。身體認得它是自己的 |
| 被駭 | 會（有電子零件的） | **不會**。沒有東西可以駭 |
| 被掃描 | 掃得出來 | **掃不出來**。法律上不算義體，合法性一律自由 |
| 壞了 | 要修、要換零件 | **自己會好**（慢）；但會生病、會感染、會排斥 |
| 維持 | 保養、訂閱 | **要養**：每週的營養劑與免疫調節（蜜腺賣的），加進每週帳單。斷了會萎縮 |
| 升級 | 換更高級的零件 | **會成長**（8.3 節） |
| 拆下來 | 可以，零件還在 | **拆了就死**，除非立刻移植。不能二手、不能囤 |
| 峰值 | 高 | 同等級的數值約低一級。出力、容量、護甲都比不上金屬 |
| 感覺 | 準 | **細**。感知類更靈；觸感是真的 |
| 親和 | 看零件 | 天生偏**社交與媒體**：真的體溫、真的毛、真的反應 |
| 感載 | 看神經元 | 活的神經更敏感：受到的感載略增 |

一句話：**機械是買的，生體是養的。** 機械強、快、可換、有沉溺成本、會被駭；生體弱一點、慢、不可逆、幾乎不增加沉溺、沒人駭得進去。

### 8.2 等級與來源

- 生體件同樣分 I～V 級，指的是培養的世代與純度。
- **蜜腺生技**幾乎獨佔。正規的生體件從蜜腺療養院與玻璃岸的診所下單，等一到四週。
- **車庫生技**：同人眾裡做生體的社團。便宜、快、什麼都敢做；狀態是同人，怪癖可能是**變異**（多長了一點什麼）。
- **移植**：從活體取下的生體件可以直接移植。這是拆體客另一門更黑的生意，也是生體件唯一的「二手」來源——時效以小時計。
- 生體件的價格約是同級機械件的兩倍，加上每週的維持費。所以生體派在世界裡是有錢人的選擇（[CULTURE](../world/CULTURE.md) 第 2 節）。

### 8.3 成長

機械的東西出廠是幾級就是幾級。生體的東西**會長**。

- 每個生體件有**成熟度**。裝著、用著、養著，它慢慢累積；滿了升一級，直到設計圖的等級上限。
- 怎麼累積：用它（獸耳用來聽、培養肌用來出力）、每週的營養劑、好的生活（睡得好、吃真的食物）。
- 怎麼倒退：斷營養劑、重傷、感染、長期高感載、戰鬥藥。
- 升級時有機率長出一條新的屬性——可能是你要的，可能不是。高級的營養劑能引導方向。
- 所以生體派的成長是**時間**，機械派的成長是**錢**。兩條路都通到 IV 級；V 級的生體件只有蜜腺的實驗室裡有。

### 8.4 混裝

同一個設計圖裡，機械件與生體件可以混裝，但它們不太願意待在一起。

| 組合 | 結果 |
|---|---|
| **全機械** | 第 6 節的規則 |
| **全生體** | 「活的」加成：沉溺成本歸零、自癒加快、掃描不到、親和（社交、媒體）各 +1；感載的受傷倍率 +10% |
| **混裝** | 每一個「機械接生體」的接面，組裝難度 +1，並且需要一個過渡件（通常是機械神經元當轉接）。成品不算全生體：掃得出來、有沉溺成本（但比全機械低） |
| 生體的設計圖裝機械件 | 可以，但那個機械件掃得出來，而且會讓這件生體的成熟度長得慢 |

最常見的混裝：**機械的骨架與致動器，生體的皮與神經**——外表與觸感是真的，力氣是機器的。高級人偶與偶像的標準做法。

### 8.5 獸化改造

把上面的規則套在 [CULTURE](../world/CULTURE.md) 第 2 節的兩派上：

| | 機械派 | 生體派 |
|---|---|---|
| 設計圖 | 機械的耳、尾、爪 | 生體的耳、尾、爪 |
| 「哪一系」由什麼決定 | 設計圖的外形＋情緒連動韌體 | **基因譜**（軟體槽的生體件）：貓、狐、兔、犬…… |
| 系的特色 | 感測器的型號：貓系偏高頻與夜視、狐系偏範圍、兔系偏遠距、犬系偏追蹤（配嗅覺） | 同上，由譜帶出來；而且會隨成熟度長得更像 |
| 情緒外洩（耳朵與尾巴藏不住心情） | 有。可以裝抑制器鎖住 | 有，而且**鎖不住**——它是真的反射。要靠定力 |
| 誰在用 | 街頭、潛網者、野良 | 有錢人、偶像、高級人偶 |

- **基因譜**是獸化的核心零件：它是「軟體」的生體版，決定這對耳朵是哪一系、有哪些本能（聽到高頻會轉向、緊張時尾巴會炸毛）。換譜等於換一種動物，但要等它重新長。
- **全身獸化**（耳、尾、爪、毛皮都是同一系的生體件）有系的套裝加成：貓系的落地與夜行、狐系的察覺、兔系的跳躍、犬系的追蹤。這是野良裡最資深的那些人的樣子——以及他們付不起營養劑時的處境。
- 天然的獸耳在掃描器前是**人的一部分**。冠冕區的門禁攔不住它，但雇主的眼睛看得見。

### 8.6 生體的武器與護甲

- **爪、牙、骨刺**是刃的生體件，裝在義臂的內藏槽或「爪」的設計圖裡。掃描不到——進得了任何不准帶武器的地方。
- **蛛絲織物**是纖維的生體件：輕、會自己補破洞、要保濕。蜜腺的高級防護服用它。
- **活皮革**是外皮的生體件，用在服裝上：風格極高，會老。
- 槍管與機構沒有生體版。這個世界沒有「長出來的槍」——至少牆內沒有。

### 8.7 生體的橋

邊緣橋也可以用生體件：活體神經當神經元、神經節當晶片。

- 活體神經的橋沉溺成本最低、同步最順。
- **神經節的容量比同級的晶片少**（約低兩級）。純生體的橋裝不了多少技能。
- 所以實務上的做法是**機械的晶片＋活體的神經**——這就是蜜腺原型橋（[CYBERWARE](CYBERWARE.md) 第 7 節）四類各 15、沉溺成本最低、要長期用藥的由來。
- 純生體的橋有一個別人沒有的特性：**沒有熔斷器可以裝**（[CYBERSPACE](../systems/CYBERSPACE.md) 第 6 節）。它不是違禁品，因為法律沒想過這種東西。這是一條任務線的種子。

| 來源 | 拿得到什麼 | 備註 |
|---|---|---|
| **正規商店**（刀巷、電器街、槍店、裁縫） | I～II 級，全新；III 級要許可 | 會登記 |

| **黑市**（舊港夜市碼頭；網內的蚌殼市，[CYBERSPACE](../systems/CYBERSPACE.md) 第 3 節） | III～IV 級；來路不明的 | 貴；可能有後門、有追蹤器 |
| **蜜腺的診所** | 生體件，下單培養 | 要等；每週維持費 |
| **車庫生技** | 同人的生體件 | 可能變異 |
| **拆解** | 從自己的舊裝備、戰利品、撿到的東西拆出來 | 第 10 節 |
| **骨場** | 隨機的二手零件 | 每天不同；要挖 |
| **拆體客** | 二手的義體零件；移植用的生體件 | 有殘響；你知道它們怎麼來的 |
| **委託的戰利品與報酬** | III～IV 級 | 軍規主要從這裡來 |
| **訂做** | 指定屬性的零件 | 找同人社團或固定 NPC；要等、要交情 |
| **特殊任務、流竄 AI** | V 級原型 | V 級只從這兩個地方來；每一個都有名字 |

玩家**不能從原料做出零件**。訂做是請別人做——這個世界裡做零件需要一座工廠、一間培養室，或一個瘋子。

## 10. 組裝、安裝與拆解

### 10.1 組裝

- **在哪裡**：有工作台的據點（二級以上）、診所、槍店、同人社團的攤位。
- **誰來做**：

| 誰 | 品質 | 代價 |
|---|---|---|
| 自己或夥伴 | 技術的檢定——義體用義體學，武器與護甲用機械，生體件用醫療 | 免費；失敗有後果 |
| 診所、槍店、裁縫 | 穩定的成功 | 工錢；會登記；不做超規、不碰授權鎖 |
| 同人社團 | 成功率高，願意超規與魔改 | 便宜；成品可能多一個怪癖 |
| 原廠 | 完美 | 貴；只裝原廠全套 |

- **難度**＝設計圖的等級 ＋ 牌子數量的修正 ＋ 機械與生體接面的修正 ＋ 超規的修正。
- **結果**：

| 成功程度 | 成品 |
|---|---|
| 大成功 | **精工**：一項屬性多一點，或沉溺成本少一點 |
| 成功 | 照規格 |
| 失敗 | 能用，帶一個瑕疵 |
| 大失敗 | 燒掉一個零件（隨機，或超規的那一個） |

- 組裝前可以**預覽**：介面顯示成品的全部數值、四類親和、重量、合法性、難度；義體另外顯示沉溺成本。這個畫面是組裝的核心——玩家在這裡來回換零件，看數字怎麼動。

### 10.2 安裝

- **武器與護甲**組好就能用。
- **義體**裝到身上是手術，照 [CYBERWARE](CYBERWARE.md) 第 2 節：沉溺成本、休養、併發症的機率。可以先組好放著，可以組好拿去賣。
- **生體的義體**手術之後還要長合。

### 10.3 換零件

裝備可以**只換其中一個零件**，不用整件重來。這是日常的升級方式：這個月換一根好一點的槍管，下個月換一層皮。武器與護甲在工作台上換；身上的義體是小手術；橋的零件每一次都是大手術；生體件換了就是重新養。

所謂的改裝，就是換選配槽裡的零件。

### 10.4 拆解

- 每個零件有機率完好拆下；失敗的零件降一級或報廢。
- **有授權鎖的東西要先解鎖**，不然一拆就鎖死或回報。
- **戰利品**：敵人的武器與護甲可以整件撿走，也可以拆成零件帶走（輕）。敵人身上的義體要改造師拆。這是 III 級以上零件的重要來源——也是拆體客在做的事。行規與沉溺對此有話說（[LIFE](../world/LIFE.md) 第 9 節）：拆死人的是一回事，拆活人的是另一回事。
- 拆下來的零件是二手的。生體件拆下來要立刻移植，否則報廢。

## 11. 設計圖與訂做

- **取得設計圖**（沿用 ElondiaRPG 的圖紙）：設計圖有三個來源——買授權、偷、把一件成品完整拆解後畫出來。有了它，可以自己組，或請同人社團照著組——企業不賣給你的東西，這樣弄到手。
- **訂做零件**（沿用 ElondiaRPG 的自創配方）：向社團或固定 NPC 指定「我要一層社交 +2 的外皮，三級」。對方報價、開條件、要時間。AI 開著時可以用文字描述想要的零件，AI 設計屬性，程式把數值夾在那個等級允許的範圍內。產物一律是同人狀態。
- **玩家自己的社團**：據點是同人社團店面時（[FIXER](../systems/FIXER.md) 第 9 節），可以接別人的組裝與訂做委託，在同人夜市擺攤賣自己組的成品。

## 15. 機甲與載具的整備

> 機甲的型號、價格與掛點在 [ITEMS](ITEMS.md) 第 14 節；戰鬥中的規則在 [COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 9.3 節。這一節管戰鬥之外：壞了怎麼修、每週要付多少、怎麼換裝。整套放在一個整備畫面裡（15.7 節）。

機甲不走組裝，但會吃零件。機體耐久打掉了不會自己回來，要花錢、花時間、花板材修；修不起的機甲下一場就帶著傷上場。機甲是「帳單是敵人」的頂點，這一節的數字照這句話定。

機師的預備技能「整備」（[SKILL_TREES](../content/SKILL_TREES.md) 機師）是進副本前的臨時加值，和這一節的修理分開算。

### 15.1 戰後的狀態

機體耐久在戰鬥之間**不會回復**。下一場啟動時，機甲從上一場剩下的耐久開始。

| 狀態 | 機體耐久 | 效果 |
|---|---|---|
| 完好 | 滿 | — |
| 受損 | 一半以上，沒滿 | 下一場從剩下的耐久開始 |
| 重損 | 不到一半 | 同上，而且持續的回合數 −1 |
| 損毀 | 0 | 啟動不了，要大修（15.3 節）。損毀的那一刻機師感載 +15（COMBAT 9.3 節），掛點上的武器隨機壞一件 |

- **核心不會壞**。機體再爛，同步核心都拆得出來；最壞的情況是換一副骨架。
- 戰敗時機甲落在敵人手上的，照戰敗事件（[ENEMIES](../systems/ENEMIES.md) 第 6 節）：拆體客的戰敗事件（`stripped`）會拆走一件掛點的武器，其他的戰敗事件不另外罰。
- 板槽與輔助槽的零件不會因為受損而壞，只有怪癖（試作零號）會燒掉。

### 15.2 修理費與每週的整備費

```
每點耐久的修理費 = 等級基準 × 0.08 × 修理係數        （等級基準 I 150、II 500、III 1,600、IV 6,000；V 照 19,000 算）
每週的整備費     = 那一級每週的固定開銷 × 0.25 × 修理係數    （LIFE 1.3 節）
```

| 級 | 每點耐久 | 修滿一具（大約） | 對照：一件中型委託的個人收入 | 每週的整備費 |
|---|---|---|---|---|
| I | 12 | 40 點，480 | 400 | 60 |
| II | 40 | 45 點，1,800 | 1,200 | 180 |
| III | 130 | 50 點，6,500 | 4,000 | 600 |
| IV | 480 | 65 點，31,200 | 13,000 | 1,950 |
| V | 1,500 | 80 點，120,000 | 40,000 | 6,250 |

**修理係數**照骨架的牌子：

| 牌子 | 修理係數 | 為什麼 |
|---|---|---|
| 星旗 | ×0.7 | 修得起，零件在蜂巢東側買得到 |
| 同人 | ×0.7 | 便宜，但每一件都有怪癖 |
| 織女 | ×0.9 | 到處有零件 |
| 鉻娘子改 | ×1.0 | 熔爐的人看得懂它 |
| 崑崙 | ×1.1 | 另外有器靈的訂閱 |
| 黑泉 | ×1.3 | 零件只有黑泉的人有 |
| 緋櫻 | ×1.5 | 授權鎖；戰姬機的零件只能偷或拆 |

- 機師線讓雲雀降落的（[QUESTS](../content/QUESTS.md) 機師「再開一次」③），修理費永遠再 ×0.9。
- **崑崙的器靈訂閱**另外算：每週付骨架價的 3%，和義體的訂閱一樣（[CYBERWARE](CYBERWARE.md) 的訂閱）。
- **整備費沒付**：每欠一週，機體耐久的上限 −5，最多 −15。補付之後上限回來。整備費在週一和其他帳單一起結算（[FIXER](../systems/FIXER.md) 第 4 節）。

### 15.3 修理與大修

**在哪裡修：**

| 地方 | 能做什麼 | 錢 | 時間 | 檢定 |
|---|---|---|---|---|
| 野外，或副本的兩個階段之間 | **緊急處理**：回 10 點耐久。每次休息一次；損毀的修不了 | 一件板材 | 1 小時 | 機械，DC 10＋骨架的級 × 2；要機械工具組（第 6 節的工具加值照算） |
| 自己的整備架 | 修理、大修、換裝、升級 | 修理費 ×0.5（只付材料）＋零件 | 每 20 點 8 小時 | 機械，DC 同上。失敗多花 8 小時，零件照扣 |
| 修車廠與整備坑 | 同上，不用擲 | 修理費 ×1＋零件（店裡可以代買，照目錄價） | 每 20 點 4 小時 | — |
| 原廠的整備庫 | 只修原廠全套、而且登記在案的機甲 | 修理費 ×1.5，零件包在裡面 | 每 20 點 2 小時 | —；會登記。偷來或拆過授權鎖的進不去 |

- **整備架**是一件家具：工作台（機甲），C$12,000，薔薇驛與熔爐買得到。要放在標成「車庫」的房間裡（[DOWNTIME](../systems/DOWNTIME.md) 7.4、7.5 節）；哪些住處有放得下機甲的房間寫在 DOWNTIME 7.2 節，例如薔薇驛的車庫。
- **修車廠與整備坑**：舊港碼頭邊真白的車廠、鏽帶卡麥隆的修車廠、機甲墳場的整備坑、熔爐（鉻娘子改與同人的修得最好）；孤星連在蜂巢東側只修星旗的。
- **一次修理吃的零件**：每修 20 點（不滿 20 也算一次）用掉一件板材，等級至少是骨架的級減一。有授權鎖的骨架只吃同牌子的零件。

**大修**：損毀的機甲，以及剛買來的骨架，都要大修一次才能啟動。

| 項目 | 內容 |
|---|---|
| 錢 | 修滿的修理費 × 2（自己修照 ×0.5 的規則減半） |
| 零件 | 致動器、電源、機械神經元各一件，等級至少是骨架的級減一；修滿要的板材另外照上面算 |
| 壞掉的武器 | 損毀時壞的那一件，修理費是那件武器價的 20% |
| 時間 | 修車廠 3 天；自己修 7 天 |
| 換骨架 | 核心接到新的骨架上：同步檢定，DC 10＋骨架的級 × 2。失敗的話那一天不能再試 |

**機甲殘件**：敵方的機甲掉的是殘件（[ENEMIES](../systems/ENEMIES.md) 11.4 節），級跟著那具機甲。大修時一件殘件可以抵兩件零件（致動器、電源、機械神經元、板材任選）。也可以賣：骨架價 × 0.5，只有黑市、熔爐與墳場的拾荒者營地收。違禁。

### 15.4 換裝與升級

每一具機甲有三種槽，數量寫在 [ITEMS](ITEMS.md) 14.2 節的「掛點」欄。

| 槽 | 放什麼 | 效果 |
|---|---|---|
| 武器掛點 | [ITEMS](ITEMS.md) 14.4 節的機甲武器，一件一格 | 啟動期間能用的武器。第一個掛點是主武器，第二個是副武器 |
| 板槽 | 板材（[ITEMS](ITEMS.md) 2.4 節），一件一格 | 機體耐久 +3／+4／+5／+6（板材 I～IV 級）。連同骨架最多 80 |
| 輔助槽 | 一件零件 | 感測器：機甲的武器命中 +1。電源：持續 +1 回合。致動器：啟動期間迴避 +1。機械神經元：回灌的比例 −5%（例如標準檔從 20% 變 15%；和「回灌緩衝」疊起來最低 10%）。晶片＋軟體（一組佔一格）：槍靈或器靈，每回合第一次換彈不花行動點，但可以被駭 |

- 輔助槽的效果不看零件的等級，同一種零件只算一件。板材的效果看等級。
- 零件的等級不能高過骨架的級；超規照第 4 節。鉻娘子改的拼裝機與同人的試作零號可以直接裝高一級的。
- **換裝**在整備架或修車廠做，不用檢定：換一件武器 2 小時，換板材或輔助零件 1 小時。拆下來的東西完好，回到背包。
- **升級骨架**：同一個系列往上一級。錢是下一級的骨架價 × 3，零件是板材、致動器、電源各一件（下一級）。修車廠 3 天；自己修 7 天，機械的 DC 照新的級。升上去之後要有對應的同步才開得動。
- **換系列**等於換骨架：買新的骨架，大修一次，把核心接過去。舊的骨架可以照骨架價的一半賣掉。
- 機師線的設計圖「再開一次」（[ITEMS](ITEMS.md) 第 12 節）讓機甲多一個武器掛點。

### 15.5 一個例子

一具 III 級的星旗野馬，打完一場剩 18 點（滿是 55＋三塊 III 級板材 15＝70）。修理係數 0.7，每點 91。

- 送卡麥隆的修車廠：52 點 × 91 ＝ 4,732，板材三件（52 點算三次），12 小時。
- 自己在薔薇驛的車庫修：材料 2,366，板材照扣三件，機械 DC 16 擲三次，順利的話 24 小時。
- 不修：下一場從 18 點開始，而且算重損，持續少一回合。
- 每週的整備費 600 × 0.7 ＝ 420。

### 15.6 載具的養護

載具簡單得多。每週的養車費（蜜醇、停車、保養）機車 40、汽車 100、浮空車 300，週一和帳單一起付；沒付的那一週，下一場叫來時掩體耐久 −10。叫進場的載具被打爛（掩體耐久歸零）時，戰後開不走，要拖車（野薔薇或修車廠，C$200），修理費是目錄價的 15%，修車廠一天；在自己的工作台或整備架修是半價、兩天，機械 DC 10＋級 × 2。只被打掉一部分的掩體耐久戰後自己回滿，不用修。野薔薇的改裝車只有鏽帶的修車廠修得好；緋櫻的重機有授權鎖，修理要回原廠或先解鎖。

### 15.7 畫面要顯示的東西

整備是一個獨立的畫面，從據點的整備架或修車廠打開。

- **機甲的全身圖**：骨架的名字、牌子、級、要的同步，以及主角現在的同步夠不夠。
- **機體耐久條**：現在／上限（標出板材加的那一段與欠整備費扣掉的那一段），以及狀態（完好、受損、重損、損毀）。
- **三種槽**：武器掛點、板槽、輔助槽，每一格顯示裝了什麼、空著的可以點開換；換的時候預覽耐久、命中、持續、回灌怎麼變。
- **啟動時的數值摘要**：護甲加值、行動點加值、持續回合（照主角的同步算好）、四個檔位的回灌百分比。
- **修理的估價**：修到滿要多少錢、多少件板材、多少時間，分「自己修」（附檢定的 DC 與成功率）與「送修」兩欄；可以只修一部分。
- **大修**（損毀或剛買的骨架）：要的錢、零件清單（打勾表示背包裡有），可以用機甲殘件抵的地方。
- **每週的帳**：整備費、器靈訂閱（崑崙）、欠了幾週、下週一要付多少。
- **升級**：同系列的下一級，要的錢、零件、天數與同步。
- **載具**的一列：每台車的掩體耐久、有沒有被打爛、養車費、所在地。
