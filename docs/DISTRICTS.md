# 各區

> 上層：[WORLD](WORLD.md)。依賴：[CORPORATIONS](CORPORATIONS.md)、[GANGS](GANGS.md)、[CULTURE](CULTURE.md)。被依賴：之後的 `NPC_SYSTEM`、`EVENTS`、`STORY_QUESTS`、區域資料（`data/world/`）。
> 來源：ElondiaRPG 的聚落（固定格子地圖）、城鎮地標、特殊地圖、旅途事件。這份寫每個區「有什麼、誰管、進去會怎樣」，格子地圖本身實作時再畫。數值都是初稿。

緋夜城有八個區。它們不只是背景不同：**同一個人、穿同一套衣服、做同一件事，在每個區的後果不一樣**。

## 1. 區域怎麼運作

### 1.1 區域資料

每個區有一組固定的欄位，沿用 ElondiaRPG 聚落資料的做法，加上這個世界需要的：

| 欄位 | 說明 |
|---|---|
| 治安 | 誰會來、多久到、用什麼（實彈或神經武器） |
| 主場風格 | 穿對了有加成；穿錯了被盯上 |
| 曝露度容忍 | 0～3。超過時依區有不同後果（騷擾、被趕、被當成從業者、加豔名） |
| 對獸化的態度 | 歡迎／普通／找麻煩 |
| 物價 | 相對於霓虹腸的倍率 |
| 子網等級 | 這一區設施的蕾絲普遍到什麼顏色 |
| 勢力 | 誰的地盤。熱度與好感在這裡生效 |
| 街頭事件表 | 白天與夜晚各一張 |

### 1.2 一座連在一起的城市

緋夜城是**一張連續的地圖**。每個區是一張（或數張）格子地圖，區與區之間以**路口**直接相連：走到地圖邊緣的路口，就進入隔壁那一區，沒有世界地圖、沒有選單式的旅行。想從冠冕區走到鏽帶，就真的可以一路走過去——穿過霓虹腸，穿過蜂巢，出東門。

沿用 ElondiaRPG 城鎮地圖「走到路口換區」的做法，差別是這裡**所有的地圖都是同一座城市的一部分**，而且彼此相鄰。

**佈局**（西邊是海）：

```
        北
        玻璃岸 ───────── 外環公路 ─────────┐
          │                               │
 海     冠冕區                             │
          │  ╲                            │
        霓虹腸 ── 蜂巢 ══ 東門 ══ 鏽帶 ── 荒地
          │  ╲  ╱  │                     │
 海      櫻町 ─── 舊港 ═══ 南門 ══════════┘
        南
   （地下層在冠冕區、霓虹腸、櫻町、蜂巢、舊港的底下）
```

**大區之間一定隔著一塊橋接區**——門、橋、巷、公路。它是一張自己的小地圖，不是一條線：走進去，穿過它，才到隔壁的區。共 12 處：

| 橋接區 | 連接 | 樣子 | 有什麼 |
|---|---|---|---|
| **冠冕門・南** | 冠冕區 ↔ 霓虹腸（頭段） | 檢查哨廣場，掃橋的閘門一字排開 | 沒有憑證會被攔（第 6 節）；排隊的人、賣假憑證的 |
| **櫻門** | 冠冕區 ↔ 櫻町 | 鳥居造型的企業閘門，緋櫻員工的通勤口 | 同上；早晚的社畜人潮是混進去的機會 |
| **海岸公路** | 冠冕區 ↔ 玻璃岸 | 沿海的懸崖路，私人保全的崗哨 | 車才順；走路的人會被問 |
| **燈籠巷** | 霓虹腸 ↔ 櫻町 | 掛滿紅燈籠的窄巷，兩邊是居酒屋 | 兩區的人混在一起的地方；親衛隊與蜜糖會的灰色地帶 |
| **鏽梯** | 霓虹腸 ↔ 舊港 | 一道生鏽的長樓梯，從歡樂街往下通到海邊 | 沒有燈；拆體客在轉角等喝醉的人 |
| **尾巴口** | 霓虹腸（尾段）↔ 蜂巢 | 跨過幹道的天橋，攤販擠在兩側 | 蜂巢的人上工的路；扒手 |
| **高架橋下** | 蜂巢 ↔ 櫻町 | 輕軌高架底下的長條空地 | 平日是停車場與遊民的棚子；**週六是同人夜市** |
| **運河橋** | 蜂巢 ↔ 舊港 | 一座舊鐵橋，底下的運河不流動 | 橋下有東西；拆體客出沒 |
| **千本通南口** | 櫻町 ↔ 舊港 | 商店街盡頭的牌樓，再過去路燈就沒了 | 特攻姬與鉻娘子的界線，雙方都有人站崗 |
| **東門** | 蜂巢 ↔ 鏽帶 | 城牆的閘門。市警的檢查哨 | 查貨不查人；走私的要另外想辦法 |
| **南門** | 舊港 ↔ 鏽帶 | 城牆的缺口，蕾絲戰爭時炸開的，沒人補 | 鉻娘子收過路費 |
| **外環公路** | 玻璃岸 ↔ 鏽帶 | 繞過市區的公路。中途有一個休息站 | 車才走得了；休息站是車族與有錢人唯一會擦身而過的地方 |

地下層的入口另計（各區都有數個，見第 10 節）。

**區內的街區之間不一定有橋接區。** 多數直接相鄰，走到邊緣就過去；有些地方中間隔著一段——暗巷、樓梯、空橋、棧橋、公路。這些小橋接區共 19 處，列在 1.3 節的表裡。

橋接區的用途：

- **事件的舞台**。攔路、盤查、埋伏、偶遇，在這裡發生最自然。街頭事件表在橋接區有自己的一張。
- **封鎖的對象**。封一個區，其實是封它的橋接區。
- **界線**。站在千本通南口，就知道前面換了一套規矩。

- **走路穿過一個區**大約花 30～60 分鐘的遊戲時間（鏽帶更久）。走在街上會遇到街頭事件、看得到這一區的人與店——這是認識城市的主要方式，也是城市的密度所在。
- **橋接區可以被封**：幫派衝突、企業封鎖、祭典組辦祭典、暴雨淹水。封了就要繞路、硬闖、付錢，或走地下層。這是區域狀態的一部分（[OPINION](OPINION.md) 第 9 節的輿論戰也能造成）。
- **追逐**會跨區：被追的時候逃進另一區，追兵依勢力決定跟不跟（緋櫻警備局不進舊港，鉻娘子不進冠冕區）。

### 1.2.1 公共交通

走得到，但不必每次都走。公共交通是**站點之間的快速移動**：去過的站才能搭，付車資、花時間，到站後出現在那一站所在的格子上。

| 交通 | 路線 | 時間（每站） | 特性 |
|---|---|---|---|
| **地鐵紅線** | 冠冕中央 — 霓虹腸頭 — 霓虹腸腹 — 霓虹腸尾 — 蜂巢天井 — 東門 | 5 分鐘 | 便宜；進站掃橋（熱度高時有風險）；深夜停駛 |
| **地鐵櫻線** | 冠冕中央 — 櫻町劇場前 — 千本通 — 舊港碼頭 | 5 分鐘 | 同上；舊港碼頭站入夜後沒有站務員 |
| **輕軌環線** | 蜂巢 — 櫻町 — 霓虹腸腹 — 蜂巢（高架，繞一圈） | 8 分鐘 | 不掃橋；擠；扒手多；看得到街景 |
| **外環巴士** | 東門 — 鏽帶各站（精煉廠、薔薇驛、骨場）— 玻璃岸 | 20 分鐘 | 班次少；鏽帶區內唯一的大眾運輸 |
| **渡輪** | 舊港碼頭 — 冠冕區濱海 — 玻璃岸遊艇碼頭 | 15 分鐘 | 胭脂堂經營；不問身分；可以帶貨 |
| **浮空計程車** | 任意兩個地面站點 | 10 分鐘 | 貴；不進舊港與鏽帶深處；乘客紀錄會留下 |
| **自己的車** | 任何有路的地方 | 最快 | 要養車、要停車；可以載貨、可以逃、可以被追 |

- 車廂與月台本身是小型場景，有自己的街頭事件：臨檢、扒手、認錯人、末班車上只剩你和一個穿玩偶裝的。
- **地下層沒有公共交通**，但淺層的貓道可以當成不經任何檢查哨的捷徑（第 10 節）。
- 存檔規則可以調整：關閉快速移動（一律用走的）、或讓沒去過的站也能搭。

**要地**的設計規則：

- **平常進不去，或進去很危險**。它們在地圖上看得到、走得到門口，但要有理由、有門路、有案子才進得去。
- **每一處都有對應的子網**（[NETRUNNING](NETRUNNING.md) 第 4 節），樓層與子網的權限層對應，控制節點連著各層的門、攝影機、砲塔。
- **可以重複進入**。不同的案子去同一棟樓的不同樓層、為了不同的目的；樓裡的人記得你上次做了什麼。這是固定地圖比隨機地圖好的地方。
- **有主**。每一處屬於一個勢力，進去就是動他們。
- 每區至少一處適合前中期、一處適合後期。

### 1.4 日與夜

每個區白天與夜晚的設施、人、事件表不同。大致上：冠冕區與玻璃岸是白天的區，霓虹腸與舊港是夜晚的區，櫻町與蜂巢兩者都醒著。

## 3. 蜂巢

**一句話**：九棟巨型集合住宅，每棟十萬人。玩家從這裡開始。

**樣子**：外牆是整面的廣告，裡面是走不完的走廊。每棟塔是一座垂直的城：低樓層是市場與工坊，中樓層是住家，高樓層沒有電梯會到，屋頂上另有一個村子。水管漏水，燈管一半不亮，鄰居之間什麼都聽得到。但是有人會幫你留一碗麵。

**誰管**：帳面上的房東是緋櫻銀行——重建債的抵押品。它只收租，不管事。市警不進來。東側三棟由飛行夾克巡守；屋頂是野良的；其餘靠樓長與互助會。

**街區與地標**：

| 地標 | 是什麼 | 玩法 |
|---|---|---|
| **四號塔** | 玩家的起始據點所在 | 一級據點；鄰居是第一批固定 NPC |
| **天井市場** | 四號塔與五號塔之間、加了頂棚的中庭。蜂巢最大的市集 | 基本的商店都在這裡；白天的街頭事件中心 |
| **阿蓮雜貨** | 天井市場角落的雜貨店。老闆娘是蜂巢的中間人 | 第一位中間人；新手案子（[FIXER](FIXER.md) 第 1 節） |
| **縫縫診所** | 無照改造師的地下室診所 | 便宜的治療與基本義體；有併發症的機率；改造師路數的起點 |
| **屋頂村** | 塔頂的違建：鐵皮屋、菜園、水塔、天線 | 野良的地盤；跨塔的屋頂捷徑；打聽情報 |
| **東側巡守站** | 飛行夾克改裝過的舊派出所 | 可以付保護費、接巡守的案子、或者被叫去問話 |
| **桃子屋蜂巢店** | 二十四小時營業 | 補給；深夜的街頭事件 |
| **膠囊旅館「繭」** | 一晚一格 | 零級據點；不問身分 |
| **九號塔** | 封閉了二十年。官方說法是結構受損 | 特殊地圖；裡面的東西是一條任務線 |
| **高架橋下** | 蜂巢與櫻町的交界 | 每週一次的同人夜市（[CULTURE](CULTURE.md) 第 6 節） |

**區域規則**：

- **鄰里**：在蜂巢做的事鄰居都知道。幫過人，會有人替你擋討債的；害過人，沒人會開門。這是一個只在蜂巢生效的小型聲望。
- **房租**：每週結帳時，緋櫻銀行的收租無人機準時到。

**街頭事件舉例**：鄰居的老人走失了；樓上漏水漏的不是水；收租無人機故障，在走廊上追著錯的人；有人在天井賣來路不明的義體扭蛋；飛行夾克盤查一個野良，看你站哪邊。

## 4. 霓虹腸

**一句話**：貫穿市中心三公里的歡樂街。這座城市的錢、慾望和消息都流過這裡。

**樣子**：一條彎彎曲曲的窄街與它的上百條岔巷，頭頂是層層疊疊的招牌，下雨時地上是粉紅色與青色的倒影。分成三段，街上的人叫它**頭、腹、尾**：頭段接冠冕區，店面體面，客人穿西裝；腹段是最熱鬧的地方；尾段接蜂巢，便宜、雜亂、什麼都有。

**誰管**：沒有單一的主人。伊甸園擁有最大的幾間店，蜜糖會保護獨立的從業者，萬華鏡在這裡取材，胭脂堂有幾間賭場。市警收了錢才來。這種誰也吃不掉誰的局面，讓霓虹腸成為城裡最自由的地方。

**街區與地標**：

| 地標 | 段 | 是什麼 | 玩法 |
|---|---|---|---|
| **琉璃宮** | 頭 | 伊甸園的旗艦人偶館。七層樓，每層一個主題 | 高級人偶館；企業主管出沒，踩點的重點場所；契約線的舞台 |
| **半夢** | 腹 | 蜜糖會保護的獨立人偶館。媽媽桑是霓虹腸的中間人 | 中間人；蜜罐、挖角、人偶逃亡的案子；可以在這裡打工 |
| **糖罐** | 腹 | 蜜糖會的會館。一樓是糖果店 | 蜜糖會的任務線；互助診所；逃亡路線的起點 |
| **過載** | 腹 | 城裡最大的夜店。舞池的音響接橋 | 表演與打工；打聽情報；邊緣行者聚集、隊友招募的地方 |
| **刀巷** | 腹 | 一整條巷子的改造診所，從正規到黑的都有 | 義體的主要購買處；診所之間品質與價格不同 |
| **靜室** | 腹 | 調校診所。安靜得不像在霓虹腸 | 量測與調整橋參數、裝卸調校（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 4 節） |
| **帶子街** | 腹 | 感官帶的攤販與試聽間 | 買賣素材；黑帶在簾子後面 |
| **井** | 尾 | 地下的感官擂台。圓形的坑，觀眾在上面往下看 | 感官擂台（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 6 節）；下注 |
| **萬華鏡街頭棚** | 頭 | 玻璃牆的直播攝影棚 | 主播的任務線；賣斷素材 |
| **旅館坡** | 尾 | 一整面山坡的愛情旅館 | 最便宜的安全屋；不查身分；偶爾查房 |
| **片場「第七棚」** | 尾 | 出租的感官帶攝影棚 | 拍攝工作（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 6 節） |

**區域規則**：

- **不問**：霓虹腸不查身分、不問來歷。熱度在這裡的效果減半——除了伊甸園與蜜糖會的。
- **豔名漲得快**：這裡人多、鏡頭多。
- **店規大於法律**：每間店有自己的規矩與保全。在店裡鬧事，得罪的是那間店背後的人。

**街頭事件舉例**：喝醉的企業主管掉了通行憑證；拉客的認錯人；一個人偶在巷子裡醒過來，不知道自己為什麼在這裡；伊甸園的回收員在追人，蜜糖會的人擋在前面；祭典組突然封了腹段；有人在你的飲料裡加了東西。

## 5. 櫻町

**一句話**：緋櫻的企業城下町，也是日本移民住了三代的老社區。宅文化的中心。

**樣子**：兩個世界疊在一起。大街上是緋櫻映像的巨型螢幕、偶像劇場、整棟的周邊商場，乾淨、明亮、每個街角有穿制服的警備。轉進巷子是另一回事：招牌褪色的商店街、澡堂、小神社、掛著燈籠的居酒屋，電線桿上貼著特攻姬的貼紙。

**誰管**：大街是緋櫻警備局的。巷子是特攻姬的。雙方有不成文的界線，偶爾有人越界。親衛隊各自佔著劇場周邊的街區。

**街區與地標**：

| 地標 | 是什麼 | 玩法 |
|---|---|---|
| **緋櫻劇場** | 三千人的偶像劇場。戰姬的常設公演場 | 大型場景地圖；偶像路數的頂點；演唱會是社交與潛入案的舞台 |
| **地下二階** | 商店街地下室的 live house，站滿是兩百人 | 地下偶像的起點；公演（[MEDIA](MEDIA.md) 第 9 節）；地下轉播站的一個節點 |
| **白手套** | 女僕咖啡廳。女僕公會的門面，店長是櫻町的中間人 | 中間人；高級雇傭（[GANGS](GANGS.md) 第 4 節）；保鑣與潛入的案子；情報 |
| **千本通** | 老商店街 | 日常商店；老店有只賣熟客的東西；特攻姬的「町費」 |
| **電器街** | 零件、二手甲板、無人機、機娘的維修鋪 | 潛網者與技術路數的裝備；織女的原廠店與一堆不是原廠的 |
| **稻荷神社** | 山坡上的小神社。特攻姬的集會所 | 特攻姬的任務線；總長的決鬥在這裡 |
| **扭蛋會館** | 五層樓，三千台扭蛋機。頂樓是義體扭蛋 | 義體扭蛋（[CULTURE](CULTURE.md) 第 7 節） |
| **緋櫻映像本社** | 屋頂有一隻巨大的吉祥物 | 偶像簽約；媒體線的對手；高難度的潛入目標 |
| **奉公課分館** | 沒有招牌的白色建築 | 忠誠調校的安裝與卸載。「畢業」的偶像被帶去的地方。後期地圖 |
| **社宅群** | 緋櫻員工的宿舍區 | 挖角案的目標所在；社畜的日常 |
| **獸耳專門店街** | 耳、尾、爪的義體與保養 | 獸化改造（[CULTURE](CULTURE.md) 第 2 節）；機械派與生體派的店各佔一邊 |

**區域規則**：

- **兩套治安**：在大街犯事，來的是警備局（神經武器，要活的）；在巷子犯事，來的是特攻姬（木刀，然後看你認不認錯）。
- **推的問題**：這一區的人會問你推誰。答案影響親衛隊對你的態度。
- **耳朵**：獸耳在這裡是加分。鎖住耳朵（抑制器）反而讓人起疑。
- **觀光客稅**：風格不是櫻町系時，物價再 ×1.2。

**街頭事件舉例**：兩支親衛隊在劇場前對峙；握手會的隊伍裡有人不對勁；特攻姬在追一個偷了商店街東西的人；警備局臨檢，隨機掃橋；迷路的機娘跟著你走；社畜在自動販賣機前過載倒下，手上的公事包還亮著。

## 6. 冠冕區

**一句話**：企業塔與空中花園。這座城市的頂端，字面上也是。

**樣子**：街道寬闊、安靜、沒有垃圾，也沒有閒人。玻璃帷幕把天空映成兩倍大。塔與塔之間有空橋與懸空的花園，住在這裡的人可以一輩子不踩到地面。

**誰管**：理事會。每棟塔是一家企業的領土，適用它自己的規則。公共區域由各家保全聯合巡邏。

**進出**：每個入口掃橋。沒有通行憑證的人進不來。方法：偽造的憑證（潛網者或同人夜市）、借來的身分（伶人的人格面具）、有人帶（雇主、工作證）、從地下層上來、或者硬闖。

**街區與地標**：

| 地標 | 是什麼 | 玩法 |
|---|---|---|
| **緋櫻塔** | 城裡最高的建築。頂層是御前的居所 | 終局級的設施地圖與子網；家政課的本部 |
| **星旗領事樓** | 外觀是使館，底下是軍營 | 緋櫻與星旗冷戰的另一端；雙面間諜的案子 |
| **萬華鏡球體** | 一顆懸在半空的巨大球形螢幕，裡面是總部 | 媒體線的終點（[MEDIA](MEDIA.md) 第 8 節） |
| **議事堂** | 理事會開會的地方 | 劇情場所；全城最密的保全 |
| **夜鶯核心機房** | 在地下。地面上只有一座沒有窗的方塊 | 牆內最深的子網（[NETRUNNING](NETRUNNING.md)） |
| **樂園** | 伊甸園的本店。會員制 | 契約的拍賣；契約線的終點 |
| **天使急救總站** | 浮空車不斷起降的白色平台 | 改造師的任務線；劫持救護浮空車 |
| **空中花園** | 塔與塔之間的懸空公園 | 社交場景；企業的人在這裡談不能在辦公室談的事 |
| **服務層** | 每棟塔的地下三到五層。清潔工、廚工、機娘的維修間 | 所有潛入案的入口；這裡的人什麼都看得到 |

**區域規則**：

- **先灌再問**：保全兩分鐘內到場，用粉蕾絲與感官彈。在這裡打輸的下場是被捕（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 8 節）。
- **全程掃描**：義體會被掃出來。武器要藏或要有許可。機械派獸耳、幫派風格、曝露度 1 以上都會被攔下來問。
- **熱度加倍**：在這裡留下的痕跡，熱度 ×2。
- **直播無效**：訊號被擋。除非先拿下一個控制節點。

**街頭事件舉例**：不多——這裡的「街頭」不發生事情。臨檢；有人認出你；一個主管在花園裡等的人沒來，轉而看著你；服務層的清潔工塞給你一張紙條。

## 7. 舊港

**一句話**：蕾絲戰爭的廢墟。重建沒有輪到這裡。

**樣子**：半沉的貨輪、堆成山的貨櫃、被炸出來的海灣。貨櫃改成的住家疊了七八層，用鷹架與繩橋連著。空氣裡有鹽、鏽與蜜醇的味道。白天安靜，晚上亮起來的是賭船與車廠的火。

**誰管**：胭脂堂管碼頭與賭場，鉻娘子管倉庫區與通往鏽帶的路，中間的灰色地帶是拆體客與各種沒有名字的人。沒有任何公權力。

**街區與地標**：

| 地標 | 是什麼 | 玩法 |
|---|---|---|
| **海棠樓** | 胭脂堂的茶樓。三層，臨水 | 胭脂堂的帳房是舊港的中間人；借錢；仲裁；樓裡不准動武 |
| **賭船「福星」** | 永遠停在碼頭的舊渡輪 | 賭博；洗錢；社交案 |
| **貨櫃城** | 貨櫃疊成的住宅區 | 便宜的安全屋；迷宮般的場景地圖 |
| **熔爐** | 鉻娘子的車廠與本部。舊的煉鋼廠 | 鉻娘子的設施地圖；義體黑市；黑拳場 |
| **彈坑灣** | 2046 年那場爆炸留下的圓形海灣。水底有東西 | 特殊地圖（潛水）；戰爭的真相是一條任務線 |
| **沉沒的機甲** | 半埋在泥灘裡的星旗機甲，沒人搬得動 | 機師路數的起點；零件；裡面的機師艙還封著 |
| **黑診所「無名」** | 沒有招牌。知道的人才找得到 | 不問來歷的手術；二手義體；解授權鎖 |
| **冷庫** | 拆體客的貨倉。位置常換 | 找回被拆走的義體；二手貨的殘響任務 |
| **夜市碼頭** | 每晚的黑市 | 違禁品；價格浮動；偶爾被掃 |
| **貨櫃場** | 空曠的舊貨櫃堆置場 | 一年兩次的緋夜祭（[CULTURE](CULTURE.md) 第 6 節）；平時是車族的卸貨點 |

**區域規則**：

- **沒人會來**：沒有治安。熱度不會因為在這裡犯事而增加——但幫派的會。
- **天使急救加收費**：到場時間加倍，帳單加倍。
- **過載倒在路邊很危險**：拆體客的事件機率大幅提高。
- **規矩**：在胭脂堂的地盤照它的規矩（不賴帳、不在茶樓開槍）；在鉻娘子的地盤沒有規矩，只有誰比較硬。

**街頭事件舉例**：拆體客的廂型車慢慢跟著你；鉻娘子在路口收過路費；有人在賣剛從水裡撈上來的東西；賭輸的人求你借錢；貨櫃裡有敲打的聲音。

## 8. 玻璃岸

**一句話**：城北的海岸。有錢人住的地方。

**樣子**：白色的別墅沿著懸崖排開，每一棟都有整面的落地窗對著海——所以叫玻璃岸。路上沒有行人，只有車。草是真的。

**誰管**：住戶委員會，與他們僱的私人保全。這裡是全城天使急救白金會員密度最高的地方。

**街區與地標**：

| 地標 | 是什麼 | 玩法 |
|---|---|---|
| **鏡廳** | 會員制的私人俱樂部。裡面的事不出門 | 社交案的主舞台；俱樂部內曝露度容忍 3；企業高層不設防的地方 |
| **遊艇碼頭** | 以及停在外海、不在任何法律管轄內的船 | 走私；海上的設施地圖 |
| **拍賣行「白槌」** | 藝術品、稀有義體、機密、契約 | 拍賣會（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 6 節） |
| **廢教堂** | 懸崖上蓋到一半就停工的教堂 | 夜宴社的聚會所；入社考驗 |
| **蜜腺療養院** | 高級的生體改造與「休養」設施 | 生體派獸化；人性治療（貴）；地下樓層是另一回事 |
| **製作人的別墅** | 萬華鏡離職製作人的家。玻璃岸的中間人 | 中間人；醜聞、偷拍、公關滅火的案子 |
| **晨星社** | 改建自燈塔的新聞社 | 主播的另一條路；「只播真的」的代價 |
| **黑泉俱樂部** | 鄉村俱樂部的外表 | 黑泉高層的社交場所；他們在這裡不談乾淨 |

**區域規則**：

- **看起來要像屬於這裡**：風格是高級訂製或哥德才不會被攔。機械派的義體外露被當成沒教養；生體派被當成品味。
- **僕人的門**：和冠冕區一樣，每棟別墅有服務入口。女僕公會的人在這裡進出自如。
- **打倒一個住戶，就開始倒數**：他們幾乎都有白金會員。

**街頭事件舉例**：派對的邀請函寄錯人；保全禮貌地問你要去哪裡；有人在海灘上醒來，什麼都不記得；一個富家的成年子女想「體驗街頭」，願意付錢；夜宴社留下一朵黑玫瑰。

## 9. 鏽帶

**一句話**：城牆外的工廠、回收場與農地。再過去是荒地。

**樣子**：煙囪、管線、看不到盡頭的燃料作物田。天空是黃的。路上跑的是油罐車與車族的改裝車。聚落稀疏，每一個都圍著鐵絲網。

**誰管**：黑泉擁有土地，星旗擁有基地，兩者只守自己的圍牆。圍牆之間是素體教的傳教所、車族的驛站與沒人管的路。

**街區與地標**：

| 地標 | 是什麼 | 玩法 |
|---|---|---|
| **精煉廠** | 黑泉的蜜醇精煉廠。供應全城的燃料 | 大型設施地圖；破壞或竊取的案子；無橋私兵 |
| **契約農場** | 一望無際的燃料作物田。工人是契約人 | 契約線；救援案；黑泉的虛偽（[CORPORATIONS](CORPORATIONS.md) 第 5 節） |
| **骨場** | 全城的廢棄物最後到的地方。機械的墳場 | 撿零件；隨機生成的探索地圖；有時候撿到還會動的東西 |
| **機甲墳場** | 蕾絲戰爭的戰場遺跡 | 機師路數的任務線；機甲零件；有些殘骸的同步系統還開著 |
| **星旗前進基地** | 圍牆、哨塔、跑道 | 後期的設施地圖；黑蕾絲；飛行夾克的舊帳 |
| **傳教所** | 素體教的本部。灰色的水泥建築 | 素體教的任務線；被拔橋的人；也是脫離契約的人的避難所 |
| **薔薇驛** | 車族的驛站：加油、修車、交易、過夜 | 野薔薇的車隊長是鏽帶的中間人；走私與護送；載具的購買與改裝 |
| **蜜腺試驗田** | 圍牆比精煉廠還高 | 生技的揭弊案；逃出來的東西 |

**區域規則**：

- **距離**：鏽帶很大，是由幾張相連的地圖組成的。區內移動靠車或外環巴士，用走的很花時間。
- **訊號差**：網路時有時無。快駭的距離縮短；直播斷斷續續；天使急救不保證到。
- **無橋的人多**：車族、黑泉的私兵、素體教徒。神經武器與神經類快駭常常沒用，要帶實彈。
- **這裡的人不吃城裡那一套**：豔名與風格的效果大減。

**街頭事件舉例**：油罐車拋錨，司機很緊張；車族的車隊邀你搭便車，條件是幫忙擋一段路；素體教徒攔路傳教；田裡有人在跑，後面有無人機；沙暴。

## 10. 地下層

**一句話**：這座城市底下的另一座城市。

**樣子**：廢棄的地鐵線、排水道、維修通道、戰時的防空洞，以及更早之前不知道誰挖的東西。有的地方有燈，是住在這裡的人拉的。牆上有野良的記號，認得的人靠它認路。越往下越安靜，越往下訊號越怪。

**誰管**：沒有人。牆語者在深處，野良在淺處，中間住著所有不想被找到的人。貞網局偶爾派人下來，下來的人不一定都回去。

**結構**：地下層不是一個區，是**一組特殊地圖**（沿用 ElondiaRPG 的特殊地圖），在蜂巢、霓虹腸、舊港、櫻町底下各有入口，彼此相連。分三層：

| 層 | 有什麼 |
|---|---|
| **淺層** | 舊地鐵月台、排水道。野良的通道、流民的聚落、走私路線。可以不經檢查哨穿越各區，包括進冠冕區的服務層 |
| **中層** | 戰時的防空設施、廢棄的機房。地下轉播站、黑市的倉庫、躲風頭的人、沒人認領的舊網節點 |
| **深層** | 大潮崩之前的網路骨幹。牆語者的聖堂。通往牆的路 |

**地標**：

| 地標 | 層 | 是什麼 | 玩法 |
|---|---|---|---|
| **月台市** | 淺 | 廢棄地鐵站裡的聚落 | 以物易物的市集；不問身分的住處 |
| **貓道** | 淺 | 野良標記的通道網 | 快速移動；要野良的好感才看得懂記號 |
| **排水大廳** | 淺 | 巨大的地下蓄洪池。下雨天會淹 | 場景地圖；有些交易只在這裡談 |
| **轉播站** | 中 | 牆語者與車族合營的地下廣播 | 不會被萬華鏡降流的發布管道（[MEDIA](MEDIA.md) 第 8 節） |
| **探員的書店** | 中 | 前貞網局探員開的舊書店。地下層的中間人 | 中間人；竄網案、和牆有關的事 |
| **舊網節點** | 中、深 | 沒有接上夜鶯的機房 | 可以在這裡深潛而不留下追蹤度；也可能遇到別的東西 |
| **聖堂** | 深 | 牆語者的本部。一整面牆的舊伺服器，還在運轉 | 牆語者的任務線；最好的潛網老師 |
| **門** | 深 | 通往粉牆的接入點 | 竄網線的終局（[NETRUNNING](NETRUNNING.md) 第 7 節） |

**區域規則**：

- **沒有治安，也沒有急救。**
- **沿用 ElondiaRPG 地下城的光線規則**：地下層是這款遊戲裡唯一真的黑的地方。要帶光源或夜視。
- **越深越怪**：深層的舊網節點會主動連上你的橋。沒裝橋的人在這裡反而安全。
- **地下的人情**：這裡不用錢。幫過誰、欠過誰，是唯一的貨幣（[FIXER](FIXER.md) 第 8 節）。

**事件舉例**：走錯一個岔路，記號不見了；有人在黑暗裡用很溫柔的聲音叫你的名字；流民的聚落在辦一場小小的婚禮；貞網局的探員受了傷，求你別說出去；水位開始上升。

## 11. 周邊：地圖的邊緣

故事只發生在緋夜城與它的周邊。城外不是另一張世界地圖，而是**邊緣**：走得到的地方到此為止。

| 邊緣 | 是什麼 | 玩法 |
|---|---|---|
| **荒地邊緣** | 鏽帶再往東，公路沿線一天車程以內的範圍：廢棄的加油站、車族的營地、沙暴 | 車族的案子；走私的交貨點；隨機生成的探索地圖。再往外，路牌還在，但遊戲不讓你過去——車族會說「那邊沒有東西了，至少沒有你要的」 |
| **外海** | 港外不在任何法律管轄內的水域：賭船、私人遊艇、鑽油平台改成的設施 | 渡輪到不了的地方要有船；海上的設施地圖 |
| **軌道** | 抬頭看得到的燈。企業的站台在上面 | 只出現在新聞、對話與極少數的劇情場景裡，不是可以去的地方 |
| **別的城市、別的國家** | 大阪、舊美國、車族口中的其他自由市 | 只以**人、貨物、新聞**的形式存在：外來的 NPC、進口貨、螢幕上的報導、打來的電話。玩家永遠不會離開 |

這是刻意的限制。它讓緋夜城有「被困在這裡」的感覺——很多角色的人生目標就是離開，而玩家知道沒有人真的離得開。

## 13. 遊戲進程上的順序

| 階段 | 區 | 為什麼 |
|---|---|---|
| 開場 | 蜂巢 | 便宜、安全、有鄰居 |
| 前期 | 霓虹腸、舊港 | 生活機能與第一批真的危險 |
| 中期 | 櫻町、鏽帶、地下層淺層 | 勢力變複雜；需要車與門路 |
| 後期 | 玻璃岸、冠冕區、地下層深層 | 要身分、要憑證、要有人帶 |

沒有硬性的鎖：一開始就能走到任何地方（真的用走的），只是會被攔、會被搶、會付不起。
