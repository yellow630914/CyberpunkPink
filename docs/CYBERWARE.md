# 義體、人性與溺感症

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[CORE_RULES](CORE_RULES.md)（人性、感載、同步原則）。被依賴：[COMBAT_SYSTEM](COMBAT_SYSTEM.md)、[NETRUNNING](NETRUNNING.md)、[LEWD_SYSTEM](LEWD_SYSTEM.md)。
> 來源：ElondiaRPG 的裝備欄位、刺青部位、雙面效應與鎖、寄生物，重新推導成一套。預定資料：`data/rules/cyberware.json`、`malware.json`。

義體是這款遊戲的主要成長線，也是主要的債務來源。

## 1. 部位

每個部位有固定的槽數。沿用 ElondiaRPG 刺青的「部位圖」介面：角色詳情裡一張人形圖，點部位看裝了什麼。

| 部位 | 槽 | 典型的義體 |
|---|---|---|
| 橋（後頸） | 1 ＋調校槽 2 | 邊緣橋本體（人人都有，分等級）；調校見 [LEWD_SYSTEM](LEWD_SYSTEM.md) 第 4 節 |
| 腦 | 3 | 甲板、反射加速器、記憶庫、人格面具槽、人偶晶片 |
| 眼 | 2 | 義眼（瞄準、夜視、錄影）、掃描器 |
| 耳與喉 | 2 | 聲紋偽裝、指向收音、費洛蒙腺 |
| 軀幹 | 3 | 皮下裝甲、合成臟器、藥泵、備用心臟 |
| 皮膚 | 2 | 觸覺強化皮膚、光學迷彩、**光紋刺青** |
| 臂 ×2 | 各 2 | 義臂、內藏武器、駭入接頭、手術指 |
| 腿 ×2 | 各 2 | 義腿、跳躍增壓、靜音足墊 |
| 私密 | 2 | 感官強化、鎖具、藏匿艙（走私與偷渡資料晶片用） |

- **光紋刺青**取代 ElondiaRPG 的刺青：皮下的發光電路，可以是裝飾（加風格與豔名）、幫派標記、或契約的可見標記（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 7 節）。
- 服裝另有欄位（上身、下身、外套、內衣、鞋、頭、飾品），沿用 ElondiaRPG 的裝備與曝露度規則。護甲是服裝的屬性（見 [COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 4 節）。

## 2. 人性成本

每件義體有一個**人性成本**，裝上就壓低人性上限（[CORE_RULES](CORE_RULES.md) 4.3 節），拆掉拿回來。

| 等級 | 例 | 人性成本 |
|---|---|---|
| 表層 | 光紋刺青、義眼的濾鏡 | 0～1 |
| 一般 | 義眼、聲紋偽裝、藥泵 | 2～4 |
| 侵入 | 義肢、皮下裝甲、甲板 | 5～8 |
| 重度 | 反射加速器、全身觸覺皮膚、合成臟器組 | 9～14 |
| 極限 | 軍規全身改造、機甲的常駐同步插槽 | 15～25 |

- 改造師的「手術刀」每階把安裝時的人性成本 −5%（最多 −25%）。好診所同理；黑診所便宜但有機率留下**併發症**（一個小缺陷）。
- **蜜腺的抑制劑**：每週服用，人性上限暫時 +10。停藥一週後 −15（比沒吃過更糟），持續兩週。這是每週帳單的一項，也是企業拴人的方式。

## 3. 雙面效應

每一件有分量的義體都有一正一反，寫在同一張卡上。沒有純好處的義體。

| 義體 | 正 | 反 |
|---|---|---|
| 觸覺強化皮膚 | 感知類檢定 +2；誘惑 +1；能感覺到隔牆的震動 | 受到的感載 ×1.25 |
| 皮下裝甲 | 護甲 +3，不會耗損 | 敏感度 −15（開不了深同步）；誘惑 −1 |
| 費洛蒙腺 | 交涉與誘惑 +2；可以對近身敵人造成感載 | 自己的感載每回合 +1；在掃描器前藏不住 |
| 痛覺編輯器 | 無視重傷懲罰 | 不知道自己快死了：生命值的顯示變成模糊的分段 |
| 記憶庫 | 調查 +2；可以存感官帶素材 | 被駭入時，對方可以讀走 |
| 駭入接頭 | 可以直接插進裝置駭入，不經無線，追蹤度不漲 | 反過來，裝置裡的蕾絲也直接打進你身上：感載 ×1.5 |

設計規則：反面要和正面出自同一個原理（皮膚更敏感所以更容易過載），而不是隨便配一個懲罰。

## 4. 加速與驅動

戰鬥用的主力義體，都套用同步原則（[CORE_RULES](CORE_RULES.md) 第 5 節）：開得越深越強，回灌越重。

- **反射加速器**：啟動後依檔位每回合多 1／2／3 點行動點，每回合自己承受 3／6／10 點感載。原理是把獎賞迴路的訊號拿去催神經傳導——用的人形容是「一直在邊緣上」。會自己把自己打到過載。
- **熱驅動**：把感載轉成力量。目前感載每 10 點，近戰傷害 +1、體格檢定 +1。鉻娘子的招牌。等於鼓勵使用者故意維持高感載，在過載邊緣戰鬥。
- **冷卻迴路**：反過來，花行動點把感載排掉。保守派與企業保全用。

## 5. 授權鎖、二手貨與惡意韌體

義體不只是裝備，也是把柄。

**授權鎖。** 企業出的義體有三種買法：

| 買法 | 價格 | 代價 |
|---|---|---|
| 買斷 | 全額 | 無 |
| 訂閱 | 每週付全額的 3% | 沒付就**鎖**：功能停止，但人性成本照扣 |
| 契約 | 免費 | 交出部分橋權：企業可以遠端讀取、限制、或在指定情況下接管這件義體 |

- 解鎖的方法：付清、請改造師破解（義體學檢定，失敗會損壞或觸發回報，加企業熱度）、請潛網者偽造授權（要進那家企業的子網）。
- 沿用 ElondiaRPG 的「鎖與鑰匙」機制：鎖是物品上的屬性，鑰匙是一種條件。

**二手貨。** 黑市與拆體客賣的義體便宜四到七成，但有：

- **殘響**：前一個使用者的感官記憶沒洗乾淨。偶爾閃回。機制上是一個隨機的小特質，可能好可能壞，有時是任務線索（這條手臂的前主人是怎麼死的？）。
- 較高的惡意韌體機率。

**惡意韌體。** 取代 ElondiaRPG 的寄生物：感染義體的程式，有潛伏、發作、擴散三個階段，隨時間推進。

| 例 | 來源 | 發作 |
|---|---|---|
| 發情蠕蟲 | 黑帶、不乾淨的二手義體 | 感載不會自然消退；之後開始每小時自己漲 |
| 傀儡絲 | 黑蕾絲、鉻娘子的武器 | 義肢偶爾不聽使喚；最後階段可以被遠端操控一回合 |
| 竊聽花 | 企業的禮物、被捕後釋放 | 沒有症狀。你做的事對方都知道，案子的警戒起始值上升 |
| 妖精的吻 | 牆外 | 見 [NETRUNNING](NETRUNNING.md) 第 7 節 |

- 清除：改造師（義體學對階段 DC）、潛網者（進自己的橋裡跑一次小型深潛）、或直接拆掉那件義體。
- 發作事件沿用 ElondiaRPG 的事件視窗。

## 6. 溺感症

人性歸零的結果（分段見 [CORE_RULES](CORE_RULES.md) 4.3 節）。這裡補的是世界觀如何對待它：

- **兩種走向**：**空殼**（什麼都不在乎，通常被企業回收當作不會抗命的保全）與**渴癮**（為了感覺到什麼而不擇手段）。街上說的溺感者是後者。
- NPC 也會溺感。重度改造的敵人（鉻娘子的幹部）人性本來就低，戰鬥中把他們打到過載可能直接推過線——變成更危險、但不分敵我的東西。這是可以利用的戰術，也可能失控。
- **鎮溺隊**：玩家人性低於 20 時開始累積他們的熱度。他們是遊戲裡最硬的常規敵人，設計成「不該打贏」的壓力來源。
- **拉回來**：隊友人性快到底時會出現事件，可以帶去治療、勸他拆義體、或者不管。這是關係線的重要節點。
