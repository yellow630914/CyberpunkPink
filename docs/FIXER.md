# 中間人與案子

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[CORE_RULES](CORE_RULES.md)（街頭信譽、熱度）、[COMBAT_SYSTEM](COMBAT_SYSTEM.md)、[NETRUNNING](NETRUNNING.md)、[MEDIA](MEDIA.md)。被依賴：無（這是把所有系統串起來的那一份）。
> 來源：ElondiaRPG 的公會委託與階級、特殊任務與劇情旗標、夥伴與雇傭、交易與談判、情報、派奴隸去工作（→ 派工）、房屋（→ 據點）。預定資料：`data/rules/gigs.json`、`fixers.json`、`favors.json`、`bases.json`。數值都是初稿。

這份文件有兩半：第 1～4 節是**案子**——所有玩家都會經歷的主迴圈；第 5～9 節是**當中間人**——掮客路數的經營玩法。

## 1. 中間人是什麼

緋夜城沒有冒險者公會。想找人做事的人不認識做事的人，做事的人不想讓雇主知道自己是誰，中間站著的就是中間人。他們賣的是信任：保證雇主付錢、保證做事的人不亂說。

每個中間人有自己的**地盤**（區）、**門路**（擅長的案子類型）、**後台**（哪個勢力罩他）與**脾氣**。他們是固定 NPC，各有一條關係線。信譽越高，肯見你的中間人越多。

每個區各有一位，名單與場所見 [DISTRICTS](DISTRICTS.md) 第 12 節。

## 2. 一案一團

一件案子有固定的四拍，每一拍是一到數份報告。這是把跑團的一場團變成遊戲流程。

### ① 接案

- 中間人給一份**簡報**：目標、地點、報酬、期限、**條件**（不准死人／不准留痕跡／要活的／不准曝光），以及他**願意說**的情報。
- 簡報可能不完整，也可能有假。調查或街頭知識可以當場看出破綻。
- **談判**（沿用 ElondiaRPG 的談判）：報酬、預付款、裝備補助、分紅、指定要一樣戰利品。
- 也可以不經中間人直接找雇主，或自己找上門的案子（街頭事件、關係線、看了某段素材之後）。

### ② 踩點

行動前的準備。花時間換情報，但**期限在走，目標那邊的狀況也會變**。

每件案子有一張隱藏的**未知清單**：保全人數、蕾絲的顏色、有沒有機甲、入口、目標的作息、雇主沒說的事。每一次踩點行動揭開一到兩項，或直接製造一個優勢：

| 手段 | 揭開／得到 | 主要技能 |
|---|---|---|
| 實地勘查 | 地圖、入口、掩體 | 隱匿、調查 |
| 打聽 | 傳聞、作息、內部矛盾 | 街頭知識、交涉 |
| 淺層駭入 | 子網的層數與蕾絲、班表；可以預埋後門 | 介面 |
| 收買或色誘內線 | 憑證、內應；行動時多一個入口 | 交涉、誘惑 |
| 以採訪為名 | 進入場所、接觸目標 | 表演 |
| 進人偶館當班 | 聽到目標在床上說的話 | 伶人的招牌能力 |
| 買情報 | 直接買一項未知 | 錢或人情 |

- 踩點行動可能失敗並**驚動目標**：警戒起始值上升。
- 沒揭開的未知，行動時會以最壞的時機出現。完全不踩點直接衝也行——那是另一種玩法。
- 沿用 ElondiaRPG 的情報系統與冒險筆記：案子的頁面列出已知與「？？？」。

### ③ 行動

進入**場景地圖**（沿用 ElondiaRPG 的固定格子地圖與特殊地圖）。每張設施地圖有對應的子網，區域和控制節點一一對應（[NETRUNNING](NETRUNNING.md) 第 4 節）。

四種解法，可以混用、可以中途換：

| 解法 | 靠什麼 | 壓力條 |
|---|---|---|
| 強攻 | 戰鬥 | 增援的倒數 |
| 潛入 | 隱匿、快駭、控制節點 | **警戒**（0～100，對應子網的追蹤度；兩條互相影響） |
| 社交 | 偽裝、人格面具、誘惑、交涉 | **破綻**（偽裝被看穿的累積） |
| 竄網 | 深潛 | 追蹤度 |

- **警戒**取代 ElondiaRPG 地下城的光線，是現實這一側的壓力條：被看見、屍體被發現、警報響都會加；到某個值就從潛入變成強攻。
- **撤退**永遠是選項。帶著一半的成果出來，進入收尾時算部分完成。

### ④ 收尾

- **結算**：報酬（依完成度與條件）、歷練點、街頭信譽、各勢力的熱度、戰利品、素材。
- **背刺檢查**：雇主或中間人依其性格、後台與你知道了多少，有機率翻臉——少付、滅口、把你賣給對方。踩點時查過雇主的話會事先知道。玩家也可以背刺：私吞貨、把貨賣給對家、把過程拍下來（[MEDIA](MEDIA.md)）。
- **餘波**：案子的結果寫進劇情旗標與區域狀態，影響之後出現的案子。
- 一份 `gig` 報告交給 AI 寫成這場團的尾聲。

## 3. 案子的種類

| 類 | 內容 | 這個世界特有的版本 |
|---|---|---|
| 竊取 | 偷資料、偷原型、偷義體 | 偷一段感官帶母帶 |
| 抹除 | 殺人、毀證、刪資料 | 把一個人從所有人的記憶庫裡刪掉 |
| 挖角 | 把一個企業員工帶出來 | 他是契約人：要連橋權一起處理，不然帶出來也會被遠端鎖死 |
| 護送與保鏢 | | 護送一個剛逃出人偶館的人到蜜糖會 |
| 救援 | | 把被粉蕾絲釘在線上的潛網者拔出來 |
| 蜜罐 | 用色誘取得把柄或情報 | 伶人與主播的主場 |
| 討債與回收 | 收錢，或收義體 | 你也可能是被回收的那個 |
| 滅火 | 幫客戶處理醜聞 | 在帶子發出去之前找到它 |
| 獵溺 | 處理一個溺感者，搶在鎮溺隊之前 | 委託人常常是他的家人，要活的 |

- 一般案子由引擎依區、中間人的門路與信譽**生成**（沿用 ElondiaRPG 的一般委託）。
- **特殊任務**是人工編寫的任務鏈，沿用 ElondiaRPG 的劇情旗標系統。每個中間人、每個路數、每個主要勢力各有一條。

## 4. 每週帳單

每七天結算一次（`downtime` 報告）：

| 項目 | 說明 |
|---|---|
| 房租 | 依據點等級 |
| 義體訂閱 | 沒付就鎖（[CYBERWARE](CYBERWARE.md) 第 5 節） |
| 抑制劑與藥 | 停藥的後果見 [CYBERWARE](CYBERWARE.md) 第 2 節 |
| 債的利息 | 胭脂堂與伊甸園的利率不同、催討方式也不同 |
| 天使急救會費 | 可以不保 |
| 小隊的薪水與分紅 | |
| 收入 | 頻道的廣告、派工的抽成、店面 |

付不出來時依序發生：鎖義體 → 討債人上門（街頭事件）→ 債權被賣給伊甸園 → 被要求簽契約（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 7 節）。**這條下坡路是遊戲的預設失敗狀態**，取代「主角死亡」成為最常見的壞結局入口——而且它是可以玩下去的。

## 5. 當中間人：盤口

掮客路數的玩家不只接案，還**開盤**：自己當中間人。這是經營玩法，和親自出任務並行。

- 每週有若干**委託人**帶著需求上門（依信譽、地盤、人脈生成）。
- 你做三件事：**談價**（和委託人）、**配人**（從名冊選人，或自己上）、**擔保**（出事的時候是你的名字）。
- 你賺**抽成**（預設 20%，「人面」每階可以多談一些）與**人情**。

## 6. 名冊

取代 ElondiaRPG 的夥伴名單與酒館雇傭。名冊是你認識、而且願意接你電話的人。

- 容量：`3 + mod(魅力) + 人面階數 × 2`。非掮客也有名冊，只是小。
- 每個人有：路數與階數、技能、要價、**可靠度**（會不會做完、會不會亂說）、**忠誠**（對你個人）、目前的狀況（有空、受傷、躲風頭、欠你一次）。
- 來源：一起出過任務的人、中間人介紹、救過的人、買下契約的人、用人情換來的引薦。
- 名冊上的人可以：**帶進小隊**（最多 4 人一起行動）、**派工**（第 7 節）、**外包單項**（請一個潛網者遠端支援這件案子的竄網部分）。
- 名冊上的人會出事。他們有自己的生活（沿用 ElondiaRPG 的「NPC 自己的日子」）：被抓、欠債、溺感邊緣、被對家挖走。處理這些事是掮客的日常，也是關係線。

## 7. 派工

把名冊上的人派去做一件你沒親自去的案子。

- 引擎依派去的人的能力對案子的難度，加上你提供的情報（踩點成果可以交給他們）與裝備，**擲出結果**：完成度、傷亡、熱度、有沒有帶回額外的東西。一份簡短的報告，AI 寫成他們回來交差時的轉述。
- 失敗的後果算在你頭上：信譽、委託人的熱度、名冊上的人受傷或被捕（變成一件新的救援案）。
- 沿用 ElondiaRPG「派奴隸去娼館工作」的離場結算骨架，推廣成一般的派工。
- 玩家可以選擇親自帶隊做最重要的那一件，其他的派出去。**同時跑幾件案子、決定自己去哪一件**，是掮客玩法的核心決策。

## 8. 人情

第二種貨幣。不能存銀行，但買得到錢買不到的東西。

- **欠你的**與**你欠的**分開記，對象是具體的人或勢力，有大小（小、中、大）。
- 來源：幫忙不收錢、救人、放人一馬、壓下一段素材、替人擔保。
- 用途：要一項情報、借一個人、借一件裝備、請市警晚到十分鐘、讓某個中間人肯見你、讓企業的人「沒看見」。
- 你欠的人情會被**討**：對方在不方便的時候打來，要你做一件事。拒絕可以，信譽大跌。
- 談判時人情可以當籌碼（沿用 ElondiaRPG 的談判，多一種標的）。

## 9. 據點

取代 ElondiaRPG 的房屋。

| 等級 | 例 | 功能 |
|---|---|---|
| 0 | 愛情旅館、膠囊 | 只能睡 |
| 1 | 蜂巢的單位 | 儲物、休息回復、養傷 |
| 2 | 改裝過的安全屋 | 工作台（改裝）、接入點（從家裡深潛）、多人住 |
| 3 | **店面**：酒吧、診所、小型人偶館、轉播站 | 每週收入；自己的盤口有固定的場地（委託人變多）；名冊上的人有地方待 |

- 店面的種類決定經營的方向：酒吧偏情報與人情，診所偏義體與改造師的任務線，人偶館偏錢與蜜罐（也帶來伊甸園的注意），轉播站偏媒體線。
- 據點會被找到。熱度高時，街頭事件變成**上門事件**。
- 家具沿用 ElondiaRPG；種植不做。
