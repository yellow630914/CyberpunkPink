# 核心規則：屬性、技能、檢定與三條軌

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。被依賴：所有系統。依賴：無。
> 預定資料：`data/rules/attributes.json`、`skills.json`、`paths.json`、`progression.json`。
> 記號：`mod(x) = floor((x − 10) / 2)`（沿用 ElondiaRPG）。所有數值都是初稿。

## 1. 六屬性

| 屬性 | 影響 |
|---|---|
| 體格 | **生命值**、近戰傷害、能承載的義體重量 |
| 反應 | 槍械命中、**迴避**、**行動點**、先攻 |
| 技術 | 改裝、義體的安裝與維修、醫療、操甲 |
| 智識 | 竄網、**RAM**、調查 |
| 膽識 | **感載上限**、**行動點**、抗蕾絲與威嚇的豁免、瀕死豁免 |
| 魅力 | 交涉、誘惑、表演、名冊容量 |

- **建角**：把 `[15, 14, 13, 12, 10, 8]` 分配到六項，再加 2 點自由點數（單項上限 18）。
- **基礎屬性與有效屬性**：沿用 ElondiaRPG 的做法——檢定讀有效屬性（基礎＋義體、藥物、狀態的加減），來源移除時自動回復。有效屬性上限 24。基礎屬性之後幾乎不再成長；要變強靠義體。
- 沒有種族。取而代之的是**出身**（蜂巢、企業、車族、歡場、舊港），給一項技能 +1、一筆起始人脈、一個出身特質。

## 2. 技能

十八項，每項 0～6 級。

| 屬性 | 技能 |
|---|---|
| 體格 | 格鬥、運動 |
| 反應 | 槍械、重武器、駕駛、隱匿 |
| 技術 | 機械、義體學、醫療、操甲 |
| 智識 | 介面（竄網）、調查、街頭知識 |
| 膽識 | 威嚇、定力 |
| 魅力 | 交涉、誘惑、表演 |

## 3. 檢定

```
1d20 + mod(屬性) + 技能等級 + 情境修正  對  DC
```

| 難度 | DC |
|---|---|
| 容易 | 10 |
| 普通 | 13 |
| 困難 | 16 |
| 極難 | 19 |
| 傳說 | 22 |

- **成功程度**四級：大成功（超過 DC 5 以上或自然 20）、成功、失敗、大失敗（低於 DC 5 以上或自然 1）。對應主持人的「是，而且／是／不，但是／不，而且」。
- **自由行動**沿用 ElondiaRPG 的主動行動：擲骰先發生，AI 看骰值與情境決定成功程度並寫出經過，後果由程式夾在封閉清單與上限內。AI 關閉時照上表的規則判定。
- **協力**：隊友有同一項技能 2 級以上時可以協助，+2。
- **重傷**（生命值低於一半）、**餘韻**（剛過載過）、低人性各有檢定懲罰，見第 4 節。

## 4. 三條軌

角色有三條會被打掉的東西。前兩條是戰鬥中的，第三條是長期的。

### 4.1 生命值（肉體）

```
最大生命值 = 20 + 體格 × 2 + mod(膽識) × 2          （初稿）
```

- 低於一半：**重傷**，所有檢定 −2。
- 歸零：**瀕死**。每回合擲瀕死豁免（1d20 + mod(膽識) 對 DC 10，每回合 +1）；失敗三次死亡。有天使急救會員資格時改成觸發救援（見 [COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 8 節）。
- 沒有等級，所以生命值幾乎不會成長。變耐打的方法是護甲與義體。這是刻意的：槍永遠危險。

### 4.2 感載（神經）

橋目前承受的訊號量。從 0 往上累積。

```
感載上限 = 20 + 耐受 ÷ 2 + mod(膽識) × 3             （初稿；耐受是橋參數，見 LEWD_SYSTEM 第 1 節）
受到的感載 = 原始值 × (0.75 + 敏感度 ÷ 200)
每回合自然消退 = 2 + mod(膽識)，受慾求修正
```

- **來源**：蕾絲、快駭、神經武器（感官彈、費洛蒙霧、電擊鞭）、機甲被擊中時的回灌、深度同步的副作用、成人場景。
- **到達上限 → 過載**：失去下一個回合，斷開所有同步（潛網者被踢出子網、機師被彈出同步），感載歸零，得到**餘韻**（3 回合，檢定 −2、受到的感載 ×1.25）。同一場戰鬥第二次過載起，每次扣 1 點人性。
- 過載不會死，但被打到過載的人任人處置。**這是這個世界的非致命傷害軌**：要活捉、要審問、要不留屍體，都走感載。企業保全的標準配備是粉蕾絲與感官彈，不是實彈——死人不能簽契約。
- 感載同時是成人場景的進度條，見 [LEWD_SYSTEM](LEWD_SYSTEM.md) 第 3 節。兩者是同一個數字，不是兩套系統。

### 4.3 人性（長期）

還剩多少「自己的感覺」。0～100。

```
人性上限 = 100 − 所有義體的人性成本合計
```

- **上限**被義體壓低（見 [CYBERWARE](CYBERWARE.md) 第 2 節）；**目前值**會因為創傷事件下降：反覆過載、被黑蕾絲燒到、殺第一個人、看黑帶、長時間戴人偶晶片、被妖精碰過。
- **回復**：休息與關係慢慢回（每週 +2，有親密關係的 NPC 時 +4）；心理治療快但貴；拆掉義體可以把上限拿回來。
- **分段**：

| 人性 | 狀態 | 效果 |
|---|---|---|
| 80 以上 | 完整 | 無 |
| 60～79 | 淡 | 無機制效果；AI 描寫開始有距離感 |
| 40～59 | 鈍 | 交涉、誘惑、表演 −1；定力 +1 |
| 20～39 | 空 | 魅力系技能 −2；定力 +2；受到的感載 ×0.9（感覺不太到了）；每週有機率發生**渴癮事件** |
| 1～19 | 溺感邊緣 | 上面的效果加倍；自由行動時 AI 被要求把衝動寫進結果；鎮溺隊的熱度每週 +1 |
| 0 | 溺感 | 角色失控。主角可以選一次「拉回來」（強制拆義體＋住院，人性回到 20，欠一大筆債）；第二次遊戲結束。隊友變成敵人。 |

低人性不是純懲罰：它讓人更冷靜、更耐打，代價是社交崩壞。這是雙面效應。

### 4.4 完整度（網內）

潛入網路空間時，化身另有一條**完整度**，是網內的生命值；歸零只會被踢回現實。感載在兩邊是同一條。公式與規則見 [CYBERSPACE](CYBERSPACE.md) 第 4 節。

## 5. 同步原則

三條玩法都有一個「接多深」的旋鈕，規則是同一條：

| 檔位 | 力量 | 回灌（受到的感載） |
|---|---|---|
| 淺 | 檢定 −2，能做的事受限 | ×0.5 |
| 標準 | — | ×1 |
| 深 | 檢定 +2，解鎖進階動作 | ×1.5 |
| 全 | 檢定 +4，解鎖終極動作 | ×2，且過載時扣 2 點人性 |

- 用在：竄網的同步深度（[NETRUNNING](NETRUNNING.md) 第 3 節）、機甲的同步率（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 9 節）、反射加速類義體的輸出檔位（[CYBERWARE](CYBERWARE.md) 第 4 節）。
- 能開到哪一檔受技能等級限制（深要 3 級、全要 5 級），並受敏感度限制（敏感度太低的橋開不了深同步，見 [LEWD_SYSTEM](LEWD_SYSTEM.md) 第 1 節）。
- 換檔是自由動作，每回合一次。

## 6. 路數

沒有職業，只有**路數**：一個人靠什麼吃飯。每條路數有一項**招牌能力**，1～5 階。建角選一條從 1 階開始，之後可以用歷練點學別條。

| 路數 | 招牌能力 | 它做什麼 |
|---|---|---|
| **槍手** | 戰鬥直覺 | 每場戰鬥開始時，把階數的點數分配到先攻、命中、迴避，戰鬥中可以花行動點重分配 |
| **潛網者** | 介面 | 快駭的專精；網內的**管理行動**——破解閘門、接管節點、改寫地形（[NETRUNNING](NETRUNNING.md)） |
| **改造師** | 手術刀 | 自己安裝義體並降低人性成本；戰場急救；清除惡意韌體；解授權鎖 |
| **主播** | 聚光燈 | 素材品質、直播的聲量、公信力上限（[MEDIA](MEDIA.md)） |
| **偶像** | 應援 | 把隊友的橋接到自己身上：分擔感載、給增益；人氣與親衛隊（[MEDIA](MEDIA.md) 第 9 節） |
| **掮客** | 人面 | 名冊容量、抽成、黑市貨源、人情的額度（[FIXER](FIXER.md)） |
| **伶人** | 入戲 | 載入人格面具偽裝成另一個人；用誘惑造成感載；社交潛入的專家 |
| **機師** | 同步 | 駕駛女武神機甲與載具；階數決定能開的同步檔位與機甲等級 |

- 伶人是這個世界特有的路數：人偶館出身、懂得把人偶晶片當工具而不是被它用的人。在「社交」這條解法上，他們等於潛網者之於網路。
- 偶像也是這個世界特有的：靠體質吃飯的人（極高的耐受與敏感度）。主播的力量在不在場的觀眾，偶像的力量在在場的人——她是隊伍的輔助與指揮，也是能叫來一群人的人。
- 八條路數對應四種解法各兩條：戰鬥（槍手、機師）、竄網與技術（潛網者、改造師）、社交（伶人、偶像）、經營（主播、掮客）。
- **每條路數都有現實與網路兩面**：招牌能力在網路空間有另一種表現（槍手是網內的前鋒、改造師解剖蕾絲、伶人騙過閘門……），階數共用。對照表見 [CYBERSPACE](CYBERSPACE.md) 第 5 節。
- 路數只給招牌能力，不限制技能。任何人都能潛入內海、都能用快駭；沒有「介面」招牌能力的人不能破解閘門與接管節點。

## 7. 成長

- **歷練點**：案子收尾時發，依難度與表現（達成附帶目標、沒觸發警報、素材品質）。
- **花費**（初稿）：技能升到 N 級花 `N × 10`；路數升到 N 階花 `N × 30`；學新路數的 1 階花 40。
- **特質**：沿用 ElondiaRPG 的特質系統（被動，影響檢定與戰鬥）。建角選 2 個特質、可選 1 個缺陷換點數；之後用歷練點買或從劇情取得。
- 義體用錢買，不花歷練點。所以成長有兩條腿：歷練點（技術）與瑰元（身體）。錢同時要付帳單，這是主要的取捨。

## 8. 名聲與熱度

| 數值 | 範圍 | 是什麼 | 影響 |
|---|---|---|---|
| **街頭信譽** | 0～100，六階 | 邊緣行者圈子裡知不知道你、信不信你 | 能接的案子、中間人願意介紹誰、黑市的貨 |
| **豔名** | 每區 0～100 | 這一區有多少人看過你、談論你（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 5 節） | 誘惑與表演、直播的起始觀眾、被認出來的機率 |
| **熱度** | 每個勢力 0～100 | 這個勢力多想找你麻煩 | 街頭事件、追兵、案子中的增援、進不了它的地盤 |
| **公信力** | 0～100 | 觀眾相不相信你發的東西（[MEDIA](MEDIA.md) 第 4 節） | 爆料的效果 |
| **人氣** | 0～100 | 有多少人把你當成「推」（[MEDIA](MEDIA.md) 第 9 節） | 親衛隊的規模、公演收入、應援的強度 |

信譽六階：無名（0）、熟面孔（15）、有號（35）、搶手（55）、頂尖（75）、傳說（90）。對應 ElondiaRPG 的公會階級，但沒有考核——信譽是別人給的，做砸一件案子會掉。

熱度沿用 ElondiaRPG 的警戒與通緝骨架：犯案被目擊、被追蹤到、爆料指名都會加；隨時間消退；滿了會被懸賞。差別是依勢力分開記。
