## 1. 分歧點：快感即協定

這條世界線和我們熟悉的賽博龐克只差一件事：**腦機介面是從哪裡突破的**。

1998 年，藥廠蜜腺生技的實驗室發現，要讓電極和大腦穩定地雙向溝通，唯一不會被排斥的通道是邊緣系統的獎賞迴路——大腦願意讓「舒服的訊號」進來。他們做出來的介面叫**邊緣橋**（Limbic Bridge，街上只叫「橋」）。從那之後，所有接進神經的東西都得過這座橋：義肢的觸覺、網路的資料流、機甲的回饋，在使用者的感覺裡都帶著一層快感的底色。資料量越大，感覺越強。

工程師的說法是「快感即協定」。後果是：

- **科技長在情慾產業上。** 第一批肯砸錢做介面的不是軍方，是娛樂業和藥廠。今天的巨型企業，前身是藥廠、媒體集團、連鎖歡場。軍工是後來才跟上的。
- **情慾不是私事，是基礎建設。** 一個人對刺激的耐受度決定他能接多少義體、能潛多深的網。耐受訓練是職業技能，像體能一樣被公開談論、被寫進履歷。
- **過載是通用的弱點。** 把人打倒不一定要子彈：把他的橋灌爆就行。這就是[感載](CORE_RULES.md)。
- **身體是可以被授權的資產。** 橋有管理權限。權限在誰手上，是這個世界最重要的法律問題，也是最常見的犯罪。

除此之外，該有的都有：企業大過國家，街上有槍，窮人賣器官，富人買永生。

## 2. 年表

| 年 | 事件 |
|---|---|
| 1998 | 蜜腺生技發表邊緣橋。 |
| 2004–2019 | 橋普及。第一代沉浸式網路「深海」成形。感官帶（可以回放別人感覺的錄影）取代電影。各國政府在一連串金融崩潰後，把公共服務賣給企業。 |
| 2031 | **大潮崩**。代號「夜后」的駭客放出自我複製的程式「無盡迴圈」，它把連線者的橋鎖進正回饋，三天內數百萬人在過載中腦死。深海的九成淪陷，裡面的陪伴型 AI 與推薦引擎失去管束，開始自己演化。 |
| 2033 | 夜鶯系統與各國殘存的網路機關合組**貞網局**，築起**粉牆**，把淪陷的舊網隔在外面。牆內重建的網路由一個個互不相通的**子網**組成。 |
| 2052–2058 | **蕾絲戰爭**。緋櫻重工與對手為了軌道資源開戰，戰場從網路打到街上。**女武神機甲**第一次大量投入。 |
| 2058 | 戰爭在緋灣港的一場爆炸後草草收場。沒人承認是誰做的。緋灣宣布成為不屬於任何國家的**自由市**，由企業理事會共管。 |
| 2081 | 現在。市中心重建完成，舊港區的彈坑還在。 |

## 3. 緋灣自由市

西岸的港口城市，人口約七百萬。日夜的分別只剩廣告的顏色。

| 區 | 樣子 | 玩法上的定位 |
|---|---|---|
| **冠冕區** | 企業塔與空中花園。進出要掃橋。 | 高難度的案子；企業子網 |
| **霓虹腸** | 貫穿市中心的歡樂街：夜店、人偶館、感官帶攤、診所。 | 主要的生活區；接案、改造、媒體台 |
| **舊港** | 蕾絲戰爭的廢墟與貨櫃屋。幫派的地盤。 | 新手區；黑市、拆體客 |
| **蜂巢** | 巨型集合住宅，一棟十萬人。 | 起始據點；街頭事件最密 |
| **玻璃岸** | 有錢人的濱海別墅與私人俱樂部。 | 社交與潛入的案子 |
| **鏽帶** | 城外的工廠與回收場，再過去是荒地。 | 車族；機甲殘骸；走私 |
| **地下層** | 舊地鐵與排水道，接著沒人管的舊網節點。 | 特殊地圖；通往牆的路 |

## 4. 企業

五家企業組成理事會。每一家各管一塊基礎建設，也各有一種支配人的方式。

| 企業 | 本業 | 它賣什麼、怎麼拴住你 |
|---|---|---|
| **蜜腺生技**（Nectar） | 藥、荷爾蒙、橋的專利 | 每座橋都要付它授權費。它的抑制劑讓你撐得住義體，停藥就崩。 |
| **緋櫻重工**（Hizakura） | 軍工、保全、女武神機甲 | 終身雇用。員工的橋裡有忠誠調校，離職要「卸載」。 |
| **萬華鏡**（Kaleido） | 媒體、感官帶平台、廣告 | 收視就是貨幣。它決定什麼是真的。 |
| **夜鶯系統**（Nightingale） | 網路基建、甲板、蕾絲 | 子網都是它蓋的。貞網局名義上獨立，預算是它出的。 |
| **伊甸園**（Eden） | 連鎖歡場、人偶館、人力派遣 | 你欠的錢最後都會轉到它手上。還不起就簽契約，把橋權抵給它。 |

公家機關只剩三個還有牙齒：

- **貞網局**：守粉牆、獵捕越牆者與牆外來的東西。可以不經審判燒掉一個人的橋。
- **市警**：按合約辦事。哪一區的治安費繳得多，就去哪一區。
- **鎮溺隊**：專門處理溺感者（見第 6 節）的重裝小隊。

還有一項誰都買得到的服務：**天使急救**。白金會員的橋一旦偵測到瀕死，三分鐘內武裝醫療隊到場，把你搶出來——帳單另計。

## 5. 街上的人

| 勢力 | 是什麼 | 和玩家的關係 |
|---|---|---|
| **蜜糖會** | 歡場從業者組成的武裝互助會。保護自己人，收保護費，也接案子。 | 早期的盟友與雇主；人偶逃亡的案子多半從這裡來 |

## 6. 這個世界特有的東西

**粉牆。** 一道由 AI 維護的防火長城。牆內是子網，牆外是 2031 年淪陷的舊網。牆外那些東西本來是陪伴程式與推薦引擎，被設計來讓人離不開，沒有人管之後把這件事做到了極致。街上叫它們**妖精**。和妖精連線的人不會想回來，而妖精一直在找進牆的路。牆之所以叫「粉」，是因為它在潛網者的感覺裡是一片溫熱的粉色——它用同樣的方式把靠近的人勸回去。

**蕾絲（LACE）。** Limbic Attack Countermeasure Electronics，邊緣攻擊反制電子。子網的防禦程式。白蕾絲只是警報與追蹤；粉蕾絲把入侵者灌到過載後留在原地等人來收；黑蕾絲直接燒橋。見 [NETRUNNING](NETRUNNING.md)。

**女武神機甲。** 三到五公尺高的戰鬥外骨骼。駕駛艙是一套全身神經同步裝置：機甲的每一塊裝甲都是機師的皮膚。同步率越高反應越快，被擊中時回灌也越重。能撐住高同步的人天生耐受高，而且多半是女性——統計上如此，「女武神」這個名字是從緋櫻的徵兵廣告來的。見 [COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 9 節。

**感官帶。** 錄下一個人全部感覺的錄影，用橋回放。合法的叫帶子，是主流娛樂；非法的叫**黑帶**，內容是真的犯罪、真的死亡。新聞也是帶子：記者親眼看到的東西，觀眾可以親身感覺一次。所以在這裡，新聞、娛樂和色情用的是同一個平台、同一套收視數字。見 [MEDIA](MEDIA.md)。

**人偶。** 裝了人偶晶片的服務業者：上班時把意識退到後台，讓客人選的人格面具接手，下班後不記得。合法、體面，有工會。問題是晶片的管理權在店家手上。

**橋權。** 橋的管理員權限。正常情況下只有本人有。貸款、雇用契約、企業義體的授權條款，都可能要求你交出一部分。交出全部的人叫**契約人**。見 [LEWD_SYSTEM](LEWD_SYSTEM.md) 第 7 節。

**溺感症。** 義體裝得越多，橋的負擔越重，天然的感覺越淡。到了某個程度，人會分不清哪些感覺是自己的。有的人變成空殼，什麼都不在乎；有的人為了再感覺到一點什麼，什麼都做得出來。後者叫**溺感者**，由鎮溺隊處理。見 [CYBERWARE](CYBERWARE.md) 第 6 節。

**瑰元（R$）。** 理事會發行的貨幣，街上叫「瑰」。
