# 竄網

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[CORE_RULES](CORE_RULES.md)（感載、同步原則、介面技能）、[CYBERWARE](CYBERWARE.md)（甲板、駭入接頭）、[COMBAT_SYSTEM](COMBAT_SYSTEM.md)（回合）。被依賴：[FIXER](FIXER.md)（案子的竄網解法）、[MEDIA](MEDIA.md)（偷素材、推流量）。
> 來源：ElondiaRPG 的法術環（→ RAM）與地下城分層探索（→ 子網）。預定資料：`data/rules/programs.json`、`lace.json`、`subnets.json`。數值都是初稿。

> **網路空間本身**（內海的地理、誰能潛入、化身與構裝、每條路數在網內的位置、網內的戰鬥）寫在 [CYBERSPACE](CYBERSPACE.md)。這份只寫「怎麼駭」。

竄網分兩種：站在現實裡丟程式的**快駭**，和把意識送進去的**深潛**。兩者人人都能做；**潛網者的專業是「介面」**——破解、接管、改寫，那是只有他們做得到的事。

## 1. 資源：RAM

取代 ElondiaRPG 的法術環。差別是它**每回合回復**，不用等長休——駭客的節奏在回合裡，不在一天裡。

```
RAM 上限 = 3 + mod(智識) + 甲板的加值
每回合回復 = 1 + 甲板的加值
```

- 甲板是腦部義體，等級決定 RAM、程式槽數、防火牆（抵擋資料傷害與反駭）。
- 脫離戰鬥後 RAM 立刻回滿。真正會耗盡的資源是**感載**與**追蹤度**。

## 2. 快駭

對視線內（自己的眼睛，或已經駭入的攝影機）的目標丟一個程式。檢定：`1d20 + mod(智識) + 介面` 對目標的防火牆。

| 類 | 例 | RAM | 效果 |
|---|---|---|---|
| 裝置 | 開鎖、關燈、迴圈攝影機、引爆、干擾 | 1～3 | 改變場景；不驚動人的話不加警報 |
| 義體 | 致盲（義眼）、鎖槍（智慧槍）、卡關節（義肢） | 2～4 | 讓目標的某件義體失效 1～3 回合 |
| 神經 | 撩撥、灌頂、迴圈 | 2～5 | 直接對目標造成感載；「迴圈」是持續型 |
| 控制 | 傀儡（義肢動一下）、遺忘（刪掉最近 30 秒）、誘導 | 4～6 | 高階；需要先上傳一個標記 |
| 支援 | 冷卻（幫隊友排感載）、掃描、標記 | 1～2 | |

- 每次快駭，目標所屬子網的**追蹤度**上升（第 5 節）。
- 目標義體越多，可以打的面越大。沒有橋的人只能從裝置下手。
- 神經類快駭和神經武器是同一條傷害軌，可以接力：槍手用感官彈墊，潛網者用「灌頂」收。

## 3. 深潛

在**接入點**接上線，意識進入內海或某個子網（接入點的種類見 [CYBERSPACE](CYBERSPACE.md) 2.2 節）。**有橋的人都能潛入**；能做什麼看甲板與路數。

- **身體留在現實**，不能動。現實的戰鬥與網內的行動走同一個先攻序列。潛入的人在自己的回合照常用行動點行動（用構裝戰鬥，見 [CYBERSPACE](CYBERSPACE.md) 第 6 節）；**潛網者另有管理行動**，每回合的次數＝介面階數：破解閘門、接管控制節點、改寫地形、擦掉追蹤度。這些事只有「介面」招牌能力做得到。
- **同步深度**套用同步原則（[CORE_RULES](CORE_RULES.md) 第 5 節）：淺同步安全但笨重，全同步所向披靡但蕾絲打進來是雙倍。換檔是每回合一次的自由動作——在蕾絲面前退到淺檔挨打，還是開到深檔拚一把先破它，是深潛的核心決策。
- **拔線**：自己登出花 1 點行動點，安全。被隊友強拔、被過載、或完整度歸零被踢出來，受一次**脫鉤衝擊**（感載 +10、暈眩一回合）。
- 沒有甲板的人可以被**帶潛**：借用帶他的人的構裝槽。用在護送委託人進去指認資料、帶新手隊友。

## 4. 子網

一個子網就是一座**地下城**，沿用 ElondiaRPG 的分層探索，換一層皮。子網掛在內海的企業環礁上（[CYBERSPACE](CYBERSPACE.md) 3.4 節）；主線的是手工設計，一般案子的隨機生成：

| ElondiaRPG 的地下城 | 子網 |
|---|---|
| 層（淺、中、深、底） | 權限層（訪客、員工、管理、核心） |
| 房間與走道 | 節點與鏈路 |
| 怪物 | 蕾絲、守衛程式、對方的潛網者 |
| 層主 | 每層的閘門守衛 |
| 寶箱 | 檔案庫 |
| 光線 | 追蹤度（第 5 節） |
| 安全房 | 後門：自己或前人留下的隱藏節點，可以存放程式、下次直接從這層進來 |
| 撤退 | 拔線 |

**節點種類：**

- **閘門**：通往下一層。破解（介面檢定）、用偷來的憑證（踩點的成果）、或繞路。
- **檔案庫**：案子要的東西通常在這裡。下載要幾個回合，期間不能離開。
- **控制節點**：連著現實的裝置——攝影機、門、砲塔、電梯、灑水器、整層樓的燈。拿下之後，隊友在現實的那一區得到好處（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 2 節）。**這是深潛和現實小隊的接點**，也是地圖設計的重點：子網的節點要和設施地圖的區域一一對應。
- **蕾絲節點**：見下。
- **人**：連在這個子網上的員工，他們的橋是節點。可以從這裡對他們快駭，不需要視線。

**蕾絲（LACE）：**

| 色 | 做什麼 | 被它打敗 |
|---|---|---|
| 白 | 不攻擊。發現入侵就拉警報、加追蹤度、鎖閘門。 | 現實裡的保全知道你在哪 |
| 粉 | 造成感載，目標是把入侵者灌到過載，然後**把他釘在線上**（不能拔線）等人來收。有的還會附帶惡意韌體。 | 等於被活捉（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 8 節） |
| 黑 | 造成資料傷害，直接打生命值。目標是燒掉橋。 | 瀕死 |

- 蕾絲是有生命值（完整度）、防火牆與行動模式的敵人，用 ElondiaRPG 的敵人資料格式。網內的戰鬥用同一套行動點戰鬥規則，只是武器換成程式：攻擊程式（破冰）、防禦程式（護盾、誘餌）、工具程式（隱形、後門、追蹤干擾）。
- 粉蕾絲有個性。高階的是半個 AI，會說話，會勸降，會依入侵者的橋參數挑手段。企業偏好粉的理由和偏好感官彈一樣：活捉的潛網者值錢。
- 黑蕾絲只在核心層與貞網局的設施出現。

## 5. 追蹤度

取代 ElondiaRPG 地下城的光線：一個隨著行動上升的壓力條，0～100，每個子網一條。

| 追蹤度 | 發生什麼 |
|---|---|
| 0～29 | 沒人知道 |
| 30～59 | 系統起疑：白蕾絲開始巡邏，閘門 DC +2 |
| 60～89 | 確認入侵：現實的保全進入警戒；對方的潛網者上線 |
| 90 以上 | **定位**：知道你的身體在哪。現實的增援往接入點去；這次留下的痕跡會加企業熱度 |

- 來源：每個管理行動 +1、破解失敗 +5、打蕾絲每回合 +3、觸發白蕾絲 +15、快駭依程式 +1～5。
- 降低：隱形類程式、踩點時預埋的後門、用駭入接頭直連（不走無線）、主播的假新聞干擾保全調度（[MEDIA](MEDIA.md)）。
- 潛完之後花行動「擦痕跡」，把殘留的熱度降下來。來不及擦就拔線的話，熱度照追蹤度算。

## 6. 潛網者在隊伍裡做什麼

設計上要避免跑團的老問題：「駭客自己玩一局，其他人等」。做法：

1. **全隊都能進去。** 每條路數在網內都有自己的位置（[CYBERSPACE](CYBERSPACE.md) 第 5 節），潛網者不是一個人下去。
2. **同一個先攻序列。** 網內的一個回合就是現實的一個回合。
3. **控制節點讓兩邊互相需要。** 現實的小隊要潛網者開門、關砲塔；潛網者要小隊把他送到接入點、守住他的身體。
4. **快駭讓潛網者不潛也有事做。**
5. **沒有潛網者也能過。** 破不了閘門，就讓閘門自己開：偽裝成管理員（伶人）、當場買憑證（掮客）、實地去插資料埠直通核心（戰鬥與潛入）、或外包給名冊上的 NPC 潛網者（[FIXER](FIXER.md)）。

## 7. 粉牆與牆外

竄網線的終局內容。

- **牆**在遊戲裡是地下層某些舊網節點深處的一道閘門，守它的是整個遊戲最強的粉蕾絲——牆本身。它不想殺你，它想讓你舒服地回頭。打輸的後果是醒來時不記得為什麼想過去。
- **牆外**是一座沒有底的子網。規則和牆內不同：
  - 沒有追蹤度。取而代之的是**沉溺度**：待得越久，登出的檢定越難。
  - 敵人是**妖精**。它們不攻擊，而是**提出交易**：一個你要的東西（一段失落的資料、一個程式、一個死人的印記），換你的一樣東西（一段記憶、一部分橋權、把它的一小片帶進牆內）。交易用 ElondiaRPG 的談判系統。
  - 妖精給的東西是真的、而且是牆內買不到的。代價也是真的。
- **妖精的吻**：和妖精連線過留下的惡意韌體（[CYBERWARE](CYBERWARE.md) 第 5 節）。初期只是偶爾聽見它的聲音、得到一些有用的提示；後期它開始替你做決定。可以清除，但清掉就失去它給的能力。
- **貞網局**：越過牆的人會被標記。之後貞網局的熱度永久有一個下限。
- **牆語者**想把牆打開。主線的其中一條會走到這個選擇。
