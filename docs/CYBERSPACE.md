# 網路空間：內海

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[CORE_RULES](CORE_RULES.md)（屬性、技能、感載、同步原則、路數）、[NETRUNNING](NETRUNNING.md)（快駭、蕾絲、追蹤度）、[COMBAT_SYSTEM](COMBAT_SYSTEM.md)（回合與站位）。被依賴：[NETRUNNING](NETRUNNING.md)（子網在內海的位置）、[DISTRICTS](DISTRICTS.md)（接入點）、[FIXER](FIXER.md)（網內的案子）。
> 來源：ElondiaRPG 的隨機地下城（分層、層主、寶箱、陷阱）搬到這裡。預定資料：`data/world/cyberspace.json`、`data/rules/constructs.json`。結構圖：[`art/preview/cyberspace.png`](art/preview/cyberspace.png)。數值都是初稿。

緋夜城有兩座：一座在地上，一座在線上。線上的那座叫**內海**——粉牆以內的網路空間。它不是駭客專用的後台，而是一個**所有人都會去的地方**：買東西、看演唱會、打遊戲、談生意、偷東西、打架。牆的另一邊是**深海**。

分工：這份寫「網路空間是什麼地方、誰能進去、進去之後怎麼玩」；[NETRUNNING](NETRUNNING.md) 寫「怎麼駭」（快駭、程式、蕾絲、追蹤度）。

## 1. 兩座城市

| | 現實（緋夜城） | 網路（內海） |
|---|---|---|
| 地圖 | 幾乎都是**固定**的（[DISTRICTS](DISTRICTS.md) 1.3 節） | 公共區固定；**其餘大量隨機生成** |
| 身體 | 就是你 | **化身**。身體留在現實 |
| 被打倒 | 生命值歸零：瀕死 | 完整度歸零：被踢回現實 |
| 共通 | **感載是同一條**。在網內被灌到過載，現實的身體也過載 | |
| 裝備 | 槍、護甲、義體 | **構裝**（第 4 節） |
| 時間 | 一比一。網內過一小時，現實也過一小時 | |
| 探索的樂趣 | 認識一座城市：每條街都有人認得你 | 下潛：每次進去都不一樣，越深越怪 |

這個分工是刻意的：**現實給熟悉感，網路給未知**。固定地圖讓城市有記憶，隨機地圖讓重玩有變化，兩者各放在適合的地方。

## 2. 怎麼進去

### 2.1 兩種連線

| | 投影 | 潛入 |
|---|---|---|
| 是什麼 | 橋把網路的畫面疊在視野上。人還在走路 | 意識整個進去。身體躺著不動 |
| 能做什麼 | 耳語、看牆報、逛大街的櫥窗、付錢、快駭 | 在內海裡走動、進任何區、戰鬥 |
| 需要 | 橋 | 橋，加上一個**接入點** |
| 風險 | 幾乎沒有 | 身體沒人顧；感載是真的 |

### 2.2 接入點

| 接入點 | 在哪 | 進去之後在哪 | 特性 |
|---|---|---|---|
| 自己的床 | 據點 | 港灣（自己的房間） | 免費；安全程度等於據點的安全程度 |
| 據點的接入艙 | 二級以上的據點 | 港灣 | 身體有鎖、有維生；可以多人一起潛 |
| **潛艙店** | 街上。每個區都有，霓虹腸與櫻町最多 | 大街 | 付費的隔間，像網咖；便宜的不鎖門；有紀錄 |
| 設施的資料埠 | 案子的目標建築裡 | **那個設施的子網核心** | 繞過所有外圍防禦——這是實地潛入的理由 |
| 地下層的舊網節點 | 地下層中層與深層 | 沉船帶；深層的那一個通往「門」 | 不留追蹤度；也沒有任何保護 |

### 2.3 誰能進

**有橋的人都能潛入。** 不需要是潛網者。

| | 能去哪 | 能做什麼 |
|---|---|---|
| **訪客**（沒有甲板） | 港灣、大街、樂園島 | 逛、買、玩。沒有構裝，不能戰鬥，遇到事只能登出 |
| **租用甲板**（潛艙店附的） | 以上，加上暗礁的外圍 | 2 個構裝槽；有紀錄；被踢出去要賠押金 |
| **自己的甲板** | 任何地方 | 依甲板等級（第 4 節） |
| **被帶潛** | 帶你的人能去的地方 | 借用對方的構裝槽。用在護送委託人、帶沒有甲板的隊友 |

沒有橋的人（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 1 節）進不來。他們只能用板子看到內海的文字介面——那是另一種完全不同的、安全的、盲的體驗。

### 2.4 身體

潛入的時候，身體是最大的弱點。

- 身體在現實受到傷害，化身立刻知道（並受一次干擾）。
- **追蹤度**到「定位」（[NETRUNNING](NETRUNNING.md) 第 5 節），對方就知道身體在哪——現實的人會去找它。
- 隊伍的標準做法：一部分人潛入，一部分人守著。或者全員一起潛，把身體留在夠安全的地方——「夠不夠安全」是踩點的一項。

## 3. 內海的地理

越往裡越深，越深越沒有規矩。

| 區 | 是什麼 | 誰在這裡 | 危險 | 地圖 |
|---|---|---|---|---|
| **港灣** | 登入點。每個人有一間自己的**房間** | 你，和你邀請的人 | 無 | 固定 |
| **大街** | 內海的市中心：商店、銀行、市政、牆報廣場、萬華鏡的頻道大廳 | 所有人 | 無。貞網局巡邏，禁止戰鬥 | 固定（3 塊） |
| **樂園島** | 娛樂區：遊戲館、演唱會場、擂台、主題館、賭場 | 玩家、觀眾、偶像、賭徒 | 低；館內的危險是「遊戲的一部分」，但感載是真的 | 場館固定（3 塊）；**館內關卡隨機** |
| **企業環礁** | 一圈島，每家企業一座。外圍是客服與商店，裡面是子網 | 員工、客戶、蕾絲、入侵者 | 中～高 | 各家前台固定；主線的子網固定；**一般案子的子網生成** |
| **暗礁** | 沒有登記的節點：黑市、同人伺服器、駭客的窩、無照擂台 | 潛網者、同人眾、牆語者、資料掮客、貞網局的臥底 | 中 | 據點固定（2 塊）；其餘**會搬家** |
| **沉船帶** | 大潮崩時被隔在牆內的舊網殘骸。沒人維護，沒人管 | 拾荒的人、殘留的程式、野生的蕾絲 | 高 | **隨機** |
| **深海** | 牆外 | 妖精 | 不是高低的問題 | **隨機**，規則不同（[NETRUNNING](NETRUNNING.md) 第 7 節） |

### 3.1 港灣

每個有橋的人在內海都有一間房間。它是網內的據點：

- 可以佈置（外觀是風格的一部分）、存放構裝與資料、邀請別人進來談事情。
- **房間有鎖**，鎖的強度看甲板。被闖入是一種事件：有人翻過你的東西。
- 中間人常在自己的房間見人——比現實安全，因為誰都帶不了槍進來。

### 3.2 大街

現實的商店多半在這裡有分店，另外賣只存在於網內的東西：

| 店 | 賣什麼 |
|---|---|
| 構裝店 | 合法的構裝：護盾、工具、遊戲用的武器構裝 |
| 皮店 | 化身的外觀。緋櫻映像的聯名款最貴 |
| 夜鶯服務中心 | 甲板的登記、更新、維修 |
| 牆報廣場 | 全城各區的牆報匯集在這裡（[LIFE](LIFE.md) 第 7 節）。一般案子的來源 |
| 頻道大廳 | 萬華鏡的入口。主播與偶像的頻道在這裡有「門面」 |
| 銀行 | 帳戶。洗錢不在這裡，在暗礁 |

大街是安全區：動手會被貞網局當場踢出並記錄。所以它也是談判的好地方。

### 3.3 樂園島

內海最熱鬧的地方，也是**隨機地圖最大的來源**。每座館是一個入口，進去之後是館方生成的空間。

| 館 | 玩法 | 生成 |
|---|---|---|
| **迷宮館** | 組隊闖關的遊戲：打程式生成的敵人、解機關、打館主。破關有獎金與稀有構裝 | 每次進去都不同。分層，越深獎越好——就是 ElondiaRPG 的地下城 |
| **競技場** | 化身對化身。有排名、有賭盤 | 固定的幾張場地 |
| **感官擂台・線上** | 比誰先過載（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 6 節）的網路版，觀眾更多 | 固定 |
| **演唱會場** | 虛擬偶像與真人偶像的公演。萬人同步 | 固定；演出內容隨偶像 |
| **主題館** | 溫泉、海灘、古城、太空站……想得到的場景。也有成人向的館 | 固定的幾種，細節隨機 |
| **賭場** | 伊甸園與胭脂堂各開一間 | 固定 |

- 迷宮館是**合法的地下城**：打輸只是被踢出來。它是練手、賺錢、找隊友的地方，也是偶像與主播的舞台（闖關可以直播）。
- 館方是企業（多半是萬華鏡與伊甸園）。有些館的深層接著不該接的東西——沉船帶的一角、企業的實驗、被關在裡面出不來的人。
- 遊戲裡的「死亡」不痛。但館內的感載是真的，有些館靠這個賺錢。

### 3.4 企業環礁

每家企業一座島，結構相同：

```
前台（公開：客服、商店、展示廳）→ 員工區（要憑證）→ 管理區 → 核心
```

- 這就是 [NETRUNNING](NETRUNNING.md) 第 4 節的**子網**。從內海正面進去，要一層一層打穿；從設施內的資料埠進去，直接到核心附近。
- 企業在現實的**每一棟設施**各有一個子網，掛在島上。控制節點連著現實的那棟樓。
- 主線與特殊任務的子網是手工設計的；一般案子的子網依企業與設施類型生成。

### 3.5 暗礁

沒有地址的地方。要有人帶、或自己找到入口。

- **蚌殼市**：網內的黑市。違禁構裝、偷來的資料、憑證、假身分、洗錢。
- **同人伺服器**：同人眾的地盤（[GANGS](GANGS.md) 第 4 節）。同人夜市的線上版，每天都開。
- **窩**：潛網者團體的據點。牆語者在這裡有前哨。
- 暗礁的節點會被貞網局掃蕩，所以**會搬家**：固定的只有兩個老據點，其餘每隔幾天換位置，要重新打聽。

### 3.6 沉船帶

大潮崩那三天，有一部分舊網沒有被隔到牆外，而是沉在牆內的底部。破碎的伺服器、斷掉的連結、沒人關的程式。

- **全部隨機生成**。每一艘「船」是一座地下城：分層、有守在裡面的東西、有寶。
- **能撈到的**：大潮崩之前的程式（有些比現在的好，有些有問題）、失落的資料（值錢）、死在那三天的人留下的**印記**——一小段人格的殘片，會說話，不知道自己已經死了。
- **在裡面的**：殘留的失控程式（街上叫**遺魂**）、沒有主人的野生蕾絲、「無盡迴圈」的碎片（碰到就開始灌，要立刻脫離）、別的拾荒者。
- 不屬於任何企業，所以**沒有追蹤度**。壓力來自別的東西：越深，登出的訊號越弱。
- 離牆越近的船越完整、越危險。最深的那幾艘貼著牆。

### 3.7 深海

見 [NETRUNNING](NETRUNNING.md) 第 7 節。地圖上，它是沉船帶的延續：沒有底的隨機生成，規則不同（沒有追蹤度，只有沉溺）。

## 4. 化身

潛入之後，你是一個化身。

### 4.1 數值

```
完整度 = 10 + 智識 × 2 + mod(膽識) × 2 + 甲板的加值          （初稿）
```

- **完整度**是化身的生命值。歸零時被踢回現實：脫鉤衝擊（感載 +10、暈眩一回合），之後一小時不能再潛入。**不會死**。
- **感載**是同一條（[CORE_RULES](CORE_RULES.md) 4.2 節）。網內過載＝現實過載。
- **生命值**在網內不會掉——除了黑蕾絲的資料傷害，它越過完整度直接打身體。
- **屬性**照用，只有一項替換：**體格在網內由膽識代替**。化身的強度不是肌肉，是意志。於是一個瘦弱但膽識高的人，在內海可以是巨人。
- **技能**照用。槍械就是槍械，格鬥就是格鬥——只是拿的是構裝。這是關鍵：**在現實會做的事，在網內也會**，不必重新學一套。
- **行動點**照舊。**RAM** 是網內的能量，有甲板的人都有；構裝的特殊動作與快駭都花它。

### 4.2 構裝

網內的裝備。存在甲板裡，槽數看甲板等級。

| 類 | 是什麼 | 對應現實的 |
|---|---|---|
| 武器構裝 | 網內的槍與刀。打完整度（資料傷害）或感載（神經傷害），看型號 | 武器 |
| 防護構裝 | 護盾、誘餌。減少受到的資料傷害 | 護甲 |
| 工具構裝 | 隱形、探針、後門、追蹤干擾 | 工具 |
| 駭入程式 | 破解閘門、接管節點、快駭。**要「介面」招牌能力才能用** | — |
| 專屬構裝 | 各路數的招牌能力在網內的形式（第 5 節） | — |
| 構裝體 | 大型的戰鬥化身。機師專用 | 機甲 |
| 皮 | 外觀。給風格 | 服裝 |

- 構裝有品級與牌子（[LIFE](LIFE.md) 第 4、5 節）：夜鶯的穩但會回報、聖堂的強但沒有保護、同人的有怪癖、沉船帶撈上來的不照規則。
- 沒有甲板＝沒有構裝槽＝不能戰鬥。**甲板因此是所有人都值得買的裝備**，不只是潛網者的。入門甲板 2,500，4 槽。

### 4.3 同步深度

潛入時每個人都選一個同步檔位（[CORE_RULES](CORE_RULES.md) 第 5 節）。深檔讓化身更強，回灌更重。這個旋鈕不是潛網者專屬的。

## 5. 每條路數的兩面

**八條路數在網路空間都有自己的位置。** 潛網者是網內的專家，但不是唯一能在網內戰鬥的人——正如槍手是現實的戰鬥專家，但不是唯一能開槍的人。

招牌能力在兩邊各有一種表現，階數共用：

| 路數 | 現實 | 網路 | 在網內的角色 |
|---|---|---|---|
| **槍手**・戰鬥直覺 | 分配先攻、命中、迴避 | **戰鬥構裝精通**：同樣的分配；武器構裝的傷害骰加大；可以同時持有兩把武器構裝 | 前鋒。把蕾絲打掉的人 |
| **潛網者**・介面 | 快駭 | **管理行動**：破解閘門、接管控制節點、改寫地形（造牆、斷路、開後門）、降低追蹤度。每回合額外的次數＝階數 | 開路的人。沒有他，隊伍只能走正門 |
| **改造師**・手術刀 | 手術、急救、解鎖 | **除錯**：修復隊友的完整度、清除惡意韌體、**解剖**被打倒的蕾絲取得構裝與憑證 | 醫護與拆解。戰利品的來源 |
| **主播**・聚光燈 | 素材、直播 | **導流**：把觀眾的流量當成資源——灌向一個節點讓它癱瘓、照亮隱形的敵人、把一場網內的戰鬥變成全城在看的事 | 控場。把「被看見」當武器 |
| **掮客**・人面 | 名冊、抽成、人情 | **代理**：當場買到憑證與後門、租用守衛程式當傭兵、把名冊上的人遠端叫進來 | 補給與增援。用錢和人情解決問題 |
| **伶人**・入戲 | 人格面具、誘惑 | **偽裝**：化身冒充成別的身分——員工、管理員、甚至某個蕾絲。高階的蕾絲有人格，所以**可以被說服、被誘惑、被騙** | 滲透。不打穿閘門，而是讓閘門替你開 |
| **偶像**・應援 | 分擔感載、曲目 | **共鳴**：同樣的應援，範圍更大（網內沒有距離）；可以**安撫**蕾絲與遺魂，讓它們暫時不攻擊；演唱會場是她的主場 | 輔助與安撫。能和「不是人的東西」溝通的人 |
| **機師**・同步 | 女武神機甲、載具 | **構裝體**：駕駛大型的戰鬥化身，有自己的完整度與武器；遙控現實的無人機與機甲 | 重火力。網內的坦克，也是現實與網路之間的橋 |

設計上的保證：

- **每條路數在網內都有「只有它做得到」的事**，就像在現實一樣。
- **沒有潛網者的隊伍進得了內海**，也打得了架，只是破不了閘門——要靠偽裝（伶人）、買憑證（掮客）、或實地去插資料埠。
- **沒有槍手的隊伍在網內一樣打得贏**，只是慢。
- 成長是一份：升了招牌能力，兩邊一起變強。玩家不必在「現實的自己」與「網路的自己」之間分配點數。
- 但**裝備是兩份**：現實要槍與護甲，網內要甲板與構裝。錢怎麼分，是每個角色的取捨。

## 6. 網內的戰鬥

用的是同一套戰鬥規則（[COMBAT_SYSTEM](COMBAT_SYSTEM.md)），換了名詞：

| 現實 | 網路 |
|---|---|
| 生命值 | 完整度 |
| 護甲 | 防護構裝 |
| 掩體 | 防火牆節點（站在它後面；可以被打穿，也可以被潛網者造出來） |
| 站位：掩體／暴露／近身 | 相同 |
| 動能、利刃、熱能…… | **資料**（打完整度）、**神經**（打感載）、**干擾**（讓構裝失效，網內的電磁） |
| 彈藥 | RAM |
| 重創 | **破損**：一個構裝槽暫時失效 |

**兩種打法**在網內同樣成立，而且差別更大：

| | 打完整度 | 打感載 |
|---|---|---|
| 結果 | 對方被踢回現實。**人沒事**，一小時後可以再進來，而且知道是誰幹的 | 對方過載。現實的身體也倒了；可以把他**釘在線上**（不能登出），讓現實的隊友去找他的身體 |
| 適合 | 趕人、爭取時間 | 活捉、滅口、斷後 |

企業的粉蕾絲選的是第二種。這就是為什麼在網內打輸可以比在現實打輸更糟。

**敵人**：蕾絲（白、粉、黑）、守衛程式、企業的潛網者與保全化身、遺魂、別的入侵者、迷宮館的遊戲敵人、妖精。用 ElondiaRPG 的敵人資料格式。

## 7. 雙層的案子

一件案子可以發生在：

| 類型 | 例 | 隊伍 |
|---|---|---|
| **只在現實** | 護送、討債、街頭的衝突 | 全員在現實；潛網者用快駭 |
| **只在網路** | 迷宮館的比賽、暗礁的交易、從內海正面入侵企業環礁、沉船帶的打撈 | 全員潛入；身體放在安全的地方 |
| **雙層** | 潛入一棟樓：一組人在裡面走，一組人在它的子網裡開門、關砲塔 | 分兩組，同一個先攻序列，兩邊互相影響（控制節點） |
| **接力** | 先在現實拿到資料埠，再全員從那裡潛進核心 | 先一起，再一起 |

雙層是這款遊戲最有特色的場面，但不是每件案子都要是。前兩種讓「全隊一起行動」保持是常態。

## 8. 地圖的規模

網內地圖用同一套格子引擎。

| | 塊數 | 生成 |
|---|---|---|
| 港灣（房間） | 1（小，7×5，可佈置） | 固定 |
| 大街 | 3 | 固定 |
| 樂園島的場館區 | 3 | 固定 |
| 暗礁的老據點 | 2 | 固定 |
| 企業環礁的前台 | 7（理事會六家加貞網局，各一小塊） | 固定 |
| 主線與特殊任務的子網 | 約 15 座，每座 3～4 層 | 固定 |
| 一般案子的子網 | 無限 | **生成**：依企業（蕾絲的風格）與設施類型（結構） |
| 迷宮館的關卡 | 無限 | **生成**：幾種主題，分層 |
| 沉船帶 | 無限 | **生成**：每艘船一座 |
| 深海 | 無限 | **生成**：另一套規則 |

- 隨機生成沿用 ElondiaRPG 的地下城生成器：`carve_steps` 挖出結構，依層放敵人、陷阱（→ 警報與迴圈碎片）、寶箱（→ 檔案庫）、層主（→ 閘門守衛）。
- 每種生成地圖有**主題**（企業的冷白、樂園的糖果色、沉船帶的鏽與雪花、深海的粉）與**詞條**（這一座特別的地方：「有一個還在運作的印記」「蕾絲全是粉的」「登出點只有一個」）。詞條讓隨機地圖每次有個說法，也給 AI 敘事材料。

## 9. 網內的人

- 固定 NPC 在兩邊都有（[NPCS](NPCS.md)）：中間人在港灣見人；蕾諾拉只在網內；澪只在樂園島；貞網局的霜兩邊都追。
- **常駐者**：幾乎不登出的人。身體在潛艙店的長租隔間、療養院、或某個沒人知道的地方。他們是內海的在地人——店員、嚮導、賭徒、傳教的。有些人的身體已經不在了，自己不知道。
- **AI**：店員、客服、遊戲裡的角色。法律上是程式。有幾個不太確定。
- 化身可以和本人長得完全不同。**網內認識的人，在現實見面時可能認不出來**——這是關係線與偽裝的材料。豔名與街頭信譽在網內用的是化身的名字，可以和現實分開經營，也可以被人連起來。

## 10. 成人向

- 樂園島有成人向的主題館；暗礁有不合法的。
- 網內的親密是化身之間的，但**感載是真的**，橋參數照樣成長（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 1、3 節）。
- 化身可以不是自己的樣子，所以網內的關係多一層「對方到底是誰」。
- 粉蕾絲、遺魂、妖精的手段，以及在網內過載被釘住的戰敗事件，都受內容篩選控制（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 9 節）。
- 所有化身背後的人都是成年人；化身的外觀同樣不得呈現為未成年。
