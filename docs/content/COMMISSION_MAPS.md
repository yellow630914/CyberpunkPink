# 委託副本的地圖版面

> 上層：[SITES](../world/SITES.md) 第 12 節（版面上的標記、掩體配置、誰住進去）、[COMMISSION_TEMPLATES](COMMISSION_TEMPLATES.md) 的「現實面的地圖模板」（每張圖要放什麼）。依賴：[COMMISSIONS](../systems/COMMISSIONS.md) 2.3 節（階段）與第 5 節（連動）、[NETRUNNING](../systems/NETRUNNING.md) 第 4 節（控制節點）、[COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 2.1、2.5 節（遮蔽、場地效果）。資料：[DATA](../systems/DATA.md) 9.3 節。
> 這份是 `data/world/commission_maps.json` 的版面設計稿。圖例、座標與記法是定案；各張的版面是 L4 的內容，之後可以個別調。

COMMISSION_TEMPLATES 寫了三十張現實面模板「要放什麼」；這份把每一張（串多張的每一張都畫）畫成格子版面，引擎可以直接讀。一共 30 個模板、52 張圖。每張圖下面列區塊、入口與條件、目標與其他標記、遭遇點的掩體配置、控制區對應的子網控制節點、巡邏、踩點揭開的東西在哪一格，以及張與張怎麼接。所有登場的人都是成年人。

## 1. 怎麼讀

### 1.1 圖例

每一格一個字元，用等寬字型看。版面只用下面這些字元；區塊另外畫在右邊的區塊圖。

| 字元 | 資料裡的名字 | 意思 |
|---|---|---|
| `#` | `wall` | 牆 |
| `.` | `floor` | 室內的地板 |
| `,` | `ground` | 戶外的地面（街、院子、甲板、堆場） |
| `~` | `water` | 水（不能走；排水道的深水、碼頭外的海） |
| `+` | `door` | 門（開著或一推就開） |
| `%` | `door_locked` | 上鎖或要條件的門（門禁、鑰匙、機械檢定） |
| `=` | `window` | 窗（不能走；標成 E 的窗才是入口） |
| `^` | `vent` | 通風口、管道口、線槽口（爬得進去） |
| `<` | `stair_up` | 往上的樓梯、梯子 |
| `>` | `stair_down` | 往下的樓梯、梯子、人孔 |
| `H` | `lift` | 電梯、貨梯、升降台 |
| `O` | `cover` | 掩體的擺設（擋路） |
| `o` | `half_cover` | 半掩體的擺設（擋路） |
| `*` | `crowd` | 人群（可以穿過；打起來算打不破的半掩體） |
| `$` | `safe` | 保險箱、保險櫃、金庫 |
| `F` | `facility` | 街區地圖上的設施門口（店、診所、住處）；委託副本的版面不用 |
| `&` | `hostage` | 人質的位置 |
| `E` | `entry` | 入口 |
| `T` | `target` | 目標點 |
| `D` | `data_port` | 資料埠 |
| `C` | `control` | 控制區的面板（控制區的範圍見表） |
| `G` | `guard` | 保全崗 |
| `S` | `camera` | 監視器 |
| `K` | `credential` | 憑證點 |
| `X` | `extract` | 撤離點 |
| `1`～`9` | `spot` | 遭遇點 ①～⑨（數字就是模板的編號） |

- 大寫的 `E T D C G S K X` 是 SITES 12.1 節的標記，`$` 與 `&` 是 COMMISSION_TEMPLATES「放東西的位置」裡的保險箱與人質。標記站的那一格可以走（窗上的 `E` 也是）。
- `O` 與 `o` 只是描寫用的擺設，告訴你那一區打起來哪裡是掩體、哪裡是半掩體；遮蔽只分掩體與半掩體，不另外標材質（DECISIONS 2026-11-20）。真正的八格遮蔽照遭遇點的配置（1.3 節）。
- 區塊圖：同一個小寫字母是同一個區塊；`#` 是牆，`~` 是水。門、入口與擺設算在它所在的那一區。區塊的名字寫在每張圖的區塊表。

### 1.2 座標與編號

- 座標寫成（x,y），左上角是（0,0），x 往右、y 往下，和 `ui/` 的地下城、家園的 `'x,y'` 一樣。每張圖的格數就是模板寫的大小（9×9、11×9、13×9），外牆也算在裡面。
- 同一種標記照「由上到下、由左到右」編號：`E1`、`E2`、`T1`……表裡的 id 就是這個順序。`$`、`&` 也一樣（`$1`、`&1`）。
- 遭遇點直接寫模板的編號：圖上的數字 `1` 就是 ①，資料裡寫 `!1`。串多張的模板，編號在整個模板裡不重複（辦公樓層的 ① 在大廳、②③④ 在目標樓層）。
- 串多張時，張與張之間的樓梯（`<` `>`）、電梯（`H`）與相通的門寫在每張圖的「接到別張」，不算 `E`。寫座標的連接（例如宅邸的大門（6,0））就是那一格。

### 1.3 遭遇點的配置

照 SITES 12.2 節的四種，寫法是「我方 4→1｜敵方 1→4」：

| 配置 | 資料 | 我方 4→1｜敵方 1→4 |
|---|---|---|
| 密 | `dense` | 掩 掩 半 半｜半 半 掩 掩 |
| 中 | `medium` | 掩 半 半 暴｜暴 半 半 掩 |
| 稀 | `sparse` | 半 暴 暴 暴｜暴 暴 暴 半 |
| 一邊倒 | `one_sided` | 半 暴 暴 暴｜掩 掩 半 半 |

- 「一邊倒」照 COMMISSION_TEMPLATES 的寫法（例：小辦公室 ②、檢查哨 ①）：守方是敵人，敵方佔好位置。從後門進來、或我方埋伏時對調。和 SITES 12.2 節的表一致。
- 埋伏與被埋伏照 [COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 2.1 節再調一級；遭遇點寫的「黑暗」「人群」「煙霧」照 2.5 節與 COMMISSION_TEMPLATES 的寫法。

### 1.4 標記的數量怎麼算

- 照 SITES 12.1 節：「每張至少」的 `E T D C G K X` 以**一個模板**算（一個副本可以串的全部張數），遭遇點以**每一張**算（至少 2 個）。和 SITES 第 15 節 `commission_maps` 一個模板一筆 `markers` 的寫法一致。
- `T` 每張最多 3。模板說保險箱就是某個目標點時（片場的母帶櫃）只標 `T`。
- 每張圖的實際數量列在第 32 節，那一節的數字是用程式從版面數出來的。

### 1.5 已經有的規則，圖上怎麼用

| 規則 | 出處 | 在這些圖上 |
|---|---|---|
| 現實面一般的階段是「一段探索加一場遭遇」，最後一個階段是一場戰鬥或一次動手的檢定 | [COMMISSIONS](../systems/COMMISSIONS.md) 2.3 節 | 一個階段用一張圖的一段路與一個遭遇點；串多張的模板通常一個階段一張 |
| 入口對應分支：正門是強攻，後門、通風、屋頂多半是潛行，員工門、送貨口多半是交涉或偽裝；寫「要踩點」的入口沒揭開就不存在 | COMMISSION_TEMPLATES 的「現實面的地圖模板」 | 每個 `E` 的種類與條件照模板抄進入口表；選了哪一條分支，隊伍就從那個 `E` 進來 |

## 2. 小辦公室（`map_office_small`）

模板見 [COMMISSION_TEMPLATES](COMMISSION_TEMPLATES.md) 的「小辦公室」。9×9，一個副本用 1 張；四個區塊、2 個遭遇點。適合：竊密、抹除、竄改、蜜罐、討債。辦公室在二樓：正門是樓梯間上來的那扇門，二樓的窗開在開放座位的外牆。

```text
   012345678   012345678
 0 ####=E###   ####bb###
 1 #TOT#.OS#   #ccc#bbb#
 2 #.2.%G1.#   #ccccbbb#
 3 #DC.#o.o#   #ccc#bbb#
 4 ######+##   ######a##
 5 #T&.#.GS#   #ddd#aaa#
 6 E...%.O.#   dddddaaa#
 7 #X..#C.K#   #ddd#aaa#
 8 ######E##   ######a##
```

左邊是版面，右邊是區塊。座標寫成（x,y），左上角是（0,0）。

| 區塊 | 名稱 | 這一區有什麼 |
|---|---|---|
| a | 接待區 | E3、C2、G2、K1、監視器 1 |
| b | 開放座位 | E1、G1、監視器 1、① |
| c | 主管室 | T1、T2、D1、C1、② |
| d | 茶水間與後門 | E2、T3、X1、&1 |

| 入口 | 座標 | 種類 | 走它要什麼 |
|---|---|---|---|
| E1 | (5,0) | 二樓的窗（`window`） | 運動對 DC 基準＋3，全隊每人都要擲，一人失敗警戒 +10。夜間才開放。 |
| E2 | (0,6) | 後門（茶水間旁的防火門）（`back`） | 機械對 DC 基準，或拿到 `K` 的員工卡。 |
| E3 | (6,8) | 正門（`front`） | 沒有條件。營業時間要擲表演（扮成客戶或送貨員）對 DC 基準，失敗就照強攻算。 |
