# 身上的裝備：穿著、飾品與攜帶

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[CRAFTING](CRAFTING.md)（底材與零件）、[CYBERWARE](CYBERWARE.md) 第 1 節（義體的部位）、[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 2 節（曝露度與風格）、[LIFE](LIFE.md) 第 3 節（合法性）、[COMBAT_SYSTEM](COMBAT_SYSTEM.md)（護甲、用道具）。被依賴：[DISTRICTS](DISTRICTS.md)（各區的掃描與風格）、之後的 `ITEMS`。
> 來源：ElondiaRPG 的裝備欄位（18 格加額外飾品格）、曝露度與真空、NPC 的服裝。預定資料：`data/rules/equipment.json`、`gear.json` 的 `slots`。數值都是初稿。

ElondiaRPG 的欄位是為奇幻設計的：武器看哪隻手拿，護甲就是上身那一件，飾品多是因為要放附魔。這裡重新分。

## 1. 四層

一個角色身上的東西分四層：

| 層 | 是什麼 | 幾格 | 寫在哪 |
|---|---|---|---|
| **身體** | 義體，九個部位 | — | [CYBERWARE](CYBERWARE.md) 第 1 節 |
| **穿著** | 衣服與護甲 | 10 | 第 2 節 |
| **飾品** | 首飾、配件 | 5（可以用存檔規則增加） | 第 3 節 |
| **攜帶** | 武器與隨手拿得到的道具 | 3 ＋快取格 | 第 4 節 |

行囊是另外的：放在行囊裡的東西不算「身上」，戰鬥中拿不到。

## 2. 穿著（10 格）

| 欄位 | 放什麼 | 組裝嗎 | 備註 |
|---|---|---|---|
| 頭部 | 帽、兜帽、盔 | 是 | |
| **面部** | 面具、眼鏡、口罩、面紗 | 是 | 偽裝、濾鏡、防掃描都靠它。這座城市戴面具很平常 |
| 上身 | 上衣、襯衫 | 是 | 連身類同時佔上身與下身 |
| 下身 | 褲、裙 | 是 | |
| **外套** | 夾克、大衣、長外套、披肩 | 是 | 這個題材最有代表性的一件。蓋住底下的東西（第 5 節），也決定能藏多少（第 6 節） |
| **護甲** | 防彈衣、戰術背心、重甲 | 是 | 從上身分出來。穿在外套底下 |
| 手 | 手套 | 是 | |
| 鞋 | 鞋、靴 | 現成 | |
| 內衣 | | 現成 | |
| 內褲 | | 現成 | |

- 「組裝」的格子裡放的是用底材與零件組出來的成品（[CRAFTING](CRAFTING.md) 3.3 節）；「現成」的是單件物品。
- 裝甲制服（女僕服、執事服、高訂）是連身類，佔上身與下身；它自帶護甲，所以通常不另外穿護甲格。
- 重甲佔護甲格，而且**不能再穿外套**。
- **獸耳與尾巴不影響穿搭。** 這個世界的衣服預設都有可以開的孔（拉鍊、暗扣）——獸化改造太普遍，成衣業早就這樣做了。所以帽子不擋耳朵，褲子與裙子不擋尾巴，不需要為此另外處理。義肢同理：手套與鞋預設相容。

## 3. 飾品（5 格，可增加）

| 欄位 | 放什麼 | 備註 |
|---|---|---|
| **頸** | 項鍊、項圈、領巾 | 獨立一格：項圈在這個世界有意義（契約的可見標記、時尚、或兩者都是） |
| **腿** | 腿環、吊帶襪、長襪 | 影響曝露度與風格 |
| 通用 ×3 | 戒指、耳環、穿孔飾品、手環、腰鍊、胸針、髮飾、錶 | 不分部位。同一種可以戴不只一個 |

- 飾品是現成的單件，不組裝。它們給的多半是風格、小幅的親和、偶爾一個功能（錶是板子、髮飾是麥克風、胸針是鏡頭）。
- **額外飾品格**：存檔規則可以增加通用格，0～5 格，預設 0（沿用 ElondiaRPG 的 `extraSlots`）。調少時，超出的飾品自動收回行囊。
- 腰帶不是飾品：它在攜帶那一層（第 4 節）。

## 4. 攜帶

武器不看哪隻手拿，看**怎麼帶**。

| 欄位 | 放什麼 | 大小 |
|---|---|---|
| **主武器** | 步槍、霰彈槍、狙擊槍、重武器 | 大的。揹著或提著 |
| **副武器** | 手槍、衝鋒槍、感官彈槍、電擊器 | 小到中 |
| **近戰** | 刀、棍、劍、鞭 | 小到中 |
| **快取格** | 藥、彈匣、手榴彈、工具 | 每格一件小東西 |

- 義臂的**內藏武器**、生體的**爪**不佔攜帶格：它們是身體的一部分（[CRAFTING](CRAFTING.md) 3.1 節）。
- 戰鬥中換武器花 1 點行動點；主武器與副武器之間切換照這個算。
- 沒有「雙手／單手」的限制。重武器佔主武器格，而且讓副武器的拔槍變慢。

### 4.1 快取格

**戰鬥中只能用快取格裡的道具**（1 點行動點）。行囊裡的東西打起來拿不到。

| 來源 | 格數 |
|---|---|
| 每個人都有 | 2 |
| 腰帶（放在快取的「腰帶」位，不佔格） | +1～2 |
| 戰術背心（護甲格） | +2～4 |
| 藥泵（義體） | 另外 1～3 格，只能放藥，用的時候不花行動點 |
| 上限 | 8 |

這讓「進副本前帶什麼」是個要想的決定，也讓護甲的選擇不只是護甲值。

## 5. 外層蓋住內層

別人看到的是最外面那一層。

- **看得到的**：頭部、面部、外套（穿著時）、沒被外套蓋住的上身與下身、手、鞋、腿與頸的飾品、主武器。
- **被外套蓋住的**：上身、護甲、副武器、近戰、通用飾品的一部分。
- 外套有兩種穿法，隨時可以切換，不花時間：

| 穿法 | 看得到底下嗎 | 曝露度 | 拔副武器與近戰 |
|---|---|---|---|
| 敞開 | 看得到上身與護甲 | 照上身、下身、內衣算 | 正常 |
| 扣上 | 看不到 | 上半身算 0；下身看外套的長度 | 慢一拍（第一回合拔槍 +1 點行動點） |

**這影響三件事：**

| | 看什麼 |
|---|---|
| **風格** | 看得到的那幾件。全部同一個風格標籤時有一致的加成（四件以上）。外套扣上，底下穿什麼都不算 |
| **曝露度** | 沿用 ElondiaRPG 的算法（上身、下身、內衣、真空），加上外套：扣上的長外套讓全身算 0～1。穿著歡場的衣服走過冠冕區，披一件大衣就行 |
| **威脅感** | 看得到的護甲與武器讓人緊張：交涉 −、威嚇 ＋、被盯上的機率 ＋。藏在外套底下就沒有這些 |

各區對風格、曝露度的反應見 [DISTRICTS](DISTRICTS.md) 第 2 節。

## 6. 藏匿

帶著違禁的東西走在街上，有兩種被發現的方式：**被看到**，和**被掃到**。對策不同。

### 6.1 大小與藏匿量

每件攜帶的東西有**大小**：

| 大小 | 例 |
|---|---|
| 0 | 刀片、晶片、藥 |
| 1 | 手槍、短刀、電擊器 |
| 2 | 衝鋒槍、短管霰彈槍、長刀 |
| 3 | 步槍、霰彈槍 |
| 4 | 狙擊槍、重武器——藏不了 |

身上的衣服提供**藏匿量**：

| 來源 | 藏匿量 |
|---|---|
| 沒穿外套 | 1（腰後） |
| 短外套、夾克 | 3 |
| 長外套、大衣、特攻服 | 5 |
| 裝甲制服的內藏槽 | +2（襯裙、圍裙口袋） |
| 槍套、腿帶（飾品） | +1 |
| 義體的藏匿艙 | +1，而且搜身找不到 |

- 想藏的東西，大小加起來不超過藏匿量，就是**藏好了**：別人看不到。
- 超過的部分是露在外面的。主武器格的東西（大小 3 以上）通常藏不住——要帶長槍進去，得放在包裡、車裡，或另外想辦法。
- 外套要扣上才算滿的藏匿量；敞開時減半。

### 6.2 被看到

藏好的東西平常沒人看得到。只有被**搜身**或被有心的人細看時才檢定：隱匿（加上衣服的修正）對對方的察覺。

### 6.3 被掃到

掃描器不管你藏得多好。它看的是**東西本身**：

| 東西 | 掃得到嗎 |
|---|---|
| 金屬與電子零件 | 掃得到 |
| 帶「防掃描」特性的零件（陶瓷板材、消光外皮、屏蔽襯裡） | 掃不到 |
| 生體件（爪、蛛絲、活皮） | 掃不到 |
| 義體 | 機械的掃得到，生體的掃不到（[CRAFTING](CRAFTING.md) 第 8 節） |

- **一件東西只要有一個掃得到的零件，整件就掃得到。** 要做一把過得了安檢的槍，每個零件都要挑——這是一種組裝的目標。
- 屏蔽襯裡是外套的一種選配零件：讓藏在外套裡、大小 1 以下的東西掃不到。
- 掃描的強度是地點的屬性：

| 強度 | 在哪 | 掃什麼 |
|---|---|---|
| 0 | 蜂巢、舊港、霓虹腸的街上、地下層 | 不掃 |
| 1 | 地鐵站、櫻町的大街、一般的店 | 只掃大小 2 以上的武器 |
| 2 | 企業的建築、俱樂部、劇場 | 所有武器；違禁的義體 |
| 3 | 冠冕門、企業塔的內部、議事堂 | 所有武器與義體；橋 ID |

### 6.4 被發現之後

照合法性（[LIFE](LIFE.md) 3.1 節）：自由的沒事；登記類要查登記；許可類要看執照；違禁的沒收、拘留，並加上那個勢力的熱度。在沒有人執法的地方（舊港），被看到帶著重武器只會讓人躲開你。

### 6.5 繞過的方法

| 方法 | 靠誰 |
|---|---|
| 假的執照、假的登記 | 掮客、同人夜市 |
| 讓掃描器瞎掉、竄改它的結果 | 潛網者 |
| 把東西交給不會被掃的人帶（內應、送貨的、機娘） | 掮客、伶人 |
| 偽裝成有資格帶的人（保全、警備） | 伶人 |
| 全身都是掃不到的東西 | 生體派；組裝的功夫 |
| 走不經過掃描的路 | 地下層；野良帶路 |

## 7. 重量

每件東西有重量。身上的總重量超過體格允許的範圍時，迴避與隱匿下降，行動點的回復變慢。

- 重的是：板材、重武器、彈藥、動力護甲沒開機的時候。
- 義體的致動器（義臂、義腿）提高負重。這是重裝路線要先換腿的理由。

| ElondiaRPG | 這裡 | 為什麼 |

| 頭部 | 頭部、面部 | 面具與眼鏡太重要 |
| 手腕 | 手 | |
| 腰帶 | 快取格的一部分 | 腰帶的功能是帶東西 |
| 首飾、戒指 ×2、穿孔 ×2 | 頸、通用 ×3 | 沒有附魔，不需要那麼多格 |
| 腿部飾品 | 腿 | 沿用 |
| 內衣、內褲 | 相同 | 沿用，曝露度與真空的算法不變 |
