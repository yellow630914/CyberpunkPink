## 2. 設計代幣

那邊約七成的顏色有變數，間距完全沒有，斷點有七種（[scan/06-ui-tests](../plan/scan/06-ui-tests.md) 第 3 節）。這邊從第一天全部變數化，來源是一份 `data/ui/tokens.json`，建置時產生 CSS 與 TS。

### 2.1 顏色

**原色**沿用樣稿的 `:root`（`--bg-0`～`--bg-2`、`--line`、`--ink`～`--ink-3`、`--pink`／`--pink-hi`／`--pink-lo`、`--cyan`、`--mint`、`--gold`、`--rust`、`--violet`、`--red`）。元件**不直接用原色**，只用下面的語意色：

| 語意色 | 指向 | 用在 |
|---|---|---|
| `--surface-0`／`-1`／`-2`／`-term` | `--bg-0`／`--bg-1`／`--bg-2`／`#0a0710` | 頁底、面板、浮起、終端機（編輯台、網內） |
| `--text`／`--text-2`／`--text-3` | `--ink` 系 | 內文、次要、提示 |
| `--border`／`--border-hot` | `--line`／`--pink` | 一般框、焦點框 |
| `--focus` | `--pink` | 主要按鈕、選中、現在該看的 |
| `--accent` | 依所在區（2.5 節） | 標題的線、地圖的框、次要強調 |
| `--danger`／`--ok`／`--warn` | `--red`／`--mint`／`--gold` | 警告、成功、注意 |
| `--track-hp`／`-load`／`-sink` | `--red`／`--pink`／`--cyan` | 三條軌 |
| `--res-ap`／`-ram`／`-edit` | `--gold`／`--mint`／`--violet` | 行動點、RAM、編輯點 |
| `--layer-meat`／`-net`／`-media` | `--ink-2`／`--mint`／`--violet` | 現實、內海、輿論三個面（紀錄、委託總覽、先攻條的底色） |
| `--lace-w`／`-p`／`-b` | 樣稿原值 | 蕾絲三色 |
| `--fit` | `--violet` | 成人場景的契合 |

**表面**：那邊的 `.parchment` 改成 `[data-surface="panel|raised|term"]`，同一組語意色在不同表面換值。不做淺色模式。

### 2.2 間距、字、形狀

| 代幣 | 值 |
|---|---|
| `--space-1`～`--space-8` | 2、4、8、12、16、24、32、48 px |
| `--fs-xs`／`sm`／`md`／`lg`／`xl`／`2xl` | 12／13／15／18／22／34 px；手機 `md` 改 16（避免輸入框放大） |
| `--lh-ui`／`--lh-prose` | 1.4／1.8（紀錄正文） |
| `--cut-sm`／`--cut`／`--cut-lg` | 6／10／14 px：斜切角（按鈕、面板、對話框） |
| `--font`／`--mono`／`--prose` | 黑體／等寬／正文字型（預設黑體，設定可換宋體） |
| `--glow` | `0 0 10px` 加該元素的顏色。只給標題、感載條、四十二番街 |
| `--dur-fast`／`--dur` | 120／240 ms；「減少動態」時都是 0 |
| `--z-sheet`／`--z-dialog`／`--z-toast` | 20／30／40 |

### 2.3 斷點

七種收成四種。CSS 變數不能放進 `@media`，所以 `tokens.json` 同時產生 `@custom-media`（PostCSS）與 `src/ui/breakpoints.ts`；JS 的 `isMobile` 讀同一個常數。

| 名字 | 寬度 | 版面 |
|---|---|---|
| `--bp-phone` | ≤ 720 | 手機版外殼（`MobileGame`） |
| `--bp-tablet` | ≤ 960 | 單欄：地圖、紀錄、這裡 由上而下 |
| `--bp-narrow` | ≤ 1180 | 兩欄：左欄分頁（地圖／這裡）、中欄紀錄 |
| `--bp-wide` | ≤ 1380 | 三欄縮窄（320／彈性／320） |
| 以上 | — | 三欄（380／彈性／360） |

### 2.4 檢查

- stylelint：`.vue` 與 `.css` 裡不准出現色碼（`tokens.css` 除外）；`padding`／`margin`／`gap` 只准用 `--space-*` 或 0。
- SVG 圖標用 `currentColor` 與 `.a`（粉的那一筆）兩個 class，不寫色碼（[ART_STYLE](ART_STYLE.md) 第 5 節）。
- JS 產生的特效讀 `getComputedStyle` 的語意色，不寫死。

### 2.5 區的強調色

`<html data-district="…">` 換 `--accent`。值取城市地圖的那一組：

蜂巢 `hive` 紫、四十二番街 `ave42` 霓虹粉（唯一帶 `--glow` 的區）、櫻町 `sakura` 淡粉、冠冕區 `crown` 金、舊港 `oldport` 灰藍、玻璃岸 `glass` 冰藍、鏽帶 `rust` 鏽橘、地下層 `under` 薄荷；潛入內海時是 `net`，薄荷，表面換成 `term`。色碼在第 18 節。

`--accent` 永遠不等於 `--focus`：四十二番街與櫻町的強調色偏粉，所以這兩區的焦點框改用 `--pink-hi` 加粗，避免和強調色混在一起。

### 3.2 紀錄的細節

- **擲骰行**用等寬字，左邊一條粉線（樣稿的 `.roll`）：`基本功 1d20(14)+調整值+等級=19 對 DC16 → 成功`，主持人的轉折（`twist`）跟在後面，用 `--pink-hi` 標一個 ✦。
- **雙層場景**：正文裡網內的段落（[PROMPTS](../systems/PROMPTS.md) 6.3 節的 `<net>` 標記）左邊多一條 `--layer-net` 的細線、字改成等寬體的次要色；現實的段落照常。沒有標記時整段照常顯示。
- **直播中**的報告卡右上角一個「● LIVE 1,240」標籤，正文裡的彈幕句用次要色。
- **成人場景**的報告卡預設摺疊成一行「（私密的場景）」，點開才顯示；設定可以改成直接展開（第 15 節）。
- **AI 關閉**時顯示戰報：`describe` 依報告產生的條列，和那邊相同。

### 3.3 待處理事件

指令到期、討債上門、名冊上的人出事、戰敗事件等要玩家回應的事。**推算在引擎**（`engine/pendingEvents.ts` 回傳 `{id, kind, blocking, ref}`），元件只管顯示與「稍後」——那邊推算寫在 `events/eventQueue.ts`，搬的時候移回引擎。擋住行動的事件直接開對話框，不擋的進鈴鐺。

### 3.6 指南（已確認，2026-11-20）

玩家第一次碰到一個系統時，跳出一張指南，講清楚這個系統在做什麼、怎麼操作。看過的指南收進筆記，隨時可以重看。

**跳出來的樣子**

```
┌ 指南 · 委託副本：階段、面與分支 ─────────────── 1／3 ┐
│ [示意圖：階段軌]                                        │
│ 一個副本有三到五個階段。每個階段寫明可以選哪些面，     │
│ 你選一個自己玩，其餘的面可以派人去當輔助。             │
│                                                        │
│ ☐ 之後不要再跳出指南（直接收進筆記）                    │
│                          [上一頁] [下一頁] [知道了]    │
└────────────────────────────────────────────────────────┘
```

- 一個 `CutPanel` 的對話框，置中，不蓋滿畫面。現實與內海用各自的皮。
- 一張指南一到四頁，每頁一個重點：一張示意圖（畫面的局部截圖或簡圖）加兩三句完整的句子。文字照 [NPCS](../world/NPCS.md) 第 1 節的規則。
- 底下一個勾選：**之後不要再跳出指南**。勾了之後，之後的指南不再跳出來，觸發時直接收進筆記，筆記亮紅點。設定的「顯示」頁有同一個開關，可以再打開。
- **什麼時候跳**：觸發的那一刻如果玩家正在操作（戰鬥的回合中、成人場景的行動中、輿論戰的出牌中），等到下一個安全的時機（回合開始前、場景開始前、開場前）才跳。同時觸發好幾張時一次跳一張，關掉一張再跳下一張；一個畫面最多連跳兩張，其餘直接收進筆記並亮紅點。
- 成人的指南只在內容篩選開著對應內容時出現；關掉的系統不觸發，也不出現在筆記裡。
- 指南是固定的文字，不經過 AI；照輸出語言（繁體或簡體）顯示。內文與寫法在 [GUIDES](../content/GUIDES.md)（六張樣板，其餘實作時寫）。

**筆記裡的「指南」**

- 筆記多一個分頁「指南」，照下表的類分組。每張寫名字與一句說明；沒看過的有紅點，點開就是同一張指南。
- **紅點**：筆記的「指南」分頁、工具列的「筆記」按鈕（手機在「更多」）都亮紅點，直到所有收進來的指南都看過。
- 還沒觸發過的指南不列出來，所以筆記裡的指南也是一份「你碰過哪些系統」的清單。
- 世界觀上：指南是介面的說明，不是角色手上的東西。它在筆記裡用系統的樣式（等寬字、`SYS` 標籤、紀錄裡系統行的那種顏色），和角色寫的筆記分開。

**夜課**換成另一種樹：

規則在 [DOWNTIME](../systems/DOWNTIME.md) 第 7 節，已確認用**房間制**：據點分四級，等級決定有幾間房，每間房有幾個家具位。家會被闖，只有保險箱與暗格裡的東西安全。下表是畫面的骨架；安全屋、家務、訪客、五種店面與「在自己的店工作」的區塊之後照 [DOWNTIME](../systems/DOWNTIME.md) 第 7 節補上。

| 區塊 | 資訊 | 操作 |
|---|---|---|
| **公寓** | 據點等級、房型、舒適度、這週的房租；店面的話加上週收入 | 升級、搬家 |
| **房間圖** | 一串房間，每間列出它的家具位與擺著的家具（房間制，不逐格擺） | 擺放、收起家具 |
| **設施** | 床（休息）、儲物、工作台（二級）、接入點（二級）、店面（三級） | 直接打開對應的畫面（組裝、潛入、休息） |
| **住戶與訪客** | 住在這裡的人（同居、契約人、名冊上暫住的人）、今天會來的人 | 談、主動行動、請離開 |
| **儲物** | 據點的倉庫，和行囊分開；保險箱與暗格另外標出來，因為家被闖的時候只有它們安全 | 存取（拖曳；手機點選） |

- ElondiaRPG 的 `HomePanel` 只有 200 行，家具資料模型照搬，畫面重寫。
- **手機版**：從「更多 → 家園」打開全螢幕頁，四個區塊是 `SwipeTabs` 的四頁。

## 14. 建角

**下拉選單為主，自由輸入為輔**（已定案，[ROADMAP](../plan/ROADMAP.md) 第 1 節第 5 項）。步驟照 [CHARACTER](../systems/CHARACTER.md) 第 1 節，一共九步；一頁一步，上方是步驟條，每一步都可以回頭改。內容篩選在建角之前先設定，關掉的題材不會出現在選項裡。

| 步 | 選什麼 | 控制項 |
|---|---|---|
| 1 基本資料 | 名字（自由輸入，旁邊一顆「隨機」）、性別、稱呼（她／他／祂／自訂）、敘事視角的預設、年齡（下拉，下限 18；選項 20 出頭、20 後半、30 出頭……）、外觀（體型、身高、膚色、髮型、髮色、眼睛、獸化、明顯的義體）、背景 | 輸入框加下拉；外觀與背景各有一格自由輸入（選用） |
| 2 出身 | 七個：蜂巢、企業、車族、歡場、舊港、櫻町、地下層（[CHARACTER](../systems/CHARACTER.md) 第 2 節） | 下拉；選了顯示加一級的基本功、出身特質、起始的身分與住處、好感 25 的勢力 |
| 3 屬性 | 把 15、14、13、12、10、8 分到六項，再加 2 點自由點數，單項最高 18 | 每項一個下拉（選過的數字從其他下拉消失）；兩顆 ± |
| 4 基本功 | 起始 10 點分到十八項基本功，單項最高 3 級 | 每項一組 ±，上方顯示剩下幾點 |
| 5 生命軌跡 | 八張表（原本的六張，加上性經歷與潛在性癖兩張）；可以擲、可以選、可以跳過 | 每張表一個下拉，旁邊「擲」 |
| 6 橋與義體 | 用起始的義體點數（10 點）自由選一座橋與其他義體；顯示四類技能的容量與橋參數的初值 | 清單；上方顯示剩下幾點，沒花完的點數換成錢 |
| 7 特質與缺陷 | 用特質點買（起始 4 點，另外送一個出身特質）：每個特質 1～3 點；最多 2 個缺陷，每個退 1～3 點；可以自訂 | 清單借 `PerkPicker`；上方顯示剩下幾點；「自訂」開一個小表單 |
| 8 技能 | 起始歷練點 200，在技能樹上花 | 技能樹畫面（8.4 節） |
| 9 起始的錢與裝備 | 起始的錢與依出身給的一包裝備；難度與存檔規則；最後一頁是總覽 | 「開始」 |

- **快速開始**：每個出身有兩個預設角色，選了直接進遊戲。
- 外觀的選項由程式組成 AI 用的外觀描述（那邊的 `engine/look.ts`），不交給 AI。
- 架構照搬 `NewGameView`、`LookPicker`、`PcTagPicker`、`PerkPicker`；種族、職業、等級的部分拿掉。`NewGameView` 那邊 690 行，這邊每一步一個元件。
- **手機版**：一步一個全螢幕頁，「上一步／下一步」固定在底部。
