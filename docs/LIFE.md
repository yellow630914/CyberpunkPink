# 日常：錢、身分、法律、貨與行規

> 上層：[WORLD](WORLD.md)。依賴：[CORPORATIONS](CORPORATIONS.md)、[GANGS](GANGS.md)、[DISTRICTS](DISTRICTS.md)。被依賴：之後的 `ITEMS`（物品目錄）、`TRADE`、`STORY_QUESTS`、`EVENTS`；[FIXER](FIXER.md)（案子的行規）、[CYBERWARE](CYBERWARE.md)（品級與品牌）。
> 這份是世界觀文件，目的是**讓物品、系統、任務有東西可以依據**：一把槍多少錢、什麼東西犯法、同一種東西為什麼有五種牌子、一年裡什麼時候會發生什麼。價格與數值都是初稿。

## 1. 錢

### 1.1 兩種錢

| | 帳上的瑰元 | 瓣 |
|---|---|---|
| 是什麼 | 綁在橋 ID 上的帳戶餘額 | 匿名的現金晶片，指甲大小，粉色的 |
| 誰收 | 所有地方 | 黑市、幫派、霓虹腸、舊港、地下層；冠冕區與正規商店不收 |
| 好處 | 方便；可以分期、可以貸款 | 查不到；被捕、被鎖帳戶時還在 |
| 壞處 | **每一筆都有紀錄**。用帳戶付髒錢，熱度會找上來；欠債時可以被直接扣走 | 會被偷、被搶；不能貸款 |

- **洗錢**：把瓣變成乾淨的帳上瑰元（或反過來）要過一手，抽 10%～20%。胭脂堂的賭船、霓虹腸的店、同人夜市都做這個生意。
- 案子的報酬通常付瓣。這是每週帳單（[FIXER](FIXER.md) 第 4 節）的一個小摩擦：房租與義體訂閱要從帳戶扣，所以玩家得定期洗錢，或者接受付現的折扣差。
- 系統上：兩個數字。帳戶的支出會留下 `paper_trail`，被調查時成為證據。

## 2. 身分

### 2.1 橋 ID

每座合法安裝的橋有一個 ID。它是身分證、錢包、鑰匙、病歷。**掃橋**——讀取橋 ID——是這座城市最日常的動作：進地鐵、進冠冕區、進企業的樓、租房、就醫、買登記類的東西。

### 2.2 三種人

| 身分 | 是誰 | 有什麼 | 沒有什麼 |
|---|---|---|---|
| **社員** | 理事會企業的正式員工與眷屬 | 公司的法律保護、醫療、進出冠冕區 | 離職的自由 |
| **市民** | 登記了橋、繳得起市民稅的人。城裡的多數 | 帳戶、地鐵、合法的工作、名義上的法律保護 | 企業塔內的任何權利 |
| **無籍** | 橋沒登記、被註銷、或沒有橋的人。蜂巢與舊港很多 | 沒人查得到你 | 帳戶、地鐵、正規診所、任何保護。被捕時沒有程序 |

- 玩家開場是市民（或依出身是無籍）。身分會變：欠稅被降成無籍；被企業雇用成為社員；簽了契約則三者皆非，是**契約人**——法律上是持約人的責任。
- 無籍不全是壞事：掃不到的人，熱度也難累積。很多邊緣行者刻意註銷。

### 2.3 假身分

| 等級 | 能做什麼 | 撐多久 |
|---|---|---|
| 一次性 | 過一次掃橋 | 一次 |
| 淺層 | 一個名字、一個帳戶、過例行檢查 | 幾週，或直到有人認真查 |
| 深層 | 完整的履歷，查得到同事與鄰居 | 直到你自己搞砸 |
| 借來的 | 一個真人的 ID——他同意的、被迫的、或已經不需要了 | 直到那個人被發現 |

- 做假身分的：同人夜市（淺層）、潛網者（進市政子網）、伶人的人格面具（連行為都換掉，掃描與盤問都過）。
- 假身分是踩點階段常見的準備，也是冠冕區與玻璃岸的門票。

## 3. 法律

緋夜城的法律是理事會訂的《自由市公約》。它不長，原則只有一條：**財產權高於一切**，而契約是財產。

### 3.1 四個等級

物品與行為依合法性分四級。這是物品資料的一個欄位，決定在哪裡買得到、被掃到時會怎樣。

| 級 | 意思 | 被查到 |
|---|---|---|
| **自由** | 誰都能買、能帶 | 沒事 |
| **登記** | 買的時候掃橋，紀錄綁在 ID 上 | 沒登記的：沒收、罰金 |
| **許可** | 要有執照（職業、企業、公會發的） | 沒執照的：沒收、拘留 |
| **違禁** | 只有理事會企業與公家機關能持有 | 拘留、義體鎖定、可能更糟 |

| 東西 | 級 | 備註 |
|---|---|---|
| 刀、鈍器 | 自由 | |
| 神經武器（感官彈槍、電擊器） | 自由 | 公約鼓勵市民使用「非致命的自衛手段」。街上人手一把 |
| 手槍 | 登記 | |
| 長槍、霰彈槍 | 許可 | 保全執照、飛行夾克的巡守證 |
| 重武器、爆裂物 | 違禁 | |
| 表層與一般義體 | 自由 | |
| 侵入與重度義體 | 登記 | 正規診所會自動登記；黑診所不會 |
| 軍規義體、內藏武器 | 許可／違禁 | |
| 獸化改造 | 自由 | 冠冕區的雇主可以不雇用 |
| 工具與支援類程式 | 自由 | |
| 攻擊類程式、破解工具 | 違禁 | |
| 甲板 | 登記 | 深潛本身不犯法；未經授權進入子網犯法 |
| 調校 | 登記 | **在契約或雇用條款下強制安裝是合法的** |
| 人偶晶片 | 許可 | 店家要有牌 |
| 感官帶 | 自由 | 未經當事人同意錄製的：違禁，但幾乎沒人查 |
| 黑帶 | 違禁 | |
| 抑制劑、一般藥品 | 自由 | |
| 戰鬥藥、街頭藥 | 違禁 | |
| 假身分 | 違禁 | |
| 契約 | 合法 | 買賣、轉讓、抵押都受公約保護 |

- 值得注意的是**什麼東西是合法的**：把人灌到過載不算傷害罪（沒有身體損傷）；強制調校在契約下合法；契約可以轉賣。這座城市的恐怖之處大多不違法。
- **塔內是公司的法**：企業的建築內適用公司內規，市警無權進入。在緋櫻塔裡被抓，適用的是緋櫻的規矩。

### 3.2 刑罰

城裡沒有監獄——關人要花錢。刑罰依序是：

1. **罰金**。
2. **拘留**（幾天，市警的拘留所）。
3. **義體鎖定**（依判決鎖一段時間）。
4. **刑事契約**：付不出罰金或罪太重的，判決把你的橋權交給出價最高的企業若干年。這就是這座城市的徒刑。

所以「被捕」的戰敗事件（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 8 節）最壞的結局不是坐牢，是被賣。

### 3.3 誰在執法

各區不同，見 [DISTRICTS](DISTRICTS.md) 第 2 節。一般原則：**法律只在有人付錢執行的地方存在。**

## 4. 貨：品級

取代 ElondiaRPG 的稀有度與附魔。**義體另有更細的一套**：底材與零件各分 I～V 級，由玩家組裝（[CRAFTING](CRAFTING.md)）；下表的品級對義體來說是等級的另一種叫法（量產＝I～II、制式＝III、軍規＝IV、原型＝V）。

每件裝備（武器、護甲、義體、甲板）有一個**品級**，決定基礎數值、改裝槽、價格與合法性。

| 品級 | 是什麼 | 數值 | 改裝槽 | 價格 | 哪裡來 | 特性 |
|---|---|---|---|---|---|---|
| **同人** | 社團自製 | 不穩定：可能比量產好，也可能出包 | 1～3 | ×0.6～1.5 | 同人夜市 | 每件有一個隨機的**怪癖**（好壞都有）；沒有保固；可能有後門 |
| **街貨** | 二手、拼裝、來路不明 | −1 級 | 0～1 | ×0.4 | 黑市、拆體客、骨場 | 有**瑕疵**的機率；義體有殘響；不在任何登記上 |
| **量產** | 企業的民用產品 | 基準 | 1 | ×1 | 正規商店 | 穩定；會被登記 |
| **制式** | 保全與警用規格 | +1 級 | 2 | ×3 | 許可；或從敵人身上 | 有授權鎖：非授權使用者要先解鎖 |
| **軍規** | 企業軍隊規格 | +2 級 | 3 | ×10 | 違禁；案子的戰利品 | 有授權鎖與追蹤器；人性成本高 |
| **原型** | 獨一無二，有名字 | 特殊 | 特殊 | 不賣 | 特殊任務 | 有一個別的東西沒有的能力；全城都有人在找它 |
| **牆外** | 妖精給的 | 不照規則 | — | 用別的東西換 | [NETRUNNING](NETRUNNING.md) 第 7 節 | 好得不像真的。有代價 |

- **改裝件**取代附魔：瞄具、消音、彈匣、槍靈的人格、義體的韌體、甲板的散熱。裝在改裝槽裡，可以拆換。
- **授權鎖**（[CYBERWARE](CYBERWARE.md) 第 5 節）讓「從敵人身上撿到好東西」多一步：制式以上的東西撿到不等於能用。這是改造師與潛網者在戰後的工作。
- 品級不是線性的好壞。同人貨的怪癖、街貨的不被登記、軍規的追蹤器，都讓「該用哪一把」是個要想的問題。

## 5. 貨：牌子

同一種東西，不同牌子有不同的**脾氣**。牌子是物品資料的一個欄位，帶一組固定的特性。這讓物品目錄不必靠數值堆疊來做出差異。

### 5.1 武器

| 牌子 | 脾氣 | 特性 |
|---|---|---|
| **星旗** | 便宜、粗、不會壞 | 不卡彈、不用保養；沒有任何電子零件，**不能被駭**；準度普通 |
| **崑崙** | 聰明、多話 | 有槍靈：命中 +、自動管彈、會提醒；**可以被駭**（鎖槍、偏移）；資料回傳崑崙 |
| **緋櫻** | 精密、嬌貴 | 要害率高；穿甲好；貴；每場戰鬥後要保養，不然性能下降；制式以上有授權鎖 |
| **織女** | 不是給人拿的 | 無人機、自動砲塔、遙控武器。潛網者與技術路數的武器 |
| **胭脂堂的師傅** | 手工、老派 | 刀劍為主。沒有電子零件；可以傳家；訂製要等、要有交情 |
| **鉻娘子改** | 過頭 | 傷害高得不合理；後座力要義肢才壓得住；偶爾炸膛 |

緋櫻也做刀——**緋櫻刀工**的單分子刃是城裡近戰武器的頂點，家政課的制式裝備。

### 5.2 義體

牌子同時是底材與零件的屬性。同一個牌子有 I～V 五個等級；原廠全套有套裝加成，混搭沒有（[CRAFTING](CRAFTING.md) 第 6 節）。

| 牌子 | 脾氣 | 特性 |
|---|---|---|
| **織女** | 標準、無聊、到處有零件 | 基準。維修便宜 |
| **緋櫻** | 高性能、高代價 | 數值最好；幾乎都有授權鎖；訂閱制；外觀精緻（風格 +） |
| **星旗** | 軍用、耐打 | 護甲與耐久高；人性成本高；醜（風格 −）；退伍要歸還 |
| **蜜腺** | 生體 | 人性成本低；掃描器不當它是義體；貴、不能退、要定期用藥維持 |
| **伊甸園** | 感官與私密部位 | 橋參數相關的義體最好；多半綁契約條款 |
| **鉻娘子改** | 超頻 | 輸出超過設計值；人性成本 ×1.5；容易中惡意韌體 |
| **同人** | 什麼都有 | 冷門功能、獸化改造的各種花樣、企業不做的東西 |

邊緣橋本身也照這些牌子的脾氣分型號，各有不同的技能容量（[CYBERWARE](CYBERWARE.md) 第 7 節）。

### 5.5 吃的與開的

- **吃**：甜心的**糰糧**（口味很多，都是同一種東西）是窮人的三餐；桃子屋的便當是中間；**真的食物**是奢侈品，也是送禮與收買的好東西。糰糧裡有情緒調節劑（[CORPORATIONS](CORPORATIONS.md) 第 5 節）——長期只吃糰糧的角色，定力略高、衝動略低。
- **開**：星旗的皮卡（耐撞、能載貨）、織女的浮空車（快、貴、有紀錄）、緋櫻的重機（特攻姬的最愛）、車族的改裝車（荒地用）。全部燒蜜醇。

## 6. 藥

藥是消耗品的主力，取代奇幻世界的藥水。每種藥都有**成癮值**，累積到門檻後出現戒斷。

| 牆灰 | 灰 | 同步檔位 +1 級 | 沉溺；可能留下惡意韌體 | 違禁 | 據說來自牆外。地下層 |

- 藥泵（[CYBERWARE](CYBERWARE.md) 第 1 節的軀幹義體）可以預裝藥，戰鬥中不花行動點施打。
- 成癮是每個角色的一組數字，戒斷的效果依藥而異。治療是生活行動。

## 7. 通訊與消息

**耳語**：橋內通訊。不用開口、不用手，想著就能傳。這是城裡的電話。有橋的人都有一個耳語號。

- 耳語會被攔截、被定位（熱度高時，開著耳語等於亮著燈）。
- **拋棄號**：一次性的耳語號，同人夜市一把一把賣。中間人與邊緣行者的標準做法。
- **板子**：手持終端。沒有橋的人、不想讓橋連網的人用。慢，但安全。
- **靜默**：關掉橋的所有無線功能。不能耳語、不能快駭、不能被快駭、不能被定位。潛入時的一個選擇。

**消息怎麼流**——這是情報、傳聞與媒體玩法（[MEDIA](MEDIA.md)）的管線：

```
發生的事 → 街上的耳語（幾小時）→ 牆報（一天）→ 帶子街（兩三天）→ 萬華鏡（如果它想報）
```

| 管道 | 是什麼 | 特性 |
|---|---|---|
| **街上的耳語** | 口耳相傳 | 最快；只在一兩個區內；會走樣 |
| **牆報** | 每個區的匿名留言板，掛在公共子網上 | 徵人、尋人、懸賞、謠言。一般案子的來源之一 |
| **帶子街** | 有人把事情錄成帶子拿來賣 | 可以「親身」確認；要錢 |
| **地下轉播站** | 牆語者與車族的廣播 | 不被審；聽眾少 |
| **晨星社** | 標榜查證的新聞 | 慢、可信、不報金主的事 |
| **萬華鏡** | 全城的螢幕 | 它報了才算「大家都知道」 |

玩家可以在任何一段介入：在牆報上放假消息、買下帶子不讓它流出去、把事情直接送上萬華鏡。

## 8. 時間

### 8.1 一週

| 日 | 發生什麼 |
|---|---|
| 週一 | **收租日**。每週帳單結算（[FIXER](FIXER.md) 第 4 節）。收租無人機出動，討債的人上門 |
| 週三 | 牆報更新最多的一天；中間人放新案子 |
| 週五 | 企業發薪。霓虹腸最熱鬧的晚上；冠冕區的人下來玩 |
| 週六 | **同人夜市**（高架橋下） |
| 週日 | 偶像的公演日。櫻町人最多；親衛隊最容易打起來 |

每個區的商店、人、街頭事件表依星期幾有小變化。

### 8.2 一年

十二個月。年度事件是任務與區域狀態的時間錨點：

| 月 | 事件 | 影響 |
|---|---|---|
| 1 月 | 新年參拜 | 稻荷神社擠滿人；特攻姬維持秩序；各幫派休戰三天（多半） |
| 2 月 | **緋夜祭・冬** | 舊港貨櫃場三天。全城的社團、獵頭、臥底 |
| 3 月 | 理事會年會 | 冠冕區戒嚴一週；各企業的髒活集中在會前 |
| 4 月 | 櫻祭；**戰姬大公演** | 櫻町最大的活動；偶像線的高潮 |
| 5 月 | 契約季 | 企業的年度合約到期與續約。挖角案與逃亡案最多 |
| 6 月 | 雨季 | 地下層淺層淹水，部分通道封閉、部分只有這時候才出現 |
| 7 月 | 夏祭 | 祭典組最活躍；隨時可能封街 |
| 8 月 | **緋夜祭・夏** | 同上 |
| 9 月 | 停戰紀念日 | 緋櫻與星旗各辦各的；飛行夾克上街；舊港的彈坑灣有人獻花 |
| 10 月 | 假面夜 | 全城戴面具。偽裝最容易的一晚；布偶裝也最容易混在人群裡 |
| 11 月 | 沙暴季 | 鏽帶與荒地的能見度；外環公路時常封閉 |
| 12 月 | **畢業季** | 偶像的畢業公演。年底的最後一週，奉公課很忙 |

遊戲從 9 月開始（停戰紀念日前後），第一年的事件依序出現一輪。

## 9. 行規

邊緣行者沒有公會，但有規矩。這些規矩是**案子系統的預設值**——遵守它們是常態，打破它們有具體的後果（街頭信譽）。

| 規矩 | 意思 | 系統上 |
|---|---|---|
| **先付三成** | 接案時雇主預付三成，不退 | 談判的預設值；可以談高或談低 |
| **不問是誰** | 不問雇主的身分，雇主也不問你的 | 查雇主是踩點的選項，不是禮貌 |
| **接了就做完** | 接了案子中途放棄，比做砸更糟 | 放棄扣的信譽比失敗多 |
| **不動中間人** | 中間人是中立的。動了一個，所有的都不再接你的電話 | 攻擊中間人：全體中間人好感歸零 |
| **貨先說好** | 戰利品歸誰，行動前講清楚 | 簡報的一個欄位；沒講的照「誰撿到歸誰」 |
| **倒下的人有份** | 行動中死掉的人，那一份給他指定的人 | 夥伴死亡時自動結算；吞掉的話其他夥伴的忠誠下降 |
| **翻了的人不補槍** | 過載倒地的人不殺。帶走、綁起來、丟在路邊都行 | 殺過載的敵人：額外的熱度與人性流失 |
| **帶子不外流** | 行動時錄的東西，未經全隊同意不發 | 主播的取捨（[MEDIA](MEDIA.md)）：擅自發布扣夥伴忠誠 |
| **欠的要還** | 人情是真的債 | [FIXER](FIXER.md) 第 8 節 |

- 企業與部分幫派（鉻娘子、拆體客、布偶裝）不守這些規矩。這是他們被當成「外人」的原因。
- 胭脂堂另有自己更老的一套（[GANGS](GANGS.md) 第 2 節）。
- 開場時由阿蓮（[NPCS](NPCS.md) 第 2 節）一條一條教給玩家——這是新手教學的形式。
