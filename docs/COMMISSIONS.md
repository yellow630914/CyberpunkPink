# 委託副本

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[FIXER](FIXER.md)（接案、踩點、收尾）、[COMBAT_SYSTEM](COMBAT_SYSTEM.md)（現實面）、[CYBERSPACE](CYBERSPACE.md) 與 [NETRUNNING](NETRUNNING.md)（內海面）、[OPINION](OPINION.md)（輿論面）、[CORE_RULES](CORE_RULES.md) 第 6 節（三個領域）。被依賴：[FIXER](FIXER.md) 第 2、3 節。
> 來源：新做。ElondiaRPG 只有特殊任務與事件兩種內容形式；這是第三種。可以借的：一般委託的生成、地下城生成器、特殊地圖。預定資料：`data/rules/commissions.json`、`data/world/commission_maps.json`。數值都是初稿。

## 1. 三種內容形式

| | 特殊任務 | 事件 | **委託副本** |
|---|---|---|---|
| 是什麼 | 人工編寫的任務鏈，用劇情旗標串起來 | 走在路上、待在某處時發生的一件事 | 一件案子的行動階段：一組**獨立的地圖**，帶著目標與三條指標 |
| 發生在哪 | 城市的地圖網上（街區、要地、內海的固定區） | 當下所在的格子 | **地圖網之外**。從入口進去，做完出來 |
| 數量 | 有限，每一條都是寫出來的 | 幾百件，重複觸發 | 無限：模板 × 生成 × 類型 |
| 會不會重複 | 不會 | 會 | 會，但每次的地圖、敵人、條件不同 |
| 規則 | **傳統的旗標系統**：完成了哪些任務點、立了哪些旗標。沒有主面、沒有指標、沒有路線的限制，怎麼寫就怎麼走 | 條件與效果 | **主面與領域指標**（第 2～4 節） |
| 給玩家的 | 故事 | 生活感 | **玩法**：這是遊戲的主食 |
| ElondiaRPG 的 | 有 | 有 | 沒有（最接近的是一般委託＋隨機地下城） |

分工很清楚：城市是固定的、有記憶的；委託副本是可以一直玩下去的。中間人給的一般案子（[FIXER](FIXER.md) 第 3 節）全部是委託副本。

## 2. 一個副本長什麼樣

```
            ┌─────────── 委託副本 ───────────┐
 城市  ──▶ 入口                              出口 ──▶ 城市
（接案、踩點）│  現實面 ── 內海面 ── 輿論面   │       （收尾）
            │   地圖      地圖      棋盤    │
            │   指標      指標      指標    │
            │      ╲       │       ╱       │
            │         達成條件              │
            └───────────────────────────────┘
```

每個副本有：

| 部分 | 說明 |
|---|---|
| **類型** | 暗殺、竊密、抹黑、滅火……（第 7 節） |
| **主面** | 每個委託有**一個**主面，由類型決定。目標只能在主面完成；其餘的面是輔助（第 4 節） |
| **三個面** | 現實面、內海面、輿論面。每個副本有其中一到三個 |
| **三條領域指標** | 每個面一條，0～100。在那個面做成的事會讓它上升 |
| **達成條件** | 主面的指標到 100（第 4 節） |
| **連動點** | 輔助面的成果怎麼幫到主面：讓主面的指標上漲、讓主面變容易、或開出新路（第 5 節） |
| **時鐘** | 副本的時間以「節」計。有期限，到了就結算 |
| **附帶條件** | 不准死人、不准留痕跡、不准曝光……來自簡報 |

### 2.1 三個面

| 面 | 是什麼 | 地圖 | 用哪套規則 | 壓力條 |
|---|---|---|---|---|
| **現實面** | 目標所在的實體場所：辦公樓、倉庫、俱樂部、機房、宅邸、片場 | 1～3 張固定的模板地圖（9×9 ～ 13×9），依類型抽，換上不同的房客、保全與擺設 | 探索、潛入、[戰鬥](COMBAT_SYSTEM.md) | 警戒 |
| **內海面** | 目標的子網，或和這件事有關的網內場所 | 隨機生成（2～4 層）；可能另有一塊**隔離區** | [竄網](NETRUNNING.md)、[網內戰鬥](CYBERSPACE.md) | 追蹤度 |
| **輿論面** | 這件事在全城的消息管線上的樣子 | 不是地圖，是一張棋盤（[OPINION](OPINION.md) 第 3 節） | 輿論戰（SLG） | 對手的公關 |

- **獨立於地圖網**：副本裡的現實面不在城市的街區圖上，內海面不在企業環礁的固定子網裡。它們是「這件案子的那棟樓」「這件案子的那個子網」，做完就消失。
- 入口在城市裡：接案後，地圖上某個街區出現委託地點的標記，走過去、進去，就進了副本。所以**區還是有意義的**——副本繼承入口所在那一區的治安、增援、物價與勢力。
- **要地不是副本**。緋櫻塔、九號塔這些地方在地圖網上、是固定的、給特殊任務用（[DISTRICTS](DISTRICTS.md) 1.3 節）。副本的現實面是「緋櫻某間分公司的辦公樓」這種不具名的地方。

### 2.2 隔離區

有些子網的核心沒有接上內海——**氣隙隔離**。從網內怎麼打都進不去；唯一的入口是那棟樓裡的資料埠。

這是三個面第一種也是最重要的咬合：**要先在現實面入侵機房，才能潛入被隔離的內海**。隔離區通常是指標給得最多的地方。

## 3. 指標怎麼漲

每個面有四到六個**里程碑**，各值一些分數。里程碑是具體的事，不是抽象的進度。以一件主面是現實的竊密為例：

| 面 | 里程碑 | 分數 |
|---|---|---|
| **現實面（主）** | 進入建築 | 10 |
| | 到達目標樓層 | 15 |
| | 進入機房／保險庫 | 25 |
| | **拿到實體的晶片**（決定性的一步） | 50 |
| 內海面（輔助） | 通過訪客層 | 15 |
| | 取得員工憑證 | 25 |
| | 接管這棟樓的控制節點 | 30 |
| | 找到晶片存放的位置與保險庫的密碼 | 30 |

- **主面的里程碑加起來剛好 100**，最後一個是**決定性的一步**——殺掉那個人、拿到那個東西、讓聲量與風向到位。它只能在主面做。
- **輔助面的指標**是另外算的，自己不會讓委託達成。它的每個里程碑各帶一個連動（第 5 節）：有的直接替主面的指標加分（等於替主面跳過一段），有的讓主面變容易。
- 指標只升不降，除了輿論面（對手會把聲量壓回去）。
- 介面上：主面的橫條最大，上面標著還沒拿到的里程碑；輔助面的橫條在旁邊，每個里程碑寫著「做到了主面會怎樣」。踩點階段揭開的未知，有一部分就是這些。

## 4. 主面與輔助面

**每個委託有一個主面，由它的類型決定。目標一定要在主面完成；其他的面只起輔助作用。**

| 主面 | 這類委託的目標 | 為什麼只能在這裡 |
|---|---|---|
| **現實** | 殺一個人、毀掉一樣實體的東西、帶走一個人或一件物品、護送、討債 | 內海殺不了人、碰不到實體（[CYBERSPACE](CYBERSPACE.md) 第 6 節的「精神污染」）；輿論只能毀掉名聲 |
| **內海** | 偷資料、刪資料、改資料、打撈、對一個人的心智動手（讓他忘記、讓他崩潰、在他的橋裡種東西） | 資料在網裡；精神污染只有網內做得到 |
| **輿論** | 抹黑、爆料、滅火、造勢、洗白 | 「大家怎麼想」只能在編輯台上改變 |

**達成條件只有一條：主面的指標到 100。**

輔助面能做的三種事：

| 輔助的方式 | 意思 | 例 |
|---|---|---|
| **代勞** | 替主面完成前面的里程碑，主面的指標直接加分 | 內海接管門禁 → 現實面「進入建築」「到達樓層」直接算完成 |
| **減壓** | 主面變容易：敵人變少、變弱、變慢，壓力條漲得慢 | 輿論聲量過 60 → 現實面的保全被禁止用致命手段 |
| **開路** | 開出主面原本沒有的路，或原本進不去的地方 | 現實面插上機房的資料埠 → 內海面的隔離區打開 |

- **輔助面最多把主面推到「決定性的一步」之前**。那一步——扣扳機、按下載、讓風向定案——一定要有人在主面做。
- **可以一路走到通**：全員去主面，完全不碰輔助面。這永遠可行，只是硬。
- **可以分多路進攻**：一部分人去輔助面，讓主面的人輕鬆。人手分散，但每一路都更容易。
- **有些委託的輔助面是必經的**：資料存在隔離區的竊密案，主面是內海，但不先在現實面入侵機房，內海的最後一步就做不了。這種「開路」型的連動會在簡報或踩點時標明。
- 簡報會說主面是什麼（「這是一件要動手的案子」）。輔助面有哪些、各能幫上什麼，要踩點才知道。

**特殊任務沒有這些限制。** 它們用傳統的劇情旗標：到某地、和某人談、打贏某場、做某個選擇。要在現實還是在網內、要不要打輿論戰，由那條任務線自己寫，不套主面與指標。

## 5. 連動

連動是輔助面幫到主面的方式（代勞、減壓、開路，見第 4 節）。每個副本生成時帶二到四個連動點，踩點可以提前知道。下表列出所有方向的連動；一個副本裡實際生效的，是**指向主面**的那些。

| 來源 | 做了什麼 | 目標 | 效果 |
|---|---|---|---|
| 現實 | 插上機房的資料埠 | 內海 | **開啟隔離區**；或直接從核心附近進入，略過外面幾層 |
| 現實 | 活捉一名主管 | 內海 | 取得管理憑證：內海面的閘門不用破解 |
| 現實 | 拿到實體文件／拍到現場 | 輿論 | 得到一張高品質、已查證的素材牌 |
| 現實 | 切斷大樓的電力或網路 | 內海 | 蕾絲降一級；追蹤度的上升減半 |
| 內海 | 接管控制節點 | 現實 | 開門、關攝影機、停砲塔、放下防爆門（[NETRUNNING](NETRUNNING.md) 第 4 節） |
| 內海 | **取得內部消息**（郵件、帳目、通訊紀錄） | 輿論 | **輿論指標大漲**（+20～40），並得到「內幕」素材牌，對手無法否認 |
| 內海 | 竄改班表／調度系統 | 現實 | 這一節的巡邏減半；增援延後 |
| 內海 | 駭進平台 | 輿論 | 這一回合無視萬華鏡的門檻，或把議題置頂 |
| 輿論 | 聲量過 60 | 現實 | 全城在看：保全被上層禁止使用致命手段；記者與圍觀的人擠在門口（多一種掩護，也多一種麻煩） |
| 輿論 | 風向對目標勢力極不利 | 現實 | 內部的人動搖：出現願意開門的內應；部分保全不抵抗 |
| 輿論 | 假消息調虎離山 | 現實 | 一節之內，警戒不上升或增援去了錯的地方 |
| 輿論 | 聲量過 60 | 內海 | 目標的子網湧入流量：追蹤度的判定變鬆，但訪客層變擠（移動變慢） |

- 連動是**雙向的好處，也是雙向的麻煩**：輿論面的對手在公關上輸了，可能改用實體的手段——派人去找主播的身體（[OPINION](OPINION.md) 第 6 節）。
- 最漂亮的打法是把三個面串成一條鏈：從內海取得內部消息 → 輿論面進度大漲、內應出現 → 現實面的門自己開了。

## 6. 怎麼玩

### 6.1 召集與分工

**行動開始前召集同伴。** 走到委託地點、進入副本之前，從名冊（[FIXER](FIXER.md) 第 6 節）選這次要帶的人。

- **人數**：一件委託最多 6 人（含主角）；每個面最多 4 人。帶越多人，報酬分得越薄，名冊上的人也不是每次都有空。
- **看職能召集**：主角沒有職業，什麼都能碰一點；夥伴的職能是固定的，每人一到三條路數（[CORE_RULES](CORE_RULES.md) 6.2、6.3 節）。這件委託的主面是什麼、打算開幾條輔助的路，決定該找誰。

| 去哪 | 人在哪 | 誰在這裡強 |
|---|---|---|
| 現實面 | 現場 | 戰鬥型（強）；潛網者（中）；社交型負責開打前的事（弱） |
| 內海面 | 身體在安全屋或現場的接入點，意識在網內 | 潛網者（強）；社交型與媒體型（中）；戰鬥型（弱） |
| 輿論面 | 編輯台（據點、轉播站、或任何有訊號的地方） | 媒體型（強）；社交型（中） |

- **主角去哪一面由玩家決定**——通常是主面，但不一定。主角親自操作的那一面最細；其他面可以手動，也可以交給帶隊的夥伴自動進行（6.3 節）。
- **沒有人去的面，指標不會動**。
- **複合職能的夥伴可以換面**：偶像／潛網者的夥伴前半段在編輯台，後半段潛進內海。換面要花一節。
- 人手不夠的面可以**外包**給名冊上沒被召集的人：不操作，每一節自動推進一點，品質較差。

### 6.2 節

副本的時間切成**節**。每一節，三個面各推進一段，然後時鐘走一格：

| 面 | 一節裡發生什麼 |
|---|---|
| 現實面 | 一段探索（在地圖上走、開門、搜索），直到遇到一場遭遇（戰鬥、對峙、檢定）並解決它 |
| 內海面 | 同上，在網內 |
| 輿論面 | 一個回合（[OPINION](OPINION.md) 第 4 節） |

- 玩家操作全隊，依序處理每個有人的面。順序可以自己排——先打內海拿到控制節點，這一節的現實面就輕鬆。
- **現實面與內海面在同一處交戰時**（一組人在樓裡、一組人在這棟樓的子網裡），兩邊併成同一個先攻序列（[NETRUNNING](NETRUNNING.md) 第 3 節）。
- 期限以節計：簡單的副本 6～8 節，複雜的 12～16 節。警報、追蹤度滿、對手公關得手，都會讓時鐘加速。

### 6.3 一個人怎麼玩三個面

- 只想打的玩家：專接主面是現實的委託，帶一隊戰鬥型一路走到通。輔助面不碰也行。
- 想玩全貌的玩家：分隊，每一節輪流處理。
- 存檔規則可以選「非主角所在的面自動進行」：只操作主角那一面，其他面交給隊友（依能力結算，可以隨時切回手動）。

## 7. 委託的類型

每種類型有一個**主面**（★），其餘的面是輔助（◐常見、○偶爾有、—沒有）。

| 類型 | 現實 | 內海 | 輿論 | 決定性的一步 | 輔助面通常怎麼幫 |
|---|---|---|---|---|---|
| **暗殺** | ★ | ◐ | ○ | 殺掉目標 | 內海：定位他、關掉他的保全系統、把他灌到過載讓現實的人好下手。輿論：把他引到公開場合 |
| **破壞** | ★ | ◐ | ○ | 毀掉那樣東西 | 內海：關閉安全系統、解鎖 |
| **奪取（實體）** | ★ | ◐ | — | 把東西拿到手 | 內海：門禁、位置、密碼 |
| **挖角／綁架** | ★ | ◐ | ○ | 把人帶出來 | 內海：處理他的橋權，不然帶出來也會被遠端鎖死 |
| **護送／救援** | ★ | ○ | ○ | 人安全抵達 | 內海：路線上的監視器。輿論：全城在看，對方不敢動手 |
| **討債／回收** | ★ | ○ | — | 拿到錢或義體 | |
| **蜜罐** | ★ | — | ◐ | 取得把柄 | 輿論：事先把目標捧高，他才會上鉤 |
| **竊密（資料）** | ◐ | ★ | — | 下載檔案 | 現實：偷憑證、插資料埠直通核心；**有隔離區時，現實是必經的** |
| **抹除** | ○ | ★ | ○ | 刪掉資料與備份 | 現實：毀掉離線的備份 |
| **竄改** | ○ | ★ | ◐ | 改掉紀錄 | 輿論：讓改過的版本被當成真的 |
| **心智**（讓人忘記、崩潰、聽話） | ◐ | ★ | ○ | 對目標的橋造成指定的精神污染 | 現實：讓他待在接得上線的地方 |
| **網內打撈** | — | ★ | — | 把東西從沉船帶帶出來 | |
| **抹黑** | ○ | ◐ | ★ | 聲量與風向到位 | 內海：內部消息讓進度大漲。現實：蜜罐、拍到現場 |
| **爆料** | ◐ | ◐ | ★ | 同上 | 現實與內海提供證據；沒有證據的爆料撐不久 |
| **滅火** | ◐ | ◐ | ★ | 撐到期限，聲量壓在底下 | 現實與內海：找出並毀掉對方的料 |
| **造勢／洗白** | — | ○ | ★ | 聲量與風向到位 | |

- 同一個東西可以是不同的委託：一份機密，要**實體的晶片**是奪取（主面現實），要**裡面的資料**是竊密（主面內海）。委託人要的是哪一個，簡報會說。
- 中間人的門路決定他給哪些類型（[DISTRICTS](DISTRICTS.md) 第 12 節）：舊港的帳房多半給現實的；地下層的探員給內海的；玻璃岸的製作人給輿論的。
- **同一件事可以從兩邊接**：一個中間人發抹黑案，另一個同時發滅火案，對手是另一隊邊緣行者。

## 8. 路線與後果

達成之後，依**用了哪些輔助面**結算。同一份報酬，不同的餘波：

| 怎麼做的 | 留下什麼 | 額外得到 |
|---|---|---|
| 只走主面，一路走到通 | 主面的痕跡最重（硬闖的現場、被追蹤的入侵、公開的敵人） | 最少的人分最多的錢 |
| 用了現實當輔助 | 目擊者、監視畫面。目標勢力的熱度 | 實體的戰利品 |
| 用了內海當輔助 | 追蹤紀錄。夜鶯與貞網局的熱度 | 資料：可以賣、可以當素材、可以當下一件案子的憑證 |
| 用了輿論當輔助 | 一個公開的敵人 | 觀眾、公信力、人氣 |

- **評價**（影響歷練點與街頭信譽）看：達成度、附帶條件、用了幾節、輔助面的指標（做得漂亮有加分）。
- 沒有達成也有結果：主面的指標過半算「部分完成」，拿一部分報酬；手上的資料與素材還在。

## 9. 生成

一個副本＝**類型 × 委託人與目標勢力 × 現實面模板 × 內海面生成參數 × 輿論面的議題 × 連動點 × 詞條**。

| 部分 | 來源 |
|---|---|
| 現實面模板 | 手工畫的固定地圖，約 24 張起：小辦公室、辦公樓層、倉庫、機房、俱樂部、人偶館、診所、宅邸、片場、碼頭貨櫃區、公寓、停車場……每張標了可以放目標、資料埠、入口的位置 |
| 現實面的內容 | 依目標勢力放保全（[CORPORATIONS](CORPORATIONS.md) 第 7 節的敵人類型）、依等級定數量 |
| 內海面 | ElondiaRPG 的地下城生成器（[CYBERSPACE](CYBERSPACE.md) 第 8 節）；蕾絲的風格依企業 |
| 輿論面 | 議題模板 × 對手的公關強度（[OPINION](OPINION.md) 第 5 節） |
| 詞條 | 一兩個讓這次不一樣的條件：「今晚有派對」「正在換班」「目標不在預定的位置」「另一隊人也在裡面」 |

- **現實面用固定模板，不用隨機生成**——現實的地圖應該看起來是人蓋的。重玩的變化來自內容與詞條，不是牆的位置。
- 生成的結果存在存檔裡，重新整理不會變。

## 10. 四個例子

**暗殺（主面：現實）**
委託人要星旗的一名軍需官死。內海殺不了人，這件事只能在現實做。
- 一路走到通：全員去現場，打穿他的護衛。
- 分路：潛網者進他宅邸的子網，關掉警報、把他的位置報出來（代勞：現實面前兩個里程碑直接完成），再把他灌到過載（減壓：他動不了）。現實的人只要走到他面前。
- 最後一步——扣扳機——一定在現實。

**竊取機密（主面：內海，現實是必經的輔助）**
蜜腺的一份配方。委託人要的是資料，所以主面是內海。
- 踩點發現配方存在隔離區，從網內進不去。
- 現實面入侵機房，插上資料埠（開路：隔離區打開）。一個人在機房裡接線潛入，其他人守住門。
- 最後一步——下載——在內海。

**抹黑（主面：輿論）**
委託人要讓星旗的一位領事下台。名聲只能在編輯台上毀掉。
- 一路走到通：主播坐上編輯台，用手上的素材和星旗的公關拉鋸。做得到，但慢，期限很緊。
- 分路：潛網者同時進領事館的子網，拿到一批內部郵件（代勞：輿論指標 +35，並得到對手否認不了的「內幕」牌）。伶人去現實認識領事的秘書（減壓：對手下一步落空）。
- 最後一步——讓風向定案——在編輯台。

**救援（主面：現實，輿論當輔助）**
一名契約人從伊甸園逃出來，要送到蜜糖會。
- 現實面是一路的追兵。
- 偶像在編輯台上表態、動員親衛隊，聲量過 60（減壓：全城在看，伊甸園的回收員被禁止動手，只能跟著）。
- 最後一步——人走進糖罐的門——在現實。
