# 輿論戰：編輯台

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[MEDIA](MEDIA.md)（素材、觀眾、公信力、人氣）、[LIFE](LIFE.md) 第 7 節（消息的管線）、[CORE_RULES](CORE_RULES.md) 第 6 節（三個領域）。被依賴：[COMMISSIONS](COMMISSIONS.md)（輿論面）、[FIXER](FIXER.md) 第 9 節（轉播站）。
> 來源：新做。可以借的：ElondiaRPG 的情報與傳聞、物品（素材牌）、主動行動（帶風向的判定）、據點與每週結算。預定資料：`data/rules/opinion.json`、`topics.json`、`pr_moves.json`。數值都是初稿。

媒體人不靠槍。媒體型的兩條路數——主播與偶像——在現實的戰鬥裡沒有招牌能力可用；她們的戰場是另一張桌子。

**編輯台**是一個獨立的經營與策略玩法（SLG），有自己的資源、自己的回合、自己的對手。它有兩層：

| 層 | 是什麼 | 節奏 |
|---|---|---|
| **經營層：頻道** | 你的媒體事業。人手、設備、欄目、收入 | 每週 |
| **戰役層：議題** | 把一件事推上去、壓下來、或扭過來 | 每回合半天，一場 6～14 回合 |

兩層互相餵：頻道養得好，打議題時手上的牌與人手多；議題打贏了，觀眾與公信力回到頻道。

## 1. 三個長期的數字

沿用 [MEDIA](MEDIA.md) 第 4 節，這裡補上它們在編輯台的作用：

| 數字 | 在經營層 | 在戰役層 |
|---|---|---|
| **觀眾** | 每週的廣告與打賞收入 | 你的投放有多少基礎的熱 |
| **公信力** | 廣告單價；能不能上晨星社 | 你的說法有多少人信：帶風向的力道；被反爆料時扛不扛得住 |
| **預算** | 就是錢。頻道有自己的帳 | 買推廣、收買、付律師 |

流量與可信互相拉扯這件事不變：衝觀眾的做法（煽情、水軍、假料）會掉公信力。

## 2. 經營層：頻道

### 2.1 編制

頻道有**編制**——替你做事的人。每個位子放一個人：名冊上的 NPC（[FIXER](FIXER.md) 第 6 節），或雇來的生成 NPC。每週付薪水。

| 位子 | 給什麼 |
|---|---|
| 剪輯 | 素材的品質 +1；每回合多 1 點編輯點 |
| 線人 | 每週自動帶回 1～2 張素材牌或一條線索；戰役中「挖料」不必派隊友 |
| 寫手 | 每回合多 1 點編輯點；「帶風向」的檢定 + |
| 水軍頭 | 「水軍」行動便宜、不易被拆穿 |
| 法務 | 抵銷律師函與下架 |
| 技術 | 抗降流；可以用地下轉播站 |
| 攝影 | 隊友在現實面時自動錄素材；直播的品質 + |

- 編制的上限看頻道等級（2 → 7 個位子）。
- 位子上的人有自己的可靠度與忠誠——寫手會被挖走，線人會被抓，水軍頭會賣你。這些是經營層的事件。
- 路數是主播的夥伴放在編制裡，效果加倍。

### 2.2 欄目

每週排三到五個**欄目**——固定播出的節目。這是頻道平常的樣子，也是被動的成長來源。

| 欄目 | 每週給 | 代價 |
|---|---|---|
| 街頭新聞 | 公信力 +，線索 + | 要有線人或自己跑 |
| 深度專題 | 公信力 ++，偶爾一張高品質素材 | 佔兩格；慢 |
| 八卦 | 觀眾 ++ | 公信力 −；累積名人的敵意 |
| 直播實況 | 觀眾 +，打賞 + | 要有人上鏡（主播自己、偶像、伶人） |
| 感官帶精選 | 觀眾 +，豔名 + | 公信力 − |
| 業配 | 預算 ++ | 公信力 −；那個金主的事你不能報 |
| 讀者投書／爆料信箱 | 隨機的素材與線索 | 有假料；有陷阱 |
| 重播 | 維持觀眾不流失 | 什麼都不長 |

- 欄目的組合決定頻道的**定位**：新聞台、八卦台、成人台、地下台。定位影響誰願意給你料、哪些管道對你友善。
- 這是每週結帳（[FIXER](FIXER.md) 第 4 節）的一部分：一個畫面排好下週的欄目。

### 2.3 設備與據點

頻道要有地方。**轉播站**是三級據點的一種店面（[FIXER](FIXER.md) 第 9 節）；沒有轉播站也能經營，只是編制與設備的上限低。

| 設備 | 效果 |
|---|---|
| 剪輯室 | 素材可以重剪（換角度）；偽造的品質 + |
| 直播棚 | 「直播實況」欄目的效果 +；戰役中可以開現場連線 |
| 自有伺服器 | 被下架時保留一半的熱；不怕降流 |
| 線人網 | 線人的位子 +1；每週多一條線索 |
| 資料庫 | 存放素材不會過期；可以翻舊帳（舊素材在相關議題上重新可用） |

### 2.4 每週

| 項目 | 怎麼算 |
|---|---|
| 收入 | 廣告（觀眾 × 單價，單價看公信力與定位）＋打賞＋賣斷素材＋業配 |
| 支出 | 薪水、頻寬、據點、保護費（看在誰的地盤） |
| 流失 | 沒有新東西的頻道每週掉觀眾 |
| 事件 | 編制的人出事、金主施壓、對手頻道挖角、平台改演算法 |

## 3. 戰役層：棋盤

一場戰役圍著一個**議題**打。棋盤是緋夜城的消息管線（[LIFE](LIFE.md) 第 7 節）——六條**管道**，由下往上：

| 管道 | 觸及 | 進得去的條件 | 特性 |
|---|---|---|---|
| 街上的耳語 | 1 | 無 | 最快；會走樣（風向每回合隨機漂一點） |
| 牆報 | 2 | 無 | 匿名；水軍的主場 |
| 帶子街 | 3 | 要有感官帶素材 | 「親身感覺」：這裡的風向最難扭 |
| 地下轉播站 | 2 | 要有技術，或牆語者／車族的好感 | 不會被下架、不會被降流；聽眾少 |
| 晨星社 | 4 | 公信力 ≥ 50，素材要查證過 | 慢一回合才生效；但生效後公信力 + |
| 萬華鏡 | 8 | 聲量夠高它自己會報；或買進去；或駭進去 | 觸及最大；它有自己的立場，會降流、會改寫 |

每條管道有兩個值：

- **熱**（0～5）：這件事在這條管道上有多紅。
- **向**（−5～+5）：這條管道上的人偏向哪一邊的說法。正的是你的，負的是對手的。

由它們算出整場戰役的兩個數字：

```
聲量 = Σ（各管道的 熱 × 觸及）          最高 100
風向 = Σ（各管道的 向 × 熱 × 觸及）÷ 聲量    −5 ～ +5
```

**擴散**：每回合結束時，熱 ≥ 3 的管道會把上一級的管道帶熱 1 點，風向跟著過去。消息自己會往上爬——這是「點火」之後可以放手的原因，也是壓不住的原因。萬華鏡例外：它不會被自動帶熱，除非總聲量過 50。

## 4. 戰役層：回合

一回合是半天。流程：

```
① 翻一張城市事件   ② 你的行動（花編輯點）   ③ 對手的行動   ④ 擴散與衰退   ⑤ 結算里程碑
```

**編輯點**：每回合 2 點，加上編制給的。主播的「聚光燈」每階 +1。

| 行動 | 編輯點 | 效果 |
|---|---|---|
| **投放** | 1 | 打出一張素材牌到一條管道。熱 +（依品質），向往你的方向 +（依真實性與公信力）。選一個角度（[MEDIA](MEDIA.md) 第 3 節） |
| **帶風向** | 1 | 不用素材，靠嘴。表演或交涉檢定，一條管道的向 ±1～2 |
| **加碼** | 1＋錢 | 買推廣。一條管道熱 +1 |
| **水軍** | 1 | 耳語或牆報熱 +2。有機率被拆穿：公信力 −，那條管道的向反彈 |
| **查證** | 1 | 替一張素材牌加上「已查證」。調查檢定。進晨星社的門票 |
| **採訪** | 1 | 得到一張即時但品質低的素材牌 |
| **挖料** | 1 | 請線人（或隊友）去找。下回合得到一張牌，品質看人 |
| **降溫** | 1 | 一條管道熱 −1。滅火用 |
| **轉移焦點** | 2＋一張無關的素材 | 所有管道熱 −1，另一件事替它上去 |
| **設防** | 1 | 抵銷對手下一次的下架或律師函 |
| **現場連線** | 2 | 要有隊友正在現實面或內海面行動。這一節他們做的精彩的事，直接變成熱（見第 6 節） |
| **留一手** | 0 | 蓋一張牌。對手反爆料時翻開，抵銷並反打 |

- 素材牌打出去就用掉了（獨家性沒了），除非有資料庫。
- **假素材**可以打：效果和真的一樣，但每回合有機率被拆穿。被拆穿時那條管道的向大幅反轉，公信力重挫。用不用是一場賭。
- AI 開著時，「帶風向」是一次自由行動：玩家用文字寫這則貼文／這段話，AI 判定成功程度，效果由程式夾在上表的範圍內。

**衰退**：每回合結束，沒有被加熱的管道熱 −1。議題不餵就會冷——所以滅火有時候只要拖。

## 5. 議題與對手

### 5.1 議題

戰役的目標寫在議題上：

| 類型 | 要做到 | 用在 |
|---|---|---|
| 引爆 | 聲量 ≥ X 且風向 ≥ +Y | 爆料、造勢 |
| 抹黑 | 聲量 ≥ X 且風向 ≥ +Y，目標是一個人或勢力的名聲 | 抹黑 |
| 滅火 | 到期限為止，聲量 ≤ X | 滅火。這時你是「公關」，對手是想把事情鬧大的那一方 |
| 洗白 | 把一個已經很熱的議題，風向從負的扭到正的 | 公關、救人 |
| 嫁禍 | 讓聲量落在另一個勢力頭上 | 抹黑的變體 |

在委託副本裡，這些條件換算成輿論面的里程碑與指標（[COMMISSIONS](COMMISSIONS.md) 第 3 節）。

### 5.2 對手

每場戰役有一個對手：目標勢力的**公關**。它每回合行動，次數看強度（1～3）。它不是亂數——每個勢力的公關有自己的性格。

| 對手的行動 | 效果 | 怎麼擋 |
|---|---|---|
| 否認 | 一條管道的向 −1 | 已查證的素材讓它無效 |
| 反爆料 | 打出一張對你不利的牌：向 −2，你的公信力受檢驗 | 留一手；公信力高的話影響小 |
| 降流 | 你在萬華鏡的熱 −1 | 自有伺服器；地下轉播站不受影響 |
| 下架 | 移除你上一次的投放 | 設防；法務 |
| 律師函 | 你下回合的編輯點 −2 | 設防；法務 |
| 轉移焦點 | 所有管道熱 −1 | 手上留著能再點火的牌 |
| 收買 | 提一個價。接受：拿錢，戰役結束，公信力 −，委託失敗 | 這是一個選擇，不是攻擊 |
| 買通你的人 | 編制裡可靠度低的人倒戈：你的下一步被對手知道 | 養好你的人 |
| **找上門** | 派人到現實來（見第 6 節） | 隊友；躲；靜默 |

| 對手 | 性格 |
|---|---|
| 萬華鏡 | 平台是它的。降流與改寫是免費的。最難的對手 |
| 緋櫻 | 耐心。前幾回合只否認，然後一次打出準備好的反爆料。最後找上門的是家政課 |
| 星旗 | 粗。直接律師函與威脅，很早就找上門 |
| 蜜腺 | 用專家與數據否認。公信力低的對手對它幾乎無效 |
| 伊甸園 | 收買。對你的編制下手 |
| 黑泉 | 把事情扯到道德上；動員教會的聽眾（耳語與地下轉播） |
| 幫派 | 不玩公關。直接找上門 |
| 另一個主播 | 鏡像對手：和你用同一套行動。出現在「同一件事兩邊都有人接」的時候 |

### 5.3 城市事件

每回合翻一張。它們是棋盤的天氣：

- 另一樁醜聞爆出來（所有管道熱 −1）。
- 祭典組封街（耳語與牆報的熱翻倍）。
- 萬華鏡換了演算法（這回合萬華鏡的觸及減半）。
- 偶像的畢業公演（帶子街與萬華鏡被佔滿，進不去）。
- 停電、雨季淹水、理事會開會……

年度事件（[LIFE](LIFE.md) 第 8 節）會固定影響那幾天的棋盤。

## 6. 和另外兩個面的往來

編輯台不是孤島。這些往來寫成委託副本的連動（[COMMISSIONS](COMMISSIONS.md) 第 5 節），這裡列出編輯台這一側看到的樣子：

**進來的**

| 來源 | 編輯台得到 |
|---|---|
| 隊友在內海取得內部消息 | 一張「內幕」牌：高品質、已查證、對手不能否認。聲量與風向一次跳一大段 |
| 隊友在現實拍到現場／拿到文件 | 一張高品質的素材牌 |
| 潛網者駭進平台 | 這回合無視萬華鏡的門檻；或把議題置頂（萬華鏡熱 +2） |
| 現場連線 | 隊友這一節每一件精彩的事（要害、過載、機甲、險些被發現）＝ 一條管道熱 +1 |
| 偶像的人氣 | 帶子街與萬華鏡的基礎熱。偶像不只是助力——她自己可以坐上編輯台（第 7 節） |
| 掮客的人情 | 買到一個版面、讓某個管道的守門人放行、讓對手的律師晚一天 |

**出去的**

| 編輯台做到 | 另外的面得到 |
|---|---|
| 聲量過 60 | 現實面：保全被禁止使用致命手段；現場有圍觀與記者 |
| 風向對目標極不利 | 現實面：出現內應 |
| 假消息 | 現實面：增援去了錯的地方 |
| 聲量過 60 | 內海面：目標子網的追蹤判定變鬆 |

**找上門**

對手在公關上輸了，會改用別的方式。「找上門」讓編輯台的對手**在現實生成一隊人**，朝主播的所在位置去。

- 主播與偶像在現實的戰鬥裡都沒有招牌能力。她們需要隊友，或者躲得夠好。
- 所以分工時要想：留誰守著編輯台？這是媒體路數對隊友的依賴，也是隊友對媒體的回報。
- 擋不住的話：編輯台被砸（這場戰役的編輯點歸零一回合）、主播被抓（戰敗事件）、或者——如果他有準備——整個過程被直播出去，變成一張最好的牌。

## 7. 誰能玩

輿論戰是**媒體型**的主場，社交型居中，其餘兩類的招牌能力在這裡沒有效果（[CORE_RULES](CORE_RULES.md) 6.1 節）。

| 誰坐在編輯台 | 分量 | 能做什麼 |
|---|---|---|
| **主播** | 強 | 第 4 節的全部行動。編輯點 ＋聚光燈階數；可以用所有管道；可以打假素材；可以現場連線 |
| **偶像** | 強 | 自己的一組行動：表態、公演、聲援與動員、唱出來（[MEDIA](MEDIA.md) 9.5 節）。編輯點 ＋應援階數。主播出牌，偶像出聲 |
| **伶人** | 中 | 基本的投放與帶風向，加上自己的兩招。**假身分**：扮成內部員工、當事人、路人放話——帶風向的效果加倍，被拆穿時掉的是那個假身分，不是頻道的公信力。**蜜罐**：花一回合去「認識」對手陣營的人，帶回一張素材牌，或讓對手下一步落空。編輯點 ＋入戲階數的一半 |
| **掮客** | 中 | 基本的投放，加上自己的兩招。**買**：加碼不花編輯點；買版面（直接進一條有門檻的管道）；收買對手的人（讓對手這回合少一步）。**擋**：用人情讓律師函晚一回合、讓下架不成立。全部花錢或人情。編輯點 ＋人面階數的一半 |
| 潛網者、戰鬥型 | 無 | 招牌能力在編輯台上沒有效果。坐上去只有每個人都有的 1 點編輯點，只能在耳語與牆報投放 |
| 沒有人 | — | 外包給 NPC 記者（名冊）：每回合自動推進，品質依他的能力，不會用假素材 |

- 編輯台可以同時坐兩個人，每個人用自己的編輯點。
- **社交型可以獨立打一場輿論戰**，只是手上的行動比媒體型少、用不了查證與現場連線，進不了晨星社。
- 潛網者與戰鬥型對輿論戰的貢獻不在編輯台上，而在他們自己的戰場：取得內部消息、駭進平台、拍到現場、守住編輯台。這些走的是連動（第 6 節），不是招牌能力。

## 8. 自己發起的戰役

編輯台不只在委託裡用。主播隨時可以拿自己手上的素材**自己開一場戰役**：

- 目標自己定：爆哪個勢力的料、捧誰、救誰。
- 沒有委託人，也就沒有報酬——得到的是觀眾、公信力，以及對世界的改變。
- 六條主線裡的「母帶」（[NPCS](NPCS.md) 第 7 節）最後就是一場這樣的戰役，對手是萬華鏡。

## 9. 結果

一場戰役結束時，依最終的聲量與風向算出**衝擊值**，換成封閉清單裡的後果（一份 `broadcast` 報告）：

- **勢力的聲望與熱度**：目標勢力在市民間的聲望；它對你的熱度。
- **區域狀態**：衝擊夠大時改變一個區幾天——保全增減、物價、抗議、某間店關門。
- **人**：被捲進來的 NPC 的處境與態度。可以毀掉一個人，也可以救一個人（讓全城看著，企業就不方便讓他消失）。
- **之後的委託**：和那個勢力有關的副本，警戒的起始值、可用的入口、報酬會變。
- **頻道**：觀眾、公信力、預算的增減回到經營層。

## 10. 畫面

一張桌子的樣子：

- 中央是**六條橫向的管道**，由下（耳語）到上（萬華鏡）。每條上有熱的格子（0～5，像火焰一格格點亮）與向的滑標（左右兩色拉鋸）。
- 上方是兩個大數字：聲量與風向，以及目標線。
- 下方是**手牌**：素材牌，寫著標籤、品質、真實性、獨家、剩餘的新鮮度。
- 右側是對手：它的頭像、強度、上一步做了什麼、推測下一步。
- 左側是編制：誰在位子上、這回合貢獻了什麼。
- 委託副本裡，上緣另有三條領域指標（[COMMISSIONS](COMMISSIONS.md) 第 3 節）。
