# 日常：錢、身分、法律、貨與行規

> 上層：[WORLD](WORLD.md)。依賴：[CORPORATIONS](CORPORATIONS.md)、[GANGS](GANGS.md)、[DISTRICTS](DISTRICTS.md)。被依賴：[ITEMS](../gear/ITEMS.md)（物品目錄）、[TRADE](../systems/TRADE.md)、[STORY_QUESTS](STORY_QUESTS.md)、[EVENTS](../systems/EVENTS.md)；[FIXER](../systems/FIXER.md)（委託的行規）、[CYBERWARE](../gear/CYBERWARE.md)（品級與品牌）。
> 這份是世界觀文件，目的是**讓物品、系統、任務有東西可以依據**：一把槍多少錢、什麼東西犯法、同一種東西為什麼有五種牌子、一週裡什麼時候會發生什麼、城市的大事怎麼觸發。價格與數值都還要平衡。

## 1. 錢

### 1.1 兩種錢

| | 帳上的信用點 | 現金晶片 |
|---|---|---|
| 是什麼 | 綁在橋 ID 上的帳戶餘額 | 匿名的現金晶片，指甲大小，粉色的 |
| 誰收 | 所有地方 | 黑市、幫派、四十二番街、舊港、地下層；冠冕區與正規商店不收 |
| 好處 | 方便；可以分期、可以貸款 | 查不到；被捕、被鎖帳戶時還在 |
| 壞處 | **每一筆都有紀錄**。用帳戶付髒錢，敵對值會找上來；欠債時可以被直接扣走 | 會被偷、被搶；不能貸款 |

- **洗錢**：把現金晶片變成乾淨的帳上信用點（或反過來）要過一手，抽 10%～20%。胭脂堂的賭船、四十二番街的店、同人夜市都做這個生意。
- 委託的報酬預設付現金晶片；談判時可以改成匯進帳戶（少一成五，算髒交易）或三成換人情（[FIXER](../systems/FIXER.md) 第 2 節①）。這是每週帳單（[FIXER](../systems/FIXER.md) 第 4 節）的一個小摩擦：房租與義體訂閱要從帳戶扣，所以玩家得定期洗錢，或者接受付現的折扣差。
- 介面上兩種錢各有一個圖示，數字前面不寫 C$：帳戶是淡紫色的卡，現金晶片是粉色的小晶片（[UI](../art/UI.md) 3.5 節）。
- 系統上：兩個數字。**用帳戶做髒交易，當場加那個勢力的敵對值**；用現金晶片就不加。不另外記一條「帳面痕跡」的數字：帳戶會留下把柄這件事，由敵對值和事件來表現（被查帳的事件、偷別人的交易紀錄當素材）。

### 1.3 經濟的基準

敵人、裝備、委託都分 I～V 級之後，錢也照等級走。**比例是定案**，表裡的金額是照比例推出來的；[BALANCE](../systems/BALANCE.md) 2.8 節對過，每一級的三條比例都對得上。

**三條比例：**

| 比例 | 目標 | 意思 |
|---|---|---|
| 一件同級的裝備 | 大約是 2～3 件同級委託的個人收入 | 做兩三件事換一樣好東西 |
| 全身換到下一級 | 大約 15～20 件委託，其中一半的東西靠掉落與拆解，不靠買 | 和歷練點的節奏對齊：15 件委託大約是一棵樹開到五階（[CORE_RULES](../systems/CORE_RULES.md) 7.1 節） |
| 每週的固定開銷 | 大約是一件同級小委託的個人收入 | 一週做一件打平，做兩三件才有餘 |

**照等級的金額：**

| 等級 | 一件中型委託的個人收入 | 一件同級的裝備 | 每週的固定開銷 | 大概的生活 |
|---|---|---|---|---|
| I | 400 | 1,000 | 250 | 蜂巢的單位、糰糧、一把街貨 |
| II | 1,200 | 3,000 | 700 | 像樣的義體，偶爾吃真的食物 |
| III | 4,000 | 10,000 | 2,400 | 安全屋、訂閱制的義體、一輛車 |
| IV | 13,000 | 32,000 | 7,800 | 軍規的裝備、自己的店面 |
| V | 40,000 | 不賣 | 25,000 | 原型只能靠委託、任務與流竄 AI 拿到 |

- 每升一級大約是 3.2 倍。這個倍率和「等級之間的差距要大」是同一件事。
- **委託的報酬**：小的 ×0.6，大的 ×1.8。全隊的報酬是個人收入乘上分紅的份數；主角當老闆可以多拿一份。
- **委託的等級**看區與中間人，街頭信譽決定你接不接得到那一級（信譽六階對應 I～V 級：最低兩階無名、熟面孔都算 I 級，之後每升一階升一級，有號 II 級、搶手 III 級、頂尖 IV 級、傳說 V 級；最高一階接得到 V 級的大委託）。信譽怎麼漲怎麼掉照 [CORE_RULES](../systems/CORE_RULES.md) 8.1 節：只有完成同級以上的委託才會升，比自己低一級的委託錢照拿、信譽不動）。事件裡 AI 給的錢的上限也照這個對法（[EVENTS](../systems/EVENTS.md) 2.4 節）。
- **每週的固定開銷**由這些組成：房租、吃、抑制劑、義體訂閱（售價的 3%）、生體件的營養劑、債的利息、夥伴的出場費。等級越高，義體訂閱佔的比例越大。住處的週租最貴是玻璃岸臨海的別墅 4,000（[DOWNTIME](../systems/DOWNTIME.md) 7.2 節），不跟著帳單長：IV 級的 7,800 大約是房租一兩千、四到六件 IV 級義體的訂閱（一件每週約 1,000）與載具或機甲的整備（[CRAFTING](../gear/CRAFTING.md) 15.2 節）；V 級的 25,000 有八成以上是訂閱、機甲的整備與夥伴的出場費。

**錢從哪裡來、花到哪裡去：**

| 收入 | 支出 |
|---|---|
| 委託的報酬（主要） | 裝備與零件、手術 |
| 掉落的零件與拆解（[CRAFTING](../gear/CRAFTING.md) 第 10 節） | 每週帳單（[FIXER](../systems/FIXER.md) 第 4 節） |
| 派工（[FIXER](../systems/FIXER.md) 第 7 節） | 夥伴的出場費與分紅 |
| 打工（一天 40～300，照那一區的等級） | 踩點時買情報、買通 |
| 頻道：廣告、打賞、賣斷素材（[MEDIA](../systems/MEDIA.md)） | 輿論戰裡買聲量、買版面 |
| 店面（三級據點） | 洗錢的抽成、洗點、治療 |
| 走私與收贓（[TRADE](../systems/TRADE.md) 第 4、6 節） | 買斷契約、還債 |

打工讓你活著，委託才讓你往上；這一點不變。

## 2. 身分

### 2.1 橋 ID

每座合法安裝的橋有一個 ID。它是身分證、錢包、鑰匙、病歷。**掃橋**——讀取橋 ID——是這座城市最日常的動作：進地鐵、進冠冕區、進企業的樓、租房、就醫、買登記類的東西。

**掃橋是一個統一的動作**：世界讀你的橋。不管在哪裡被掃，都依序看這四樣：

| 看什麼 | 結果 |
|---|---|
| 身分（社員、市民、無籍、契約人；2.2 節） | 這個地方你進不進得去、這樣東西你買不買得到 |
| 掃的那個勢力對你的敵對值 | 記名以上，那個勢力的檢查哨認得你，假身分比較難過關；到了通緝，它的檢查哨一律攔你（[FACTIONS](FACTIONS.md) 6.1 節） |
| 你用的是不是假身分（2.3 節） | 假身分的等級對上這個點的掃描強度，擲一次；失敗就是一件盤查的事件 |
| 沉溺與契約 | 只有鎮溺隊、貞網局、伊甸園的掃描器會看。主角藏著沉溺時，在這裡擲看穿的檢定：對方的調查，對上主角的定力加隱藏手段的加值 |

- 掃橋的點寫在地圖上：地鐵的閘門、冠冕門、企業建築的入口、檢查哨、賣登記類的櫃台。每個點有掃描強度（[EQUIPMENT](../gear/EQUIPMENT.md) 6.3 節）。
- 玩家對 NPC 用的「快駭讀橋」是同一件事反過來做（[NPC_SYSTEM](../systems/NPC_SYSTEM.md) 6.4 節）。
- 無籍的人沒有橋 ID 可掃：進不了要掃橋的地方，但也不會被認出來。

### 2.2 三種人

| 身分 | 是誰 | 有什麼 | 沒有什麼 |
|---|---|---|---|
| **社員** | 理事會企業的正式員工與眷屬 | 公司的法律保護、醫療、進出冠冕區 | 離職的自由 |
| **市民** | 登記了橋、繳得起市民稅的人。城裡的多數 | 帳戶、地鐵、合法的工作、名義上的法律保護 | 企業塔內的任何權利 |
| **無籍** | 橋沒登記、被註銷、或沒有橋的人。蜂巢與舊港很多 | 沒人查得到你 | 帳戶、地鐵、正規診所、任何保護。被捕時沒有程序 |

- 玩家開場是市民（或依出身是無籍）。身分會變：欠稅被降成無籍；被企業雇用成為社員；簽了契約則三者皆非，是**契約人**——法律上是持約人的責任。
- 無籍不全是壞事：掃不到的人，敵對值也難累積。很多邊緣行者刻意註銷。

### 2.3 假身分

| 等級 | 能做什麼 | 撐多久 |
|---|---|---|
| 一次性 | 過一次掃橋 | 一次 |
| 淺層 | 一個名字、一個帳戶、過例行檢查 | 幾週，或直到有人認真查 |
| 深層 | 完整的履歷，查得到同事與鄰居 | 直到你自己搞砸 |
| 借來的 | 一個真人的 ID——他同意的、被迫的、或已經不需要了 | 直到那個人被發現 |

- 做假身分的：同人夜市（淺層）、潛網者（進市政子網）、名媛的人格面具（連行為都換掉，掃描與盤問都過）。
- 假身分是踩點階段常見的準備，也是冠冕區與玻璃岸的門票。

### 2.4 工作

主角靠委託往上爬，城裡多數人不接委託，他們上班。一般人的工錢和主角的打工是同一個量級（[DOWNTIME](../systems/DOWNTIME.md) 第 4 節）：一天 40～300，照那一區的等級。蜂巢的搬貨工時薪 5，一週做六天拿到 240，比 I 級的每週開銷（1.3 節）還少一點，所以蜂巢的人多半同時做兩份工。

**誰做什麼**

| 身分 | 做什麼 | 怎麼被雇用 | 錢怎麼付 |
|---|---|---|---|
| **社員** | 企業的辦公室、研發、產線、警備；家政課與戰姬也是社員 | 公司的徵選、社員家庭的子女優先、從派遣轉正。雇用條款可以要求裝調校（3.1 節），家政課的忠犬就是這樣來的 | 帳戶。醫療、住處與冠冕區的通行算在薪水裡 |
| **派遣** | 企業的櫃檯、助理、清潔、服務層的雜工；女僕公會的派遣女僕與管家 | 伊甸園的人力派遣與女僕公會替人排名額。合約多半三個月一簽，續不續約看派遣公司 | 帳戶，派遣公司先抽一成到三成 |
| **市民的服務業** | 桃子屋、女僕咖啡廳、潛艙店、夜店、修理鋪、人偶館 | 店家掃橋看身分與契約（2.1 節），再看一班試做。人偶館要先把橋登記在店家的牌照下，晶片由店家管（人偶沒有正式的工會，見 [LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 6.1 節） | 帳戶，照班結 |
| **無籍的零工** | 天井市場的搬貨、舊港的卸貨與跑腿、黑拳場的陪練、帶路 | 天亮前到市場或碼頭排隊，工頭點到誰就是誰。不掃橋，也不留紀錄 | 現金日結。沒有帳戶的人只能拿現金 |
| **自己做的** | 同人社團、夜市的攤販、改造師、主播、司機 | 沒有人雇他們，靠熟客與口碑 | 現金或帳戶，看客人 |
| **契約人** | 持約人派到哪裡就做什麼。伊甸園的契約人多半被派去歡場、人偶館與派遣的缺 | 簽約或判決（3.2 節的刑事契約）。橋權在誰手上，誰就決定他的班表（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.1 節） | 收入照契約歸持約人，契約人拿零用與生活費 |

- **雇用合約本身就是一份橋權**：多數雇主要讀取級的橋權，看得到員工的位置與生理數據；借錢給員工的雇主會再要限制級（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.1 節）。所以一般人身上有幾份讀取級的橋權是常態，這和當契約人是兩回事。
- **邊緣行者是例外**：他們不被雇用，只接委託。委託透過中間人來，照行規（第 9 節）先付三成。很多邊緣行者原本是派遣或零工，被裁掉以後才找上中間人（[FIXER](../systems/FIXER.md) 第 1 節）。

**失業了會怎樣**

失業本身不犯法，問題出在帳單。一般人走的大致是和主角同一條下坡路（[FIXER](../systems/FIXER.md) 第 4 節、[DOWNTIME](../systems/DOWNTIME.md) 5.2 節）：

| 順序 | 發生什麼 |
|---|---|
| 1 | 訂閱的義體先被鎖住。社員被解雇時，公司配的義體與公司的橋權一起收回，冠冕區的通行當天失效 |
| 2 | 房租欠兩週，門鎖被換掉。很多人在這一步搬進蜂巢更小的單位，或住進愛情旅館 |
| 3 | 繳不出市民稅，身分被降成無籍（2.2 節）。從這裡開始只能做現金的零工 |
| 4 | 債權被賣給伊甸園，再過一週，伊甸園的回收員上門請他簽契約。很多人在這一步自己走進伊甸園，因為契約人至少有住處與醫療（[CORPORATIONS](CORPORATIONS.md) 第 6 節） |

- 重度獸化或裝滿訂閱義體的人失業時跌得最快，因為營養劑與訂閱費每週照收。野良裡有不少人就是這樣上街的（[CULTURE](CULTURE.md) 第 2 節）。
- 往回爬的路有三條：找中間人接委託、找蜜糖會幫忙逃契約，或者等某個企業的徵選。三條路都不保證有結果。

### 2.5 一般人的一天

這五段是世界書的素材，給 AI 寫路人與生成 NPC 時有依據。每一段照一天的六個時段（[CORE_RULES](../systems/CORE_RULES.md) 7.4 節）從清晨寫到深夜；五個人都是虛構的一般人，不是固定 NPC。

**社畜**：她 29 歲，住在蜂巢西棟，在冠冕區崑崙大樓的一樓當派遣櫃檯。清晨她 5 點半起床，在走廊的共用洗手台前排隊洗臉，吃一條糰糧，搭紅線地鐵到冠冕中央，和幾千個人一起在掃橋閘門前排隊，派遣公司給的通行憑證只在早上 9 點以前有效。上午她坐在櫃檯後面替訪客掃橋、印臨時的訪客證；雇用合約裡的那份讀取級橋權讓派遣公司看得到她每一次離開座位的時間。中午她在服務層的員工食堂吃一份 C$6 的套餐，那是她一整天唯一一餐熱的東西。下午訪客最多，她的笑容是公司訓練過的，嘴角的角度每三個月考核一次。黃金時段她下班，在地鐵上睡著，回到天井市場買一碗麵；週五的晚上她會和同事去四十二番街下城段的便宜酒館喝兩杯。深夜她在單位裡看夜鶯的直播，一邊看一邊查下一期的派遣合約有沒有續約的通知，常常到 1 點才睡。

**攤販**：他 50 歲，在天井市場擺一個麵攤，攤子是他母親留下來的。清晨 4 點他就在攤子後面熬湯，四號塔的早班工人6 點以前會來吃第一碗，一碗 C$5，他收現金晶片也收帳戶，現金晶片的那幾筆不必報稅。上午他去市場另一頭的批發處買麵和菜，和隔壁的攤販交換昨晚聽到的消息，例如誰家被換了門鎖、收租無人機今天會走哪一層。中午是一天最忙的時候，他一個人顧 4 口鍋；他的兒子在冠冕區當派遣，只有週日會回來幫忙。下午市場比較空，他把湯底補滿，坐在折疊椅上打盹，桃子屋的店員常常拿便當來跟他換一碗湯。黃金時段下工的社畜回來了，攤前的塑膠凳坐滿了人，他會替阿蓮雜貨留一碗，讓阿蓮收店時端回去。深夜他的攤子是天井市場最後兩盞還亮著的燈之一，另一盞是桃子屋；他收攤前把剩下的湯分給從屋頂村下來的野良，然後在攤子後面的鐵捲門裡睡 4 個小時。

**人偶**：她 26 歲，在四十二番街中城段一間人偶館上班，在工會登記過，晶片由店家保管。清晨她剛下班，晶片已經拔下來交回櫃檯，她從保管櫃領回自己的東西，坐在更衣室的鏡子前面卸妝，等頭痛過去，再搭第一班紅線回到旅館坡的月租房。上午與中午她睡覺，終端機設成只有媽媽桑的電話會響。下午她起床吃一碗立食麵，去靜室量一次橋參數，診所的報告上寫著她的馴化又高了 2 點；之後她到刀巷的生體件店買這一週的營養劑。黃金時段她回到店裡化妝、換上店裡的衣服，在保管櫃前讓店家替她裝上晶片；從這一刻起到她把晶片交回去之前的事，她多半不會記得。深夜是她的班表最滿的時段，一晚接 4 到 6 位客人，店家抽走五成，另一半照班結進她的帳戶，帳戶每週先扣掉房租與營養劑。

**車族**：她 34 歲，跟著野薔薇的補給車隊跑荒地，沒有橋，身分欄上只有一個外號。清晨她在薔薇驛的宿營地醒來，先檢查她那台改裝皮卡的輪胎與油管，再到加油站排隊加蜜醇；鏽帶的燃料便宜，她每次都把兩個備用桶加滿。上午車隊出發，沿著外環公路往東開，她開在第三台，無線電裡的人一路都在吵早餐要吃什麼。中午他們停在休息站「半途」吃飯，她和卡車司機交換路況，也替城裡的人帶一包信。下午車隊穿過荒地邊緣，她的護目鏡上積了一層黃沙；沙暴來的時候，所有的車圍成一圈等它過去。黃金時段車隊在荒地邊緣的營地停下來，大家生火、修車、把白天收來的貨分好；週四回到薔薇驛的那一晚，營火旁邊有泥坑摔角與賭盤。深夜她睡在車斗裡，蓋著防砂斗篷，旁邊的人在彈吉他；城裡的人說的那堵牆，她從來沒有放在心上。

**契約人**：他 31 歲，欠的債被賣給伊甸園之後簽了契約，現在是管理級的契約人，後頸有一圈粉紅色的光紋。清晨持約人透過耳語把今天的班表送到他的橋上，他在伊甸園配給的宿舍裡醒來，宿舍在蜂巢西棟，一間住 4 個人。上午他被派到冠冕區的服務層當清潔，掃橋閘門讀到他的契約，讓他走員工的貨梯，不走正門。中午他在員工食堂吃伊甸園付錢的那一份；他的工錢照契約全部歸持約人，他每週只拿 C$60 的零用。下午他繼續打掃，一位主管在走廊上叫住他問路，看到他的後頸，就改口去問別人。黃金時段班表換成四十二番街，伊甸園把他排到上城段的一間店當服務生，契約上把這一段寫作「夜間支援」。深夜他回到宿舍，用零用在桃子屋買一罐啤酒，算著還要幾年才能把自己贖回來；蜜糖會的人在糖罐門口給過他一張傳單，那張傳單他一直摺好壓在鞋墊底下。

## 3. 法律

緋夜城的法律是理事會訂的《自由市公約》。它不長，原則只有一條：**財產權高於一切**，而契約是財產。

### 3.1 四個等級

物品與行為依合法性分四級。這是物品資料的一個欄位，決定在哪裡買得到、被掃到時會怎樣。

| 級 | 意思 | 被查到 |
|---|---|---|
| **自由** | 誰都能買、能帶 | 沒事 |
| **登記** | 買的時候掃橋，紀錄綁在 ID 上 | 沒登記的：沒收、罰金 |
| **許可** | 要有執照（職業、企業、公會發的；網內的由貞網局發） | 沒執照的：沒收、拘留 |
| **違禁** | 只有理事會企業與公家機關能持有 | 拘留、義體鎖定、可能更糟 |

| 東西 | 級 | 備註 |
|---|---|---|
| 刀、鈍器 | 自由 | |
| 神經武器（感官彈槍、電擊器） | 自由 | 公約鼓勵市民使用「非致命的自衛手段」。街上人手一把 |
| 手槍 | 登記 | |
| 長槍、霰彈槍 | 許可 | 保全執照、孤星連的巡守證 |
| 重武器、爆裂物 | 違禁 | |
| 表層與一般義體 | 自由 | |
| 侵入與重度義體 | 登記 | 正規診所會自動登記；黑診所不會 |
| 軍規義體、內藏武器 | 許可／違禁 | |
| 獸化改造 | 自由 | 冠冕區的雇主可以不雇用 |
| 工具與支援類程式 | 自由 | |
| 攻擊類程式、破解工具 | 違禁 | |
| 網內的武器構裝（II 級）、防護構裝（IV 級）、構裝體 | 許可 | 許可由貞網局在企業環礁的前台（貞網局・派出所）發，見 [SITES](SITES.md) 13.6 節 |
| 甲板 | 登記 | 潛入本身不犯法；未經授權進入子網犯法 |
| 調校 | 登記 | **在契約或雇用條款下強制安裝是合法的** |
| 人偶晶片 | 許可 | 店家要有牌 |
| 感官帶 | 自由 | 未經當事人同意錄製的：違禁，但幾乎沒人查 |
| 黑帶 | 違禁 | |
| 抑制劑、一般藥品 | 自由 | |
| 戰鬥藥、街頭藥 | 違禁 | |
| 假身分 | 違禁 | |
| 契約 | 合法 | 買賣、轉讓、抵押都受公約保護 |

- 值得注意的是**什麼東西是合法的**：把人灌到過載不算傷害罪（沒有身體損傷）；強制調校在契約下合法；契約可以轉賣。這座城市的恐怖之處大多不違法。
- 東西會不會被發現，看藏匿與掃描（[EQUIPMENT](../gear/EQUIPMENT.md) 第 6 節）：藏得好只擋得住眼睛，擋不住掃描器。
- **塔內是公司的法**：企業的建築內適用公司內規，市警無權進入。在緋櫻塔裡被抓，適用的是緋櫻的規矩。

### 3.2 刑罰

城裡沒有監獄——關人要花錢。刑罰依序是：

1. **罰金**。
2. **拘留**（幾天，市警的拘留所）。
3. **義體鎖定**（依判決鎖一段時間）。
4. **刑事契約**：付不出罰金或罪太重的，判決把你的橋權交給出價最高的企業若干年。這就是這座城市的徒刑。

所以「被捕」的戰敗事件（[COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 第 8 節）最壞的結局不是坐牢，是被賣。

### 3.3 誰在執法

各區不同，見 [DISTRICTS](DISTRICTS.md) 第 2 節。一般原則：**法律只在有人付錢執行的地方存在。**

### 3.4 契約：紙上寫什麼

契約的規則（橋權三級、七種指令、抗拒與滿意、九條脫身的路、牆外的兩種契約）在 [LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 7 節，已經逐條確認。這一節寫世界的那一面：一份契約在紙上寫了什麼、城裡最常見的三種契約讀起來是什麼樣子、簽了以後的人怎麼過日子。這裡的條文是世界裡的文字，不另外加規則。

- 街上說「簽契約」，只指交出**管理級**橋權的那一種（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.1 節）。讀取級與限制級的條款寫在雇用合約、貸款與保險裡，大家把那些叫作「合約」，不叫契約（2.4 節）。
- 每一份契約都要在伊甸園的**登記庫**登記才算數（[CORPORATIONS](CORPORATIONS.md) 第 6 節）。登記庫在樂園的地下二層，和外部的網路隔開；掃橋時讀到的「契約人」三個字就是從那裡來的（2.1 節）。不經伊甸園仲介的契約也一樣要登記，登記費 C$300 由持約人付。

**一份契約的樣子**

下面是伊甸園債務契約的標準格式，城裡多數的契約都是照它改的。引號裡是契約上的原文。

| 條 | 名目 | 契約上怎麼寫 |
|---|---|---|
| 一 | 當事人與登記 | 「立約人（橋 ID 後八碼）自願將本人邊緣橋之管理級權限交予持約人，並登記於登記庫。自登記之日起，立約人之身分為契約人。」身分一改，立約人就不再是市民（2.2 節），掃橋的每一個點都看得到 |
| 二 | 期限 | 「本契約至立約人所負債務清償完畢之日終止。債務以登記之日的金額為準，另計月息百分之二。」債務契約寫金額，不寫年數；工作契約與刑事契約寫年數 |
| 三 | 橋權 | 「持約人得讀取立約人之位置與生理數據；得鎖定立約人之義體與功能，並設定禁區與宵禁；得下達指令、安裝調校與晶片，並得轉讓本契約。」這三句依序就是讀取、限制、管理三級的內容，管理級的契約三句都寫 |
| 四 | 指令範圍 | 「持約人得下達之指令如下：差事、改造、侍奉、工作、規矩、回報、出借。」七種指令印成七個打勾的格子。伊甸園的標準版七格全勾；私人契約常把出借或改造劃掉。紙上劃掉的格子，橋不會替契約人擋下來，持約人照樣下得了那一條指令；契約人能做的是拿著這一頁去談判，或者把它爆出去（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.6 節的「找到合約的漏洞」與「爆料」） |
| 五 | 禁止事項 | 「立約人不得遮蓋或移除後頸之可見標記，不得未經許可進入靜默超過八小時，不得另簽其他管理級之契約，不得前往荒地與外海。持約人不得使立約人之身體受到永久之損傷。」持約人要不要把前面幾條設成規矩（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.4 節）是另一回事。最後一句是《自由市公約》唯一要求每份契約都寫進去的條文：公約只保護身體，所以契約也只保證這一件 |
| 六 | 分帳 | 「立約人因持約人指派之工作所得，全數歸持約人。持約人每週撥付其中一成予立約人作為零用，並負擔立約人之住處、醫療與抑制劑。」債務契約另外寫明，所得的九成先拿去抵債。事件裡「收入歸持約人，你拿一成」的那一成就是這一條（[EVENTS](../systems/EVENTS.md) 4.5 節） |
| 七 | 違約金 | 「立約人擅離指定之住處，或使持約人之橋權失效者，應負擔回收之費用，並按剩餘債務之百分之二十加計違約金。」所以逃跑之後又被回收員帶回來的人，欠的債只會更多 |
| 八 | 解約 | 「有下列情形之一者，本契約解除：債務清償完畢；期限屆滿；持約人以書面同意解除。持約人轉讓本契約時，本契約不因轉讓而解除。」贖身的價錢是剩餘的債乘上附件裡的一個倍率。新簽的契約，倍率一年比一年高（[CORPORATIONS](CORPORATIONS.md) 第 6 節） |

[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.6 節的九條脫身的路裡，寫在紙上的只有兩條：「還清」用的是第八條的清償，「被另一個更好的人買走」用的是第八條的轉讓。找漏洞、偽造登記、讓持約人消失、爆料、蜜糖會燒掉橋權、改成另一種主僕關係，以及牆外的路，都發生在紙的外面。陛下的誓約與「您的」替人換的主人都不在登記庫裡（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.7 節），所以貞網局一看到就知道那是牆外來的。

**三種常見的契約**

| | 債務契約 | 工作契約 | 自願的私人契約 |
|---|---|---|---|
| 持約人 | 伊甸園。之後常被轉賣給個人或企業 | 企業、店家或經紀公司 | 一個人 |
| 從哪裡來 | 每週帳單的下坡路走到底（2.4 節、[FIXER](../systems/FIXER.md) 第 4 節）；戰敗之後被賣（[ENEMIES](../systems/ENEMIES.md) 第 6 節） | 換一筆簽約金、一份工作或一個名額。刑事契約（3.2 節）也用這個格式，只是簽名欄上簽的是法官 | 兩個人自己談好的。[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.1 節的「自願簽約」就是這一種 |
| 期限 | 債還清為止。剩下的債多半在 C$10,000～40,000 之間 | 三到五年。期滿離開叫「畢業」（[CULTURE](CULTURE.md) 第 8 節） | 兩個人自己寫，短的一個月，也有人不寫 |
| 指令範圍 | 七格全勾 | 多半只勾差事、工作、規矩與回報，侍奉與出借劃掉 | 看兩個人；常見的是只留侍奉與規矩 |
| 分帳 | 九成抵債，一成當零用 | 薪水照付，每個月扣掉一期簽約金 | 多半不寫，或者寫「生活費由持約人負擔」 |
| 讀起來是什麼樣子 | 條文全是印好的，空白的地方只有名字、金額與日期。封底印著白薇的照片和一句話：「我也簽過這一份，所以我知道它會帶你回家。」 | 前面二十頁是一般的雇用條款，管理級的那一條夾在第十四頁，和調校的強制安裝（3.1 節）寫在同一段裡 | 很多是兩個人手寫的。第八條常常多一句「立約人說出約定的那個詞時，持約人同意解除本契約」。橋不認得那個詞，守不守是持約人自己的事 |

**契約人的日子**

簽約的那一天，診所在契約人的後頸寫上光紋（[CYBERWARE](../gear/CYBERWARE.md) 第 1 節）。讀取級與限制級的橋權只在髮際線下留一兩個淡淡的光點，要湊近才看得到；管理級是一段兩指寬的淡粉色光紋，從髮際線一直延伸到第一節頸椎，頭髮紮起來的時候，地鐵上站在後面的人都看得到。很多契約人因此留長髮、穿高領或戴頸環。刀巷的攤子賣遮瑕貼，也賣光紋貼片（[ITEMS](../gear/ITEMS.md) 7.2 節）改成的假光紋，契約上寫著不准遮，所以遮蓋才會是一門生意（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.1 節）。

持約人不跟在身邊（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.2 節），所以契約人一天裡的大部分時間和別人一樣：上班、吃麵、搭地鐵、跟鄰居打招呼。指令和一般的耳語一樣直接送進腦子裡，差別是它帶著持約人的簽章：後頸的光紋亮一下，那一小塊皮膚熱起來，一行字和期限停在視野的左下角，要等做完或過期才會消失（[EVENTS](../systems/EVENTS.md) 4.5 節）。馴化低的人收到指令時胸口會先緊一下，要過一兩秒才回得了話；馴化高的人感覺到的是肩膀放鬆，因為橋把「照做」接在獎賞迴路舒服的那一邊。很多契約人說，他們最怕的是發現自己開始期待那一下發熱。

回報是每週固定的一天。契約人走到持約人那裡，讓他把一條線接上後頸，持約人看得到這一週去過哪裡、心跳在哪幾個小時跳快過、身上被裝了什麼。伊甸園的契約人在樂園或各分店的櫃台回報，櫃台後面的人多半也是契約人。伊甸園替他們安排宿舍，兩個人一間，醫療與抑制劑按時發，一週休一天，生日那天會收到白薇親手挑的一小束花（[NPCS](NPCS.md) 第 5 節）。

契約人之間有自己的禮節（[CULTURE](CULTURE.md) 11.3 節）：不問對方的持約人是誰，也不問對方還欠多少；問「你今天響了沒」，意思是問對方今天有沒有收到指令；看到別人把頭髮放下來遮住光紋，不會有人伸手去撥開。多數的契約人說，比指令更難習慣的，是知道有一個人隨時看得到自己在哪裡、心跳有多快。

### 3.5 婚姻、伴侶與親密關係

這一節寫這座城市裡的人怎麼談戀愛、怎麼住在一起、怎麼分開。夥伴的關係線（[NPC_SYSTEM](../systems/NPC_SYSTEM.md) 10.3 節）與同居（[DOWNTIME](../systems/DOWNTIME.md) 7.8 節）照這裡的樣子寫台詞與事件。

**婚姻在公約裡是什麼**：《自由市公約》把婚姻當成一份財產的合約，內容是共同的帳戶、共同的租約，以及誰的債算在誰頭上。婚姻登記在市政的子網，不在伊甸園的登記庫，**它完全不碰橋權**：結了婚的兩個人，在法律上看不到對方的位置。旅館坡的銀鐘禮拜堂二十四小時都能結婚，十五分鐘辦完，連登記一共 C$120；櫻町的老住戶在稻荷神社辦，黑泉的人在教會辦。結婚的人比同居的人少很多，蜂巢的情侶多半只是住在一起分攤房租。

**怎麼開始**：在這座城市，身體的快感很容易買到，人偶館、帶子、愛情旅館到處都有，所以兩個人睡過並不代表什麼。情侶之間真正算數的是另外幾步：

| 一步 | 是什麼 | 為什麼算數 |
|---|---|---|
| 一起潛 | 第一次約會常在內海，樂園島的主題館一館只要 C$20 | 便宜，而且兩個人可以換成任何樣子，看對方會選什麼樣子來見自己 |
| 開位置 | 把讀取級的橋權開給對方，讓對方看得到自己在哪裡 | 這是情侶之間最常見的一份橋權。分手的時候，第一件事就是把位置關回來 |
| 一起靜默 | 兩個人在一起的時候，把橋的無線功能全部關掉（第 7 節的靜默） | 多數人身上掛著雇主的讀取級橋權，雇主看得到員工的生理數據（2.4 節）。不關掉，公司的面板就看得到你今晚的心跳。一起靜默的那幾個小時，沒有雇主、沒有持約人、沒有攝影機看得到這兩個人，這是這座城市裡最難得的親密 |
| 不錄 | 錄影義體關掉，臉上的濾鏡也關掉 | 讓對方看到自己沒有修過的臉，也保證這一晚不會出現在帶子街上 |

**住在一起**：蜂巢一個單位週租 C$150（1.2 節），兩個人分攤剛好過得去，所以交往幾個月就同居的人很多。房東掃兩個人的橋，把兩個名字都寫進租約。四十二番街的從業者之間有一條默契：住在一起的人不過問對方上班時做了什麼，下班以後的時間才是兩個人的。

**分手**：先把位置關回來，再拆共同的帳戶，最麻煩的是帶子。兩個人一起錄過的帶子，分手以後被拿到帶子街去賣，是城裡最常見的報復；未經當事人同意錄的帶子違禁，但幾乎沒有人查（3.1 節），所以小心的人從一開始就不錄。如果其中一方把橋權交給了對方，分手不會讓那份契約消失，只有持約人能解約（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.5 節）。私人契約最常見的壞結局就是這樣來的。

**「只屬於彼此」為什麼少見**：在這座城市，很多人的身體本來就有一部分不屬於自己。人偶、演員與歡場的從業者每天接觸不同的人；契約人的持約人可以下指令，也可以把他出借給別人；上班族的心跳被雇主看著；就算只是在家看帶子，一個人每天晚上都可能感覺過別人的身體。所以多數人把身體和感情分成兩本帳，吃醋的對象多半是時間與注意力，很少是一場性事。答應對方「只屬於彼此」的情侶也有，但街上的人會覺得那是老派、有錢或者櫻町的偶像劇看太多。所以兩個人真的這樣約定的時候，身邊的朋友會把它當成和結婚一樣重的事。

**對戒和橋權是兩種不同的承諾**

| | 對戒 | 把橋權交給對方 |
|---|---|---|
| 是什麼 | 一對素圈，內側刻著兩個人橋 ID 的前四碼（[ITEMS](../gear/ITEMS.md) 7.2 節），玻璃岸的工坊做，一對 C$510 | 一份自願的私人契約：把管理級的橋權交給伴侶（3.4 節） |
| 法律上 | 什麼都不是 | 對方成為持約人，自己成為契約人。身分、掃橋的結果與後頸的光紋都跟著變 |
| 告訴別人什麼 | 「這兩個人是一對」。街上的人、NPC 與 AI 敘事都讀得到這件事 | 一般的掃橋讀得到你是契約人，伊甸園的掃描器還讀得到你的持約人是誰（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.1 節） |
| 收得回來嗎 | 拔下來就好 | 只有持約人能解約；分手不會讓契約消失 |
| 誰會這樣做 | 多數的情侶。戴對戒是城裡最普通的告白 | 少數人。多半是主僕關係已經走到情趣、激烈或戀人的兩個人（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.3 節），或者寧可讓愛人拿著自己的橋權、也不要哪天被伊甸園買走的人 |

蜜糖會的姐妹會勸人不要把橋權交給愛人，她們的理由是人會變，而契約不會跟著變。伊甸園對這種契約什麼都不說，因為私人契約和別的契約一樣可以轉賣。牆外的「您的」給人的是另一個版本（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 7.7 節）：自己選一個主人，伊甸園追不回來，選了也不能反悔。

**夥伴說這些事時的口氣**（給台詞與 AI 敘事的例子，照 [NPCS](NPCS.md) 1.3 節的規則）：

- 「我們先去玻璃岸訂一對戒指，其他的事情以後再慢慢說。」
- 「今晚把橋關掉吧，我不想讓公司的人在面板上看到我的心跳。」
- 「我可以把位置開給你，可是管理級的橋權我不會交給任何人，我也不要你交給我。」
- 「如果有一天我把橋權交給你，那會是我自己想清楚以後做的決定。」
- 「你在店裡做什麼是你的工作，我知道，我只想要你下班以後的時間。」

## 4. 貨：等級與狀態

取代 ElondiaRPG 的稀有度與附魔。**義體、武器、護甲都由設計圖與零件組裝而成**，設計圖與零件各分 I～V 級；完整的規則在 [CRAFTING](../gear/CRAFTING.md)。這裡只留世界觀上的說法。

| 等級 | 街上的叫法 | 合法性 | 哪裡來 |
|---|---|---|---|
| I | 入門 | 自由 | 正規商店 |
| II | 標準 | 自由或登記 | 正規商店 |
| III | 專業、制式 | 許可 | 原廠；黑市；從保全身上 |
| IV | 軍規 | 違禁 | 黑市；委託的戰利品 |
| V | 原型 | 不在市面上 | 特殊任務。每一件都有名字，全城都有人在找它 |

等級之外，每件東西有一個**狀態**：

| 狀態 | 是什麼 | 特性 |
|---|---|---|
| 全新 | 照規格出廠 | 會被登記 |
| 二手 | 街貨、拼裝、來路不明 | 便宜；有**瑕疵**的機率；義體有殘響；不在任何登記上 |
| 同人 | 社團自製或魔改 | 一個隨機的**怪癖**（好壞都有）；沒有保固；可能有後門 |
| 活的 | 生體件：培養出來的組織 | 會長、會病、掃描不到、不能二手（[CRAFTING](../gear/CRAFTING.md) 第 8 節） |
| 牆外 | 流竄 AI 給的 | 不照規則。好得不像真的。有代價（[NETRUNNING](../systems/NETRUNNING.md) 第 7 節） |

- **附魔的替代品是零件**：瞄具、塗裝、槍靈、韌體、插板，都是裝在設計圖選配槽裡的零件，可以拆換。
- **授權鎖**（[CYBERWARE](../gear/CYBERWARE.md) 第 5 節）讓「從敵人身上撿到好東西」多一步：III 級以上的東西撿到不等於能用。這是改造師與潛網者在戰後的工作。
- 等級不是線性的好壞。同人貨的怪癖、二手貨的不被登記、軍規的追蹤器，都讓「該用哪一把」是個要想的問題。

## 5. 貨：牌子

同一種東西，不同牌子有不同的**脾氣**。牌子是設計圖與零件的屬性；原廠全套有套裝加成，混搭沒有（[CRAFTING](../gear/CRAFTING.md) 第 6 節）。下面寫的脾氣，落實在各牌零件的屬性上——例如「星旗的槍不能被駭」，是因為星旗不出晶片與軟體，全套星旗的槍裡沒有電子零件。這讓物品目錄不必靠數值堆疊來做出差異。

### 5.1 武器

| 牌子 | 脾氣 | 特性 |
|---|---|---|
| **星旗** | 便宜、粗、不會壞 | 不卡彈、不用保養；沒有任何電子零件，**不能被駭**；準度普通 |
| **崑崙** | 聰明、多話 | 有槍靈：命中 +、自動管彈、會提醒；**可以被駭**（鎖槍、偏移）；資料回傳崑崙 |
| **緋櫻** | 精密、嬌貴 | 要害率高；穿甲好；貴；每場戰鬥後要保養，不然性能下降；制式以上有授權鎖 |
| **織女** | 不是給人拿的 | 無人機、自動砲塔、遙控武器。潛網者與機師的武器 |
| **胭脂堂的師傅** | 手工、老派 | 刀劍為主。沒有電子零件；可以傳家；訂製要等、要有交情 |
| **鉻娘子改** | 過頭 | 傷害高得不合理；後座力要義肢才壓得住；偶爾炸膛 |

緋櫻也做刀——**緋櫻刀工**的單分子刃是城裡近戰武器的頂點，家政課的制式裝備。

牌子同時是設計圖與零件的屬性。同一個牌子有 I～V 五個等級；原廠全套有套裝加成，混搭沒有（[CRAFTING](../gear/CRAFTING.md) 第 6 節）。

### 5.5 吃的與開的

- **吃**：甜心的**糰糧**（口味很多，都是同一種東西）是窮人的三餐；桃子屋的便當是中間；**真的食物**是奢侈品，也是送禮與收買的好東西。糰糧裡有情緒調節劑（[CORPORATIONS](CORPORATIONS.md) 第 5 節）——長期只吃糰糧的角色，定力略高、衝動略低。
- **開**：星旗的皮卡（耐撞、能載貨）、織女的浮空車（快、貴、有紀錄）、緋櫻的重機（特攻姬的最愛）、車族的改裝車（荒地用）。全部燒蜜醇。

## 7. 通訊與消息

**耳語**：橋內通訊。不用開口、不用手，想著就能傳。這是城裡的電話。有橋的人都有一個耳語號。

- 耳語會被攔截、被定位（敵對值高時，開著耳語等於亮著燈）。
- **拋棄號**：一次性的耳語號，同人夜市一把一把賣。中間人與邊緣行者的標準做法。
- **板子**：手持終端。沒有橋的人、不想讓橋連網的人用。慢，但安全。
- **靜默**：關掉橋的所有無線功能。不能耳語、不能快駭、不能被快駭、不能被定位。滲透時的一個選擇。

**消息怎麼流**。下面這條線是情報、傳聞與媒體玩法（[MEDIA](../systems/MEDIA.md)）的背景：

```
發生的事 → 街上的耳語（幾小時）→ 牆報（一天）→ 帶子街（兩三天）→ 萬華鏡（如果它想報）
```

消息會經過九個地方，它們就是輿論戰的九個格子（[OPINION](../systems/OPINION.md)）：上排是圈子，中排是主流，下排是街頭。

| 排 | 格子 | 是什麼 | 特性 |
|---|---|---|---|
| 圈子 | **同人圈** | 同人眾與各社團之間的圈子 | 傳得不遠；圈內的人很相信圈內的話 |
| 圈子 | **帶子街** | 有人把事情錄成帶子拿來賣 | 可以「親身」確認；要錢 |
| 圈子 | **應援圈** | 親衛隊與偶像粉絲的圈子 | 人多而且齊心；只在意和自己的推有關的事 |
| 主流 | **緋櫻映畫**（新聞部） | 標榜查證的新聞 | 慢、可信、不報緋櫻的事 |
| 主流 | **萬華鏡** | 全城的螢幕，在九格的正中央 | 它報了才算「大家都知道」 |
| 主流 | **夜鶯直播** | 夜鶯的虛擬主播與直播 | 每一塊螢幕都收得到；說話的是 SKIN，中之人不露面 |
| 街頭 | **牆報** | 每個區的匿名留言板，掛在公共子網上 | 徵人、尋人、懸賞、謠言。一般委託的來源之一 |
| 街頭 | **街上的耳語** | 口耳相傳 | 最快；只在一兩個區內；會走樣 |
| 街頭 | **地下轉播站** | 牆語者與車族的廣播 | 不被審；聽眾少 |

玩家可以在任何一段介入：在牆報上放假消息、買下帶子不讓它流出去、把事情直接送上萬華鏡。

## 8. 時間

### 8.1 一週

| 日 | 發生什麼 |
|---|---|
| 週一 | **收租日**。每週帳單結算（[FIXER](../systems/FIXER.md) 第 4 節）。收租無人機出動，討債的人上門 |
| 週三 | 牆報更新最多的一天；中間人放新委託 |
| 週五 | 企業發薪。四十二番街最熱鬧的晚上；冠冕區的人下來玩 |
| 週四 | 野薔薇的補給車隊跑完一趟回到薔薇驛（區域狀態「車隊回來」，到週五早上）：宿營地開營火，交易棚多一批荒地的貨 |
| 週六 | **同人夜市**（高架橋下） |
| 週日 | 偶像的公演日。櫻町人最多；親衛隊最容易打起來 |

每個區的商店、人、街頭事件表依星期幾有小變化。

### 8.2 城市的大事：不照月份

**沒有年曆。** 祭典、公演、年會這些大事不綁在固定的月份上，因為照日期發生的事太容易錯過。它們改成由**事件與特殊任務觸發**：條件到了才發生，發生之前會先預告，發生之後持續幾天，並在那幾天改變區域的狀態。

| 大事 | 怎麼觸發 | 影響 |
|---|---|---|
| 新年參拜 | 特攻姬或櫻町的任務線走到某一步 | 稻荷神社擠滿人；特攻姬維持秩序；各幫派休戰三天（多半） |
| **緋夜祭** | 同人眾的好感夠高，或社團的任務線走到出攤那一步 | 舊港貨櫃場開三天。全城的社團、獵頭和臥底都在 |
| 理事會年會 | 任何一條企業的任務線走到要攤牌的時候 | 冠冕區戒嚴一週；各企業的髒活集中在會前 |
| 櫻祭與**戰姬大公演** | 偶像線的進度 | 櫻町最大的活動；偶像線的高潮 |
| 契約季 | 和契約有關的任務線（伊甸園、蜜糖會、夢露）的進度，或玩家自己簽了契約 | 企業的合約到期與續約；挖角與逃亡的委託變多 |
| 淹水 | 地下層的事件；也可以由玩家的行動造成 | 地下層淺層淹水，一部分通道封閉，另一部分只有這時候才出現 |
| 夏祭 | 祭典組的好感，或祭典組自己的事件 | 祭典組最活躍，隨時可能封街 |
| 停戰紀念日 | 和 2046 年那場爆炸有關的任務線（喬、陸伯、星旗）的進度 | 緋櫻與星旗各辦各的；孤星連上街；彈坑灣有人獻花 |
| 假面夜 | 夜宴社或萬華鏡的任務線 | 全城戴面具，偽裝最容易的一晚；吉祥物也最容易混在人群裡 |
| **串珠夜** | 孤星連的好感夠高、勞軍團巡演的最後一場，或停戰紀念日之後的事件 | 蜂巢東側到東門封街兩天。孤星連的皮卡與野薔薇的卡車當花車遊行，車上的人把塑膠珠串丟給路邊的人，路邊的人掀一下上衣就換得到一串；那兩天東側的曝露度容忍 +1。緋夜祭是同人眾的祭典，串珠夜是退伍兵與車族的 |
| 海岸小姐 | 玻璃岸的事件、萬華鏡或 Contour 的任務線，或你或一位夥伴報名 | 遊艇碼頭一週：遊艇俱樂部辦「海岸小姐」選美與 Contour 健美比基尼賽，每晚都有遊艇派對；玻璃岸的盤查放鬆一點 |
| 畢業季 | 偶像線或緋櫻的任務線的進度 | 偶像的畢業公演；奉公課很忙 |
| 沙暴 | 鏽帶與野薔薇的事件 | 鏽帶與荒地的能見度降低；外環公路時常封閉 |

- 一週的節奏（8.1 節）照舊，那是每週都會回來的，不會錯過。

## 9. 行規

邊緣行者沒有公會，但有規矩。這些規矩是**委託系統的預設值**——遵守它們是常態，打破它們有具體的後果（街頭信譽）。

| 規矩 | 意思 | 系統上 |
|---|---|---|
| **先付三成** | 接下委託時雇主預付三成，不退 | 談判的預設值；可以談高或談低 |
| **不問是誰** | 不問雇主的身分，雇主也不問你的 | 查雇主是踩點的選項，不是禮貌 |
| **接了就做完** | 接了委託中途放棄，比做砸更糟 | 放棄 −5，失敗 −3（CORE_RULES 8.1 節） |
| **不動中間人** | 中間人是中立的。動了一個，所有的都不再接你的電話 | 城裡的 NPC 不能被攻擊，所以這條管的是出賣或背刺中間人：做了之後全體中間人好感歸零 |
| **東西歸帶頭的分** | 戰利品一律交給帶隊的人（玩家）分配 | 所有戰利品直接進玩家的背包，由玩家決定給誰；沒有分帳的規則 |
| **翻了的人不補槍** | 過載倒地的人不殺。帶走、綁起來、丟在路邊都行 | 殺過載的敵人：額外的敵對值與沉溺上升 |
| **不拆活人** | 倒下的人身上的義體不拆。被打倒、失去意識的敵人也是活人；從停屍間、冷庫或殘骸拆下來的另當別論 | 拆活人每拆一個人，沉溺 +1、那個人所屬勢力的敵對值 +5（[ENEMIES](../systems/ENEMIES.md) 第 7 節）。拆死人沒有這條代價 |
| **帶子不外流** | 行動時錄的東西，未經全隊同意不發 | 主播的取捨（[MEDIA](../systems/MEDIA.md)）：擅自發布扣夥伴忠誠 |
| **欠的要還** | 人情是真的債 | [FIXER](../systems/FIXER.md) 第 8 節 |

- 企業與部分幫派（鉻娘子、拆體客、吉祥物）不守這些規矩。這是他們被當成「外人」的原因。拆體客靠拆活人過日子，所以「不拆活人」這一條讓他們在街上抬不起頭；玩家拆活人時照樣付上面的代價，不因為對方是誰而免除。
- 胭脂堂另有自己更老的一套（[GANGS](GANGS.md) 第 2 節）。
- 開場時由阿蓮（[NPCS](NPCS.md) 第 2 節）一條一條教給玩家——這是新手教學的形式。
