# 企業

> 上層：[WORLD](WORLD.md)。依賴：[WORLD](WORLD.md)（歷史、用語）。被依賴：[GANGS](GANGS.md)、[CULTURE](CULTURE.md)、[DISTRICTS](DISTRICTS.md)、[ENEMIES](../systems/ENEMIES.md)、[STORY_QUESTS](STORY_QUESTS.md)。
> 這份是世界觀文件，沒有規則數值。每家企業的「玩法」一欄只寫它會帶來哪一類委託與敵人，細節等 [ENEMIES](../systems/ENEMIES.md) 與 [STORY_QUESTS](STORY_QUESTS.md)。

賽博龐克題材裡該有的企業位置，這裡每個都有一家：軍工財閥、傭兵承包商、新興軍火、武裝急救、生技、硬體、網路警察、媒體、食品、能源。但每一家都是從這條世界線自己的歷史長出來的——**橋是從快感迴路突破的，而打贏最後一場戰爭的是日本財閥**。這兩件事決定了它們的樣子。

## 1. 權力結構

緋夜城由**企業理事會**共管，七席：緋櫻佔兩席，星旗、蜜腺、萬華鏡、夜鶯、伊甸園各一席。其他企業在城裡做生意，但沒有投票權。

### 1.1 兩個級別

| 級別 | 是什麼 | 哪幾家 |
|---|---|---|
| **主要勢力** | 有中間人、專屬的委託線、完整的敵人線；城裡的大事繞不開它 | 緋櫻、星旗、崑崙、蜜腺、夜鶯、萬華鏡、伊甸園、黑泉（八家） |
| **次要勢力** | 內容較少，活在某個主要勢力的影子裡（主從）；甜心食品例外，誰也不靠 | 天使急救（隨蜜腺）、織女（隨崑崙）、貞網局（隨夜鶯）、甜心食品（獨立） |


### 1.2 每一家有自己的文化分支

**每一家企業都有自己的好感與熱度，不合併**——主要或次要都一樣（[CORE_RULES](../systems/CORE_RULES.md) 第 8 節）。主從只是世界裡的關係：誰靠誰、惹了誰會驚動誰，寫在勢力關係表裡，不是數值的合併。

緋櫻把「侍奉」做成了一種生活方式。其他企業也一樣：**每一家企業，都有一種它賣的、它的人活在裡面的性癖與美學。** 那是它的品牌、它的制服、它的調校、它的廣告——也是它在牆外的那個原型（[NPCS](NPCS.md) 第 8 節）。

| 企業 | 文化分支 | 看起來 | 牆外的原型 |
|---|---|---|---|
| 緋櫻重工 | 侍奉 | 女僕、執事、和服 | 女僕長（另有您的） |
| 星旗防務 | 畫報女郎 | 金髮、豐滿、啦啦隊、牛仔、軍裝 | Miss 七月 |
| 崑崙智造 | 仙子 | 仙俠、漢服、旗袍、清冷 | 小仙 |
| 天使急救 | 護士 | 白衣、照護、檢查 | 下一位 |
| 蜜腺生技 | 流動 | 賀爾蒙與性別改造、男娘、TS | 都可以 |
| 織女電子 | 人偶 | 機娘、球形關節、型號 | 零七 |
| 甜心食品 | 餵養 | 甜食、粉紅、吉祥物、被照顧得好好的 | 再一口 |
| 夜鶯系統 | 聲音 | 耳語、聲優、蒙眼、匿名 | 噓 |
| 貞網局 | 戒律 | 制服、紀律、禁慾與許可 | 鎖匠 |
| 萬華鏡 | 扮演 | 角色扮演、人設、變裝 | Ａ子（另有本台、@all_eyes） |
| 黑泉能源 | 背德 | 端莊、保守、禮拜服 | 神父不在 |
| 伊甸園 | 佔有 | 契約、項圈、所有權 | 陛下 |

- 文化分支決定：那家企業的人怎麼穿、它的場所是什麼氣氛、它賣的調校與義體偏哪一邊、和它的人發生成人場景時傾向往哪邊走（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 1.1 節）。
- 穿對應風格的服裝，在那家企業的地盤上社交有加值（[EQUIPMENT](../gear/EQUIPMENT.md) 的風格標籤）。
- 所有角色都是成年人；每一種分支都可以在內容篩選裡單獨關掉。
- 之後可以再加不算勢力的背景招牌（飲料、成衣、連鎖旅館），那些不追蹤數值。
- 幫派的文化分支見 [GANGS](GANGS.md) 1.2 節。日系宅文化目前集中在緋櫻與櫻町的街頭；等分支都補齊，再看比重要不要調。

### 1.3 對立

三條主要的對立：

| 對立 | 是什麼 |
|---|---|
| **緋櫻 對 星旗** | 蕾絲戰爭的兩造。名義上停戰，實際上是冷戰。城裡一半的髒活是這兩家互相下的單。 |
| **萬華鏡 對 緋櫻映畫** | 平台對內容。萬華鏡擁有觀眾的眼睛，緋櫻擁有觀眾想看的人。 |
| **黑泉 對 所有人** | 唯一公開反對「橋文化」的企業。它的錢和所有人一樣髒。 |

## 2. 軍工與保全

### 緋櫻重工（Hizakura）

**級別**：主要勢力。**文化分支**：**侍奉**——女僕、執事、和服、奉公。服侍是榮譽，被服侍是身分。牆外的原型是「女僕長」（更廣的服從是「您的」）。

**本業**：企業保全、銀行、重兵器、機甲。城裡最大的雇主，也是最大的債主。

**來歷**：大阪起家的家族財閥，戰前做精密機械。它在橋的時代押對了一件事：別人把橋當成娛樂產品，緋櫻把它當成**忠誠的載體**。它是第一家把「調校」寫進雇用契約的企業。蕾絲戰爭打到最後，星旗的本土補給線先斷，緋櫻沒有贏，但它是站著離開的那一個——而且它的銀行出錢重建了緋夜城。這座城市從地基到路燈都欠它錢。

**家風**：歷代家主稱「御前」，目前是第四代。企業文化的核心是**奉公**：公司是家，員工是家臣，服侍是榮譽。這不是口號，是寫在橋裡的（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 4 節的「忠犬」調校）。

**它為什麼讓宅文化成為主流**：重建期間，緋櫻發現賣動畫、偶像與吉祥物，比派保全更便宜地讓一座外國城市習慣它的存在。它的映像部門把日本的御宅文化包裝成一整套生活方式輸出。二十多年後，緋夜城的小孩是看緋櫻的動畫長大的大人。細節見 [CULTURE](CULTURE.md)。

**部門**：

| 部門 | 做什麼 |
|---|---|
| 警備局 | 制服保全。城裡最常見的企業敵人。標準配備是粉蕾絲與感官彈 |
| **家政課** | 要人警護與「特殊清掃」。成員穿女僕與執事的制服，是緋櫻最精銳的近身戰力。「請問需要打掃嗎」是城裡最不想聽到的一句話 |
| **戰姬事業部** | 機甲部隊，同時是偶像團體。機師的戰鬥會被剪成帶子販售（見 [CULTURE](CULTURE.md) 第 4 節） |
| 緋櫻銀行 | 重建債、房貸、義體貸款。帳面上擁有半個蜂巢 |
| 緋櫻映畫 | 動畫、偶像、遊戲、周邊。文化輸出的引擎 |
| 奉公課 | 人事。負責忠誠調校的安裝與「卸載」（離職） |

**怎麼拴住你**：終身雇用。進來的時候裝調校，出去的時候拆——拆的過程會帶走一部分記憶。

**玩法**：最完整的企業敵人線（警備局 → 家政課 → 機甲）；挖角案的主要目標；家政課的叛逃者是名冊上的頂級人選。

### 星旗防務（Starbelle Defense）

**級別**：主要勢力。**文化分支**：**畫報女郎**——金髮、豐滿、曬過的皮膚、啦啦隊、牛仔帽、軍裝。「健康、陽光、大方」既是它的徵兵海報，也是它的審美；機鼻上畫的女郎是真人照著改造出來的。牆外的原型是「Miss 七月」。

**本業**：槍、彈藥、裝甲車、傭兵。美國殘存政府的軍火庫兼外包軍隊。

**來歷**：美國聯邦崩解時，國防部最大的承包商接手了它付不出薪水的軍隊。星旗的東西便宜、粗、耐操、到處都有——緋夜城街上十把槍有六把是它的。

**風格**：緋櫻賣的是「萌」，星旗賣的是**畫報女郎**：機鼻彩繪、孤星連、口紅和香菸。它的徵兵廣告上是叼著雪茄的女機師。它嘲笑緋櫻的機師是「會唱歌的洋娃娃」，緋櫻則說星旗的機甲是「有腿的拖拉機」。兩邊說的都對：星旗的機甲同步率低、反應慢，但機師不容易過載，而且修得起。

**怎麼拴住你**：軍事契約與退伍福利。義體是軍方的財產，退伍時要歸還，或者用下一份合約抵。

**玩法**：重火力敵人、載具與機甲殘骸的來源；退伍兵是槍手與機師的主要出身；它在鏽帶的基地是後期地圖。

### 崑崙智造（Kunlun）

**級別**：主要勢力（沒有理事會席次，但在街上有胭脂堂這條老關係）。**文化分支**：**仙子**——仙俠、漢服與旗袍、清冷、可望不可即。它的槍靈一律是「劍靈」人設；公司裡升職叫「破境」，主管稱「師姐」「長老」。賣的是高嶺之花，以及把高嶺之花摘下來的念頭。牆外的原型是「小仙」。

**本業**：智慧武器。新興、便宜、更新快。

**賣點**：每一把崑崙的槍裡都有一個**槍靈**——一個小型的陪伴 AI，接在使用者的橋上，負責輔助瞄準、管理彈藥、提醒保養，以及跟你說話。槍靈有人格（可以選、可以課金換），用久了會記得你的習慣。這本來是為了和緋櫻、星旗做出差異的行銷手法，結果成了主力：很多人買崑崙的槍是為了槍靈。

**問題**：槍靈的資料會回傳。崑崙知道它賣出去的每一把槍在哪裡、對誰開過火。

**怎麼拴住你**：訂閱。槍靈的進階功能、新人格、彈道更新都要月費。停止付費的槍還是能開，但槍靈會變得很沉默——有人形容像是被冷戰。

**玩法**：智慧武器（可以被駭，也可以駭別人的）；槍靈是一個會說話的裝備，可以有關係線；崑崙的資料中心是竄網案的目標。

## 3. 醫療與生技

### 天使急救（Angel Team）

**級別**：次要勢力，依附**蜜腺**（藥與醫材全靠蜜腺供應，蜜腺也是它最大的股東）。**文化分支**：**護士**——白衣、照護、檢查與被檢查、把自己交出去。它的制服是全城被模仿最多的一套。牆外的原型是「下一位」。

**本業**：訂閱制的武裝急救。

**樣子**：白色的浮空車，車身有翅膀的標誌。下來的人穿強化護理服、拿衝鋒槍。她們不交涉、不繞路、不問是誰開的槍，只把會員帶走。擋路的人不在保單範圍內。

**分級**：

| 方案 | 內容 |
|---|---|
| 白銀 | 十分鐘內到場；只送到診所門口 |
| 黃金 | 五分鐘；含手術 |
| 白金 | 三分鐘；含手術、復健，以及「回收」——即使你已經死了，也會把橋帶回來 |

**怎麼拴住你**：會費，以及每次出勤後的帳單。天使急救從不拒絕付不起的人——它把債賣給伊甸園。

**玩法**：戰敗的保險（[COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 第 8 節）；敵人有會員資格時，打倒他就開始倒數；離職的隊員是改造師路數的頂級出身。

### 蜜腺生技（Nectar）

**級別**：主要勢力。**文化分支**：**流動**——賀爾蒙與性別的改造、男娘、TS。在蜜腺的型錄裡，身體是一份可以重新調配的配方，性別是其中一欄；它旗下的診所讓「換一個身體過一陣子」變成和換髮色差不多的事。牆外的原型是「都可以」。

**本業**：藥、基因工程、合成燃料，以及橋的原始專利。

**來歷**：地中海沿岸的老藥廠，1998 年做出邊緣橋。專利讓它從每一座橋抽成。它另外發明了**蜜醇**——一種從改造作物發酵出來的燃料，現在所有的車都燒這個。

**兩張臉**：對外是穿白袍的溫和科學家，贊助醫院與公園。對內，它需要大量的人體數據來研發下一代的橋與抑制劑，而緋夜城有很多沒人會找的人。

**生體改造**：蜜腺是「生體派」的源頭——不裝機器，改基因與組織。生體件是零件的另一種材質，和機械件裝在同樣的槽裡（[CRAFTING](../gear/CRAFTING.md) 第 8 節）。真的會動的獸耳、真的毛皮、真的尾巴，都是它的技術（見 [CULTURE](CULTURE.md) 第 2 節）。生體改造的沉溺成本低，但貴、慢、而且不能退貨。

**怎麼拴住你**：抑制劑（[CYBERWARE](../gear/CYBERWARE.md) 第 2 節）。

**玩法**：人體實驗的揭弊案；實驗體逃亡的救援案；生體改造的來源；主線中「橋的真相」那一條。

## 4. 科技、網路與媒體

### 織女電子（Orihime）

**級別**：次要勢力，依附**崑崙**（崑崙是它最大的股東與客戶：槍靈的晶片、劍靈人設的機娘外殼都由織女代工；牌子還是日本名字，錢是崑崙的）。**文化分支**：**人偶**——機娘、球形關節、無機質的皮膚、型號與序號。把機器做得像人，也把人做得像機器；「人偶化」的義體風格從它的展示間流行起來。牆外的原型是「零七」。

**本業**：甲板、無人機、浮空車、基礎義體的韌體，以及**機娘**——家用與服務用的人形機器人。

**樣子**：城裡的便利店店員、櫃檯、清潔工，三成是織女的機娘。它們不是人，沒有橋，不會過載，法律上是家電。它們長得越來越像人，是因為消費者要它們長得像人。

**玩法**：無人機與機器敵人（神經武器無效，要用實彈或電磁）；駭入機娘當眼線；「這台機娘好像有自我意識」是一條任務線。

### 夜鶯系統（Nightingale）

**級別**：主要勢力。**文化分支**：**聲音**——耳語、聲優、蒙上眼只剩下聽覺、不露臉的匿名。夜鶯的人不出現在鏡頭前，城裡卻每個人都聽過她們的聲音：系統語音、客服、子網的播報。牆外的原型是「噓」。

**本業**：網路基礎建設。牆內所有的子網都跑在它的機房上；蕾絲是它的產品。

**怎麼拴住你**：你上網，就是在它的房子裡。

**玩法**：竄網線的主要對手；它的核心機房是牆內最深的子網。

### 貞網局（NetVigil）

**級別**：次要勢力，依附**夜鶯**（牆與蕾絲由夜鶯維運，局裡一半的探員是夜鶯借調的）。**文化分支**：**戒律**——制服、紀律、禁慾與許可。「未經許可不得」是它的標語，也是它的癖好；探員的橋上有局裡發的鎖。牆外的原型是「鎖匠」。

不是營利企業，是各國殘存政府與企業共同出資的網路警察，預算的大頭來自夜鶯。職責是守粉牆、獵捕越牆者與牆外來的東西。可以不經審判燒掉一個人的橋。

探員多半裝了「冰后」調校（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 4 節）——他們是這座城市裡最不容易被誘惑的人，也因此是最孤獨的。

**玩法**：見 [NETRUNNING](../systems/NETRUNNING.md) 第 7 節。

### 萬華鏡（Kaleido）

**級別**：主要勢力。**文化分支**：**扮演**——角色扮演、人設、濾鏡、變裝。在萬華鏡的平台上每個人都在演某個人，演久了分不清哪個是本來的。牆外的原型是「Ａ子」；「本台」與「@all_eyes」也是它前身公司的產品。

**本業**：感官帶平台、新聞、廣告。城裡每一塊螢幕都是它的。

**對手**：**緋櫻映畫**（緋櫻重工的內容部門）。平台對內容：萬華鏡擁有觀眾的眼睛，緋櫻映畫擁有觀眾想看的人，還有一個標榜「只播查證過的」的新聞部。兩家互相揭對方的短，默契是有些事誰都不報。

**怎麼拴住你**：演算法。它不禁止任何內容，它只決定沒人看得到什麼。

**玩法**：見 [MEDIA](../systems/MEDIA.md) 第 8 節。

## 5. 民生與能源

### 甜心食品（Sweetheart Brands）

**級別**：次要勢力，不依附任何人——每一家都要吃飯。**文化分支**：**餵養**——甜食、粉紅色、吉祥物、「乖，再吃一口」。被餵、被照顧得好好的、什麼都不用想，是它賣的感覺；糖霜、鮮奶油與圍兜是它的美學。親切是真的，只是沒有人在裡面。牆外的原型是「再一口」。

**本業**：糧食。城裡八成的人吃的是它的合成口糧**糰糧**，在它的連鎖超商**桃子屋**買的。

**樣子**：粉紅色的招牌，一隻桃子吉祥物，二十四小時營業，每個街角都有。店員永遠在笑，廣播永遠是同一首兒歌一樣的曲子。它是這座城市最親切、最人畜無害的臉。

**底下**：笑容是排班表的一欄。桃子屋的每一句問候都有 A/B 測試過的版本；店員的笑由橋上的考核程式計分，低於標準就扣薪。它的客服信永遠以「我們很遺憾」開頭，然後一個字都不讓。它不恨任何人，也不在乎任何人——你是一個購買頻率。它是最不能倒的一家，所以任何競爭者都會安靜地消失，連新聞都沒有。

**添加物**：糰糧裡有微量的情緒調節劑。合法，標示在成分表第十四行。吃糰糧長大的人比較不容易暴動。

**玩法**：桃子屋是全城通用的補給點與街頭事件場所；食品走私（真的食物是奢侈品）；配方的揭弊案。

### 黑泉能源（Blackspring）

**級別**：主要勢力。**文化分支**：**背德**——端莊、保守、長裙與禮拜服。它公開反橋、反放縱；也因此，它的人是城裡壓得最緊、最渴的一群。禁忌是它賣得最好的東西，只是不寫在型錄上。牆外的原型是「神父不在」。

**本業**：蜜醇的量產與經銷、燃料作物的農地、私人軍隊。蜜腺發明蜜醇，黑泉種它、賣它。

**立場**：德州起家的老錢。董事會公開厭惡「橋文化」，贊助反改造的教會與政客，廣告主打「乾淨的土地、乾淨的身體」。它的高層也真的大多不裝橋——他們不需要，有人替他們裝。

**虛偽**：黑泉的農場用的是契約工，鏽帶外圍的私人俱樂部是它的。城裡最賺錢的幾間人偶館，房東是黑泉的子公司。

**玩法**：鏽帶與荒地的主要勢力；素體教的金主（[GANGS](GANGS.md)）；「沒有橋的敵人」——神經武器打不動的重裝私兵。

## 6. 歡場與人力

### 伊甸園（Eden）

**級別**：主要勢力。**文化分支**：**佔有**——契約、項圈、所有權證明。人可以被擁有，而且有價目表。牆外的原型是「陛下」。

**本業**：連鎖歡場、人偶館、人力派遣、債權收購。

**來歷**：這條世界線獨有的企業。別的企業把人當員工或消費者，伊甸園把人當**資產**：它不生產任何東西，它擁有人的時間。全城的壞帳最後都流到它手上，還不起的人簽契約，把橋權抵給它，再被派到需要人的地方——包括其他企業。

**樣子**：乾淨、明亮、合法。門口有花。契約人的待遇寫得清清楚楚，有休假、有醫療、有申訴管道。很多人是自願進去的，因為外面更糟。這是它最可怕的地方。

**怎麼拴住你**：橋權（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 7 節）。

**玩法**：每週帳單那條下坡路的終點（[FIXER](../systems/FIXER.md) 第 4 節）；蜜糖會的死對頭；契約線的主要對手。
