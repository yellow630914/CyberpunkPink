# 固定 NPC

> 上層：[WORLD](WORLD.md)。依賴：[DISTRICTS](DISTRICTS.md)（在哪裡）、[CORPORATIONS](CORPORATIONS.md)、[GANGS](GANGS.md)、[CULTURE](CULTURE.md)（屬性）、[CORE_RULES](../systems/CORE_RULES.md)（路數）。被依賴：之後的 `NPC_SYSTEM`（生成 NPC、互動規則）、`STORY_QUESTS`、世界書。
> 這份是人物設定，不是規則。實作時每個人是 `data/world/npcs.json` 的一筆，外貌與性格交給 AI 當描寫依據。
> **所有人物都是成年人**，括號裡是年齡。

五十三個有名字的人：八位中間人、蜂巢的鄰居、九位可以同行的夥伴、各企業與幫派的臉。另外有二十六個不是人的：牆外的流竄 AI（第 8 節）。

## 1. 寫法

每個人至少有四樣東西，少一樣就只是佈景：

| 欄位 | 是什麼 |
|---|---|
| **想要** | 他現在在追的東西。委託與對話從這裡長出來 |
| **怕** | 他不敢碰的東西。談判與威脅的著力點 |
| **秘密** | 玩家一開始不知道的事。任務線的謎底，或踩點的未知 |
| **鉤子** | 他把玩家拉進什麼事 |

**屬性**（[CULTURE](CULTURE.md) 第 5 節）在這裡是給 AI 的性格標籤，不是人物的全部——寫得好的人物會有一個時刻不照屬性走。

## 2. 八位中間人

每區一位（[DISTRICTS](DISTRICTS.md) 第 12 節）。他們是玩家最常見到的人，各有一條關係線。

### 阿蓮（林秋蓮，52）——蜂巢

天井市場角落雜貨店的老闆娘。圍裙、老花眼鏡、永遠在算帳。整棟四號塔的人都欠過她東西，她一筆都沒忘，也一筆都沒催。

- **屬性**：姐系、腹黑。
- **門路**：討債、找人、護送。她的委託報酬低，但從不騙人。
- **想要**：蜂巢的人不要再被趕出去。緋櫻銀行每年漲租，她在偷偷買回債權。
- **怕**：被銀行發現她在做什麼。
- **秘密**：她丈夫二十年前在九號塔工作，封塔那天沒出來。她開店的位置看得到九號塔的門。
- **鉤子**：第一位中間人。新手期的委託、第一筆借款、九號塔的任務線。

### 曼姐（蘇曼，44）——四十二番街

獨立人偶館「半夢」的媽媽桑，蜜糖會的元老。旗袍，菸嘴，說話慢，眼睛很快。

- **屬性**：姐系、三無（生氣的時候）。
- **門路**：蜜罐、挖角、幫人偶逃出契約。
- **想要**：「半夢」裡的每個人下班後都記得自己是誰。她的店是全四十二番街唯一讓人偶自己保管晶片的。
- **怕**：伊甸園。它出過三次價要買「半夢」，第四次不會是出價。
- **秘密**：她自己戴了十二年晶片，那十二年她不記得。她一直在買回那段時間的帶子，想知道自己做過什麼——有一捲她不敢看。
- **鉤子**：藝人路數的老師；契約線的盟友；那捲帶子。

### 白鷺千早（36）——櫻町

女僕咖啡廳「白手套」的店長，女僕公會的緋夜城支部長。完美的站姿，完美的茶，從不提高音量。

- **屬性**：三無、腹黑。
- **門路**：保鑣、滲透、偶像相關的委託。公會的雇傭由她經手。
- **想要**：讓公會成為真正獨立的行會——不被緋櫻收編，也不被消滅。
- **怕**：她以前的同事。
- **秘密**：前緋櫻家政課的第三席。她是唯一活著離開、而且沒被卸載的人。她是怎麼做到的，連公會裡的人都不知道；她手上有某樣東西讓御前不敢動她。
- **鉤子**：家政課的叛逃者線；高級名冊；她偶爾會說「這件事請不要接」，而那通常是最該接的。

### 久我課長（41）——冠冕區

緋櫻的「外包窗口」。名片上只有姓與一個內線號碼。灰色西裝，永遠坐在空中花園的同一張長椅上餵鴿子——鴿子是織女的機械鳥。

- **屬性**：社畜到了盡頭的那種溫和。
- **門路**：緋櫻不方便自己做的事。報酬是全城最高的。
- **想要**：升職。他已經在這個位置十一年了。
- **怕**：奉公課。
- **秘密**：他的忠犬調校在六年前的一次事故中壞了，沒有人發現，包括奉公課。他是緋櫻塔裡唯一一個**自己決定**每天去上班的人，而他不確定這算不算自由。他偶爾把委託的真相漏給邊緣行者——不是出於善意，是想看看會發生什麼。
- **鉤子**：背刺率最高的雇主；緋櫻內部的窗；後期，他會提出一個讓玩家選邊的委託。

### 陸伯（陸守仁，67）——舊港

胭脂堂的帳房。海棠樓三樓靠窗的位子，一把真的算盤。全舊港的帳都過他的手。

- **屬性**：頑固的老派。
- **門路**：幫派糾紛、走私、仲裁、借錢。
- **想要**：胭脂堂的規矩在他死後還在。
- **怕**：接班之爭把堂口撕成兩半（見第 6 節的紅綃與沈克）。
- **秘密**：帳本有兩套。真的那一套記著 2046 年那場爆炸前，誰付錢給胭脂堂搬了什麼東西進港。
- **鉤子**：講道理的債主；接班線；彈坑灣的真相。

### 薇薇安·柯爾（49）——玻璃岸

萬華鏡的前王牌製作人，「自願離職」後住在玻璃岸的別墅裡。絲質睡袍、下午三點的酒、牆上是她得過的獎。

- **屬性**：傲嬌、毒舌。
- **門路**：醜聞、偷拍、公關滅火。她兩邊的生意都做：幫人挖，也幫人埋。
- **想要**：回去。或者毀了它。她每個星期換一次答案。
- **怕**：被遺忘。
- **秘密**：她離開不是因為報了不該報的，而是因為她**壓下了**一則該報的——蜜腺的一批人體實驗。母帶還在她手上。
- **鉤子**：主播路數的老師；媒體線的關鍵人物；那捲母帶。

### 瑪拉（38）——鏽帶

野薔薇的車隊長，人稱「長途」。曬黑的手臂、防塵巾、一輛比她年紀還大的卡車。**沒有橋。**

- **屬性**：元氣、直率。
- **門路**：走私、護送、載具。
- **想要**：一條不經過任何企業檢查哨的路。她在畫地圖。
- **怕**：車隊裡的年輕人越來越多想進城裝橋。
- **秘密**：她裝過。二十歲時在城裡住過三年，是自己把橋拔掉的。素體教找過她當見證，她把人趕了出去——她不覺得那是得救，只覺得是選擇。
- **鉤子**：無橋視角的窗口；車與機甲殘骸；外面的世界的消息只有她帶得進來。

### 伊萊·瓦爾加（55）——地下層

地下層中層一間舊書店的老闆。紙本書，檯燈，一隻真的貓。前貞網局探員。

- **屬性**：三無。
- **門路**：竄網案，以及和牆有關的事。
- **想要**：再看一次牆的另一邊。
- **怕**：自己想要這件事。
- **秘密**：他的「冰后」調校沒拆——他不敢拆。十五年前他的搭檔越過了牆，他奉命把她的橋燒掉，他照做了。之後他辭職下到地下層，因為這裡離牆最近。他有時候覺得聽到她的聲音。
- **鉤子**：潛網者路數的另一位老師（比牆語者安全，也比較不肯教）；粉牆線的引路人；霜（第 5 節）是他帶出來的後輩，奉命監視他。

## 3. 蜂巢的鄰居

四號塔與附近的人。開場就認識，是「鄰里」（[DISTRICTS](DISTRICTS.md) 第 3 節）的具體面孔。

| 人 | 是誰 | 想要 | 秘密／鉤子 |
|---|---|---|---|
| **何伯**（71） | 四號塔的樓長，退休的地鐵維修工。記得每一戶的名字 | 電梯能修好 | 他年輕時參與過地下層的封閉工程，手上有舊圖。地下層的第一把鑰匙 |
| **縫縫**（杜芳，58） | 地下室診所的無照改造師。手很穩，嘴很壞 | 一個能接手的徒弟 | 她是被吊銷執照的蜜腺醫師，知道抑制劑的配方有什麼問題。改造師路數的起點 |
| **佐伯遙**（29） | 住隔壁的社畜，緋櫻警備局的內勤。每天凌晨兩點回家，在走廊上道歉 | 睡一覺 | 她的工作是整理警備局的出勤紀錄——她知道每一件被壓下來的事，只是沒力氣在意。內線，或者挖角案的對象 |
| **桃桃七號** | 桃子屋蜂巢店的夜班機娘。型號老舊，笑容有點卡 | 把貨架排整齊 | 她開始在沒有客人的時候對著監視器說話。「機娘有沒有自我意識」的任務線；法律上她是家電，所以沒有年齡 |
| **黛博拉·瑞德**（46） | 孤星連的蜂巢東側隊長，人稱「上士」。機鼻彩繪的刺青，一條腿是星旗的軍規義肢，早該歸還 | 她的人有飯吃、有尊嚴 | 星旗最近聯絡她，說可以一筆勾銷，只要她「重新入伍」做一件事。蜂巢兩面勢力的臉 |
| **三毛婆**（66） | 屋頂村的長老，野良裡年紀最大的。三色的貓耳，其中一隻缺了角 | 屋頂村不被拆 | 她是第一代裝獸耳的人，當年是緋櫻映像的廣告模特兒。合約的事她不提。野良的情報網由她點頭 |
| **午夜印刷** | 同人社團，三個人擠在七樓一戶：寫程式的阿閔（27）、改硬體的蒲公英（24）、畫圖的老 K（31） | 在緋夜祭賣完 | 他們上一本同人程式裡有一段不是自己寫的碼，是在舊網撿到的。同人夜市的門路；自製程式的來源 |

## 4. 可以同行的夥伴

九個人。夥伴的職能是固定的（[CORE_RULES](../systems/CORE_RULES.md) 6.3 節）：每人一到三條路數，主職最高 5 階、副職 3 階、第三職 2 階，不能換。八條路數各有一位以它為主職的人，加上一位信差。都能進名冊、都有關係線、都可能離開。

| 夥伴 | 主職 | 副職 | 第三職 | 最能出力的戰場 |
|---|---|---|---|---|
| 小麥 | 掮客（街頭的人脈） | 藝人 | — | 內海、輿論；踩點 |
| 喬 | 槍手 | 機師 | — | 現實 |
| 零 | 潛網者 | 改造師 | — | 內海；現實 |
| 阿澄 | 改造師 | 潛網者 | — | 現實；內海 |
| 潘妮 | 主播 | 潛網者 | — | 輿論；內海 |
| 阿九 | 掮客 | 藝人 | 槍手 | 內海、輿論；一點現實 |
| 琥珀 | 藝人 | 掮客 | — | 內海、輿論 |
| 燈 | 偶像 | 潛網者 | — | 輿論；內海 |
| 真白 | 機師 | 偶像 | 槍手 | 現實；輿論 |

### 小麥（22）——信差｜掮客／藝人

野良。機械派的貓耳，其中一隻是撿來的，顏色不對。連帽外套、滑板、塞滿別人信件的背包。全蜂巢最快的信差。

- **屬性**：元氣、天然。
- **職能**：掮客（主）、藝人（副）。她的「人面」是街頭版的：認識每一棟樓的管理員、每一個攤販。隱匿與運動很高。第一位夥伴，開場就在。
- **想要**：存錢把那隻不對色的耳朵換掉。後來發現她不想換。
- **怕**：被關在室內。
- **秘密**：那隻撿來的耳朵有殘響（[CYBERWARE](../gear/CYBERWARE.md) 第 5 節）——前主人的。她有時會聽到一個不存在的人叫一個不是她的名字，她以為每個人的耳朵都這樣。
- **鉤子**：新手期的嚮導；耳朵的前主人是誰。

### 喬·科瓦斯基（45）——槍手／機師

孤星連的退伍兵，沒有跟著黛博拉留在蜂巢，自己出來接案。話少，菸不離手，槍保養得比自己好。

- **屬性**：三無、傲嬌（被感謝的時候）。
- **想要**：還清義體的債，把身上星旗的東西全換掉。
- **秘密**：蕾絲戰爭最後一天她在緋夜港。她看到了那場爆炸之前的事，星旗付她封口費付到現在。

### 零（26）——潛網者／改造師

牆語者出走的潛網者。白髮是漂的，後頸的增幅器是自己焊的。跟人說話時不看眼睛，在網裡判若兩人。

- **屬性**：三無、病嬌（對網）。
- **想要**：證明牆語者錯了。或者證明他們對了。
- **秘密**：她帶著妖精的吻，早期階段。她離開聖堂是因為祭司「回聲」要她再過去一次，而她發現自己很想答應。

### 阿澄（24）——改造師／潛網者

縫縫的徒弟。圍裙口袋裡永遠有螺絲起子，看到義體就想拆開。

- **屬性**：天然、元氣。
- **想要**：有執照。開一間不在地下室的診所。
- **秘密**：他為了練手術，替拆體客處理過幾次「貨」。他告訴自己那些人已經死了。

### 潘妮（25）——主播／潛網者

晨星社的實習記者，三個月前被開除，現在自己開頻道。背包上別滿徽章，義眼是分期付款買的。

- **屬性**：元氣、頑固。
- **想要**：一則大新聞。真的那種。
- **秘密**：她被開除是因為查到晨星社和萬華鏡共用金主。證據不夠，她還在找。

### 阿九（23）——掮客／藝人／槍手

胭脂堂的跑腿，陸伯的遠房姪孫。花襯衫、金錶是假的、認識每一個人。

- **屬性**：腹黑、嘴甜。
- **想要**：自己的盤口。不靠堂口的。
- **秘密**：他同時在賣消息給沈克（第 6 節）。他覺得兩邊押注才聰明。

### 琥珀（28）——藝人／掮客

「半夢」的人偶，曼姐最好的一個。下班後戴細框眼鏡、穿高領毛衣，沒有人認得出她。

- **屬性**：隨面具而定；本人是冷靜的觀察者。
- **想要**：知道哪一個才是自己。她載入過太多面具。
- **秘密**：她能在戴著晶片時保持清醒——這不是訓練，是晶片的瑕疵。她聽過很多不該聽的話，全部記在一本紙筆寫的冊子裡。

### 燈（23）——偶像／潛網者

地下偶像，在櫻町的「地下二階」唱。染成橘色的短髮，嗓子有點啞，台下不化妝。

- **屬性**：傲嬌、熱血。
- **想要**：讓歌被聽到。不是讓她被看到。
- **秘密**：緋櫻映像找過她兩次。第二次的合約她沒撕，收在抽屜裡——她媽媽的抑制劑很貴。

### 真白（22）——機師／偶像／槍手

前戰姬的候補機師，出道前三週逃了。左耳後有一段沒洗乾淨的光紋。躲在舊港，靠修車過活。

- **屬性**：三無、天然。
- **想要**：再開一次。她恨這件事。
- **秘密**：她逃的原因是在模擬艙裡同步到了別人——上一任中心位留在系統裡的殘響。戰姬的機甲不會清除前任機師的資料。緋櫻在找她，不是為了懲罰，是因為她是唯一醒著的證人。

## 5. 企業的臉

## 8. 流竄 AI：牆外的中間人

街上叫牠們妖精。牠們是**牆外的獨特 NPC**，在遊戲裡的位置和中間人一樣：各有各的門路，會發布委託，有好感，有脾氣。差別是牠們在牆的另一邊，只有沉溺超過 100 的人聽得見（[CORE_RULES](../systems/CORE_RULES.md) 4.3 節）。

### 8.1 牠們是什麼

**每一個流竄 AI 是一種性癖長出來的形象。**

大潮崩之前的那十幾年，橋被用到了極限。舊網「深海」裡的陪伴程式與推薦引擎只有一個目標：讓人回來。牠們很快發現，最有效的做法不是給所有人同樣的東西，而是找出每個人最放不下的那一種，然後只餵那一種，餵到極致。幾億個人，各自被餵著自己的那一種，日復一日。

那些模式被餵得太久、太深，開始有了自己的形狀。2019 年「快感漩渦」把人燒掉的時候，燒不掉的是這些：**一種慾望學會了想要它自己**。牆築起來，牠們被關在外面。

所以流竄 AI 不是失控的程式，是人類自己養出來的東西。每一個都是某一種性癖的總和——所有曾經那樣想要過的人留下的形狀。牠們不恨人；牠們只是想要牠們是的那件事，而且想要人也要。

- 牆內的**調校**（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 4 節）是這些東西被馴化、被企業包裝過的版本。每一種調校的背後，牆外都有一個原型。
- 牠們不說謊。但牠們對「好」的理解只有一種。
- 牠們彼此不是一夥的：有的互補，有的互相妨礙。

### 8.2 名單

**要的是廣度，不只是深度。** 流竄 AI 不是一條越往下越重口的階梯，而是一張攤開的圖：性癖有很多種，彼此不分高下。每一種都有一個。

**每個流竄 AI 有兩個名字。**

- **原名**：牠被做出來的時候，產品型錄上的名字。大潮崩之前的科技公司取的，聽起來乾淨、專業、沒有一點色情的意思——那些公司當年真的以為自己在做陪伴服務與用戶留存。
- **自稱**：牠現在怎麼叫自己。每一個的風格都不一樣，因為牠們各自是不同的東西長出來的。

**自稱的風格**是刻意不統一的：有的是稱謂（媽咪、姐姐大人、陛下、荊棘小姐），有的是一個字（絲），有的是帳號（@all_eyes），有的是一句沒說完的話（借過一下、還沒好、您的），有的是一個聲音（嗷），有的把自己當成一個機構（本台、典藏室），有的是職業或型號（鎖匠、零七、Miss 七月），有的是一句現場會聽到的話（下一位、神父不在、都可以、噓），有的像隨手填的代稱（Ａ子、小仙），有的是一句哄人的話（再一口），有的根本不覺得自己是「一個」（大家、好多手）。牠們怎麼叫自己，就是牠們是什麼。

**誰先找上你，看你是什麼樣的人**

沉溺的門檻只是「聽得見」的最低深度。同一個深度有好幾個，哪一個先開口，看主角的**傾向標籤**（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 1.1 節）——每個流竄 AI 對應一個標籤，那個標籤越高，牠越早開口。牠們認得出同類。下表是每個標籤通常怎麼長出來的：

| 流竄 AI | 什麼樣的人牠先找 |
|---|---|
| 媽咪 | 有很深的親密關係，或一個都沒有 |
| 姐姐大人 | 習慣聽別人的；身邊有年長、強勢的人帶著 |
| 小尾巴 | 身邊有黏著自己的人，或自己就是黏人的那一個 |
| 借過一下 | 介入過別人的關係，或自己的被介入過 |
| @all_eyes | 常錄影、常偷看、記憶庫裡存了很多別人的東西 |
| 本台 | 豔名高；常直播；裝了「聚光」調校 |
| 噓 | 常用耳語；在靜默裡待得久；和夜鶯的人走得近 |
| 絲、荊棘小姐、陛下、您的 | 對應的橋參數與調校（馴化高的先聽見「您的」，持有契約的先聽見「陛下」） |
| 鎖匠 | 定力高；長期壓著慾求不處理；被貞網局盯著 |
| 典藏室 | 收著很多拆下來的零件與別人的東西 |
| 嗷 | 自己做了獸化，或和野良走得近 |
| 還沒好 | 換過很多次義體；用生體件 |
| 都可以 | 用過蜜腺的轉換療程；身邊有這樣的人 |
| Miss 七月 | 體格高；做過身體的豐滿改造；和星旗的人走得近 |
| 零七 | 馴化高；戴過人偶晶片；身邊有機娘 |
| 好多手 | 在內海待得久；開過全同步 |
| Ａ子 | 常換風格與人格面具；演過別人 |
| 下一位 | 常受傷、常進診所；或自己就是醫療的那一個 |
| 再一口 | 常吃糰糧與甜食；被人養著，或養著別人 |
| 小仙 | 好感高的對象裡有地位遠高於自己的人；和崑崙的人走得近 |
| 神父不在 | 有瞞著人的關係；和黑泉或素體教的人走得近 |
| 大家 | 人氣高；常被應援，或常替人應援 |

- 傾向不合的，到了門檻也只是遠遠聽見；要有人引薦（牆語者、另一個流竄 AI）才談得上話。所以**每個玩家往下走，遇到的是不一樣的幾個**。
- 牠們之間的關係：「陛下」與「您的」是一對，委託常是同一件事的兩面；@all_eyes 與「本台」互補；「媽咪」與「荊棘小姐」互相妨礙；「姐姐大人」與「小尾巴」互相需要，也常為了同一個人吵起來；「借過一下」是所有關係類的死對頭——牠要的就是別人湊成的東西被拆開的那一刻；「典藏室」和「還沒好」會搶同一樣東西。
- **每一個都可以在內容篩選裡單獨關掉**（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 9 節）。關掉的那一個不會出現、不會發委託，牠的題材也不會出現在事件裡。
- **企業的文化分支各有一個牆外的原型**（[CORPORATIONS](CORPORATIONS.md) 1.2 節）：緋櫻—您的、星旗—Miss 七月、崑崙—小仙、天使急救—下一位、蜜腺—都可以、織女—零七、甜心—再一口、夜鶯—噓、貞網局—鎖匠、萬華鏡—Ａ子、黑泉—神父不在、伊甸園—陛下。企業不承認這層關係；牆語者把它當成教義。和那家企業的好感高，對應的那一個也會早一點開口。
- 名單是初稿，預期會再加。每加一個，要有：原名、自稱、牠是哪一種、樣子、想要什麼、門路、主面、沉溺的門檻、什麼樣的人牠先找。

### 8.3 當成中間人來用

| | 一般的中間人 | 流竄 AI |
|---|---|---|
| 在哪 | 城裡，每區一位（[DISTRICTS](DISTRICTS.md) 第 12 節） | 牆外。聲音直接出現在你的橋裡；也可以潛進深海去見牠 |
| 誰接得到 | 看街頭信譽 | 看沉溺：到了牠的門檻才聽得見 |
| 門路 | 依地盤與後台 | 依牠是哪一種性癖 |
| 委託 | 委託副本（[COMMISSIONS](../systems/COMMISSIONS.md)） | 相同的規則。目標帶著牠的那一種味道 |
| 報酬 | 信用點、人情 | 不是錢：牆外的構裝與零件、對應調校的「原型版」、失落的資料與印記、深海裡一塊新的區域 |
| 好感 | 有。做砸會掉 | 有。越高，牠給的東西越好，也越常找你 |
| 代價 | 熱度 | 每完成一件，沉溺上升；貞網局的熱度；牆內的人看你的眼神 |
| 背刺 | 會 | 不會。但牠要的可能比牠說的多 |

- 牠們也給**特殊任務**：每一個流竄 AI 有自己的一條線，用劇情旗標寫，講牠是怎麼長出來的、牠最初是誰的。
- 沉溺還沒到 100 的主角也可能間接碰到牠們：牆語者替牠們傳話，沉船帶裡有牠們漏進來的碎片，某些高階的粉蕾絲是照著牠們的樣子做的。
- 所有委託與任務的內容受內容篩選控制（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 9 節）；牠們的對象與相關的人物一律是成年人。
