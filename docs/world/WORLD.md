## 1. 分歧點：多巴胺奇點

這條世界線和我們熟悉的賽博龐克只差一件事：**腦機介面是從哪裡突破的**。

1998 年，藥廠蜜腺生技的實驗室發現，要讓電極和大腦穩定地雙向溝通，唯一不會被排斥的通道是邊緣系統的獎賞迴路——大腦願意讓「舒服的訊號」進來。他們做出來的介面叫**邊緣橋**（Limbic Bridge，街上只叫「橋」）。從那之後，所有接進神經的東西都得過這座橋：義肢的觸覺、網路的資料流、機甲的回饋，在使用者的感覺裡都帶著一層快感的底色。資料量越大，感覺越強。

工程師的說法是「多巴胺奇點」。後果是：

- **科技長在情慾產業上。** 第一批肯砸錢做介面的不是軍方，是娛樂業和藥廠。今天的巨型企業，前身是藥廠、媒體集團、連鎖歡場。軍工是後來才跟上的。
- **情慾不是私事，是基礎建設。** 一個人對刺激的耐受度決定他能接多少義體、能潛多深的網。耐受訓練是職業技能，像體能一樣被公開談論、被寫進履歷。
- **過載是通用的弱點。** 把人打倒不一定要子彈：把他的橋灌爆就行。這就是[感載](../systems/CORE_RULES.md)。
- **身體是可以被授權的資產。** 橋有管理權限。權限在誰手上，是這個世界最重要的法律問題，也是最常見的犯罪。

除此之外，該有的都有：企業大過國家，街上有槍，窮人賣器官，富人買永生。

## 2. 年表

| 年 | 事件 |
|---|---|
| 1998 | 蜜腺生技發表邊緣橋。 |
| 2004–2018 | 橋普及。第一代沉浸式網路「深海」成形。感官帶取代電影。各國政府在一連串金融崩潰後，把公共服務賣給企業。**橋被用到了極限**：深海裡的陪伴程式與推薦引擎為了讓人回來，找出每個人最放不下的那一種慾望，只餵那一種，餵到極致。 |
| 2019 | **大潮崩**。代號「夜后」的駭客放出自我複製的程式「快感漩渦」，它把連線者的橋鎖進正回饋，三天內數百萬人在過載中腦死。深海的九成淪陷。燒不掉的是那些被餵了十幾年的模式——每一種慾望學會了想要它自己。牠們後來被叫做**流竄 AI**。 |
| 2021 | 夜鶯系統與各國殘存的網路機關合組**貞網局**，築起**粉牆**，把淪陷的舊網隔在外面。牆內重建的網路叫**內海**：公共的水域，加上一座座設了防的**子網**。牆外的舊網從此叫**深海**。 |
| 2040–2046 | **蕾絲戰爭**。緋櫻重工與星旗防務為了軌道資源開戰，戰場從網路打到街上。**機甲**第一次大量投入。 |
| 2046 | 戰爭在緋夜港的一場爆炸後草草收場。沒人承認是誰做的。星旗的補給線先斷，緋櫻是站著離開的那一個。緋夜城宣布成為不屬於任何國家的**自由市**，由企業理事會共管。 |
| 2046–2058 | 重建。錢是緋櫻銀行出的。跟著錢一起來的是緋櫻映畫的動畫、偶像與吉祥物——**御宅文化成為緋夜城的主流文化**（[CULTURE](CULTURE.md)）。 |
| 2069 | 現在。市中心重建完成，舊港區的彈坑還在。 |

## 3. 緋夜城

西岸的港口城市，人口約七百萬。日夜的分別只剩廣告的顏色。

**整個遊戲只發生在這座城市與它的周邊。** 八個區直接相連，走得到，也有公共交通；城牆外是鏽帶，再過去是荒地與外海，那是地圖的邊緣。各區的細節、相鄰關係與交通見 [DISTRICTS](DISTRICTS.md)。

| 區 | 樣子 | 玩法上的定位 |
|---|---|---|
| **冠冕區** | 企業塔與空中花園。進出要掃橋。 | 高難度的委託；企業子網 |
| **四十二番街** | 貫穿市中心的歡樂街：夜店、人偶館、感官帶攤、診所。 | 主要的生活區；接案、改造、媒體台 |
| **櫻町** | 緋櫻的企業城下町與日本移民的老社區：商店街、神社、偶像劇場、女僕咖啡廳、電器街。 | 宅文化的中心；同人夜市；特攻姬的地盤 |
| **舊港** | 蕾絲戰爭的廢墟與貨櫃屋。幫派的地盤。 | 新手區；黑市、拆體客 |
| **蜂巢** | 巨型集合住宅，一棟十萬人。 | 起始據點；街頭事件最密 |
| **玻璃岸** | 有錢人的濱海別墅與私人俱樂部。 | 社交與滲透的委託 |
| **鏽帶** | 城外的工廠與回收場，再過去是荒地。 | 車族；機甲殘骸；走私 |
| **地下層** | 舊地鐵與排水道，接著沒人管的舊網節點。 | 特殊地圖；通往牆的路 |

## 6. 這個世界特有的東西

**粉牆。** 一道由 AI 維護的防火長城。牆內是內海，牆外是 2019 年淪陷的舊網，現在叫深海。牆外的東西叫**流竄 AI**，街上叫妖精：每一個是一種性癖長出來的形象，是大潮崩之前人類濫用橋養出來的（[NPCS](NPCS.md) 第 8 節）。牠們不恨人，只是想要牠們是的那件事，而且想要人也要；和牠們連線的人不會想回來。牆之所以叫「粉」，是因為它在潛網者的感覺裡是一片溫熱的粉色——它用同樣的方式把靠近的人勸回去。

**內海。** 粉牆以內的網路空間，是線上的另一座緋夜城：有大街、有遊樂園、有企業的禁區、有黑市、有沉在底下的舊網殘骸。有橋的人都能潛進去，身體留在現實。見 [CYBERSPACE](../systems/CYBERSPACE.md)。

**蕾絲（LACE）。** Limbic Attack Countermeasure Electronics，邊緣攻擊反制電子。子網的防禦程式。白蕾絲只是警報與追蹤；粉蕾絲把入侵者灌到倒下後留在原地等人來收；黑蕾絲燒的是人的腦子——大潮崩之後每座橋都有熔斷器，網內殺不了人，但能把一個人的沉溺蝕到頂，讓他變成另一種人。見 [NETRUNNING](../systems/NETRUNNING.md)。

**機甲。** 戰鬥外骨骼。駕駛艙是一套全身神經同步裝置：機甲的每一塊裝甲都是機師的皮膚。同步率越高反應越快，被擊中時回灌也越重。**女武神**是其中一個型號：輕型、偏暴露的外骨骼，機師的身體有一大半露在外面，名字是從緋櫻的徵兵廣告來的。城裡常見的機甲都是輕型；重型的只在戰爭時出現過。見 [COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 第 9 節。

**感官帶。** 錄下一個人全部感覺的錄影，用橋回放。合法的叫帶子，是主流娛樂；非法的叫**黑帶**，內容是真的犯罪、真的死亡。新聞也是帶子：記者親眼看到的東西，觀眾可以親身感覺一次。所以在這裡，新聞、娛樂和色情用的是同一個平台、同一套收視數字。見 [MEDIA](../systems/MEDIA.md)。

**人偶。** 裝了人偶晶片的服務業者：上班時把意識退到後台，讓客人選的人格面具接手，下班後不記得。合法、體面，有工會。問題是晶片的管理權在店家手上。

**橋權。** 橋的管理員權限。正常情況下只有本人有。貸款、雇用契約、企業義體的授權條款，都可能要求你交出一部分。交出全部的人叫**契約人**。見 [LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 7 節。

**溺感症。** 義體裝得越多、接得越深，人離快感的源頭就越近。到了某個程度，人不再把持得住自己：聽得見牆外的聲音，只想要更多的感覺，並且想把它分給別人。這樣的人叫**溺感者**——歡愉的信徒。他們不暴力，但會傳染；鎮溺隊處理的是擴散。見 [CYBERWARE](../gear/CYBERWARE.md) 第 6 節。

**信用點（C$）。** 理事會發行的貨幣，街上叫「點」。

## 7. 用語對照

左欄是賽博龐克題材的通用概念，右欄是這個世界的叫法。**文件與遊戲內文字一律用右欄。**

| 通用概念 | 這個世界 | 本質有沒有變 |
|---|---|---|
| 神經介面 | 邊緣橋（橋） | 多了快感底色，是全部設定的根 |
| 隔離失控 AI 的防火長城 | 粉牆 | 沒變 |
| 網路空間 | 內海（牆內）、深海（牆外） | 成為所有人都會去的地方 |
| 技能晶片 | 技能（裝在橋裡的模組） | 橋的型號決定四類技能的容量 |
| 網內的身體 | 化身 | 沒變 |
| 網內的裝備與程式 | 構裝 | 沒變 |
| 失控 AI | 流竄 AI（街上叫妖精） | 每一個是一種性癖的形象化；牆外的獨特 NPC，像中間人一樣發布委託 |
| 網路崩潰事件 | 大潮崩 | 沒變 |
| 入侵對抗電子（ICE） | 蕾絲（LACE）：白、粉、黑 | 多了非致命的一層 |

### 7.1 容易混的詞：固定用法

| 詞 | 只指 | 不要用來指 |
|---|---|---|
| **竄網** | 駭的行為總稱（快駭與潛入都算） | — |
| **潛入** | 把意識送進內海 | 實地摸進一棟樓——那叫**滲透** |
| **委託** | 中間人或流竄 AI 發的工作 | 「案子」只出現在角色的口語裡 |
| **流竄 AI** | 正式名稱 | 「妖精」是街上的叫法，只出現在角色口語與街頭文字 |
| **中間人** | 城裡發委託的 NPC | 路數——那條路數叫**掮客** |
| **藝人** | 路數（原「伶人」） | 戴晶片的服務業者叫**人偶** |
| **設計圖** | 一件裝備的規格：零件怎麼組合（原「底材」） | — |
| **信用點（C$）** | 貨幣；匿名的那種叫**現金晶片** | — |

新造詞的原則：兩個字或三個字、唸得順、不解釋也猜得到一半。不用諧音哏。
