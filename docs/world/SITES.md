## 1. 怎麼讀

### 1.1 街區

每塊 13 × 9 格，一格是一間店面或一段街（[DISTRICTS](DISTRICTS.md) 1.3 節）。每塊寫五樣：

| 欄 | 意思 |
|---|---|
| 是什麼 | 一句話 |
| 設施 | 8～12 個。粗體是有名字的地標（[DISTRICTS](DISTRICTS.md) 各區的表）；「→」是出口：橋接區、隔壁街區、地鐵站、地下層入口 |
| 人 | 生成居民時抽的類型與固定 NPC |
| 事件 | 這一塊街頭事件表的傾向（1.2 節） |
| 白天／夜晚 | 6～18 點與 18～6 點的差別：哪些設施開、人換成誰、事件傾向怎麼變 |

### 1.2 事件的傾向

每塊街區給街頭事件（[EVENTS](../systems/EVENTS.md) 4.1 節）的**主題**一個權重（1～3）：導演從這一區的白天或夜晚表抽事件時，帶這個主題的事件照權重放大。主題比 [EVENTS](../systems/EVENTS.md) 3.5 節的六種類型細，每個主題歸到其中一類，所以類型平衡照那一節算。

| 主題 | 是什麼 | 歸到哪一類 |
|---|---|---|
| 生活 | 鄰居、店家、小事，不一定有衝突 | 人情 |
| 衝突 | 搶劫、鬥毆、追逐、討債的上門 | 麻煩 |
| 盤查 | 掃橋、臨檢、保全問話 | 麻煩 |
| 勢力 | 幫派與企業的人在做他們的事，你被捲進去 | 麻煩 |
| 交易 | 有人賣東西、買情報、找人做事 | 買賣 |
| 媒體 | 鏡頭、直播、偶像、萬華鏡 | 機會 |
| 網路 | 被快駭、舊網節點、遺魂 | 傳聞 |
| 怪談 | 吉祥物、殘響、說不清楚的事 | 傳聞 |
| 誘惑 | 拉客、搭訕、場所、豔名（受內容篩選控制） | 慾望 |

寫法：「生活³ 交易² 衝突¹」，沒寫的主題權重 1。夜晚欄只寫和白天不同的部分。

### 1.3 要地

17 處（[DISTRICTS](DISTRICTS.md) 1.3 節）。每處：

- **層**：每層 11 × 9。「層」是任務上的一段，不一定是一層樓（緋櫻塔的七層是七個區段）。
- **權限層**：每一層對應它子網的哪一層（訪客、員工、管理、核心）。控制節點連著同一層的門、攝影機、砲塔（[NETRUNNING](../systems/NETRUNNING.md) 第 4 節）。
- **守備**：敵人類型（[CORPORATIONS](CORPORATIONS.md) 第 7 節的表）、蕾絲的顏色、警報之後增援幾分鐘到。
- **進入**：至少兩種，其中一種不用打。
- **可以做**：哪些特殊任務用它，以及平常去能做什麼。
- **記得你**：每處有一組記憶旗標（`site:<id>:<事>`）。上次從通風口進來，這次通風口焊死了；上次放過的警衛，這次會認出你。
