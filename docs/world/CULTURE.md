# 文化：霓虹底下的御宅城市

> 上層：[WORLD](WORLD.md)。依賴：[CORPORATIONS](CORPORATIONS.md)（緋櫻）、[GANGS](GANGS.md)。被依賴：[DISTRICTS](DISTRICTS.md)、[ITEMS](../gear/ITEMS.md)、[NPC_SYSTEM](../systems/NPC_SYSTEM.md)、世界書。
> 這份是世界觀文件。第 1 節是文化地圖（主流、次文化、小眾），第 12 節列出每個文化元素在系統上的落點，規則細節回到各系統文件。

緋夜城的主流文化是日本的御宅文化——動畫、偶像、女僕、獸耳、同人。不是因為這座城市在日本，而是因為重建它的錢是日本財閥出的（[CORPORATIONS](CORPORATIONS.md) 第 2 節）。但這座城市不只有一種文化：每個企業、每個幫派都長出了自己的一支，有的被收進主流，有的佔著一條街，有的只在少數人之間流傳。

## 1. 文化地圖：主流、次文化、小眾

緋夜城的每一個勢力都有自己的美學與性癖（[CORPORATIONS](CORPORATIONS.md) 1.2 節、[GANGS](GANGS.md) 1.2 節）。把它們攤開來看，是三圈：

| 圈 | 是什麼 | 怎麼判斷 |
|---|---|---|
| **主流文化** | 多數人活在裡面、不覺得它是「一種文化」的東西 | 螢幕上、廣告裡、每條街都有；穿成那樣不會有人多看一眼 |
| **次文化** | 有自己的地盤、圈子與規矩；主流認得它，但不屬於它 | 有固定的場所與人群；穿成那樣，別人知道你是哪一掛的 |
| **小眾文化** | 封閉、被排斥、或危險；多數人只聽說過 | 要有人帶才進得去；穿成那樣走在街上會被躲開或被盯上 |

**三圈會流動。** 獸耳二十多年前是小眾，現在是主流；偶像的應援同步原本是地下的玩法，被緋櫻買走做成產業。企業的工作就是把次文化收編成主流，街頭的工作就是在被收編之前長出下一個。

### 1.4 公司的、街上的、自己做的

同一種文化常常有三個版本，互相看不順眼：

| 版本 | 是什麼 | 例 |
|---|---|---|
| **公司的** | 量產、精緻、安全。骨子裡替公司說話 | 緋櫻的家政課、公司偶像、夜鶯的官方 SKIN、天使急救的制服 |
| **街上的** | 移民社區與街頭留下來的。不可愛，但是真的 | 特攻姬、胭脂堂的堂口、蜜糖會的姐妹 |
| **自己做的** | 同人。拿公司的東西做公司不會做的事 | 同人眾、地下偶像、個人勢的虛擬主播、車庫生技 |

賽博龐克的老問題——企業把反抗也做成商品——在這裡有了具體的形狀：**緋櫻賣給你叛逆的動畫主角，然後僱你當她的反派**。街上的人用同一套符號反過來用：女僕裝可以是忠誠的制服，也可以是職人的招牌；偶像可以是公司的商品，也可以是在地下室唱公司不准唱的歌的人。

## 2. 獸化改造

貓耳、狐耳、兔耳、尾巴。緋夜城最顯眼的流行，街上每五個人就有一個。

**怎麼來的**：二十年前，緋櫻映畫一部獸耳女主角的動畫大紅。織女電子順勢推出第一款「會動的貓耳」——本來是頭戴式的玩具，接上橋之後會隨情緒擺動。再後來有人問：為什麼不直接裝上去？

**兩派**：

| | 機械派 | 生體派 |
|---|---|---|
| 是什麼 | 機械的零件：耳朵是感測器陣列，尾巴是平衡陀螺 | 生體的零件（蜜腺的技術）：真的軟骨、真的毛、真的神經，是**長出來的** |
| 好處 | 便宜、可換、可升級；數值高 | 幾乎沒有沉溺成本；摸起來是真的；掃描器不當它是義體；不會被駭；會隨時間成長 |
| 壞處 | 沉溺成本；會被駭；要保養 | 貴、要等它長、拆了就死；每週要營養劑；會掉毛、會生病 |
| 誰在用 | 街頭、潛網者、野良 | 有錢人、偶像、高級人偶 |

兩派用的是**同一套設計圖與零件系統**，差別只在零件的材質；也可以混裝——機械的骨架、生體的皮與神經。「哪一系」（貓、狐、兔、犬）在機械派看設計圖的外形與韌體，在生體派看**基因譜**。規則見 [CRAFTING](../gear/CRAFTING.md) 第 8 節。

**不只是裝飾**：獸耳是耳部義體的一個主流分支（[CYBERWARE](../gear/CYBERWARE.md) 第 1 節的「耳與喉」槽），真的有用——指向收音、超音波、聽得到隔牆的心跳。尾巴是軀幹或腿部的義體，給平衡與落地。貓系偏敏捷與隱匿，狐系偏感知，兔系偏聽覺與跳躍，犬系偏追蹤。

**雙面效應**：耳朵和尾巴接在橋上，**會洩漏情緒**。高興會豎起來，害怕會貼平，說謊時尾巴會僵住。裝了的人在誘惑與表演上有加成（藏不住的反應很討喜），在交涉、唬人、隱瞞上有懲罰。機械的可以裝抑制器把它鎖住——但在櫻町，鎖住耳朵被當成「這個人有事瞞著」。生體的鎖不住，那是真的反射。

**社會意義**依區而異：櫻町與四十二番街是時尚；冠冕區當作不夠莊重；蜂巢東側的孤星連會找麻煩；鏽帶的素體教視為褻瀆。重度獸化又沒錢維護的人落到街上，成了野良（[GANGS](GANGS.md) 第 3 節）。

## 3. 女僕與執事

在緋夜城，女僕不是一種扮裝，是一種**職業倫理的符號**。

**源頭是緋櫻的「奉公」**：服侍是榮譽，忠誠是美德。緋櫻的家政課——穿女僕與執事制服的要人警護部隊——把這個形象推到極致：彬彬有禮、一塵不染、能在倒茶的同時解決房間裡的每一個人。

**於是有了四種女僕**：

| | 是誰 | 忠於 |
|---|---|---|
| 家政課 | 緋櫻的精銳，橋裡有忠犬調校 | 公司 |
| 女僕公會 | 緋櫻底下的行會：有牌的保鑣與管家，照行規接委託（[GANGS](GANGS.md) 第 4 節） | 合約 |
| 咖啡廳女僕 | 服務業。櫻町與四十二番街滿街都是 | 排班表 |
| 人偶館的女僕型 | 載入女僕人格面具的人偶 | 這一個小時的客人 |

同一套衣服，四種完全不同的處境。認不認得出眼前是哪一種，是在這座城市活下去的常識——也是踩點時的一項未知。

**女僕咖啡廳**是櫻町的情報交換所。店員聽得到所有客人說的話，而沒有人會防一個端蛋包飯的。好幾個中間人的店面就是咖啡廳（[FIXER](../systems/FIXER.md) 第 1 節）；玩家也可以開一間（[FIXER](../systems/FIXER.md) 第 9 節）。

**制服是裝備**：正規的女僕服與執事服是有護甲的——夾層纖維、藏刀的襯裙、藏槍的圍裙口袋。它是少數能同時兼顧護甲、隱匿與風格的服裝（[COMBAT_SYSTEM](../systems/COMBAT_SYSTEM.md) 第 4 節的「三選二」的例外），代價是只有受過訓的人穿得出效果，而且穿上它，別人就會用女僕的規矩看待你。

執事與男性從業者同樣存在，行規相同。

## 4. 偶像

偶像是這座城市最有權力的一種人，也是最不自由的一種。

**為什麼偶像這麼重要**：演唱會不只是看和聽。幾千個觀眾的橋同時接上舞台，感覺偶像感覺到的東西。這叫**應援同步**，是合法範圍內最強烈的集體體驗。能承受幾千人份回灌的人萬中選一——偶像首先是一種體質（極高的耐受與敏感度），其次才是歌與舞。

**四種偶像**：

| | 是什麼 | 處境 |
|---|---|---|
| **公司偶像** | 緋櫻映畫與萬華鏡旗下的偶像 | 契約寫到私生活。「畢業」的時候，在團期間的部分記憶歸公司所有 |
| **戰姬** | 緋櫻戰姬事業部的機甲機師，同時是偶像團體 | 耐受高到能承受幾千人同步的人，也正好能開全同步的機甲。出擊就是公演，戰鬥會被剪成帶子賣。她們是真的在打仗 |
| **地下偶像** | 沒有公司，在地下室、屋頂、祭典上唱 | 這條世界線的抗議歌手。唱公司不准唱的，用地下轉播站播。紅了之後，不是被簽走，就是被處理掉 |
| **虛擬偶像** | 沒有身體，只有形象與聲音。背後是一個人、一個團隊、或一個 AI | 永遠不會老、不會鬧醜聞。傳聞有一位當紅的虛擬偶像背後沒有任何人——而她的粉絲登出之後，都說還聽得到她 |

**周邊文化**：

- **親衛隊**：粉絲的武裝組織（[GANGS](GANGS.md) 第 3 節）。
- **握手會**：不是握手，是短暫的一對一同步。票價驚人。也是刺殺、竊取資料、植入惡意韌體的機會。
- **推**：一個人支持的那一位偶像。「你推誰」是櫻町的寒暄，也是劃分敵我的問題。
- **畢業**：偶像契約期滿。對外是含淚的告別公演，對內是奉公課的卸載手術。畢業後的偶像去了哪裡，是城裡的禁忌話題，也是不只一條任務線的起點。

**玩法上**：偶像是媒體玩法的另一種形狀——主播靠素材，偶像靠同步。偶像是第八條路數，規則見 [MEDIA](../systems/MEDIA.md) 第 9 節。

## 5. 萌的工程學

「萌」在這裡是一門應用科學。

緋櫻映畫的情感工學部門花了幾十年研究：什麼樣的語氣、動作、反應模式，最能在觀眾的橋上觸發保護欲與依戀。成果是一套標準化的**屬性**——傲嬌、三無、天然、元氣、腹黑、姐系、病嬌……每一種都是一組量過的行為參數。

這套東西現在是整個產業的共通規格：

- **人格面具**（[CORE_RULES](../systems/CORE_RULES.md) 第 6 節藝人的招牌能力、[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 6 節的人偶館）依屬性分型號販售。客人點的不是「一個人」，是「傲嬌型，B 規格」。
- **槍靈**（崑崙）、**機娘**（織女）的人格同樣用這套型號。
- **偶像**出道前被分配屬性。
- 普通人也會說自己「是什麼屬性」，像說星座。

黑暗面：屬性可以被**安裝**。戴久了面具的人偶分不清哪個是自己；公司偶像的屬性寫在契約裡；家政課的禮貌是調校出來的。這座城市裡最可愛的那些人，有多少是自己選的，沒人說得準——包括他們自己。

系統上，屬性沿用 ElondiaRPG 的 NPC 性格標籤：生成 NPC 時抽一到三個，交給 AI 作為描寫依據；人格面具則是把這個標籤暫時換掉。

**屬性清單（已確認）**。一個人標一到三個，而且要和他的性格對得上（[NPCS](NPCS.md) 1.1 節）。

| 屬性 | 指的是什麼樣的人 |
|---|---|
| 傲嬌 | 她嘴上不饒人，心裡其實在意 |
| 三無 | 她沒有表情，不開口，也不表露情感 |
| 冰山 | 她冷淡、難以接近，但會皺眉、會不耐煩，和三無不同 |
| 天然 | 她少一根筋，常常沒意識到自己做了什麼 |
| 元氣 | 她精力充沛，靜不下來 |
| 腹黑 | 她說話得體，心裡一直在算計 |
| 病嬌 | 她的喜歡帶著佔有，到了會傷人的程度 |
| 姐系 | 她習慣照顧人，把對方當弟弟妹妹 |
| 御姐 | 她是從容的年長女性，氣場在對方之上 |
| 人妻 | 她結過婚或守著一段婚姻，身上有家的味道 |
| 大姐頭 | 她罩著一群人，講義氣 |
| 兄貴 | 他是可靠的大哥，豪爽、講義氣 |
| 溫柔 | 她待人和氣，很少說重話 |

## 6. 同人

公司做的東西是「官方」，自己做的叫**同人**。在緋夜城，同人的範圍比漫畫大得多：

| 同人的什麼 | 是什麼 |
|---|---|
| 本子 | 漫畫與小說。畫官方不會畫的 |
| 同人帶 | 自製的感官帶。品質參差，但有官方沒有的東西 |
| 同人程式 | 自己寫的快駭與工具。沒有保固，有時候有後門，有時候比企業的好用 |
| 同人零件 | 自製與魔改的零件、調校、車庫生技的生體件。冷門的、奇怪的、企業嫌市場太小不做的 |
| 同人皮 | 給槍靈、機娘、虛擬形象用的自製人格與外觀 |

**同人夜市**每週在蜂巢與櫻町交界的高架橋下開一次，是城裡最大的非正規市場——賽博龐克題材裡的夜市，在這裡長成了即賣會的樣子：一排排摺疊桌，社團名寫在紙板上，熟客天沒黑就來排隊。

**緋夜祭**佔滿整個舊港的貨櫃場，一次開三天。全城的社團、企業的獵頭、貞網局的臥底、來買禁品的和來抓人的，都在。它沒有固定的日期，由事件與任務觸發（[LIFE](LIFE.md) 8.2 節）。

同人眾見 [GANGS](GANGS.md) 第 4 節。

## 7. 日常

把這些放進城市的每個角落，世界才會像活的：

- **扭蛋**：街角的扭蛋機。便宜的轉出吊飾與貼紙；貴的那種在診所與夜市——**義體扭蛋**，轉到什麼裝什麼。新手期的賭博式成長，以及「這顆扭蛋裡的義眼好像不是新的」的故事。
- **痛車、痛甲**：把喜歡的角色畫滿整台車。戰姬的機甲有官方塗裝；街頭的機師自己畫。星旗那邊的對應物是機鼻彩繪。
- **動畫帶**：動畫也是感官帶——觀眾不是看主角，是**成為**主角。有人一部看上百遍，有人看完分不清哪些記憶是自己的。
- **遊戲中心**：格鬥機台接的是橋，輸的人真的會痛一下。地下的那種就是感官擂台（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 6 節）。
- **角色扮演**：穿成動畫角色上街很平常。所以**偽裝在這座城市特別容易**——沒人會多看一個戴面具、穿制服的人。藝人的生意靠這個。
- **吉祥物**：每家企業、每個區、每間店都有。桃子屋的桃子、天使急救的小天使、市警的警犬。吉祥物讓這件事不再只是可愛（[GANGS](GANGS.md) 第 3 節）。
- **課金**：一切都能加購。槍靈的新語音、義眼的濾鏡、公寓牆面的桌布。
- **社畜**：企業底層員工的自稱。奉公文化的另一面——加班到在工位上過載。

## 9. 主流文化的其他幾支

### 9.1 虛擬主播

夜鶯維運這座城市的網路，卻沒有一張對外的臉。它的人從不露面：對外出現的永遠是一個**SKIN**——有名字、有設定、有生日、有粉絲的化身；後面那個人叫**中之人**。

- **到處都是 SKIN**：子網的播報員、客服、導航、公共廣播，每一個都是一個角色。城裡的人認得「客服的小夜」「報站的燕子」，就像認得鄰居。
- **公司勢與個人勢**：夜鶯與萬華鏡旗下的是公司勢，SKIN 歸公司，中之人可以換；自己畫 SKIN、自己開台的是個人勢，是同人的一支。
- **中之人是秘密**：SKIN 的人氣和中之人無關是這一行的鐵則。挖出一位當紅 SKIN 的中之人是誰，是狗仔最值錢的料，也是委託裡常見的目標。
- **換人演**：公司勢的 SKIN 換了中之人，粉絲通常察覺不到。察覺到的那幾個會變得很危險。
- 和**虛擬偶像**的差別：虛擬偶像是偶像的一種（第 4 節），可能根本沒有中之人；虛擬主播一定有人在後面。
- 牆外的原型是「初見」；夜鶯更早的聲音產品留下的是「噓」。

### 9.2 扮演

萬華鏡的平台上，每個人都在演某個人。

- **人設**：頻道主的性格、口頭禪、喜好都是設計過的。紅的人設會被別人抄，抄到後來沒人記得誰先。
- **角色扮演**：穿成動畫角色、遊戲角色、甚至別的名人上街很平常。所以**偽裝在這座城市特別容易**——沒人會多看一個戴面具、穿制服的人。藝人的生意靠這個。
- **濾鏡**：橋裡的視覺濾鏡讓別人看到你想讓他們看到的樣子。免費的有浮水印，付費的沒有；被掃描時會現形。
- **演久了**：分不清哪個是本來的。這是萬華鏡的職業病，也是人偶館的日常（第 5 節）。
- 牆外的原型是「Ａ子」。

### 9.3 歡場

四十二番街從美式的劇院街與艷舞俱樂部，變成現在這條掛滿直書霓虹的歡樂街（[DISTRICTS](DISTRICTS.md) 第 4 節）。它的文化是兩邊混出來的：

- **兔女郎與禮服**來自戰前的俱樂部；**陪酒、指名、送行**的規矩來自日式的店。
- **姐妹**是認真的稱呼。店與店搶客人，但從業者之間互相罩：誰被客人為難、誰欠了伊甸園的錢，消息一個晚上就傳遍整條街。這是蜜糖會的根。
- **伊甸園的店**是另一個版本：一樣的燈、一樣的笑，但裡面的人是契約人或人偶。客人多半分不出來；從業者一眼就看得出來。
- 歡場的服裝在番街是日常，走出番街就是另一回事（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 2 節）。
- 牆外的原型是「今晚幾位」。

### 9.4 照護

天使急救的白色制服是全城被模仿最多的一套。

- 它的急救員是武裝的：衝進槍戰把會員拖出來，是這座城市最接近「英雄」的職業形象。
- 於是「護士」成了一種信任的符號：診所、藥局、甚至調校診所的櫃台都穿得像天使急救。穿上那一身，別人會把身體交給你——這也是假扮護士的人偶與騙子特別多的原因。
- 另一面是**帳單**：天使急救救你，然後把付不起的債賣給伊甸園（[CORPORATIONS](CORPORATIONS.md) 第 3 節）。街上的說法是「天使先收靈魂再收錢」。
- 牆外的原型是「下一位」。

### 9.5 可愛與餵養

甜心食品的桃子屋是這座城市最親切的臉：粉紅色的招牌、桃子吉祥物、永遠在笑的店員。

- **集點、聯名、限定口味**：城裡每個人的橋裡都有一張桃子屋的集點卡。
- **吉祥物文化**：每家企業、每個區、每間店都有吉祥物，源頭是甜心與緋櫻映畫的聯名。
- **被照顧的感覺**是它賣的東西；底下是 A/B 測試過的問候與扣薪的笑容考核（[CORPORATIONS](CORPORATIONS.md) 第 5 節）。
- 牆外的原型是「再一口」。

## 10. 次文化

### 10.1 不良

櫻町的巷子不歸緋櫻管，歸**特攻姬**。

- **樣子**：繡滿字的特攻服長外套、纏胸布、口罩、木刀與改裝機車。外套背上的字是隊名與誓詞，是真的要守的。
- **規矩**：前輩後輩、義氣、不對街坊動手。她們自認是這條街的守護者，收的保護費比市警的治安費便宜，而且人真的會到。
- **和緋櫻的關係**：緋櫻映畫把不良少女做成動畫的類型角色來賣；特攻姬恨這件事，又穿著那部動畫帶紅的款式。
- **真的與買來的**：真的特攻服只有隊裡的人訂得到；店裡賣的是「特攻風」。穿著買來的走進她們的巷子，要有被問話的準備。
- 牆外的原型是「夜露死苦」。

### 10.2 哥德、哥德羅莉塔與中二

**夜宴社**有兩派，互相嫌棄，偷起感覺來是同一套手法。

- **黑派**：傳統哥德。束腰、黑蕾絲、十字架、蒼白的妝，聚會辦在廢教堂與玻璃岸的地下室。
- **甜派**：哥德羅莉塔。蓬裙、蝴蝶結、頭飾、洋傘、抱著玩偶，茶會辦在櫻町的洋館咖啡廳，全程開著直播。甜派是打扮，不是年紀；成員都是成年人。
- **中二**：兩派都滿口封印、真名、契約與「被選上的人」。外人以為是在演——直到看見**可愛的裙子底下掏出來的是機槍**，洋傘是槍管，玩偶裡是炸藥。她們是真的有破壞力。
- **茶會的規矩**：衣裝不合格的不能入座。入社要通過一場品味的考驗。
- 牆外的原型是「請入座」。

### 10.3 畫報與硬派

星旗把一整套美式的東西帶進這座城市，然後輸了戰爭，留下來的變成次文化。

- **畫報女郎**：金髮、豐滿、曬過的皮膚、啦啦隊、牛仔帽。星旗的徵兵海報至今用這個樣子；機鼻上畫的女郎是照著真人改造出來的。
- **硬派**是它的另一面：孤星連的老兵穿磨舊的飛行夾克與牛仔靴、抽雪茄、開戰時留下來的皮卡。話少、守信用、記仇。
- 兩者的關係：**海報上的是廣告，酒吧裡的是真的打過仗的那一個**。孤星連的引擎蓋上也畫著畫報女郎——是她們自己年輕時的臉。
- 在日系主流的城裡，這一身是「輸家的制服」，也是少數不買緋櫻帳的姿態。
- 牆外的原型是「Miss 七月」（畫報）與「長官」（硬派）。

### 10.4 仙俠與任俠

舊港的華埠有兩張臉，同一個根。

- **仙俠**是崑崙的版本，在雲上：漢服與旗袍、清冷、可望不可即。公司裡升職叫「破境」，主管稱師姐與長老；賣的智慧武器裡住著「劍靈」。它賣的是高嶺之花，以及把高嶺之花摘下來的念頭。
- **任俠**是胭脂堂的版本，在泥裡：旗袍、刺青、長煙管、花牌與麻將。義理、面子、規矩——欠的要還，說過的話要算。
- 胭脂堂裡有兇的，也有**溫柔的姐姐**：替你倒茶、聽你把話說完，然後才談債。很多人是為了那一杯茶才借下第一筆錢。
- 兩邊有幾十年的老關係，各算各的。
- 牆外的原型是「小仙」（仙俠）與「這杯我請」（任俠）。

### 10.5 機件的三種迷戀

對機械身體的喜好分三支，互相分得很清楚：

| | 是什麼 | 追求 | 牆外的原型 |
|---|---|---|---|
| **半機娘**（鉻娘子） | 把關節換成外露的球關節、肌肉換成液壓缸，走起來有氣壓的聲音 | 像一台漂亮的機器。越不像肉越美 | 嘶—— |
| **人偶**（織女） | 把機器做得像人，也把人做得像機器：無機質的皮膚、型號與序號 | 被擺放、被操作、不必是一個人 | 零七 |
| **零件宅**（拆體客） | 對拆下來的東西比對人有興趣。電器街式的零件攤，為了一顆初版晶片吵半天 | 那一件 | 典藏室 |

- 鉻娘子看不起人偶派（「妳們是擺著看的」），人偶派看不起零件宅（「你們連整體都沒有」），零件宅賣東西給兩邊。
- 三者的共同敵人是素體教。

### 10.6 流動

在蜜腺的型錄裡，身體是一份可以重新調配的配方，性別是其中一欄。

- **轉換療程**：賀爾蒙與生體件，幾週到幾個月。可以轉過去，也可以再轉回來；不便宜，但在玻璃岸，它和換髮色差不多平常。
- **男娘**是其中最顯眼的一支：有自己的店、自己的偶像、自己的同人圈。
- **為什麼還是次文化**：冠冕區當它是有錢人的消遣，蜂巢與鏽帶當它是奢侈。真正普及的是內海——在那裡每個人的化身都可以自由變化（[CHARACTER](../systems/CHARACTER.md) 1.1 節），不需要蜜腺。蜜腺賣的是「在現實裡也可以」。
- 牆外的原型是「都可以」。

### 10.7 野性與狂歡

- **野良**：重度獸化、又沒有錢或不想被人養的人。獸耳在主流裡是時尚；在野良身上是身分。沒有主人的項圈是她們的記號——戴著，但環上什麼都沒扣。住在蜂巢的屋頂與地下層，互相照顧毛與耳朵。牆外的原型是「嗷」。
- **祭典組**：只為了熱鬧的派對幫。浴衣、泡泡、螢光漆、面具，一整條街一起。她們沒有地盤，只有行程表；場子與酒是蜜糖會的。牆外的原型是「大家」。

### 10.8 魔法少女

**鎮溺隊**是處理溺感者的特警（[WORLD](WORLD.md) 第 4 節），文化上是另一回事。

- **樣子**：變身式的制式裝備——平常收在手環或胸針裡，出勤時展開成護甲與武器；每個人有花俏的代號與代表色；成對出勤。都是成年的特警。
- **為什麼是這個樣子**：最早是公關部門的主意，讓一支專門對付「歡愉的信徒」的部隊看起來不那麼可怕。後來隊員自己接了過去：這份工作需要一個理由，「愛與正義」至少是一個。
- **代價**：她們的工作是靠近溺感者，把人「淨化」回來——也就是**每一次出勤都離那條線更近**。隊員的沉溺普遍偏高；隊上最資深的往往也是最危險的。退役的方式只有兩種：轉文職，或者被自己的搭檔處理。
- 城裡的小孩喜歡她們的周邊；牆語者說她們只是還沒承認的同類。
- 牆外的原型是「愛與正義」。

## 11. 小眾文化

### 11.1 反橋的兩支：女騎士與巫女

黑泉與素體教站在這座城市的對面。

- **女騎士**（黑泉）：私人部隊幾乎全是女性，穿厚重的動力裝甲、手持電漿劍。沒有橋、不被駭、不吃神經武器，站在霓虹底下像走錯了時代。她們有誓詞、有階級、有授劍的儀式。
- **修女**（黑泉）：文職與教務的樣子。端莊、保守、長裙與禮拜服。公開反放縱——也因此是城裡壓得最緊、最渴的一群。
- **巫女**（素體教）：白衣緋袴式的素色裝束、沒有改造的身體、不化妝。儀式是祓除與清淨，要祓掉的「髒東西」就是橋。脫離契約的人常往她們的傳教所躲。
- **兩者的關係**：黑泉是素體教的金主。女騎士在前面擋，巫女在後面祓。
- **為什麼是小眾**：這座城市的一切都跑在橋上。沒有橋的人不能用耳語、不能進內海、很多門打不開。選擇這條路的人，是把自己關在外面。
- 牆外的原型是「寧死不屈」（女騎士）、「神父不在」（修女）、「請低頭」（巫女）。

### 11.2 溺感

**牆語者**是沉溺超過那條線的人組成的教團（[CORE_RULES](../systems/CORE_RULES.md) 4.3 節）。

- 她們沒有統一的樣子：**每個人照著自己聽見的那一個流竄 AI 打扮**。聽見「媽咪」的和聽見「荊棘小姐」的站在一起，像兩個不同的教派——她們自己不覺得有差別。
- 教義只有一條：牆外的不是怪物，是我們自己養大的東西，該讓牠們回來。
- 對外，她們是鎮溺隊與貞網局要抓的人。對彼此，她們是城裡最不設防的一群：溺感者接納溺感者。
- 沉溺還沒到的人也碰得到她們：地下層的聖堂、沉船帶的集會、替流竄 AI 傳話的人。

### 11.3 契約與戒律

兩種關於「誰說了算」的文化，都藏在制度裡。

- **契約**（伊甸園）：人可以被擁有，而且有價目表。項圈、所有權證明、登記庫裡的一行字。契約人之間有自己的禮節與黑話；持約人之間也是。它完全合法，但沒有人在餐桌上談它。牆外的原型是「陛下」與「您的」。
- **戒律**（貞網局）：「未經許可不得」。探員的橋上有局裡發的鎖：能看什麼、能感覺什麼、下班後能做什麼，都要申請。局裡的人把這套當成紀律，也當成榮譽；局外的人只看得到制服。牆外的原型是「鎖匠」。

### 11.4 城外與傳說

- **荒地**（野薔薇）：城外的車族聯盟。皮革、防風鏡、曬痕、車隊就是一家人。她們進城做生意，但不留下來過夜。城裡的人覺得她們髒，她們覺得城裡的人被關著。牆外的原型是「到哪算哪」。
- **吉祥物**：不是組織，是街上對「穿著玩偶裝、再也不脫下來的人」的稱呼（[GANGS](GANGS.md) 第 3 節）。有人把它當成一種嚮往：消失在一個永遠在笑的殼裡。這種人很少，但每個區都聽說過一個。

## 13. 寫作的界線

- **所有角色都是成年人**（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 第 9 節）。「萌」「可愛」在這裡是成年人的風格與職業形象，不是年齡。
- **不寫校園**。這個世界的「制服」指職業制服：女僕、執事、護理、警備、偶像的打歌服。
- 偶像出道年齡下限 18；人偶、歡場從業者同樣。這是世界內的法規，也是引擎生成 NPC 時的規則。
