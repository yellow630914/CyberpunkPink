> 來源：ElondiaRPG 的勢力聲望、衛兵警戒與通緝（`security.json` 的 `alert`、`reputation_bands`）。預定資料：`data/world/factions.json`（名單與關係表）、`data/rules/standing.json`（好感與敵對值的分段、來源、消退）。數值都是初稿。

這份寫三件事：**誰和誰是什麼關係**、**好感與敵對值怎麼漲怎麼跌、到了哪裡會發生什麼**、以及**之後如果要讓勢力連動，規則可能長什麼樣**（第 9 節，草案，現在不做）。

已經定案、這裡只引用的：每個勢力各有一條好感與一條敵對值，**不合併**；主從只是世界裡的關係；勢力之間的自動連動**先不做**（[CORE_RULES](../systems/CORE_RULES.md) 第 8 節、[ROADMAP](../plan/ROADMAP.md) 第 1 節第 12、13 項）。

## 2. 關係的種類

| 記號 | 關係 | 意思 | 現在在系統裡做什麼 |
|---|---|---|---|
| 盟 | **盟友** | 立場相同，會互相幫忙 | 委託的生成：盟友不會雇你去打盟友；AI 敘事的口吻 |
| 生 | **生意** | 有往來，沒有交情 | 委託的生成：生意夥伴的貨、場地會出現在對方的委託裡 |
| 競 | **競爭** | 搶同一塊餅，不到開打 | 委託的生成：競爭對手是最常見的「委託人 × 目標」組合 |
| 敵 | **敵對** | 公開或實質上在打 | 同上，而且委託可以要求 `lethal`；街頭事件裡兩邊的人碰到會動手 |
| 主／從 | **主從** | 次要勢力活在主要勢力的影子裡（第 4 節）。表上「主」是那一列罩著那一欄 | 第 4 節 |
| 金／受 | **金主** | 出錢的一方與拿錢的一方。「金」是那一列出錢給那一欄 | 委託的生成：查金主是踩點的一項未知 |
| · | 沒有特別的關係 | | |

- 關係是**一列對一欄**讀的：「緋櫻」那一列、「女僕公會」那一欄寫「主」，意思是緋櫻罩著女僕公會；反過來讀是「從」。
- 一格只寫一種關係，寫的是**最主要的那一種**。複雜的另附註。
- 標了 ◇ 的格子是這份文件補的，[CORPORATIONS](CORPORATIONS.md) 與 [GANGS](GANGS.md) 沒有寫過（第 10 節）。

## 4. 主從的作用

主從**不是數值的合併**。惹了次要勢力，漲的是它自己的敵對值（[GANGS](GANGS.md) 1.1 節）。它現在只做這幾件事：

| 作用 | 規則 |
|---|---|
| **委託的後台** | 次要勢力當委託人時，有 30% 的機率真正出錢的是上面那一家。踩點的「查雇主」可以揭開；背刺檢查讀這個 |
| **增援表** | 在次要勢力的地盤或設施打到增援時，增援有 20% 抽到上面那一家的人（孤星連叫來的可能是星旗的皮卡；[ENEMIES](../systems/ENEMIES.md) 第 13 節）。這是遭遇的組成，不動敵對值 |
| **貨源** | 次要勢力的店賣上面那一家的牌子（女僕公會的制服是緋櫻規格、孤星連手上是星旗的零件） |
| **AI 敘事** | 主從寫進世界書；角色說話時知道誰罩著誰 |
| **特殊任務** | 主從可以在劇情裡改變：女僕公會的獨立派、星旗重新徵召孤星連、黑泉斷掉素體教的錢、夜宴社和萬華鏡翻臉。改變後關係表跟著改 |

- 甜心食品沒有上家，也沒有下家。
- **好感與敵對值一家一組**：二十九條好感、二十九條敵對值。畫面上只列出目前不是 0 的那幾家（[CORE_RULES](../systems/CORE_RULES.md) 第 8 節）。

## 5. 好感

這個勢力多願意幫你。0～100，起始 10；出身對應的勢力起始 25（第 10 節）。**好感不會自己消退**——它是做出來的，也是做砸的。

### 5.1 分段

價格的倍率沿用 ElondiaRPG 的 `reputation_bands`（依聲望調整買價、賣價與罰金）。

| 好感 | 叫法 | 效果 |
|---|---|---|
| 0～19 | **外人** | 照常；在它的地盤上被盤查、被多看兩眼 |
| 20～39 | **認得** | 它的店賣你 I～II 級的貨；對峙時它的人先開口談 |
| 40～59 | **友好** | 買價 −10%、賣價 +5%；它的地盤不盤查你；主要勢力的特殊任務第一段開放 |
| 60～79 | **信任** | 買價 −20%、賣價 +10%；III 級貨；借人（名冊上多一個它的人）、借地方（安全屋）；它罩的中間人肯見你 |
| 80～100 | **自己人** | IV 級貨；它的敵對值事件改成先傳話（5.3 節）；特殊任務的終段；被追的時候它的地盤可以躲 |

### 5.2 怎麼漲、怎麼跌

| 來源 | 好感 |
|---|---|
| 完成它當委託人的委託 | +3；評價最高、附帶條件全達成 +5 |
| 它的特殊任務的一段 | +5～10 |
| 救它的人；制伏它的人之後放走 | +1～2，每場最多 +4 |
| 還它的人情；它欠你人情時不討 | +2（[FIXER](../systems/FIXER.md) 第 8 節） |
| 在它的店消費、穿它的風格在它的地盤社交 | +1，每週最多 +2 |
| 送禮（它的分支喜歡的東西；真的食物通用） | +1～3，每週一次 |
| **對它動手，而且它知道是你** | −5（竊密、抹黑）～ −15（殺人、破壞） |
| 殺它的人（它知道） | −2／人，每場最多 −10 |
| 背刺它（收尾時翻臉的是你） | −20 |
| 拒絕它來討的人情 | −5 |
| 壞了它的規矩 | −10（各勢力的規矩見第 7 節） |

- **「它知道是你」怎麼判**：這件事讓它的敵對值上升了（被目擊、被追蹤到、被爆料指名），好感才扣。乾淨的活不扣好感——它只知道出事了，不知道是誰。
- 委託人與目標是不同勢力時，**只動這兩家**：委託人的好感加，目標的敵對值加（以及它知道時好感扣）。不會因為關係表牽動第三家（第 9 節）。

### 5.3 好感與敵對值同時高

兩條分開記，可以同時高（[CORE_RULES](../systems/CORE_RULES.md) 第 8 節）。組合起來的態度：

| 好感 | 敵對值 | 它怎麼對你 |
|---|---|---|
| 低 | 低 | 外人 |
| 高（≥ 60） | 低（< 40） | 自己人 |
| 低（< 40） | 高（≥ 40） | 敵人：照敵對值的分段（6.1 節） |
| 高（≥ 60） | 高（≥ 40） | **欣賞但要算帳**：敵對值事件第一次改成「傳話」——它派人來談，開一件**抵帳委託**（做完敵對值 −30，不給錢）。拒絕或做砸，之後照敵對值的分段 |

## 6. 敵對值

這個勢力多想找你麻煩。0～100，起始 0，**會消退**。骨架沿用 ElondiaRPG 的衛兵警戒與通緝；差別是依勢力分開記（[CORE_RULES](../systems/CORE_RULES.md) 第 8 節）。

### 6.1 分段

| 敵對值 | 叫法 | 效果 |
|---|---|---|
| 0～19 | **沒注意** | — |
| 20～39 | **記名** | 它的檢查哨與盤查認得你（掃橋時你的偽裝 DC +2）；它的地盤物價 +10%；街頭事件多「被盯上」 |
| 40～59 | **找麻煩** | 每週一次追兵事件（它的地盤或相鄰的橋接區）；以它為目標的委託，遭遇預算 +1；它的要地不讓你進 |
| 60～79 | **追捕** | 它的人看到你直接動手，不對峙；以它為目標的委託，警戒起始 +20；據點可能出現上門事件（[FIXER](../systems/FIXER.md) 第 9 節） |
| 80～99 | **懸賞** | 其他邊緣行者接到抓你的委託（[ENEMIES](../systems/ENEMIES.md) 12.4 節）；它罩的中間人不接你；上門事件每週 |
| 100 | **通緝** | 全城懸賞；它的檢查哨與它管的交通一律攔你。清掉要一個大人情、一條特殊任務，或一大筆錢（先降到 79） |

### 6.2 怎麼漲

| 來源 | 敵對值 |
|---|---|
| 在它的地盤、或對它的人犯案，被目擊 | +3～10（看事情多大） |
| 殺它的人 | +5／人；殺過載倒地的人 +10（[LIFE](LIFE.md) 第 9 節的行規） |
| 拆它的人的義體 | +5 |
| 以它為目標的委託，用了現實面 | +5～15（[COMMISSIONS](../systems/COMMISSIONS.md) 第 8 節） |
| 竄網被追蹤到「定位」 | 子網所屬的企業 ＋ 追蹤度 ÷ 10；夜鶯與貞網局各另 +2（[NETRUNNING](../systems/NETRUNNING.md) 第 5 節） |
| 爆料、抹黑指名它 | +5～20（依輿論面的聲量） |
| 偷它的東西、劫它的貨、救走它要的人 | +3～10 |
| 沉溺 60 以上 | 鎮溺隊與貞網局每週 +1；80 以上 +2（[CORE_RULES](../systems/CORE_RULES.md) 4.3 節） |

- **區的修正**（[DISTRICTS](DISTRICTS.md) 第 2 節）：冠冕區 ×2；四十二番街 ×0.5（伊甸園與蜜糖會除外）；舊港的企業與市警不加，幫派照加。
- 敵對值記在**橋 ID** 上。假身分（[LIFE](LIFE.md) 2.3 節）讓檢查哨認不出你，但記名以上的勢力記得你的臉：用假身分時「記名」的效果無效，其他照舊。

### 6.3 怎麼降

| 方式 | 敵對值 |
|---|---|
| 時間 | 每週 −5；那一週沒有任何新的敵對值 −10 |
| 躲風頭 | 一週不接委託、不進它的地盤：再 −10 |
| 收買 | 錢：每降 1 點要 50 C$ × （敵對值 ÷ 20，進位），一次最多 −20。市警、胭脂堂、拆體客、鉻娘子、野薔薇收錢；貞網局、鎮溺隊、素體教、特攻姬不收；其他看找的是誰 |
| 人情 | 中的 −15，大的 −30 |
| 抵帳委託 | −30（5.3 節） |
| 交還東西、交出人 | −10～−30，看是什麼 |

- **敵對值的下限**：有些事讓敵對值降不下去——越過粉牆的人，貞網局的敵對值永遠 ≥ 30（[NETRUNNING](../systems/NETRUNNING.md) 第 7 節）；沉溺 100 以上的人，鎮溺隊的敵對值 ≥ 40；被戰敗事件鎖過橋、隔離過的人另有下限（[ENEMIES](../systems/ENEMIES.md) 第 6 節）。

## 9. 勢力連動（草案，目前不做）

> **這一節是草案。** 現階段不做連動：每個勢力各算各的，連動用事件與委託的後果**手動寫**（[CORE_RULES](../systems/CORE_RULES.md) 第 8 節）。這裡先寫下之後要做時可能的規則，等名單定了、看複雜度再決定。

### 9.1 三個方案

| 方案 | 做什麼 | 好處 | 壞處 |
|---|---|---|---|
| **A 不連動**（現在） | 關係表只用在生成委託、事件與 AI 敘事 | 透明、好調 | 世界顯得各自為政；要靠手寫的後果撐 |
| **B 只連主從** | 次要勢力的敵對值變化，按比例傳到上家 | 規則少；對應「惹了小的、驚動大的」 | 主從以外的關係沒有作用 |
| **C 一跳連動** | 沿著關係表傳一跳，依關係種類給係數 | 世界有反應 | 難預測；需要在報告裡講清楚 |

### 9.2 方案 C 的係數（草稿）

一件事讓 A 的好感或敵對值變了 X，和 A 有關係的 B 跟著變：

| A 和 B 的關係 | A 的好感 +X 時，B | A 的敵對值 +X 時，B |
|---|---|---|
| 盟友 | 好感 +0.3X | 敵對值 +0.3X |
| A 是 B 的上家（主） | 好感 +0.2X | 敵對值 +0.2X |
| A 是 B 的下家（從） | 好感 +0.3X | 敵對值 +0.5X |
| A 是 B 的金主（金） | — | 敵對值 +0.2X |
| A 拿 B 的錢（受） | — | 敵對值 +0.3X |
| 生意 | 好感 +0.1X | 敵對值 +0.1X |
| 競爭 | 好感 −0.1X | — |
| 敵對 | 敵對值 +0.2X（只在 A 的好感來自對 B 不利的事時） | 好感 +0.2X（敵人的敵人） |

- **只傳一跳**：B 因為連動而變的量，不再往下傳。
- **門檻與上限**：X 小於 5 不傳；每次傳出去的量最多 5；每個勢力每週因連動變動的總量最多 15。小數捨去。
- **看得見**：收尾報告列出「牽動」：誰、多少、因為哪一條關係。畫面上的關係表可以點開看。
- **例**：從伊甸園救一名契約人送到糖罐。蜜糖會好感 +5、伊甸園敵對值 +10（直接）。連動：祭典組好感 +1（蜜糖會是它的上家，0.2 × 5）；伊甸園是蜜糖會的敵人——伊甸園敵對值已經直接加了，不重複；天使急救、黑泉、萬華鏡、緋櫻、蜜腺與伊甸園是生意，敵對值各 +1（0.1 × 10）。
- 這個例子說明了方案 C 的問題：一件小事碰到六家。所以如果要做，比較可能從**方案 B** 開始。
