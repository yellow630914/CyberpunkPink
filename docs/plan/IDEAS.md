## 2. 其他

- 勢力連動（幫了這個、那個不高興）：三個方案——A 不連動（現在的做法）、B 只連主從（次要勢力的敵對值按比例傳到上家）、C 沿著關係表傳一跳、依關係種類給係數；要做的話先從 B 開始。目前不做。
- 住處的出租：ElondiaRPG 的點子庫裡也有，目前不做。
- 真正的競拍系統：白槌的拍賣有個性的對手（每個競標者有自己的脾氣、記仇、愛搶特定的拍品）、暗標（一輪只出一次價、同時開價）、拍到一半被搶走（有人砸大錢直接買斷、有人舉報拍品而中止）、玩家寄拍自己的東西。M4 先做簡單版：每週一場、4～6 件、預算與興趣決定加不加價、玩家加價或跟或退出（[LEWD_SYSTEM](../systems/LEWD_SYSTEM.md) 6.2 節）。

## 3. Agent 模式的兩個提議

這兩個是 ElondiaRPG 舊版任務表裡的 Agent 任務，不在 [AI_TASKS](AI_TASKS.md) 6.2 節的五個掛點裡，目前不做。

| 提議 | 想法 | 要做的話得先解決 |
|---|---|---|
| 提議進成人場景 | Agent 在一般的行動之後，主動提議這件事可以走到成人場景 | 現在成人場景只由 `scene_gate` 判定。要做的話得另寫驗證與每天的上限，而且只能新增一個情況讓玩家選，不能改已經結算的行動 |
| 提議一件委託 | Agent 主動替中間人提一件委託，不經過接委託的那條鏈 | 現在委託只由 `commission_gen` 照骨架生成。要做的話得讓提議走同一套骨架與驗證，並另訂每天的上限 |

兩個都要照 AI_TASKS 第 1 節第 11 條：遊戲不等 Agent，Agent 只新增情況、新增報酬，不修改已經發生的事。
