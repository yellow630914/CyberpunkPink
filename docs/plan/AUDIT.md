# 全書一致性檢查（2026-11-18）

> 進 L4、L5 之前做的一次檢查。五路同時讀完四十五份文件，對照「已確認的決定」找出矛盾、還沒定的框架細節，並判斷現有的內容符不符合框架。這份只記結論與待辦，沒有改任何設計文件。

## 1. 結論

- **有矛盾，而且不少。** 五路共回報約兩百七十條，扣掉重複大約一百五十件事。
- **其中八成是「舊文件沒跟上後來的決定」**：規則本身沒有衝突，只是早寫的段落還在講舊的系統。這一類不需要再做決定，照已確認的規則改掉就好。
- **約二十件是真的要決定的事**：兩份文件各說各的，或新規則留下了沒人填的洞（第 2 節）。
- **框架還缺一塊：資料的格式。** 規則都定了，但技能、夜課、體位、事件裡的成人場景、戰敗事件、輿論對手這些東西「一筆資料長什麼樣子」多半還沒寫。現在直接生成內容，每一批的格式會不一樣（第 3 節）。
- **L4 現有的內容大部分不符合框架**，文件自己也都標了「素材」。技能、敵人的數值、零件與設計圖、流竄 AI 的名單要整批重寫；街區與要地、事件的例子、區域狀態、打工表、勢力的預設表小修就能用（第 5 節）。
- **L5 的三份文件**：畫面要重寫一半，提示詞與 AI 任務中修（第 6 節）。

## 3. 還沒定的框架細節：資料的格式

規則有了，但下面這些「一筆資料長什麼樣子」還沒寫。這是生成 L4 之前一定要補的，不然每一批內容的欄位會對不起來。

| 東西 | 缺什麼 |
|---|---|
| **技能** | 前層與後層的欄位；預備與日常的效果寫在哪；輿論的效果怎麼寫成新棋盤的欄位（聲量、風向、佔格、設防、扣公關點、抽牌）；共鳴的格式；份量（幾格）的欄位 |
| **夜課的技能、體位、成人道具** | 整份都沒有資料樣本：用哪個部位、接對方哪個部位、持續的數值、對主動權的影響、能用在哪些體位、人數、倍率、誰是上位 |
| **事件裡的成人場景** | 現在只有「會不會進場景」一個欄位。缺：這一場的性質、目的、參與者與分圈、起始的體位。事件的條件裡也沒有主角的體型 |
| **戰敗事件** | 沒有格式：是不是用事件模板寫、「照主角體型兩版」怎麼標、三種體型怎麼對到兩版 |
| **敵人** | 內海用的欄位（RAM、防護、構裝）；輿論對手的格式（強度、先搶哪些格子、行動的優先順序、開場位置）；武器的彈匣單位與遮蔽倍率 |
| **裝備** | 武器與護甲的設計圖沒有樣本；零件沒有份量、重量、大小、合法性的欄位 |
| **義體部位對成人場景的部位** | 義體有九個部位，場景有七個，沒有對應表；零件也沒有「多出哪個部位、敏感的修正」的欄位 |
| **NPC** | 特質、性經歷、夜課技能三樣還沒進資料欄位；性別的值沒列男娘、TS、扶他 |
| **委託副本** | 資料樣本還是舊的；每個階段的分支、遭遇、連動、直播目標沒有格式；生成的公式沒有階段結構 |
| **等級的欄位名** | 有的叫 `grade`，有的叫 `tier`，而 `tier` 在技能裡指的是階。統一成等級用 `grade` |

另外有幾樣規則上的小洞：同步檔位在加速義體上看哪一項基本功、敏感度的門檻、機甲啟動要多少同步；內海的傷害怎麼加魅力（槍沒有屬性加值）；脫離戰鬥擲的是什麼。
