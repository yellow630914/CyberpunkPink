## 1.1 從附件得到的三個想法（還沒寫進規則）

附件是一份桌上角色扮演遊戲的入門規則。它的規則本身（十屬性、1d10）不照用——我們的骨架已經定在 ElondiaRPG 的 d20 上——但有三個做法值得借，等世界觀告一段落再決定：

| 想法 | 怎麼用在這裡 |
|---|---|
| **生命軌跡**：建角時用幾張表擲出出身、家庭變故、朋友、仇人、失敗的戀情、人生目標 | 建角流程的一部分。擲出來的朋友與仇人直接變成名冊上的人與帶熱度的 NPC；AI 敘事與案子生成會回頭用這些人 |
| **對峙**：動手之前先比氣勢，輸的人退讓，或者帶著懲罰硬上 | 戰鬥前的一步：膽識＋威嚇的對抗。贏了可以不打就過，或讓對方開場吃懲罰。很合「態度至上」 |
| **行頭勝於實力** | 已經部分體現在風格值；可以再往前一步，讓風格直接影響街頭信譽的成長 |

## 2. 還沒寫的文件

核心規則定案後再寫，順序大致如下：

2. `NPC_SYSTEM`：固定 NPC（中間人、各勢力的臉）、生成 NPC、關係與記憶。大部分沿用。
3. `ITEMS`：武器、護甲、服裝、義體、程式、藥的目錄。
4. `ENEMIES`：各勢力的敵人、蕾絲、機甲。
5. `STORY_QUESTS`：主線骨架（牆、契約、萬華鏡三條）與各路數的任務線。
6. `EVENTS`、`TRADE`、`PROMPTS`、`SAVES`、`CONTENT_EDITOR`：和 ElondiaRPG 差異小，照搬後改。
7. 世界書（`data/worldbook/`）：把 [WORLD](../WORLD.md) 拆成條目。

## 3. 實作階段

每個階段結束時都要是能玩的。

| 階段 | 內容 | 完成的樣子 |
|---|---|---|
| **M0 地基** | 專案骨架、報告與存檔、AI 管線、主動行動、六屬性與技能、檢定 | 可以建角，在一個空房間裡做自由行動並看到敘事 |
| **M1 槍戰** | 三條軌、行動點戰鬥、站位、護甲、武器、基本義體、戰敗事件 | 蜂巢的一張地圖，打得起來 |
| **M2 一案一團** | 中間人、案子的四拍、踩點與未知清單、警戒、街頭信譽與熱度、每週帳單 | 可以連續接生成的案子、付房租 |
| **M3 竄網** | RAM、快駭、深潛、子網、蕾絲、追蹤度、控制節點 | 同一件案子可以用竄網解 |
| **M4 身體** | 完整的義體、人性與溺感、授權鎖、惡意韌體、橋參數、調校、成人場景、場所 | 改造與成人向內容完整 |
| **M5 經營** | 媒體（素材、發布、直播）、盤口、名冊、派工、人情、據點、契約 | 媒體與掮客兩條路數可玩 |
| **M6 終局** | 粉牆與牆外、女武神機甲、主線 | 主線可以破關 |
| **M7 開放** | 內容編輯器、世界包、手機版 | 和 ElondiaRPG 同等的自訂能力 |

排序的理由：M1～M3 把「戰鬥、竄網、案子」三根柱子立起來；成人向與媒體依賴三條軌與案子的流程，所以排在後面，但它們用的數值（感載、橋參數）從 M1 就在。
