## 2. 還沒用上的想法

附件（一份桌上角色扮演遊戲的入門規則）的規則本身不照用——骨架已經定在 ElondiaRPG 的 d20 上——但有三個做法值得借：

| 想法 | 怎麼用在這裡 |
|---|---|
| **生命軌跡**：建角時用幾張表擲出出身、家庭變故、朋友、仇人、失敗的戀情、人生目標 | 建角流程的一部分。擲出來的朋友與仇人直接變成名冊上的人與帶熱度的 NPC |
| **對峙**：動手之前先比氣勢，輸的人退讓，或者帶著懲罰硬上 | 戰鬥前的一步。ElondiaRPG 已經有對峙的模組可以用（[MIGRATION](MIGRATION.md) C 組） |
| **行頭勝於實力** | 已經部分體現在風格；可以再往前一步，讓風格直接影響街頭信譽的成長 |

## 4. 實作階段

每個階段結束時都要是能玩的。

| 階段 | 內容 | 完成的樣子 |
|---|---|---|
| **M0 地基** | 專案骨架、報告與存檔、AI 管線、主動行動、六屬性與基本功、檢定 | 可以建角，在一個空房間裡做自由行動並看到敘事 |
| **M1 槍戰** | 三條軌、行動點戰鬥、四格縱深的站位、護甲、武器（先用現成的成品，設計圖與零件的資料格式一開始就照 [CRAFTING](../gear/CRAFTING.md)）、基本義體、戰敗事件 | 蜂巢的一張地圖，打得起來 |
| **M2 一案一團** | 中間人、委託的四拍、踩點與未知清單、**委託副本的現實面**（模板地圖、里程碑、領域指標）、警戒、街頭信譽與熱度、每週帳單 | 可以連續接生成的委託、付房租 |
| **M3 網路** | 內海的公共區、化身與構裝、八條路數的網路面、RAM、快駭、蕾絲、追蹤度、控制節點、隨機生成（迷宮館、沉船帶）、**副本的內海面與連動** | 全隊可以一起潛入；同一件委託可以走現實、走內海、或混搭 |
| **M4 身體** | 完整的義體、**設計圖與零件的組裝**（義體、武器、護甲；機械與生體）、邊緣橋的型號與技能容量、沉溺與溺感、授權鎖、惡意韌體、橋參數、調校、成人場景、場所 | 改造與成人向內容完整；可以自己配橋 |
| **M5 經營** | **輿論戰**（編輯台的戰役層與經營層）、**副本的輿論面**、直播、偶像、盤口、名冊、派工、人情、據點、契約 | 媒體人、偶像、掮客可玩；三個戰場齊全 |
| **M6 終局** | 粉牆與牆外、女武神機甲、主線 | 主線可以破關 |
| **M7 開放** | 內容編輯器、世界包、手機版 | 和 ElondiaRPG 同等的自訂能力 |

排序的理由：M1～M3 把「戰鬥、竄網、委託」三根柱子立起來；成人向與媒體依賴三條軌與委託的流程，所以排在後面，但它們用的數值（感載、橋參數）從 M1 就在。
