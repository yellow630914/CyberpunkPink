# 媒體

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[CORE_RULES](CORE_RULES.md)（表演、調查、熱度、公信力）、[LEWD_SYSTEM](LEWD_SYSTEM.md)（豔名、聚光調校）。被依賴：[FIXER](FIXER.md)（案子的收尾、派工）。
> 來源：新做。骨架借自 ElondiaRPG 的情報與傳聞系統（反過來用：玩家製造傳聞）、物品與交易（素材是物品）。預定資料：`data/rules/media.json`、`footage_tags.json`。數值都是初稿。

在緋灣，新聞、娛樂、色情是同一個平台上的同一種東西：感官帶。觀眾不是「看」到一件事，而是「感覺」到它。所以誰有帶子，誰就定義發生了什麼。

媒體玩法的核心是一個問題：**你手上有一段素材，要拿它做什麼？**

## 1. 流程

```
拍（案子進行中、生活中）→ 素材（物品）→ 剪（選角度）→ 處置：發布／賣斷／勒索／留著
                                                          └─▶ 觀眾、錢、熱度、世界的變化
```

## 2. 素材

行囊裡的一種物品。任何有錄影義眼或攝影機的人都能拍，主播拍得更好。

| 屬性 | 說明 |
|---|---|
| **標籤** | 這段拍到了什麼：`戰鬥`、`醜聞`、`罪證`、`親密`、`名人`、`機甲`、`牆外`、`死亡`…… 加上涉及的勢力與人 |
| **品質** 1～5 | 拍攝者的表演或調查檢定、敏感度（感官的鮮明程度）、器材。主播的「聚光燈」每階 +上限 |
| **真實性** | 真的、剪過的、偽造的。偽造要技術檢定，被拆穿的機率依公信力與對方的調查 |
| **獨家** | 只有你有嗎。別人也拍到的話價值隨時間掉得很快 |
| **期限** | 新聞會舊。多數素材的價值每天 −10%～20% |

- 引擎在案子的報告裡自動記下「這一幕有什麼可拍的」（`changes.footage` 的候選），條件是隊伍裡有人在錄。**錄影本身有代價**：義眼錄影時隱匿 −1，而且素材是證據——被捕時它也證明你在場。
- 素材可以偷（從別人的記憶庫、從媒體公司的子網）、可以買、可以委託別人拍。

## 3. 剪

發布前選一個**角度**，決定同一段素材變成什麼：

| 角度 | 效果傾向 |
|---|---|
| 揭弊 | 公信力 +，目標勢力的聲望大跌，目標勢力的熱度大增 |
| 煽情 | 觀眾大增，公信力 −，豔名 +（如果你在畫面裡） |
| 英雄 | 街頭信譽 +，把自己或隊友塑造成傳說 |
| 抹黑 | 把責任導向另一個勢力（需要技術檢定；被拆穿時公信力重挫） |
| 匿名投放 | 效果打折，但熱度不找上你 |

AI 開著時，剪輯是一次自由行動：玩家用文字描述想怎麼講這個故事，AI 判定角度與成功程度，效果仍由程式夾在上表的清單與上限內。

## 4. 兩個數字：觀眾與公信力

| | 觀眾 | 公信力 |
|---|---|---|
| 是什麼 | 你的頻道有多少人在看 | 他們信不信 |
| 怎麼漲 | 煽情、親密、名人、直播、豔名 | 揭弊、查證過的罪證、被事後證實 |
| 怎麼掉 | 太久沒發東西 | 偽造被拆穿、抹黑、太多煽情 |
| 換成什麼 | 廣告與打賞（每週收入）、直播的聲量 | 爆料的**效力**：能不能真的撼動一個勢力 |

這是媒體線的雙面效應：**流量與可信是兩條會互相扯的路**。全走流量會變成有錢但沒人當真的豔星；全走公信力會變成窮但能扳倒企業的記者。兩種都是可行的玩法，也可以想辦法兩者兼顧（最難）。

## 5. 發布的效果

一次發布是一份 `broadcast` 報告。效果由「品質 × 觀眾 × 公信力（依角度）」算出一個**衝擊值**，再換成封閉清單裡的後果：

- **勢力聲望與熱度**：被爆料的勢力在市民間的聲望下降，對你的熱度上升。
- **區域狀態**：衝擊夠大時改變一個區的狀態幾天——保全增加或撤離、物價波動、抗議（街頭事件表換一張）、某間店關門。
- **案子的條件**：下一件和那個勢力有關的案子，警戒起始值、報酬、可用的入口會變。把爆料當成另一件案子的踩點，是媒體路數的高階玩法。
- **人**：被拍到的 NPC 的態度、處境改變。可以毀掉一個人，也可以救一個人（讓全城都看著，企業就不方便讓他消失）。
- **錢**：廣告分潤，或賣斷給萬華鏡（拿一筆錢，失去怎麼剪的權力）。

**不發布也是選項：**

- **勒索**：拿給當事人看。一次談判（沿用 ElondiaRPG 的談判系統），換錢、人情、或讓步。之後對方的熱度有個下限。
- **留著**：當保命符。持有某勢力的重大罪證時，被那個勢力俘虜的戰敗事件多一條「你們敢動我，帶子就會自己發出去」的分支。

## 6. 直播

案子進行中開直播。這是媒體玩法在戰鬥與潛入中的即時版本。

- 開播後有一個**聲量**條（0～100），起始值依觀眾數與所在區的豔名。精彩的事（要害命中、過載、機甲出場、險些被發現）讓它上升；冷場下降。
- **聲量的好處**：
  - 每 20 點，全隊每場戰鬥多一次重擲（「觀眾在看」）。
  - 打賞：案子結束時依聲量峰值給一筆錢。
  - 有「聚光」調校的人直接吃加成。
  - 聲量高時，企業保全動手會有顧忌：某些致命手段被上層叫停（黑蕾絲不啟動、不准開實彈），因為全城在看。
- **聲量的代價**：
  - 敵人也在看。隱匿不可能維持；增援來得更快；對方的潛網者可以從直播訊號反查位置（追蹤度持續上升）。
  - 所有熱度的增加 ×1.5。
  - 素材不再是獨家。
- 適合強攻與公開場合的案子，不適合潛入。**直播把一件案子從「不被發現」的遊戲變成「被所有人看著做完」的遊戲。**

## 7. 主播在隊伍裡做什麼

和潛網者同樣的原則：不能是一個人的小遊戲。

- **踩點**：以採訪的名義進入場所、接觸目標；用爆料換情報。調查與表演在這個階段是主力。
- **行動中**：錄影；直播；用假消息調開保全（降低一個區的警戒，或延後增援）；在社交場合當吸引目光的那個人，讓隊友做事。
- **收尾**：把這件案子變成故事。同一件案子，發不發、怎麼剪，決定街頭信譽是 +2 還是 +10，熱度是藏住了還是爆了。
- 沒有主播的隊伍也能拍素材，只是品質低、沒有直播；也可以把素材賣給 NPC 記者。

## 8. 萬華鏡

- 平台是萬華鏡的。它抽成、它可以下架、它的演算法決定誰被看到。
- 獨立頻道在它的容忍範圍內活著。爆它的料或它金主的料，會遇到**降流**（衝擊值打折）與**封鎖**。對策：走地下轉播站（牆語者與車族經營，觀眾少但封不掉）、或駭進它的子網把東西推上首頁（[NETRUNNING](NETRUNNING.md)）。
- 媒體線的主線衝突是：你能不能在一個由它定義真實的城市，讓一件它不想讓人知道的事變成真的。
