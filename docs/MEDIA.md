# 媒體

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[CORE_RULES](CORE_RULES.md)（表演、調查、熱度、公信力）、[LEWD_SYSTEM](LEWD_SYSTEM.md)（豔名、聚光調校）。被依賴：[FIXER](FIXER.md)（案子的收尾、派工）。
> 來源：新做。骨架借自 ElondiaRPG 的情報與傳聞系統（反過來用：玩家製造傳聞）、物品與交易（素材是物品）。預定資料：`data/rules/media.json`、`footage_tags.json`。數值都是初稿。

第 1～8 節是媒體的基礎：素材、觀眾、公信力、直播；主播的主要玩法——輿論戰的 SLG——在 [OPINION](OPINION.md)。第 9 節是偶像（應援與人氣）。

在緋夜城，新聞、娛樂、色情是同一個平台上的同一種東西：感官帶。觀眾不是「看」到一件事，而是「感覺」到它。所以誰有帶子，誰就定義發生了什麼。

媒體玩法的核心是一個問題：**你手上有一段素材，要拿它做什麼？**

## 1. 流程

```
拍（案子進行中、生活中）→ 素材（物品）→ 剪（選角度）→ 處置：發布／賣斷／勒索／留著
                                                          └─▶ 觀眾、錢、熱度、世界的變化
```

## 2. 素材

行囊裡的一種物品。任何有錄影義眼或攝影機的人都能拍，主播拍得更好。

| 屬性 | 說明 |
|---|---|
| **標籤** | 這段拍到了什麼：`戰鬥`、`醜聞`、`罪證`、`親密`、`名人`、`機甲`、`牆外`、`死亡`…… 加上涉及的勢力與人 |
| **品質** 1～5 | 拍攝者的表演或調查檢定、敏感度（感官的鮮明程度）、器材。主播的「聚光燈」每階 +上限 |
| **真實性** | 真的、剪過的、偽造的。偽造要技術檢定，被拆穿的機率依公信力與對方的調查 |
| **獨家** | 只有你有嗎。別人也拍到的話價值隨時間掉得很快 |
| **期限** | 新聞會舊。多數素材的價值每天 −10%～20% |

- 引擎在案子的報告裡自動記下「這一幕有什麼可拍的」（`changes.footage` 的候選），條件是隊伍裡有人在錄。**錄影本身有代價**：義眼錄影時隱匿 −1，而且素材是證據——被捕時它也證明你在場。
- 素材可以偷（從別人的記憶庫、從媒體公司的子網）、可以買、可以委託別人拍。

## 3. 剪

發布前選一個**角度**，決定同一段素材變成什麼：

| 角度 | 效果傾向 |
|---|---|
| 揭弊 | 公信力 +，目標勢力的聲望大跌，目標勢力的熱度大增 |
| 煽情 | 觀眾大增，公信力 −，豔名 +（如果你在畫面裡） |
| 英雄 | 街頭信譽 +，把自己或隊友塑造成傳說 |
| 抹黑 | 把責任導向另一個勢力（需要技術檢定；被拆穿時公信力重挫） |
| 匿名投放 | 效果打折，但熱度不找上你 |

AI 開著時，剪輯是一次自由行動：玩家用文字描述想怎麼講這個故事，AI 判定角度與成功程度，效果仍由程式夾在上表的清單與上限內。

## 4. 兩個數字：觀眾與公信力

| | 觀眾 | 公信力 |
|---|---|---|
| 是什麼 | 你的頻道有多少人在看 | 他們信不信 |
| 怎麼漲 | 煽情、親密、名人、直播、豔名 | 揭弊、查證過的罪證、被事後證實 |
| 怎麼掉 | 太久沒發東西 | 偽造被拆穿、抹黑、太多煽情 |
| 換成什麼 | 廣告與打賞（每週收入）、直播的聲量 | 爆料的**效力**：能不能真的撼動一個勢力 |

這是媒體線的雙面效應：**流量與可信是兩條會互相扯的路**。全走流量會變成有錢但沒人當真的豔星；全走公信力會變成窮但能扳倒企業的記者。兩種都是可行的玩法，也可以想辦法兩者兼顧（最難）。

## 5. 發布

素材怎麼變成後果，寫在**編輯台**（[OPINION](OPINION.md)）——那是主播的獨立玩法，一張有回合、有對手的棋盤。這裡只留兩種不上棋盤的用法：

**快速發布**：不想打一場戰役時，把一張素材直接發出去。程式用簡化的公式（品質 × 觀眾 × 公信力，依角度）算出一次性的效果：觀眾與公信力的增減、目標勢力的聲望與熱度。沒有對手、沒有拉鋸，效果約是認真打一場的三成。適合小料。

**不發布也是選項：**

- **勒索**：拿給當事人看。一次談判（沿用 ElondiaRPG 的談判系統），換錢、人情、或讓步。之後對方的熱度有個下限。
- **留著**：當保命符。持有某勢力的重大罪證時，被那個勢力俘虜的戰敗事件多一條「你們敢動我，帶子就會自己發出去」的分支。
- **賣斷**：賣給萬華鏡或晨星社。拿一筆錢，失去怎麼剪的權力。

## 6. 直播

行動進行中開直播。直播**不給戰鬥加成**——媒體的力量不在戰場上。它做的是把現場即時送進編輯台：

- 開播時，編輯台得到「現場連線」（[OPINION](OPINION.md) 第 4 節）：隊友這一節每一件精彩的事（要害命中、過載、機甲出場、險些被發現），直接變成一條管道的熱。不必等素材剪出來。
- 在委託副本裡，這讓輿論指標跟著現實面或內海面一起漲（[COMMISSIONS](COMMISSIONS.md) 第 5 節）。聲量夠高之後觸發的連動——保全被禁止用致命手段、出現內應——才是直播對現場的影響。**是輿論改變了現場的條件，不是直播讓誰打得更準。**
- **代價**：
  - 敵人也在看。隱匿不可能維持；增援來得更快；對方的潛網者可以從直播訊號反查位置（追蹤度持續上升）。
  - 所有熱度的增加 ×1.5。
  - 拍到的東西不再是獨家。
- 誰在拍：隊上有人戴著錄影的義眼就行，不必是主播本人。主播通常不在現場——他在編輯台。
- 適合強攻與公開場合的案子，不適合潛入。**直播把一件案子從「不被發現」的遊戲變成「被所有人看著做完」的遊戲。**

## 7. 主播在隊伍裡做什麼

媒體型的兩條路數——主播與偶像——**在現實的戰鬥中沒有招牌能力**（[CORE_RULES](CORE_RULES.md) 6.1 節）。主播有三個地方可以待（偶像的見 9.6 節）：

| 在哪 | 做什麼 |
|---|---|
| **編輯台**（主場） | 打輿論戰：經營頻道、打議題。在委託副本裡負責輿論面，並透過連動改變另外兩個面的條件 |
| **內海**（主場） | 導流：灌流、曝光、洗版、圍觀（[CYBERSPACE](CYBERSPACE.md) 第 5 節）。這是他能正面戰鬥的地方 |
| **現場** | 以採訪的名義進入場所、接觸目標、錄素材。打起來的時候，他是要被保護的人 |

- **踩點**：調查與表演是主力。用採訪當理由進門；用爆料換情報。
- **收尾**：把這件案子變成故事。發不發、怎麼剪，決定街頭信譽與熱度的走向。
- 沒有主播的隊伍也能拍素材（品質低）、也能把料賣給 NPC 記者、也能勉強坐上編輯台（[OPINION](OPINION.md) 第 7 節）。

## 8. 萬華鏡

- 平台是萬華鏡的。它抽成、它可以下架、它的演算法決定誰被看到。
- 獨立頻道在它的容忍範圍內活著。爆它的料或它金主的料，會遇到**降流**（衝擊值打折）與**封鎖**。對策：走地下轉播站（牆語者與車族經營，觀眾少但封不掉）、或駭進它的子網把東西推上首頁（[NETRUNNING](NETRUNNING.md)）。
- 媒體線的主線衝突是：你能不能在一個由它定義真實的城市，讓一件它不想讓人知道的事變成真的。

## 9. 偶像：應援、人氣與親衛隊

偶像路數的招牌能力「應援」。世界觀見 [CULTURE](CULTURE.md) 第 4 節。偶像和主播同屬**媒體型**：主播的力量在錄下來的東西，偶像的力量在她自己。兩者在現實的戰鬥中都沒有招牌能力；她們的戰場是內海與編輯台（[CORE_RULES](CORE_RULES.md) 6.1 節）。

### 9.1 應援同步（只在內海）

應援是接在網路上的同步，**只在內海生效**——那裡沒有距離，她可以把全隊的化身接到自己身上。在現實的戰鬥中它不給任何效果（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 11 節）。這是她在網內的「共鳴」（[CYBERSPACE](CYBERSPACE.md) 第 5 節）。

花 1 點行動點開始，之後每回合自動維持。

- **能接幾個人**：應援階數 + 1。
- **分擔**：被接上的隊友受到感載時，偶像可以替他承受一半。她的體質就是為了這個——但那是她自己的感載，她過載時全隊的同步一起斷，每個人都吃一次脫鉤衝擊（[NETRUNNING](NETRUNNING.md) 第 3 節）。**全隊最耐灌的人，也是全隊的單點故障。**
- **曲目**：同時只能唱一首，換歌花 1 點行動點。

| 曲目 | 效果（對同步中的隊友） | 解鎖 |
|---|---|---|
| 進行曲 | 命中與迴避 +1 | 1 階 |
| 搖籃曲 | 每回合多消退 3 點感載 | 1 階 |
| 安可 | 一名隊友立刻多行動一次（每場一次） | 2 階 |
| 合唱 | 協力不需要相同技能；協力加值 +1 | 3 階 |
| 絕唱 | 把自己目前的感載一次灌給一個敵人，自己歸零並得到餘韻 | 4 階 |
| 全員同步 | 套用同步原則的「全」檔：全隊檢定 +2，全隊受到的感載 ×1.5 | 5 階 |

- 應援套用同步原則（[CORE_RULES](CORE_RULES.md) 第 5 節）：偶像可以選自己的同步檔位，檔位越深，曲目效果越強，分擔時自己承受的越多。
- 追蹤度：應援是大量的同步流量，開著的時候追蹤度每回合多 +1。要安靜地潛，就不能唱。
- 另外兩招也只在網內：**安撫**（讓蕾絲與遺魂暫時不攻擊）與**召集**（親衛隊的化身湧進來，擋路、佔位）。

### 9.2 人氣

0～100。有多少人把你當成推。和觀眾數（第 4 節）不同：觀眾是看你的人，人氣是**肯為你做事的人**。

- **怎麼漲**：公演（見下）、握手會、直播中的精彩表現、豔名、被剪成英雄角度的素材。
- **怎麼掉**：醜聞（別人發布的、關於你的素材）、太久沒露面、被拍到和「不該在一起的人」在一起——人氣高的偶像，**私生活是一項會被攻擊的資產**。親密關係要藏，或者公開並承受代價，這是偶像線的核心取捨。
- **公演**：一種生活行動，花半天，表演檢定。收入與人氣成長依場地（地下室、live house、劇場、祭典的舞台）。大場地要有門路或公司。
- **握手會**：一對一的短暫同步。收入高、人氣漲得快，每次承受感載，而且每一個來握的人都是一次風險（[CULTURE](CULTURE.md) 第 4 節）。

### 9.3 親衛隊

人氣到 20 之後，你有了自己的親衛隊（[GANGS](GANGS.md) 第 3 節）。它是一項依人氣成長的資源，不是可以細部操控的部隊。

| 人氣 | 親衛隊 | 能叫他們做的事（每週次數有限） |
|---|---|---|
| 20 | 十幾個熟面孔 | 打聽、排隊、帶話；編輯台上當水軍（不花編輯點、不容易被拆穿） |
| 40 | 有隊長、有制服 | **召集**：網內湧進一群化身。**聲援**：編輯台上一條管道熱 +2 |
| 60 | 一區之內叫得動上百人 | **動員**：委託副本的輿論指標 +，並觸發「圍觀」的連動——現場門口擠滿了人（[COMMISSIONS](COMMISSIONS.md) 第 5 節） |
| 80 | 有地盤、有收入 | **出征**：當成一次派工（[FIXER](FIXER.md) 第 7 節），不必付錢 |

- 親衛隊**不進現實戰鬥的公式**。他們出現在現場，是輿論面的連動改變了場景的條件（多了人群、保全有了顧忌），不是多了一支部隊。
- **代價**：他們不完全聽你的。每次動用都有機率**做過頭**——有人受傷、有人被捕、有人替你做了你沒要求的事，熱度算在你頭上。人氣越高、你越少露面，越容易失控。
- 親衛隊裡的人會出事，會變成案子。隊長是一個固定 NPC，有自己的關係線。
- 和別的偶像的親衛隊自動處於競爭關係。

### 9.4 公司，或者地下

- **簽約**（緋櫻映像或萬華鏡）：大場地、宣傳、每週固定收入、公司的保全。代價是交出部分橋權（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 7 節）、被分配屬性、不能唱的歌、不能見的人，以及合約到期時的「畢業」。
- **地下**：什麼都要自己來，萬華鏡會降流。但歌是自己的。地下偶像可以在公演中「唱出來」——把一段素材的內容當成歌發布，效果等同一次發布（第 5 節），走人氣而不是公信力。
- 中途可以換邊。從公司逃出來是一件案子；被公司簽走也是。

### 9.5 偶像在編輯台上

偶像和主播一樣是輿論戰的主場，但打法不同（[OPINION](OPINION.md) 第 7 節）。主播手上是素材牌；**偶像手上是她自己**。

| 行動 | 編輯點 | 效果 | 代價 |
|---|---|---|---|
| **表態** | 1 | 公開說一句話。一條管道的向大幅往她的方向移（幅度看人氣） | 說錯了、被打臉了，掉的是人氣 |
| **公演** | 2 | 為這件事唱一場。帶子街與萬華鏡熱 +2～3 | 承受感載；要有場地 |
| **聲援／動員** | 1 | 親衛隊上場（9.3 節） | 可能做過頭 |
| **唱出來** | 2＋一張素材 | 把素材的內容寫成歌。效果等同投放，走人氣而不是公信力；對手很難「否認」一首歌 | 只有地下偶像能唱公司不准唱的 |
| **沉默** | 0 | 什麼都不說。有時候，全城都在等她開口，本身就是熱 | — |

- 偶像的編輯點是 2 ＋應援階數。她可以用所有管道，但在帶子街與萬華鏡最強。
- 主播與偶像同隊時，一個出牌、一個出聲，是編輯台上最強的組合。

### 9.6 偶像在隊伍裡做什麼

| 在哪 | 做什麼 |
|---|---|
| **編輯台**（主場） | 用人氣打輿論戰；動員親衛隊，透過連動改變現場 |
| **內海**（主場） | 應援：全隊的增益與感載的保險；安撫蕾絲；召集 |
| **現場** | 以演出的名義進入場所；社交場合裡她是所有人都在看的那一個——意味著沒人在看別人。打起來的時候，她是要被保護的人 |

- **踩點**：粉絲到處都是。親衛隊的打聽。
- **收尾**：把這件案子唱成歌。
- 偶像單獨行動很弱。她是一條**依賴隊友、也被隊友依賴**的路數。
