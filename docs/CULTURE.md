# 文化：霓虹底下的御宅城市

> 上層：[WORLD](WORLD.md)。依賴：[CORPORATIONS](CORPORATIONS.md)（緋櫻）、[GANGS](GANGS.md)。被依賴：之後的 `DISTRICTS`、`ITEMS`、`NPC_SYSTEM`、世界書。
> 這份是世界觀文件。第 9 節列出每個文化元素在系統上的落點，規則細節回到各系統文件。

緋夜城的主流文化是日本的御宅文化——動畫、偶像、女僕、獸耳、同人。不是因為這座城市在日本，而是因為重建它的錢是日本財閥出的（[CORPORATIONS](CORPORATIONS.md) 第 2 節）。

## 1. 三層

宅文化在緋夜城有三層，三層互相看不順眼：

| 層 | 是什麼 | 誰的 |
|---|---|---|
| **公司的** | 緋櫻映像量產的動畫、偶像、吉祥物、周邊。精緻、安全、無所不在。骨子裡是「奉公」的宣傳：可愛的人總是忠誠的 | 緋櫻 |
| **街上的** | 櫻町的移民社區留下來的東西：商店街、神社、祭典、暴走族。不可愛，但是真的 | 特攻姬、老店 |
| **自己做的** | 同人。拿公司的角色畫公司不會畫的東西，拿公司的義體改成公司不會賣的樣子 | 同人眾、地下偶像、野良 |

賽博龐克的老問題——企業把反抗也做成商品——在這裡有了具體的形狀：**緋櫻賣給你叛逆的動畫主角，然後僱你當她的反派**。街上的人用同一套符號反過來用：女僕裝可以是忠誠的制服，也可以是不屬於任何人的職人的招牌；偶像可以是公司的商品，也可以是在地下室唱公司不准唱的歌的人。

城裡其他的文化都還在，只是變成支流：星旗的美式畫報風（飛行夾克、機鼻彩繪）、胭脂堂的老派華埠（旗袍、茶樓、堂口）、黑泉的清教徒式保守、車族的荒地風。

## 2. 獸化改造

貓耳、狐耳、兔耳、尾巴。緋夜城最顯眼的流行，街上每五個人就有一個。

**怎麼來的**：三十年前，緋櫻映像一部獸耳女主角的動畫大紅。織女電子順勢推出第一款「會動的貓耳」——本來是頭戴式的玩具，接上橋之後會隨情緒擺動。再後來有人問：為什麼不直接裝上去？

**兩派**：

| | 機械派 | 生體派 |
|---|---|---|
| 是什麼 | 義體。耳朵是感測器陣列，尾巴是平衡陀螺 | 基因與組織改造（蜜腺的技術）。真的軟骨、真的毛、真的神經 |
| 好處 | 便宜、可換、可升級；功能強 | 人性成本低；摸起來是真的；掃描器不當它是義體 |
| 壞處 | 人性成本；會被駭；要保養 | 貴、慢、不能退貨；會掉毛 |
| 誰在用 | 街頭、潛網者、野良 | 有錢人、偶像、高級人偶 |

**不只是裝飾**：獸耳是耳部義體的一個主流分支（[CYBERWARE](CYBERWARE.md) 第 1 節的「耳與喉」槽），真的有用——指向收音、超音波、聽得到隔牆的心跳。尾巴是軀幹或腿部的義體，給平衡與落地。貓系偏敏捷與隱匿，狐系偏感知，兔系偏聽覺與跳躍，犬系偏追蹤。

**雙面效應**：耳朵和尾巴接在橋上，**會洩漏情緒**。高興會豎起來，害怕會貼平，說謊時尾巴會僵住。裝了的人在誘惑與表演上有加成（藏不住的反應很討喜），在交涉、唬人、隱瞞上有懲罰。可以裝抑制器把它鎖住——但在櫻町，鎖住耳朵被當成「這個人有事瞞著」。

**社會意義**依區而異：櫻町與霓虹腸是時尚；冠冕區當作不夠莊重；蜂巢東側的飛行夾克會找麻煩；鏽帶的素體教視為褻瀆。重度獸化又沒錢維護的人落到街上，成了野良（[GANGS](GANGS.md) 第 3 節）。

## 3. 女僕與執事

在緋夜城，女僕不是一種扮裝，是一種**職業倫理的符號**。

**源頭是緋櫻的「奉公」**：服侍是榮譽，忠誠是美德。緋櫻的家政課——穿女僕與執事制服的要人警護部隊——把這個形象推到極致：彬彬有禮、一塵不染、能在倒茶的同時解決房間裡的每一個人。

**於是有了四種女僕**：

| | 是誰 | 忠於 |
|---|---|---|
| 家政課 | 緋櫻的精銳，橋裡有忠犬調校 | 公司 |
| 女僕公會 | 獨立的保鑣與管家，照行規接案（[GANGS](GANGS.md) 第 4 節） | 合約 |
| 咖啡廳女僕 | 服務業。櫻町與霓虹腸滿街都是 | 排班表 |
| 人偶館的女僕型 | 載入女僕人格面具的人偶 | 這一個小時的客人 |

同一套衣服，四種完全不同的處境。認不認得出眼前是哪一種，是在這座城市活下去的常識——也是踩點時的一項未知。

**女僕咖啡廳**是櫻町的情報交換所。店員聽得到所有客人說的話，而沒有人會防一個端蛋包飯的。好幾個中間人的店面就是咖啡廳（[FIXER](FIXER.md) 第 1 節）；玩家也可以開一間（[FIXER](FIXER.md) 第 9 節）。

**制服是裝備**：正規的女僕服與執事服是有護甲的——夾層纖維、藏刀的襯裙、藏槍的圍裙口袋。它是少數能同時兼顧護甲、隱匿與風格的服裝（[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 4 節的「三選二」的例外），代價是只有受過訓的人穿得出效果，而且穿上它，別人就會用女僕的規矩看待你。

執事與男性從業者同樣存在，行規相同。

## 4. 偶像

偶像是這座城市最有權力的一種人，也是最不自由的一種。

**為什麼偶像這麼重要**：演唱會不只是看和聽。幾千個觀眾的橋同時接上舞台，感覺偶像感覺到的東西。這叫**應援同步**，是合法範圍內最強烈的集體體驗。能承受幾千人份回灌的人萬中選一——偶像首先是一種體質（極高的耐受與敏感度），其次才是歌與舞。

**四種偶像**：

| | 是什麼 | 處境 |
|---|---|---|
| **公司偶像** | 緋櫻映像與萬華鏡旗下的藝人 | 契約寫到私生活。「畢業」的時候，在團期間的部分記憶歸公司所有 |
| **戰姬** | 緋櫻戰姬事業部的女武神機師，同時是偶像團體 | 耐受高到能承受幾千人同步的人，也正好能開全同步的機甲。出擊就是公演，戰鬥會被剪成帶子賣。她們是真的在打仗 |
| **地下偶像** | 沒有公司，在地下室、屋頂、祭典上唱 | 這條世界線的抗議歌手。唱公司不准唱的，用地下轉播站播。紅了之後，不是被簽走，就是被處理掉 |
| **虛擬偶像** | 沒有身體，只有形象與聲音。背後是一個人、一個團隊、或一個 AI | 永遠不會老、不會鬧醜聞。傳聞有一位當紅的虛擬偶像背後沒有任何人——而她的粉絲登出之後，都說還聽得到她 |

**周邊文化**：

- **親衛隊**：粉絲的武裝組織（[GANGS](GANGS.md) 第 3 節）。
- **握手會**：不是握手，是短暫的一對一同步。票價驚人。也是刺殺、竊取資料、植入惡意韌體的機會。
- **推**：一個人支持的那一位偶像。「你推誰」是櫻町的寒暄，也是劃分敵我的問題。
- **畢業**：偶像契約期滿。對外是含淚的告別公演，對內是奉公課的卸載手術。畢業後的偶像去了哪裡，是城裡的禁忌話題，也是不只一條任務線的起點。

**玩法上**：偶像是媒體玩法的另一種形狀——主播靠素材，偶像靠同步。偶像是第八條路數，規則見 [MEDIA](MEDIA.md) 第 9 節。

## 5. 萌的工程學

「萌」在這裡是一門應用科學。

緋櫻映像的情感工學部門花了幾十年研究：什麼樣的語氣、動作、反應模式，最能在觀眾的橋上觸發保護欲與依戀。成果是一套標準化的**屬性**——傲嬌、三無、天然、元氣、腹黑、姐系、病嬌……每一種都是一組量過的行為參數。

這套東西現在是整個產業的共通規格：

- **人格面具**（[CORE_RULES](CORE_RULES.md) 第 6 節伶人的招牌能力、[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 6 節的人偶館）依屬性分型號販售。客人點的不是「一個人」，是「傲嬌型，B 規格」。
- **槍靈**（崑崙）、**機娘**（織女）的人格同樣用這套型號。
- **偶像**出道前被分配屬性。
- 普通人也會說自己「是什麼屬性」，像說星座。

黑暗面：屬性可以被**安裝**。戴久了面具的人偶分不清哪個是自己；公司偶像的屬性寫在契約裡；家政課的禮貌是調校出來的。這座城市裡最可愛的那些人，有多少是自己選的，沒人說得準——包括他們自己。

系統上，屬性沿用 ElondiaRPG 的 NPC 性格標籤：生成 NPC 時抽一到兩個，交給 AI 作為描寫依據；人格面具則是把這個標籤暫時換掉。

## 6. 同人

公司做的東西是「官方」，自己做的叫**同人**。在緋夜城，同人的範圍比漫畫大得多：

| 同人的什麼 | 是什麼 |
|---|---|
| 本子 | 漫畫與小說。畫官方不會畫的 |
| 同人帶 | 自製的感官帶。品質參差，但有官方沒有的東西 |
| 同人程式 | 自己寫的快駭與工具。沒有保固，有時候有後門，有時候比企業的好用 |
| 同人義體 | 改裝件與自製調校。冷門的、奇怪的、企業嫌市場太小不做的 |
| 同人皮 | 給槍靈、機娘、虛擬形象用的自製人格與外觀 |

**同人夜市**每週在蜂巢與櫻町交界的高架橋下開一次，是城裡最大的非正規市場——賽博龐克題材裡的夜市，在這裡長成了即賣會的樣子：一排排摺疊桌，社團名寫在紙板上，熟客天沒黑就來排隊。

**緋夜祭**一年兩次，佔滿整個舊港的貨櫃場，三天。全城的社團、企業的獵頭、貞網局的臥底、來買禁品的和來抓人的，都在。這是遊戲裡的定期大事件。

同人眾見 [GANGS](GANGS.md) 第 4 節。

## 7. 日常

把這些放進城市的每個角落，世界才會像活的：

- **扭蛋**：街角的扭蛋機。便宜的轉出吊飾與貼紙；貴的那種在診所與夜市——**義體扭蛋**，轉到什麼裝什麼。新手期的賭博式成長，以及「這顆扭蛋裡的義眼好像不是新的」的故事。
- **痛車、痛甲**：把喜歡的角色畫滿整台車。戰姬的機甲有官方塗裝；街頭的機師自己畫。星旗那邊的對應物是機鼻彩繪。
- **動畫帶**：動畫也是感官帶——觀眾不是看主角，是**成為**主角。有人一部看上百遍，有人看完分不清哪些記憶是自己的。
- **遊戲中心**：格鬥機台接的是橋，輸的人真的會痛一下。地下的那種就是感官擂台（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 6 節）。
- **角色扮演**：穿成動畫角色上街很平常。所以**偽裝在這座城市特別容易**——沒人會多看一個戴面具、穿制服的人。伶人的生意靠這個。
- **吉祥物**：每家企業、每個區、每間店都有。桃子屋的桃子、天使急救的小天使、市警的警犬。布偶裝讓這件事不再只是可愛（[GANGS](GANGS.md) 第 3 節）。
- **課金**：一切都能加購。槍靈的新語音、義眼的濾鏡、公寓牆面的桌布。
- **社畜**：企業底層員工的自稱。奉公文化的另一面——加班到在工位上過載。

## 8. 街頭用語

日語借詞混在日常對話裡，沒人覺得是外來語。

| 詞 | 意思 |
|---|---|
| 推 | 你支持的偶像；引申為任何你無條件挺的人 |
| 同擔 | 推同一個人的人；同一邊的 |
| 畢業 | 契約期滿；委婉地說「被處理掉」 |
| 奉公 | 替公司賣命。街上講的時候是諷刺 |
| 社畜 | 企業底層員工 |
| 課金 | 花錢加購；引申為用錢解決 |
| 前輩、後輩 | 字面意思。特攻姬與企業裡是認真的 |
| 屬性 | 一個人的行為類型（傲嬌、三無……） |
| 面具 | 人格面具；引申為裝出來的樣子 |
| 素體 | 沒改造過的身體；素體教的自稱 |
| 鉻 | 義體的統稱。「上鉻」是去改造 |
| 橋 | 邊緣橋 |
| 灌 | 對人造成感載。「把他灌了」 |
| 翻了 | 過載 |
| 溺了 | 得了溺感症 |
| 帶子、黑帶 | 感官帶；非法的感官帶 |
| 牆外來的 | 妖精；也指好得不像真的東西 |
| 契約人 | 交出橋權的人 |
| 野良 | 沒有主人的；獸化改造者的幫派 |
| 請問需要打掃嗎 | 家政課動手前的招呼。街上當成「你死定了」的玩笑 |

## 10. 寫作的界線

- **所有角色都是成年人**（[LEWD_SYSTEM](LEWD_SYSTEM.md) 第 9 節）。「萌」「可愛」在這裡是成年人的風格與職業形象，不是年齡。
- **不寫校園**。這個世界的「制服」指職業制服：女僕、執事、護理、警備、偶像的打歌服。
- 偶像出道年齡下限 18；人偶、歡場從業者同樣。這是世界內的法規，也是引擎生成 NPC 時的規則。
