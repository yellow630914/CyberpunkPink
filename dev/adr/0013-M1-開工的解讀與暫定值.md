# 0013 M1 開工的解讀與暫定值（戰鬥、敵人、裝備、技能、戰敗）

- 日期：2026-11-22　狀態：暫定，等使用者看（每一項都標了現在引擎與工單照哪一邊；使用者定案之後寫回設計書，這份改成「採用」）

## 背景
M1 把第四版 Demo 的現實戰鬥搬進引擎，逐條對照 COMBAT_SYSTEM。對照出來三類東西：Demo 和設計書不一樣的（照設計書）、設計書自己兩處對不上的（要使用者決定，引擎先挑一邊）、設計書沒有寫而實作一定要有個答案的（先定暫定值）。這份把三類都列出來，下游的工單引用它。

## 三、設計書沒有寫：先定的暫定值

### 核心（現在的引擎就是這樣）

| # | 項目 | 暫定 |
|---|---|---|
| C1 | 餘韻「全屬性 −2」（CORE_RULES 4.2）落在哪 | 每一層命中、迴避、豁免各 −1（等於屬性 −2 的調整值）；不連帶改生命上限、感載上限、行動點上限。內海相反：每一層 +1 |
| C2 | 長槍在第 1 格的 −4 與距離的懲罰 | 兩個都算（和 Demo 一樣） |
| C3 | 我方的人算什麼位階 | 被制伏的條件照精英（要餘韻疊滿）；單位的等級是場景的等級 |
| C4 | 倒下的人打完之後 | 帶著傷回來，生命最少剩 1；餘韻疊滿再過載而倒下的，餘韻清空、沉溺 +2 |
| C5 | 戰鬥與在格子地圖上走花不花遊戲時間 | 都不花（結束時也不加）；副本的時間由 M2 的委託算 |
| C6 | 後方的增援 | 有空格才補，從最後面的空格進場；先攻當場擲；行動點從上限開始 |
| C7 | 遮蔽被打穿時多出來的傷害 | 算到下一級 |
| C8 | 埋伏的一方「多一格掩體」是哪一格 | 從前面數第一個不是掩體的格子升成掩體 |
| C9 | 首領戰的遮蔽 | 具名的首領戰情境用「中」。用「一邊倒」（守方掩體、攻方暴露）自動對打：勝率 69～88%、掉 60～77% 的生命，比 BALANCE 的目標（勝率 90% 以上、掉 30～50%）兇很多；「中」是勝率 90～95%、掉 45～56% |
| C10 | 打和人重疊的東西 | 沒有要害與重創、不傷那一格的遮蔽；敵人位階的傷害倍率照乘 |
| C11 | 回退 | 開戰留一步，戰鬥裡的每一步不另留；戰鬥中回退回到開打之前（0011） |

## 後果
- 第二類的每一項，引擎現在照的那一邊如果被否決，要改的地方：B1 改一個數字；B2 改資料的格式與敵人的功能；B3～B5、B7 只動技能的資料；B6 只動地圖的資料。
- 第三類的數字都集中在核心的 `BattleNumbers`、工單與資料裡，定案之後各改一處。
- A5 與 C9 會動到平衡：重傷的 −2 開始對攻擊生效之後，受傷的一方打得更不準；首領戰用哪一種遮蔽差很多。這兩項建議交給平衡的 session 重跑模擬。
