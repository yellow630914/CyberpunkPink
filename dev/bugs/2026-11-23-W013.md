# W013：被拉回來的人狀態清空，但技能的 buff 還在
- 發現者：cpp-tester-whitebox
- 嚴重度：小問題（要「倒下時帶著 buff」再被「拉回來」；改造師的拉回來在現在的資料裡）。屬於解讀，見最後一條。
- 規格出處：dev/adr/0015 第一節 `run.revive(unit, hp)`：「回到場上……行動點 0、**狀態清空**、先攻的順位不變」；SKILL_TREES 拉回來「回到 2d6＋醫療等級的生命值，重新回到戰鬥」。
- 實際行為：`revive` 清掉 `unit.statuses`，技能的 buff 記在 `unit.ext.abilities.buffs`（features/abilities/mods.ts），不受影響。倒下的人沒有回合，own_turn_* 的 buff 在他倒下的期間停住，拉回來之後接著算，修正照樣加（例：心流、號令、子彈時間的命中與行動點）。
- 重現：engine/tests/whitebox/fixtures/W013-buffs-survive-revive.json（不擲骰）。
  會失敗的測試：engine/tests/pending/W011-W013-ability-timers.test.ts 的「W013」。
- 可能的位置（只寫推測，不改）：核心沒有 `revive` 的掛點（只有記一拍）；features/abilities 可以聽 `out`（倒下時就清 buff，比照 ward.ts）——但這樣「倒下之前的 on_end」要不要做也要一起定。
- 要 cpp-architect 定的：buff 算不算 ADR 0015 說的「狀態」。若定成「不算、留著」，把這一份改成在 ADR 寫明，pending 測試刪掉。
