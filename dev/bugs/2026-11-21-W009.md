# W009：undoSteps 收到不是整數的步數時丟 RangeError
- 發現者：cpp-tester-whitebox
- 嚴重度：小問題
- 重複：和 B004（cpp-tester-boundary 同時找到）是同一件，修一個就好；修好之後兩邊的測試都要過。
- 規格出處：`Game.undoSteps`／`UndoStack.pop` 的註解「沒有那麼多步就回傳 null（false），什麼都不動」；AI_TASKS 2.4 節。
- 實際行為：
  - `UndoStack.pop(n)` 只檢查 `n < 1 || n > 步數`；`n = 1.5` 時 `this.steps[length - 1.5]` 是 undefined，接著 `this.steps.length -= 1.5` 丟 `RangeError: Invalid array length`。
  - 種子 7、空房間：`commit` 兩次，`undoSteps(1.5)` 丟錯（`NaN` 也會走到同一行：`n < 1`、`n > length` 都是 false）。介面的回退選單傳的是整數，所以只在外部呼叫時碰到。
- 重現：`engine/tests/whitebox/fixtures/W009-undo-non-integer.json`（種子、情境、輸入與期望；要註冊掛鉤或直接呼叫函式，不是 Repro 格式）；
  會失敗的測試：`engine/tests/whitebox/bugs.whitebox.test.ts` 的「W009」（用 `it.fails` 標著，主套件保持全綠；修好之後改成 `it`）。
- 可能的位置（只寫推測，不改）：`engine/src/shell/undo.ts` 的 `pop`，加 `!Number.isInteger(n)` 的檢查。
