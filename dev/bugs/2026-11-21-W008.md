# W008：建好角的存檔摘要永遠沒有出身
- 發現者：cpp-tester-whitebox
- 嚴重度：小問題
- 規格出處：`engine/src/shell/save.ts` 的 `SaveMeta.pc`「主角的摘要：名字與出身」；MIGRATION「敘事、狀態與介面」（存檔）；CHARACTER 第 2 節（出身）。
- 實際行為：
  - 建角把出身存成物件：`ext.origin = { id, favor, favorValue, status, home, roster }`（`engine/src/features/creation/index.ts` 的 `buildCreationReport`）。`saveMeta` 只在 `typeof pc.ext.origin === 'string'` 時放出身。
  - 種子 7、還沒建角、裝 creation 與 MINI_PACK，建一個出身 hive 的角色後存檔：`meta.pc` 是 `{ name: '露' }`，沒有 `origin`。
- 重現：`engine/tests/whitebox/fixtures/W008-save-meta-origin.json`（種子、情境、輸入與期望；要註冊掛鉤或直接呼叫函式，不是 Repro 格式）；
  會失敗的測試：`engine/tests/whitebox/bugs.whitebox.test.ts` 的「W008」（用 `it.fails` 標著，主套件保持全綠；修好之後改成 `it`）。
- 可能的位置（只寫推測，不改）：`engine/src/shell/save.ts` 的 `saveMeta`（讀 `ext.origin.id`，或讓出身的名字由內容查）；兩邊誰改要 architect 定（存檔是核心、建角是功能，功能之間的資料形狀要寫進工單）。

- 狀態：已修（2026-11-22，cpp-architect）。約定：角色的出身放在 `actor.ext.origin`，是一個至少有 `id` 的物件（`originIdOf` 讀）；存檔摘要放出身的 id 與名字（`meta.pc.origin`、`originName`）。回歸：`engine/tests/whitebox/bugs.whitebox.test.ts`、`engine/tests/core/game.test.ts`。
