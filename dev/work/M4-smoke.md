## 要做的

1. 測試用的最小世界（`worldBody.ts`）：兩座橋、五件義體（含甲板、反射加速器、一件生體）、十來個零件、三種診所與調校診所的設施、三種藥與抑制劑、兩種調校、一種惡意韌體、一個流竄 AI 與兩件蠱惑事件、五個夜課技能與三個體位（一個三人的）、一份契約的持約人與三件指令事件、簾後館的兩個夜與最小的表、兩種雙形象的敵人、生命軌跡每張表兩條。全部是假資料、文字中性。
2. 具名的情境（`scenariosBody.ts`；dev/test-harness.md 第 1 節補上）：「剛裝完義體在休養」「沉溺 65 而且藏著」「依賴一種藥」「身上有一份債務契約、佇列兩條」「持有一個契約人」「三個人的場景進行到第三回合」「簾後館第二幕、場熱 65」「M3 的舊存檔（背包裡裝著甲板、一對一的場景進行中）」。
3. 冒煙主幹（AI 關閉、固定種子；每一條一個檔或一個 `describe`）：
   - **身體**：建角（選橋、義體、技能、裝備、生命軌跡）→ 診所裝一件義體 → 沉溺被補到下限 → 休養過完效果生效 → 組一把槍 → 打一場現實戰鬥（開反射加速器）→ 受重創 → 診所治療與手術 → 吃藥到依賴 → 戒斷。
   - **成人場景**：學一個夜課 → 一對一 → 三個人的一圈加一個不展開的圈、換圈 → 單人 → `dive` 裡的一場 → 每一場的結算都在範圍裡（沉溺 ±4、橋參數最多一項 +1）。
   - **契約**：效果簽下契約 → 過幾天收到指令 → 抗拒失敗 → 走到指定的地方、事件做完 → 一條逾期 → 還清。另一條：持有一個契約人 → 觸發一件事 → 調整 → 解約。
   - **長線**：染上惡意韌體 → 推進到發作 → 清除；沉溺到 66 → 蠱惑的事件來 → 順著五次。
   - **簾後館**：邀請函 → 面談 → 報名 → 走完四幕結算；另一條：第二幕全隊倒下 → 落幕 → 補演 → 記帳。
4. 種子重播：上面每一條存一份 `engine/tests/fixtures/repro/m4-*.json`（種子、輸入、最後的狀態摘要），重播的結果逐欄相同；每一條在中途存檔再讀、接著走，結果和不中斷的一樣。
5. 舊存檔：M3 的那一份讀進來——甲板搬進腦部、場景轉成新的形狀、接著玩不丟錯。
6. 性質測試（fast-check）：隨機的一串「裝、拆、吃藥、治療、場景結算、過週一」之後，沉溺不低於 `sink_floor`、每個衍生數值等於「把來源一個一個拿掉再加回去」的結果；簾後館任何種子生成的四幕都合格。
7. 白名單的掃描：場景、簾後館的一趟、擂台的一場進行中，逐一試每一種報告的前綴，放行的只有該放行的。
8. 文件：dev/test-harness.md 補 M4 的情境與重播的清單；dev/invariants.md 把 M4 各工單回報要加的不變式收齊、標上哪裡驗；0019 補「實作補記：M4-smoke」。

- `npm run test:smoke` 的 M4 那幾個檔全過，或斷掉的每一處都有一份 bug 報告與一條會失敗的測試（標 `it.fails` 並寫 bug 的 id）。
- 重播的每一份 fixture 結果相同；中途存讀的每一條相同。

- `npm test`、`npx tsc --noEmit` 全過。
