# M2-smoke

- 交給：cpp-architect 角色（sonnet；**改的是 testkit 與測試基礎建設**）
- 目標：M2 的測試基礎建設收尾：具名的情境與一份最小的假世界、冒煙的主幹、種子重播的固定檔、分層檢查與不變式對一次。
- 規格出處：dev/test-harness.md（照它補第 1、4、6 節）；dev/adr/0016；dev/invariants.md；這一批每張工單的「新的格式與鍵」。設計書不用讀。
- 可以改的路徑：`engine/src/testkit/`、`engine/tests/smoke/`、`engine/tests/repro/`、`engine/tests/fixtures/`、`engine/tests/core/layers.test.ts`、dev/test-harness.md、dev/invariants.md、`.claude/cpp/project.json`（只有路徑對不上時）。
- 不可以做的事：不改 `engine/src/core`、`engine/src/shell`、`engine/src/features`（冒煙斷在哪裡就寫 bug 報告，放 dev/bugs/，附重現的固定檔；不要自己修）；假世界不放進 `engine/data`；共同的規定見 dev/work/M2-plan.md。

## 要做的

1. **最小的假世界** `TEST_WORLD`（testkit 匯出的一包內容，只給測試用）：兩個區、三塊街區加一塊橋接區、一條三站的路線、一間店與六樣東西、一份兩階段的工作、一處住處、兩個勢力、三個固定 NPC 與一個區的生成規則、一個中間人、一種委託的類型與一件寫好的三階段副本（用 DATA 9.3 的小辦公室）、三個假兵種、兩件街頭事件、一件兩段的戰敗事件、三個基本體位。每一種內容只放驗主幹用得到的最少幾筆。
2. **具名的情境**：`makeCityGame()`（建好角色、站在起點的街區、有住處）、`makeCommissionGame()`（已經接案、隊伍兩個人、站在委託地點）、小工具 `walkTo`、`passTime`、`untilIdle`（把引擎開起來的事件與場景用第一個選項走完）。
3. **冒煙**（`engine/tests/smoke/m2.test.ts`，固定種子、AI 關著，每一條回報斷在哪一步）：
   - 城市：走到另一區 → 進店買一樣東西 → 打工一班 → 睡一覺 → 跨過週一付帳單。
   - 事件：走路觸發一件街頭事件 → 選一個帶檢定的選項 → 效果生效。
   - 委託：看委託 → 接案 → 踩點一次 → 召集 → 進副本 → 三個階段各選面與分支、走地圖、打贏 → 做完入帳。
   - 撤退：進副本走一個階段 → 撤退 → 時間與錢回到出發之前、紀錄留著。
   - 戰敗：在副本裡投降 → 戰敗事件選完 → 接受 → 委託失敗、回到進去之前；另一條選「回到這個階段開始時」。
   - 場景：一件帶場景的事件 → 進場景 → 說話、主導、停下 → 結算。
   - 整條主幹中途存檔讀檔一次，結果和沒有中斷的一樣。
4. **種子重播**：上面的委託與城市兩條各錄一份固定檔進 `engine/tests/fixtures/repro/`；重播的執行器補上 M2 的步驟種類。
5. **分層檢查**：確認新的功能都只 import 核心；補一條掃原始碼的檢查：`features/` 底下沒有讀別的功能的 `state.ext.<別的功能>`（0016 第三節的規矩）。
6. dev/test-harness.md 與 dev/invariants.md 照這一批實際做出來的更新（每一條標在哪裡驗）；dev/work/M2-plan.md「每一張都適用的規定」裡能用測試守的，寫成測試。

## 驗收條件

- 冒煙的每一條通過；任何一條不過的，bug 報告裡有固定檔與會失敗的測試路徑。
- `TEST_WORLD` 帶著全部功能載入沒有錯；拿掉任何一個 M2 的功能（逐一試）核心與其餘的功能照樣載得起來（不相干的那幾種內容先濾掉）。
- 兩份重播的固定檔每次跑結果一樣。
- 「不讀別的功能的 `ext`」那條檢查抓得到故意寫的反例。
- `npm test`、`npx tsc --noEmit` 全過；不變式的編號連續、每一條都有出處與驗的地方。
