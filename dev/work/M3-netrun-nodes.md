# M3-netrun-nodes

- 交給：cpp-feature（sonnet）
- 目標：`netrun` 的第二張：其餘的節點（檔案庫與下載、控制節點、人、警報節點、迴圈碎片、巡邏、安全點）、六種目標、探索中的管理行動、「帶出去才算數」。
- 規格出處：CYBERSPACE 8.1 節（「節點」表其餘各列、巡邏那一條、「陷阱的感載」、「帶出去才算數」、「把固定目標放進生成的地圖」含六種目標的表）、8.3 節「每一層放什麼」與「追蹤度在生成的子網裡」；NETRUNNING 第 4 節（節點種類）；ITEMS 11.4 節「後門鑰匙」；BALANCE 2.1 節（招牌行動裡寫死的感載怎麼照等級乘，陷阱同一條）；dev/adr/0018 第六、七節與 N7、N8、N23。
- 可以改的路徑：`engine/src/features/netrun/`、`engine/tests/features/M3-netrun-nodes.test.ts`。
- 可以用的介面：M3-netrun 的全部；`SheetState.movers`（`map.sheet` 變更的 `movers`）；`k.effects.resolve`（檔案庫的表給東西）；核心的檢定；`actor.ext.paths`（共用的資料慣例：路數與階數，看有沒有主控）；`k.stats`；`item` 變更。
- 不可以做的事：不 import 別的功能；檔案庫的內容（八種企業各自的表、提貨單、髒錢）不寫，表是資料；印記與機關只收節點、不做規則（那是沉船帶與迷宮館）；共同的規定見 dev/work/M3-plan.md。

## 新的格式與鍵

- `objective`（`setup` 帶的，或自己那一趟的 `goal`）：`{ kind: 'download' | 'seize' | 'find' | 'defeat' | 'plant' | 'extract', turns?, foe?, item? }`。生成時把它放在離入口最遠的那一半、不在陷阱後面（生成器的 `far_half`）：下載與帶出來放在一個檔案庫、接管放在一個控制節點、找人放在一個「人」、打倒放在一場遭遇（`foe` 是指定的敵人，加進那一場）、放東西放在一個檔案庫；位置記在 `state.ext.netrun.goal.at`。
- `net_region` 多 `archive_table?: [{ weight, name, give: 效果[] }]`（每個檔案庫擲一次；效果裡的數字可以寫照等級的五個值）與 `trap: { alarm: 10, loop_load: 8 }`。
- 地圖實例的 `ext.net` 多：`traps`（看不到的陷阱與找到了沒有）、`patrols: [{ id, route: 節點 id[], foes, at, step }]`、`controls: { 標記 id: { node?, taken? } }`、`keys: string[]`（拿到的憑證）、`wiped: { 圖的 id: 次數 }`。
- `netrun.use` 多的事：`download`（繼續下載）、`loot`（開檔案庫）、`seize`、`talk`、`hack_person`、`plant`、`crack`（破解閘門）、`cred`（用憑證過閘門）、`wipe`（擦痕跡）、`safe_logout`。
- `result` 多：`controls`（接管了哪些，副本拿去給連動）、`goal`（做到了沒有）、`lost`（倒下或被定位時擲掉的東西）。

## 要做的

1. **目標**：六種照 CYBERSPACE 8.1 的表。下載與放東西是待在節點上的回合（N7）：每做一次「繼續」過一個探索回合、追蹤度 +2（放東西不加）、離開那一格進度歸零；做滿就完成。接管：主控的檢定（智識加介面，加招牌的階數的一半進位，對地圖的 DC），或用掉一把後門鑰匙（快取或腳本裡帶 `backdoor_key` 標籤的道具）。找人：走到之後一次交涉或介面的檢定。打倒：那一場打贏。帶出來：拿到之後要走到出口（最後一層的閘門）或安全點；倒下時這一件一定丟。完成之後（帶出來是走到之後）這一趟結束（`done`）。
2. **檔案庫**：不是目標的那幾個，開一次擲一次 `archive_table`（照權重），效果經 `k.effects.resolve`（內建的來源）；拿到的東西記進這一趟的 `loot`。沒有表的區開了是空的。
3. **控制節點**：接管（同上的檢定）之後記 `taken`；`result.controls` 列出來。
4. **人**：談（交涉對地圖的 DC：成功給一把憑證，記進 `keys`）；有主控的人可以對他快駭（一次介面的檢定對 DC：成功同樣拿到憑證，不論成敗追蹤度 +1）。憑證可以用來過一道閘門（`cred`，不必打守著它的遭遇，N：照 CYBERSPACE「可以不打層主，但拿不到它的掉落」）。
5. **陷阱**（N8）：生成時是看不到的（`hidden`）。進到視野時全隊最高的介面擲一次對 DC，過了就把那一格改成 `net_alarm` 或 `net_loop`（看得到、可以繞）；沒看到而踩上去：警報節點追蹤度 +10；迴圈碎片每個人擲介面或意志（取高的）對 DC，失敗的人感載 +8（照等級乘）而且全隊被送回這一層的入口。踩過的陷阱失效。
6. **巡邏**：生成之後從節點的圖挑一條三到五個節點的路線，放一隊（位階照區的規則：一個精英或兩個雜兵）；每三個探索回合沿路線走一個節點（來回）；它和隊伍在同一個節點或相鄰的節點時：全隊潛行對 DC（`setup.stealth` 的那一趟自動過），沒過就開戰（和遭遇節點同一種開法）。打贏就沒有了。追蹤度到 30 的時候多一隊。畫面要的位置在 `netrunView`。
7. **探索中的管理行動**（N23；隊上要有人有主控）：破解閘門（檢定對 DC，到 30 之後 +2；成功閘門開了，但守著它的遭遇還在：之後可以不打直接通過）、擦痕跡（−5；每一層最多「主控的階數」次）；每做一次追蹤度 +1、失敗 +5。
8. **安全點**：站在上面可以正常登出（自己的那一趟：東西全部帶走；`face.net`：仍然是撤退，N13）。
9. **帶出去才算數**：這一趟以戰敗被接受或被定位結束而且**沒有**回到快照（自己的那一趟、或不算委託失敗的戰敗）時，`loot` 的每一件擲 d6，1～3 的丟掉（`item` 變更拿走），`result.lost` 列出來。正常結束、登出、拔線全部帶走。

## 驗收條件（`engine/tests/features/M3-netrun-nodes.test.ts`；沿用 M3-netrun 測試的假資料，加一張三列的 `archive_table`、一把後門鑰匙、一個有主控的角色）

- 六種目標各一條：下載 `turns: 3` 要做三次「繼續」，每次追蹤度 +2、`round` +1，中途走開再回來要從頭；接管用檢定成功、用後門鑰匙免檢定並用掉那一把；找人要走到並過檢定；打倒要那一場打贏而且指定的敵人在場；放東西兩回合、不加追蹤度；帶出來拿到之後還沒完成，走到閘門才完成。完成的那一刻交回 `done`，`result.goal` 是 true。
- 目標的節點在離入口最遠的那一半（對 `graph` 的 `depth`），二十個種子都成立。
- 檔案庫：固定種子擲到表的第二列，效果套用、`loot` 多一筆；同一個檔案庫第二次灰掉。
- 控制節點接管之後 `result.controls` 有它。
- 人：交涉成功拿到憑證，用它過閘門不必打遭遇；沒有主控的隊伍沒有「快駭」那一項。
- 陷阱：察覺成功的那一格看得到（`gridView` 的種類是 `net_alarm`）；沒察覺踩上去追蹤度 +10；迴圈碎片失敗的人感載照等級加、全隊回到入口；踩過的第二次沒事。
- 巡邏：三個探索回合之後它在路線的下一個節點；走到它旁邊，潛行全過就沒事、沒過開戰；打贏之後不再出現；追蹤度到 30 之後多一隊。
- 擦痕跡：主控 2 階的人一層只能做兩次，第三次灰掉並有原因；每次是 −5 +1；沒有主控的隊伍沒有這幾項。
- 自己的那一趟打輸、接受：`loot` 裡三件照固定的骰面丟掉兩件，`result.lost` 列出來；「帶出來」的那一件一定丟。正常登出三件都在。
- 生成的地圖帶著巡邏、陷阱、目標存檔再讀，接著走的結果一樣。
- `npm test`、`npx tsc --noEmit`、分層檢查全過。
