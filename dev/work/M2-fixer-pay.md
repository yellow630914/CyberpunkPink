# M2-fixer-pay

- 交給：cpp-feature（sonnet）
- 目標：召集時替輔助面請人的四種辦法與向中間人借人；副本做完之後的入帳：報酬照付法、中間人的抽成、出場費與分紅、信譽、和你一起去的人的忠誠與親密度。
- 規格出處：COMMISSIONS 6.1、6.5 節；NPC_SYSTEM 10.5 節（薪水與分紅）、10.4 節（忠誠的表裡和委託有關的幾列）、7.3 節（一起出過委託）；FIXER 第 2 節④收尾的「結算」、第 8 節；UI 7.3 節（分帳那一條）；dev/adr/0016 第三節與 G16。
- 可以改的路徑：`engine/src/features/fixer/`、`engine/tests/features/M2-fixer-pay.test.ts`。
- 可以用的介面：`state.party`、`k.stats`（`roster_fee`，沒有人註冊當 0）、`meterOf`（`affinity`、`loyalty`、`rep`）、`k.effects`（`cash`、`cred`、`owed`、`owed_to_pc`、`loyalty`、`affinity`、`rep`、`hostility`）、`k.conditions`（`has_favor`、`in_roster`）、核心的 `actor.add`、`actor.condition` 變更、核心的檢定、`activity.end`。
- 不可以做的事：不 import `features/roster`、`features/favors`（它們沒裝時，對應的辦法不列、對應的結算略過）；隊伍本身怎麼選是名冊的 `muster`；共同的規定見 dev/work/M2-plan.md。

## 新的格式與鍵

- 手上的委託多：`aux: { [面]: [{ actor, way: 'pay' | 'use_favor' | 'owe_favor' | 'bond' | 'borrow', cost }] }`、哪些人「靠交情」已經失敗過。
- 規則 `fixer_rule`：評價對報酬的加成（G16）、信譽的增減（G16）、借人的倍率 1.5、老闆多拿一份。
- 報告：`fixer.hire`、`fixer.unhire`、`fixer.payout`（kind `gig`）。

## 要做的

1. `hireOptions(k, state, job, face, actor)`：四種辦法各自成不成立、代價、成功率。付錢＝出場費；用人情＝用掉一個他欠你的小人情；欠人情＝你欠他一個小人情；靠交情＝擲交涉（魅力）對 20 − 親密度 ÷ 5，忠誠 70 以上不用擲，失敗的話這個人這一件不能再用這個辦法。請得到的只有不在隊上、身上沒有 `busy`、`injured`、`lying_low`、`arrested` 的人；每一面最多 2 個。
2. `hire`：付代價、把人記進 `aux`、在他身上掛 `busy`；`unhire` 在出發之前可以退（錢退、用掉的人情不退）。借人：照委託的等級建一個只有基本功的臨時角色，只能付錢，價錢是「等級² × 200」的 1.5 倍。
3. 出發時把 `aux` 整理成副本要的樣子（每一面的角色 id、哪些是借來的）併進 `setup`。
4. 入帳（`activity.end` 的 `done`）：
   - 報酬 = 談好的數字 × 評價的加成；照付法給（現金全額、帳戶 85% 並讓目標勢力敵對值 +2、人情七成加一個人情）。
   - 先扣中間人的抽成（換成人情的那三成不抽），再付出場費（跟著報酬用同一種錢），剩下的在場拿分紅的人均分、主角多一份。不夠付出場費時從主角身上同一種錢補，補不出來記成欠（一行結果，忠誠照沒付算）。
   - 信譽照 G16；一起去的人（隊伍與輔助面）親密度 +2；錢照說好的付了的人忠誠 +2。
   - 把 `aux` 的人身上的 `busy` 拿掉；借來的臨時角色移除。
5. 失敗（`failed`）：沒有報酬、信譽 −3、`busy` 拿掉；已經付的出場費不退。撤退不走這裡（狀態回到出發之前，請的人與付的錢都回去）。
6. 對外：`splitPreview(k, state, job)`（分帳那一條每一段是誰、多少、哪一種錢）。

## 驗收條件

- 四種辦法：付錢扣了出場費；用人情之後那一筆沒了；欠人情之後你欠他一筆；靠交情固定骰面的成功與失敗各一條，失敗之後那個辦法灰掉並有原因；忠誠 70 的人不擲。
- 沒裝人情的功能時只有付錢與靠交情兩種。
- 隊上的人、受傷的人請不了並有原因；同一面第三個人被擋。
- 借來的人：價錢是 1.5 倍、進了 `aux` 的 `borrowed`。
- 入帳：報酬 2,000、抽成 10%、一個出場費 400 的人、一個拿分紅的夥伴、評價 B、現金 → 抽 200、付 400、剩 1,400 分三份，主角拿兩份；數字和 `splitPreview` 一樣。
- 匯進帳戶：進的是帳戶、是 85%、目標勢力敵對值 +2、只加一次。換人情：抽成只算七成的那一部分、多一個人情。
- 評價 S 多 20%；信譽 +2；失敗信譽 −3、沒有錢。
- 做完之後請的人身上沒有 `busy`；借來的角色不在 `state.actors`。
- 撤退之後付出去的出場費回來了、人也不再是 `busy`。
