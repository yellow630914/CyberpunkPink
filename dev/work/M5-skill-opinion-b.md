## 要做的

1. **名媛**：有輿論欄的逐條寫。OPINION 第 7 節的兩個方向對到清單：
   - **假身分**（扮成當事人或內部員工放話）：這回合的下一張說法效果加倍 → `card_mod { kind: 'line', mult: 2, scope: 'next' }`；「反噬時掉的是那個假身分，不是公信力」→ 要一個「這一次拆穿不扣公信力」的記號（`mark`；清單沒有對應的處理就列進寫不出來的）。
   - **蜜罐**：對手這回合少 2 點公關點 → `foe_pr { amount: -2, scope: 'next' }`。
   - 編輯點的上限 +1 的那個被動（這才是真的我）→ `ep_cap 1`。
   - 其餘照表逐條對：改風向的、讓對手的某個行動失效的、開場的。
2. **掮客**：
   - **買**（花錢換聲量）：`need` 是付得起、效果是 `voice` 加一筆 `out` 的 `cash` 負數；金額照技能寫的。
   - **買版面**（無視相鄰佔一格）：`capture_extra { n: 1, any: true }`，花錢或人情。
   - **擋**（用人情抵銷對手的一次手段）：反應 `on: foe.mute`、`foe.takedown`、`foe.lawyer` → `negate`，花一個小人情（`out` 的效果；人情的功能沒裝時這一招灰掉、原因：「這一招要用人情。」）。
   - 人脈 → `ep_cap 1`；大局（多佔一格）照表。
   - 第 6 節「掮客的人情：開場佔著一格（買來的版面），或對手第一回合少 2 點」：是預備（開戰前花人情）→ `opinion` 欄的 `open`。
3. **每一條都在真的戰役裡用一次**（固定種子、固定的對手），斷言和 SKILL_TREES 寫的一樣；花的錢與人情在戰役結束時真的扣了（戰役中途放棄也扣：`out` 是結算時一起套，回報這個時機合不合設計書）。
4. **寫不出來的**照三類（差鍵、差觸發點、差掛點）列出來，資料標 `pending`。

## 驗收條件（`engine/tests/features/M5-skill-opinion-b.test.ts`）

- 兩棵樹每一個有輿論欄的技能各有一個測試（做得出來的）。
- 編輯點：入戲、人面的樹階 1～5 是 2、3、3、4、4；加這才是真的我（或人脈）上限 +1。
- 假身分：下一張說法加倍、只管一張；蜜罐：對手下一回合的公關點少 2、最少 0。
- 買：錢不夠用不了（原因）；用了之後聲量加了、結算時現金少了。買版面：佔了一格不相鄰的。擋：對手的降流無效、少一個人情。
- 人情的功能沒裝：擋灰掉、其餘照常。
- 全部測試資料過 `opinion.check`；`pending` 的條數和回報裡列的一樣。
- M3 的 `M3-skill-net-b` 測試原樣全過；`npm test`、`npx tsc --noEmit` 全過。
