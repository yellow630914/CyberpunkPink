# M1b-ordnance

- 交給：cpp-feature（sonnet）
- 目標：武器的附帶效果（燃燒、義體失效、推拉以外的命中效果、卡彈與炸膛）、特殊彈（換彈時選、裝滿一匣、打空就用掉）、投擲物（一顆骰打兩格）、兩樣放在格子上的消耗品（立牌、紙鶴）。只做機制與格式，不寫任何一件物品的資料。
- 規格出處：ITEMS 5.1 節（特殊彈的規則與那張表，只當成「格式要表達得出這六種」的對照）、5.2 節「怎麼算」的「投擲物的型」與表裡的手榴彈、燃燒彈、電磁手雷、霧彈、閃光彈、煙霧彈、一綑炸藥、紙鶴、立牌九列；COMBAT_SYSTEM 第 5 節（傷害類型）；dev/adr/0015 第一、二節。名冊轉不進去的武器敘述見 dev/status.md 最後「名冊轉不進格式」那一條（燃燒、義體失效、無視一半護甲、炸膛、卡彈、無聲）。
- 可以改的路徑：`engine/src/features/combat/`（新增 `fx.ts`、`throw.ts`，改 `items.ts`、換彈的行動）、`engine/tests/features/M1b-ordnance.test.ts`。
- 可以用的介面：M1b-ops 的效果；`k.battle.on('attack.before' | 'attack.after' | 'attack.hit', …)`；`AttackOpts`（`type`、`dice`、`pierce`、`armorMult`、`natural`、`redirect`）；`run.addOverlay`；`BattleWeapon.ammo`、`BattleWeapon.ext`；`picks`（dev/adr/0014）。
- 不可以做的事：不改核心；不改 `engine/data/`；不把效果寫死在武器的類型或物品的 id 上（一律讀格式）。

## 一、武器的附帶效果 `fx`

放在 `BattleWeapon.ext.fx`（敵人資料的武器寫 `fx`、之後零件也給得出來；這一張只讀），特殊彈的物品寫 `ammo.fx`，兩個同時有就合起來（數字相加、清單接起來、`type` 以彈為準）。

| 欄位 | 意思 |
|---|---|
| `hit`、`dice`、`pierce`、`armor_mult`、`type`、`cover_mult_min`、`no_cover` | 這把武器的每一擊都帶（在 `attack.before` 加進 `opts`） |
| `on_hit` | 命中而且造成傷害之後做的效果清單（M1b-ops 的 `op`；`who` 預設是被打的人）。例：燃燒 `[{ op: 'status', status: 'burning', turns: 2 }]`、義體失效 `[{ op: 'implant', mode: 'off', turns: 1 }]`、沉溺 `[{ op: 'sink', amount: 1, save: {…} }]` |
| `on_use` | 開火之前擲的：`jam`（卡彈的機率，百分比：這一擊不發生、彈匣照扣、記一拍）、`backfire`（炸膛：`{ pct, dice }`，這一擊不發生、開槍的人自己受傷） |
| `silent` | 只變成攻擊的標籤 `silent`（警戒在 M2） |

「無視一半護甲」是熱能這個傷害類型本身的規則（資料已經有），不另外給欄位。

## 二、特殊彈

物品多一段 `ammo: { fits: [武器的類型…], fx }`。換彈的行動多一個選項（`picks`：`ammo`，可以不選）：

- 列出快取格裡 `fits` 包含手上那一把的類型的彈；不合的不列。
- 選了：用掉一件、彈匣裝滿、`weapon.ammo` 記下這一種。沒選：裝普通彈，`weapon.ammo` 清掉。
- 彈匣打空時 `weapon.ammo` 清掉（那一件已經用掉了）。
- 戰鬥結束：裝著沒打完的特殊彈作廢（不還給快取格）。

## 三、投擲物

道具效果 `throw`（物品的 `use.target` 是 `foe_slot`、`use.ap` 是 2）：

- 欄位：`dice`、`type`、`hit`、`cover_mult`、`on_hit`（效果清單）、`save`（閃光彈：不造成傷害，兩格裡的人過檢定，沒過的做 `on_hit`）、`cover`（一綑炸藥：那兩格的遮蔽各降幾級）。
- 打目標那一格與相鄰的一格：相鄰的那一格由玩家選（`picks`：`also`，目標在第 1 或第 4 格時只有一個選項）。
- 距離：投的人到目標那一格的距離要在 1～4，超出的那一格灰掉並寫原因。
- 擲一次 1d20 ＋ mod(反應) ＋ 運動（＋ `hit`），同一個骰面分別對兩格裡每個人的迴避與掛著的每一台的迴避。

煙霧彈照舊用 `soft_cover`（III 級的兩格：`also`）。

## 四、放在格子上的消耗品

- 立牌：道具效果 `decoy`，在我方一格放一台種類 `decoy` 的東西（`run.addOverlay`，沒有操作者、耐久 1）；下一次以那一格的人為目標的攻擊改打它（`attack.before` 設 `redirect`），它倒下。
- 紙鶴：道具效果清單就寫得出來（`status` 標記；II 級的不受黑暗是 `see_dark` 的狀態），不用新的 `op`；驗收時用假資料證明寫得出來。

## 五、驗收條件

- 帶 `on_hit` 燃燒的武器命中之後目標有 `burning`、兩回合後消失；沒中或被護甲擋光（傷害 0）時沒有。
- `jam: 100` 的武器開火：沒有擲命中、彈匣少一格、有一拍說明卡彈。`backfire: { pct: 100, dice: 1 }`：開槍的人受傷。
- 六種特殊彈各用一筆假資料：穿甲 +2、空尖（多一顆、護甲兩倍）、改神經（少一顆、對沒有橋的無效）、改電磁（命中後義體失效一回合）、改熱能加燃燒、改快感（沉溺可以用定力擋）。
- 換彈：不合這把槍的彈不在選項裡；選了之後快取格少一件、彈匣是滿的；打空之後下一匣是普通彈；監視的自動射擊、技能裡的攻擊也吃到彈的效果。
- 投擲物：兩格裡三個人用同一個骰面（紀錄裡三拍的骰面一樣）；掛在那兩格的無人機也被打到；距離 5 的格子選不了，原因是一句完整的話；閃光彈不造成傷害、沒過檢定的人下一回合少行動點。
- 立牌：下一次打那一格的人的攻擊打在立牌上、那個人不受傷、立牌沒了；再下一次照常。
- AI 的敵人拿著帶 `fx` 的武器，效果照樣發生。
- `fx`、`ammo`、`throw` 的欄位寫錯在載入時擋下。
