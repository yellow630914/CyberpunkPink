# M1b-skill-gunner-broker

- 交給：cpp-feature（sonnet）
- 目標：槍手與掮客兩棵樹裡通則寫不出來的那幾樣機制（戰鬥直覺的分配、守著一格、範圍的壓制、叫人的加項、勸降與收買、被贖回），並用假資料證明兩棵樹現在標 `pending` 的三十八個技能都寫得出來。
- 規格出處：SKILL_TREES「槍手：戰鬥直覺」「掮客：人面」兩節的「現實」欄（只看這兩節）；COMBAT_SYSTEM 第 5 節「壓制」、8.3 節（戰敗事件的選項）；dev/adr/0015 E1～E3、E7、E13。
- 可以改的路徑：`engine/src/features/abilities/`、`engine/src/features/defeat/`（只加「被贖回」這個選項的接點）、`engine/tests/features/M1b-skill-gunner-broker.test.ts`。
- 可以用的介面：M1b-skill-format 的格式；M1b-ops 的效果；`k.battle.on('moved' | 'attack.before' | 'turn.start', …)`；`performAction`。
- 不可以做的事：不改核心；不改 `engine/data/rules/abilities.json`（示意資料不動；鍵的對照寫在回報裡）；增援（名冊的人進場）與派工網、人脈的日常部分不做（E13，留 `pending`）。

## 一、新的鍵

| 鍵 | 用在 | 意思 |
|---|---|---|
| `instinct` | 戰鬥直覺 | 從只收下改成有效果：開打時把「樹階」點分到先攻、命中、迴避（每點先攻 +3、命中 +1、迴避 +1，每項最多 3）；多一個行動「重分配」（1 點、每回合一次；`picks` 三項）。預設的分法（AI 與沒選的玩家）：平均、多的給命中。心流用 `buff` 改三個數字：`instinct_points`、`instinct_cap`、`instinct_free`（這三個是這個功能自己認的修正名，不進核心的 `MOD_KINDS`） |
| `attack.suppress.area` | 彈幕、火力牆 | `adjacent`（目標相鄰一格上的人）或 `row`（敵方整排）也要過壓制的檢定；`dc_bonus` |
| `attack.suppress.auto` | 壓制姿態 | 命中就壓制、不必檢定（配 `mods` 的 `per_turn: 1`） |
| `ward` | 不准動喔 | `{ slot: 'target', until: 'own_turn_start', on: ['move', 'compact', 'attack'], do }`：守著敵方一格，那一格上的人第一次做這幾件事時做 `do` |
| `call.options` 的加項、`call.bonus` | 我有認識的人、派工網、人脈 | 叫人的選項可以由別的技能加（`alter`）；每場次數與支援射擊的命中吃 `mods`（修正名 `call_uses`、`call_hit`，同上是功能自己認的） |
| `parley` | 勸降、有話好好說、收買 | 寫成 `do` 就夠：`check`（交涉，對 `{ base: 10, per_grade: 2, elite: 2, boss: 4 }`）加 `status` 或 `out`。這一張只補一件事：`needs.no_rank` 與「重傷的雜兵才投降」的 `if` 寫法要驗得到 |
| `ransom` | 保釋 | 裝著的人在隊上時，戰敗的三個選擇之外多一個「被贖回」：付 `grade*1000` 的現金、跳過事件的內容。`features/defeat` 開一個登錄點（別的功能可以加戰敗的選項），這個功能往裡面註冊；兩邊不互相 import |

其餘的技能只用通則：走開啦（`attack` 加 `shift`）、穿透（`cover_shift`、`pierce`）、跑位射擊（`move` 加 `attack` 加 `cover`）、死線（`hp_half` 的反應）、獵眼與人槍合一（`mods`）、掩護撤退、獵殺節奏（`mods` 加 `ap`）、下一個！、一槍定局、子彈時間（`buff`）、還給你～（`after` 加 `if: 'miss'`）、有我在、代理（`cash` 加 `mag`）、擋（`hit` 的反應加 `favor`）、黑市門路、打他打他！、布陣與號令（姿態）、大局（`order`）、總攻令、護盤、全城欠我。

## 二、驗收條件（假資料：每個技能一筆最小的假技能，名字用設計書的，數字照設計書）

- 戰鬥直覺：2 階的人有 2 點；分配之後先攻、命中、迴避的明細各多對的數字；重分配花 1 點、一回合第二次灰掉；每項不能超過 3。
- 點放（`alter` 加 `as_pick`）：開了只花 2 格、壓制的 DC 是 16。
- 彈幕開著時連射的壓制打到相鄰一格的人、兩個人的 DC 都 +2；火力牆不花彈匣、敵方每個人各自檢定。
- 不准動喔：守著的那一格上的人換位時挨一槍（不花行動點、花彈匣），第二次不挨；到自己下一回合開始就失效。
- 下一個！：第一槍沒打倒就沒有第二槍。一槍定局：距離不到 5 時灰掉、原因是一句完整的話。
- 勸降：對沒有重傷也沒有餘韻的敵人灰掉；對重傷的雜兵成功是投降退出、對精英成功是暈眩；首領選不了。
- 收買：扣現金、目標失去下一回合；首領選不了；現金不夠灰掉。
- 擋：隊友要被重創時觸發、那一擊變成一般的命中、小人情少一個；沒有人情不觸發。
- 大局：兩個人的順位對調；被換到前面的人這一輪還沒動過就接著動、並拿回 1 點。
- 被贖回：隊上有裝著保釋的人、全隊倒下時多一個選項；選了扣對的金額、不進戰敗事件的內容；錢不夠時這個選項灰掉。
- 回報裡附一張表：兩棵樹五十四個技能各用了哪些鍵；寫不出來的列出原因（預期只有增援、戰前佈置與情報網的踩點部分、日常的部分）。
