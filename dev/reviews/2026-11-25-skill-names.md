# 技能名收斂盤點（2026-11-25）

> 只做盤點與建議，沒有改 docs/、engine/、ui/。範圍：SKILL_TREES.md 八棵樹 216 個技能、NIGHT_LESSONS.md 64 個夜課技能。
> 共鳴（每棵樹 5 個、夜課每分支 5 個）在表裡只有「階／效果／份量」，**沒有名字**，所以沒有可改的名稱。

## 1. 判斷原則

1. **看效果落在哪一欄。** 「現實」欄有效果的技能是現實技能，名字要收斂；只有「內海」或「輿論」欄有效果的（例如我不在家喔、說服蕾絲、握握手、我還可以！、我來擋！），算內海／輿論情境，可以保持可愛，不改。
2. **要拿掉的是撒嬌尾巴與疊字幼兒語。** 包括「～」「♡」「啦」「喔」「嘛」「囉」、「槍槍」「煙煙」「呼呼」「手手」「拆拆」「剪剪」這類疊字。
3. **名字改成俐落的動詞或名詞，但保留一點角色味。** 優先改成角色會說的短句（「討債」「護犢」「倒打一耙」），不要全改成冷冰冰的術語。
4. **有特色的口語可以留。** 留下的是不撒嬌的口語和有梗的名字，例如「謝謝招待」「我有認識的人」「全城欠我」「今天也第一名」「還不准睡」「看我的！」「下一個！」「小心後面！」「撞過去！」。偶像棵整棵是人設，口語多半在內海或輿論，只動一個。
5. **夜課分兩種改法。** 「收斂」是動作寫得太直接或口吻太幼兒化，改成含蓄的名字。「性感化」是名字本身可愛，但動作是挑逗的，改成成年人的口氣（低、慢、帶一點命令或暗示），不露骨。體位名（跪姿、騎乘、交纏、夾在中間、三王一後、膝上、綁縛、靠牆、抱起來）是通用詞，不動。
6. **改名不影響 id。** engine 的技能 id（例如 `sk_gunner_instinct`）與名字無關，只有顯示名要換；圖標的 id 是由名字算出來的，這點要注意（見第 4 節）。

## 4. 改名的影響

名字是從 docs 產生資料的，所以主要靠**重新產生**，不用手改多處。

**來源（手改）**

- `docs/content/SKILL_TREES.md`、`docs/content/NIGHT_LESSONS.md`：每個名字在自己檔案裡出現 1～6 次（定義列、前置欄、描述）。技能被當成別的技能的「前置」時，前置欄也要改。例如「看這邊♡」在 SKILL_TREES 出現 6 次、「乖孩子去吧」5 次、「插播一下喔」5 次、「呼呼不燙了」5 次。
- 其他 docs（`docs/systems/SKILLS.md`、`docs/systems/LEWD_SYSTEM.md`、`docs/content/ADULT_EVENTS.md`、`docs/DECISIONS.md` 等）有零星引用。
  - 樹的技能：只有 呼呼不燙了（2）、不痛不痛（1）、偷看是不行的喔（2）、我很清醒喔（2）、看錯人囉（1）、幫槍槍保養（1）在別的 md 出現，約 9 處。
  - 夜課：慢慢摸 4、貼貼 3、摸摸頭 2、交給你嘛 1、量量看 4、蹭蹭 6、噴一點點 12、要看好喔 6、冰冰的手 2、乖乖不動 2、兩邊都要 1，約 45 處。
  - 這些詞很多是一般詞彙，要逐處確認是不是真的在指技能。

**自動產生（不用手改，重跑）**

- `docs/art/icons/skills.csv`：每個技能 2 處（名字欄、`icon_manifest.py` 產生）。**圖標 id 是由名字算出來的**（`tools/art/gen_icons_l3.py` 說明），所以改名會讓 id 變、sprite 與圖標檔跟著換，需要重跑 `python3 tools/art/icon_manifest.py` 與 `gen_icons_l3.py`；`docs/art/style/icons-l3-sprite.svg` 也會變。手改的提示詞在 `icons/overrides.csv`（如果有）要同步。
- `ui/src/data/content.generated.ts`：由 `scripts/build-content.mjs` 產生（`npm run content`），每個技能 2～5 次。不用手改，重跑即可。
- `docs/book/CyberpunkPink-設計書.html`、`.pdf`：設計書合訂本，改完要重新建置（我沒有計入）。

**需要手改的程式與資料**

- `engine/data/rules/abilities.json`：技能的 `name` 欄與說明文字，要改的名字裡有 幫槍槍保養（3）、不准動喔（1）、走開啦（1）、還給你～（1）、換個位子嘛（1）、再加一點嘛（1）、打他打他！（2）共 10 處。技能的 id 沒有帶名字，不受影響。
- `engine/data/world/npcs.json`：「好多手」是敵人名，不是技能，**改夜課「好多手」時不要被連帶改到**（docs 裡有約 33 處是敵人或條目名）。
- `engine/src`（註解與少數字串）：不准動喔 2、偷看是不行的喔 3、敢打我家孩子？ 3、我演得很像吧 3、換個位子嘛 2、不要走嘛 1、欺負人家要賠喔 1、還給你～ 1、修修就好 1、幫槍槍保養 1、打他打他！ 1、兩邊都要 1，共約 20 處，多半是註解。
- `engine/tests`：測試的描述與斷言裡用名字查技能，約 **180～190 處**（看技能名單，例如 換個位子嘛 13、不要走嘛 12、不准動喔 15、暈乎乎 10、排好隊喔 10、看這邊♡ 9）。需要逐個檢查是用名字查還是用 id 查。
- `ui/src/data`：手寫的示意資料 `profile.ts`、`demo/scene.ts` 有用到夜課名（慢慢摸、偷偷看你等），約 5～10 處。

**合計**：手改的約 **70 處 docs**（來源檔 + 其他文件）、約 **10 處 engine/data**、約 **20 處 engine/src**、約 **180 處 engine/tests**、約 **10 處 ui 手寫資料**，另有重跑產生的 CSV、sprite、content.generated.ts、設計書合訂本。建議用「名稱對照表 + 腳本批次取代，再逐一檢查被誤傷的普通詞」來做，而不是手動逐一改。

**被引用次數最多、改了影響最廣的名字**（只計「真的是技能名」的疑慮最少的）：
